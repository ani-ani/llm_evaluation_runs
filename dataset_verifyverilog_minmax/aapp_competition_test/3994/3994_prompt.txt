Design a Verilog module named 'max_lights_on' that calculates the maximum number of simultaneously ON lights after periodic toggling.

Module interface:
module max_lights_on(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // pulse to begin computation
  input [2:0] n, // number of lights (1-8)
  input [7:0] init_state, // initial ON(1)/OFF(0) for 8 lights (bit 0 = light0)
  input [23:0] a_vals, // 8x3-bit a_i intervals (packed: [2:0]=light0, [5:3]=light1...)
  input [23:0] b_vals, // 8x3-bit b_i offsets (same packing)
  output reg [3:0] max_on, // maximum lights ON (0-8)
  output reg done // high when computation complete
);

Behavior:
1. On reset (rst_n=0), clear all states.
2. When start=1 pulll/'"'e""':
   - Set internal state registers to initial values
   - Begin time stepping from t=0 to maximum t=25
3. At each time step:
   - Update all lights where (t >= b_i) and ((t - b_i) % a_i) == 0
   - Track current ON count and update maximum
4. Output final max_on when all time steps computed (done=1).

Timing:
- Compute latency: Exactly 25 clock cycles after start pulse.
- All outputs (including done) must be registered.
- Use non-blocking assignments for all state updates.
