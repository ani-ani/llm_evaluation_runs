Design a sequential Verilog module named 'onion_protect' that finds the maximum number of onions protected by selecting K fence posts.

Module interface:
module onion_protect(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // pulse high to start computation
  input [3:0] num_onions, // N (1-8)
  input [3:0] num_posts, // M (3-8)
  input [3:0] select_count, // K (3-4)
  input [15:0] onion_x[0:7], // X coordinates of onions (8 onions max)
  input [15:0] onion_y[0:7], // Y coordinates of onions
  input [15:0] post_x[0:7], // X coordinates of fence posts (8 posts max)
  input [15:0] post_y[0:7], // Y coordinates of fence posts
  output reg [3:0] max_protected, // maximum protected onions count
  output reg done // high when computation complete
);

Behavior description:
1. On start pulse: Initialize all registers
2. Iterate through all combinations of K fence posts (using combinatorial number generator)\
3. For each combination:
   a. Compute convex hull of selected posts (if needed)\
   b. Check each onion against the convex hull using ray-casting point-in-polygon method
   c. Count number of onions inside hull
4. Track the maximum count across all combinations

Latency: Completion within (M choose K)*N*20 clock cycles worst case
Implementation note: Use state machine with states IDLE, COMB_GEN, HULL_CHECK, COUNT, DONE
