Design a sequential Verilog module named 'handsome_number_finder' that finds the closest handsome number(s) for 4-digit input.

A number is handsome if all consecutive digits have differing parity (even/odd) and single-digit numbers are handsome.

Module interface:
module handsome_number_finder(
  input clk,                   // Clock
  input rst_n,                 // Active-low reset
  input start,                 // Start computation
  input [13:0] num_in,         // Input number (4-digit max 9999)
  output reg [13:0] result1,   // First closest number
  output reg [13:0] result2,   // Second closest number (if tie)
  output reg valid,            // Result valid
  output reg tie_flag          // Set when two valid results exist
);

Behavioral description:
1. On reset: clear all outputs and internal states
2. When start asserted:
   a. Starting from num_in, search downwards and upwards simultaneously
   b. Check candidates for "handsome" property by comparing digit parity
   c. First valid candidate in each direction is stored
3. Output strategy:
   - If one candidate is closer: result1 = candidate, tie_flag=0
   - If equal distance: store smaller in result1, larger in result2, tie_flag=1
4. The module should complete within 100 clock cycles max.
5. Handsome check logic: Break numbers into 4 digits. For each digit pair (while valid), check even/odd properties alternate.
6. Digit extraction: tens place comparisons using modulo and division operations.

Timing: Output valid after variable latency (3-50 cycles depending on input). Valid signal asserted when results are ready.
