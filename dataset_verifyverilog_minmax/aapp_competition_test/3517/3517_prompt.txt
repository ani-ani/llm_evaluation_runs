Design a sequential Verilog module named "critical_path_optimizer" that finds the shortest critical path when one step can be eliminated in a 4-step process.
Module interface:
module critical_path_optimizer(
  input clk,                    // clock signal
  input rst_n,                  // active-low reset
  input start,                  // start computation
  input [1:0] node_count,       // number of steps (2-4)
  input [7:0] time_vals [0:3],  // step times (4 elements)
  input [3:0] deps [0:3]        // dependency bitmask for each node (bit i set = depends on node i)
  output reg [7:0] min_time,    // minimal critical path time
  output reg done               // high when computation complete
);

Behavior:
1. When start=1, compute critical path for the DAG when each step's time is set to 0 (one at a time), keeping the minimum result.
2. Use an adjacency matrix representation with max 4 nodes.
3. Implement topological sorting using fixed 4-state logic.
4. Output valid when done=1, with min_time containing the result.
5. Requires max 40 clock cycles (10 per node elimination check).
Timing:
- Output becomes valid within 40 clock cycles after start asserted
- Use a state machine with states: IDLE, CALCULATE_BASELINE, TRY_ELIMINATE, DONE",
