Design a Verilog module named 'resistance_calculator' that calculates the minimum number of unit resistors required to achieve resistance a/b.

Module interface:
module resistance_calculator(
  input clk,                    // system clock
  input rst_n,                  // active-low reset
  input start,                  // pulse high to start computation
  input [15:0] a,               // numerator (1 ≤ a ≤ 65535)
  input [15:0] b,               // denominator (1 ≤ b ≤ 65535)
  output reg [15:0] result,     // minimum resistor count
  output reg done               // high when computation completes
);

Behavior: When start is asserted, module begins computation. Uses iterative algorithm:
  1. Initialize count = 0, x = a, y = b
  2. While y ≠ 0:
      count += x / y
      x, y = y, x % y
  3. Store count in result and assert done

Timing: Variable latency - completes within 50 clock cycles maximum. done asserts at end of computation.
