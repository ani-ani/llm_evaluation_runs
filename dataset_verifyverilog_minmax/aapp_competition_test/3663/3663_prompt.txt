Design a sequential Verilog module named 'army_move_calculator' that calculates the minimum transport cost for army redistribution across a tree-structured network of up to 8 nations. Module interface:
module army_move_calculator(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // start calculation
  input [3:0] num_nations, // 0-8 nations (0=none, 1-8 valid)
  input [3:0] parent_node [0:7], // parent for each node (4-bit per node)
  input [15:0] move_costs [0:7], // cost to parent (16-bit per node)
  input [15:0] init_armies [0:7], // x_i initial armies
  input [15:0] req_armies [0:7], // y_i required armies
  output reg [31:0] total_cost, // accumulated cost (32-bit)
  output reg done // high when calculation complete
);

Behavioral description:
1. The module processes nations in order from leaves to root (smallest to largest index).
2. For each nation: Calculate army surplus/deficit, add cost*|movement| for transferring armies to/from parent.
3. Move surplus armies to parent nation (or request deficit from parent).
4. Accumulate total_cost as sum(c_i * |army_movement|) across all edges.
Latency: Result valid 16 clock cycles after start asserted.
State machine:
- IDLE (wait for start)
- PROCESS_BFS (compute node processing order)
- CALCULATE (process nodes and accumulate costs)
- DONE (assert done)
