Design a sequential Verilog module named 'fluid_optimizer' that implements a simplified gradient ascent algorithm to maximize F^a * W^(1-a). Use Q8.8 fixed-point (16-bit: 8 int, 8 frac) throughout.

Module interface:
module fluid_optimizer(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [15:0] v, // Viscosity in Q8.8
  input [15:0] a, // Alpha in Q8.8
  input [2:0] pipe_j [0:15], // Pipe start nodes (8 pipes max)
  input [2:0] pipe_k [0:15], // Pipe end nodes
  input [7:0] pipe_cap [0:15], // Pipe capacities (water)
  input [3:0] p, // Actual pipe count (1-8)
  output reg [15:0] flubber_rates [0:15], // Q8.8 Flubber rates
  output reg [15:0] water_rates [0:15], // Q8.8 Water rates
  output reg [15:0] optimal_value, // Maximized value Q8.8
  output reg done // Computation complete
);

Behavior:
1. On reset, clear all rates and outputs
2. When start==1, begin gradient optimization
3. Initialize all flows to zero
4. Perform 256 iterations of gradient ascent
5. Each iteration updates flow rates while enforcing:
   (v * f + w) <= capacity (all pipes)
   Flow conservation at all nodes except 1 (Flubber), 2 (Water), 3 (FD)
6. After final iteration, output pipe rates and optimal value
7. Assert done signal when complete
Latency: 256 cycles after start assertion.
