Design a sequential Verilog module named `knight_placement_generator` that generates initial knight coordinates following a specific placement pattern.

Module interface:
module knight_placement_generator(
  input clk, // Clock signal
  input rst_n, // Active-low reset
  input start, // Start generation
  input [3:0] n, // Number of knights (1-16)
  output reg [7:0] x, // X-coordinate (8-bit signed)
  output reg [7:0] y, // Y-coordinate (8-bit signed)
  output reg valid, // Current output is valid
  output reg done // All coordinates generated
);

Behavioral description:
1. When start is asserted, begin generating n coordinate pairs
2. Output coordinates follow this pattern (0-indexed i):
   - If i < n//3*2:
     * When i even: x = i, y = 0
     * When i odd: x = i-1, y = 3
   - Else: x = i, y = 0
3. Output valid for 1 cycle per coordinate with 1 cycle delay between outputs
4. Processing completes in n+3 cycles max (assert 'done' next cycle after last valid)
5. Use 4-bit counter to track current knight index (0 to n-1)
6. Reset values: x=0, y=0, valid=0, done=0
7. Implementation must match pattern from these examples:
   n=4 → [(0,0), (1,0), (1,3), (2,0)]
   n=7 → [(0,0), (1,0), (1,3), (2,0), (3,0), (3,3), (4,0)]
