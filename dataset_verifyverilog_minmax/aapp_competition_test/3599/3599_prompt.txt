Design a sequential Verilog module named 'break_scheduler' that schedules musician breaks ensuring at most 2 musicians are absent at any time.
Module interface:
module break_scheduler(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // start computation
  input [3:0] T, // concert length (4 bits, 0-15)
  input [2:0] N, // number of musicians (3 bits, max 5)
  input [4:0][3:0] breaks, // 5x4-bit break lengths (packed for 5 musicians)
  output reg [4:0][3:0] start_times, // 5x4-bit start times
  output reg done // high when computation complete
);

Behavioral description:
1. When start is asserted, the module begins scheduling break start times for up to 5 musicians
2. Use an algorithm that ensures no more than 2 musicians have overlapping breaks
3. Output start_times when computation completes (each musician's start time <= T - break_length)
4. Assert done signal when results are valid (latency: 10 clock cycles after start)
5. All inputs and outputs use unsigned integer representation
6. Module must handle max N=5 musicians and T=15 minutes
Timing: Output becomes valid 10 clock cycles after start is asserted. Maintain done signal until reset.
