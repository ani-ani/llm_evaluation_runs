Design a sequential Verilog module named 'longest_twice_subarray' that finds the longest consecutive sub-array where each element appears exactly twice.

Module interface:
module longest_twice_subarray(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // pulse high to start computation
  input [3:0] arr [0:7], // 8-element array (each element 4-bit)
  output reg [3:0] max_length, // longest valid sub-array length (0-8)
  output reg done // high when computation completes
);

Behavioral description:
1. On reset, all internal registers reset to zero.
2. When start is pulsed high:
   - Load input array into internal memory
   - Initialize left=0, right=0 pointers and frequency counters (16 counters, each 2-bits)
3. State machine progresses through elements (right pointer moves each cycle):
   - Increment freq[arr[right]] when element added to window
   - When freq[arr[right]] > 2: move left pointer until freq reduces <=2
   - Track maximum window length where all elements' freq == 2
4. Output valid max_length when done asserts (after 15 clock cycles max)
5. Signal timing: done asserts 15 cycles after start.
6. Use non-blocking assignments for all internal state changes.

Implementation notes:
- Use 16 frequency counters (each 2-bit) for 4-bit element values (0-15)
- Max window size tracking requires comparing current window length
- When computing validity, check that all non-zero counters == 2
