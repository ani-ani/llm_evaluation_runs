Design a combinational Verilog module named 'media_companies_counter' that calculates the maximum number of non-overlapping media company assignments.

Parameters:
- Fixed stadium size: N = 8 sectors
- Input constraints: K value scaled to 1-8, C value scaled to 1-8

Module interface:
module media_companies_counter(
  input [2:0] k, // Minimum consecutive sectors [1-8] (3 bits)
  input [2:0] c, // Minimum distinct colors [1-8] (3 bits)
  input [7:0] sectors [0:7], // Team IDs (8-bit each)
  output reg [3:0] company_count // Maximum companies (0-4 possible)
);

Behavior:
- The module must find the maximum number of non-overlapping intervals where:
  1. Each interval has ≥ K consecutive sectors
  2. Each interval has ≥ C distinct team colors
- Implement greedy left-to-right scanning (earliest valid segments first)
- All inputs should be treated as unsigned integers
- Purely combinational logic (no clocks needed)

Implementation note:
Use nested loops (unrolled for fixed N=8) to:
1. Find valid segments starting from current position
2. Take first valid segment meeting conditions
3. Advance to next position after segment
4. Count total valid segments possible
