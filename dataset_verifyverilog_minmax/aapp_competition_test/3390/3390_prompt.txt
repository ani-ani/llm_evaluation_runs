Design a sequential Verilog module named 'longest_menu_path' that finds the longest path without repeated dishes in an 8-node directed graph.

Module interface:
module longest_menu_path(
  input clk, // System clock
  input rst_n, // Active-low reset
  input start, // Start computation (pulse high) when inputs are ready
  input [3:0] n, // Number of dishes (1-8) (0-based input: 0=1 dish, 7=8 dishes)
  input [63:0] adjacency, // Adjacency matrix (flattened 8x8) [i][j] = dish i+1 to j+1 edge
  output reg [3:0] max_path_length, // Maximum found path length (0-8)
  output reg done // High when computation complete
);

Behavior:
- On reset: clear outputs and internal state
- When start is asserted: begin path computation through all valid nodes (0 to n-1)
- Computes longest path without repeating any dish using BFS with backtracking
- Supports graph sizes n ≤ 8 (n input specifies actual node count)
- Output becomes valid when done=1 (latency varies with graph complexity)
- Ignores edges connecting nodes >= n
- Adheres to max 8-node constraint (for benchmarking purposes)
