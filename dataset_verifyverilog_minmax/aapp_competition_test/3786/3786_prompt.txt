Design a sequential Verilog module named 'apple_collector' that calculates the number of apples Arcady collects using depth-level parity.
Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [2:0] n // number of nodes (3-8 valid)
input [2:0] p_2, p_3, p_4, p_5, p_6, p_7, p_8 // parent nodes (values < node index)
Outputs:
output reg [3:0] result // final apple count (0-8)
output reg done // high when computation complete
Behavior:
1. On reset, all registers clear and FSM returns to IDLE
2. When start is asserted in IDLE state:
   a. Compute depth for each node (depth[i] = depth[p_i] + 1)
   b. Count nodes per depth level (max depth = 7)
   c. Sum parity (count mod 2) for all depth levels
3. Latency: Result valid 16 clock cycles after start
4. FSM States: IDLE, CALC_DEPTHS, COUNT_LEVELS, SUM_PARITY, DONE
Interface constraint: Valid only for n=3 to 8. Input p_i valid only when i <= current n.
