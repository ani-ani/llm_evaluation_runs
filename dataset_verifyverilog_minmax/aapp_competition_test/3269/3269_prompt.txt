Design a sequential Verilog module named 'digit_distance_accumulator' that calculates the sum of digit-wise distances between all number pairs in [A,B].

Inputs:
input clk           // clock
input rst_n         // active-low reset
input start         // pulse high to start computation
input [15:0] A      // 4-digit BCD number (A <= B)
input [15:0] B      // 4-digit BCD number

Outputs:
output reg [31:0] result  // sum modulo 1000000007
output reg done            // high when computation complete

Behavior:
1. On reset, set result=0, done=0
2. When start=1:
   a. Iterate through all numbers X from A to B (inclusive)
   b. For each X, iterate through all numbers Y from A to X
   c. For each pair (X,Y):
      i. Calculate distance as sum(|X_digit[i] - Y_digit[i]|) for i=0 to 3
      ii. Add distance to accumulated sum (mod 1000000007)
3. Set done=1 when computation finishes, result holds final value

Timing:
- Computation latency depends on input range (maximum 100M cycles for 0-9999)
- All signals sampled on rising clock edge
- New computation starts only when done=1 and start=1

Note: All numbers represented as 4-digit BCD (4 bits per digit, total 16 bits). Upper digits unused if number has fewer than 4 digits.
