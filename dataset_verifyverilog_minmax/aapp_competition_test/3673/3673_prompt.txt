Design a sequential Verilog module named 'arrow_reconstruction' that reconstructs dance arrows from permutation data after K moves.

Module Interface:
module arrow_reconstruction(
    input clk,               // system clock
    input rst_n,             // active-low reset
    input start,             // start processing (pulse high for 1 cycle)
    input [15:0] K,          // number of moves (16-bit max 65535)
    input [3:0] a[15:0],     // end permutation (16 elements, each 4-bit)
    output reg [3:0] arrows[15:0], // reconstructed arrows (16 elements)
    output reg done           // high when computation complete
);

Behavior:
1. On start pulse, begin processing the permutation data in array a[].
2. The module must find the initial arrow configuration such that applying the permutation K times results in the given a[] permutation.
3. Algorithm: For each element, determine its cycle in the permutation, compute the inverse permutation with (cycle_length - (K % cycle_length)) % cycle_length steps, then reconstruct arrows[].
4. Output valid when done=1 (high) with latency of up to 256 cycles (16 elements * 16 cycles max).
5. Use at least these states: IDLE, FIND_CYCLES, COMPUTE_BACK_STEPS, DONE.
6. If any cycle verification fails (impossible case), set arrows[] to all 0s and done=1.
