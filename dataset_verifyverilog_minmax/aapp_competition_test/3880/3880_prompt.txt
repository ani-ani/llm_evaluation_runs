Design a sequential Verilog module named 'max_array_sum' that computes maximum possible sum after optimal sign-flip operations.

Inputs:
- input clk          // Clock
- input rst_n        // Active-low reset
- input start        // Start computation (pulse) 
- input [3:0] n_mode // Current n (2 ≤ n ≤ 8) 
- input [15:0] data [14:0] // 15 signed 16-bit elements (2n-1 valid)

Outputs:
- output reg [15:0] max_sum // Maximum possible sum (unsigned)
- output reg done            // High when result valid

Behavior: On start pulse, module:
1. Resets all counters (neg_count=0, sum_abs=0, min_abs=32767)
2. Iterates through array elements (15 cycles):
   - Adds absolute value to sum_abs
   - Counts negative elements in neg_count
   - Tracks minimum absolute value in min_abs
3. Computes result (next 3 cycles):
   - If n_mode[0]=1 (odd n) || neg_count[0]=0 (even negatives): result = sum_abs
   - Else: result = sum_abs - 2*min_abs
4. Asserts 'done' and holds result until next start.

Timing: Inputs must be stable during processing. Result valid 20 cycles after start.
Note: Only first (2*n_mode-1) array elements are considered.
