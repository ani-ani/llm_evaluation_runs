Design a sequential Verilog module named 'phaser_max_hits' that calculates the maximum room intersections for a phaser beam with discretized angles. Inputs: clk (clock), rst_n (active-low reset), start (begin computation), room_count [3:0] (number of rooms, 1-15), length [9:0] (beam length 1-1000), rooms_array [14:0][39:0] (packed array of 15 rooms, each room = {x1[9:0], y1[9:0], x2[9:0], y2[9:0]}). Outputs: max_hits [3:0] (max rooms hit 0-15), done (high when result ready).

Behavior:
1. Discretize beam angle to 16 fixed directions (0 to 337.5 degrees in 22.5 degree steps)
2. For each angle, compute beam endpoint (x + l*cos(θ), y + l*sin(θ)), quantized to integer coordinates
3. For each room, check beam segment intersection using rectilinear collision check
4. Track maximum count over all angles
5. Output available 16-20 cycles after start assertion (varies with room_count)
Precompute fixed-point cos/sin values in Q8.8 format for angles (stored in ROM).
