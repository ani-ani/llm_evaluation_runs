Design a sequential Verilog module named 'fence_painter' that finds the minimal acceptable painter offers for a 16-section fence.
Inputs:
  input clk, // clock
  input rst_n, // active-low reset
  input start, // pulse high to begin computation
  input [3:0] num_offers, // number of offers (1-8)
  input [7:0][15:0] offer_data, // 8 offers packed as {color[2:0], start[3:0], end[3:0]} (each 7 bits)
Outputs:
  output reg [3:0] min_count, // minimum offers needed (0-8)
  output reg impossible, // high when no solution exists
  output reg done // high when computation completed

Behavior:
1. Accepts up to 8 painter offers. Each offer has:
   - Color ID (3 bits, 0-7 represents different colors)
   - Start section (4 bits, 0-15)
   - End section (4 bits, >= start)
2. When start pulse is detected:
   - Enumerate all possible offer combinations (2^8 max)
   - For each combination:
      a) Check if it covers all 16 sections without gaps
      b) Verify uses ≤ 3 distinct colors
   - Track minimum valid offer count
3. Output either:
   - min_count = minimal offer count found (valid when impossible=0)
   - impossible=1 if no valid combinations found
4. Timing: Requires up to 256 cycles (1 cycle per combination). Done asserts when computation completes.

Implementation Notes:
- Use bitmask (8-bit) to iterate through all combinations
- Maintain these registers:
   current_mask[7:0] - current offer combination
   coverage[15:0] - represents covered sections
   color_count[2:0] - count of unique colors used
   color_present[7:0] - 1 bit per color
- Use parallel section coverage expansion (OR all selected offers' coverage)
- Use combinational logic for coverage and color counting
