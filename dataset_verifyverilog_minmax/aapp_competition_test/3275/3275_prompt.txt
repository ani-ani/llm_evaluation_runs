Design a sequential Verilog module named 'painting_purchases' that calculates the number of valid purchase combinations where at least C clients choose colored paintings.

Module interface:
module painting_purchases(
  input clk,                // clock
  input rst_n,              // active-low reset
  input start,              // start calculation
  input [1:0] client_sel,   // client select (0-3)
  input [7:0] a_i,          // max colored paintings for selected client (≥1)
  input [7:0] b_i,          // max B&W paintings for selected client (≥1)
  input [3:0] C_param,      // C value (1-4)
  output reg [15:0] result, // number of valid combinations % 10007
  output reg done           // high when calculation complete
);

Behavior:
- On reset: Clear all registers
- When start=1: Load 4 client parameters (client_sel=0→3 cycles) with a_i/b_i
- After loading: For each subset of clients (16 possible):
  • If subset size ≥ C: multiply (a_i+1) for clients in subset, (b_i+1) for others
  • Else: multiply by 0 for that subset
- Sum all valid subset contributions modulo 10007
- Result available after 20 clock cycles (for N=4,C=4) with done=1

Registers required:
reg [7:0] a[0:3];  // stored client a_i values
reg [7:0] b[0:3];  // stored client b_i values
Use combinational logic for subset evaluation and modulo reduction.
