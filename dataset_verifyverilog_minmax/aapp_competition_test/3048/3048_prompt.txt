Design a combinational Verilog module named 'path_counter' that counts the number of optimal paths of length exactly 2 in a tree with up to 16 junctions. Each path is considered as an ordered pair (u -> v) where the shortest path between u and v is exactly 2 edges.

Inputs:
input [3:0] N - number of junctions (1 ≤ N ≤ 16)
input [255:0] adjacency_matrix_flat - flattened adjacency matrix (16x16) where bit [16*i + j] represents presence of a direct road between junction i and j. If either junction index >= N, ignore the bit.

Outputs:
output [7:0] count - total number of optimal paths of length 2

Behavior:
For each ordered pair (u, v) where u ≠ v and u < N and v < N:
1. Check no direct road exists (adjacency_matrix_flat[16*u + v] == 0)
2. Check if ∃w (0 ≤ w < N) with roads u->w and w->v (adjacency_matrix_flat[16*u + w] == 1 && adjacency_matrix_flat[16*w + v] == 1)
Count increments by 1 for each valid (u, v) pair. Module must be purely combinational.
