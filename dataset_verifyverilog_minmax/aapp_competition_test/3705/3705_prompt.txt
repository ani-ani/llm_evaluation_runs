Design a combinational Verilog module named 'phone_number_counter' that calculates the maximum number of 11-digit phone numbers (starting with '8') that can be formed from given digit cards.

Module interface:
module phone_number_counter(
  input [4:0] n,           // Number of cards (1-32)
  input [127:0] s,         // 32 digits packed left-aligned (MSB [127:124] = first digit)
  output reg [1:0] count   // Maximum number of phone numbers (0-2)
);

Behavior:
- Only consider first n digits in s (each 4-bit group represents a digit 0-9)
- Count occurrences of '8' (4'b1000) in valid digits
- Calculate max phone numbers as minimum between '8' count and floor(n/11)
- Output 'count' must update combinationally

Implementation notes:
- floor(n/11) can be determined by: 2 when n >=22, 1 when 11<=n<22, 0 otherwise
- Example: n=22 + two '8's => count=2
- Use parallel comparators for '8' detection and adder tree for counting
