Design a sequential Verilog module named 'balanced_paren_replace' that determines # replacement counts for 8-character inputs.

Inputs:
input clk
input rst_n
input start // Start processing
input [7:0] char [7:0] // 8 characters (ASCII encoded: '('=40, ')'=41, '#'=35)

Outputs:
output reg valid // High when computation complete
output reg error // High when result is -1 (invalid)
output reg [3:0] replace_counts [7:0] // Replacement counts (0 unused when no # present)

Behavior:
- On reset (rst_n=0), initialize all signals.
- When start=1, begin processing input string over 8 clock cycles.
- Track balance (initial 0): +=1 for '(', -=1 for ')', -=assign for '#'.
- For each '#', assign 1 except last which gets all remaining balance.
- If any time balance <0 or final balance !=0 → error=1.
- After 8 cycles, output valid=1 and results. First #'s counts in replace_counts[0], etc.

Timing:
Latency: Valid output 9 cycles after start assertion (8 processing + 1 output).
Example:
Input "(((#)((#" → replace_counts[0]=1, [1]=2 (others 0), error=0.
