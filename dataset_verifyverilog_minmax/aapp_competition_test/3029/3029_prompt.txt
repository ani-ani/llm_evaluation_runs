Design a Verilog module named tree_jumping_path that computes the longest non-decreasing jumping path (L) and its count modulo 11092019 (M_mod) for a tree with 4 nodes. The module is sequential and requires a clock and active-low reset.

Inputs:
input clk              // clock
input rst_n            // active-low reset
input start            // start computation
input [15:0] u_1, u_2, u_3, u_4  // node labels (node 1 is root)
input [1:0] p_2, p_3, p_4        // parent indices (each 2 bits, valid for nodes 2-4, p_i < i)

Outputs:
output reg [2:0] L     // longest path length (range 1-4)
output reg [15:0] M_mod // number of paths mod 11092019
output reg done        // high when computation complete

Behavior:
- On reset (rst_n=0), the module initializes internal state and sets outputs to zero.
- When start is asserted, the module begins processing the tree.
- Each node is processed in order from 1 to 4. Node 1 is the root and is initialized with l=1 and c=1.
- For nodes 2-4, the longest non-decreasing path ending at each node is computed by traversing ancestors, finding the maximum l[j] where u_j <= u_i and summing counts c[j] for that maximum.
- The module then computes the global L (maximum l[i] across all nodes) and M_mod (sum of c[i] for nodes with l[i] == L, modulo 11092019).
- The done signal is asserted after processing is complete (approximately 16 clock cycles).

Timing:
- All inputs are sampled when start is high.
- The result is valid when done is high.
- Computation should complete within 16 clock cycles after start is asserted.
