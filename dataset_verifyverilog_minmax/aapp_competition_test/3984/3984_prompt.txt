Design a Verilog module named 'string_game_winner' that determines the winner (Mike or Ann) for each position in an input string.

Module interface:
module string_game_winner(
  input clk,              // clock signal
  input rst_n,            // active-low reset
  input start,            // pulse high to start processing
  input [3:0] str_len,    // string length (1-15 accepted, 0=empty)
  input [7:0] char_in,     // ASCII character input (serial)
  output reg [15:0] results, // bitmask results (1=Ann, 0=Mike)
  output reg done          // high when all results ready
);

The module should:
1. On reset (rst_n=0), clear all results and reset done to 0
2. When start pulses high:
   a. Accept str_len input as number of characters to process (max 15)
   b. Process char_in over str_len clock cycles (one char per cycle)
3. For each character index k (0-indexed):
   a. If k != 0 and current_char > running_minimum: set results[k]=1 (Ann wins)
   b. Else: set results[k]=0 (Mike wins)
   c. Update running_minimum with current_char if smaller
4. After str_len cycles:
   a. Set done=1 until next reset
   b. Hold results for all positions (bits beyond str_len-1 should be 0)

Notes:
- First character (k=0) always outputs Mike (results[0]=0)
- Running minimum is initialized to 'z' (ASCII 122) on start
- Behavior undefined if start pulses while processing previous string
- Latency: str_len+1 cycles from start pulse to valid results
- All assignments must use non-blocking operators (<=)
