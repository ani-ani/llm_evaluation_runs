Design a sequential Verilog module named 'minimal_phone_calls' that computes the minimal phone calls based on detector data.

Module interface:
module minimal_phone_calls(
  input clk,
  input rst_n,
  input start,
  input [3:0] N,        // Number of detectors (1-8)
  input [15:0] M,      // Total houses (2-65535)
  input [15:0] P0,     // Detector 0 position
  input [31:0] C0,     // Detector 0 count
  input [15:0] P1,
  input [31:0] C1,
  input [15:0] P2,
  input [31:0] C2,
  input [15:0] P3,
  input [31:0] C3,
  input [15:0] P4,
  input [31:0] C4,
  input [15:0] P5,
  input [31:0] C5,
  input [15:0] P6,
  input [31:0] C6,
  input [15:0] P7,
  input [31:0] C7,
  output reg [31:0] result,
  output reg done
);

Behavior:
1. On start pulse, load all inputs into internal registers
2. Sort detectors by position (P) in ascending order using bubble sort (takes 7+6+...+1=28 cycles)
3. Compute required minimal calls as max(C_i, C_{i+1} - C_i for adjacent detectors)
4. Result available 100 clock cycles after start signal (includes sorting + computation)
5. Done signal asserts when result is valid

Note:
- Only first N detectors should be processed
- Upper detector count limit: 32-bit outputs
- Implementation must handle up to 8 detectors
- All arithmetic is unsigned integer
