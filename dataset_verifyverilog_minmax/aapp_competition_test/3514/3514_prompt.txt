Design a sequential Verilog module named 'max_bombs_disarmed' that calculates the maximum disarmable buildings in an 8x8 grid.
Inputs:
  input clk,              // System clock
  input rst_n,            // Active-low reset
  input start,            // Start calculation (pulse high)
  input [63:0] grid_data  // Flattened grid data (64 bits: 8 rows of 8 bits, 1='x', 0='.')
Outputs:
  output reg [2:0] max_count, // Maximum disarmable buildings (0-7)
  output reg done           // Asserted when calculation complete

Functionality:
1. On reset: Clear all outputs and internal state
2. When start is pulsed:
   a. Accept grid_data representing an 8x8 grid
   b. Build row_armed[7:0] (1 bit/row) - for row x: 1 if any building in row x armed
   c. Build col_armed[7:0] (1 bit/col) - for col y: 1 if any building in col y armed
3. Compute maximum possible disarm sequence count as:
   - If total armed buildings == 0: 0
   - Else if any building has both row_armed and col_armed: max_count = total_armed
   - Else: max_count = total_armed - 1
4. Output available 2 clock cycles after start pulse with done asserted

Note: This implements the optimal disarm strategy where all buildings can be disarmed if at least one building has both row and column armed neighbors.
