Design a sequential Verilog module named `swap_sort_min_steps` that computes the minimum swaps required to sort a permutation.

Module interface:
module swap_sort_min_steps(
  input clk, 
  input rst_n, 
  input start, 
  input [3:0][1:0] initial_perm,  // 4 elements, each 2 bits (values 1-4)
  input [5:0][3:0] allowed_swaps, // Max 6 swaps, each 4 bits (2 bits per index A/B)
  input [2:0] m_swaps,          // Actual number of swaps (0-6)
  output reg [3:0] min_steps,   // Min swaps needed (0-15)
  output reg done               // High when computation complete
);

Behavior: On start signal, performs BFS through permutation space using allowed swaps.
Latency: Worst-case 24 states * 3 cycles/state = ~72 cycles. Done asserts when result is ready.
Implementation: Use state machine with visited states (24 possible) and swap application logic.
Constraints: Supports N=4 permutations (1-4) and M up to 6 allowed swap pairs.
