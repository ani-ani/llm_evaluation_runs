Design a sequential Verilog module named 'max_secure_rooms' that finds the optimal door to secure in a small building.

Module interface:
module max_secure_rooms(
    input clk,                // Clock signal
    input rst_n,              // Active-low reset
    input start,              // Start computation
    input [3:0] num_rooms,    // Number of rooms N (0 < N <= 8)
    input [3:0] num_doors,    // Number of doors M (0 < M <= 16)
    input [31:0] door_data [0:15],  // Door list (packed as {u[3:0], v[3:0]} per door)
    output reg [2:0] result,  // Max secured rooms (0-8)
    output reg done           // High when computation completes
);

Behavioral description:
1. Implements bridge detection via iterative DFS for small graphs (max 8 nodes).
2. Finds door whose removal creates largest component without external connection
3. Expects node -1 (external) encoded as 4'b1111 (3-bit extended to 4'b)
4. Uses state machine with:
    - IDLE: Wait for start signal
    - BUILD_GRAPH: Convert door_data to adjacency list
    - FIND_BRIDGES: Detect all bridge edges
    - EVAL_COMPONENTS: Calculate component sizes
    - OUTPUT: Set result and assert done
5. Latency: Maximum 40 clock cycles after start assertion
6. Result is the size of largest protected component when securing one bridge edge
7. Reset initializes all registers and FSM to IDLE state. Use non-blocking assignments.
