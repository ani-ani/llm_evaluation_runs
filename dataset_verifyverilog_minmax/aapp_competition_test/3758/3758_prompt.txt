Design a sequential Verilog module named 'packman_optimizer' that calculates the minimum time for Packmen to eat all asterisks on a 16-cell grid.
Module interface:
module packman_optimizer(
  input clk, 
  input rst_n, 
  input start, 
  input [15:0] game_field, // 16-bit field: 01='*', 10='P', 00='.' 
  output reg [5:0] min_time, // 6-bit output (max time 32) 
  output reg done // high when computation completes
);

The module should perform a binary search algorithm to find the minimum time.
Behavior description:
1. On reset (rst_n=0), reset all states and outputs
2. When start=1:
   a. Parse game_field into Packmen and asterisk positions
   b. Perform binary search between l=0, r=32 (6-bit range)
   c. For each midpoint m, check if all asterisks can be eaten within m time units
   d. Iterate until r-l>1
3. Output final r value when done=1

Timing requirements:
- Computation should complete within 6 clock cycles after start assertion.
- Use pipelined comparisons where advantageous.
- Implement position parsing as combinational logic.
- Binary search logic should be implemented with sequential state transitions.
