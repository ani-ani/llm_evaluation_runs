Design a sequential Verilog module named 'matrix_recover' that reconstructs a 4x4 binary matrix from row and column parity constraints with maximum ones and minimum binary value priorities.

Module interface:
module matrix_recover(
  input clk,             // system clock
  input rst_n,           // active-low reset
  input [3:0] R,         // row parity bits (LSB=top row)
  input [3:0] C,         // column parity bits (LSB=left column)
  output reg [15:0] matrix, // flattened matrix [row0_col3:row0_col0, ..., row3_col3:row3_col0]
  output reg valid       // 1 = valid solution, 0 = -1
);

Behavioral description:
The module should find a 4x4 binary matrix meeting these conditions:
1. Row parities match input R (bit0 for row0, bit1 for row1, etc)
2. Column parities match input C (bit0 for col0, bit1 for col1, etc)
3. Maximal number of 1's
4. Smallest row-concatenated binary value if multiple solutions exist

Implementation strategy:
- Start with all 1s matrix (max ones)
- Iteratively flip bits from LSB (row3_col3) to MSB (row0_col0)
- Maintain row/column parity conditions
- Finish when no improvements possible or after fixed cycles

Timing: Result valid 10 clock cycles after reset deassertion. Use a state machine with these states: IDLE, INIT, ROW_ADJUST, COL_ADJUST, VERIFY, DONE.
Output -1 equivalent is valid=0 with matrix=0.
