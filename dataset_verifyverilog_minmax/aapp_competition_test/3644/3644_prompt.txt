Design a sequential Verilog module named 'hr_scheduler' that calculates the minimum HR staff needed for worker management.
Inputs:
input clk,
input rst_n,
input start, // Start processing
input [2:0] n, // Number of days (1-8)
input [7:0] fi [0:7], // Fire counts per day (8 days max)
input [7:0] hi [0:7] // Hire counts per day (8 days max)

Outputs:
output reg [3:0] min_hr_count, // Minimum HR people needed
output reg [3:0] hr_assign [0:7], // HR assignments per day
output reg done // High when computation complete

Behavior:
- At posedge clk when start=1, begin processing
- Fire counts must obey LIFO order: FIRED workers are removed from last-hired-first-fired
- HR assignment constraints: For each fired worker, current HR person != their original HR person
- Process days sequentially (1 cycle per day)
- Output 'done' pulses high when all days processed

Implementation notes:
- Use an internal stack memory [255:0][7:0] to track worker hire HR IDs (max 256 workers)
- Stack pointer tracks current worker count
- For each day: pop fi workers, check HR conflicts → log which HR IDs cannot be used
- Assign new HR ID to hi workers that minimizes total count (priority encoder)
- Output hr_assign when all days processed
