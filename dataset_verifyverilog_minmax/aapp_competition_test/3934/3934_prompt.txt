Design a combinational Verilog module named 'tree_edge_operation_check' that determines if a configuration is possible for a tree with fixed 8 nodes.

Inputs:
input [2:0] node_id [7:0] // Array of 8 node IDs (0-7)
input [7:0] adj_matrix [7:0] // 8x8 adjacency matrix (1 = edge exists, 0 = no edge)

Output:
output reg result // 1=YES (no degree-2 nodes), 0=NO (has degree-2 node)

Behavior:
For each node, calculate its degree (count adjacent edges). If ANY node has degree 2, output 0 (NO). Else output 1 (YES).

Implementation:
- Use parallel adders to calculate each node's degree
- Compare each degree to 2 in parallel
- OR all failure flags to generate final result

Note: All degrees should be between 0-7 (3-bit counters). Input tree must be valid (connected, no cycles, n=8 nodes).
