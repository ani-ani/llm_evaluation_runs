Design a sequential Verilog module named 'dora_city_height' that solves the scaled-down problem for a 4x4 grid. Inputs:
- input clk // clock
- input rst_n // active-low reset
- input start // start computation
- input [15:0] a[0:3][0:3] // grid heights (4x4 elements, each 16 bits)
- input [1:0] target_i, target_j // intersection to compute (2-bit addresses)
Outputs:
- output reg [3:0] x_result // computed x value (4-bit)
- output reg done // high when computation complete

Behavior:
1. On start pulse:
   a. For selected row and column (i = target_i, j = target_j):
      i. Sort unique row elements (4 elements max) using sorting network
      ii. Sort unique column elements (4 elements max)
      iii. Compute ranks for current element in both sorted lists
   b. Compute result: x_result = max(row_rank, col_rank) + max(R_len - row_rank, C_len - col_rank)
2. Implement 3-stage pipeline:
   Stage 1: Sort row and column elements (3 clock cycles)
   Stage 2: Calculate ranks and lengths (2 clock cycles)
   Stage 3: Compute final result (1 clock cycle)
Latency: Result valid 6 clock cycles after start asserted.

Implementation constraints:
- Maximum 4 unique elements per row/column
- Each element comparator uses parallel sorting networks
- Rank calculation via finite state machine
