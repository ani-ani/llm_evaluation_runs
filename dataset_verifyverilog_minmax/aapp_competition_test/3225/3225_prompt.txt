Design a Verilog module named 'candidate_queue_processor' that simulates the candidate elimination process.

Module interface:
module candidate_queue_processor(
  input clk,              // clock 
  input rst_n,            // active-low reset 
  input start,            // start processing 
  input [7:0] initial_values [0:7],  // 8 candidates with 8-bit values each 
  output reg done,                  // high when processing complete 
  output reg [3:0] round_count,     // number of rounds completed 
  output reg [7:0] final_queue [0:7], // final retained candidates 
  output reg queue_size            // size of final queue 
);

Behavior:
1. On reset: clear all outputs, return to IDLE state
2. On start pulse: 
   a. Load initial_values into working register 
   b. Initialize round_count = 0 
   c. Begin elimination process 
3. Each processing cycle (1 clock) performs: 
   a. Compare each candidate with both neighbors (treat ends as only having one neighbor)
   b. Mark candidates for removal if either neighbor is strictly greater
   c. All marked candidates are removed simultaneously
   d. Record removed values for the current round
   e. Increase round_count when round completes
4. Continue until no candidates are eliminated in a round
5. Set done=1 when complete, output final_queue and queue_size
Latency: Variable (depends on elimination rounds needed, max 7 rounds for 8 candidates).
