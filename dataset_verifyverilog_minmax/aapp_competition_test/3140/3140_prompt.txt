Design a sequential Verilog module named 'fish_point_counter' that calculates the maximum number of grid points where fish can be caught under time constraints.

Inputs:
input clk, // clock
input rst_n, // active-low reset
input start, // pulse high to start computation
input [1:0] x0, // starting x position (2 bits for 0-3)
input [1:0] y0, // starting y position (2 bits for 0-3)
input [4:0] k_val, // fish duration (1-5, 5-bit width)
input [4:0] l_val, // total time limit (1-16, 5-bit width)
input [4:0] t_grid [0:3][0:3] // 4x4 grid of appearance times (each 5-bit)

Outputs:
output reg [4:0] count, // number of reachable points (0-16)
output reg done // high when computation completes

Functionality:
1. On reset, set count=0 and done=0.
2. When start is pulsed high:
   a. Perform BFS from (x0,y0) starting at time=1
   b. For each point (x,y):
      i. Arrival time must be <= l_val
      ii. Arrival time >= t_grid[x][y] and < (t_grid[x][y] + k_val)
3. Count all valid reachable points (including start if valid)
4. Assert done when complete (within 32 cycles max)

Implementation notes:
- Use states: IDLE, BFS_EXPAND, BFS_CHECK, DONE
- Maintain visited tracking (16-bit register)
- Use shift register queue for BFS (16 entries, 5-bit x + 5-bit y + 5-bit time)
- Combinational logic to check neighbor validity and time constraints
- Clocks per point: 1 cycle check, 1 cycle enqueue (worst-case 32 cycles total)
