Design a sequential Verilog module named max_partition_score to find the maximum partition score. The module should have the following interface:
module max_partition_score(
  input clk,
  input rst_n,
  input start,
  input [7:0] v0,
  input [7:0] v1,
  input [7:0] v2,
  input [7:0] v3,
  input [7:0] v4,
  input [7:0] v5,
  input [7:0] v6,
  input [7:0] v7,
  input [1:0] k,
  output reg [7:0] score,
  output reg done
);

The module should partition the 8 input values into k (1-4) consecutive regions and compute the score as follows: for each region, find the largest prime number that divides all values in that region (or 0 if none exists), then take the minimum of these primes across regions. The max possible score is the maximum such minimum over all valid partitions.

The module should compute the result in sequence: first generate all 36 subarray GCDs, then find the largest prime divisor for each GCD, then compute the optimal partition using dynamic programming. Output 'score' should be valid when 'done' is high, within 50 clock cycles after 'start' is asserted. Use a state machine with states IDLE, COMPUTE_GCD, FIND_PRIMES, DP_CALC, DONE.

Note: Values v0-v7 are 8-bit unsigned integers, k is 2-bit (max 4 regions). Use combinatorial logic for GCD and prime checks where possible, but pipelining is allowed. The algorithm must correctly handle cases where no valid prime exists, returning score 0.
