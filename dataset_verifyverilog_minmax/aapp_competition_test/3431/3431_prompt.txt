Design a sequential Verilog module named 'manhattan_mst' that calculates Minimum Spanning Tree weight for up to 8 points using Manhattan distances.

Module interface:
module manhattan_mst(
  input clk,                   // clock
  input rst_n,                 // active-low reset
  input start,                 // pulse high to start computation
  input [3:0] num_points,      // number of points (1-8)
  input [9:0] x[0:7],          // x coordinates (10-bit each) 
  input [9:0] y[0:7],          // y coordinates (10-bit each) 
  output reg [13:0] mst_weight, // MST weight output (14-bit)
  output reg done               // high when computation completes
);

Behavioral description:
1. On reset: clear all registers and set done=0
2. When start pulse is detected:
   a. Compute all Manhattan distances between points (max C(8,2)=28 edges)
   b. Sort edges in non-decreasing order (use simple sorting algorithm for small set)
   c. Apply Kruskal's algorithm with Union-Find data structure
   d. Sum selected edges to compute MST weight
3. Latency: Result available in 100 clock cycles maximum (set done=1)
4. Union-Find implementation should support maximum 8 nodes
5. Use 14-bit unsigned arithmetic for weight accumulation
6. Manhattan distance between points i & j: |xi - xj| + |yi - yj|
7. Assume input point coordinates are stable until done is asserted
