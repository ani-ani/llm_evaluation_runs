Design a Verilog module named 'sliding_blocks_check' that checks if target blocks can be properly placed via legal sliding moves.

Inputs:
input [1:0] init_r, init_c; // Initial block coordinates (2-bit for 4x4 grid)
input [3:0][1:0] target_r, target_c; // Up to 4 target blocks (row/col pairs)
input [1:0] block_count; // Actual targets to check (0-3 extra blocks)

Output:
output reg possible; // 1=possible, 0=impossible

Behavior:
1. The module must verify that all target blocks are reachable from existing blocks via legal sliding moves
2. For each target block:
   - Check exists clear path from board edge to target (stopping at previous block)
   - Path must not collide mid-way for any direction
3. Block connections must form tree structure (additional verification)
4. All comparisons use grid coordinates (0-3 for 2-bit inputs)
5. Combinational logic only - no clock required

Rules:
- Use structural checks instead of sequence generation
- Illegal if target overlaps with initial block
- Directional checks: For each target, verify at least one direction (up/down/left/right) has clear path from edge
