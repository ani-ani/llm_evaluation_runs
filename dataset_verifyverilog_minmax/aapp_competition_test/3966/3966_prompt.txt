Design a combinational Verilog module named 'max_game_score' that computes the maximum game score described in the problem.

Inputs:
  input [3:0] n,          // Number of valid elements in array (1 ≤ n ≤ 8)
  input [15:0] arr [0:7], // Array of up to 8 numbers (each 16-bit unsigned)

Output:
  output reg [31:0] score // Maximum possible score (32-bit unsigned)

Behavior:
1. Internally sort the first 'n' elements of 'arr' in ascending order (use parallel sorting network or other hardware-friendly sort)
2. Compute score = Σ (sorted_arr[i] * (i+2)) for i=0 to n-2 + sorted_arr[n-1] * (n) for n>1 else sorted_arr[0]
3. For invalid cases (n=0): output 0 (though problem states n≥1)

Note: Module must be purely combinational - no clock/state required. Use parallel operations suitable for small arrays.
