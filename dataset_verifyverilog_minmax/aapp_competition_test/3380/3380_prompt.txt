Design a sequential Verilog module named 'road_network_prob' that calculates connected graph probability for N=2 to 4 cities using precomputed lookup table.

Module interface:
module road_network_prob(
  input clk, // clock signal
  input rst_n, // active-low asynchronous reset
  input start, // pulse high for 1 cycle to start calculation
  input [3:0] N, // number of cities (2-4 valid)
  output reg [31:0] probability, // Q16.16 fixed-point probability
  output reg done // high when result ready
);

Behavior description:
- Uses lookup table with precomputed probabilities:
  N=2 -> 65536 (1.0 in Q16.16)
  N=3 -> 60689 (~0.926 in Q16.16)
  N=4 -> 63161 (~0.963 in Q16.16)
- When start is asserted:
  1. Reset internal registers on rst_n low
  2. Wait 3 clock cycles (simulate lookup delay)
  3. Output probability matching N input
  4. Assert done for 1 cycle
- Output guaranteed valid 3 cycles after start assertion.
