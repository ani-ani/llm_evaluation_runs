Design a sequential Verilog module named 'tree_optimizer' that finds optimal flight changes in small trees.

Module interface:
module tree_optimizer(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // start computation
  input [2:0] num_nodes, // 3-8 nodes (0-7 encoding)
  input [55:0] edges, // flattened 8*7-bit edge list [3:0]a,city_b; 3:0]b (16 edges max)
  output reg [2:0] min_flights, // result: min max flights needed
  output reg [3:0] cancel_a, cancel_b, // edge to remove (city numbers 1-8)
  output reg [3:0] add_a, add_b, // edge to add
  output reg done // high when results valid
);

Behavior: On start, compute optimal edge to cancel/add to minimize maximum path length between any city pair. The module should:
1. For each existing edge (potential cancellation):
   a. Split tree into two subtrees
   b. Compute subtree diameters using parallel BFS for small graphs
   c. Test all possible new edges connecting the subtrees
2. Track solution producing minimum max(diameter1, diameter2, combined_diameter)
3. Output first optimal solution found when multiple exist

Timing: Computation completes within 256 cycles max. Done signal asserts when results are valid. Uses state machine with IDLE, COMPUTE, DONE states.

Note: City numbers are 1-8 (3-bit index + 1). Edge input format: 8 edges * 7 bits (3b city_a, 3b city_b, 1b valid). Unused edges marked invalid.
