Design a sequential Verilog module named 'grasshopper_path' that finds the maximum flower visit path under movement rules for a 4x4 grid. The module should:

- Accept flattened 16-element grid input (4x4 row-major order)
- Start computation when 'start' is asserted
- Output maximum visit count when 'done' is high

Module interface:
module grasshopper_path(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [15:0] grid [0:15], // Flattened 4x4 grid (each element 16-bit petal count)
  input [1:0] init_row, // Initial row (0-3)
  input [1:0] init_col, // Initial column (0-3)
  output reg [3:0] max_flowers, // Maximum flowers visited (1-16)
  output reg done // High when computation complete
);

Behavior description:
1. On reset: clear outputs and internal state
2. When start asserted: begin traversal from (init_row, init_col)
3. Movement rules: From current flower (r,c) can move to (r±1,c±2),(r±2,c±1), etc. valid moves
4. Only move if next petal > current petal
5. Implement depth-first search with bounded depth (max 16 flowers)
6. Track maximum path length found
7. Assert done after computation completes (latency varies, max 100 cycles)
8. Output max_flowers valid when done is high

Implementation notes:
- Use states: IDLE, INIT, EXPLORE, DONE
- Store grid in internal 4x4 register array
- Maintain current path stack and visited flags
- Maximum path length outputs 4-bit count (1-16)
