Design a sequential Verilog module named "casino_profit_calculator" that calculates maximum expected profit with the following specifications:
Module interface:
module casino_profit_calculator(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // start calculation
  input [15:0] x, // refund percentage (fixed-point: value * 100, e.g., 20.5% = 2050)
  input [15:0] p, // win probability (fixed-point: value * 100, e.g., 49.85% = 4985)
  output reg [31:0] max_profit, // Q16.16 fixed-point output (max profit * 65536)
  output reg done // high when calculation complete
);

Behavioral description:
- Supports max 16 bets (parameter MAX_BETS = 16)
- On reset: set all registers to 0, done=0
- When start=1:
  1. Calculate expected profit for all bet counts from 0 to MAX_BETS
  2. Compare results and store maximum
- Calculation steps for N bets (0 ≤ N ≤ 16):
  a. Compute binomial probabilities and payouts
  b. Apply refund x% if final result is negative
  c. Calculate expected value in Q16.16 format
- Implement using iterative state machine with 3 states: IDLE, CALCULATING, DONE
- Latency: Output valid after MAX_BETS+2 clock cycles (18 cycles) when done=1
- Use combinatorial logic for probability/payout calculations within stages
- All arithmetic operations use Q16.16 fixed-point representation
