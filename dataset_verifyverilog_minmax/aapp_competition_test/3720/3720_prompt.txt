Design a combinational Verilog module named 'powers_game' that determines the winner for inputs n \u2264 255.

Module interface:
module powers_game(
  input [7:0] n,  // Input number (1 \u2264 n \u2264 255)
  output winner    // 1=Vasya wins, 0=Petya wins
);

Behavioral description:
- Precomputed nimber array: arr = [0,1,2,1,4,3,2,1,5,6,2,1,8,7,5,9,8,7,3,4,7,4,2,1,10,9,3,6,11,12]
- Calculate log2(n) as the highest power where 2^p \u2264 n
- Initialize ans = arr[log2(n)]
- Calculate s = log2(n)
- For each i from 3 to sqrt(n), if i isn't a perfect power:
  - Calculate highest power p where i^p \u2264 n
  - ans = ans ^ arr[p]
  - s += p
- ans = ans ^ ((n - s) % 2)
- If ans != 0, Vasya wins (winner=1), else Petya wins (winner=0)
