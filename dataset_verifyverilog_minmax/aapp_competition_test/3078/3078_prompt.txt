Design a combinational Verilog module named 'longest_interesting_subsequence' that computes for each start position in an 8-element sequence, the maximum valid subsequence length starting at that element. A subsequence of length 2K is valid if:
1. It fits within the array bounds (start+K*2-1 < 8)
2. The sum of its first K elements <= S
3. The sum of its last K elements <= S

Module interface:
module longest_interesting_subsequence(
  input [15:0] S, 
  input [15:0] A [0:7], 
  output reg [3:0] result [0:7]
);

Behavioral description:
- For each start index i (0-7), compute all possible even lengths L from min(8-i, 8) down to 2, checking pairs of K-length sums (L=2K)
- Output the largest valid L (or 0 if none found)
- All comparisons must be combinational - use parallel sum comparisons
- Pre-calculate all required subarray sums using adder trees/unrolled logic
- Final result array contains 8 outputs (one per start position) with 4-bit values (max length 8)
