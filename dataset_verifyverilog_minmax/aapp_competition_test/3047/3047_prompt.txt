Design a sequential Verilog module named 'puzzle_solver' that computes the number of distinct solutions for a scaled-down monster plate puzzle.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // pulse high to start computation
input [7:0] burger [0:2] // burger amounts (S/Y/G) - '255' indicates missing
input [7:0] slop [0:2] // slop amounts (S/Y/G)
input [7:0] sushi [0:2] // sushi amounts (S/Y/G)
input [7:0] drumstick [0:2] // drumstick amounts (S/Y/G)
Outputs:
output reg [15:0] num_solutions // number of valid solutions found
output reg many_flag // asserted when infinitely many solutions exist
output reg done // high when computation completes

Behavioral description:
- When start is pulsed high, module begins processing.
- Each monster's plate must maintain identical ratio: burger/slop = sushi/drumstick (i.e., burger*drumstick == slop*sushi).
- Each '_' from original input is represented by a missing value (255) and must be solved.
- For numerical comparisons, exact integer equality must hold (using 8-bit unsigned values).
- Modules scans missing value possibilities from 1-255 and counts distinct solutions where all 4 ratios are consistent.
- If any solution allows arbitrary scaling beyond 255 without violating ratios, many_flag is set and num_solutions is ignored.
- Computation completes within 256 clock cycles (worst-case search) after start assertion.
- Assert 'done' when complete.

Implementation note: Normalize all comparisons using integer multiplication (burger*drumstick == slop*sushi) to avoid division.
