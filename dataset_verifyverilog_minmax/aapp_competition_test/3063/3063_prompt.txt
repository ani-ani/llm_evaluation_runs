Design a combinational Verilog module named 'debt_resolution' that calculates the minimum total amount needed to resolve all debts for up to 8 people.

Inputs:
input [7:0] valid_mask // Bitmask indicating which people exist (0-indexed, up to 8)
input [2:0] a_id [7:0] // a_id[i] indicates who person i owes money to (3-bit IDs)
input [13:0] b_amount [7:0] // b_amount[i] specifies debt amounts (14-bit values)

Output:
output [16:0] total_min // Minimum total money needed (17-bit output)

Behavior: The module should find all unique cycles in the debt graph and sum the smallest debt amount in each cycle. The debt graph is defined by a_id relationships. If multiple people form a cycle, only the smallest debt in that cycle is counted toward the total. For non-cyclic chains (trees), their contributions are computed automatically through cycle analysis. All inputs are valid and there are no self-loops (a_id[i] != i).

Implementation Note: The module must handle up to 8 people. Use parallel cycle detection and minimum tracking suitable for small N.
