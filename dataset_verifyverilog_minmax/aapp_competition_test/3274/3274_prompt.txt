Design a sequential Verilog module named 'torpedo_avoidance' that computes whether a torpedo can avoid ships in a bounded 2D plane.

Module interface:
module torpedo_avoidance(
  input clk,
  input rst_n,
  input start,
  input [3:0] n_seconds, // Total steps (2-8)
  input [2:0] m_ships,   // 0-4 ships
  input signed [4:0] ship_x1 [0:3], // 4 ships max (-8 to +8)
  input signed [4:0] ship_x2 [0:3],
  input [3:0] ship_y [0:3],
  output reg [1:0] path [0:7], // 8 steps max (2'b00:-, 2'b01:0, 2'b10:+)
  output reg done,
  output reg possible
);

Behavior:
- On reset: Clear outputs
- When start=1: Begin computation
- For each time step y from 1 to n_seconds:
  - Track possible x positions (prev_x ±1)
  - For each ship at current y: check if collision occurs
  - Prune impossible paths
- After n_seconds cycles: done=1 and possible=1/0
- Output path stored in path[0:n_seconds-1] if possible=1

Latency: Result valid (done=1) exactly n_seconds+1 clock cycles after start. Pre-compute steps using pipeline.
