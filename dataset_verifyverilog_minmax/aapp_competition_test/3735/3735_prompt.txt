Design a combinational Verilog module named 'max_digit_sum' that takes a 16-bit unsigned integer n and calculates the maximum possible sum of digits S(a) + S(b) where a + b = n.

Module interface:
module max_digit_sum(
  input [15:0] n,
  output [6:0] max_sum
);

Behavior:
1. Determine L (number of digits):
   - L=1 if n < 10
   - L=2 if 10 <= n < 100
   - L=3 if 100 <= n < 1000
   - L=4 if 1000 <= n < 10000
   - L=5 if n >= 10000
2. Calculate a = 10^(L-1) - 1 (precomputed as: 0 when L=1, 9 when L=2, 99 when L=3, etc)
3. Compute b = n - a
4. Compute digit sums of a and b by summing individual digits
5. Output max_sum = digit_sum(a) + digit_sum(b)

Note: Digit extraction must use combinational arithmetic (mod 10 and division by 10).
