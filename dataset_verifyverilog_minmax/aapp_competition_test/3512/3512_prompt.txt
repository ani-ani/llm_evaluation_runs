Design a sequential Verilog module named 'tsp_special' that finds the minimum travel duration for a salesman visiting up to 8 cities under special constraints.

Module interface:
module tsp_special(
  input clk,               // system clock
  input rst_n,             // active-low reset
  input start,             // pulse high to start computation
  input [2:0] n,           // number of cities (2-8)
  input [63:0][9:0] dist_matrix  // flattened 8x8 distance matrix (each entry 10 bits)
  output reg [12:0] min_duration,  // minimum total duration (13-bit output)
  output reg done           // high when result valid
);

Behavioral description:
The module must compute the minimum path duration where for each city K, all smaller-numbered cities are either all visited before K or all after K. Only the first n*n entries of dist_matrix are used. The module uses dynamic programming to find the optimal path. On reset, the module goes to IDLE state. When start is pulsed high:
1. Begins computation using an iterative DP approach that tracks current endpoint cities and visited cities
2. Takes approximately n*n clock cycles to complete
3. Sets done high and outputs result when computation finishes
Latency: Result valid within 64 clock cycles after start (worst-case for n=8).
