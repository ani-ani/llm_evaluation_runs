Design a sequential Verilog module named 'minimum_energy_search' that finds the minimum energy to achieve target probability P

Module interface:
module minimum_energy_search(
  input clk,
  input rst_n,
  input start,
  input [31:0] p_target, // Q12.20 fixed-point (P * 2^20)
  input [7:0] [9:0] energies, // 8 boxes, 10-bit energy values each
  input [7:0] [31:0] probs, // 8 boxes, Q12.20 probabilities each
  output reg [12:0] min_energy, // Max energy 8*1000=8000 (13-bit)
  output reg done
);

Behavior:
1. On reset or start, initialize min_energy=8191 (max) and done=0
2. Iterate through all 256 subsets over 256 clock cycles
3. Each cycle: Calculate subset's total energy and probability sum
4. If sum >= p_target and energy < current min_energy: update min_energy
5. After 256 cycles, set done=1 and hold result

Latency: 257 cycles (256 processing + 1 done state)
