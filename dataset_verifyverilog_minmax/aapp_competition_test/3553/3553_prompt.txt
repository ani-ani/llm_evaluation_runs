Design a sequential Verilog module named 'shortest_subarray_finder' that finds the minimal subarray containing all values 1-K.

Parameters:
N = 8 (array size)
K = 4 (max distinct values)

Interfaces:
module shortest_subarray_finder(
  input clk,
  input rst_n,
  input start,
  input [2:0] query_type,  // 0=update, 1=query
  input [2:0] position,    // 0-7
  input [1:0] value,       // 1-4
  output reg [3:0] result, // subarray length (0-8, 15=-1)
  output reg done
);

Behavior:
1. Array initialized to all 1s on reset
2. On start pulse:
   - For update query: update array[position] <= value
   - For query operation: compute minimal subarray containing 1-K
3. Results valid 10 cycles after start assertion
4. Output format: result=15 indicates -1 (no valid subarray)
5. Use sliding window approach checking all possible subarrays

Timing:
- Update: 1 cycle
- Query: 8 cycles (worst-case window search)
- done pulses high for 1 cycle after result ready
