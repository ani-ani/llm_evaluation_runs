Design a sequential Verilog module named "frog_jump_calculator" that computes the minimal total jumps needed for frogs to reach a target.
Module interface:
module frog_jump_calculator(
  input clk, // Clock signal
  input rst_n, // Active-low reset
  input [1:0] cmd_type, // 00: add frog, 01: remove frog, 10: change target
  input [15:0] cmd_data, // Position data for command
  input cmd_valid, // Pulse high for 1 cycle when command valid
  output reg [4:0] total_jumps, // Result: minimal total jumps
  output reg result_valid // High when output valid
);

Behavior:
1. Maintains an array of up to 8 frog positions (16-bit each) and current target position
2. On reset: initialize with 0 frogs and target position 0
3. Processes commands sequentially when cmd_valid is high for 1 cycle:
   - Add frog: Store new position if <8 frogs
   - Remove frog: Delete first matching position
   - Change target: Update target position
4. After each command, computes for each frog:
   k = smallest integer where k(k+1)/2 >= |pos-target| and same parity
5. Outputs maximum k found across all frogs (result_valid pulses high for 1 cycle)
6. Latency: new result appears 2 cycles after cmd_valid

Implementation notes:
- Use 2-cycle pipeline: 1 cycle for command processing, 1 cycle for jump calculation
- Each frog's k calculated via parallel combinational logic (limit k <= 31)
- Use registers: frog_positions[0:7], frog_count[3:0], current_target[15:0]"
