Design a sequential Verilog module named 'permutation_square_count' that counts valid square permutations.

Module interface:
module permutation_square_count(
  input clk, // Clock signal
  input rst_n, // Active-low reset
  input start, // Start computation
  input [2:0] n, // Permutation size (1-8)
  input [2:0] t_0, // Element 1 (chair assignments)
  input [2:0] t_1, // Element 2
  input [2:0] t_2, // Element 3
  input [2:0] t_3, // Element 4
  input [2:0] t_4, // Element 5
  input [2:0] t_5, // Element 6
  input [2:0] t_6, // Element 7
  input [2:0] t_7, // Element 8
  output reg [31:0] result, // Computed count (mod 1e9+7)
  output reg done // High when computation complete
);

Behavior:
1. On reset: result=0, done=0 
2. When start=1: begin computation
3. Detect cycles in permutation t[0..n-1]
4. For each cycle: if length is odd ⇒ multiply count by len; if even ⇒ check if len % 2=0 ⇒ multiply by len/2 else 0
5. Result available after 8+n*4 cycles (max 40 cycles)
6. Output result modulo 1000000007
7. Set done=1 when complete

Implementation note:
- Use visited flags array to track processed elements
- Multiply results using 32-bit modular arithmetic
- States: IDLE, INIT, FIND_CYCLES, COMPUTE, DONE
