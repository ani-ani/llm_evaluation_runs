Design a sequential Verilog module named 'max_stable_edges' that calculates the maximum additional edges for a 16-node graph.

Module interface:
module max_stable_edges(
  input clk,                  // clock signal
  input rst_n,                // active-low reset
  input start,                // start computation
  input [3:0] node_count,     // number of nodes (1-16)
  input [3:0] gov_count,      // number of governments (1-4)
  input [3:0] gov_list [0:3], // government node IDs (4 elements)
  input [6:0] edge_count,     // current edge count (0-120)
  input [15:0] edge_mask [0:15], // adjacency matrix (16x16)
  output reg [6:0] max_edges, // maximum addable edges
  output reg done             // high when computation complete
);

Behavioral description:
1. The module implements a state machine with states: IDLE, COMPONENT_SEARCH, SIZE_CALC, RESULT_CALC, DONE.
2. On reset, all registers are cleared and FSM returns to IDLE.
3. When start is asserted:
   a. Perform connected component search using DFS for government nodes (max 7-cycle DFS per node).
   b. Calculate component sizes and identify largest component.
   c. Compute max edges formula: 
      total = Σ(size_i*(size_i-1)/2) + size_largest*remaining_nodes
      max_edges = total - edge_count - (Σ(components edges))
4. Result valid 35 clock cycles after start asserted (1 cycle per node + computation).
5. edge_mask[i][j] indicates edge between node i and j (symmetric).
