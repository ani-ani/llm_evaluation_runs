Design a Verilog module for counting valid house numbers in range [L,R] with conditions: no digit 4, equal count of (6,8) and other digits. Scale down to 16-digit max length. Use digit DP with state tracking (position, tight constraint, difference between 6/8 count and other count). Inputs: 16-digit BCD array, outputs: count modulo 10^9+7. Implement combinational logic for digit processing and sequential state machine for DP transitions.
