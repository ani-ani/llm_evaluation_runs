Module: guitar_hero_max_score

// Interface Specification
// Inputs:
//   clk         : Clock signal (rising edge triggered)
//   rst_n       : Active-low synchronous reset
//   start       : Start pulse (assert for 1 cycle to begin computation)
//   num_notes   : 2-bit number of valid notes (1 to 4)
//   note0..note3: 4-bit note times (0-15), only first num_notes are used
//   num_phrases : 2-bit number of SP phrases (0 to 2)
//   phrase0_start, phrase0_end: 4-bit start/end for phrase 0
//   phrase1_start, phrase1_end: 4-bit start/end for phrase 1
// Outputs:
//   max_score   : 4-bit maximum score (base notes + doubled notes)
//   done        : Asserted high for 1 cycle when result is valid

// Behavior:
//   Base score = num_notes.
//   Compute extra points = max number of notes that can be covered by an activation interval
//   whose length C is the sum of durations of a subset of phrases, and which does not overlap
//   any phrase in that subset. Consider all subsets (0, 1, 2, both) and all activation start times T from 0 to 15.
//   Activation interval is [T, T+C) (left-closed, right-open).
//   Overlap condition: (T < phrase_end+1) and (T+C > phrase_start) for any phrase in subset.
//   Note coverage: T <= note_time < T+C.
//   Final max_score = base_score + max_extra.

// Implementation Notes:
//   - Use a state machine to iterate over subsets (4 possibilities) and T values (16 possibilities).
//   - Compute C for each subset (durations = end - start, max duration 15, sum up to 30 => use 5 bits).
//   - For each (subset, T), check overlap and count covered notes.
//   - Keep track of maximum extra points.
//   - The computation may take several cycles; assert done when finished.
//   - On reset, clear internal state.

// Example test cases:
//   1) num_notes=3, notes=0,10,20, num_phrases=1, phrase0_start=0, phrase0_end=10 -> max_score=4
//   2) num_notes=4, notes=0,5,10,15, num_phrases=2, phrase0_start=0, phrase0_end=5, phrase1_start=10, phrase1_end=15 -> max_score=5
//   3) num_notes=4, notes=0,5,10,15, num_phrases=0 -> max_score=4
