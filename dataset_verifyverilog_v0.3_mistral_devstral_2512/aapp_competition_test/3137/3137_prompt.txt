Verilog module for bacteria movement simulation on 8x8 board with 2 bacteria.

INTERFACE SPECIFICATION:

Inputs:
  - clk: Clock signal (rising edge triggered)
  - rst_n: Active-low synchronous reset
  - start: Start pulse (assert for 1 cycle to begin simulation)
  - trap_row[7:0], trap_col[7:0]: Trap position (1-8)
  - For each bacterium i (0 and 1):
    - start_row_i[7:0], start_col_i[7:0]: Starting position (1-8)
    - start_dir_i[1:0]: Starting direction (0=U,1=R,2=D,3=L)
    - grid_i[0:7][0:7]: 8x8 grid of 4-bit values (0-15)

Outputs:
  - result[15:0]: Simulation time (0-255) when all bacteria at trap, or 65535 if never
  - done: Asserted high for 1 cycle when computation completes

Timing:
  - Assert start for 1 clock cycle
  - done will go high within 256 cycles
  - Sample result on the same cycle done is high

Reset behavior:
  - On rst_n=0: done=0, result=0, internal state cleared
  - Minimum 2 clock cycles of reset required

Implementation notes:
  - Use state machine to simulate up to 256 time steps
  - Each bacterium has state: row, col, direction
  - Movement: read grid value, turn clockwise X times, move, handle boundaries
  - Check after each step if both bacteria at trap position
  - If not found within 256 steps, output 65535
