Module: street_widening

Parameters:
  - MAX_N = 16 (maximum number of street parts)
  - DATA_WIDTH = 16 (bit width for arithmetic operations)

Inputs:
  - clk: System clock
  - rst_n: Active-low reset
  - start: Start computation pulse
  - n: Number of valid parts (1-16)
  - s_in [15:0][DATA_WIDTH-1:0]: Initial road widths
  - g_in [15:0][DATA_WIDTH-1:0]: Initial lawn widths

Outputs:
  - total_removed [DATA_WIDTH*2-1:0]: Total lawn width removed
  - s_out [15:0][DATA_WIDTH-1:0]: New road widths
  - done: Computation complete pulse
  - error: Asserted if no solution exists

Internal Architecture:
1. State Machine (4 states: IDLE, FORWARD, BACKWARD, VALIDATE)
2. Forward pass: Propagate upper bounds from left to right
3. Backward pass: Propagate lower bounds from right to left
4. Validation: Check feasibility and compute total removal

Timing:
- Computation takes 2*n + 3 clock cycles
- start pulse must be 1 cycle
- done pulses for 1 cycle when complete
- results available when done=1

Implementation Details:
- Uses 2D registers for intermediate values
- Handles overflow with saturation
- Strict cycle limits prevent infinite loops
- All operations use DATA_WIDTH=16 bits
