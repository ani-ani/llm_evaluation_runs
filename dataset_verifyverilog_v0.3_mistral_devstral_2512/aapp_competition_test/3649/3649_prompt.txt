Design a Verilog module that computes a bit string satisfying given subsequence counts.

Module name: subsequence_string

Inputs:
  a[7:0], b[7:0], c[7:0], d[7:0]  (8-bit unsigned integers)

Outputs:
  valid: 1 if a solution exists, else 0
  length[3:0]: length of the output string (1-16)
  string_bits[15:0]: bits of the string, where string_bits[i] is the i-th character (0-indexed from leftmost). Valid only for i < length.

Behavior:
  The module must compute the bit string in combinational logic (no clock). It should:
  1. Determine possible numbers of zeros (n0) and ones (n1) from a and d:
     - For a: if a == 0, n0 can be 0 or 1; else if a is in {1,3,6,10,15,21,28}, n0 is respectively {2,3,4,5,6,7,8}; otherwise no solution.
     - Similarly for d to get possible n1.
  2. Check all combinations of possible n0 and n1 (0..8) to find one where:
        n0 + n1 > 0  (nonempty)
        b + c == n0 * n1
     If none, set valid = 0 and zero outputs.
  3. If a combination is found, set valid = 1, length = n0 + n1.
  4. Compute c_val = n0 * n1 - b (which equals c, but we use for construction).
  5. Construct the string bits according to the following algorithm:
        If n1 == 0:  // all zeros
            for i = 0 to n0-1: string_bits[i] = 0
        else if n0 == 0:  // all ones
            for i = 0 to n1-1: string_bits[i] = 1
        else:
            q = c_val / n1;   // integer division
            r = c_val % n1;
            zeros_start = n0 - q - (r>0 ? 1 : 0);
            // Now fill bits for positions p = 0 .. (n0+n1-1):
            if (p < zeros_start)                bit = 0;
            else if (p < zeros_start + r)       bit = 1;   // only if r>0
            else if (p < zeros_start + r + (r>0 ? 1 : 0)) bit = 0;
            else if (p < zeros_start + r + (r>0 ? 1 : 0) + (n1 - r)) bit = 1;
            else                                bit = 0;
  6. For positions i >= length, string_bits[i] can be any value (recommend 0).

Implementation notes:
  - Use combinational always @(*) blocks.
  - The loops for n0,n1 search can be implemented with for loops over 0..8 (static bounds) or if-else chains.
  - The string construction loop can be a for loop over p=0..15, with condition p < length.
  - Ensure that b and c are within 0..n0*n1; the check b+c == n0*n1 already ensures that.
