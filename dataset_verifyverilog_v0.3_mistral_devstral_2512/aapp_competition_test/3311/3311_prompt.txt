Module: exponial_mod

Inputs:
  - clk: Clock signal
  - rst_n: Active-low reset
  - start: Start pulse (1 cycle)
  - n[7:0]: Input n (1-255)
  - m[31:0]: Input modulus

Outputs:
  - result[31:0]: exponial(n) mod m
  - done: Asserted when computation completes

Behavior:
  - Computes exponial(n) mod m recursively using Euler's totient
  - Base cases: n=1→1, n=2→2, n=3→9, n=4→262144 mod m
  - For n≥5: uses totient reduction
  - Maximum recursion depth: 16 levels
  - Computation time: 100-1000 cycles depending on n

Timing:
  - Assert start for 1 clock cycle
  - done goes high when result is ready (within 1000 cycles)
  - Sample result on same cycle as done

Reset:
  - rst_n=0: clears state, done=0, result=0
  - Minimum 2 clock cycles reset required
