Design a Verilog module for string matching with at most one wildcard character.

Module name: string_match

Parameters:
- MAX_LEN: maximum string length (16)
- DATA_WIDTH: character width (8 bits ASCII)

Inputs:
- clk: clock
- rst_n: active-low reset
- start: start pulse
- s_arr: array[0:15] of 8-bit pattern characters
- t_arr: array[0:15] of 8-bit target characters  
- n: 5-bit pattern length (1-16)
- m: 5-bit target length (1-16)

Outputs:
- result: 1-bit match result
- done: 1-bit completion signal

Behavior:
1. When start=1, begin matching
2. Scan s for '*' (ASCII 42):
   - If no '*' found: compare all n characters with t (must have n==m)
   - If '*' found at position pos:
     * Check prefix: s[0:pos] == t[0:pos]
     * Check suffix: s[pos+1:n-1] == t[m-(n-pos-1):m-1]
     * Check length: n-1 <= m
3. Set result and assert done for one cycle

Use state machine:
- IDLE: wait for start
- FIND_STAR: scan for '*'
- COMPARE_PREFIX: compare prefix characters
- COMPARE_SUFFIX: compare suffix characters  
- CHECK_LENGTH: verify n-1 <= m
- DONE: assert done

Complete within 100 cycles for MAX_LEN=16.
