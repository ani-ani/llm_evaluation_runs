Create a Verilog module `phone_numbers` that takes two inputs: `n` (7 bits) and `digits` (400 bits, representing 100 4-bit digits). The module must output `result` (4 bits). The module should count the number of '8's in the first `n` digits and compute k = n // 11 using a combinational lookup (using ternary operators for n values 0-100). Then output min(count_8, k). The module must be purely combinational.
