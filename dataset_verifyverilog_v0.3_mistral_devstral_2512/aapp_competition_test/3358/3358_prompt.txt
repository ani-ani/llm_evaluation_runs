module spec: sequential processor that outputs a program for given N.

INTERFACE (testbench will use these exact names):
  Inputs:
    - clk      : Clock signal (rising edge triggered)
    - rst_n    : Active‑low synchronous reset
    - start    : Start pulse (assert for 1 cycle to begin generation)
    - N        : 8‑bit unsigned number (0‑255) to output

  Outputs:
    - instruction : 8‑bit encoded instruction (see encoding below)
    - valid       : High when instruction is valid
    - done        : High for 1 cycle when all instructions have been output

ENCODING (8‑bit instruction):
  [7:5] – opcode (0=ST, 1=ZE, 2=PH, 3=PL, 4=AD, 5=DI)
  [4:3] – register (0=A, 1=X, 2=Y; ignored for AD/DI)
  [2:0] – unused (set to 0)

BEHAVIOR:
  On reset: all outputs 0, state idle.
  When start=1: generate the program for the given N.
  The program is output one instruction per clock cycle.
  The program length is at most 40 instructions.
  After the last instruction, done is asserted for 1 cycle.

IMPLEMENTATION:
  Use a case statement for N values 0,1,2,5 (other N may output a default program).
  For N=0: output "ZE Y" then "DI Y".
  For N=1: output "ST Y" then "DI Y".
  For N=2: output the example program.
  For N=5: output the example program.
  For other N: output a minimal program (e.g., only DI Y after setting Y to 0).

  The state machine should have a counter that iterates through the pre‑defined instruction list.
  Use parameters for instruction list lengths.

  Timing: After start is de‑asserted, the module should begin outputting instructions on the next cycle.
  The done signal should go high after the last instruction is placed on the output bus.

  The design must be synthesizable and follow standard Verilog practices.
