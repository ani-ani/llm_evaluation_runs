Design a Verilog module that takes up to 8 swimmers' positions and outputs two lifeguard positions that split the swimmers equally. Assume distinct x-coordinates for simplicity.

**Interface Specification:**

Inputs:
- clk: Clock signal (rising edge triggered)
- rst_n: Active-low synchronous reset
- start: Start pulse (assert for 1 cycle to begin computation)
- n[3:0]: Number of swimmers (1 to 8)
- x0, y0, x1, y1, ..., x7, y7: 8-bit signed coordinates of swimmers (unused swimmers can be 0)

Outputs:
- A_x, A_y: 16-bit signed coordinates of lifeguard A
- B_x, B_y: 16-bit signed coordinates of lifeguard B
- done: Asserted high for 1 cycle when computation completes

**Behavior:**
1. On start, the module should latch the inputs.
2. Sort the x-coordinates of the valid swimmers (n swimmers) using a sorting network.
3. Compute the median x-coordinate:
   - If n is even: median = average of the two middle values (use integer division by 2).
   - If n is odd: median = the middle value.
4. Set A = (median - 100, 0) and B = (median + 100, 0).
5. Assert done for one cycle.
6. On reset, all outputs become 0.

**Assumptions:**
- All swimmers have distinct x-coordinates (or if duplicates exist, the median will be chosen such that at most one swimmer lies exactly on the bisector).
- The computation should complete within a bounded number of cycles (e.g., 20 cycles).
- The output coordinates must fit within 16 bits signed.

**Implementation Notes:**
- Use a finite state machine (FSM) to control the sorting and computation.
- Implement a comparator network for sorting up to 8 elements (e.g., bitonic sort or bubble sort network).
- Use signed arithmetic for median calculation.
- The offset 100 is chosen to ensure the two lifeguard positions are far apart, guaranteeing the bisector is a vertical line through the median x.
