Design a Verilog module that computes the longest interesting subsequence for each starting index in an array of length N (N=8). The module must be purely combinational.

Parameters:
- N = 8
- DATA_WIDTH = 32
- RESULT_WIDTH = 4 (enough for max length 8)

Ports:
- input [DATA_WIDTH-1:0] A [0:N-1] : array of input values
- input [DATA_WIDTH-1:0] S           : threshold sum
- output [RESULT_WIDTH-1:0] result [0:N-1] : result for each starting index

Functionality:
For each i from 0 to N-1:
  1. Let Kmax = floor((N-i)/2).
  2. Find the largest K (1 ≤ K ≤ Kmax) such that:
       sum(A[i .. i+K-1]) ≤ S  AND  sum(A[i+K .. i+2K-1]) ≤ S.
  3. If such K exists, output L = 2*K; otherwise output 0.

Implementation Guidelines:
- Compute prefix sums: prefix[0]=0, prefix[j+1] = prefix[j] + A[j] for j=0..N-1.
- For each i and each possible K, compute sum1 = prefix[i+K]-prefix[i] and sum2 = prefix[i+2K]-prefix[i+K].
- Use priority selection to pick the largest valid K.
- The module must be combinational (no clock or reset).

Write the Verilog code accordingly, using generate loops for clarity.
