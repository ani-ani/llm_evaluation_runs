Create a Verilog module for the dry ice transfer problem. The module uses two largest bottles from the input and implements a BFS-like state machine to generate moves.

INTERFACE SPECIFICATION:

Inputs:
  - clk: Clock signal (rising edge triggered)
  - rst_n: Active-low synchronous reset
  - start: Start pulse (assert for 1 cycle to begin computation)
  - bottle1_cap: 8-bit capacity of first bottle
  - bottle2_cap: 8-bit capacity of second bottle  
  - target: 8-bit target amount T to transfer

Outputs:
  - op: 3-bit operation code (0=fill, 1=discard, 2=transfer, 3=impossible, 4=done)
  - src: 2-bit source bottle index (1 or 2)
  - dst: 2-bit destination bottle index (0=mix, 1=bottle1, 2=bottle2)
  - valid: Asserted when outputs contain valid move
  - done: Asserted when computation complete

Internal State:
  - Uses state machine to track amounts in two bottles
  - Implements BFS to find sequence of moves
  - Maximum moves: 1000
  - Handles impossible cases when T not reachable

Timing:
  - Assert start for 1 clock cycle
  - valid will be high when outputting moves
  - done will be high when sequence is complete
  - If impossible, op=3 will be output once

Reset behavior:
  - On rst_n=0: All outputs 0, state cleared
  - Minimum 2 clock cycles of reset required
