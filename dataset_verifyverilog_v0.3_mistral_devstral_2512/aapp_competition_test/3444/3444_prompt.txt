Module Specification:

Module name: ski_probability

Parameters:
- N = 4 (fixed)
- MAX_K = 3 (fixed)
- DATA_WIDTH = 32 (for Q16.16 fixed-point)

Inputs:
- clk : clock signal (rising edge)
- rst_n : active-low synchronous reset
- start : start pulse (assert for one cycle to begin computation)
- ski_prob_01, ski_prob_02, ski_prob_03, ski_prob_12, ski_prob_13, ski_prob_23 : 32-bit Q16.16 survival probabilities for skiing edges between nodes (0,1), (0,2), (0,3), (1,2), (1,3), (2,3) respectively. A value of 0 means no ski edge.
- walk_edge_01, walk_edge_02, walk_edge_03, walk_edge_12, walk_edge_13, walk_edge_23 : 1-bit flags indicating existence of a walkable edge between the same node pairs.

Outputs:
- prob_k0, prob_k1, prob_k2, prob_k3 : 32-bit Q16.16 probabilities for k=0,1,2,3 walks respectively.
- done : asserted high for one cycle when computation is complete.

Behavior:
On reset (rst_n=0), all internal dp registers are cleared to 0. When start is asserted, the module performs the following steps:
1. Initialize dp[0][0] = 1.0 (Q16.16), all other dp entries = 0.
2. For current walk count k from 0 to 3:
   a. Ski propagation: for edges (0,1), (0,2), (0,3), (1,2), (1,3), (2,3) in this order, if ski_prob != 0, compute product = dp[lower][k] * ski_prob (64-bit), then take bits [47:16] to get Q16.16 product. Update dp[higher][k] = max(dp[higher][k], product).
   b. Walk propagation: for each walk edge that exists, update dp[higher][k+1] = max(dp[higher][k+1], dp[lower][k]) and dp[lower][k+1] = max(dp[lower][k+1], dp[higher][k]).
3. After reaching k=3, compute best probabilities for cabin 3:
   best0 = dp[3][0]
   best1 = max(dp[3][0], dp[3][1])
   best2 = max(best1, dp[3][2])
   best3 = max(best2, dp[3][3])
4. Assign these values to prob_k0..prob_k3 and pulse done high for one cycle.

The module should complete within 200 clock cycles for any input.
All arithmetic is unsigned Q16.16. Multiplication must be performed with 64-bit intermediate to preserve precision.
