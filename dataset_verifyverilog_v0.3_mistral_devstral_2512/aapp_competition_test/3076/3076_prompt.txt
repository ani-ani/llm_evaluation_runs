Design a Verilog module that solves the 0/1 knapsack problem for multiple knapsack sizes (1 to k) with the following specifications:

Module Name: knapsack_solver
Inputs:
  - clk: Clock signal (rising edge triggered)
  - rst_n: Active-low synchronous reset
  - start: Start pulse (assert for 1 cycle to begin computation)
  - n: 3-bit input, number of jewels (1 to 8)
  - k: 4-bit input, maximum knapsack size (1 to 16)
  - s_0 to s_7: 8 inputs, each 9-bit, sizes of jewels (1 to 300)
  - v_0 to v_7: 8 inputs, each 32-bit, values of jewels (1 to 10^9)

Outputs:
  - result_1 to result_16: 16 outputs, each 32-bit, maximum value for knapsack sizes 1 to 16
  - done: 1-bit output, asserted high when computation is complete

Behavior:
  - On reset (rst_n=0): all registers cleared, done=0, results=0
  - When start is asserted (high for 1 clock cycle), the module captures the current values of n, k, and all s_i, v_i
  - The module then computes the maximum value for each knapsack size from 1 to k using a dynamic programming approach
  - The computation is done sequentially: for each jewel (from 0 to n-1), the module updates the DP table for all capacities from k down to the jewel's size
  - When all jewels are processed, the results are placed in result_1 to result_16, and done is asserted high for 1 cycle
  - The module returns to IDLE state after done is asserted
  - The computation takes at most 128 clock cycles (8 jewels * 16 capacities)

Implementation Details:
  - Use a state machine with states: IDLE, RUN
  - Maintain a DP table of 17 registers (dp[0] to dp[16]), each 32 bits
  - dp[i] stores the maximum value for knapsack size i
  - The DP update rule: dp[capacity] = max(dp[capacity], dp[capacity - s] + v)
  - Process jewels in order, capacities in descending order to avoid multiple uses
