Design a Verilog module that validates and restores arrays according to the problem statement. The module should implement the following algorithm:
1. Accept inputs: n (4-bit), q (4-bit), and an array of 16 elements (each 4-bit, only first n used).
2. Validate the array using a stack-based approach with these steps:
   - Precompute last occurrence indices for non-zero values by scanning backward.
   - Traverse forward, using a stack to track active segments:
     - Replace zeros with current max (or 1 if max=0).
     - If encountering a value > current max and not at its last occurrence, push current max to stack and update current max.
     - If at last occurrence of current max, pop stack.
     - If encountering a value < current max, flag invalid.
   - After traversal, ensure max value equals q by setting a zero to q if possible.
3. Outputs: done (1-bit), valid (1-bit), and restored array (16×4-bit).

Interface Specification:
- Inputs: clk, rst_n, start, n[3:0], q[3:0], a_0 to a_15 (4-bit each)
- Outputs: done, valid, result_0 to result_15 (4-bit each)

State Machine:
- States: INIT, BACKWARD_PASS, INIT_FORWARD, FORWARD, AFTER_FORWARD, FIND_ZERO, OUTPUT_VALID, OUTPUT_INVALID.
- On start: Initialize, process backward for last occurrences, then forward for validation/zero-filling.
- On completion: Set done and valid; output restored array if valid.
