Design a Verilog module that builds a binary search tree (BST) from a sequence of distinct integers (1 to 8) and outputs the cumulative sum of depths after each insertion.

Module name: bst_builder

Inputs:
- clk: clock, rising edge
- rst_n: active low reset, synchronous
- start: pulse for one clock cycle to indicate that data_in contains the next number to insert
- data_in: 8-bit unsigned integer (value from 1 to 8)

Outputs:
- cumulative_sum: 8-bit unsigned integer, the value of counter C after the current insertion
- done: high for one clock cycle when the insertion is complete and cumulative_sum is valid

Behavior:
- The module maintains a BST with at most 8 nodes.
- On reset, the tree is empty, cumulative_sum = 0.
- When start is asserted, the module inserts data_in into the BST using the standard insertion algorithm.
- The insertion depth is computed as the number of edges from the root to the new node.
- After insertion, cumulative_sum is updated by adding the insertion depth.
- The done signal is asserted for one clock cycle when the insertion is finished and cumulative_sum is valid.
- The module must be able to handle consecutive insertions (after each done, start can be asserted again).

Implementation details:
- Use a fixed-size array to store nodes (8 nodes). Each node has:
   * valid flag (1 bit)
   * value (8 bits)
   * left child index (3 bits, 111 indicates null)
   * right child index (3 bits)
- Keep registers: root index (3 bits), next_node_idx (3 bits), cumulative_sum (8 bits), state machine (IDLE, TRAVERSE, INSERT, DONE).
- The traversal may take multiple cycles (maximum 7 cycles) because the depth is at most 7.
- Use a state machine to control the insertion process.

The testbench will feed a sequence of numbers (e.g., [1,2,3,4]) and check that after each insertion, cumulative_sum matches the expected value.
