Verilog Module Specification:

Module: find_number_small
Function: Finds smallest m-digit number satisfying cross-out-and-append condition

Interface:
- Inputs:
  * clk: Clock signal (rising edge triggered)
  * rst_n: Active-low synchronous reset
  * start: Start pulse (1 cycle high to begin computation)
  * m[5:0]: Number of digits in result (1-6)
  * n[5:0]: Number of digits to cross out (1-6, n <= m)
  * p[7:0]: Number to append (1-255, no leading zeros)
  * q[7:0]: Multiplier (1-255, no leading zeros)

- Outputs:
  * result[31:0]: Smallest solution (valid when done & valid high)
  * done: High for 1 cycle when computation completes
  * valid: High if solution found, low if impossible

Operation:
1. On start pulse, compute L = m - n (trailing digits count)
2. Compute d = number of decimal digits in p (1-3)
3. Compute min_N = 10^(m-1), max_N = 10^m - 1
4. Compute M = 10^L (M=1 when L=0)
5. Iterate A from 0 to M-1 (max 10,000 for L<=4):
   a. Compute B = A * 10^d + p
   b. Compute N = q * B
   c. If N >= min_N and N <= max_N:
      i. Compute remainder = (L>0) ? (N % M) : 0
      ii. If remainder == A: store N as solution
6. Output smallest solution found, or indicate impossible

Timing:
- Multiple cycles per iteration required
- Worst-case (L=4) ~10,000 iterations, <300,000 cycles total
- At 10 MHz: <30 ms computation time

Reset Behavior:
- rst_n=0: Clear all state, done=0, valid=0, result=0
- rst_n=1: Normal operation
- Minimum 2 clock cycles of reset required

Implementation Notes:
- Use combinational logic or LUT for 10^k calculations
- State machine controls iteration and arithmetic
- 32-bit result sufficient for m<=6
- done and valid asserted simultaneously for 1 cycle
- All arithmetic operations must complete within one cycle
