Design a sequential Verilog module that finds the maximum interval d between bamboo checks such that total cut length doesn't exceed k.

MODULE SPECIFICATION:
- Parameters: N=8 (max bamboos), A_WIDTH=8 (a_i up to 255), K_WIDTH=16 (k up to 65535), D_MAX=256
- Inputs: clk, rst_n, start, n (actual number of bamboos), a[0:7] (target heights), k (max cut length)
- Outputs: max_d (8-bit result), done (completion signal)
- Functionality: Iterate d from 1 to D_MAX, compute total cut = Σ(ceil(a_i/d)*d - a_i), track maximum valid d
- Reset: Active-low, clears all registers
- Timing: Start pulse initiates computation, done goes high when complete

Interface:
  Inputs:
    - clk: Clock (rising edge)
    - rst_n: Active-low reset
    - start: Start computation (1 cycle pulse)
    - n[2:0]: Number of bamboos (1-8)
    - a[7:0][7:0]: 8-element array of target heights
    - k[15:0]: Maximum cut length
  Outputs:
    - max_d[7:0]: Maximum valid d
    - done: High when result ready

Implementation Strategy:
1. State machine: IDLE → ITERATE_D → COMPUTE_SUM → CHECK → UPDATE → COMPLETE
2. For each d (1 to 256):
   - Initialize sum = 0
   - For each bamboo i (0 to n-1):
     - Compute ceil(a_i/d) = (a_i + d - 1)/d
     - Add (ceil(a_i/d)*d - a_i) to sum
   - If sum ≤ k, update max_d = d
3. Output max_d when done
