Verilog HDL module for key-person assignment to minimize maximum travel time

MODULE SPECIFICATION:

  Inputs:
    - clk: Clock signal
    - rst_n: Active-low reset  
    - start: Start computation pulse
    - people_pos[0:7]: 8 people positions (Q16.16 fixed-point)
    - key_pos[0:15]: 16 key positions (Q16.16 fixed-point)
    - office_pos: Office position (Q16.16)
    - valid_people: Number of valid people (1-8)
    - valid_keys: Number of valid keys (1-16)
  
  Outputs:
    - min_max_time: Minimum maximum time (Q16.16)
    - done: Computation complete
  
  Implementation:
    - Sort people and key positions using bubble sort
    - Use state machine to try all contiguous assignments
    - Compute max time for each assignment, track minimum
    - Fixed-point arithmetic for distances
    - Complete within 1000 cycles
  
  Timing:
    - Assert start for 1 clock cycle
    - done goes high when computation completes
    - Sample result when done is high
  
  Reset behavior:
    - rst_n=0: All registers cleared, done=0
    - Minimum 2 clock cycles reset required
