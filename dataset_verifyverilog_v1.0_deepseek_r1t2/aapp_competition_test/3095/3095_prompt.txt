Create a Verilog module that computes the maximal number of elements in an extremely cool submatrix. The matrix dimensions are fixed: R=3 rows, S=3 columns. The matrix is provided as a flattened array `matrix_flat[0:8]` where each element is 12-bit signed. The module has a clock `clk`, active-low reset `rst_n`, start pulse `start`, and outputs `max_area` (6 bits) and `done`. The combinational block iterates over all submatrices and checks the Monge condition using nested loops. On `start` rising edge, the result is latched and `done` is asserted for one cycle. Include parameters for data and area widths.
