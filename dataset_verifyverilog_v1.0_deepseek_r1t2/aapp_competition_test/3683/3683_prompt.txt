Module: MiniGolfMinRank

Parameters:
  NUM_PLAYERS = 8
  NUM_HOLES = 8
  SCORE_WIDTH = 8
  RANK_WIDTH = 4
  LL_MAX = 255

Ports:
  input  wire                    clk;
  input  wire                    rst_n;
  input  wire                    start;
  
  // Scores: for each player i (0 to 7) and hole j (0 to 7)
  input  wire [SCORE_WIDTH-1:0]  score_0_0, score_0_1, ..., score_0_7,
                                 score_1_0, ..., score_7_7;
  
  output reg  [RANK_WIDTH-1:0]   min_rank_0, min_rank_1, ..., min_rank_7;
  output reg                     done;

Behavior:
  On reset (rst_n = 0), all outputs become 0, internal state reset.
  When start pulses high, the computation begins.
  The module iterates ℓ from 1 to LL_MAX (255).
  For each ℓ:
    - Compute adjusted total for each player: sum over holes of min(score, ℓ).
    - Compute rank for each player: count of players with adjusted total <= its own.
    - Update min_rank for each player: keep the smallest rank seen so far.
  After processing all ℓ, assert done for one clock cycle.

Implementation details:
  You can use a state machine with states:
    IDLE, COMPUTE_ADJUSTED, COMPUTE_RANKS, UPDATE_MIN_RANK, INCREMENT_LL, FINISHED
  Use counters for ℓ, player index, hole index, and comparison loops.
  Since the data sizes are small, you can use sequential loops or partially unrolled logic.
  The adjusted total for a player can be computed by comparing each score with ℓ and accumulating in a register.
  The rank computation can be done by comparing each player's adjusted total with all others (nested loops).
  The min_rank update is straightforward.
  The total number of cycles will be large but acceptable for simulation.
