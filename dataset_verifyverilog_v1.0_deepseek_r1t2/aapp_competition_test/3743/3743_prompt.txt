Write a Verilog module that computes the maximum number of colors for a path of length n (scaled to 16-bit). The algorithm:
1. If n == 1, output 1
2. Find the smallest divisor d of n (from 2 to 256)
3. If found, check if n is a power of d (keep dividing by d until no longer divisible)
4. If the result is 1, output d, else output 1
5. If no divisor found, output n (n is prime)

Interface:
- Inputs: clk, rst_n (active-low reset), start, n_in (16-bit)
- Outputs: result (16-bit), done (asserted when computation completes)
- Timing: Start with start=1 for one cycle, then wait for done. Result is valid when done is high.
- Implementation: Use a state machine with trial division up to 256.
