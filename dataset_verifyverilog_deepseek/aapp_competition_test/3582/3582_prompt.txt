Design a sequential Verilog module named 'mentor_assign' that implements optimized mentor assignment for up to 8 Gagglers.

Module interface:
module mentor_assign(
  input clk, 
  input rst_n, 
  input start, 
  input [2:0] n, // Number of Gagglers (3 bits, max 8)
  input [2:0] current_mentors [0:7], // Current mentor assignments (8 elements, 3-bit each)
  output reg [2:0] new_mentors [0:7], 
  output reg done
);

Behavioral description:
1. On reset: clear all outputs and internal state
2. When start=1: begin processing to create valid permutation cycle
3. Processing steps (3-stage state machine):
   a) STAGE1: For each Gaggler (1-8), initialize new_mentors with current_mentors
   b) STAGE2: Check for cycle validity (must form single cycle)
   c) STAGE3: If invalid cycle: modify assignments starting from lowest-numbered Gaggler, preferring original assignment when possible, then lowest-numbered alternative
4. Output valid after ≤ 16 clock cycles (5 for n≤8)
5. done=1 when new mentor assignments form a single cycle and satisfy the priority rules
