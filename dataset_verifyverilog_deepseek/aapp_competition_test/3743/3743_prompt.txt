Design a sequential Verilog module named 'aesthetic_path_colors' that computes the maximum possible colors for an aesthetic path of length n.

Inputs:
  input clk,          // clock signal
  input rst_n,        // active-low reset
  input start,        // start computation (assert high)
  input [7:0] n       // path length (1-255)

Outputs:
  output reg [7:0] result, // result (1, prime factor, or n if prime)
  output reg done      // asserted when computation complete

Behavior:
1. When start is asserted, compute result based on n:
   - If n=1: result=1
   - Else if n has exactly one distinct prime factor p: result=p
   - Else: result=1
2. Implement via trial division:
   a. Find smallest divisor >1 (if none, n is prime)
   b. Check if n is a power of this divisor (repeated division)
3. Uses 4 states: IDLE, FIND_DIVISOR, CHECK_POW, DONE
4. Latency: 23 clock cycles max (15 divisor checks + 7 divisions)
5. Reset: Assert rst_n=0 to reset all internals. Start computation with start=1.
6. Output valid when done=1 (held until next start).
