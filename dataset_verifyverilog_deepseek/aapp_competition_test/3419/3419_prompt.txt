Design a sequential Verilog module named 'license_counter' that maximizes the number of customers who can be served given two counters with time limits.
Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation (pulse high)
input [3:0] n // number of customers (max 16)
input [7:0] s1 // counter 1 max time (0-255)
input [7:0] s2 // counter 2 max time (0-255)
input [7:0] t [0:15] // customer times array (16 elements, each 8 bits)

Outputs:
output reg [3:0] max_customers // maximum served (0-16)
output reg done // high when computation complete

Behavior:
1. When start is pulsed high, initialize state with s1/s2 time
2. Process customers sequentially from index 0 to n-1
3. Maintain DP table tracking possible time pairs
4. Update state each clock cycle - try assign customer to counter1 or counter2 if possible
5. After processing all customers, output highest customer count

Timing:
- Latency: n+2 cycles (1 cycle start, n cycles processing, 1 cycle result) 
- Output valid when done=1

Implementation Notes:
- Use state machine: IDLE, PROCESSING, DONE
- Represent DP state with 256x256 memory (s1 x s2 possible times)
- Initialize with s1_init = s1, s2_init = s2
- Iterate through customer list sequentially
