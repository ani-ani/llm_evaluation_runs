Design a sequential Verilog module named 'frog_flower_sync' that finds the minimum time when two linear congruential generators reach target values.

Interface:
module frog_flower_sync(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [15:0] m, // Modulo value (2 ≤ m ≤ 65535)
  input [15:0] h1, a1, x1, y1, // Frog parameters (h1 ≠ a1)
  input [15:0] h2, a2, x2, y2, // Flower parameters (h2 ≠ a2)
  output reg [11:0] time_out, // Minimum sync time (0-3071)
  output reg done, // High when finished
  output reg fail // High if no solution found
);

Behavior:
1. On reset or !start: Initialize time_out=0, done=0, fail=0
2. When start==1:
   - Each clock cycle update:
     h1_next = (x1 * h1 + y1) % m
     h2_next = (x2 * h2 + y2) % m
   - Compare updated values to a1/a2 each cycle
3. If h1 == a1 and h2 == a2: assert done=1 with time_out
4. If no match after 3072 cycles (0xFFF): assert fail=1 and done=1

Latency: Variable (1-3072 cycles). Done/fail asserted in cycle when solution is found/rejected.
