Design a sequential Verilog module named 'coin_flip_average' that calculates the average number of operations L(C) for a given coin sequence with uncertainty.

Module interface:
module coin_flip_average(
  input clk,                    // clock signal
  input rst_n,                  // active-low reset
  input start,                  // pulse high to start computation
  input [1:0] data,             // input coin states (H=1, T=0) for known positions
  input [1:0] mask,             // mask where 1=unknown ('?'), 0=known
  output reg [31:0] result,     // Q16.16 fixed-point average (16 integer, 16 fractional bits)
  output reg done               // high when computation complete
);

Behavior: On start pulse, module computes average operations across all possible configurations (accounting for '?' positions) using the Bank of Bath flipping rule. Process finite 4-state sequences - scale down from original problem but maintain core algorithm.

Latency: Maximum 40 clock cycles (10 cycles/config * 4 config max for 4-character input) with done signal assertion on completion.

Implementation requirements:
1. Use Q16.16 fixed-point format for result
2. Handle all 4-character combinations (each config = where masked bits vary)
3. For each configuration:
   a. Initialize coin state
   b. Iteratively flip coins according to rules until all T
   c. Count operations L(C)
4. Average = (sum of all L(C)) / total_configurations
5. Must handle test cases scaled to 4-bit width
