Design a combinational Verilog module named 'tree_validator' that checks if tree construction is possible based on input constraints.

Inputs:
input [4:0] n,  // Number of nodes (1-24)
input [4:0] c [0:23],  // 24-element array, each element 5 bits (c_i values, unused positions ignored)

Output:
output reg valid  // 1 if valid tree possible (YES), 0 otherwise (NO)

Behavior:
The module must check two conditions in parallel:
1. The largest value in c[0] to c[n-1] must equal n
2. None of the values c[0] to c[n-1] can be exactly 2
valid should be 1'b1 only when both conditions are true. Use parallel comparators to check all c_i values simultaneously.
