Design a sequential Verilog module named 'hopper_path_finder' that finds the longest exploration sequence under these constraints:
1. Array size fixed at 8 elements (16-bit signed each)
2. Jump distance D (3-bit input, 1-7)
3. Max value difference M (8-bit signed input)

Module interface:
module hopper_path_finder(
  input clk,               // clock signal
  input rst_n,             // active-low reset
  input start,             // initiate computation
  input [2:0] D,           // max jump distance (1-7)
  input [7:0] M,           // max value difference (signed)
  input [15:0] arr_0,      // array elements
  input [15:0] arr_1,
  input [15:0] arr_2,
  input [15:0] arr_3,
  input [15:0] arr_4,
  input [15:0] arr_5,
  input [15:0] arr_6,
  input [15:0] arr_7,
  output reg [3:0] max_length,  // result: longest path length
  output reg done           // high when computation complete
);

Behavior:
- On reset: clear all states
- When start=1: compute longest path using BFS-like approach with visited masks
- Constraints: 1) Next index ≤ D away 2) |value difference| ≤ M 3) No revisits
- Output valid 64 cycles after start (worst-case for 8 nodes)
- Use state machine: IDLE, INIT, COMPARE_JUMP, UPDATE_PATH, DONE
- Store array in internal 8x16-bit register array
- Implement parallel validity checks for jump targets within constraints
