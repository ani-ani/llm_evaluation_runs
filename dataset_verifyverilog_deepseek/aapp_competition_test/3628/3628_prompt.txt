Design a sequential Verilog module named 'permutation_crypto' that verifies if two permutations π and σ exist for given public key a, where (π_i + σ_i) mod n ≡ a_i for all i.

Parameters: Fixed n = 8.
Inputs:
  input clk,              // clock signal
  input rst_n,            // active-low reset
  input start,            // start computation (pulse high)
  input [3:0] a [0:7],   // public key (8 elements of 4 bits each)

Outputs:
  output reg [3:0] pi [0:7],  // first permutation (if solution exists)
  output reg [3:0] sigma [0:7],// second permutation
  output reg valid,           // high when solution exists
  output reg impossible,      // high when no solution exists
  output reg done             // high when computation completes

Behavior:
1. On reset (rst_n=0), clear all outputs.
2. When start=1:
   - Systematically checks all candidate π permutations (0-7) 
   - For each π, computes σ_i = (a_i - π_i) mod 8 
   - Checks if σ is a valid permutation
3. If valid π/σ found:
   - Outputs permutations via pi/sigma ports
   - Asserts valid=1 and done=1
4. If no solution after all permutations checked:
   - Asserts impossible=1 and done=1

Latency: Worst-case 8! cycles (40320), but finds solution as soon as possible.
Implementation note: Use iterative approach with permutation generator state machine.
