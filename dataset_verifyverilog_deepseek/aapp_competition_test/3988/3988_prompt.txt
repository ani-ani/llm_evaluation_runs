Design a sequential Verilog module named 'graph_reachability_optimizer' that computes optimal edge orientations for a small graph.
Module interface:
module graph_reachability_optimizer(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // start computation
  input [2:0] start_node, // s (source node, 0-7)
  input [2:0] graph_nodes [0:15][0:2], // 16 max edges, [t,u,v] per edge
  input [3:0] edge_count, // actual edges (1-16)
  output reg [3:0] max_reachable, min_reachable, // reachable counts (0-8)
  output reg [15:0] max_orient, min_orient, // orientation bits (1'b1='+', 1'b0='-')
  output reg done // high when computation complete
);

Behavioral description:
- Implements simplified BFS for max/min reachability in 8-node graph
- Represent graph with adjacency list (size limited to 16 edges)
- For undirected edges: Orientation determines direction (u->v for '+', v->u for '-')
- Compute MAX plan first, then MIN plan
- Latency: Output valid within 32 clock cycles maximum after start
- Use 3-bit node IDs (0-7)
- Undirected edges must be oriented differently in max/min plans
- Edge types: t=1 (directed), t=2 (undirected)
- Reset initializes all outputs to 0
- State machine: RESET, PROCESS_MAX, PROCESS_MIN, DONE
- Output 'done' high for 1 cycle when complete
