Design a sequential Verilog module named 'mission_assigner' that finds the maximum success probability for N=4 Jimmy Bonds.

Inputs:
input clk, // clock signal
input rst_n, // active-low reset
input start, // start computation
input [6:0] probabilities[0:3][0:3] // 4x4 matrix, each entry 0-100 (7-bit) representing percentage success chance

Outputs:
output reg [31:0] max_prob, // maximum product in Q16.16 fixed-point (0xNNNN.NNNN format)
output reg done // high when computation complete

Functionality:
1. On reset: all outputs set to 0
2. When start=1: begin computing maximum product permutation
3. Test all 4! (24) possible mission assignments
4. For each assignment:
   - Multiply success probabilities (convert 0-100 values to Q16.16 fractions by multiplying by 65536/100)
   - Maintain maximum product found
5. After 32 clock cycles, output max_prob and assert done=1

Behavior:
- Internal state machine with states: IDLE, CALCULATING, DONE
- Use combinatorial permutation generator with 24 states
- All multiplication operations use 32-bit fixed-point arithmetic
- Latency: 32 cycles from start assertion to valid output
