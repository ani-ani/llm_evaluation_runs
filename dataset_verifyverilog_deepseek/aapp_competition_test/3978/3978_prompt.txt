Design a Verilog module named 'color_minimizer' that calculates the minimal color count for an 8-element sequence. The module must be sequential with start/done signaling.
Module interface:
module color_minimizer(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // start signal
  input [63:0] data_in, // packed 8x8-bit input elements
  output reg [3:0] color_count, // result (range 1-8)
  output reg done // high when calculation complete
);

Behavioral description:
1. On reset: clear all registers, set done=0
2. When start asserted:
   a. Extract 8 8-bit elements from data_in into a working array
   b. Sort the array in ascending order using bubble sort (requires ~28 cycles worst-case)
   c. Main algorithm: Initialize color counter to 0. For each element i from 0 to 7:
      i. If element not marked as painted: increment color counter, mark all subsequent elements divisible by current element
   d. Total expected latency: 40 cycles (sorting + processing)
3. After 40 cycles from start: output color_count and assert done=1
4. Module clears done when start is lowered
