Design a sequential Verilog module named 'game_level_optimizer' that calculates the minimum time to complete 3 levels with shortcut options.

Inputs:
  input clk,             // clock
  input rst_n,           // active-low reset
  input start,           // start computation
  // Level 0 parameters:
  input [1:0] x0,        // shortcut item for level 0
  input [31:0] s0,       // shortcut time for level 0
  input [31:0] a00,      // time when using item 0 (level 0)
  input [31:0] a01,      // time when using item 1 (level 0)
  input [31:0] a02,      // time when using item 2 (level 0)
  input [31:0] a03,      // time when using item 3 (level 0)
  // Level 1 parameters:
  input [1:0] x1,        // shortcut item for level 1
  input [31:0] s1,       // shortcut time for level 1
  input [31:0] a10,      // time when using item 0 (level 1)
  input [31:0] a11,      // time when using item 1 (level 1)
  input [31:0] a12,      // time when using item 2 (level 1)
  input [31:0] a13,      // time when using item 3 (level 1)
  // Level 2 parameters:
  input [1:0] x2,        // shortcut item for level 2
  input [31:0] s2,       // shortcut time for level 2
  input [31:0] a20,      // time when using item 0 (level 2)
  input [31:0] a21,      // time when using item 1 (level 2)
  input [31:0] a22,      // time when using item 2 (level 2)
  input [31:0] a23,      // time when using item 3 (level 2)

Outputs:
  output reg [31:0] min_time, // minimum total time
  output reg done              // high when computation complete

Behavior:
1. At start==1, the module loads all input parameters.
2. Calculates minimum time for all 6 possible permutations of level order.
3. For each permutation, tracks available items and selects best time (shortcut if available, else best item time).
4. Computes total time for each permutation sequence.
5. Finds minimum total time among all permutations.
6. Result is valid 1 clock cycle after start assertion.
7. The done signal is raised for 1 cycle when complete.
