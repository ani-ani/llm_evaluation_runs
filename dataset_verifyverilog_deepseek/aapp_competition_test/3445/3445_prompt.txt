Design a sequential Verilog module named 'courier_partition_optimizer' that finds the optimal customer division between two companies to minimize the maximum delivery time.

Inputs:
input clk, // system clock
input rst_n, // active-low reset
input start, // pulse high to start computation
input [3:0] x[0:7], // x coordinates (4-bit each, 8 customers)
input [3:0] y[0:7], // y coordinates (4-bit each, 8 customers)
input [2:0] num_customers, // actual number of customers (3-8)

Outputs:
output reg [4:0] min_max_time, // final result (minimum possible max time)
output reg done // high when computation complete

Behavior:
1. When start pulses high, the module computes all pairwise Manhattan distances between customers (distance = |x_i - x_j| + |y_i - y_j|).
2. For each possible partition of customers (divided into two non-empty groups):
   a. Compute maximum intra-group distance for each company
   b. Track the smaller of the two companies' maximum distances
   c. Record the global minimum of these values
3. Output the result via min_max_time when done=1.

Implementation notes:
- Use a state machine with: IDLE, CALC_DIST, EVAL_PARTITIONS, DONE
- Pre-compute customer pair distances (28 pairs for 8 customers)
- Evaluate up to 254 possible partitions (2^8 - 2)
- Each partition evaluation requires 2-8 distance lookups
- Results must be ready within 300 clock cycles after start
- Input coordinates can represent values 0-15, distances 0-30 (5-bit)
