Design a Verilog module named 'truck_encounter_counter' that calculates the number of times two trucks meet while moving along fixed routes. The module must implement the following behavior:

Inputs:
  input clk,               // clock signal
  input rst_n,             // active-low reset
  input start,             // pulse high to start calculation
  input [3:0] truck1_segments,  // number of route segments for truck 1 (2-4)
  input [3:0] truck2_segments,  // number of route segments for truck 2 (2-4)
  input [9:0] truck1_route [0:3], // 4-way array: city positions (10-bit each)
  input [9:0] truck2_route [0:3], // 4-way array: city positions (10-bit each)

Outputs:
  output reg [7:0] encounter_count, // number of meetings 
  output reg done,            // high when calculation complete

Behavior:
1. On reset or initial power-on, all outputs should be cleared.
2. When 'start' pulse is detected:
   a. Validate route segments (must form valid zig-zag pattern)
   b. Simulate truck movements minute-by-minute
   c. Count when trucks occupy the same non-integer position
   d. Ignore meetings at departure, turning, or alien pickup times
3. Module should progress through these states:
   IDLE → VALIDATE → SIMULATE → COMPLETE
4. Truck positions calculated using fixed-point Q10.2 arithmetic (integer=city, fractional=progress)
5. Simulation completes when both trucks finish their final segment
6. Result valid 1 clock cycle after done assertion

Timing Constraints:
- Max simulation time: 2^12 minutes (4096 cycles)
- Encounter comparison done combinationally in SIMULATE state
- Must complete within 4096 + 100 clock cycles after start

Implement with:
- 12-bit time counter
- 10-bit integer + 2-bit fractional position tracking
