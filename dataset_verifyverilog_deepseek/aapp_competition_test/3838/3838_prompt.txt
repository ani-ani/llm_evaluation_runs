Design a sequential Verilog module named 'permutation_checker' that verifies if Petya's game result is possible with scaled constraints (n≤8, k≤16).

Module interface:
module permutation_checker(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // start computation
  input [2:0] n, // permutation size (1-8)
  input [3:0] k, // number of moves (1-16)
  input [23:0] q, // permutation q[0:n-1] (3 bits per element, 8 elements)
  input [23:0] s, // target permutation s[0:n-1] (3 bits per element)
  output reg result, // 1=possible, 0=impossible
  output reg done // high when computation complete
);

Description:
1. Accepts start signal to begin computation.
2. Computes 2 sequences: (a) applying q forward, (b) applying inverse of q (operation alternates per move)
3. Checks if s appears exactly at k moves, not earlier, in either sequence.
4. Also checks initial state (beginning of game) is not equal to s.
5. Uses cycle detection with parity constraints for k and minimal steps.
6. Outputs result after 8 clock cycles maximum (for n≤8).
7. Implements parity checking following same logic as Python's e[k%2]/f[k%2] approach.
