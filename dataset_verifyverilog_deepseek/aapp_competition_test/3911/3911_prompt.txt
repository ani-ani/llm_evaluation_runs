Design a sequential Verilog module named 'slime_merger' that simulates the slime merging process for up to 8 slimes.

Module interface:
module slime_merger(
    input clk,                  // clock
    input rst_n,                // active-low reset
    input [2:0] n,              // number of slimes (1-8)
    input start,                // pulse high to begin processing
    output reg [2:0] elem_0,    // stack element 0 (leftmost)
    output reg [2:0] elem_1,    // stack element 1
    output reg [2:0] elem_2,    // stack element 2
    output reg [2:0] elem_3,    // stack element 3
    output reg done             // high when computation complete
);

Behavioral description:
- On reset (rst_n=0), clear all elem_* outputs and done flag.
- When start is asserted:
  * Initialize an internal stack with first slime (value 1)
  * Process n-1 additional slimes (1 per clock cycle):
    - Add slime with value 1 to end of stack
    - Repeatedly merge last two elements if equal (v=v+1 until differ)
  * After processing all slimes (n cycles from start), output stack in elem_0 (leftmost) to elem_3 registers, pad unused positions with 0
  * Assert done for one cycle when complete
Timing: Output available n clock cycles after start assertion. Done pulses for 1 cycle when result is ready.
