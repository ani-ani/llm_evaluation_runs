Design a sequential Verilog module named 'bookcase_area_min' that finds the minimum area for a three-shelf bookcase with exactly 5 books.

Module interface:
module bookcase_area_min(
  input clk,  // System clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [8:0] h0, h1, h2, h3, h4, // Book heights (9 bits each)
  input [4:0] t0, t1, t2, t3, t4, // Book thicknesses (5 bits each)
  output reg [17:0] min_area, // Minimum area (18-bit output)
  output reg done // High when computation completes
);

Behavioral description:
- The module must test all 3^5=243 possible shelf assignments (each book -> shelf 0,1,2), excluding cases where any shelf is empty.
- When 'start' is asserted:
  1. Reset min_area to maximum value (18'h3FFFF)
  2. Iterate through all valid shelf partitions (state machine)
  3. For each partition:
      a. Compute shelf heights: max height per shelf
      b. Compute total_thickness per shelf
      c. Calculate area = (sum of shelf heights) * (max total_thickness)
      d. Update min_area if current area is smaller
  4. Assert 'done' signal when all partitions tested
- Latency: min_area valid 250 clock cycles after start assertion.
- Use combinatorial logic for area calculations within each state iteration.
- Use a state machine with states: IDLE, INIT, COMPUTE, UPDATE, DONE.
