Design a sequential Verilog module named 'minimal_tunnel_cost' that calculates the minimal cost for connecting planets in 3D space.

Inputs:
input clk, // clock signal
input rst_n, // active-low reset
input start, // start computation
input [7:0] x[0:3], // 4 planet coordinates (8-bit signed)
input [7:0] y[0:3],
input [7:0] z[0:3],

Outputs:
output reg [9:0] total_cost, // minimal total cost (10-bit unsigned)
output reg done // high when computation complete

Behavior:
1. On reset (rst_n=0), set total_cost=0, done=0
2. When start=1, compute tunnel costs between all planet pairs:
   TunnelCost(A,B) = min(|x_A-x_B|, |y_A-y_B|, |z_A-z_B|)
3. Compute Minimal Spanning Tree (MST) for 4 planets using Kruskal's algorithm:
   - Generate all 6 edges with costs
   - Sort edges by cost (ascending)
   - Select smallest edges until 3 edges are selected without cycles
4. Sum selected edge costs into total_cost
5. Assert done after 50 clock cycles

Latency: Inputs must remain stable for 50 cycles. Output valid when done=1. Implement cycle counter and edge sorting using state machine.
