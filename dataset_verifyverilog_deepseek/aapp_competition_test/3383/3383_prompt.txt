Design a sequential Verilog module named 'ice_cream_optimizer' that computes maximum tastiness/gold ratio for up to 16 scoops and 4 flavors.
Module interface:
module ice_cream_optimizer(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // pulse high to start computation
  input [3:0] n, // max scoops (1-16) 
  input [1:0] k, // num flavors (1-4) 
  input [8:0] a, // cost per scoop (1-200)
  input [8:0] b, // cone cost (1-200)
  input [8:0] t [0:3], // 4x tastiness (9-bit signed)
  input [8:0] u [0:3][0:3], // 4x4 add'l tastiness (9-bit signed)
  output reg [31:0] max_ratio, // Q16.16 fixed-point result
  output reg done // high when computation completes
);

Behavior:
1. When start=1, begin computation using provided inputs
2. Latency ≤200 cycles (depends on n)
3. Implement optimized DP:
   - Maintain max_tastiness[1..16] registers (14-bit signed)
   - For each scoop count s (1 to n):
      - For flavor combinations: track max achievable tastiness
4. Compute ratio = (max_tastiness[s] << 16) / (a*s + b)
5. Output max ratio in Q16.16 format
6. If max_tastiness ≤0, output 0

Timing:
- Output valid when done=1
- Finish within 200 cycles max after start asserted
