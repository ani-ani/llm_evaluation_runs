Design a sequential Verilog module named 'matrix_optimizer' that finds operations to maximize sum of 4x4 matrix elements. Inputs: clk, rst_n, start, and 16-bit signed matrix inputs. Outputs: best_sum (32-bit), operation_count (8-bit), and operation sequence. The module has 3 cycles latency after start.

Module interface:
module matrix_optimizer(
  input clk, // Clock signal
  input rst_n, // Active-low reset
  input start, // Start optimization
  input signed [15:0] matrix_in [0:3][0:3], // 4x4 matrix input
  output reg signed [31:0] best_sum, // Maximum sum achievable
  output reg [2:0] operation_count, // Number of operations (0-5)
  output reg [127:0] operation_sequence // Encoded operations (3-bit per op + 16-bit args)
);
// Implementation details:
// - Supports max 4x4 matrix scaled from original problem
// - Each operation stored as {2'b00 for rotR, 2'b01 for rotS, 2'b10 for negR, 2'b11 for negS}, row/col index, shift amount
// - Evaluates all possible single operations, computes maximum sum improvement
// - Operation sequence built over 3 clock cycles after start
// - Reset initializes all registers to zero
// - Output valid 3 cycles after start assertion
endmodule
