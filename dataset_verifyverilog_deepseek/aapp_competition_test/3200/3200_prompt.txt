Design a Verilog module named icar_driver that calculates minimum travel time through traffic lights.
Inputs:
- input clk
- input rst_n
- input start
- input [3:0] n // Road length (1-16 km)
- input [6:0] t_i [15:0] // Initial green time offsets (0-99), unused indices ignored
- input [6:0] g_i [15:0] // Green durations (40-50)
- input [6:0] r_i [15:0] // Red durations (40-50)
Outputs:
- output reg [31:0] total_time // Final time in Q32.16 format (lower 16 bits fractional)
- output reg done // High when calculation complete

Behavior:
- Sequential module using fixed-point arithmetic with 16 fractional bits
- Simulates car motion at 0.1s time steps with acceleration control
- At each step: 
  1. Update position: pos_next = pos + velocity * dt + 0.5 * accel * dt^2
  2. Check if passing traffic lights: For each km, verify light state
  3. Brake if crossing light during red phase (hold acceler=0 when released)
- Output total_time when reaching end (pos >= 1000*n meters)
- Latency: Variable cycles (1 cycle per 0.1s simulated time + overhead), completes within 100k cycles.
Use state machine with states: IDLE, ACCELERATING, COASTING, COMPLETE.
