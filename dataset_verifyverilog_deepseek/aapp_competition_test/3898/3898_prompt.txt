Design a combinational Verilog module named 'statue_rotator' that checks if rearranging statues on 8 islands forming a cycle is possible given initial and desired configurations. The module must have:
- Inputs: a[7:0][2:0] (initial statue IDs, exactly one 0), b[7:0][2:0] (desired statue IDs, same)
- Output: possible (1-bit)
Behavior:
1. Remove the zero from 'a' and 'b' to form 7-element arrays 'a_nz' and 'b_nz'. For each input array, find the index of 0, then create the non-zero array as elements following 0 (wrapping around end) until 7 elements are collected.
2. Find the position of 'b_nz[0]' in 'a_nz'. If not found, set possible=0.
3. Rotate 'a_nz' to start at this position and check if equal to 'b_nz'.
4. If equal, set possible=1; else possible=0.
All operations must be combinational with no clock or reset.
Module definition:
module statue_rotator(
  input [7:0][2:0] a,
  input [7:0][2:0] b,
  output reg possible
);
