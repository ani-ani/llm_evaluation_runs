Design a sequential Verilog module named 'three_states_router' that finds the minimum roads to connect three states on an 8x8 grid.

Module interface:
module three_states_router(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [2:0] grid [0:7][0:7], // Grid cells [2:0]: {state[1:0], is_road_allowed}
  output reg [7:0] result, // Min roads needed (255 = -1 if impossible)
  output reg done // High when computation complete
);

Behavior description:
1. On reset or when start=0: Initialize all registers and set done=0
2. On start=1:
   a. Perform BFS expansion from all three states in parallel
   b. Track minimum road construction paths to connect states
   c. After 64 cycles (grid area), compute minimum connections
3. Output valid when done=1:
   - If states are connectable: result = minimum roads needed
   - Otherwise: result = 255

Timing: Output valid after 100 clock cycles maximum when done asserts.
