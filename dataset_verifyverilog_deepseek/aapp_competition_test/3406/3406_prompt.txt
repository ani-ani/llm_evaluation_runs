Design a sequential Verilog module named 'castle_danger_detector' that detects castles in danger per the following spec:

Inputs:
input clk,              // Clock
input rst_n,            // Active-low reset
input load,             // Load data pulse (1 cycle per point)
input [15:0] x_i,       // X-coordinate of point being loaded (Nazi troop or castle)
input [15:0] y_i,       // Y-coordinate of point being loaded
input is_castle_i,      // 1=current point is castle, 0=Nazi troop
input start             // Start computation after loading

Outputs:
output reg [1:0] danger_count, // Number of castles in danger (0-4)
output reg done          // High when computation complete

Functionality:
- Maximum 8 Nazi troops (N=8) and 4 castles (S=4)
- Store loaded points in internal registers
- After start signal, for each castle:
  - Check all combinations of 4 Nazi troops
  - For each combination:
    1. Verify quadrilateral is non-degenerate (no 3 collinear points + non-intersecting edges)
    2. If castle is inside or on border of valid quadrilateral
    3. Mark castle as in-danger and move to next castle
- danger_count = number of castles with at least one enclosing quadrilateral
- Latency: Variable (depends on number of castles and valid combinations), done asserted when complete

Notes:
- Use cross products for:
  - Collinearity check (dx1*dy2 == dx2*dy1 for 3 points)
  - Edge intersection check (line segment AB vs CD)
- Use point-in-quadrilateral algorithm with barycentric coordinates or ray casting
- Implement using state machine with states: IDLE, LOADING, CHECK_CASTLE, CHECK_QUAD, DONE
- Proper pipelining of arithmetic operations recommended for timing closure
