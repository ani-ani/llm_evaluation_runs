Design a sequential Verilog module named 'lottery_probability' that calculates the probability of a group getting tickets with these scaled constraints: maximum m=16, n=8, t=8, p=16.

Inputs:
  input clk,             // Clock
  input rst_n,           // Active-low reset
  input start,           // Start calculation
  input [4:0] m,         // Total people (1-16)
  input [3:0] n,         // Winners drawn (1-8)
  input [3:0] t,         // Tickets per winner (1-8)
  input [4:0] p          // Group size (1-16)

Outputs:
  output reg [31:0] probability, // Q16.16 fixed-point (16 int, 16 frac)
  output reg done                // High when result ready

Behavior:
1. On reset: probability=0, done=0
2. When start=1:
   a. Compute required tickets: req_tickets = p
   b. Compute minimum winners needed: k_min = ceil(req_tickets / t)
   c. Calculate probability as sum_{k=k_min}^{min(n, m)} [C(p, k) * C(m-p, n-k)] / C(m, n)
3. Use 32-bit fixed-point division (Q16.16 format)
4. Done asserts after 20 clock cycles (latency for computation)
5. Implement with state machine: IDLE, CALC_COMB, DIVIDE, DONE

Note: Precompute combinations for m<=16 using lookup tables or iterative multiplication. Approximate division if needed.
