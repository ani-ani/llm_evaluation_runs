Design a sequential Verilog module named 'string_interleave_check' that verifies if string s can be formed by interleaving s1 and s2 with preserved order.

Input signals:
  input clk                  // Clock
  input rst_n                // Active-low reset
  input start                // Start computation
  input [2:0] len_s          // Length of s (0-7)
  input [7:0][4:0] s         // 8 chars (5 bits each)
  input [2:0] len_s1         // Length of s1 (0-7)
  input [7:0][4:0] s1        // 8 chars
  input [2:0] len_s2         // Length of s2 (0-7)
  input [7:0][4:0] s2        // 8 chars

Output signals:
  output reg done           // Computation complete
  output reg result         // 1=valid interleave, 0=invalid

Behavior:
- When start is asserted, begin computation
- Uses dynamic programming approach: dp[i][j] = (s1[0:i] and s2[0:j] form s[0:i+j])
- Implements row-by-row DP to reduce storage (max 16 bits per row for len_s2)
- Result valid after (len_s1+1)*(len_s2+1) + 2 clock cycles (max 64 cycles)
- done goes high for 1 cycle when result is valid

State machine:
  IDLE, COMPUTE_ROW, CHECK_COMPLETE, DONE
