Design a sequential Verilog module named 'permutation_shift_deviation' that finds the cyclic shift with minimum deviation for permutations up to size 16.
Module interface:
module permutation_shift_deviation(
  input clk,              // clock
  input rst_n,            // active-low reset
  input start,            // start calculation
  input [3:0] n,          // permutation size (2 ≤ n ≤ 16)
  input [15:0][3:0] p,    // permutation elements (p[0] to p[15])
  output reg [7:0] min_dev,   // minimum deviation (max 16*15=240)
  output reg [3:0] shift_id,  // optimal shift id (0 to n-1)
  output reg done          // high when calculation complete
);

Behavioral description:
- On reset: Clear all registers
- When start is asserted: Begin deviation calculation
- Implement the optimized algorithm with these states:
  1. INIT_CALC: Compute deviation for shift_id=0
  2. ITERATE: Compute deviation for remaining shifts (1 to n-1)
  3. UPDATE: Track minimum deviation and corresponding shift_id
  4. DONE: Assert done signal
- Use counters for:
  - shift iteration (0 to n-1)
  - deviation calculation across permutation elements
- For each shift k (0 ≤ k < n):
  - deviation = Σ|p[(i+k)mod n] - (i+1)| for all i in 0 to n-1
- Latency: n+4 clock cycles (max 20 cycles for n=16)
- Use combinational logic for absolute values and sums
