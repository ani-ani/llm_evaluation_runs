Design a sequential Verilog module named "wheel_rotator" that finds minimal rotations to make all columns have distinct letters.

Module interface:
module wheel_rotator(
  input clk,               // clock signal
  input rst_n,             // active-low reset
  input start,             // pulse high to start computation
  input [2:0] str_len,     // actual string length (2-8)
  input [7:0][1:0] wheel0, // first wheel (8 cols max)
  input [7:0][1:0] wheel1, // second wheel
  input [7:0][1:0] wheel2, // third wheel
  output reg [3:0] result, // min rotations or 15 for -1
  output reg done           // high when computation complete
);

Behavior:
- All wheels have same length (2-8 cols) specified by str_len
- Letters encoded: "A"=00, "B"=01, "C"=10 (11 invalid)
- When start=1, compute minimal single-wheel rotations required to make all columns have distinct letters
- Rotation count: moving 1 position left/right = 1 rotation
- Output result=15 (0xF) if impossible
- Algorithm: Try all combinations of rotation offsets for the 3 wheels (max ±7 rotations)
- Use state machine with init/config/calculation/done states
- Latency: Result valid within 1000 clock cycles max (for worst-case n=8)
- Reset sets all registers to initial state
