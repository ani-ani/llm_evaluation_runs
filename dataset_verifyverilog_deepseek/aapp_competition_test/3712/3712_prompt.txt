Design a sequential Verilog module named 'compartment_swaps' that calculates the minimum people to convince for valid compartment configurations.
Inputs:
input clk,               // clock signal
input rst_n,             // active-low reset
input start,             // pulse high to start computation
input [2:0] comp0,       // student count for compartment 0 (0-4)
input [2:0] comp1,       // ... up to comp7
input [2:0] comp2,
input [2:0] comp3,
input [2:0] comp4,
input [2:0] comp5,
input [2:0] comp6,
input [2:0] comp7
Outputs:
output reg [6:0] result, // minimum swaps needed (0-127)
output reg done          // high when computation complete
Behavior:
- On reset: Clear all internal registers, set done=0
- When start=1: Initialize counts[1], counts[2], counts[3], counts[4] based on comp0-comp7
- Process these steps sequentially (1 step per clock cycle):
  1. Process min(counts[1], counts[2]) pairs: ans += min_val, counts[3] += min_val
  2. Handle remaining counts[1]:
     a. ans += 2*(counts[1]/3), counts[3] += counts[1]/3
     b. For remainder: if counts[3]>0 add remainder else add 2 if remainder≠0
  3. Handle remaining counts[2]:
     a. ans += 2*(counts[2]/3), counts[3] += 2*(counts[2]/3)
     b. For remainder: if counts[4]>0 add remainder else add 2 if remainder≠0
- Set result = ans, done=1 when complete (after ~15 cycles)
- If total students <3 or =5, result=-1 (represented as 7\'b1111111)
Notes:
- All counts registers should be 4-bit (max 8 compartments)
- Implement internal FSM with states: IDLE, COUNTING, PROCESS_12, PROCESS_1_REM, PROCESS_2_REM, FINISH
