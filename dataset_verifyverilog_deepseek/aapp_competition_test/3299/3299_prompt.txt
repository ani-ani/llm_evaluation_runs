Design a combinational Verilog module named 'magic_checkerboard_validator' that checks compliance for a completely filled 4x4 grid.

Module interface:
module magic_checkerboard_validator(
  input [11:0] grid [0:3][0:3], // 4x4 grid cells (12-bit values to handle up to 4095)
  output reg valid // 1 if valid Magic Checkerboard, 0 otherwise
);

Behavioral description:
1. Check all rows are strictly increasing left-to-right
2. Check all columns are strictly increasing top-to-bottom
3. For cells sharing only corners (diagonal neighbors), check opposite parity (one even, one odd)
4. Verify all cells are positive (no zeros)
The module must output valid=1 only if ALL conditions are satisfied for the entire grid. Use combinational logic.
