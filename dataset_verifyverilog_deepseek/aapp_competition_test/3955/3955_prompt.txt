Design a sequential Verilog module named 'max_bitwise_or' that computes the maximum possible bitwise OR after performing at most k operations. Each operation can multiply one number by x (2 ≤ x ≤ 4).

Module interface:
module max_bitwise_or(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // pulse high to start computation
  input [2:0] k, // max operations (0-7)
  input [2:0] x, // multiplier (2-4)
  input [7:0][15:0] arr, // fixed 8-element array (padded with 0s if n<8)
  output reg [31:0] result, // maximum OR value
  output reg done // high when computation completes
);

Behavioral description:
1. Upon reset, all internal registers are cleared.
2. When start is high:
   a. Compute x^k (max 4^7 = 16384, stored as 16-bit value)
   b. Generate prefix OR array: pref[i] = arr[0] | arr[1] | ... | arr[i-1]
   c. Generate suffix OR array: suff[i] = arr[i+1] | ... | arr[7]
   d. For each element i (0-7):
      i. Compute candidate = (arr[i] * x^k) | pref[i] | suff[i]
      ii. Track maximum candidate value
3. After 1 clock cycle, output the maximum candidate on 'result' and assert 'done' for 1 cycle.

Notes:
- All OR operations are computed in parallel for hardware efficiency
- Multiplications use combinatorial logic (ensure x^k doesn't exceed 65535)
- Input array elements are zero-padded if less than 8 elements
- Module runs at 100MHz timing constraint
