Design a combinational Verilog module named 'clock_adjust_counter' that calculates the number of unique times displayed when adjusting a clock.

Module interface:
module clock_adjust_counter(
  input [3:0] start_ht,  // Start hour tens (0-2)
  input [3:0] start_hu,  // Start hour units (0-9)
  input [3:0] start_mt,  // Start minute tens (0-5)
  input [3:0] start_mu,  // Start minute units (0-9)
  input [3:0] target_ht, // Target hour tens (0-2)
  input [3:0] target_hu, // Target hour units (0-9)
  input [3:0] target_mt, // Target minute tens (0-5)
  input [3:0] target_mu, // Target minute units (0-9)
  output [5:0] count     // Number of displayed times (N+1)
);

Behavior:
For each digit pair (ht, hu, mt, mu):
1. Compute increasing steps: (target - start + 10) % 10
2. Compute decreasing steps: (start - target + 10) % 10
3. Take minimum of both values
4. Sum minima from all four digits
5. count = sum + 1 (6-bit unsigned)
"Invalid" times are prevented by input constraints (e.g., hour tens ≤2).
