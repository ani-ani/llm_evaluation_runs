Design a Verilog module called 'min_blocked_points' that computes the minimum number of points Chubby Yang needs to block based on n.

Module interface:
module min_blocked_points(
  input [15:0] n,  // Input n (0 ≤ n ≤ 65535)
  output [19:0] result  // Minimum blocked points count
);

Behavioral description:
- The module uses fixed-point arithmetic in Q16.16 format to compute n × √2.
- √2 is approximated as 0x00016A0A in Q16.16 (decimal value ~1.4142).
- The result is calculated as (n * 0x16A0A) >> 16 to get the integer part multiplied by 4.
- Special case: if n==0, output 1. For n >=1, output 4*( (n * 92682) >> 16 ).
- Note: The multiplication uses 16-bit × 18-bit (0x16A0A is 18 bits) producing 34-bit product, take upper 18 bits after alignment.
- The module is purely combinational.
