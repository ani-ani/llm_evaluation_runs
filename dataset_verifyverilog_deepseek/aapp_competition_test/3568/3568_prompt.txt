Design a sequential Verilog module named 'floppy_organ_scheduler' that checks if musical intervals can be played without conflicts.

Module interface:
module floppy_organ_scheduler(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // start computation
  input [1:0] f, // number of frequencies (1-3)
  // Per-frequency parameters (max 3 frequencies)
  input [15:0] t_0, // period for freq 0
  input [1:0] n_0, // interval count for freq 0 (1-4)
  input [15:0] intervals_0 [0:7], // 4 intervals (8 time points)
  input [15:0] t_1, // period for freq 1
  input [1:0] n_1, // interval count for freq 1
  input [15:0] intervals_1 [0:7],
  input [15:0] t_2, // period for freq 2
  input [1:0] n_2, // interval count for freq 2
  input [15:0] intervals_2 [0:7],
  output reg possible, // 1=possible, 0=impossible
  output reg done // high when computation complete
);

Behavior:
1. On reset: possible=0, done=0, clear internal state
2. When start=1: Begin processing frequency intervals
3. For each frequency (1 to 3, based on f):
   a. Check if its intervals can be scheduled without conflicts given period t_i
   b. Consider floppy head movement mechanics (must reverse at endpoints, 1fs pause on direction change)
4. Set possible=1 only if ALL frequencies can be scheduled
5. Raises done=1 after maximum (10 + 20*f) clock cycles

Implementation note:
- Use a state machine with states: IDLE, CHECK_FREQ, CHECK_INTERVAL, VERIFY_PAUSE, DONE
- For interval checking: ensure pauses only occur between intervals, not within
- Consider movement constraints (sweep time between extremes = t_i floppyseconds)
- Intervals must be non-overlapping and strictly ascending order per frequency
