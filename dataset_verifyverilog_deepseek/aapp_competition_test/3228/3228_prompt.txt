Design a sequential Verilog module named 'gondola_scheduler' that calculates the minimum waiting time sum for skiers boarding gondolas.

Module interface:
module gondola_scheduler(
  input clk, // Main clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [2:0] n, // Number of skiers (1-8)
  input [4:0] t, // Uphill travel time (1-16 minutes)
  input [1:0] g, // Number of gondolas (1-3)
  input [4:0] skier_times [0:7], // Arrival times (0-31 minutes)
  output reg [8:0] sum, // Total waiting time (0-256)
  output reg done // High when computation completes
);

Behavioral description:
1. On reset: clear all internal registers and set state to IDLE
2. When start is asserted:
   a. Sort skier arrival times in ascending order
   b. Initialize gondola departure times to time -2*T (to indicate available)
   c. For each skier (in sorted order):
      i. Assign to the gondola with earliest possible departure
      ii. Wait time = max(0, departure_time - arrival_time)
   d. Accumulate total wait time
3. Departure times must follow:
   - Each gondola departs every 2*T minutes
   - First departure for gondola can align with arrival time
4. Implementation guidelines:
   - Use a 3-state FSM: IDLE, PROCESSING, DONE
   - Sorting implemented with simple 8-element bubble sort
   - Latency must be <=32 clock cycles
   - Use combinational logic for sort comparisons and allocation decisions.
5. Input constraints (guaranteed in testbench):
   - 0 <= skier_times[i] < skier_times[j] for i < j (after sorting)
   - Number of skiers n <= min(input_n, 8)
   - T clamps to exact input value (0-16 valid)
   - g clamps to exact input value (1-3 valid)
