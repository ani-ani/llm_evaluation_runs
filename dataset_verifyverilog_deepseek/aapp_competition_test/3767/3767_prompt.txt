Design a sequential Verilog module named 'soda_pouring' to compute the minimal number of bottles (k) and pouring time (t).

Inputs:
  input clk              // clock
  input rst_n            // active-low reset
  input start            // start computation
  input [2:0] n          // number of bottles (1-8)
  input [6:0] a [7:0]    // soda amounts (7-bit each, 8 bottles max)
  input [6:0] b [7:0]    // bottle volumes (7-bit each, 8 bottles max)

Outputs:
  output reg [3:0] k     // minimal bottles (4-bit: 1-8)
  output reg [9:0] t     // minimal time (10-bit: 0-800)
  output reg done        // high when computation complete

Behavior:
1. On reset, all outputs = 0
2. When start=1, computes k (min bottles) and t (min pour time) using dynamic programming
3. Latency: Output valid 10 clock cycles after start assertion
4. Implementation requirements:
   - Use RAM-based DP table (sums up to 800)
   - Utilize a state machine with: IDLE, COMPUTE, DONE
   - Bottle processing order doesn't affect optimal result

Constraints:
1. All soda must be preserved (a_i <= b_i always)
2. Target minimal bottles first, then minimal pour time
