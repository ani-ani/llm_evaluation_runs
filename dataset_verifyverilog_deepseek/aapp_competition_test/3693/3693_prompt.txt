Design a combinational Verilog module named "square_intersection" that checks if two squares intersect. The first square has sides parallel to coordinate axes, while the second is rotated 45 degrees.

Inputs:
input [7:0] square1 [0:7], // 8 vertices (x0,y0,x1,y1,...x3,y3) as 8-bit signed
input [7:0] square2 [0:7], // 8 vertices same format

Outputs:
output intersect // (1 = YES, 0 = NO)

Behavior:
1. For square1:
   - Find min_x1 = min(square1[0], square1[2], square1[4], square1[6])
   - Find max_x1 = max(same x-coords)
   - Find min_y1 = min(square1[1], square1[3], square1[5], square1[7])
   - Find max_y1 = max(same y-coords)
2. For square2:
   - Transform coordinates: For each vertex (x,y) compute u = x+y, v = x-y
   - Find min_u = min(u0,u1,u2,u3)
   - max_u = max(u values)
   - min_v = min(v values)
   - max_v = max(v values)
3. Squares intersect if these conditions are ALL true:
   a. square1_x_range overlaps with square2_rotated_range in original coordinates
   b. square1_y_range overlaps with square2_rotated_range in original coordinates
   c. There exists overlap between transformed coordinates

Implementation note: Use signed comparators and arithmetic units. All operations should be combinational with appropriate bit widths to prevent overflow.
