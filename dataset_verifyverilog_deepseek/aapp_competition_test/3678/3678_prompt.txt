Design a sequential Verilog module named 'loop_validator' that determines if a set of points forms a valid axis-aligned loop.
Module interface:
module loop_validator(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // start processing
  input [2:0] num_points, // number of points (1-8)
  input [15:0] x_in, // x-coordinate (signed 16-bit)
  input [15:0] y_in, // y-coordinate (signed 16-bit)
  input point_valid, // high when x_in/y_in are valid
  output reg valid_loop, // 1=YES, 0=NO
  output reg done // high when result is valid
);

Behavioral description:
1. The module should accept up to 8 points (as specified by num_points).
2. On start pulse, reset internal state and begin accepting points.
3. Load points when point_valid=1 (one per clock cycle).
4. After loading all points, begin validation:
   a. Check if all points have exactly two neighbors (one sharing same x, one same y, forming path segments)
   b. Verify all consecutive segments alternate between horizontal/vertical
   c. Confirm loop closes (first and last segment connect properly)
   d. Ensure no self-intersections (segments only meet at endpoints)
5. Small coordinate values may be identical after scaling - use exact storage.
6. Output valid_loop and done 10 + 2*num_points cycles after start 
7. Use state machine with states: IDLE, LOADING, PROCESSING, DONE
