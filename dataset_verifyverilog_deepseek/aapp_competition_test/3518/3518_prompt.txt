Design a sequential Verilog module named 'min_co2_matcher' that finds minimum CO2 pairing for 8 students.
Inputs:
input clk, // clock
input rst_n, // active-low reset
input start, // start computation
input [2:0] n, // number of students (3-bit, max 8)
input [2:0] m, // number of edges (3-bit, max 28)
input [2:0] p [0:27], // edge start nodes (3-bit each)
input [2:0] q [0:27], // edge end nodes (3-bit each)
input [13:0] c [0:27] // edge CO2 values (14-bit each, max 16383)
Outputs:
output reg [15:0] min_co2, // minimum total CO2 (16-bit)
output reg impossible, // high if no valid pairing exists
output reg done // high when computation complete

Behavior:
1. On reset: Clear all internal registers
2. When start=1:
   a. Build adjacency matrix from input edges (8x8 matrix, 14-bit CO2 values)
   b. Verify friendship cliques (should be complete subgraphs)
   c. Compute minimum weight perfect matching for n students
   d. Set impossible=1 if n is odd or no perfect matching exists
   e. Output result after computation completes
3. Timing: Computation finishes within 1000 clock cycles max
4. Storage: Use internal registers for adjacency matrix (8x8 entries of 14-bit values)
5. Algorithm: Use iterative state machine to generate pairings and calculate sums

Edge Cases:
- n=0: impossible=1
- n odd: impossible=1
- Disconnected cliques that prevent pairing

Note: All students are friends within their clique (transitive friendship implied by input)
