Design a sequential Verilog module named 'rectangle_intersect' that checks if any two rectangles in a set of up to 8 rectangles intersect.
Module interface:
module rectangle_intersect(
  input clk, // clock signal
  input rst_n, // active-low reset
  input load, // load rectangle data (asserted for 1 cycle per rectangle)
  input start, // begin checking (pulse high for 1 cycle)
  // Rectangle coordinates (16-bit signed): 
  input [15:0] x1, // lower left x
  input [15:0] y1, // lower left y
  input [15:0] x2, // upper right x (must > x1)
  input [15:0] y2, // upper right y (must > y1)
  output reg result, // 1 if any intersect, 0 otherwise
  output reg done // high when computation complete
);

Behavior:
1. On reset (rst_n=0), clear all stored rectangles.
2. When load=1, store the rectangle {x1,y1,x2,y2}. Max 8 rectangles stored.
3. When start pulses high (1 cycle):
   a. Begin pairwise comparison of stored rectangles
   b. Each clock cycle compares one pair (i,j) where i<j
   c. If any pair overlaps (boundary intersection only, not nesting), set result=1 and done=1
   d. If all pairs checked with no overlap, set result=0 and done=1
4. Computation completes when done=1. Maintain result until next start pulse.

Timing:
- Requires 1-28 cycles to complete after start (28 = maximum pairs for 8 rectangles)
- Rectangle coordinates must remain stable during operation

Notes:
Two rectangles (r1 and r2) DO NOT intersect if:
r1.x2 <= r2.x1 OR r2.x2 <= r1.x1 OR
r1.y2 <= r2.y1 OR r2.y2 <= r1.y1
Otherwise, they intersect.
