Design a combinational Verilog module named 'returnable_rooms_counter' that counts returnable rooms in an 8-room circular conveyor system.
Inputs:
input [15:0] belt_states // 8 rooms * 2 bits (00: '-', 01: '>', 10: '<')
Output:
output [3:0] count // Number of returnable rooms (0-8)
Behavior:
1. If all belt states are '>' (01) or all are '<' (10), count = 8
2. Else, room i is returnable if belt[i] is '-' (00) OR belt[(i-1) mod 8] is '-'.
3. Count all returnable rooms.
All comparisons should be combinational logic with the belt_states input.
