Design a combinational Verilog module named 'bitstring_subsequence' that finds a bit string (up to 8 bits) with specified subsequence counts.
Inputs:
   input [3:0] a,  // '00' subsequence count
   input [3:0] b,  // '01' count
   input [3:0] c,  // '10' count
   input [3:0] d;  // '11' count
Outputs:
   output reg [7:0] string_out,  // left-aligned, MSB first, pad with 0
   output reg impossible;        // high if no solution exists

Behavior:
1. Find n0 where n0*(n0-1)/2 == a (allow n0:0-6). Similarly n1 from d.
2. If n0 or n1 invalid or (n0+n1 > 8), set impossible=1.
3. Else, check if (b + c) == n0*n1. If not, set impossible=1.
4. Else:
   - If b == n0*n1 and c==0: create '0'*n0 + '1'*n1
   - Else if c == n0*n1 and b==0: create '1'*n1 + '0'*n0
   - Else impossible=1
5. Pack bits into string_out[7:0] (MSB first), padding with 0s.
6. Output impossible=0 for valid cases.
