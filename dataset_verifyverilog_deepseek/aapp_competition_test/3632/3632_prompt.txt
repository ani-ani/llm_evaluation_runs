Design a Verilog module named 'composite_string_position' that computes the 1-indexed position of a test composite string in lexicographically sorted permutations list. Module is sequential with start/done handshaking.

Module interface:
module composite_string_position(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // initiate computation
  input [2:0] n, // number of initial strings (1-8)
  input [1:0] k, // number of concatenations (1-4)
  input [7:0][31:0] sorted_strings, // alphabetically sorted strings (unused)
  input [3:0][2:0] test_indices, // k indices for test composite (MSB first)
  output reg [15:0] position, // 1-based output position
  output reg done // high when result valid
);

Behavior:
- Implements permutation rank calculation in k clock cycles
- Uses 8-bit used_mask to track selected indices
- Precomputes Permutation(a,b) = a!/(a-b)! via lookup tables
- Position = (Σ(count * Permutation(n-i-1, k-i-1)) for i=0 to k-1) + 1
- Start pulse initiates computation, done asserted k cycles later
- Reset clears all registers and outputs

Timing:
- Latency: k clock cycles from start assertion
- Inputs must remain stable during computation
- Output valid when done=1 until next reset

Implementation note:
- Permutation table stored as 8x1 ROM with values for (a,b) pairs
- Max output value 40320 (8P4) fits in 16 bits.
