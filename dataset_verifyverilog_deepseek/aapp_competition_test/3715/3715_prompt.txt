Design a Verilog module named 'vacation_rest_counter' that calculates the minimum rest days for Vasya.
Module interface:
module vacation_rest_counter(
  input clk, // Clock input
  input rst_n, // Active-low reset
  input start, // Start computation
  input [4:0] num_days, // Number of days (1-16)
  input [1:0] day_status [0:15], // Day status array (2-bit values)
  output reg [4:0] rest_count, // Minimum rest count
  output reg done // High when computation completes
);

Behavior:
- Implements a state machine to process each day sequentially
- Uses state registers to track previous activity (00:rest, 01:contest, 10:sport)
- Processes one day per clock cycle after start is asserted
- Outputs valid rest_count 16 cycles after start with done flag set
- Resets outputs to zero on active-low reset
State encoding:
- IDLE: Wait for start signal
- PROCESS: Compute rest days sequentially
- DONE: Assert done flag
Timing:
- 16 clock cycle latency maximum
- Assert 'start' for at least 1 cycle to begin
