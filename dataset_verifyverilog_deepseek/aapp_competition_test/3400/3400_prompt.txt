Design a sequential Verilog module named 'rabbit_pathfinder' that computes the shortest real travel time from location A to R using scaled-down trip data.

Module interface:
module rabbit_pathfinder(
  input clk, // Clock signal
  input rst_n, // Active-low reset
  input start, // Start computation
  // Configuration inputs (fixed for N=4 nodes, T=3 trips, max_p=4 locations per trip)
  input [1:0] alice_node, // Alice's location (2 bits for 4 nodes)
  input [1:0] hole_node, // Rabbit hole location (2 bits)
  // Trip data inputs (3 trips total)
  input [3:0] trip1_d, input [1:0] trip1_p, input [1:0] trip1_seq [0:3], // First trip data
  input [3:0] trip2_d, input [1:0] trip2_p, input [1:0] trip2_seq [0:3], // Second trip
  input [3:0] trip3_d, input [1:0] trip3_p, input [1:0] trip3_seq [0:3], // Third trip
  output reg [7:0] shortest_time, // Shortest path time (8-bit max 255)
  output reg done // High when computation complete
);

Behavioral description:
1. On reset, clear all internal states.
2. When start=1:
   a. Deduce real edge times from trip logs (solving mod 12 constraints)
   b. Build adjacency matrix (4x4) with real travel times
   c. Implement simplified Dijkstra's algorithm for 4 nodes
   d. Output shortest path time when complete
3. Timing: Output valid 20 clock cycles after start asserted.
4. Assumptions: Nodes (0-3), input data consistent & solvable.
5. Fixed-point representation: Real times stored as 8-bit integers, edge weights calculated as multiple of 12 + d when needed.
