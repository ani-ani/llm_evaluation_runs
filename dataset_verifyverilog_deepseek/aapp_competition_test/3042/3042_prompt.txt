Design a Verilog module named 'lcm_tree_counter' that computes the number of valid LCM tree arrangements modulo 1_000_000_007.

Inputs:
input clk, // clock signal
input rst_n, // active-low reset
input start, // pulse high to start computation
input [31:0] node_values [0:15], // 16-node maximum (16x32 array)
input [4:0] num_nodes // actual number of nodes (1-16)

Outputs:
output reg [29:0] result, // result count mod 1e9+7 (30 bits)
output reg done // high when computation complete

Behavior:
1. On reset or power-up, initialize all registers.
2. When start is pulsed high:
   - Load node values into internal memory
   - Begin combinatorial arrangement count process
3. Compute using 3 main phases:
   - Phase 1: Identify possible parent nodes by verifying LCM(child1, child2) == parent
   - Phase 2: Calculate arrangement permutations accounting for duplicate values
   - Phase 3: Apply modulo 1_000_000_007 operation
4. Result should appear 100 clock cycles after start assertion (worst-case latency).
5. Done signal goes high when result is valid.

Implementation notes:
- Use a state machine with states: IDLE, CHECK_PAIRS, CALC_PERMS, MOD_OUTPUT, DONE
- Precompute GCD using Euclidean algorithm in combinational logic
- LCM(a,b) = (a * b) / GCD(a,b) - use modular inverse for division under mod
- Handle duplicate values by dividing by factorial(counts) in final permutation count
