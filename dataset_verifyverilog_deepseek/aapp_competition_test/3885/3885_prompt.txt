Design a combinational Verilog module named 'min_cost_tickets' that calculates the minimum ticket cost based on optimized formula.

Module interface:
module min_cost_tickets(
  input [15:0] n,  // Number of schools (1 ≤ n ≤ 65535)
  output [14:0] min_cost  // Minimum cost = (n-1)/2 (integer division)
);

Behavioral description:
The module should compute min_cost = (n - 1) >> 1 (arithmetic right shift equivalent to floor division). Output must be purely combinational with no clock or reset signals required.
