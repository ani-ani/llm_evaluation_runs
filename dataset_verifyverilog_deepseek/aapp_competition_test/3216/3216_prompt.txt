Design a sequential Verilog module named 'repeating_decimal_to_fraction' that converts a repeating decimal to its reduced fraction form.

Inputs:
input clk,            // clock signal
input rst_n,          // active-low reset
input start,          // pulse high to start computation
input [9:0] integer_part,   // integer portion (0-999, 10 bits)
input [13:0] non_rep_frac,  // non-repeating fractional digits (4 digits max, 14 bits)
input [13:0] rep_frac,      // repeating fractional digits (4 digits max, 14 bits)
input [3:0] repeat_count    // number of repeating digits (1-4, 4 bits)

Outputs:
output reg [26:0] numerator,    // 27-bit simplified numerator
output reg [26:0] denominator,  // 27-bit simplified denominator
output reg done                  // high when computation complete

Behavior:
1. On start pulse: compute denominator = (10^(non_rep_digits + repeat_count) - 10^(non_rep_digits))
2. Numerator calculated as: (int*10^(nv+rpt) + non_rep*10^rpt + rep) - (int*10^nv + non_rep)
   where nv = number of non-repeating fractional digits (calculated from input)
3. Apply Euclidean algorithm to compute GCD
4. Clock cycles: Latency ≤ 60 cycles (50 cycles GCD worst-case + fixed 10 cycles arithmetic)

States:
IDLE, CALC_DENOM, CALC_NUM, GCD_CALC, DIVIDE, DONE
Powers of 10 (1-10^8) stored in 27-bit lookup table with 4-bit index.
Assume non-repeating digit count = total fractional digits - repeat_count.
