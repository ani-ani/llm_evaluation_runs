Design a sequential Verilog module named 'max_zebra_length' that finds the maximum zebra streak length in a string of up to 16 characters (each character represented as 'b' or 'w'). The module uses a state machine with two passes: forward processing to find streaks and backward processing to check end streaks when applicable.

Module interface:
module max_zebra_length(
  input clk,                  // Clock signal
  input rst_n,                // Active-low reset
  input start,                // Start processing signal
  input [15:0] data_in,       // String bits (0='b', 1='w')
  input [3:0] data_len,        // Actual string length (1-16)
  output reg [4:0] max_streak,// Maximum streak length (1-16)
  output reg done              // High when computation complete
);

Behavior:
- Sequential operation with 4 states: IDLE, PROCESS_FORWARD, PROCESS_BACKWARD, COMPLETE
- On start: Initializes all counters and registers
- Forward pass: Processes string from start to end tracking current streak, max streak, and initial streak
- Backward pass: Processes string from end to start tracking ending streak (if first/last characters differ)
- Final result is max(forward max_streak, initial_streak + ending_streak) capped at data_len
- Latency: Worst-case 32 cycles (16 forward + 16 backward)
- Output 'done' asserted when result ready with final result in max_streak
- Use synchronous active-low reset for all registers
