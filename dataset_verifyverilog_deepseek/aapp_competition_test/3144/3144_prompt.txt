Design a sequential Verilog module named 'coin_game_solver' that calculates the maximum guaranteed coins Donald can have.
Inputs:
   input clk,               // clock signal
   input rst_n,             // active-low reset
   input start,             // start computation
   input [3:0] d_init,      // Donald's initial coins (1-15)
   input [3:0] g_init,      // Gladstone's initial coins (1-15)
   input [2:0] n_rounds,    // total rounds (1-8)
   input [2:0] k_distracted // distracted rounds (0-8)

Outputs:
   output reg [3:0] m_coins, // maximum coins Donald can have
   output reg done          // high when computation complete

Behavior:
The module should implement a state machine that simulates game rounds. Each distracted round:
- Donald bets min(d_current, g_current) coins and wins them
Each non-distracted round:
- Donald bets 1 coin and loses it
The computation takes 8 cycles plus 2 cycles for reset latency.

State machine sequence:
1. RESET: Initialize variables
2. IDLE: Wait for start signal
3. PROCESS: Iterate through n_rounds
4. DONE: Output result and assert done
