Design a sequential Verilog module named 'minimal_convex_hull_vertices' that finds the smallest subset of convex polygon vertices containing all given internal points.

Module interface:
module minimal_convex_hull_vertices(
  input clk,  // clock
  input rst_n,  // active-low reset
  input start,  // start computation
  // Polygon vertices (max 8 vertices, 16-bit signed coordinates)
  input [15:0] vx[0:7],  // x-coordinates
  input [15:0] vy[0:7],  // y-coordinates
  input [2:0] vertex_count,  // actual vertex count (3-8)
  // Internal points (max 4 points)
  input [15:0] px[0:3],  // x-coordinates
  input [15:0] py[0:3],  // y-coordinates
  input [1:0] point_count,  // actual point count (1-4)
  // Outputs
  output reg [2:0] min_vertices,  // minimal vertex count (3-8)
  output reg done  // high when computation complete
);

Behavioral description:
- At start signal, begins searching for minimal subset of polygon vertices
  that forms a convex hull containing all internal points
- Implements a state machine that iterates over possible subset sizes
- For each subset size, tests all combinations containing all points
- Utilizes parallel edge testing: checks if all points are inside the polygon
  formed by evaluating the sign of cross products with each edge
- Reports the minimal vertex count where a valid subset is found (3-8)
- Latency: Requires up to (vertex_count - 2)*100 cycles to complete
- Supports up to 8 polygon vertices and 4 internal points with 16-bit coordinates
- Uses active-low asynchronous reset to initialize state
