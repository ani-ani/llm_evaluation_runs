Design a sequential Verilog module named 'beautiful_number' that finds the smallest beautiful integer y >= x with pattern b[i] = b[i%k].
Inputs:
  input clk,                   // Clock
  input rst_n,                 // Active-low reset
  input start,                 // Start computation
  input [2:0] n,               // Number of digits (3-8, 3 bits)
  input [2:0] k,               // Period (1 <= k < n, 3 bits)
  input [3:0] digits [0:7],    // Input digits (8x4-bit array)
Outputs:
  output reg [3:0] y_digits [0:7], // Output digits (8x4-bit array)
  output reg done              // High when computation complete

Behavior:
1. On reset: Clear all registers and set done=0
2. When start asserted:
   a. Generate initial pattern: replicate first k digits through n positions
   b. Compare with original digits:
      - If replicated pattern >= original, output it
      - Else increment first k digits as a number and generate new pattern
3. State machine steps:
   - STATE_LOAD: Load input digits into registers (1 cycle)
   - STATE_COMPARE: Compare original versus first patterned digits (2 cycles)
   - STATE_INCREMENT: If needed, increment k-digit prefix (2 cycles)
   - STATE_GENERATE: Generate final beautiful number (1 cycle)
4. Total latency: 6 cycles after start asserted
5. Output valid when done=1
