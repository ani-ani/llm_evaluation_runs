Design a combinational Verilog module named 'monotone_sequence' that determines a valid permutation sequence or returns -1.
Inputs:
  input [2:0] n,  // Sequence length (1-5)
  input [2:0] k   // Target longest monotone subsequence (1-5)
Output:
  output [14:0] seq // Packed 5x3-bit results (each 3-bit represents number, or all 1s for -1)

Behavior:
- Output consists of five 3-bit fields: seq[14:12], seq[11:9], seq[8:6], seq[5:3], seq[2:0]
- When valid sequence exists: fill first 'n' fields with permutation, pad remainder with zeros
- For invalid cases: set all 15 bits to 1
- Precomputed mappings: (4,3)->1,4,2,3; (5,5)->1,2,3,4,5; (5,1)->invalid/all_ones
- Undefined (n,k) pairs default to all_ones output
