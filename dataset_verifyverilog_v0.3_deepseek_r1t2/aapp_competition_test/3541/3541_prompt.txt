Implement a combinational module that solves the candy splitting problem for N=4 candies.

Problem: Given N candies, each with two values (a_i for Alf, b_i for Beata), assign each candy to A or B to minimize |sum(A) - sum(B)|. If multiple solutions exist, output lexicographically smallest.

Constraints:
- N = 4
- Values a_i, b_i are signed in range [-2, 2] (3-bit signed)
- Output: 4-bit assignment where bit i=1 means candy i goes to Alf, bit i=0 means candy i goes to Beata
- The module must be combinational (no clock)

Interface:
module CandySplitter #(
    parameter N = 4,
    parameter VAL_BITS = 3
)(
    input wire signed [VAL_BITS-1:0] a_0, a_1, a_2, a_3,
    input wire signed [VAL_BITS-1:0] b_0, b_1, b_2, b_3,
    output wire [N-1:0] assignment
);

Implementation:
- Enumerate all 2^N = 16 possible assignments
- For each assignment, compute diff = |sum_{i in A} a_i - sum_{i in B} b_i|
- Keep track of assignment with minimum diff
- If ties, choose assignment with maximum binary value (lexicographically smallest)
- Output the best assignment
