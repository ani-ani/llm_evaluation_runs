Module: greedy_tower

Inputs:
  - clk: Clock signal (rising edge)
  - rst_n: Active-low reset
  - start: Start signal (pulse to begin computation)
  - m[19:0]: Input value m (20-bit, 0 to 1,000,000)

Outputs:
  - blocks[4:0]: Maximum number of blocks (5-bit, 0-18)
  - volume[19:0]: Maximum X value (20-bit)
  - done: Completion signal (high for 1 cycle when result is valid)

Parameters:
  - MAX_DEPTH = 18: Maximum recursion depth
  - DATA_WIDTH = 20: Bit width for volume calculations

Behavior:
1. On start pulse, begins computation using iterative DFS
2. Computes cube root via iterative search (0-100)
3. Explores two paths at each step:
   - Path A: Use largest block a, recurse on m - a³
   - Path B: Use block a-1, recurse on (a³ - 1 - (a-1)³) = 3a² - 3a + 1
4. Tracks best (blocks, volume) globally
5. Uses stack-based traversal to avoid recursion
6. Completes within 1000 cycles for worst-case m

Implementation details:
- Use 36-bit arithmetic for volume (to handle a³ up to 100³=1,000,000)
- Cube root computed via binary search
- Stack depth limited to MAX_DEPTH
- State machine for controlling search flow
