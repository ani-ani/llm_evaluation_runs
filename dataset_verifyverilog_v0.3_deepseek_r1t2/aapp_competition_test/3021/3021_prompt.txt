Module: AlphabetSolver
Parameters:
  ALPHABET_SIZE = 5 (number of letters from 'a' to 'e')
  MAX_WORDS = 4
  MAX_WORD_LEN = 8

Inputs:
  clk: 1-bit clock
  rst_n: 1-bit active-low reset
  start: 1-bit start pulse
  N: 4-bit number of valid words (1 to MAX_WORDS)
  words: 3D array [0:MAX_WORDS-1][0:MAX_WORD_LEN-1][7:0] of ASCII characters
  word_lengths: 2D array [0:MAX_WORDS-1][3:0] of actual word lengths

Outputs:
  result_order: 2D array [0:ALPHABET_SIZE-1][7:0] containing ordered alphabet when unique
  status: 2-bit output (00=IMPOSSIBLE, 01=AMBIGUOUS, 10=UNIQUE)
  done: 1-bit asserted when computation completes

Internal Requirements:
- Map characters to indices 0..(ALPHABET_SIZE-1) by subtracting 'a'
- Use adjacency matrix edge_matrix[ALPHABET_SIZE][ALPHABET_SIZE] where edge_matrix[i][j]=1 means i must precede j
- Use in-degree count array for topological sort
- Implement state machine with states: IDLE, CHECK_PREFIX, FIND_DIFF, ADD_EDGE, TOPO_INIT, TOPO_LOOP, DONE
- Constraint extraction: For each adjacent word pair i and i+1:
  * Find first differing position j
  * If one word is prefix of other, verify shorter comes first else IMPOSSIBLE
  * Else add edge from char1 to char2
- Topological sort using Kahn's algorithm:
  * Compute in-degrees
  * While nodes with in-degree >0 exist:
    - Count nodes with in-degree 0
    - If count==0: cycle detected -> IMPOSSIBLE
    - If count>1: AMBIGUOUS
    - Select node (choose smallest index for determinism), remove it, decrement neighbors' in-degrees
  * If completed without ambiguity and cycle, output order and status=UNIQUE
- All registers must be reset properly
- Operation must complete within 1000 clock cycles

Implementation Notes:
- Character comparison: words[i][j] vs words[i+1][j]
- Edge addition: set bit in edge_matrix[src][dst]
- In-degree calculation: count incoming edges for each node
- Uniqueness check: during topological sort, if multiple nodes with in-degree 0 at any step, set AMBIGUOUS
- Output order array should contain ASCII characters in the correct order
