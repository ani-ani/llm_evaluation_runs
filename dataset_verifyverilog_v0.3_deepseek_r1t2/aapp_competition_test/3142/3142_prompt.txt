Implement a Verilog module that counts numbers in [A,B] with digit sum S and finds the smallest such number. The inputs are 8-digit numbers (each digit 4 bits, packed in 32 bits) and S (7 bits). The outputs are count (16 bits) and smallest number (32 bits packed). Use a state machine to coordinate digit DP operations.

MODULE SPECIFICATION:

Module top:
  Inputs:
    clk         : Clock
    rst_n       : Active-low reset
    start       : Start signal
    A[31:0]     : Lower bound (8 digits, 4 bits each, packed)
    B[31:0]     : Upper bound (8 digits, 4 bits each, packed)
    S[6:0]      : Target digit sum
  Outputs:
    count[15:0] : Number of valid numbers in [A,B]
    candidate[31:0]: Smallest valid number (packed)
    done        : Computation complete

Implementation details:
  1. Use digit DP with state: (position, tight_lower, tight_upper, sum)
  2. State machine processes digits from MSB to LSB
  3. Use lookup tables for DP states
  4. For smallest number, use greedy construction with DP validation
  5. Handle A-1 subtraction for count_in_range
  6. Maximum 8 digits, sum up to 72

Timing:
  - Assert start for 1 clock cycle
  - done goes high when computation completes (within 10,000 cycles)
  - Sample count and candidate when done is high

Reset behavior:
  - On rst_n=0: all state cleared, outputs zero
  - Minimum 2 clock cycles of reset required
