Design a Verilog module that counts Sheldon numbers in a given range [X, Y]. A Sheldon number has binary pattern (AB)^k A or (AB)^k, where A is N ones (N>0) and B is M zeros (M>0). Since original numbers can be huge (up to 2^63), we'll scale down to 16-bit numbers (max 65535) for HDL implementation. The module should:

1. Inputs:
   - clk, rst_n: Standard clock and active-low reset
   - start: Start signal to begin computation
   - x[15:0], y[15:0]: 16-bit range boundaries (X ≤ Y)

2. Outputs:
   - count[15:0]: Number of Sheldon numbers in [X, Y]
   - done: Asserted when computation completes

3. Implementation approach:
   - Generate all possible Sheldon numbers up to 65535 and store in a lookup table (ROM)
   - Use a simple state machine to iterate through table and count matches
   - Fixed-size table with 200 entries (covers all possible 16-bit Sheldon numbers)
   - Since 200 is small, we can unroll the comparison logic

4. Timing:
   - Computation completes within 200 clock cycles
   - Reset clears all internal state

5. Module name: sheldon_counter

Provide complete Verilog implementation with comments.
