Design a Verilog module for the scaled SDS problem. The module should be a sequential circuit with clock and active-low reset. Inputs: r (8-bit), m (8-bit), start, clk, rst_n. Outputs: n (8-bit), found, done. Parameters: MAX_N=64, MAX_M=256, VAL_WIDTH=16. Implement state machine with states: IDLE, FIND_D, SEARCH_D, COMPUTE_A, UPDATE_VALUE, UPDATE_DIFF_INIT, UPDATE_DIFF, CHECK, DONE. In IDLE, initialize on start: sequence = {r}, seen[r]=1, n=1. If r==m, go to DONE with found=1. In FIND_D, search for smallest missing integer (1..MAX_M) not in seen, set d. In COMPUTE_A, compute new_A = prev_A + d. In UPDATE_VALUE, store new_A, increment n, mark seen[new_A], if new_A==m go to DONE. In UPDATE_DIFF_INIT, set i=0. In UPDATE_DIFF, compute diff = new_A - A_vals[i]; if diff<=MAX_M, mark seen[diff]; if diff==m go to DONE; increment i; if i < n-1 repeat, else go to CHECK. In CHECK, if seen[m]==1, go to DONE with found=1; else if n < MAX_N, set prev_A = new_A and go to FIND_D; else go to DONE with found=0. In DONE, pulse done=1 for one cycle then return to IDLE. Provide complete Verilog code.
