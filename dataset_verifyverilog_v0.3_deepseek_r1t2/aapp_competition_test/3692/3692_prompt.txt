Design a Verilog module that computes the number of regions formed by up to 3 circles on a plane. The module should handle n=1,2,3 circles with integer coordinates in [-10,10] and radii in [1,10].

Interface Specification:

Inputs:
  - n: 2-bit unsigned (01,10,11 for 1,2,3 circles)
  - x1, y1, r1: 8-bit signed integers for first circle
  - x2, y2, r2: 8-bit signed integers for second circle (unused if n=1)
  - x3, y3, r3: 8-bit signed integers for third circle (unused if n<3)

Outputs:
  - result: 8-bit unsigned integer (number of regions)

Behavior:
  - For n=1: output 2
  - For n=2: compute distance between centers and compare with radii sum/difference
  - For n=3: compute pairwise intersection types using integer arithmetic and apply case analysis

Use only integer arithmetic and combinational logic. The module should be combinational (no clock/reset).
