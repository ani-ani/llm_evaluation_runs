MODULE SPECIFICATION:

Design a sequential module that computes possible digits d in base k that can be formed using unlimited banknotes of given denominations.

INPUTS:
  - clk: Clock signal
  - rst_n: Active-low reset
  - start: Start computation pulse (1 cycle)
  - n: Number of denominations (4-bit, max 8)
  - denominations: Array of 8 banknote values, each 16-bit
  - k: Base of number system (5-bit, max 32)

OUTPUTS:
  - count: Number of possible d values (5-bit)
  - remainders: Array of up to 32 possible d values, each 5-bit
  - done: Asserted when computation completes

BEHAVIOR:
1. On start, compute g = gcd(denominations[0..n-1], k)
2. Generate set: { (i * g) % k for i = 0 to (k/g - 1) }
3. Output count = k/g and the set in increasing order

TIMING:
- Computation completes within 1000 cycles
- Results available when done=1
- Module resets on rst_n=0

CONSTRAINTS:
- n ≤ 8
- k ≤ 32
- denominations ≤ 65535
- remainders array size = 32
