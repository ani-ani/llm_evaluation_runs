Verilog module for finding maximum subrectangle area with sum constraint.

**Module Name**: find_max_area

**Interface**:
- Inputs:
  - clk: clock signal (rising edge)
  - rst_n: active-low synchronous reset
  - start: start pulse (assert for 1 cycle to begin computation)
  - n, m: 4-bit unsigned, actual sizes of arrays (1-8)
  - a: 8-element array of 8-bit unsigned integers (indexed 0-7)
  - b: 8-element array of 8-bit unsigned integers (indexed 0-7)
  - x: 32-bit unsigned threshold
- Outputs:
  - result: 16-bit unsigned maximum area
  - done: asserted high for 1 cycle when result is valid

**Functionality**:
The module computes the maximum area (L1 * L2) such that there exists a contiguous segment of rows of length L1 and columns of length L2 where (sum of segment in a) * (sum of segment in b) <= x.

**Internal Implementation**:
1. Uses a state machine with states: IDLE, INIT, PREFIX_A, MIN_ROW, PREFIX_B, MIN_COL, MAX_AREA, DONE.
2. Computes prefix sums of a and b.
3. For each possible length L (1 to n/m), computes the minimum segment sum of that length.
4. Then iterates over all pairs of lengths (L1, L2) to find the maximum area where min_row[L1] * min_col[L2] <= x.
5. All computations are sequential to fit within small area.

**Timing**:
- Assert start for 1 clock cycle.
- Computation takes up to ~100 cycles.
- Result is available when done is high.
- Reset clears all internal state.

**Constraints**:
- n, m <= 8
- a[i], b[i] <= 255
- x <= 2^32-1
- Result <= 64 (8*8)
