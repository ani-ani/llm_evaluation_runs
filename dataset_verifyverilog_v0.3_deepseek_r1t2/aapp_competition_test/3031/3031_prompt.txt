Module: find_good_nodes

Description: Identifies all good nodes in a tree where every simple path from the node is rainbow (adjacent edges have different colors). Scaled to max 8 nodes.

Interface:
  Inputs:
    - clk: Clock signal
    - rst_n: Active-low reset
    - start: Start pulse (1 cycle)
    - n[3:0]: Number of nodes (1-8)
    - edge_data[0:55]: Packed edge data (7 edges * 8 bits: 4 bits node_a, 4 bits node_b)
    - edge_colors[0:6]: Colors for each edge (7 edges, 4 bits each)
    - valid_edges[2:0]: Number of valid edges (0-7)
  
  Outputs:
    - good_nodes[0:7]: Array of good node indices (0-7, sorted)
    - count[3:0]: Number of good nodes
    - done: Computation complete

  Timing:
    - Assert start for 1 clock cycle
    - done goes high when all nodes are checked (within 1000 cycles)
    - good_nodes and count are valid when done is high

  Implementation:
    - Use adjacency matrix (8x8) to store graph
    - For each node, perform BFS to check if all paths are rainbow
    - Track parent and last_color for each node during traversal
    - Check condition: color(parent->current) != color(current->child)
    - Collect good nodes in sorted order
    - Use state machine with states: IDLE, BUILD_GRAPH, CHECK_NODE, BFS, NEXT_NODE, COMPLETE
