Design a combinational Verilog module named 'digit_sum_counter' that counts numbers in range [A,B] with digit sum S and finds the smallest such number.

Inputs:
input [5:0] A_digits // 6 BCD digits for A (4 bits each)
input [5:0] B_digits // 6 BCD digits for B (4 bits each)
input [5:0] S_value // digit sum target (0-54)

Outputs:
output [17:0] count // number of matching integers
output [23:0] min_number // smallest matching number (6 BCD digits, 4 bits each)

The module works with 6-digit decimal numbers (0-999999) represented as BCD. A_digits and B_digits are packed: each 4-bit segment holds one decimal digit. For example, number 123456 = 0x123456 in BCD.

Algorithm:
1. Iterate through all numbers from A to B (combinational loop)
2. For each number, calculate digit sum by extracting each 4-bit BCD digit
3. If digit sum equals S_value, increment count and compare for minimum
4. Minimum tracking: use parallel comparators for each candidate number

Constraints:
- Max range size: 1,000,000 numbers (requires unrolling or implicit iteration)
- Since full combinational implementation would be too large, implement a 6-stage pipeline where each stage processes one decimal digit position
- Use a 20-bit loop counter (log2(10^6) = 20 bits)

For hardware efficiency, implement as follows:
- Use 18-bit counter for count (max 999999)
- Use 24-bit register for min_number (6 digits × 4 bits)
- Implement digit extraction using shift operations
- Use case statements for digit-to-sum calculation

The module should compute results combinationally without clock, but may use internal loops with defined iteration bounds.
