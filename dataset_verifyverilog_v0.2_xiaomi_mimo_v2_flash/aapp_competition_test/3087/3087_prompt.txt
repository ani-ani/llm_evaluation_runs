Design a sequential Verilog module named 'dance_arrows' that implements permutation K-th root calculation.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [3:0] N // number of dancers (1-16)
input [31:0] K // number of moves (1-256)
input [4:0] a [0:15] // permutation after K moves

Outputs:
output reg [4:0] result [0:15] // arrow mapping f[i]
output reg done // high when computation complete
output reg impossible // high if no valid solution

Specify latency: 100 clock cycles after start asserted.
Use state machine with states: IDLE, LOAD, FIND_CYCLES, COMPUTE_ROOT, VERIFY, DONE.

Algorithm:
1. Parse permutation a into disjoint cycles
2. For each cycle, compute K-th root:
   - Let cycle length = L
   - If gcd(K, L) > 1, need to split into gcd(K,L) cycles
   - Each element maps to element (K mod L) positions ahead
3. Build result permutation f
4. Verify f^K = a

Edge cases:
- K=1: f = a
- Self-mapping: if a[i] = i, then impossible
- Use lookup for gcd with small numbers

Implementation:
- Use 16-element arrays for all permutations
- Store cycles as temporary arrays
- Compute K mod L using repeated subtraction
- For splitting: when gcd(K,L)=d, create d cycles of length L/d

Fixed-size implementation for N≤16.
