Design a sequential Verilog module named 'minimal_unique_substring_gen' that generates a binary string of length n such that the length of its minimal unique substring is k.

The input n and k satisfy (n mod 2) == (k mod 2).
The construction rule is:
1. Calculate spacing = (n - k) / 2.
2. Generate a repeating pattern of '0' * (spacing - 1) + '1' if spacing > 0.
3. If n == k, output '1' * n.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start generation
input [15:0] n // Length of the string to generate (max 100000)
input [15:0] k // Target minimal unique substring length

Outputs:
output reg out_bit // The generated bit
output reg done // High when n bits have been generated

Behavior:
The module should use a counter to track the number of bits generated (0 to n-1).
For each bit, it should determine if the bit is '1' or '0' based on the current counter value and the calculated spacing.
Use a state machine: IDLE, GENERATING, FINISHED.
Latency: Result valid 1 clock cycle after processing each bit, done goes high after n cycles.
