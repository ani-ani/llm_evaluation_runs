Design a sequential Verilog module named 'spell_optimizer' that implements a simplified spell optimization algorithm.

The problem scales down to:
- M (number of steps) = 8 maximum
- S (strength) = 3 maximum (so power is tracked modulo 2^3 = 8, i.e., 3-bit numbers)
- Input: 8-character string of '+' and 'x' operations
- Goal: Find which positions to replace with 'o' (no-op) to maximize final power (mod 8)

Algorithm (iterative for small M):
Since M is small (8), we can iterate through all 2^8 = 256 possible subsets of steps to keep. For each combination:
- Start with power = 1
- For each of 8 steps:
  - If step is kept (not 'o'):
    - If '+': power = (power + 1) mod 8
    - If 'x': power = (power * 2) mod 8
n- Record max power and the combination that achieves it

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [7:0] step_types // 8-bit vector, bit i = 1 if step i is 'x', 0 if '+' (from original string)

Outputs:
output reg [2:0] max_power // maximum power found (3 bits for mod 8)
output reg [7:0] best_mask // 8-bit mask where bit i=1 means keep step, 0 means 'o'
output reg done // high when computation complete

Specify latency: 256 cycles after start (one per combination).
Use state machine with states: IDLE, ITERATING, DONE.

In ITERATING state:
- Maintain current combination counter (8-bit)
- For each combination, simulate 8 steps
- Update max_power and best_mask if current power > max_power
- Increment combination counter
- When counter reaches 256, move to DONE

Output the best_mask which corresponds to the solution string (1=keep original char, 0='o').
