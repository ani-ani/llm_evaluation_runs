Design a sequential Verilog module named 'paint_the_numbers' that calculates the minimum number of colors required to paint a sequence of integers such that in each color group, all elements are divisible by the group's minimal element.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation pulse
input valid_in // High when input data is valid
input [7:0] data_in // Input integer (1-100 range)
input [7:0] num_inputs // Number of inputs to process (max 100)

Outputs:
output reg [7:0] num_colors // Result: minimum number of colors
output reg done // High when computation complete

Behavioral Description:
The module implements a greedy algorithm:
1. Collect inputs into an internal buffer (max 100 elements, 8-bit wide).
2. When 'start' is asserted, sort the buffer in ascending order.
3. Iterate through the sorted buffer. For each element:
   - If it hasn't been painted (marked) yet, increment the color count.
   - Mark this element and all subsequent elements that are divisible by it as painted.
4. Output the final color count.

Internal Implementation Details:
- Use a state machine with states: IDLE, COLLECT, SORT, PROCESS, DONE.
- COLLECT: Sample 'data_in' when 'valid_in' is high, into buffer 'arr' of size 100.
- SORT: Bubble sort the collected elements (small N, so bubble sort is acceptable).
- PROCESS: Iterate through sorted array, check 'marked' flags, compute result.
- Latency: Result valid ~20,000 cycles after start (worst case for sorting 100 elements in hardware).

Signal Widths:
- Data width: 8 bits (sufficient for values 1-100)
- Array index: 7 bits (0-127 range for 100 elements)
- Counter: 8 bits
- Colors: 8 bits
