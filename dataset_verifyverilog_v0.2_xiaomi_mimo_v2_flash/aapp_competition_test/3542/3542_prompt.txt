Design a sequential Verilog module named 'grid_router' that computes minimum wire length for connecting two pairs of points on a small grid without sharing vertices.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [3:0] grid_n // grid size N (0-15)
input [3:0] grid_m // grid size M (0-15)
input [3:0] a1_x, a1_y // coordinates for point A1
input [3:0] a2_x, a2_y // coordinates for point A2
input [3:0] b1_x, b1_y // coordinates for point B1
input [3:0] b2_x, b2_y // coordinates for point B2

Outputs:
output reg [7:0] result // minimum wire length or 255 for IMPOSSIBLE
output reg done // high when computation complete

The module should compute the minimum total wire length to connect A1-A2 and B1-B2 using Manhattan routing on the grid, ensuring the two wires do not share any vertices.

Algorithm:
1. Calculate Manhattan distances: dist_A = |a1_x - a2_x| + |a1_y - a2_y|
2. Calculate Manhattan distances: dist_B = |b1_x - b2_x| + |b1_y - b2_y|
3. Check if the two paths would necessarily intersect by checking bounding box overlap
4. If paths can be routed separately without crossing, return dist_A + dist_B
5. If crossing is unavoidable, return 255 (IMPOSSIBLE)

Simplified logic: Check if the two bounding boxes intersect (A min/max x/y vs B min/max x/y). If they don't intersect, use direct Manhattan routing. If they do intersect, check if L-shaped routing around the other box is possible within grid bounds.

Use state machine with states: IDLE, CALC_DIST, CHECK_INTERSECTION, COMPUTE_RESULT, DONE.
Result valid 6 clock cycles after start asserted.
For inputs larger than grid bounds or coordinates outside [0,N]x[0,M], treat as impossible.

Fixed-point: All calculations use integer arithmetic.
Use combinational logic for distance calculations.
Sequential logic for state machine and result computation.
