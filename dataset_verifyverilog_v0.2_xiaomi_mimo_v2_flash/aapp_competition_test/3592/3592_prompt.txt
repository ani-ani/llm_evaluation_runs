Design a sequential Verilog module named 'profit_calculator' that solves the linear Diophantine equation for profit calculation.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [31:0] total_profit // Total profit scaled by 100 (e.g., 725.85 -> 72585)
input [31:0] profit_pita // Profit per pita scaled by 100
input [31:0] profit_pizza // Profit per pizza scaled by 100

Outputs:
output reg [31:0] num_pitas // Number of pitas sold
output reg [31:0] num_pizzas // Number of pizzas sold
output reg valid // High when a valid combination is found on current cycle
output reg done // High when search is complete

Behavioral Description:
The module implements a search algorithm to find integer solutions (x, y) to the equation: x * profit_pita + y * profit_pizzas = total_profit.

1. State Machine:
   - IDLE: Wait for start signal.
   - SEARCH: Iterate x from 0 up to max possible (total_profit / profit_pita). For each x, calculate remainder = total_profit - x * profit_pita. If remainder >= 0 and remainder is divisible by profit_pizza, set valid=1 and outputs (x, remainder/profit_pizza). After outputting, increment x.
   - DONE: Search complete, done=1.

2. Constraints:
   - Input values are integers scaled by 100.
   - Use 32-bit arithmetic to prevent overflow (total_profit <= 1000000 after scaling).
   - Module must output one combination per clock cycle while valid is high.
   - Combinations must be sorted by increasing number of pitas.

3. Latency: Result valid X clock cycles after start asserted (approx 100-200 cycles worst case).

4. Logic:
   - Use a counter for the number of pitas.
   - Compute remainder = total_profit - (pitas * profit_pita).
   - Check if remainder >= 0 and remainder % profit_pizza == 0.
   - If valid, output pita count and pizza count (remainder / profit_pizza).
