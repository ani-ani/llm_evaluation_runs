Design a sequential Verilog module named 'digit_rearrange' that solves the digit rearrangement problem for inputs up to 8 digits.

The module should:
1. Accept a decimal string input (digits 0-9)
2. Count occurrences of digits 0-9
3. Remove one instance each of '1', '6', '8', '9' (these form the permutation suffix)
4. Calculate (prefix_value * 10000) % 7 where prefix is the remaining digits
5. Find a permutation of '1689' such that (prefix_mod * 10000 + perm_value) % 7 == 0
6. Output the rearranged number: prefix + permutation + zeros

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [31:0] digit_vector // 8 digits packed as 4 bits each (e.g., 8'b0001_0110_1000_1001 for '1689')
input [2:0] num_digits // number of valid digits (1 to 8)

Outputs:
output reg [39:0] result // 10 digits packed as 4 bits each
output reg [3:0] result_length // number of digits in result
output reg done // high when computation complete
output reg valid // high if a valid rearrangement exists

Specify latency: Result valid 120 clock cycles after start asserted.
Use state machine with states: IDLE, COUNT_DIGITS, REMOVE_SPECIAL, COMPUTE_PREFIX, FIND_PERMUTATION, CONSTRUCT_RESULT, DONE.

Internal Logic:
- Digit counting: iterate through input vector
- Modulo computation: (current_mod * 10 + digit) % 7 for prefix
- Permutation search: check 24 permutations of '1689' (hardcode the correct one based on prefix_mod)
- Hardcoded mapping: prefix_mod=0->1869, 1->1896, 2->1986, 3->1698, 4->6198, 5->1689, 6->1968
- Result construction: arrange prefix digits, append permutation, append zeros
