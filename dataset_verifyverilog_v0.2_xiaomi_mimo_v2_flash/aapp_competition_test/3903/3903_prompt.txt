Design a sequential Verilog module named 'three_states_solver' that computes the minimum number of road cells needed to connect three states on a small grid.

The module solves a simplified version of the problem on a 4x4 grid. The grid contains characters '1', '2', '3', '.', '#' representing states, buildable roads, and obstacles respectively.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [7:0] grid_flat [0:15] // Flattened 4x4 grid. Each byte is a character: '1'=49, '2'=50, '3'=51, '.'=46, '#'=35

Outputs:
output reg [7:0] min_cost // The minimum number of '.' cells needed to connect all three states
output reg done // High when computation is complete

Behavior:
The module should perform a Breadth-First Search (BFS) from every state ('1', '2', '3') to calculate the distance (number of '.' cells) to every reachable cell. It should then find the minimum sum of distances from the three states to any single cell (or direct connection between states). 

Simplifications:
- Grid size is fixed to 4x4 (16 cells).
- BFS must be implemented as a state machine with a fixed maximum number of steps (e.g., 16 cycles per BFS step).
- The module should iterate through the grid cells to find the minimum cost.
- If connection is impossible, output 255 (representing -1).

Specification:
- Use 3 pipeline stages for BFS from each state.
- Output format: Decimal integer.
- Latency: Approximately 500 clock cycles after start.
- Use state machine: IDLE, BFS1, BFS2, BFS3, CALCULATE, DONE.
