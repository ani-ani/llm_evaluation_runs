Design a sequential Verilog module named 'tour_finder' that solves the constrained Hamiltonian cycle problem for small grids.

The module should:
1. Accept grid dimensions N and M (max 8x8)
2. Search for a Hamiltonian cycle where adjacent nodes in the cycle have Manhattan distance 2 or 3
3. Use DFS algorithm implemented as a finite state machine
4. Return the tour sequence if found, or -1 if not possible

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [3:0] N // number of rows (1-8)
input [3:0] M // number of columns (1-8)

Outputs:
output reg [5:0] tour_addr // address for tour array (0 to N*M-1)
output reg [7:0] tour_row // row coordinate of current tour position
output reg [7:0] tour_col // column coordinate of current tour position
output reg tour_write // write enable for tour array
output reg done // high when computation complete
output reg found // high if tour found, low if -1

Internal Structure:
- Maximum grid size: 8x8 = 64 cells
- Each cell can be represented as index (row*M + col)
- DFS depth limited to N*M
- Use a stack (RAM) to store path and visited state
- Adjacency condition: distance must be exactly 2 or 3

Algorithm:
1. Initialize: start from cell (0,0)
2. DFS state machine:
   - Try all unvisited neighbors with valid distance (2 or 3)
   - Recursively continue until all cells visited
   - Check if last cell connects back to first with valid distance
3. If valid cycle found, output sequence to tour array
4. If exhausted all possibilities, output found=0

Latency: Result valid after up to 100,000 clock cycles (worst case for DFS)

State Machine States:
- IDLE: Wait for start signal
- INIT: Initialize stack and visited array
- SEARCH: DFS main loop - try neighbors
- CHECK_CYCLE: Verify cycle closure
- OUTPUT: Write tour to output registers
- DONE: Signal completion
- NO_SOLUTION: Set found=0

Use blocking assignment for state transitions. Implement visited array using registers or distributed RAM. The module must complete within reasonable time for 8x8 grid.
