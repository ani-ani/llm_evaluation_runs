Design a sequential Verilog module named 'max_operations' that computes the maximum number of operations by finding maximum bipartite matching on a graph of prime factors.

The module handles:
- Up to 8 numbers (N=8), each value up to 255 (8-bit)
- Up to 8 pairs (M=8)
- Prime factorization of numbers 1-255 (pre-computed)
- Bipartite graph: Left side = prime factors from odd positions (indices 1,3,5,7), Right side = prime factors from even positions (indices 2,4,6,8)
- Hopcroft-Karp algorithm for maximum matching

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [2:0] n // number of elements (2-8)
input [2:0] m // number of pairs (1-8)
input [7:0] a_i // array value input
input [2:0] idx1_i // pair index 1 (1-based)
input [2:0] idx2_i // pair index 2 (1-based)

Outputs:
output reg [5:0] result // maximum operations count (max 16)
output reg done // high when computation complete

Specification:
1. LOAD phase: Accept n, m values, then load array 'a' and pairs sequentially.
   - Data enters via a_i, idx1_i, idx2_i ports one item at a time
   - Use internal state machine to sequence loading
2. FACTOR phase: Decompose each number into prime factors
   - Store factor pairs (prime, instance_id) for each array position
3. BUILD phase: Construct adjacency list for bipartite graph
   - For each good pair (i,j), if i is odd and j is even, connect left factors of i to right factors of j
   - If i is even and j is odd, connect left factors of j to right factors of i
4. MATCH phase: Run Hopcroft-Karp algorithm
   - BFS to build layers, then DFS to find augmenting paths
   - Count maximum matches

Latency: Approximately 1000-2000 clock cycles (worst case)
States: IDLE, LOAD_ARRAY, LOAD_PAIRS, FACTOR, BUILD, MATCH_BFS, MATCH_DFS, DONE

Internal limits:
- Max prime factors per number: 8 (for numbers <= 255)
- Total left nodes: 32 max (8 numbers * 4 factors)
- Total right nodes: 32 max
- Adjacency: 32x32 matrix

For Hopcroft-Karp:
- left_match[31:0]: match IDs for left nodes
- right_match[31:0]: match IDs for right nodes
- dist[31:0]: distance for BFS layering
- queue: FIFO for BFS (depth 32)

Output: result contains maximum matching count (number of operations possible).
