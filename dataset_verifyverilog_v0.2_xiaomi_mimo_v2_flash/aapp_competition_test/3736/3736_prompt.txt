Design a sequential Verilog module named 'mirror_check' that determines if a string is a mirror word. A mirror word must satisfy two conditions: 1) It is a palindrome (reads same forwards and backwards). 2) All characters must be from the set {A, H, I, M, O, T, U, V, W, X, Y} which are symmetric characters.

The module processes a fixed-width string (maximum 16 characters) using a state machine that iterates through the string from both ends simultaneously.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation (high for one cycle)
input [15:0] char_valid // Bitmask indicating valid characters (1=valid, 0=invalid)
input [7:0] char_data [15:0] // Array of 16 bytes, each representing an ASCII character. Only valid positions should be checked.
input [4:0] str_length // Actual length of the string (0-16)

Outputs:
output reg is_mirror // High if string is a mirror word
output reg done // High when computation is complete

Behavior:
1. On start assertion, initialize state machine.
2. State machine should iterate through the string using two pointers (left and right).
3. In each iteration (PROCESSING state), check:
   - char_data[left] == char_data[right] (palindrome check)
   - char_data[left] is in the valid set (mirror check)
   - If both pass, increment left, decrement right.
4. Continue until pointers meet (left >= right).
5. If any check fails, immediately set is_mirror=0 and transition to DONE.
6. If all checks pass, set is_mirror=1 and transition to DONE.
7. Use states: IDLE, PROCESSING, DONE.
8. Latency: Maximum 16 clock cycles after start asserted (one cycle per character check).

The valid character set for hardware comparison:
A=0x41, H=0x48, I=0x49, M=0x4D, O=0x4F, T=0x54, U=0x55, V=0x56, W=0x57, X=0x58, Y=0x59

The char_valid input is provided as a bitmask where bit i is 1 if char_data[i] is a valid character. This allows parallel validity checking during the palindrome comparison.
