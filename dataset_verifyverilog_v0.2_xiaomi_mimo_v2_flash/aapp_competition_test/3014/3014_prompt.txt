Design a sequential Verilog module named 'disco_cyber_security' that solves the simplified cycle removal problem.

Problem Description:
Given a small directed graph with up to 8 nodes and 16 edges, remove at most half of the edges (max 8) to ensure no cycles exist. The module should identify and output the indices of edges to remove.

Input Format:
- Number of nodes n (1 to 8)
- Number of edges m (0 to 16)
- Edges represented as pairs of nodes (1-based indexing)

Output Format:
- Number of edges to remove r
- Indices of edges to remove (1-based, up to 8 indices)

Module Interface:
Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [3:0] num_nodes // Number of nodes (1-8)
input [4:0] num_edges // Number of edges (0-16)
input [3:0] edge_u [0:15] // Source nodes for edges (1-based)
input [3:0] edge_v [0:15] // Destination nodes for edges (1-based)

Outputs:
output reg [3:0] num_remove // Number of edges to remove
output reg [3:0] remove_indices [0:7] // Indices of edges to remove (0 means unused)
output reg done // High when computation complete

Specifications:
- Use a state machine with states: IDLE, CHECK_CYCLE, REMOVE_EDGE, DONE
- Latency: Maximum 256 clock cycles to complete
- The module should process edges sequentially and check for cycles using a simplified adjacency matrix approach
- If a cycle is detected involving an edge, add that edge's index to the removal list
- Limit removal to at most half of the edges (floor(m/2))
- If multiple valid solutions exist, output any valid one
- Output indices should be 1-based to match problem specification

Implementation Details:
- Use internal registers to maintain adjacency matrix (8x8 bits)
- Use a simple cycle detection algorithm that checks for paths from v back to u for each edge
- Once an edge is identified for removal, mark it and update the removal list
- The algorithm should guarantee a DAG (Directed Acyclic Graph) result

Edge Case Handling:
- If m=0, output num_remove=0
- If graph is already acyclic, output num_remove=0
- Ensure removal count <= floor(m/2)
