Design a sequential Verilog module named 'lights_controller' that computes the maximum number of lights on simultaneously for 16 lights over a time period of 64 cycles.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [15:0] initial_states // 16-bit vector where bit i is '1' if light i is initially on
input [4:0] a [15:0] // Array of 16 5-bit values for period a_i
input [4:0] b [15:0] // Array of 16 5-bit values for offset b_i

Outputs:
output reg [4:0] max_lights // Maximum number of lights on at any time (0-16)
output reg done // High when computation is complete

Behavioral Description:
The module uses a state machine with states IDLE, CALCULATING, and DONE.
1. In IDLE state, wait for start signal.
2. In CALCULATING state:
   - Iterate time t from 0 to 63.
   - For each time t, calculate the state of each of the 16 lights.
   - Light i toggles (state flips) if t >= b[i] and (t - b[i]) % a[i] == 0.
   - Track the number of lights that are ON at the current time t.
   - Update max_lights if the current count exceeds the previous maximum.
3. In DONE state, assert done signal and hold max_lights value.

Latency: The computation takes 64 * 16 clock cycles (approximately 1024 cycles) to process all time steps. Result is valid when 'done' is high.

Implementation details:
- Use a time counter (6 bits) for t (0-63).
- Use a light index counter (4 bits) for iterating through lights.
- Use a temporary register to count lights on at current time.
- The final result 'max_lights' is a 5-bit value (since max 16 lights requires 5 bits).
