Design a sequential Verilog module named 'min_subsegment_removal' that finds the minimum length of a subsegment to remove from an array so that the remaining elements are pairwise distinct.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation pulse
input [2:0] n_in // Number of elements in array (1 to 8)
input [7:0] arr_in // Input array data (8 elements, 8 bits each), presented sequentially

Outputs:
output reg [3:0] result // Minimum subsegment length to remove
output reg done // High when computation complete

Latency: Approximately 40 clock cycles after start.

Behavior:
The module should implement a two-pointer sliding window algorithm to find the minimum length of a subsegment [l, r] such that removing it leaves distinct elements. Since the array size is small (N<=8), we can process the array in a single pass.

1. Input Stage: Clock in the N elements into an internal register array.
2. Algorithm Stage: Use nested loops to iterate through all possible start positions 'l' and end positions 'r'. For each pair, check if the remaining elements (indices 0 to l-1 and r+1 to N-1) are distinct.
3. Checking Distinctness: Maintain a frequency array (lookup table) for values 0-255. Track duplicates.
4. Optimization: Since N is small (8), the state machine can iterate through l from N-1 down to 0, and for each l, find the smallest r by expanding from the right.

Specifics:
- Array size: Max 8 elements (addressed by 3 bits).
- Element values: 8-bit integers (0-255).
- Result: 4-bit integer (0-8).
- Use a lookup table for frequency counts of values 0-255 (requires 256x2 bit RAM or distributed RAM).
- State Machine states: IDLE, LOAD, INIT_DISTINCT, LOOP_L, CHECK_R, UPDATE_RESULT, DONE.

The module must verify distinctness by checking the remaining elements after hypothetically removing the subsegment.
