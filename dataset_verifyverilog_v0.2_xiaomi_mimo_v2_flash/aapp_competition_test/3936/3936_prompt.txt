Design a sequential Verilog module named 'domino_coloring' that calculates the number of valid coloring ways for a 2xN domino board arrangement.

The module processes the arrangement represented by two input strings S1 and S2. Since Verilog cannot handle variable-length strings dynamically, the input is provided as two arrays of 4-bit vectors (representing characters 'a'-'p' mapped to 0-15) of length N=16. The module identifies vertical dominos (where S1[i] == S2[i]) and horizontal dominos (where S1[i] != S2[i] but S1[i] == S1[i+1]).

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start processing (pulse high for one cycle)
input [3:0] s1 [0:15] // First string (4-bit character codes)
input [3:0] s2 [0:15] // Second string (4-bit character codes)

Outputs:
output reg [31:0] result // The calculated number of ways modulo 1000000007
output reg done // High when computation is complete

Specification:
- The module must handle N=16.
- Logic: 
  1. Parse the strings into a sequence of types: 'V' for vertical (2x1) if s1[i] == s2[i], 'H' for horizontal (1x2) if s1[i] != s2[i] (implies s1[i] == s1[i+1]).
  2. Calculate the answer based on the sequence of types.
  3. If first type is 'V', initialize ans=3. If 'H', initialize ans=6.
  4. Transition logic:
     - Prev V -> Curr V: ans = ans * 2
     - Prev V -> Curr H: ans = ans * 2
     - Prev H -> Curr V: ans = ans * 1
     - Prev H -> Curr H: ans = ans * 3
  5. All multiplications must be modulo 1000000007.
- Latency: Result valid 20 clock cycles after 'start' (assuming 1 cycle per character).
- Use a state machine with states: IDLE, PARSE, CALCULATE, DONE.
- Internally, use a temporary array to store the type sequence ('V' or 'H') derived from inputs during PARSE state.
