Design a sequential Verilog module named 'binary_string_cost' that calculates the minimum cost to convert a binary string to all '1's.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [7:0] str_len // length of string (max 8 for this scaled version)
input [7:0] char_in // current character input (0 or 1)
input valid_in // high when char_in is valid

Outputs:
output reg [31:0] result // minimum cost
output reg done // high when computation complete

Behavior:
The module processes a string of length str_len (max 8 characters). It counts the number of '0' segments by detecting transitions from '1' to '0'.

Let groups = number of '0' segments.
If groups == 0, result = 0.
Else if x <= y, result = (groups - 1) * x + y
Else result = groups * y

Note: x and y are fixed constants in this scaled version. Use x=10, y=1 for testing.

Use state machine with states: IDLE, READING, COMPUTING, DONE.
Latency: Result valid 10 clock cycles after start asserted (to simulate string reading).
