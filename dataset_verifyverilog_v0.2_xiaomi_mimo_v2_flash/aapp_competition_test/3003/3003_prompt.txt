Design a sequential Verilog module named 'chromatic_number_solver' that computes the minimum number of colors needed to color a graph such that no two adjacent vertices share the same color (graph coloring problem).

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [7:0] adjacency_matrix [0:7] [0:7] // Adjacency matrix of 8-node graph (flattened to 8 vectors of 8 bits). 1 indicates an edge.
input [2:0] num_vertices // Actual number of vertices (2-8)

Outputs:
output reg [2:0] chromatic_number // Result (1-8)
output reg done // High when computation complete

Specifications:
1. The module implements a backtracking algorithm to find the minimum chromatic number.
2. It starts in IDLE state when 'start' is asserted.
3. It proceeds to try coloring the graph with 1 color, then 2, etc., until a valid coloring is found.
4. For each candidate number of colors K (starting from 1):
   - It attempts to assign colors (0 to K-1) to vertices 0 to N-1.
   - It checks adjacency constraints: if vertex u and v are connected (matrix[u][v] == 1), they cannot have the same color.
   - It uses backtracking: if a color assignment fails, it tries the next color for the current vertex or backtracks to the previous vertex.
5. If a valid coloring is found for K colors, the algorithm stops and outputs K as the result.

Latency: The computation takes variable time depending on the graph structure and number of colors. Expect up to a few hundred clock cycles for N=8.

State Machine States:
- IDLE: Wait for start signal.
- INIT_COLOR_K: Reset current color count K to 1.
- CHECK_K: Check if current K is valid.
- SETUP_BACKTRACK: Prepare to assign colors to vertices using backtracking.
- ASSIGN_COLOR: Try assigning a color to the current vertex index.
- VERIFY_CONSTRAINT: Check if the current assignment violates adjacency constraints.
- BACKTRACK: If assignment invalid or all colors tried, move back to previous vertex.
- NEXT_VERTEX: Move to the next vertex index.
- FOUND_SOLUTION: A valid coloring with K colors was found.
- INCREMENT_K: Try K+1 colors.
- DONE: Result is ready.

Note: Since this is a hardware design, we will use fixed-size arrays (max 8 vertices). The input adjacency_matrix is provided as an 8x8 bit matrix. The 'num_vertices' input restricts the active set of vertices. The output is the integer chromatic number.
