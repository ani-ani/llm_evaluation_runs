Module Specification:
- Input: n [3:0]
- Input: start, clk, rst_n
- Output: result [31:0] (since 998244353 < 2^30)

Internal logic:
- State machine: IDLE, CALC_POW5, CALC_POW10, CALC_FINAL, DONE
- Compute p5 = 5^n % MOD
- Compute p10 = 10^n % MOD
- If n odd: comp = (1000 * p5) % MOD
- If n even: comp = (1000 * p5 - 4 * (5^(n-1))) % MOD. Note 5^(n-1) = p5 * inv(5) % MOD.
- result = comp * (comp - 1) / 2 % MOD
