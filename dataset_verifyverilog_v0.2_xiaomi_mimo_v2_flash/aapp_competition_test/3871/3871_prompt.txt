Design a sequential Verilog module named 'reality_show' that implements a simplified version of the reality show casting problem with aggressive scaling.

**Problem Adaptation**:
- Maximum 8 candidates (n <= 8)
- Maximum initial aggressiveness level 8 (m <= 8)  
- Maximum final aggressiveness level 16
- Fight resolution: when k participants have same level, floor(k/2) move to level+1, k%2 remain
- Revenue calculation: sum of c_v for all participants at all levels during fights

**Inputs**:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [2:0] n // number of candidates (<=8)
input [2:0] l_i // current candidate's aggressiveness level (1-8)
input [12:0] s_i // recruitment cost for current candidate
input [12:0] c_v // profitability for level v (1-16)
input valid_i // indicates valid input for current candidate
input done_i // indicates all candidates processed

**Outputs**:
output reg [15:0] max_profit // maximum profit found (Q16.0 format)
output reg done // high when computation complete

**State Machine**:
- IDLE: Wait for start signal
- SELECT: Decide whether to accept current candidate
- FIGHT: Resolve all fights for current participants
- UPDATE: Update DP state and move to next candidate
- DONE: Final result computed

**Behavior**:
The module processes candidates sequentially, maintaining:
- A list of current participants (up to 8) with their levels
- A running profit value
- Maximum profit found so far

For each candidate, it tries both accepting and rejecting, simulating fights recursively.

**Constraint**: All operations must complete within 256 clock cycles.

Use Q16.0 fixed-point format for all monetary values (integers scaled by 1).

**Key Simplification**: The fight resolution is computed iteratively by maintaining count per level and applying carries, similar to binary addition.
