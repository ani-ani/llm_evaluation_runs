Design a combinational Verilog module named 'find_max_even_pairs' that implements the core problem: find the longest consecutive sub-array where each element appears exactly twice.

Inputs:
input [7:0] n_i // Number of elements in array (max 8)
input [7:0][7:0] arr_i // Array of 8 elements, each 8-bit (values 0-255)

Outputs:
output reg [7:0] max_length // Length of longest valid sub-array

The module should compute this purely combinationally (no clock needed). The algorithm checks all possible sub-arrays [i, j] where 0 <= i <= j < n_i. For each sub-array, it verifies if every unique element appears exactly twice. Then it finds the maximum length among all valid sub-arrays.

For example, if arr_i = [1, 2, 3, 3, 4, 2] and n_i = 6, the valid sub-arrays are:
- [2,3] contains {3,3} -> length 2 (valid)
- [4,5] contains {4,2} -> each appears once (invalid)
- No sub-array has all elements appearing exactly twice except length-2 pairs
Result: max_length = 2

If arr_i = [1, 2, 1, 3, 1, 3, 1, 2] and n_i = 8, valid sub-arrays include:
- [2,5] contains {1,3,1,3} -> both 1 and 3 appear twice (valid, length 4)
- [0,3] contains {1,2,1,3} -> 1 appears twice, 2 and 3 appear once (invalid)
Result: max_length = 4

Edge cases:
- If n_i = 0, output 0
- If no valid sub-array exists, output 0
- Multiple elements can have different values as long as each appears exactly twice

Implementation strategy:
1. For each possible start index i (0 to n_i-1):
2. For each possible end index j (i to n_i-1):
3. Extract sub-array arr[i..j]
4. Count frequency of each value in sub-array
5. Check if all frequencies are exactly 2
6. If valid, compare length (j-i+1) with max_length

For hardware efficiency with small N (max 8):
- Use nested loops in generate blocks or case statements
- Frequency counting can use parallel comparators
- Since N is small, this is synthesizable combinational logic

Module interface:
- All inputs are combinational
- Output max_length is computed combinationally
- No clock or reset needed
- Assume complete input available at once
