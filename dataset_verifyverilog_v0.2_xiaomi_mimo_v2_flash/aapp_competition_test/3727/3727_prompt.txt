Design a combinational Verilog module named 'beautiful_sequence' that determines if a sequence can be formed from counts of numbers 0, 1, 2, 3 such that adjacent elements differ by exactly 1. The input counts are small integers (max value ~16). 

Inputs:
input [3:0] count_0 // Count of number 0
input [3:0] count_1 // Count of number 1
input [3:0] count_2 // Count of number 2
input [3:0] count_3 // Count of number 3

Outputs:
output reg valid // 1 if valid sequence exists
output reg [7:0] length // Length of the output sequence (max 16)
output reg [3:0] seq_out_0 // First element of sequence
output reg [3:0] seq_out_1 // Second element of sequence
// ... up to seq_out_15 for a max length of 16

The module should implement a simplified greedy algorithm logic. It checks valid patterns based on the counts of adjacent numbers (e.g., 0-1, 1-2, 2-3). It must handle cases where counts of inner numbers (1 and 2) are significantly larger or smaller than outer numbers (0 and 3), and check for specific parity conditions for single-number sequences. The output should be a fixed-width sequence representation.
