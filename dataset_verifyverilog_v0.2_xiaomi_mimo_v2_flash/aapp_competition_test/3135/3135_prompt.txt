Design a sequential Verilog module named 'signed_binary_converter' that converts a standard binary string to a signed binary representation (digits -1, 0, +1) with minimal non-zero digits.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start conversion
input [15:0] binary_in // 16-bit binary input (interpreted as integer)

Outputs:
output reg [17:0] signed_out // 18-bit signed representation: bit 17 is MSB, bit 0 is LSB. For each bit: 2'b01 = +1, 2'b00 = 0, 2'b11 = -1
output reg [4:0] length // actual length of representation (0-18)
output reg done // high when conversion complete

The algorithm works as follows:
Process bits from LSB to MSB (bit 0 to bit 15) plus one extra bit for carry.
Maintain a carry state that propagates.
For each position i, consider the current bit b_i and carry c:
- If (b_i + c) == 0: output 0, next carry = 0
- If (b_i + c) == 1: output +1, next carry = 0
- If (b_i + c) == 2: output -1, next carry = 1  (since 2 = -1 * 2^i + 1 * 2^{i+1})

The state machine should have states: IDLE, PROCESSING, DONE.
Processing takes 18 clock cycles (16 bits + 2 extra for carry propagation).

signed_out encoding:
- Each 2-bit pair represents one digit: 01=+, 00=0, 11=-
- Bit positions: signed_out[1:0] is LSB, signed_out[17:16] is MSB

For lexicographical ordering (+ < - < 0), the algorithm naturally produces the minimal representation.
