Design a sequential Verilog module named 'weather_prediction' that implements Vasya's weather forecasting method.

The module should accept an array of temperatures and determine if they form an arithmetic progression.
If they do, predict the next day's temperature by adding the common difference to the last element.
If they do not, predict the next day's temperature as the same as the last element.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation pulse
input signed [15:0] temp_in // Temperature input for the current day
input [6:0] n // Number of days (2 to 100, 7 bits sufficient for 100)

Outputs:
output reg signed [15:0] prediction // Predicted temperature for next day
output reg done // High when computation is complete
output reg valid // High when prediction is valid

Behavior:
1. On reset (rst_n = 0), clear the state and counters.
2. When 'start' is asserted, the module should expect to receive 'n' temperature values sequentially on 'temp_in'.
3. The module must store these values. Since it's sequential, it will process one value per clock cycle.
4. It needs to compute the difference d = t2 - t1 during the first two cycles.
5. For all subsequent inputs (t3 to tn), it must verify if (t_current - t_previous) == d.
6. If any difference does not match, set a flag indicating it is NOT an arithmetic progression.
7. After receiving all 'n' inputs, the module should compute the prediction.
8. If the sequence is an arithmetic progression, prediction = last_value + d.
9. If not, prediction = last_value.
10. The module should assert 'done' and 'valid' when the result is ready.
11. The module should use a state machine to manage the sequential process of loading and checking.

Specified Timing:
Latency: Result valid (n + 4) clock cycles after start asserted (cycles for reset, loading n values, computation, and output).

State Machine: IDLE, LOAD, CHECK, COMPUTE, DONE.
