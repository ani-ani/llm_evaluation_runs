Design a sequential Verilog module named 'replant_solver' that computes the minimum number of plants to replant to allow proper border placement. The problem is equivalent to finding the length of the Longest Non-Decreasing Subsequence (LNDS) of species IDs, such that the minimum replants = N - LNDS_length.

The module must handle:
- N plants (N <= 8)
- M species (M <= 16)
- Species IDs are 1-based integers up to 16

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [3:0] N // Number of plants (max 8)
input [4:0] M // Number of species (max 16, unused in logic but defines range)
input [3:0] species_in // Current plant species (valid when load_species = 1)
input load_species // Signal to load current plant species into buffer

Outputs:
output reg [3:0] result // Minimum number of plants to replant
output reg done // High when computation complete

Behavioral Description:
1. When load_species is high, capture species_in into an internal buffer array of size 8.
2. When start is asserted, compute the LNDS length of the species array.
   - Use dynamic programming: dp[i] = length of longest non-decreasing subsequence ending at index i.
   - dp[i] = 1 + max(dp[j]) for all j < i where species[j] <= species[i].
   - If no such j, dp[i] = 1.
3. Find the maximum value in dp array, let this be max_len.
4. Calculate result = N - max_len.
5. Assert done when finished.

Latency: Approximately 256 clock cycles for processing (to cover nested loop bounds). Specify state machine: IDLE, LOAD, COMPUTE_DP, FIND_MAX, CALCULATE_RESULT, DONE.

Fixed-Point: Not required (integers only).
