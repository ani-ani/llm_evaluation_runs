Design a sequential Verilog module named 'expected_max_dice' that calculates the expected maximum value of n tosses of an m-faced dice.

The calculation is based on the formula: E[max] = sum_{i=1}^{m} (1 - ((i-1)/m)^n)

The module must use Q16.16 fixed-point arithmetic (16 integer bits, 16 fractional bits).

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation signal
input [15:0] m // Number of faces (m <= 16)
input [15:0] n // Number of tosses (n <= 16)

Outputs:
output reg [31:0] result // The expected value in Q16.16 format
output reg done // High when computation is complete

Specifications:
- The module should use a state machine with states: IDLE, CALCULATE, DONE.
- In IDLE state, wait for start signal.
- In CALCULATE state, iterate i from 1 to m.
- For each i, calculate P_max_ge_i = 1 - ((i-1)/m)^n.
- To compute ((i-1)/m)^n, use a loop (counter for n iterations) to multiply the base value (Q16.16) by itself n times.
- Accumulate P_max_ge_i into a running sum.
- After processing all i, the accumulator holds the expected value.
- The result must be output in Q16.16 format.
- Latency: The computation takes several clock cycles. A safe upper bound for latency is 1000 cycles for m=16, n=16.
- Use internal registers for loop counters (i_loop, j_loop), intermediate values (base, power), and the accumulator.
