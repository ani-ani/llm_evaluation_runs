Design a sequential Verilog module named 'card_game' that determines the winner of a card game based on optimal play.

Problem Analysis: 
The game ends when no cards remain. The player holding the last turn wins if the opponent cannot move. The optimal strategy relies on parity of card counts. Specifically, if any card value appears an odd number of times, the first player (Conan) can force a win. If all card values appear an even number of times, the second player (Agasa) wins.

Constraints:
- Input array size: N = 16 (hardcoded parameter)
- Card values: 0 to 255 (8-bit integers)
- The module must iterate through the input array to count occurrences of the maximum value.
- Output '1' for Conan, '0' for Agasa.

Inputs:
input clk // System clock
input rst_n // Active-low reset
input start // Start computation pulse
input [7:0] data_in [15:0] // Array of 16 cards (8-bit values)

Outputs:
output reg result // 1 if Conan wins, 0 if Agasa wins
output reg done // High when computation is complete

Implementation Details:
1. The module should implement a state machine with states: IDLE, FIND_MAX, COUNT_MAX, DONE.
2. In FIND_MAX state, use a priority encoder logic (or iterative comparison) to find the maximum value in the array. Since it's sequential, you can compare elements one by one.
3. In COUNT_MAX state, iterate through the array again and count how many times the found max value appears. Use a counter.
4. In DONE state, check the parity of the counter. If odd (counter[0] == 1), set result = 1 (Conan). Else, result = 0 (Agasa).
5. Latency: Approximately 2 * N + 5 clock cycles (N to find max, N to count, few states for logic).
6. Assume unused inputs (if N < 16) are 0 or don't care, but for this problem we process all 16 entries.

Specific Logic Flow:
- State IDLE: Wait for start. Reset max_val and count.
- State FIND_MAX: Iterate index from 0 to 15. Compare data_in[index] with current max_val. If data_in[index] > max_val, update max_val.
- State COUNT_MAX: Iterate index from 0 to 15. If data_in[index] == max_val, increment count.
- State DONE: result = count[0]; done = 1.
