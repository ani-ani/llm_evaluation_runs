Design a sequential Verilog module named 'prime_palindrome_solver' that finds the maximum integer n such that π(n) ≤ A·rub(n), where A = p/q.

The module must operate on a scaled domain n <= 1023 (10 bits) to be synthesizable.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start calculation
input [13:0] p // Numerator of coefficient A (max 10000)
input [13:0] q // Denominator of coefficient A (max 10000)

Outputs:
output reg [9:0] result // Maximum n satisfying the condition
output reg done // High when computation is complete
output reg no_solution // High if no n satisfies (rare for this scaled range)

Behavior:
The module should use a state machine to iterate n from 1 to 1023.
1. Sieve Logic: Use a BRAM or distributed RAM initialized with 1s to represent primality flags. When n is prime, increment a prime counter (π). Initialize array of size 1024. Set 0 and 1 to non-prime. For i=2 to 1023, if prime[i], mark multiples as non-prime.
2. Palindrome Logic: For each n, check if it is a palindrome. Since n < 1024, it has at most 3 or 4 digits. Implement combinational logic to extract digits and compare them (e.g. compare bit patterns). Increment a palindrome counter (rub).
3. Comparison: Check if π(n) * q <= rub(n) * p. Use 24-bit multiplication to prevent overflow.
4. Update: If the condition holds, update result = n.
5. Latency: The calculation for 1023 iterations will take many cycles. Specify that done goes high after processing n=1023.

Use a state machine with states: IDLE, SIEVE_INIT, SIEVE_PROCESS, CALCULATE_ITER, FINISHED.
