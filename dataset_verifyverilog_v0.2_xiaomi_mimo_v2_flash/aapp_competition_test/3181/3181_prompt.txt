Design a sequential Verilog module named 'construct_sequence' that generates a permutation of numbers from 1 to N with longest monotone subsequence exactly K.

Problem Adaptation (Scaling):
- Original N up to 10^6, K up to N
- Scaled: Parameter N_MAX = 16 (max sequence length)
- Algorithm: Construct sequence by concatenating decreasing runs (blocks). The number of blocks M is chosen as M = N - K + 1. The sequence is formed by arranging numbers 1..N into M decreasing blocks. Block sizes are determined to be equal or nearly equal. Since the sequence is strictly decreasing inside each block and blocks are arranged in increasing order of values (block 1 has values 1..s1, block 2 has values s1+1..s1+s2, etc.), the longest ascending subsequence can take at most 1 element from each block (length M), and longest descending subsequence is the maximum block size (max(s_i)). We need M = N - K + 1 blocks. If M > N, it's impossible (output -1). Also, if K < 1, impossible (but K>=1). Note: K=1 is impossible for N>1 since max(LIS, LDS) >= sqrt(N) (Erdos-Szekeres theorem).

Inputs:
input clk // Clock
input rst_n // Active-low reset
input start // High for 1 cycle to start computation
input [4:0] N_in // Input N (0-16)
input [4:0] K_in // Input K (0-16)

Outputs:
output reg [4:0] sequence_out // The permutation output one by one
output reg valid // High when sequence_out is valid
output reg done // High when computation is finished (N values output)
output reg error // High if no solution exists

Behavior:
The module implements a state machine (IDLE, SETUP, GENERATE, FINISHED).
1. IDLE: Waits for start.
2. SETUP: Validates inputs. Check if K > N or K < 1. Also, based on theory, if K = 1 and N > 1, no solution exists (must output -1). If valid, calculate number of blocks M = N - K + 1.
3. GENERATE: Iterates through blocks. Block i (0-indexed) has size s_i. The total sum of s_i is N. We want the maximum block size to be as small as possible (ideally ceil(N/M)) but we need to verify if we can achieve exactly K. Since the longest ascending subsequence is at most M (taking one from each block) and longest descending is max(s_i), we satisfy the condition if M = N - K + 1 and we distribute sizes such that max(s_i) <= K. Actually, the problem asks for 'exactly K'. If we choose M = N - K + 1, then LIS <= M = N - K + 1. Wait, LIS is at most M. We want LIS = K. If we choose M = K, then LIS = K (can take 1 from each block) and LDS = max(s_i). Sum s_i = N, K blocks. If max(s_i) is small, LDS is small. The problem says longest monotone subsequence (either ascending or descending) is exactly K. So we need max(LIS, LDS) = K. We construct with M = K blocks. Then LIS <= K (likely equals K if we can pick 1 from each). LDS = max(s_i). We need max(s_i) <= K. Since sum s_i = N, distributed over K blocks, average is N/K. We can distribute sizes such that max size is floor(N/K) or ceil(N/K). We need ceil(N/K) <= K. This implies N/K <= K => N <= K^2. Also, if K=1, N must be 1. If K > N, impossible. Also, if N < K, impossible. So conditions: K <= N and if K=1 then N=1 else if K>1 then N <= K^2. Actually, for K > 1, we can usually achieve it if K <= N <= K^2. The construction is: M = K blocks. Sizes s_i sum to N. We want max(s_i) <= K. Since there are K blocks, the sum is N, so average is N/K. If N/K <= K, we can distribute. The upper bound is N <= K^2.

Algorithm for GENERATE state:
- Calculate block sizes: s_0 ... s_{K-1}. Base size = N / K, remainder = N % K. First 'remainder' blocks get size Base+1, others Base. (Note: N <= K^2 ensures Base+1 <= K if Base < K, but Base = floor(N/K). If N=K^2, Base=K, remainder=0, sizes are K. So max size is K. Good. If N < K^2, Base < K, so sizes <= K. Good. If N = K, sizes are 1. Good. If N > K^2, then Base >= K, sizes > K, LDS > K, so solution fails. So condition N <= K^2 is strict.)
- Output numbers: Iterate through blocks. For block i, it contains values from (current_start) to (current_start + s_i - 1). Output these values in decreasing order (from current_start + s_i - 1 down to current_start). Update current_start after each block.

Outputs:
- sequence_out: 5-bit value (since N<=16).
- valid: High when outputting a value.
- done: High after N values.
- error: High if constraints not met (K > N, K=1 & N>1, N > K*K).

Latency: About N+5 cycles.

Interface: Strictly sequential output.
