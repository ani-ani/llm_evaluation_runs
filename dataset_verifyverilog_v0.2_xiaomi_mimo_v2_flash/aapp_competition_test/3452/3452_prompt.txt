Design a sequential Verilog module named 'maze_equivalence' that determines sets of effectively identical rooms in a maze.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [6:0] num_rooms // number of rooms (1-100)
input [2:0] room_degree [0:15] // degree of each room (0-7 neighbors, max 16 rooms for simplicity)
input [6:0] room_neighbors [0:15][0:7] // adjacency list, 16 rooms max, 8 neighbors each, 0 means no neighbor

Outputs:
output reg [2:0] group_id [0:15] // group ID for each room (0 means no group)
output reg [3:0] num_groups // number of groups found
output reg done // high when computation complete
output reg none // high when no groups of size >=2 found

Specification:
Implement iterative label refinement to find structurally equivalent rooms:
1. Initialize each room's label to its degree
2. For 16 iterations:
   - For each room, gather neighbor labels
   - Sort neighbor labels ascending
   - Compute new label as hash(current_label, sorted_neighbor_labels)
   - Use simple hash: {current_label, neighbor_labels[0], neighbor_labels[1], ...}
3. After iterations, compare final labels to group rooms
4. A group is valid if it has >=2 rooms with identical labels
5. Output groups ordered by smallest room number in each group

State Machine: IDLE → INIT_LABELS → ITERATE (16 cycles) → SORT_NEIGHBORS → COMPUTE_HASH → CHECK_LABELS → FORM_GROUPS → DONE

Latency: Result valid approximately 200 clock cycles after start asserted.

Note: For hardware simplicity, limit to 16 rooms max and 8 neighbors per room. Use 32-bit labels.
