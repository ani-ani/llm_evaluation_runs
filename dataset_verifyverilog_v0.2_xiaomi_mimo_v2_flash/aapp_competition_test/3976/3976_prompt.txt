Design a sequential Verilog module named 'seq_match_finder' that finds starting positions q where a subsequence of array 'a' of length 'm' with stride 'p' is a permutation of array 'b'.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [3:0] n // total length of sequence a (max 16)
input [3:0] m // length of sequence b (max 16)
input [3:0] p // stride (max 15)
input [3:0] a [0:15] // input sequence a (values 1-15)
input [3:0] b [0:15] // input sequence b (values 1-15)

Outputs:
output reg [3:0] result_count // number of valid positions found
output reg [3:0] result_positions [0:15] // valid positions (q+1, sorted)
output reg done // high when computation complete

Behavior:
The module maintains a sliding window histogram of size 'm' over sequence 'a' with stride 'p'. It starts at position 0 (q=0) and increments by p until the window exceeds bounds.
For each position, it checks if the histogram of the window matches the histogram of 'b'.
Histograms are arrays of 16 counters (for values 1-15).

Latency: Approx 500 clock cycles for worst-case (n=16, m=16, p=1).
State Machine: IDLE -> INIT_HIST -> COMPARE -> UPDATE_WINDOW -> DONE.

Use a 16-element array of 4-bit counters for histogram implementation.
Output positions are 1-based (add 1 to 0-based index).
Result positions must be stored in sorted order.
