Design a sequential Verilog module named 'widget_packing' that computes the minimum empty squares for shipping widgets.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [15:0] N // number of widgets (max 65535)

Outputs:
output reg [15:0] min_empty // minimum empty squares
output reg done // high when computation complete

Specification:
- The module must find integers W, H (1-256) such that H/2 ≤ W ≤ 2H and W×H ≥ N
- Minimize empty squares = W×H - N
- Use state machine: IDLE, SEARCH, COMPARE, DONE
- Latency: 256*256 clock cycles worst case (search all valid pairs)
- Each cycle: increment W,H, check constraint, compute area, track minimum

Algorithm:
1. Initialize min_empty = 65535, best_W = 0, best_H = 0
2. For H from 1 to 256:
   - Compute W_min = ceil(H/2), W_max = min(256, 2*H)
   - For W from W_min to W_max:
     - Compute area = W*H
     - If area >= N: empty = area - N
     - If empty < min_empty: update min_empty, best_W, best_H
3. Output min_empty

Implementation notes:
- Use 16-bit multiplication for area calculation
- Track current W, H as state variables
- Use combinational logic for constraint checking
- Compute ceil(H/2) as (H+1)/2 for integer division
- All calculations in unsigned arithmetic
