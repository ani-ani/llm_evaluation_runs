Design a sequential Verilog module named 'lawsuit_assignment' that implements a greedy algorithm to assign lawsuit winners to minimize maximum wins.

Module Specification:
- Processes L lawsuits sequentially (L ≤ 16)
- Tracks win counts for up to 8 individuals (R ≤ 8) and 8 corporations (S ≤ 8)
- Uses greedy strategy: for each lawsuit, assigns winner to party with fewer current wins

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start processing all lawsuits
input [3:0] lawsuit_index // current lawsuit index (0 to L-1)
input [2:0] individual_idx // individual involved in current lawsuit (1-8, encoded as 0-7)
input [2:0] corporation_idx // corporation involved in current lawsuit (1-8, encoded as 0-7)

Outputs:
output reg [2:0] winner_type // 0: INDV, 1: CORP
output reg [2:0] winner_id // which individual or corporation won (0-7)
output reg done // high when all lawsuits processed
output reg [3:0] max_wins // maximum wins tracked during processing

Internal State:
- State machine: IDLE, PROCESSING, UPDATE, DONE
- Win counters: individuals_wins[7:0][3:0], corporations_wins[7:0][3:0]
- Lawsuit counter to track progress

Behavior:
1. In IDLE: wait for start signal
2. In PROCESSING: read current lawsuit (individual_idx, corporation_idx)
3. In UPDATE: compare wins, assign to party with fewer wins, increment counter
4. Update max_wins tracking
5. After all L lawsuits, go to DONE

Latency: 3 clock cycles per lawsuit (total ~3*L cycles)

Note: Winner_id outputs original 1-indexed ID (so add 1 to internal 0-indexed value)
