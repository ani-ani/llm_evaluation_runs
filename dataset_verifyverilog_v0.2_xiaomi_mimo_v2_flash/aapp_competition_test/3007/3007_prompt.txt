Design a sequential Verilog module named 'max_bling_calculator' that computes the maximum Bling Johan can achieve in a fruit farming game.

The module implements a day-by-day simulation (up to 40 days) with the following logic:
1. Normal fruits sell for 100 Bling, plant into trees.
2. Trees yield 3 fruits every 3 days (starting day 3).
3. Exotic fruits cost 400 Bling to buy (1 per day), sell for 500 Bling.
4. Exotic trees yield 3 exotic fruits every 3 days.
5. Decide daily: Buy exotic? Plant/Sell fruits? (Strategy: If remaining days >= 3, plant normal fruits. If remaining days >= 3 and Bling >= 400, buy exotic fruits to plant).

Inputs (all 8-bit unsigned integers):
input clk, rst_n, start
input [7:0] d_in       // remaining days (1-40)
input [7:0] b_in       // current Bling (0-500)
input [7:0] f_in       // current normal fruits (0-100)
input [7:0] t0_in      // trees yielding in 0 days (0-100)
input [7:0] t1_in      // trees yielding in 1 day (0-100)
input [7:0] t2_in      // trees yielding in 2 days (0-100)

Outputs:
output reg [15:0] result // Max Bling (max 500 + (40 days * profit)). Max profit approx 40*500=20000. 16 bits enough.
output reg done

Latency: Max 40 clock cycles (one per day).
State Machine: IDLE, SIMULATE_DAY, CALCULATE, DONE.

Logic per day:
- Harvest trees yielding today (add 3*yielding_trees to fruits).
- Action: Plant all normal fruits? Yes if days_left >= 3.
- Action: Buy exotic? Yes if Bling >= 400 AND days_left >= 3 (plant immediately) OR days_left < 3 (sell immediately).
- Action: Sell remaining fruits? Yes if days_left < 3.
- Update trees: Shift t2->t1->t0, new trees added to t2.
- Decrement day counter.
