Design a sequential Verilog module named 'max_chessmen' that computes the maximum number of chessmen that can be placed on an n x m board such that they are paired with Manhattan distance exactly 3.

The problem requires handling extremely large inputs (up to 10^9), but for hardware implementation we must scale down. We will implement a lookup table based solution for small dimensions (n, m <= 4), which captures the complexity of the special cases in the algorithm.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [3:0] n // Number of rows (scaled to max 4)
input [3:0] m // Number of columns (scaled to max 4)

Outputs:
output reg [31:0] result // Maximum number of chessmen
output reg done // High when computation complete

Specify latency: Result valid 2 clock cycles after start asserted.

Behavioral Description:
The module should implement the logic for small chessboards (max 4x4). The algorithm follows these rules:
1. Ensure n <= m (swap if needed)
2. Handle special cases for n=1 and n=2
3. For n >= 3, the answer is n*m if n*m is even, else n*m - 1

For n=1:
- Calculate remainder r = m % 6
- If r == 0, result = m
- If r <= 3, result = m - r
- If r > 3, result = m - (6 - r)

For n=2:
- If m == 2, result = 0
- If m == 3, result = 4
- If m == 7, result = 12
- Otherwise, result = n * m

For n >= 3:
- If (n * m) is odd, result = n * m - 1
- Else result = n * m

The module should use a state machine with states: IDLE, SWAP, CALCULATE, DONE. During IDLE, it waits for start. During SWAP, it ensures n <= m. During CALCULATE, it computes the result using combinational logic or lookup tables. During DONE, it asserts done signal.
