Design a sequential Verilog module named 'code_cracker' that solves the grid puzzle problem.

Problem Constraints (Scaled Down):
- Grid size: 4x4 (m=4, n=4)
- Digits: 1-9
- Unknowns: Up to 8 cells (half of 16)
- Fixed-point: Not applicable (integer problem)

Input Interface:
input clk: Clock signal
input rst_n: Active-low reset
input start: Start computation
input [3:0] row_addr: Row index (0-3) for loading
input [3:0] col_addr: Column index (0-3) for loading
input [3:0] data_in: Input digit (0-9, 0=unknown)
input load_en: Enable loading data into grid

Output Interface:
output reg [15:0] count: Number of valid complete codes found
output reg done: High when computation complete

Latency: Approx 1000-10000 cycles (depends on search space)

Algorithm Description:
1. Load Grid: Use 'load_en' to populate initial grid. Store in 4x4 register array.
2. Find Zeros: Identify positions of unknown digits (zeros).
3. Iterative Search: Use state machine (IDLE, LOAD_GRID, FIND_ZEROS, SEARCH, VALIDATE, DONE).
4. Backtracking: Fill zeros one by one with digits 1-9, checking constraints.
5. Constraint Checks (for each filled position):
   - Row Uniqueness: No repeated digits in same row
   - L-Shape Rule: For (i,j) not in top row or rightmost column:
     Let l = grid[i][j], u = grid[i-1][j], r = grid[i][j+1]
     Check if u == l*r OR u == l+r OR u == |l-r| OR u == l/r (integer) OR u == r/l (integer)
6. Count: Increment count when valid configuration found.

Module Structure:
- State Machine: 6 states (IDLE, LOAD, FIND, SEARCH, CHECK, DONE)
- Grid Storage: 4x4 array of 4-bit registers (16x4bit = 64 bits total)
- Stack for backtracking: 8-deep stack of 4-bit values (for unknown positions)
- Counter: 4-bit index for current zero being filled
- Loop counters: 4-bit counters for digit testing (1-9)

Output Format:
Provide Verilog module code.

Note: Since the problem involves search, the module uses iterative backtracking rather than pure combinational logic.
