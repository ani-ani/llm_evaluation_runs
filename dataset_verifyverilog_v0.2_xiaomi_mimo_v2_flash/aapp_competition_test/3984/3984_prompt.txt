Design a sequential Verilog module named 'game_winner' that determines the winner of the Mike and Ann game for all starting positions.

The game rules simplify to: For each position k, Ann wins if s[k] is lexicographically greater than the minimum character in s[0:k-1]; otherwise Mike wins.

Module interface:
- Input: clk (clock), rst_n (active-low reset), start (start computation)
- Input: char_in (7:0) - ASCII value of current character (one per cycle)
- Output: result (1:0) - 00=Mike, 01=Ann, 10=Invalid (during computation)
- Output: valid - high when result is valid for current input
- Output: done - high when entire string has been processed

Parameters:
- MAX_LEN = 64 (maximum string length)

Behavior:
1. On reset, initialize min_char to 127 (max ASCII), state to IDLE
2. When start is asserted, process characters sequentially
3. For each character, compare with current min_char
4. If char_in > min_char, result = Ann (01). Else result = Mike (00)
5. Update min_char = min(min_char, char_in)
6. Assert valid high for one cycle after processing each character
7. After MAX_LEN characters or when input stops, assert done

State Machine: IDLE, PROCESSING, DONE

Latency: Result valid 2 clock cycles after character input (pipeline delay)

Use 8-bit ASCII comparison, maintain running minimum.
