Design a combinational Verilog module named 'badge_decks' that determines the minimum number of badge decks Vasya should take to cover all possible participant distributions.

The problem constraints are scaled down: b and g (number of boys and girls) are up to 64, and n (tournament participants) is up to 64. The solution must be purely combinational.

The module should check for each integer k from 0 to n, whether a deck with k blue badges (and n-k red badges) is valid. A deck is valid if the number of boys b is at least k, and the number of girls g is at least n-k. The output is the count of valid decks.

Inputs:
input [5:0] b // Number of boys (0 to 63)
input [5:0] g // Number of girls (0 to 63)
input [5:0] n // Number of participants (0 to 63)

Outputs:
output [5:0] count // Number of valid decks

Logic:
1. The input n defines the range of decks to check: 0 to n inclusive.
2. For each potential number of blue badges k in this range:
   a. Check if b >= k.
   b. Check if g >= (n - k).
   c. If both conditions are true, this deck is valid.
3. Sum the number of valid decks.
4. Output the sum.

Note: Since n <= 63, a purely combinational implementation using a loop or unrolled logic is feasible. The output 'count' must be wide enough to hold the maximum possible count, which is n+1 (up to 64), requiring 6 bits.
