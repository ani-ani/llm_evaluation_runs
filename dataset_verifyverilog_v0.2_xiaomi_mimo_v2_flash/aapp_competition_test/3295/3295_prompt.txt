Design a sequential Verilog module named 'mirko_solver' that solves the 'Happy Numbers' problem. The module should find the starting number x of Mirko's array such that there are exactly L happy numbers in the range [x, x+K-1].

Constraints (Scaled for Verilog implementation):
- K (array length): 1 to 150
- L (required happy count): 0 to K
- M (threshold): 1 to 150
- Output x: Bounded to search up to 2000 (scaled down from 10^7)

Happy Number Definition:
A number is happy if (number <= M) OR (number is prime).

Module Interface:
- Inputs: clk, rst_n, start, K[7:0], L[7:0], M[7:0]
- Outputs: result[15:0] (the starting number x), done (signal)

Behavior:
The module implements a state machine (IDLE, PRIME_CHECK, COUNT_HAPPY, INCREMENT, FOUND).
1. In IDLE, wait for start.
2. Iterate x from 1 to 2000.
3. For each x, count happy numbers in [x, x+K-1].
4. To count happy numbers, it must check if each number in the range is <= M or Prime.
5. Primality check: Since numbers go up to ~2150 (2000+150), we need a primality check. This can be done with a small LUT (internal ROM) or combinational logic for numbers < 256.
6. If count == L, store x and go to DONE.
7. If x reaches 2000 without finding, output -1.

Latency: The search is sequential. Expect high latency (hundreds of cycles). Specify 'Result valid Y cycles after start'.
