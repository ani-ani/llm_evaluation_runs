Design a sequential Verilog module named 'graph_optimizer' that finds the minimum number of guest selections needed to make all pairs of guests friends. The problem is reduced to finding the minimum number of vertices such that all non-edges (missing friendships) are incident to at least one selected vertex (vertex cover on the complement graph).

Since n≤16, we use a BFS state machine with bitmasks.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [15:0] adj_matrix_0 // Adjacency matrix row 0 (bit i=1 means edge to node i)
input [15:0] adj_matrix_1 // Adjacency matrix row 1
input [15:0] adj_matrix_2 // Adjacency matrix row 2
input [15:0] adj_matrix_3 // Adjacency matrix row 3
input [15:0] adj_matrix_4 // Adjacency matrix row 4
input [15:0] adj_matrix_5 // Adjacency matrix row 5
input [15:0] adj_matrix_6 // Adjacency matrix row 6
input [15:0] adj_matrix_7 // Adjacency matrix row 7
input [15:0] adj_matrix_8 // Adjacency matrix row 8
input [15:0] adj_matrix_9 // Adjacency matrix row 9
input [15:0] adj_matrix_10 // Adjacency matrix row 10
input [15:0] adj_matrix_11 // Adjacency matrix row 11
input [15:0] adj_matrix_12 // Adjacency matrix row 12
input [15:0] adj_matrix_13 // Adjacency matrix row 13
input [15:0] adj_matrix_14 // Adjacency matrix row 14
input [15:0] adj_matrix_15 // Adjacency matrix row 15
input [3:0] n // Number of nodes (1 to 16)

Outputs:
output reg [3:0] result_steps // Minimum number of steps required
output reg [15:0] result_mask // Bitmask of selected guests (1 means selected)
output reg done // High when computation complete

Behavior: The module implements a BFS search over subsets of vertices. It computes the complement graph (non-edges) and searches for the smallest subset of vertices S such that all non-edges are covered by S. State machine states: IDLE, BUILD_COMPLEMENTS, BFS_INIT, BFS_LOOP, DONE.
Latency: Approximately 1000-5000 clock cycles depending on graph density (worst case 2^n states, optimized for small n).

Internal Logic:
1. IDLE: Wait for start signal
2. BUILD_COMPLEMENTS: Compute complement adjacency masks for each node (bits where edges are missing)
3. BFS_INIT: Initialize visited array, queue with mask 0 (no vertices selected), distance 0
4. BFS_LOOP: Iterate through queue, for each state, try adding each vertex not yet considered to generate new masks. Check if new mask covers all non-edges. If yes, record distance and transition to DONE. If queue empty without finding solution, increment distance and retry.
5. DONE: Set done=1, hold result.
