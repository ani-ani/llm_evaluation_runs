Design a sequential Verilog module named 'doggo_standardization' that determines if puppies can be recolored to a single color.

Problem logic: If n=1, always Yes. If any color has count >= 2, Yes. Otherwise No.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [4:0] char_in // 5-bit input representing character 'a'-'z' (0-25) arriving sequentially
input char_valid // high when char_in is valid

Outputs:
output reg result // high if possible to standardize
output reg done // high when computation complete

Behavior:
The module receives characters one by one (valid when char_valid is high). It counts occurrences of each of the 26 colors. It also tracks if the total number of puppies n is 1. After receiving all inputs (assumed to be 16 puppies max for this scaled problem), it computes the result.

Specified latency: 18 clock cycles after start (16 for input + 2 for processing).
Use state machine with states: IDLE, RECV, CHECK, DONE.

Use parameters: MAX_LEN = 16, CHAR_WIDTH = 5.
Use an array of 26 counters (5-bit width each).
