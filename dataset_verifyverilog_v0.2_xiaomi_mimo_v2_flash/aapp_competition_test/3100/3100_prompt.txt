Design a sequential Verilog module named 'fruit_arrangement' that counts arrangements of fruit boxes with the constraint that no two consecutive boxes have the same type.

The module implements a simplified dynamic programming approach for counts up to 10 boxes of each type (scaled from 200,000).

Inputs:
input clk                    // Clock signal
input rst_n                  // Active-low reset
input start                  // Start computation
input [4:0] A                // Number of apple boxes (1-10)
input [4:0] C                // Number of cherry boxes (1-10)
input [4:0] M                // Number of mango boxes (1-10)

Outputs:
output reg [31:0] result     // Number of arrangements (mod 10^9+7)
output reg done              // High when computation complete

Latency: Approximately 3000 clock cycles (enough for 10^3 states with 3 transitions each)

Algorithm:
Use DP with state: dp[a][c][m][last] = number of arrangements with 'a' apples, 'c' cherries, 'm' mangos used, ending with 'last' fruit type.
last: 0=none (start), 1=apple, 2=cherry, 3=mango

Transition:
- From state (a,c,m,last): try to add next fruit type ≠ last
- dp[a+1][c][m][1] += dp[a][c][m][last] if last ≠ 1 and a+1 ≤ A
- dp[a][c+1][m][2] += dp[a][c][m][last] if last ≠ 2 and c+1 ≤ C
- dp[a][c][m+1][3] += dp[a][c][m][last] if last ≠ 3 and m+1 ≤ M

Base case: dp[0][0][0][0] = 1

Result: dp[A][C][M][1] + dp[A][C][M][2] + dp[A][C][M][3]

Implementation details:
- Use 4D array: dp[11][11][11][4] with 3630 entries
- Each entry is 32-bit to hold result mod 10^9+7
- Initialize all to 0, then set dp[0][0][0][0] = 1
- Use state machine: IDLE, INIT, COMPUTE, SUM, DONE
- For COMPUTE state, iterate through all possible states and update neighbors
- Use nested loops with counters for a (0-10), c (0-10), m (0-10), last (0-3)
- Use modulus operation: result <= (result + value) % 32'd1000000007
- Final sum accumulates dp[A][C][M][1], dp[A][C][M][2], dp[A][C][M][3]

All operations are combinational within the state machine cycles. The module must produce correct counts for all valid inputs where A,C,M ≤ 10 and A+C+M > 0.
