Design a sequential Verilog module named 'dsu_union_find' that implements Disjoint Set Union (DSU) with path compression.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [2:0] op_type // 0: union, 1: query
input [2:0] a // first element (0 to 7)
input [2:0] b // second element (0 to 7)

Outputs:
output reg result // 1 if same set (query), 0 otherwise
output reg done // high when operation complete
output reg [2:0] parent [0:7] // current parent array for verification

Parameters:
- Maximum nodes: 8 (indices 0-7)
- Node width: 3 bits
- Operation types: 0=union, 1=query

Behavior:
The module maintains a parent array of size 8. Initially, each node is its own parent (i.e., parent[i] = i for all i).

For UNION operation (op_type = 0):
1. Find root of a (with path compression)
2. Find root of b (with path compression)
3. Set parent[root_a] = root_b
4. Complete in 20 clock cycles

For QUERY operation (op_type = 1):
1. Find root of a (with path compression)
2. Find root of b (with path compression)
3. result = 1 if roots equal, else 0
4. Complete in 20 clock cycles

State Machine:
- IDLE: Wait for start signal
- FIND_A_ROOT: Find root of node a
- FIND_B_ROOT: Find root of node b
- UNION_OP: Perform union operation
- QUERY_OP: Compare roots and set result
- DONE: Set done signal high

Path Compression: During root finding, update parent of each visited node to point directly to the root.

Reset: On reset (rst_n=0), initialize parent[i] = i for all i from 0 to 7.

Latency: Maximum 20 clock cycles from start to done.

Note: Since the hardware has limited resources, we implement path compression iteratively with a small internal stack/loop counter (max depth 8). The module uses combinational logic for find operations controlled by the state machine.
