Design a sequential Verilog module named 'resistance_calculator' that computes the minimum number of resistors needed to create a target resistance a/b.

The algorithm is based on the Euclidean algorithm:
- Start with a target resistance a/b
- If a > b: add floor(a/b) resistors, then transform the problem to a/b -> b/(a % b)
- If a < b: swap (a,b)
- Continue until b = 0, accumulating the quotients

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [63:0] a // Numerator of the target resistance (a/b)
input [63:0] b // Denominator of the target resistance (a/b)

Outputs:
output reg [63:0] result // Accumulated sum of quotients (answer)
output reg done // High when computation is complete

Behavior:
The module should implement a state machine with states: IDLE, CALCULATE, DONE.
- IDLE: Wait for start signal. On start, initialize internal variables (current_a, current_b = input a, b; sum = 0).
- CALCULATE: Implement the Euclidean algorithm loop:
  1. If current_b == 0: transition to DONE
  2. If current_a < current_b: swap current_a and current_b
  3. Add floor(current_a / current_b) to sum
  4. Update current_a = current_b
  5. Update current_b = remainder of (old current_a / current_b)
  Repeat until current_b == 0.
- DONE: Latch the result and set done high.

Latency: Result valid 64 clock cycles after start asserted (worst case for 64-bit values).

Constraint: The module must handle inputs up to 64 bits. Use a 64-bit divider and state machine.
