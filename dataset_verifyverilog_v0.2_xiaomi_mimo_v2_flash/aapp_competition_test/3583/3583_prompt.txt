Design a combinational Verilog module named 'max_hexagon_perimeter' that finds the maximum perimeter hexagon in a convex polygon with n vertices.

Inputs:
input [5:0] n // number of vertices (6-8)
input [7:0][15:0] x // x coordinates of vertices (scaled, 16-bit)
input [7:0][15:0] y // y coordinates of vertices (scaled, 16-bit)

Outputs:
output [31:0] perimeter // maximum perimeter in fixed-point Q16.16 format

The module should compute the maximum perimeter of any convex hexagon formed by selecting 6 vertices from the input polygon. Since n is small (≤8), use combinational logic to evaluate all possible combinations of 6 vertices. For each valid hexagon, calculate perimeter by summing the distances between consecutive vertices (in polygon order). The distance calculation should use Euclidean distance approximated for hardware: compute sqrt(dx² + dy²) where dx and dy are the differences between consecutive vertices. Since true sqrt is complex, use a lookup table or approximation. The perimeter should be output in Q16.16 fixed-point format (16 integer bits, 16 fractional bits). The module must handle the case where n=6 (only one hexagon) and n=8 (8 choose 6 = 28 hexagons).
