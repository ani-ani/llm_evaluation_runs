Design a sequential Verilog module named 'grundy_pile_solver' that computes the Grundy number for a single stone pile game with parameters A (initial stones) and K (max removal divisor).

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation for current A, K
input [31:0] A_i // Initial number of stones (Q16.16 format or integer)
input [31:0] K_i // K parameter (Q16.16 format or integer)

Outputs:
output reg [31:0] grundy_out // Computed Grundy number
output reg done // High when computation is complete

The module must implement the algorithm derived from Python solutions:
- If A < K, return 0
- If A % K == 0, return A // K
- Otherwise, update A in a loop: A = A - ((A // K + 1) * floor((A % K) / (A // K + 1)) + 1) or similar iterative reduction.

Since A and K can be very large, use a state machine with a bounded loop counter (max 128 iterations) to prevent infinite loops.

Use 32-bit fixed-point arithmetic (Q16.16) or 32-bit integer arithmetic. All divisions and modulo operations must be implemented using sequential logic or bounded combinational blocks.

State Machine:
- IDLE: Wait for start
- CHECK: Check termination conditions (A < K or A % K == 0)
- UPDATE: Compute next value of A
- DONE: Output result

Latency: Result valid approximately 150 clock cycles after start asserted.
