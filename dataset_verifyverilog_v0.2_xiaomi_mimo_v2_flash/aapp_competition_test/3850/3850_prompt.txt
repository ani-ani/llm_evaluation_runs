Design a combinational Verilog module named 'key_assignment' that computes the minimum maximum time for all people to reach the office with keys.

Problem Adaptation:
- Input size limited to n=2 people, k=4 keys (scaled down from 1000/2000)
- Positions are integers in range [0, 1023] (representing scaled locations)
- Office location p is an integer in range [0, 1023]
- People positions and key positions are provided as sorted arrays
- The solution requires checking all valid assignments (subset of keys to people)
- Since n=2 and k=4, we check all valid windowed assignments: k-n+1 = 3 windows of size 2
- For each window, calculate max time for person-key pairing and take the minimum over windows

Inputs (combinational):
input [9:0] p // Office location (10 bits for 0-1023)
input [9:0] people0 // Person 0 position
input [9:0] people1 // Person 1 position
input [9:0] key0 // Key 0 position
input [9:0] key1 // Key 1 position
input [9:0] key2 // Key 2 position
input [9:0] key3 // Key 3 position

Outputs:
output [10:0] result // Minimum max time (max possible is 2046, needs 11 bits)

The module must compute the result purely combinationally. Logic:
1. Calculate distance costs for all valid assignments (windows of size 2)
   - Window 0: keys 0,1 assigned to people 0,1
   - Window 1: keys 1,2 assigned to people 0,1
   - Window 2: keys 2,3 assigned to people 0,1
2. For each window i, calculate time for each person j:
   time[j] = |people[j] - key[i+j]| + |key[i+j] - p|
3. For each window, find max(time[0], time[1])
4. Result is min of all window max times

Implementation hints:
- Use intermediate wires for all distances and times
- Use combinational logic (assign statements) to calculate absolute differences
- Use ternary operators or comparators to find max and min values
- No clock or state machine needed
