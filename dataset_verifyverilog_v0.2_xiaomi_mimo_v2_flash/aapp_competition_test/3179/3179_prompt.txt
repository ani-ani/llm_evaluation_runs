Design a sequential Verilog module named 'canyon_map_solver' that computes the minimum side length for a mapping system covering a polygon.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [15:0] poly_x [0:15] // X coordinates of polygon vertices (Q12.4 fixed-point, 4 fractional bits)
input [15:0] poly_y [0:15] // Y coordinates of polygon vertices (Q12.4 fixed-point, 4 fractional bits)
input [3:0] num_vertices // Number of valid vertices (max 16)
input [1:0] k // Number of maps (1, 2, or 3)

Outputs:
output reg [31:0] result // Minimum side length in Q16.16 format
output reg done // High when computation complete

Behavior:
The module computes the bounding box of the polygon (min_x, max_x, min_y, max_y).
If k=1, the result is max(max_x - min_x, max_y - min_y).
If k>1, the module identifies the dominant axis (X or Y) based on the larger span (max - min).
It then conceptually divides the dominant axis range into k equal segments.
For each segment, it calculates the bounding box of the polygon restricted to that segment.
The side length required for each segment is the maximum of the local width and height.
Finally, it returns the maximum side length required among all k segments.

States: IDLE, COMPUTE_BBOX, DETERMINE_AXIS, CALCULATE_SEGMENTS, DONE.
Latency: Approximately 200 cycles for 16 vertices.
Use Q12.4 fixed-point for internal coordinates (12 integer bits, 4 fractional bits), converting inputs to Q16.16 for output.
