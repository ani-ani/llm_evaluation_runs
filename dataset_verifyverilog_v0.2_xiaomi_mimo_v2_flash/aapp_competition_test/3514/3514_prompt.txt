Design a combinational Verilog module named 'bomb_disarm' that computes the maximum number of buildings that can be disarmed.

Problem Analysis:
- Buildings are at positions (r, c) marked 'x'
- Can disarm a building if there's at least one other building in same row OR column
- This is equivalent to: count buildings with (row_count > 1) OR (col_count > 1)
- However, we must avoid double-counting scenarios where isolated pairs exist
- Core insight: Maximum disarmed = total_bombs - max( isolated_singletons, 0 )
- An isolated singleton is a bomb with row_count=1 AND col_count=1

For an 8x8 grid with maximum 64 positions:

Inputs:
input [7:0] grid [0:7][0:7] // 8x8 grid, each bit is 1 if bomb present

Outputs:
output [6:0] max_disarmed // maximum buildings that can be disarmed (0-64)

Combinational Logic:
1. Count bombs per row (8 rows, each count 0-8)
2. Count bombs per column (8 columns, each count 0-8)
3. For each bomb position, check if row_count > 1 OR col_count > 1
4. If both counts equal 1, it's an isolated singleton (cannot be disarmed)
5. Count all bombs where (row_count > 1) OR (col_count > 1)
6. Output count

Edge Cases:
- All isolated bombs (all row=1, col=1): max_disarmed = 0
- Single bomb: max_disarmed = 0
- No bombs: max_disarmed = 0
- Bombs in complete rows/columns: all can be disarmed except possibly one per connected component

The module computes this purely combinationally without clock.
