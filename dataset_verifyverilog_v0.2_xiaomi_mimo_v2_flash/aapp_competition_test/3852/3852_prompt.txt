Design a sequential Verilog module named 'non_decreasing_sequence' that implements an algorithm to make a sequence non-decreasing by adding elements.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input signed [31:0] a_in // Array element input (32-bit signed integer)
input [3:0] idx // Index of array element (0 to N-1)
input valid_in // High when a_in and idx are valid

Outputs:
output reg [3:0] op_x // x operand of operation (source index)
output reg [3:0] op_y // y operand of operation (target index)
output reg op_valid // High when operation is valid
output reg done // High when computation complete
output reg error // High if number of operations exceeds limit

Parameters:
N = 16 (Maximum array size)
MAX_OPS = 32 (2*N)

Behavior:
The module implements a simplified version of the non-decreasing sequence algorithm:
1. Accepts array elements sequentially via a_in and idx
2. Tracks the array values internally (N=16 max)
3. Finds the element with maximum absolute value
4. If all non-negative, applies prefix sum operations
5. If all non-positive, applies suffix sum operations
6. If mixed signs, adds the extreme element to others, then sorts
7. Generates operation pairs (x, y) meaning a[y] += a[x]
8. Stops after MAX_OPS operations or when sorted

State Machine States:
- IDLE: Wait for start signal
- LOAD: Accept N array elements
- ANALYZE: Find max/min and determine strategy
- PROCESS_OPS: Generate and output operations
- COMPLETE: Wait for handshake

Internal Logic:
- Use 16x32bit registers to store array
- Track operation count with 6-bit counter
- Strategy selection based on sign and magnitude
- Sequential operation generation

Implementation Details:
- Clock synchronous design
- Reset initializes all internal state
- Operations output one per clock cycle
- done signal remains high until reset

Latency: Operations start appearing 20 clock cycles after start, depends on array size. Complete signal appears after all operations generated.
