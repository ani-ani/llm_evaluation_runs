Design a sequential Verilog module named 'event_duration_solver' that solves for event durations given telescope observations.

Problem Scaling:
- M (event types): 4 max
- N (telescopes): 8 max
- Days per year: 365
- Event durations: 1-365 days
- Observation counts F_i: 0-200

Each observation gives an equation:
Duration = (End_Day - Start_Day) + 365 * (End_Year - Start_Year)
Duration = sum(F_i * duration_i) for i=1 to M

We need to find duration_i values that satisfy all N equations.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [8:0] start_day // start day of year (1-365)
input [8:0] end_day // end day of year (1-365)
input [7:0] F [0:3] // observation counts for 4 event types

Outputs:
output reg [8:0] duration [0:3] // computed durations for 4 event types
output reg done // high when computation complete
output reg valid // high if solution found

Specify latency: 1000 clock cycles max (iterative search).

Behavior:
1. Calculate observation_window = (end_day - start_day) if end >= start, else (end_day + 365 - start_day)
2. Iterate through possible duration combinations
3. For each combination, check if sum(F[i] * duration[i]) == observation_window for all N observations
4. Output first valid solution found

Implementation Strategy:
- Use a state machine: IDLE → READ_OBS → SOLVE → OUTPUT
- In SOLVE state, use nested loops or a structured search for duration values
- For each telescope, check if equation holds
- Since we have limited M=4, we can iterate d0=1..365, d1=1..365, etc., but optimize by checking constraints
- Use parameterizable bounds for search

State Machine States:
- IDLE: Wait for start signal, clear registers
- READ_OBS: Load observation data (simulated inputs from memory/registers)
- SOLVE: Search for duration values that satisfy all observations
- CHECK: Verify current candidate against all observations
- OUTPUT: Present result and set done signal

- A practical approach: assume the input provides one observation per clock cycle, and we validate against stored duration values
