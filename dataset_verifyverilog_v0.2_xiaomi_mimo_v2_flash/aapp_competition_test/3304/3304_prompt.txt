Design a sequential Verilog module named 'elf_dwarf_optimizer' that finds the maximum number of victories elves can achieve.

Problem adaptation:
- N is scaled to maximum 8 elements
- Elves and dwarves labeled 0-7 (3-bit)
- Strengths are 16-bit integers
- Module exhaustively tries all elf orderings, simulates seating, and returns max victories

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [2:0] N // number of elves/dwarves (1-8)
input [7:0] A_i [0:7] // elf preferred dwarf (indexed by elf label 0-7)
input [15:0] P_i [0:7] // dwarf strengths (indexed by dwarf label 0-7)
input [15:0] V_i [0:7] // elf strengths (indexed by elf label 0-7)

Outputs:
output reg [3:0] result // maximum victories (0-8)
output reg done // high when computation complete

Latency: Approximately 8! * 8 = 40320 clock cycles worst case

Implementation details:
1. Generate permutations of elves using state machine
2. For each permutation, simulate seating:
   - Track which dwarves are occupied (8-bit register)
   - For each elf in order, find first available dwarf starting from A_k
   - Mark dwarf as occupied
3. After seating, count victories where V_i[elf] > P_i[dwarf]
4. Track maximum across all permutations
5. State machine states: IDLE, INIT_PERM, NEXT_PERM, SIM_SEAT, SEAT_ELF, COUNT_WINS, UPDATE_MAX, DONE

Use parameters:
- MAX_N = 8
- STRENGTH_WIDTH = 16
- LABEL_WIDTH = 3
