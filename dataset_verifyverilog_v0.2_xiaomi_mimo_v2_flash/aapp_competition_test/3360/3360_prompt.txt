Design a sequential Verilog module named 'cfg_search' that searches for the longest substring in a text that can be generated by a given Context-Free Grammar.

**Simplifications for Hardware:**
1. Grammar: Max 5 rules, Variables (A-Z), Terminals (a-z), empty productions allowed
2. Input text: Fixed 16-character string (padded with nulls)
3. Algorithm: Simplified dynamic programming (CYK-like) optimized for small N=16
4. The module parses the grammar rules on initialization, then searches for matches

**Inputs:**
input clk // clock signal
input rst_n // active-low reset
input start // start computation (loads grammar and text)
input [4:0] rule_count // number of rules (1-5)
input [5:0][39:0] rule_data // 5 rules, each 40 bits: 8 bits head (A-Z), 8 bits prod length, 24 bits prod string (max 3 chars)
input [127:0] text_data // 16 characters, 8 bits each

**Outputs:**
output reg [7:0] result_start // start position of longest match (0-15)
output reg [7:0] result_length // length of longest match (0-16)
output reg [127:0] result_substr // matched substring (left-aligned)
output reg done // high when computation complete

**Behavior:**
1. IDLE state: Wait for start signal
2. Parse rules: Store grammar in internal memory (variables A-Z, productions)
3. Processing state: Use dynamic programming to compute which substrings can be generated
   - Build table for all substrings of length 1 to 16
   - Check if start symbol can generate any substring
   - Track longest and earliest match
4. DONE state: Output result

**Latency:** Approx 5000 clock cycles (depends on rule count and text length)

**Key Algorithm:**
- Use bit vectors to represent which variables can generate each substring
- For each substring position and length, check all rule combinations
- Special handling for empty production (epsilon rules)

**Rule Format Example:**
Rule 'S -> aSa': Head=A (0x53), ProdLen=3, Prod='aSa' (0x615361)
Rule 'S -> ' (empty): Head=A (0x53), ProdLen=0, Prod=0

Ensure the module has enough state and storage to handle the dynamic programming table for 16x16 substring checking.
