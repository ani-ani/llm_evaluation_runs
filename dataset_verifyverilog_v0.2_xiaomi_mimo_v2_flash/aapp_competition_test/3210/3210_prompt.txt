Design a sequential Verilog module named 'dots_and_boxes' that computes the maximum number of moves that can be made without completing any box in a Dots and Boxes game.

The module should implement the core algorithm: finding a maximum matching in the dual bipartite graph where edges are game moves and faces are constraints.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [7:0] row_data // Input row data for ASCII matrix (8-bit char stream)
input [5:0] row_index // Row index for input loading (0 to 2N-2)
input [2:0] N // Grid size N (2 to 8)

Outputs:
output reg [7:0] result // Result: maximum moves
output reg done // High when computation complete

Specify latency: Result valid 500 clock cycles after start asserted.

Behavioral Description:
The module should:
1. Load the 2N-1 x 2N-1 ASCII grid (max 15x15 for N=8) into internal memory
2. Build the bipartite graph representation:
   - Left nodes: horizontal edges (N*(N-1) max 56)
   - Right nodes: vertical edges (N*(N-1) max 56)
   - Constraints: For each unit square (i,j), its 4 edges cannot all be present
3. Compute maximum matching using a bounded search algorithm:
   - The dual problem: maximize edges such that no face is complete
   - This is equivalent to finding a maximum matching in the dual graph
   - Use a compact state machine to try edge combinations
4. Output the count of moves

Implementation notes:
- Use Q16.16 fixed-point format for any intermediate calculations
- Store grid as 16x16 array of 8-bit characters
- Implement as state machine with states: IDLE, LOAD_GRID, BUILD_GRAPH, COMPUTE_MATCHING, DONE
- For N=8, maximum edges is 112, maximum moves without completing box is 2N(N-1) - N² = 2*8*7 - 64 = 112 - 64 = 48
- Result fits in 8 bits
