Design a sequential Verilog module named 'carry_free_addition' that computes the minimum number of steps to make two numbers add without carry.

Problem Summary: Given two positive integers A and B, find minimum k such that (A-k + B+k) or (A+k + B-k) produces no carry digits in standard addition.

Simplified Algorithm: For each k from 0 to B (or A), check if A-k and B+k add without carry. Stop at first valid k.

Adapted Constraints:
- Input numbers: 16-bit unsigned integers (0 to 65535)
- Search space: 0 to 65535 iterations
- Carry detection: Check each digit pair (0-9) independently

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [15:0] a // first number (0-65535)
input [15:0] b // second number (0-65535)

Outputs:
output reg [15:0] steps // minimum steps required
output reg done // high when computation complete

Specify latency: Result valid after up to 65536 clock cycles after start asserted.

Module Behavior:
1. On start, initialize k=0
2. Each cycle, compute a-k and b+k (or a+k and b-k)
3. Check if digits add without carry: for each decimal position (0-9 digits), (digit_a + digit_b) must be < 10
4. If no carry detected, output k and set done=1
5. If carry exists, increment k and continue
6. Maximum iterations: 65535 (worst case)

State Machine:
- IDLE: Wait for start signal
- PROCESSING: Check carry condition for current k
- DONE: Output result

Helper Logic: For carry checking, convert binary to decimal digits at each position and verify sum < 10.

Optimization: Since we need to check decimal digit sums, extract digits (units, tens, hundreds, etc.) from a-k and b+k, compare sum of each pair.
