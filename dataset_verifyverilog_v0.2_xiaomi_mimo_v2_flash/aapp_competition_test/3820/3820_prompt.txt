Design a sequential Verilog module named 'wildcard_match' that implements a simplified wildcard string matching algorithm.

The module processes strings with a maximum length of 8 characters. It checks if a target string 't' matches a pattern 's', where 's' can contain exactly one wildcard character '*' that can be replaced by any sequence of lowercase letters (including empty).

The pattern 's' and target 't' are provided as fixed-width byte arrays. The module must:
1. Handle patterns with or without a wildcard
2. Verify the prefix before the wildcard matches the start of 't'
3. Verify the suffix after the wildcard matches the end of 't'
4. Ensure total length of fixed characters (prefix + suffix) <= length of 't'

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start the matching process
input [2:0] s_len // Length of pattern string (1 to 8)
input [2:0] t_len // Length of target string (1 to 8)
input [63:0] s_data // Pattern string packed as 8 ASCII bytes (left-aligned)
input [63:0] t_data // Target string packed as 8 ASCII bytes (left-aligned)

Outputs:
output reg match // High if pattern matches target
output reg done // High when computation is complete

Latency: Result valid 20 clock cycles after start asserted.

Internal Logic:
The module should use a state machine with states: IDLE, FIND_WILDCARD, CHECK_PREFIX, CHECK_SUFFIX, VERIFY_LENGTH, DONE.
1. IDLE: Wait for start signal
2. FIND_WILDCARD: Scan s_data to find '*' position or confirm absence
3. CHECK_PREFIX: Compare characters before '*' (or all if no wildcard) with t_data
4. CHECK_SUFFIX: Compare characters after '*' with end of t_data
5. VERIFY_LENGTH: Check if prefix_len + suffix_len <= t_len
6. DONE: Set match result and done signal

Note: All strings are packed as 64-bit values where each byte (8 bits) represents one character. The first character of the string is at the most significant byte (bits[63:56]). Strings are left-aligned within the 64-bit value, meaning unused trailing bytes are don't-care.

The ASCII value for '*' is 8'h2A.
The ASCII values for lowercase letters are 8'h61 to 8'h7A.
