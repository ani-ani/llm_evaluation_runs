Design a sequential Verilog module named 'graph_coloring' that computes the number of valid colorings for a functional graph.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [3:0] N // number of nodes (1-8)
input [7:0] K // number of colors (1-256)
input [7:0] f [0:7] // functional mapping f[i] (1-based values, 0 indicates no constraint)

Outputs:
output reg [31:0] result // result modulo 1000000007
output reg done // high when computation complete

Latency: Approximately 200 clock cycles after start asserted.

Behavioral Description:
The module processes a functional graph where each node i (1-indexed) has constraint: color[i] ≠ color[f[i]] if f[i] ≠ i.

Algorithm:
1. Use state machine: IDLE, INIT, FIND_UNVISITED, FIND_CYCLE, PROCESS_COMPONENT, UPDATE_RESULT, DONE
2. Track visited nodes and component information
3. For each component: find its cycle length L and total size m
4. Compute chromatic polynomial for cycle: P(C_L, K) = (K-1)^L + (-1)^L * (K-1)
5. Compute component contribution: contrib = P(C_L, K) * (K-1)^(m-L)
6. Multiply all component contributions modulo 1000000007

Implementation details:
- Use temporary registers for: visited[0:7], current_node, cycle_length, component_size, temp_result
- Use a small state machine for graph traversal
- Implement modular multiplication and exponentiation with iterative loops
- All arithmetic modulo 1000000007
- Handle f[i] = 0 as self-constraint (no edge)
- Input f array uses 1-based indexing (f[0] corresponds to node 1)

Special cases:
- If K=1: only valid if no constraints exist (result=1 or 0)
- If K=2: check if any component has odd cycle (result=0 for that component)
- General K: compute using formula above

The module should be synthesizable and handle the three provided test cases correctly.
