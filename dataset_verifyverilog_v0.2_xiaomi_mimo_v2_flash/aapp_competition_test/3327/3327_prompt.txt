Design a sequential Verilog module named 'crossword_solver' that implements a backtracking search algorithm to fill a fixed-size 8x8 crossword grid.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start solving the crossword
input [7:0] grid_in [0:7][0:7] // Initial grid state (0=empty, 1=hash, 2-27=letters A-Z)
input [7:0] word_list [0:15][0:7] // List of up to 16 words, each max 8 chars (0-terminator or length)
input [3:0] num_words // Number of valid words in the list
input [2:0] grid_width // Width of the valid grid area
input [2:0] grid_height // Height of the valid grid area

Outputs:
output reg [7:0] grid_out [0:7][0:7] // Solved grid
output reg done // High when solution found

Behavior:
The module must implement a backtracking algorithm to place words into the grid.
Since unbounded recursion is difficult in hardware, implement a state machine that iterates through the word list and tries to place words in all valid horizontal and vertical positions.

States:
- IDLE: Wait for start signal.
- PLACE_WORD: Attempt to place the current word index in the grid.
  - Iterate through all grid cells (row 0-7, col 0-7).
  - Try horizontal placement: Check if word fits at (r, c) horizontally.
    - Conditions: Fits within width, valid cells are empty or match letter, boundaries/voids respected.
  - Try vertical placement: Check if word fits at (r, c) vertically.
- CHECK_SOLUTION: If all words placed, assert done. If conflict or no placement found, backtrack by resetting word placement and trying next position.
- DONE: Finished.

Optimization: Since the input is small (8x8, 16 words), the state machine can be optimized to check parallel conditions. The testbench will provide the scaled inputs.

Note: The grid_in and grid_out use byte values. 0=Empty ('.'), 1=Hash ('#'), 65='A', etc. The word_list is stored as a 2D byte array.
