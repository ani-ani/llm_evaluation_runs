Design a combinational Verilog module named 'function_decomposer' that implements a scaled-down version of the function decomposition problem.

Problem: Given a function f: [n] → [n] where n ≤ 8, determine if f can be decomposed as f = h ∘ g with g: [n] → [m], h: [m] → [n], and g(h(x)) = x for all x ∈ [m].

Algorithm:
1. Check if f is idempotent: f(f(i)) = f(i) for all i
2. If not idempotent, output invalid flag
3. If idempotent, construct m as count of unique values in f
4. Build h as the sorted unique values of f
5. Build g such that g(i) = index of f(i) in h (1-indexed)

Inputs:
input [2:0] n // number of elements, 1-8
input [2:0] f_1, f_2, f_3, f_4, f_5, f_6, f_7, f_8 // function values, 1-8

Outputs:
output valid // 1 if decomposition exists
output [2:0] m // number of elements in h
output [2:0] g_1, g_2, g_3, g_4, g_5, g_6, g_7, g_8 // g values (1-8)
output [2:0] h_1, h_2, h_3, h_4, h_5, h_6, h_7, h_8 // h values (1-8), only first m are valid

The module should be purely combinational. Use an 8-element array internally for simplicity. For each i from 1 to n:
- Check f[f[i]] == f[i] (idempotency)
- Build list of unique f values
- Map each f[i] to its index in unique list

Use case statements or if-else for the logic. Output 0 for invalid cases except valid flag.

Example: n=3, f=[2,2,2] should produce valid=1, m=1, g=[1,1,1], h=[2]
Example: n=2, f=[2,1] should produce valid=0 (not idempotent)
