Design a sequential Verilog module named 'min_rect_cost' that computes the minimum total cost to whiten all black cells in a small grid.

**PROBLEM ADAPTATION**:
- Input grid size: 8x8 (n=8)
- Maximum black cells: 8 (m=8)
- Representation: 8x8 boolean matrix where 1=black, 0=white
- Cost function: min(h, w) for a rectangle operation
- Algorithm: Compute Min-Cut on the dual graph (or equivalent Max Flow) representing partitioning of black cells. Since the grid is small (8x8), we can implement the specific logic derived from the problem's bipartite nature.

**INSIGHT**: The problem is equivalent to finding the minimum weight vertex cover in a bipartite graph of row-segments and col-segments of black cells, or finding the minimum cost to cut the black cells into non-touching groups using row/column deletions (cuts). 
Given the small 8x8 constraint, we can implement a solution that effectively searches for the optimal cut pattern or uses a simplified flow network.

For the 8x8 grid, we will implement a specific state machine that:
1. Accepts the 8x8 grid as input
2. Constructs the adjacency (intersection) graph of black cells (up to 8 nodes)
3. Solves the Min-Cut/Vertex Cover using a dynamic programming approach on the small graph or exhaustive search on possible row/column cuts.

**However**, to make it truly hardware-friendly and distinct, we will implement the **Min-Cut on Grid Graph** solution using a simplified max-flow approach tailored for the 8x8 grid.

**Module Interface**:
Inputs:
- `clk`: Clock
- `rst_n`: Active low reset
- `start`: Start signal
- `grid`: Input [7:0][7:0] array (8 rows of 8 bits). Each bit represents a cell (1=black).

Outputs:
- `result`: Output [5:0] (Max cost is small for 8x8, 6 bits enough)
- `done`: High when computation complete

**Latency**: Approximately 100-200 clock cycles (enough for 8x8 flow network calculation).

**State Machine**:
- `IDLE`: Wait for start
- `CONSTRUCT`: Parse grid to identify distinct black cells and adjacency (simulating max flow)
- `FLOW`: Run simplified max flow/min cut logic (e.g., 8 iterations of augmenting path search)
- `DONE`: Output result
