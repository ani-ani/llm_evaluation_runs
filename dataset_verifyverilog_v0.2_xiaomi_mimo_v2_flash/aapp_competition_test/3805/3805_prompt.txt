Design a sequential Verilog module named 'wire_untangle' that determines if entangled wires can be untangled based on a sequence of crossings.

The problem reduces to checking if the input string of '+' and '-' characters can be reduced to an empty string by repeatedly removing adjacent identical characters (e.g., '++' or '--').

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start processing (asserts when input string is ready)
input [5:0] char_in // Current character input: 6'b000001 for '+', 6'b000010 for '-'
input valid_in // High when char_in is valid
input end_in // High when last character of string has been received

Outputs:
output reg result // 1 if wires can be untangled (Yes), 0 otherwise (No)
output reg done // High when computation is complete

Specifications:
- The module processes one character per clock cycle.
- It maintains a stack of unmatched characters using a register array.
- Maximum string length is 32 characters (stack depth 32).
- Character encoding: '+' = 6'b000001, '-' = 6'b000010.
- State machine states: IDLE, RECV, PROCESS, COMPLETE.
- In IDLE: wait for start signal.
- In RECV: receive characters and push to stack if top is different, pop if same.
- In PROCESS: verify stack state (should be empty if untangleable).
- In COMPLETE: assert done and result.
- Latency: Result valid N clock cycles after start, where N is string length + 2 cycles.

Behavioral Description:
Use a 32-element stack (register array) to store characters.
Use a 5-bit stack pointer (sp) to track stack depth.
When valid_in is high:
  If stack is empty, push char_in.
  Else if stack[sp-1] == char_in, pop (decrement sp).
  Else push char_in.
When end_in is high, transition to PROCESS state.
Result is 1 if stack is empty (sp == 0) at end, else 0.
