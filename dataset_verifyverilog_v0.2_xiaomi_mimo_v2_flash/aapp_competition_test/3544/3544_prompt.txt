Design a sequential Verilog module named 'cinema_seating' that implements a simplified movie theater seating optimizer.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [2:0] n // size of largest group (1-8)
input [7:0] num_groups_1 // number of 1-person groups
input [7:0] num_groups_2 // number of 2-person groups
input [7:0] num_groups_3 // number of 3-person groups
input [7:0] num_groups_4 // number of 4-person groups
input [7:0] num_groups_5 // number of 5-person groups
input [7:0] num_groups_6 // number of 6-person groups
input [7:0] num_groups_7 // number of 7-person groups
input [7:0] num_groups_8 // number of 8-person groups

Outputs:
output reg [4:0] result // size of widest row (1-12, or 13 for impossible)
output reg done // high when computation complete

The module should find the smallest widest row size (1-12) that can seat all groups following these rules:
- Rows have decreasing sizes: first row has X seats, second has X-1, ..., last has 1 seat
- Groups must have at least 1 empty seat between them (unless at row end)
- Groups cannot be split across rows
- Minimize total rows needed for a given X

Implementation strategy:
- Use a state machine with states: IDLE, CALCULATE_X, CHECK_SEATING, DONE
- For each X from 1 to 12, simulate seating using a greedy algorithm
- For each row size, try to place groups starting from largest groups first
- Count how many rows are needed to seat all groups
- Track minimum rows for valid X, and select smallest X among equal row counts
- If no solution found within X=12, output 13 (impossible)

Algorithm details:
1. For X in 1..12:
   - Initialize remaining groups
   - Row count = 0
   - While groups remain:
     - Current row size = X - row_count
     - If row size <= 0: this X fails, break
     - Try to fill row with greedy placement (largest first, respecting spacing)
     - If row cannot fit any group: this X fails, break
     - Increment row count
   - If all groups seated: record (X, row_count)
2. Find minimum X among those with minimum row_count
3. Output X (or 13 if none found)

Latency: Maximum 10000 clock cycles from start to done.
Use state machine with bounded counters for loops.
