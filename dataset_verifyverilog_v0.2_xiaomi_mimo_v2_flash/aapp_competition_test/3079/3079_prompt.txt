Design a sequential Verilog module named 'slavko_word' that determines the most beautiful word Slavko can form given Mirko's fixed strategy.

Problem Context:
- Mirko always takes the rightmost remaining letter.
- Slavko wants to form the lexicographically smallest word.
- N is even. Total turns = N/2 for each.

Inputs:
input clk             // Clock signal
input rst_n           // Active-low reset
input start           // Start computation (loads N and sequence)
input [7:0] char_in   // Input character (ASCII value)

Outputs:
output reg [79:0] slavko_word_out // Packed 8-character word (8 bits each)
output reg [2:0] length_out       // Length of the word (N/2)
output reg winnable               // 1 if Slavko can win (strictly better word exists)
output reg done                  // High when computation is complete

Constraints:
- Limit N to maximum 8 characters.
- Mirko's strategy: Rightmost letter.
- Slavko's strategy: Scan remaining letters. If a letter strictly smaller than the current best candidate (or starting from 'z') exists, Slavko can choose it.
- The sequence is loaded into a buffer.
- State Machine:
  1. IDLE: Wait for start.
  2. LOAD: Accept N characters (where N <= 8).
  3. MIRKO_PICK: Remove rightmost character (decrement available count).
  4. SLAVKO_PICK: Scan for best character. If 'winnable' flag is not set, check if any char < current Slavko char is available. If yes, update Slavko word and set winnable.
  5. DONE: Output results.

Simplified Module Logic (Sequential FSM):
1. IDLE: Wait for start.
2. LOAD: Store input chars into buffer[7:0][7:0]. Count N.
3. SETUP: Initialize freq[25:0] based on buffer.
4. PLAY_LOOP (Repeat N/2 times):
   - MIRKO_STATE: Find rightmost available char in buffer. Append to Mirko's word. Decrement freq.
   - SLAVKO_STATE: Find smallest char in freq (a-z). Append to Slavko's word. Decrement freq.
   - Update indices/pointers.
5. COMPARE: Compare Slavko's word with Mirko's word.
   - If Slavko < Mirko: winnable = 1.
   - Else: winnable = 0.
6. DONE.

This is a full simulation, valid for N<=8.
