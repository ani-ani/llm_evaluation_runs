Design a combinational Verilog module named 'luka_border_solver' that finds all integers M > 1 such that 4 given integers (scaled to 8-bit) give the same remainder when divided by M.

Mathematical Insight:
For integers A, B, C, D to have same remainder modulo M, it means:
(A % M) = (B % M) = (C % M) = (D % M)
This implies: M divides (A-B), (B-C), (C-D), (A-C), etc.
So M must be a common divisor of all pairwise differences.

Since we have 4 numbers, we calculate differences between them and find common divisors.

Inputs:
input [7:0] num0 // First number (1-100 range)
input [7:0] num1 // Second number (1-100 range)
input [7:0] num2 // Third number (1-100 range)
input [7:0] num3 // Fourth number (1-100 range)

Outputs (8-bit divisors, 0 means no valid M):
output [7:0] m0
output [7:0] m1
output [7:0] m2
output [7:0] m3
output [7:0] m4
output [7:0] m5
output [7:0] m6
output [7:0] m7

Logic:
1. Calculate absolute differences between all pairs: |numi - numj|
2. Find GCD of these differences (or check divisors)
3. Return all divisors M > 1 of the GCD

For 4 numbers, we need at most 6 pairwise differences: |n0-n1|, |n0-n2|, |n0-n3|, |n1-n2|, |n1-n3|, |n2-n3|

Simplified approach for hardware:
- Calculate diff0 = |num0 - num1|
- Calculate diff1 = |num0 - num2|
- Calculate diff2 = |num0 - num3|
- Find common divisor of all three differences
- Return all divisors of that common divisor (M > 1)

Note: Since inputs are small (1-100), differences are at most 99.
The result divisors will be 8-bit values.

Example: num0=6, num1=34, num2=38, num3=0 (scaled)
Differences: |6-34|=28, |6-38|=32, |34-38|=4
GCD of (28, 32, 4) = 4
Divisors of 4 > 1: 2, 4
Output: m0=2, m1=4, others=0
