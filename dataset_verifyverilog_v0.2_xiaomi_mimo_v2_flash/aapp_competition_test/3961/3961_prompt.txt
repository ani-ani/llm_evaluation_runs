Design a sequential Verilog module named 'maze_solver' that implements the Vasya's maze traversal problem.

The module computes the number of portal moves needed to exit a maze with 8 rooms (scaled down from the original problem's 1000 rooms).

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [2:0] p_i // The target room for the second portal (1 to i)
input [2:0] current_room_index // Current room index (1 to 8)

Outputs:
output reg [31:0] total_moves // Total number of portal moves (modulo 1000000007)
output reg done // High when computation is complete for current room

Behavioral Description:
The module implements the dynamic programming recurrence:
f[i] = (2 + 2 * f[i-1] - f[p[i]-1]) % MOD

Where:
- f[i] is the number of moves to reach room i+1 from room i (or similar DP state)
- p[i] is the portal target room (input p_i)
- MOD is 1000000007

State Machine:
- IDLE: Wait for start signal
- CALC: Perform the DP calculation for the current room index
- DONE: Latch result and signal completion

The module should maintain an internal memory (array) to store the DP values for rooms 0 to 8.

For room i (1 to 8):
If p_i == i: f[i] = f[i-1] + 2
Else: f[i] = (2 + 2 * f[i-1] - f[p_i-1]) % MOD

The result 'total_moves' should hold the value f[n] where n is the current_room_index.

Note: Use 32-bit arithmetic. The modulo operation should be handled carefully to avoid negative values by adding MOD before taking modulo.
