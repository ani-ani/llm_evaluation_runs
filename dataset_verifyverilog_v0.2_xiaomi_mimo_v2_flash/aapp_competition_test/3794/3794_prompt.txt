Design a sequential Verilog module named 'split_gcd' that determines if an array of integers can be partitioned into two non-empty groups with GCD=1 each.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [2:0] n // number of elements (2 to 8)
input [31:0] data [0:7] // array of up to 8 integers, each 32-bit

Outputs:
output reg possible // 1 if split exists
output reg [7:0] mask // bit mask: 0 means group 1, 1 means group 2
output reg done // high when computation complete

Specifications:
- Use state machine with states: IDLE, PROCESSING, CHECK_GCD, DONE
- Process array elements (n elements, max 8)
- Use brute-force search over all 2^n partitions
- For each partition, compute GCD of both groups
- GCD computation: sequential Euclidean algorithm for pairs
- Both groups must be non-empty (check mask != 0 and mask != (2^n-1))
- Both groups must have GCD = 1
- Latency: Maximum 256 clock cycles to explore all partitions
- Output mask: bit i=1 means data[i] goes to group 2
- Clock frequency: 100MHz

GCD Algorithm:
- Compute GCD of multiple numbers by iterating pairwise
- Use Euclidean algorithm: gcd(a,b) = gcd(b, a mod b)
- Result of 0 for empty group (treat as invalid)

Test Cases:
- Small integers (1-100)
- Fixed 8-element array, use only first n elements
- Examples: [2,3,6,7] -> mask=1100 (0-indexed) means group 1={6,7}, group 2={2,3}
