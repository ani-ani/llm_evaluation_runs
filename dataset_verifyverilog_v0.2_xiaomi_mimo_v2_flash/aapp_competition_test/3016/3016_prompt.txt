Design a sequential Verilog module named 'timmy_counter' that counts valid ball arrangements under adjacency and sequence constraints.

**Problem Adaptation**: 
- Maximum total balls (N) = 16.
- Maximum colors = 8.
- Max sequence length = 4.
- The module solves the problem using a hardware-friendly iterative DFS with state memoization (caching results of subproblems).

**Inputs**:
input clk: System clock.
input rst_n: Active-low reset.
input start: High for one cycle to start computation.
input [3:0] num_balls_total: Total number of balls.
input [2:0] num_colors: Number of distinct colors.
input [3:0] color_counts [0:7]: Array of counts for each color (0-16). Use 4 bits per color.
input [2:0] restricted_count: Number of restricted colors.
input [2:0] restricted_colors [0:7]: Array of color IDs that cannot touch.
input [2:0] sequence_len: Length of favorite sequence.
input [2:0] sequence_colors [0:7]: Array of color IDs in the sequence.

**Outputs**:
output reg [31:0] result: The number of valid arrangements (mod 1000000007).
output reg done: High when calculation is complete.

**Behavior**:
1. On `start` high, reset internal logic.
2. The module should implement a state machine to explore valid sequences.
3. Since pure recursion is hard in Verilog, implement an iterative approach using a stack of states (implemented as registers or BRAM). A state includes the remaining ball counts and the last placed ball color.
4. To handle the 'sequence preference' constraint: The algorithm must prioritize paths that complete the sequence. Specifically, if the last placed balls match the prefix of the sequence, the next ball is heavily weighted (or forced, depending on interpretation of 'as many times as possible'). In this hardware implementation, we will enforce that whenever a sequence can be completed, it *must* be completed immediately if the next ball choice allows it, to maximize occurrences.
5. **Memoization**: Store computed counts for a given set of remaining counts and last color to avoid re-computation. Use a hash or direct mapping if the state space fits.
6. Return the result modulo 1000000007.

**Latency**: Variable, but complete within 10,000 cycles for N=16.

**Constraint Logic**:
- Adjacency: If `last_color` is in `restricted_colors`, the `next_color` cannot be in `restricted_colors`.
- Sequence: If `last L-1` balls match `sequence[0...L-2]`, force `sequence[L-1]` next if available.
