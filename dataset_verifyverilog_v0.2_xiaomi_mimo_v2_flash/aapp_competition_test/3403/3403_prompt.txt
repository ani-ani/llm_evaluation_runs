Design a sequential Verilog module named 'primitive_search_steps' that computes the number of steps for a primitive string search algorithm.

The database contains exactly N=8 words, each word is exactly 8 characters (represented as 8-byte arrays). The query word is also 8 characters. Words consist of lowercase letters 'a'-'z' (ASCII 0x61-0x7A).

The algorithm steps:
1. Compare query word W with each database word sequentially
2. For each word, compute Longest Common Prefix (LCP) length
3. Steps for comparing W with one word = 1 (for the word comparison) + LCP length
4. Sum steps until W is found (exact match) or all words are compared
5. If W is found, stop and return accumulated steps

Module Interface:
- Input: clk, rst_n, start
- Input: query_word [8][7:0] - query word as 8 bytes
- Input: db_word_en - enable to load database words
- Input: db_word [8][7:0] - database word to load
- Input: db_word_index [2:0] - which database position (0-7) to load
- Output: result [15:0] - step count
- Output: done - computation complete

Internal Operation:
- Use state machine: IDLE, LOAD_DB, PROCESSING, DONE
- Load database: When db_word_en=1, store word at db_word_index
- Processing: Compare query with each db word until match or 8 words
- For LCP: Compare bytes in parallel, count matching prefix length
- Exact match: All 8 bytes must be identical
- Accumulate: steps = steps + 1 + lcp_length
- Stop on exact match

Latency: 100 clock cycles maximum (worst case: compare all 8 words)

Specify exact bit widths, state transitions, and LCP calculation logic.
