Design a sequential Verilog module named 'longest_repeated_substring' that finds the length of the longest substring that appears at least twice in a fixed-width input string.

Module Specifications:
- Input string length: 16 characters (N=16)
- Characters: lowercase English alphabet ('a'-'z'), encoded as 5-bit values (0-25)
- Input: A 16-element array of 5-bit values representing the string.
- Output: The length of the longest repeated substring (0 to 16).

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [4:0] char_in [0:15] // Input string characters (5-bit ASCII offset, 'a'=0)

Outputs:
output reg [4:0] max_len // Result: length of longest repeated substring
output reg done // High when computation is finished

Algorithm Description (Sequential FSM):
The module should iterate through possible substring lengths `len` from 15 down to 1. For each length, it checks if any substring of that length appears at least twice in the input string.

State Machine States:
1. IDLE: Wait for start signal. Reset max_len to 0.
2. CHECK_LEN: Initialize current length to 15.
3. CHECK_DUPLICATES: For the current length, iterate through all starting positions i (0 to N-len). Extract substring starting at i. Then compare with all substrings starting at j > i. If a match is found, set max_len to current length and transition to OUTPUT state.
4. NEXT_LEN: If no duplicates found for current length, decrement length. If length > 0, go back to CHECK_DUPLICATES. If length == 0, go to OUTPUT with max_len=0.
5. OUTPUT: Set done signal high.

Implementation Notes:
- Since N=16 is small, we can implement the substring extraction and comparison using nested loops in the FSM (unrolled or sequential).
- To avoid complex combinational logic, use a sequential approach for comparisons.
- Substring comparison logic: Compare character by character. If all characters match, it's a duplicate.
- Once a duplicate is found for a specific length, that length is the answer (since we start from longest).

Constraints:
- Clock frequency can be anything suitable for simulation.
- Reset is active low.
- The module must complete within a reasonable number of cycles (e.g., 1000 cycles for N=16).

Example:
Input: "sabcabcfabc" (mapped to indices) -> Result: 3 (substring "abc" appears at index 1 and 6).
Input: "abcdef" -> Result: 0.

The module should be synthesizable and verifiable with a cocotb testbench.
