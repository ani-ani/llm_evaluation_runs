Design a Verilog module named `sheldon_counter` that counts Sheldon numbers within a given range [X, Y]. A Sheldon number has a binary representation of the form (1^N 0^M)^k [1^N] (at least one run of ones, N, M > 0). 

Inputs:
input clk // Clock signal
input rst_n // Active low reset
input start // Start computation
input [63:0] range_start // X
input [63:0] range_end // Y

Outputs:
output reg [31:0] count // Number of Sheldon numbers found
output reg done // High when computation complete

Specification:
- The module should iterate through valid patterns of N (1 to 16), M (1 to 16), and total length up to 64 bits.
- For each valid (N, M, total_length), generate the binary number and check if it falls in [X, Y].
- Since this is a complex generation process, implement a state machine that iterates through N, M, and lengths.
- Use a helper combinational block to generate the candidate number from N, M, and length parameters.
- Assume 64-bit arithmetic for comparisons.
- Latency: Result valid after ~100k cycles (depending on implementation, use a reasonable bounded loop).
