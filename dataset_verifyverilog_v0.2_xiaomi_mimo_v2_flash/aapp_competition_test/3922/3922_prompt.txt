Design a sequential Verilog module named 'surgery_solver' that implements a solver for a 2x3 sliding puzzle (k=1, 6 tiles + 1 empty). The grid has 2 rows and 3 columns. Tiles are numbers 1-6, and 'E' is the empty space (represented internally as 0).

The legal moves are:
1. Left/Right: Always allowed.
2. Up/Down: Only allowed if the empty space is in column 0 (leftmost), column 2 (rightmost), or column 1 (center).

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start solving
input [5:0] grid_in [0:5] // Flattened grid input, index 0-2 is row 0, index 3-5 is row 1. 0 represents 'E'.

Outputs:
output reg [2:0] move_out // Encoded move: 000: none, 001: up, 010: down, 011: left, 100: right
output reg move_valid // High when move_out is valid
output reg done // High when puzzle is solved (1,2,3 in row 0; 4,5,6 in row 1) or failed

The module should operate as a state machine:
- IDLE: Wait for start signal.
- SOLVE: Process moves to reach the target state. It must check if the target is reachable (simple parity check or attempt to solve within a limited number of steps).
- DONE: Assert done signal.

Target State:
Row 0: 1, 2, 3
Row 1: 4, 5, 6

Note: This is a simplified version for k=1. The module should handle the specific geometry of a 2x3 grid.
