Design a sequential Verilog module named 'shortest_path_edge_counter' that counts how many shortest paths contain each edge in a small directed graph.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [3:0] node_count // number of nodes (1-8)
input [3:0] edge_count // number of edges (1-16)
input [3:0] edge_src [15:0] // source node for each edge
input [3:0] edge_dst [15:0] // destination node for each edge
input [7:0] edge_weight [15:0] // weight for each edge (0-255)

Outputs:
output reg [31:0] edge_usage [15:0] // number of shortest paths using each edge
output reg done // high when computation complete

Specify latency: Result valid 300 clock cycles after start asserted.
Use state machine with states: IDLE, LOAD_EDGES, COMPUTE_DISTANCES, COUNT_PATHS, DONE.

The algorithm:
1. Initialize distance matrix (8x8) with infinity (255) except dist[i][i] = 0
2. Fill distance matrix with edge weights (adjacency matrix)
3. Run Floyd-Warshall to compute all-pairs shortest distances
4. Count paths: For each pair (u,v), count shortest paths from u to v
5. For each edge e=(a,b), count paths that include it: sum over all u,v of (paths[u][a] * paths[b][v]) where dist[u][v] == dist[u][a] + weight(a,b) + dist[b][v]

Use 8-bit for node indices (0-7), 8-bit for distances (0-255 representing actual distances 0-255), 32-bit for path counts.

All internal computation happens in sequential logic with state machine control.
