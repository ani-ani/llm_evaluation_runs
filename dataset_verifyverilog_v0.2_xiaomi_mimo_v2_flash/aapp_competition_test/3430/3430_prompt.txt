Design a sequential Verilog module named 'min_transmission_cost' that computes the minimum transmission cost of connecting two tree networks.

The module works with fixed-size 8-node trees using adjacency matrices. The transmission cost between two nodes is the square of the distance (number of edges). Total cost is the sum over all unordered pairs.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [7:0] tree_a_nodes // number of nodes in tree A (1-8)
input [7:0] tree_b_nodes // number of nodes in tree B (1-8)
input [7:0] tree_a_adj [0:7] // adjacency matrix for tree A (8-bit rows)
input [7:0] tree_b_adj [0:7] // adjacency matrix for tree B (8-bit rows)

Outputs:
output reg [31:0] min_cost // minimum transmission cost
output reg done // high when computation complete

Specification:
- Latency: 200 clock cycles after start asserted
- Use state machine with states: IDLE, COMPUTE_DIST_A, COMPUTE_DIST_B, FIND_CENTER_A, FIND_CENTER_B, CALCULATE_COST, DONE
- Tree A and B are represented as adjacency matrices where bit i of row j is 1 if nodes i and j are connected
- The algorithm should:
  1. Compute all-pairs shortest paths for tree A using Floyd-Warshall (simplified for 8 nodes)
  2. Compute all-pairs shortest paths for tree B
  3. Find center node of each tree (node with minimum sum of distances to all other nodes)
  4. Calculate transmission cost: Cost = sum(dist_a^2) + sum(dist_b^2) + N*M + N*M * (center_dist_a^2 + center_dist_b^2 + 2*center_dist_a*center_dist_b)
  5. For simplicity, connect the two center nodes

- For 8 nodes, distances are 0-7, squared values fit in 10 bits
- Accumulate sums in 32-bit registers
- Output minimum cost as 32-bit integer

The module should implement:
1. Distance computation unit for tree A
2. Distance computation unit for tree B
3. Center finding logic
4. Cost calculation with proper accumulation
