Design a combinational Verilog module named 'triple_sum_counter' that counts ordered triples (i,j,k) with pairwise distinct indices where a[i] + a[j] = a[k].

Inputs:
input clk // clock signal
input rst_n // active-low reset  
input start // start computation
input [4:0] n // number of elements (max 8)
input [15:0] arr [0:7] // array of 8 signed 16-bit integers, values in [-50000, 50000]

Outputs:
output reg [31:0] count // total number of valid ordered triples
output reg done // high when computation complete

Specification:
- Implement with bounded computation (max 8 elements)
- Compute all combinations of indices (i,j,k) where 0 ≤ i,j,k < n
- Check if indices are pairwise distinct (i ≠ j, i ≠ k, j ≠ k)
- Check if arr[i] + arr[j] == arr[k]
- Count all valid ordered triples
- Result should be valid within 100 clock cycles of start assertion
- Use state machine with IDLE, COMPUTE, DONE states

Example:
N=4, arr=[1,2,3,4]
Valid triples: (0,1,2): 1+2=3, (1,0,2): 2+1=3, (0,2,1): 1+3=4, (2,0,1): 3+1=4
Result: 4
