Design a combinational Verilog module named 'wireless_coverage' that computes the minimum total cost to cover all corridors in a 2x3 grid.

Inputs:
input [5:0] router_mask // 6-bit vector: bit i=1 means router in cell i
// Cell mapping: cell (0,0)=bit0, (0,1)=bit1, (0,2)=bit2, (1,0)=bit3, (1,1)=bit4, (1,2)=bit5
input [5:0] router_costs // cost for each cell (unsigned 6-bit)
input [7:0] K // cellular hub cost (8-bit)

Outputs:
output [15:0] min_cost // minimum total cost

The module must compute the minimum cost by evaluating all possible router configurations (including the given mask) and finding the one with minimum total cost.

For each configuration:
1. Sum router costs for cells with routers
2. For each corridor (edge between adjacent cells):
   - Count incident routers (0, 1, or 2)
   - If count != 1, add K to cost
3. Total cost = router sum + (K * num_bad_corridors)

Corridors in 2x3 grid (5 horizontal, 4 vertical = 9 total):
Horiz: (0,0)-(0,1), (0,1)-(0,2), (1,0)-(1,1), (1,1)-(1,2)
Vertical: (0,0)-(1,0), (0,1)-(1,1), (0,2)-(1,2)

Use combinational logic only. The output should be the minimum cost across all 2^6 possible router configurations.
