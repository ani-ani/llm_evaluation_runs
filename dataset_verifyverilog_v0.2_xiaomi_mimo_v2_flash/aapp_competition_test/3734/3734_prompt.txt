Design a combinational Verilog module named 'calendar_checker' that determines if two consecutive months in a non-leap year can start on two specified days of the week.

The module takes two day names as 32-bit integer encodings (ASCII representations) and outputs a boolean result.

Logic:
1. Map day names to integer values 0-6 (monday=0, tuesday=1, ..., sunday=6). This can be done via a case statement or lookup based on the sum of ASCII values or specific characters.
2. Calculate the difference between the second day and the first day modulo 7: `diff = (day2 - day1) % 7`.
3. The possible lengths of months in a non-leap year are 28, 30, and 31 days. 
   - 28 % 7 = 0 (same day of week)
   - 30 % 7 = 2 (forward 2 days)
   - 31 % 7 = 3 (forward 3 days)
4. The module should output 1 (YES) if the calculated difference matches 0, 2, or 3. Otherwise output 0 (NO).

Inputs:
input [31:0] day1_ascii // First day name encoded as a 4-character ASCII string
input [31:0] day2_ascii // Second day name encoded as a 4-character ASCII string

Outputs:
output reg possible // 1 if such months exist, 0 otherwise

Implementation Details:
- Use 32-bit inputs to hold the ASCII string (e.g., "monday" fits in 32 bits if padded, or we can use specific bits).
- To simplify ASCII matching, we can check specific characters. For example, 'mon' vs 'tue' vs 'wed' vs 'thu' vs 'fri' vs 'sat' vs 'sun'.
- Since the inputs are variable length strings, but the prompt says they are exactly from the set, we can use the first few characters to distinguish.
- Let's use the first 3 characters to distinguish the days to fit in 24 bits.
- 'mon' = 0x6E6F6D, 'tue' = 0x657574, 'wed' = 0x646577, 'thu' = 0x756874, 'fri' = 0x697266, 'sat' = 0x746173, 'sun' = 0x6E7573.
- The module should perform the comparison and arithmetic entirely combinationally.
