Design a sequential Verilog module named 'knight_generator' that generates coordinates for n knights following a specific pattern that maximizes the final density after the knight placement process.

The module implements the following pattern discovered from the problem analysis:
- Group 1: ceil(n/3) knights at positions (2*i + 1, 3) for i = 0 to ceil(n/3)-1
- Group 2: floor(n/3)*2 + (n % 3) knights at positions (i, 0) for i = 0 to (remaining)-1
Actually, the pattern is: First place (n // 3) pairs: (2*i, 0), (2*i+1, 0), (2*i+1, 3), then handle remainder.

Simplified logic for hardware:
We will generate n knight positions using a state machine that produces coordinates iteratively.

Pattern based on test cases:
- For each block of 3 knights: (2*i, 0), (2*i+1, 0), (2*i+1, 3)
- Remainder knights: continue sequential pattern at y=0 or y=3

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start generation
input [9:0] n // Number of knights (1 to 1000, fits in 10 bits)

Outputs:
output reg [31:0] x // X coordinate of current knight
output reg [31:0] y // Y coordinate of current knight
output reg valid // High when x,y outputs are valid
output reg done // High when all n knights have been generated

Latency: 2*n + 4 clock cycles after start (initialization + iteration).

Use state machine with states: IDLE, INIT, GENERATE, DONE.

Internal logic:
- Counter 'knight_count' from 0 to n-1
- Counter 'block_index' for groups of 3
- Counter 'sub_pos' for position within a block of 3
- Logic to determine coordinates based on current counters

Coordinates mapping:
For knight index idx from 0 to n-1:
  Let block = idx / 3
  Let pos = idx % 3
  If pos == 0: x = 2*block, y = 0
  If pos == 1: x = 2*block + 1, y = 0
  If pos == 2: x = 2*block + 1, y = 3

For the remainder (when n not divisible by 3), continue the pattern.
