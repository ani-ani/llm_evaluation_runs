Design a sequential Verilog module named 'shuffling_game' that computes the minimal number of alternating Alice/Bob shuffles until deck returns to sorted order.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [2:0] n // number of cards (1-8)
input [7:0][7:0] alice_perm // Alice's permutation: alice_perm[i] = new position of card i
input [7:0][7:0] bob_perm // Bob's permutation: bob_perm[i] = new position of card i

Outputs:
output reg [15:0] result // minimal shuffles, or 0xFFFF for 'huge'
output reg done // high when computation complete

Behavior:
- Reset state to identity permutation
- On start, iterate shuffling: odd steps apply Alice, even steps apply Bob
- After each shuffle, check if permutation equals identity
- If identity found, output step count (1-based)
- If step count exceeds 128, output 0xFFFF (huge)
- Use state machine: IDLE, INITIAL_CHECK, SHUFFLE, CHECK_IDENTITY, DONE, HUGE
- Latency: Maximum 130 clock cycles after start

Identity permutation: card at position i goes to position i
Composition: (A o B)[i] = A[B[i]] where A, B are permutations
