Design a combinational Verilog module named 'optimize_harvard' that computes instruction count for a Harvard architecture program with banked memory.

Module Specifications:
- Purpose: Calculate cost given a fixed variable-to-bank assignment
- Inputs:
  input [3:0] b // number of banks (1-13)
  input [5:0] program_length // length of flattened program
  input [5:0] program [0:31] // flattened program: array of variable indices (0 unused)
  input [3:0] bank_assignment [0:13] // mapping: bank_assignment[i] = bank for variable Vi (i=1..13)

- Outputs:
  output [31:0] total_cost // total instruction count

- Behavior: Purely combinational
  Initialize BSR to undefined (15)
  For each program element i < program_length:
    var = program[i]
    bank = bank_assignment[var]
    if bank == 0: cost += 1 (direct access)
    else if current_BSR == bank: cost += 1 (BSR matches)
    else: cost += 2 (set BSR + access), update BSR = bank
  Return total_cost

- Constraints: Max 32 program elements, variables indexed 1-13
