Design a sequential Verilog module named 'frog_tower' that finds the largest tower of frogs and the smallest position where it occurs.

Problem Adaptation:
- Maximum 16 frogs (instead of 40)
- Positions scaled to 8-bit values (0-255) for feasibility
- Jump distances are small primes (2, 3, 5, 7, 11, 13)
- A tower exists at position P if multiple frogs can reach P by jumping prime distances
- Each frog i starts at position x_i and jumps by d_i to reach P if P >= x_i and (P - x_i) is a multiple of d_i

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [5:0] frog_count // number of frogs (1-16)
input [15:0] frog_data [0:15] // packed frog data: [15:8]=initial pos, [7:0]=jump dist

Outputs:
output reg [7:0] tower_position // smallest position with max frogs
output reg [7:0] tower_size // size of the tower (max frogs at one position)
output reg done // high when computation complete

Specification:
1. State Machine: IDLE, LOAD_FROGS, FIND_MAX_TOWER, DONE
2. Algorithm: Find all positions where frogs can land (up to 255), count frogs at each position
3. For each position P from 0 to 255:
   - Check each frog: if (P >= x_i) && ((P - x_i) % d_i == 0), frog reaches P
4. Track the position with maximum frog count; break ties by smaller position
5. Latency: 1024 clock cycles (256 positions * 4 cycles per position)

Implementation Details:
- Use combinational logic for modulus check (small divisors)
- Store frog data in register array
- Use counter for position scanning
- Use temporary registers to count frogs per position

Example: Frog 1 at x=0, d=2 can reach positions 0,2,4,6,...
Frog 2 at x=1, d=2 can reach positions 1,3,5,7,...
Frog 3 at x=3, d=3 can reach positions 3,6,9,12,...
At position 3: frogs 2 and 3 can meet (tower size 2)
At position 6: frogs 1 and 3 can meet (tower size 2)
