Design a sequential Verilog module named 'pacman_ice_cleaning' that simulates the PacMan's Ice Cleaning algorithm.

**Module Specifications:**
- **Inputs:**
  - `clk`: System clock
  - `rst_n`: Active-low reset
  - `start`: Start signal (pulse high to begin)
  - `input [3:0] r`: Number of rows (1-8)
  - `input [3:0] c`: Number of columns (1-8)
  - `input [3:0] start_i`: Starting row (1-8)
  - `input [3:0] start_j`: Starting column (1-8)
  - `input [5:0] n`: Number of steps (1-64)

- **Outputs:**
  - `output reg [7:0] ram_write_addr`: Address for the 8x8 grid RAM (0 to 63)
  - `output reg [7:0] ram_write_data`: Data to write to RAM ('A'-'Z' or '@')
  - `output reg ram_write_en`: Write enable for RAM
  - `output reg done`: High when computation is finished and RAM contains valid output

- **Behavior:**
  The module uses a state machine (IDLE, EXEC_LOOP, MOVE_STEPS, WAIT_STATE) to execute the algorithm. 
  1. Initialize grid (white/dot) and Zamboni position/direction (Up) and color ('A').
  2. Outer loop runs `numSteps` times (parameter N).
  3. Inner loop moves `stepSize` times. In each move:
     - Update current cell color (overwrite).
     - Move position (apply wrapping: `pos = (pos + dir + dim) % dim`).
     - Increment color (A-Z wrap).
     - Decrement remaining steps.
  4. After moving `stepSize` steps:
     - Rotate direction 90 deg clockwise.
     - Increment `stepSize`.
     - Decrement outer loop counter.
  5. When loops finish, overwrite final cell with '@'.
  6. Write results to RAM. 

- **Constraints:**
  - Use combinational logic for direction rotation and coordinate wrapping.
  - State machine required to handle the nested loops.
  - Output `ram_write_addr` and `ram_write_data` for verification (testbench will build the grid).
  - Assume 8x8 grid size max.
