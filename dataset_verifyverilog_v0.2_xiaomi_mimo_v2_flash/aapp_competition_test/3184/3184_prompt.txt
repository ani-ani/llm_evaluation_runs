Design a combinational Verilog module named 'camera_coverage' that finds the minimum number of cameras needed to cover all walls of a convex polygon building.

Inputs:
input clk // Clock signal for sequential operation
input rst_n // Active-low reset
input start // Start computation
input [2:0] n // Number of walls (3-8)
input [2:0] k // Number of cameras (1-8)
input [7:0] a_i [0:7] // Start wall of each camera coverage range
input [7:0] b_i [0:7] // End wall of each camera coverage range

Outputs:
output reg [3:0] result // Minimum number of cameras needed
output reg done // High when computation complete
output reg impossible // High if coverage impossible

Behavioral Description:
The module implements a greedy algorithm to solve the minimum camera coverage problem:
1. Pre-process: For each camera, normalize the coverage interval to handle wrap-around cases:
   - If a_i <= b_i: covers [a_i, b_i]
   - If a_i > b_i: covers [a_i, n] and [1, b_i] - split into two intervals
2. Expand to full coverage set: Create a bit mask for each camera representing which walls it covers
3. Find minimum subset using iterative search:
   - Try all combinations of cameras from 1 to k
   - Check if subset covers all walls (bitwise AND of coverage masks equals (1<<n)-1)
   - Return minimum size needed
4. If no combination covers all walls, set impossible flag

Use state machine: IDLE → PREPROCESS → SEARCH → DONE
Wall numbering: 1 to n (maps to bit positions 0 to n-1)
Maximum cycles: ~500 (bounded by 2^8 search space)

Note: Walls are numbered 1..n in input, but internally mapped to bits 0..n-1 for coverage masks.
