Design a Verilog module that solves the Challenge 24 problem for 4 numbers. The module should evaluate all possible arithmetic expressions (+, -, *, /) with all possible parenthesizations and permutations of the input numbers to find the minimum grade expression that equals 24.

**Interface Specification:**
- Input: Four 8-bit numbers: a, b, c, d
- Output: 8-bit grade (minimum grade found) or 8'hFF to indicate impossible
- Control: Start signal (1 cycle), done signal (asserted when computation complete)
- Clock and reset: Standard synchronous design

**Implementation Details:**
- Use a state machine to iterate through all permutations (24), all operator combinations (64), and all 5 expression trees
- Each expression tree corresponds to a parenthesization pattern
- Track minimum grade where expression equals 24
- Grade = parentheses_count + 2 * inversions_count
- Division only allowed if result is integer (check remainder)
- Output 8'hFF if no expression equals 24

**Constraints:**
- Numbers: 8-bit unsigned (1-100)
- All arithmetic is 16-bit internally to prevent overflow
- Division: check remainder = 0
- Maximum states: ~1000 cycles

```verilog

    input wire clk,
    input wire rst_n,
    input wire start,
    input wire [7:0] a, b, c, d,
    output reg [7:0] grade,
    output reg done
);
```
