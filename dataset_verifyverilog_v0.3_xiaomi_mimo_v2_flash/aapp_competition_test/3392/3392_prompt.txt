Design a Verilog module that computes the largest connected component in a small grid where cells have equal sum of initial height and growth speed.

Module name: largest_connected_component
Parameters:
  N = 4 (grid size)
  DATA_WIDTH = 8 (bit width for h and v)
  SUM_WIDTH = 9 (bit width for h+v)
  SIZE_WIDTH = 8 (bit width for output size)

Inputs:
  clk: clock signal, rising edge triggered
  rst_n: active-low synchronous reset
  start: start pulse, asserted for one clock cycle to begin computation
  For each cell (i,j) where i=0..3, j=0..3:
    h_{i}{j}: [DATA_WIDTH-1:0] initial height of tree at (i,j)
    v_{i}{j}: [DATA_WIDTH-1:0] growth speed of tree at (i,j)

Outputs:
  max_size: [SIZE_WIDTH-1:0] size of the largest connected component
  done: asserted high for one cycle when computation is complete

Behavior:
  1. On reset (rst_n=0), all internal state is cleared, done=0, max_size=0.
  2. On start pulse (start=1 for one cycle), the module begins computation.
  3. The module first computes for each cell the value s_{i,j} = h_{i,j} + v_{i,j} (unsigned addition, result truncated to SUM_WIDTH bits, but assume no overflow beyond SUM_WIDTH).
  4. Then it finds the largest 4-connected component (up, down, left, right) of cells that have the same s value.
  5. The result max_size is the size (number of cells) of that largest component.
  6. When finished, the module asserts done for one cycle and presents the result on max_size.
  7. The computation should complete within a bounded number of cycles (e.g., 1000 cycles). The exact implementation details are left to the designer, but a flood-fill algorithm using a stack is recommended.

Timing:
  - The module is sequential, using clk.
  - start must be asserted for one cycle while rst_n is high.
  - done will be asserted at most 1000 cycles after start.
  - The result max_size is valid when done is asserted.

Additional notes:
  - The grid size is small (4x4), so internal storage can be implemented with registers.
  - The algorithm should be robust to handle any input values.
  - The module should not use any external memory; all computation is internal.
