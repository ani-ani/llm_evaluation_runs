Create a Verilog module named `distinct_gcd_count` that computes the number of distinct GCD values over all subarrays of a sequence of up to 8 integers, each integer being 8 bits. The module should have the following interface:

Inputs:
- arr_0, arr_1, ..., arr_7: 8-bit unsigned integers, representing the sequence elements. Only the first `len` elements are valid.
- len: 4-bit unsigned integer, number of valid elements (1 to 8).

Outputs:
- result: 8-bit unsigned integer, the number of distinct GCD values.

The module should be purely combinational. It must compute the GCD for every subarray of the sequence (contiguous subarrays of length at least 1). For each subarray, compute its GCD and collect all distinct GCD values. The number of distinct values is the output.

Implementation guidelines:
- Implement a combinational `gcd` function for 8-bit unsigned integers using the Euclidean algorithm with 8 iterations.
- Use a 256-bit register `mask` to record which GCD values appear. For each GCD value `g`, set the `g`-th bit of `mask` to 1.
- Use nested `for` loops to iterate over all possible subarrays. Outer loop variable `i` from 0 to `len-1`, inner loop `j` from `i` to `len-1`.
- Inside the inner loop, compute the current GCD (starting with `arr[i]` and then updating with `arr[j]` for each `j`). Set the corresponding bit in `mask`.
- After all subarrays are processed, compute the population count (number of set bits) of `mask`. The output `result` should be this count.
- The module must not contain any sequential logic (no clock, no reset, no start signal). It is a pure combinational block.

Example: For inputs arr_0=9, arr_1=6, arr_2=2, arr_3=4, len=4, distinct GCDs are 1,2,3,4,6,9 -> output 6.
For arr_0=9, arr_1=6, arr_2=3, arr_3=4, len=4, distinct GCDs are 1,2,3,4,9 -> output 5.

Write the complete Verilog code for the module.
