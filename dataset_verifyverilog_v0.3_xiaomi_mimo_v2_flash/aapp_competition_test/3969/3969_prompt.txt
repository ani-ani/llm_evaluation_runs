Design a Verilog module that computes the minimum number of plants to replant. The module has the following interface:

Inputs:
- clk: clock signal
- rst_n: active-low reset
- start: start signal (pulse for one cycle to begin computation)
- n: 8-bit input, the actual number of plants (1 to 16)
- species: array of 16 8-bit inputs. The first n elements are the species sequence in order from left to right. The remaining elements are unused.

Outputs:
- result: 8-bit output, the minimum number of plants to replant
- done: indicates computation is complete (high for one cycle)

The module should compute the length of the longest non-decreasing subsequence (LNDS) of the species sequence, then output n - LNDS.

The module should use a state machine to compute the DP for LNDS. The algorithm:
  dp[0] = 1
  for i from 1 to n-1:
    dp[i] = 1
    for j from 0 to i-1:
      if species[j] <= species[i] and dp[j] + 1 > dp[i]:
        dp[i] = dp[j] + 1
  result = n - max(dp)

The state machine should have the following states:
  IDLE: wait for start
  INIT: initialize for i=0 (dp[0]=1, max_dp=1)
  OUTER_LOOP: for each i from 1 to n-1
  INNER_LOOP: for each j from 0 to i-1, compare species and update current_dp
  UPDATE_DP: store dp[i] and update max_dp
  CALC_RESULT: compute result = n - max_dp
  DONE: set done high for one cycle

The module should have parameters MAX_N=16 for the maximum number of plants.

The module should be designed to work for n from 1 to 16.

Example of module declaration:

module min_replant (
    input clk,
    input rst_n,
    input start,
    input [7:0] n,
    input [7:0] species [0:MAX_N-1],
    output reg [7:0] result,
    output reg done
);

parameter MAX_N = 16;

endmodule
