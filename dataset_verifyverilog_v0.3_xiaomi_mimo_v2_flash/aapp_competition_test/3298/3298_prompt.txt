Design a Verilog module named 'unsorted_checker' that checks if a given permutation is entirely unsorted.

INTERFACE SPECIFICATION:

Inputs:
- clk: Clock signal (rising edge triggered)
- rst_n: Active-low synchronous reset
- start: Start pulse (assert for 1 cycle to begin check)
- len[3:0]: Number of valid elements in the array (1 to 8)
- arr_0, arr_1, ..., arr_7: Each 8 bits, the permutation elements. Only the first len elements are valid.

Outputs:
- done: Asserted high for 1 cycle when the check is complete
- is_unsorted: 1 if the permutation is entirely unsorted, 0 otherwise

Functionality:
- When start is asserted, the module checks the permutation defined by arr_0..arr_{len-1}.
- An element at index k is considered sorted if:
  - For all j < k, arr_j <= arr_k
  - For all j > k, arr_j >= arr_k
- The permutation is entirely unsorted if no element is sorted.
- The result is registered on the next clock cycle (one‑cycle latency).
- After done is asserted, the module returns to the IDLE state.

Implementation:
- Use a two‑state FSM (IDLE, COMPUTE).
- The combinational logic iterates over all k (0 to len-1) and checks left/right conditions.
- If any element is sorted, set is_unsorted = 0; else set is_unsorted = 1.
- The design must be fully synthesizable for small n (≤8).

Timing:
- Start pulse: one cycle.
- Done: one cycle, one cycle after start.
- Total latency: two cycles.

Note: The module only checks a single permutation; the testbench will enumerate all permutations and count those that are entirely unsorted.
