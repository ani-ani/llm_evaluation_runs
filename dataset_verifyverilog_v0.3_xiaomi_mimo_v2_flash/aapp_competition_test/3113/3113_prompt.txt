Module: cloud_compare

Inputs:
  clk: Clock signal (rising edge triggered)
  rst_n: Active-low synchronous reset
  n: 4-bit number of Garry's triangles (0-8)
  m: 4-bit number of Jerry's triangles (0-8)
  garry_triangles: 3D array [0:7][0:2][0:1] of 6-bit values (scaled coordinates x2)
  jerry_triangles: 3D array [0:7][0:2][0:1] of 6-bit values (scaled coordinates x2)

Outputs:
  same: 1-bit result (1 if identical cloud cover)
  done: 1-bit flag (asserted when computation complete)

Behavior:
  - Scales original coordinates by 2 (Q2.4 fixed-point)
  - Rasterizes triangles on 16x16 grid using barycentric method
  - Compares resulting bitmaps
  - Takes ~8192 cycles for full computation
  - Implements state machine with proper reset sequence
