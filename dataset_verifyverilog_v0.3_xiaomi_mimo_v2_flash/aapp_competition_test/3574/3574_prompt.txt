Module: magical_subarray

Description: Finds longest magical subarray within query range. Magical means all values between first and last element inclusive.

Interface:
  Inputs:
    - clk: Clock signal (rising edge)
    - rst_n: Active-low synchronous reset
    - start: Start pulse (1 cycle)
    - arr_0 to arr_7: 8-bit array elements
    - L, R: 4-bit query range (1-indexed, 1-8)
  Outputs:
    - result: 4-bit length of longest magical subarray (1-8)
    - done: High for 1 cycle when result ready

Behavior:
  On reset: result=0, done=0, state=IDLE
  On start: Process query [L,R], compute max magical subarray length
  Algorithm: For all i,j with L-1 ≤ i ≤ j ≤ R-1, check if subarray arr[i..j] is magical (all elements between arr[i] and arr[j]). Track max length.
  Timing: Completes within 200 cycles max

Testbench Requirements:
  - Scale to N=8, Q=4 queries
  - Write array elements individually using arr_i ports
  - Test cases:
    1. arr=[5,4,3,3,2,0,0,0], query [1,2] → result=2
    2. arr=[5,4,3,3,2,0,0,0], query [1,1] → result=1
    3. arr=[5,4,3,3,2,0,0,0], query [2,4] → result=3
    4. arr=[6,6,5,1,6,2,0,0], query [4,5] → result=2
  - Use sequential interface with clk, rst_n, start, done
  - Clamp values to 8-bit range
  - Verify done signal and result on completion
