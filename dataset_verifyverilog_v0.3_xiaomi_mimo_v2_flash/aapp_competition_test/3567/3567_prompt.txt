Write a Verilog module that solves the character creation problem. The module should have parameters K (number of features, up to 20) and N (maximum number of players, up to 8). Inputs: clk, rst_n, start, str0..str7 (each K bits), n (4-bit number of valid strings). Outputs: result (K bits), done. The module should on start load the input strings, then iterate over all possible 2^K strings, for each compute the minimum Hamming distance to the given strings, and keep the candidate with the largest minimum distance. Use a state machine with states: IDLE, INIT, LOOP_INNER, COMPARE, DONE. Implement popcount using a combinational function. Provide the full module code.
