Module: barney_probability

Description:
Computes probability that key is under middle cup after n turns.
Outputs p/q as irreducible fraction modulo 10^9+7.

Parameters:
  MOD = 1000000007
  INV2 = 500000004  // 2^(-1) mod MOD
  INV3 = 333333336  // 3^(-1) mod MOD

Inputs:
  clk         : Clock, rising edge
  rst_n       : Active-low synchronous reset
  start       : Start pulse (1 cycle)
  n_in        : 8-bit input, value 1-255

Outputs:
  p_out       : 32-bit numerator (mod MOD)
  q_out       : 32-bit denominator (mod MOD)
  done        : Asserted high when result valid (1 cycle)

Functionality:
1. On start, capture n_in and compute parity (0=even, 1=odd)
2. Compute b = 2^n_in mod MOD using binary exponentiation
3. Compute q = b * INV2 mod MOD (this is 2^(n-1))
4. Compute flag = 1 if even, MOD-1 if odd
5. Compute p = (q + flag) * INV3 mod MOD
6. Assert done and present p_out, q_out

State Machine:
  IDLE -> EXP_LOOP -> COMPUTE -> DONE

Timing:
  - Reset requires ≥2 cycles
  - Computation completes in ≤32 cycles for n≤255
  - done pulses high for 1 cycle
  - Result valid on same cycle as done=1
