Create a Verilog module for Vasya's weather prediction method. The module should check if the given sequence of temperatures forms an arithmetic progression and predict the next day's temperature.

Module Name: weather_prediction

Interface Specification:

Inputs:
  - clk: Clock signal (rising edge triggered)
  - rst_n: Active-low synchronous reset
  - start: Start pulse (assert for 1 cycle to begin computation)
  - data_in [10:0]: 11-bit signed temperature input (range -1000 to 1000)
  - n [6:0]: 7-bit unsigned number of days (2-100)

Outputs:
  - result [15:0]: 16-bit signed predicted temperature
  - done: Asserted high for 1 cycle when prediction is ready

Behavior:
  - When start is asserted, the module expects n temperatures to be provided sequentially, one per clock cycle
  - The module stores the first temperature (t0) and second temperature (t1) to compute common difference d = t1 - t0
  - For each subsequent temperature, it checks if (current - previous) equals d
  - If all differences equal d, result = last_temp + d
  - If any difference doesn't match d, result = last_temp
  - done is asserted when the prediction is ready (after n clock cycles from start)

Timing:
  - Assert start for 1 clock cycle
  - Provide n temperatures in the next n cycles, one per cycle on data_in
  - done will be high in the cycle after the last temperature is received
  - Sample result on the same cycle done is high

Reset behavior:
  - On rst_n=0: All state is cleared, done=0, result=0
  - Minimum 2 clock cycles of reset required

Implementation Notes:
  - Use a state machine with states: IDLE, READING, DONE
  - Internal registers needed: t0, t1, last_temp, d, counter, arithmetic_flag
  - The module should handle 11-bit signed inputs and 16-bit signed output to accommodate extreme cases
