Design a Verilog module that takes a 10-bit input n (2 ≤ n ≤ 1000) and outputs a 64-bit fixed-point Q32.32 number representing the expected total number of gifts taken out. The module should compute the harmonic sum H_n = Σ_{i=1}^{n} 1/i using integer division of (2^32) by i, then multiply by n. Use combinational logic.

Module interface:
  input [9:0] n;
  output [63:0] result;

Example for n=2: H_2 = 1 + 1/2 = 1.5, expected = 2 * 1.5 = 3.0. In Q32.32, this is 3 * 2^32 = 0xC00000000.

The module should be synthesizable.
