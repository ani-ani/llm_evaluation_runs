Design a combinational Verilog module named 'max_rectangle_finder' that finds the largest possible rectangle with given aspect ratio containing a specified point.

Inputs:
input [7:0] n,        // grid width (1-255)
input [7:0] m,        // grid height (1-255)
input [7:0] x,        // point x-coordinate (0-n)
input [7:0] y,        // point y-coordinate (0-m)
input [7:0] a,        // ratio numerator (1-255)
input [7:0] b,        // ratio denominator (1-255)

Outputs:
output [7:0] x1,     // rect left
output [7:0] y1,     // rect bottom
output [7:0] x2,     // rect right
output [7:0] y2      // rect top

Behavior:
1. Compute scale = min(n/a, m/b) using integer division
2. Calculate rect_width = a * scale, rect_height = b * scale
3. Ideal center: cx = x, cy = y
4. Compute x1 = max(0, cx - rect_width/2)
   If x1 + rect_width > n: x1 = n - rect_width
5. Compute y1 = max(0, cy - rect_height/2)
   If y1 + rect_height > m: y1 = m - rect_height
6. Output x1, y1, x1+rect_width, y1+rect_height
