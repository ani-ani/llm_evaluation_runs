Design a Verilog module named 'rook_attack_counter' that tracks rook moves and calculates attacked fields.

Module interface:
module rook_attack_counter(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start_move, // Pulse high to start processing
  input [1:0] incoming_r, // New row (2 bits for N=4)
  input [1:0] incoming_c, // New column
  input [7:0] incoming_power, // Rook power (8-bit max 255)
  input [1:0] old_r, // Old position (use 0,0 if placement)
  input [1:0] old_c, // Old column
  output reg [4:0] attacked_count, // Number attacked (0-16)
  output reg done // High when result ready
);

Behavior:
- Maintains 4 rook positions (2-bit row/column) and 8-bit powers
- When start_move pulses high:
  1. Remove rook at old_r/old_c (if any)
  2. Add rook at incoming_r/incoming_c with new_power
- Then computes attacked fields for all 16 board locations:
  For each field (r,c): XOR all row r and column c rook powers
    (excluding self if rook present there)
- Counts fields where XOR != 0
- Latency: 16 cycles (1 per field) after start_move.
- After computation: attacked_count valid and done pulses high for 1 cycle.

Storage implementation:
- Register arrays for rook storage (4 entries)
- Use FSM with states: IDLE | REMOVE_OLD | ADD_NEW | COMPUTE | DONE",
