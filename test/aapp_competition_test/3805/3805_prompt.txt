Design a sequential Verilog module named 'wire_untangle' that processes a 16-character input sequence to determine if wires can be untangled.

Inputs:
input clk,        // clock signal
input rst_n,      // active-low reset
input start,      // start processing
input [15:0] data, // 16-bit input (two bits per char: '0' = "-", '1' = "+")

Outputs:
output reg done,  // high when processing completes
output reg result // 0 = No, 1 = Yes

Behavior:
1. On reset or when start=0, the module is idle
2. When start=1:
   - Read 8 characters (data[1:0], data[3:2], ..., data[15:14])
   - Process characters in order using a stack algorithm:
     * For each character: push if stack empty/top != char, else pop
   - After 8 cycles, set done=1 and result=1 if stack empty, else result=0
3. Stack max depth = 8 (uses 4-bit depth counter)

Timing:
- Output valid 8 cycles after start assertion
- Use states: IDLE, PROCESSING, DONE
