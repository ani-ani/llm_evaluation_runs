Design a combinational Verilog module named 'rival_sequence_sorter' that sorts up to four RPS sequences by their approximate appearance likelihood in the rival's moves. Each sequence is represented using:
- 2-bit length field (1-4), where 0 indicates unused entry
- 8-bit packed format for up to 4 characters (2 bits/char: 'R'=00, 'P'=01, 'S'=10)

Module interface:
module rival_sequence_sorter(
  input [3:0] n,             // Number of rounds (1-8)
  input [1:0] len0,          // Length of each sequence (1-4, 0=unused)
  input [7:0] seq0,          // Packed sequence (LSB=first char)
  input [1:0] len1, 
  input [7:0] seq1, 
  input [1:0] len2, 
  input [7:0] seq2, 
  input [1:0] len3, 
  input [7:0] seq3, 
  output reg [1:0] sorted_indices [0:3]  // Output indices in sorted order (highest to lowest)
);

Behavioral description:
1. For each sequence, calculate score = (n - len_i + 1) * 3^(4-len_i):
   - len=1: *81 (3^4) | len=2: *27 (3^3) | len=3: *9 | len=4: *3
   - len=0: score=0
2. Sort the sequence indices (0-3) by descending score. For equal scores, lower index comes first.
3. Module must be purely combinational - no clocks or resets required.
4. Implement with parallel comparison: all scores computed simultaneously.

Scoring examples:
- n=3,seq_len=2: score=2*27=54
- n=8,seq_len=4: score=(8-4+1)*3=5*3=15
