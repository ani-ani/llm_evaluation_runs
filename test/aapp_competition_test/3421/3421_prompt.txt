Design a Verilog module named 'optimal_subsequence' that finds the continuous subsequence of minimum length k with maximum success rate (1s/0s ratio).

Module interface:
module optimal_subsequence(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // pulse high to start computation
  input [3:0] k, // min subsequence length (1-8)
  input [15:0] data, // 16-bit input string (0=wrong, 1=correct)
  output reg [3:0] first_idx, // 1-based start index (4-bit: 1-16)
  output reg [3:0] length, // subsequence length (4-bit: 1-16)
  output reg done // high when computation completes
);

Behavioral description:
1. On start pulse, find all continuous subsequences of length >= k.
2. Calculate success rate as (sum of 1s)/length for each subsequence.
3. Track the subsequence with maximum success rate (for ties: prefer longer length then earlier start).
4. Sequential implementation: use state machine to iterate through possible lengths from k to 16, then through start positions.
5. Compute prefix sums in first phase to optimize calculation.
6. Output valid when done=1, 16 cycles after start (worst-case latency).
