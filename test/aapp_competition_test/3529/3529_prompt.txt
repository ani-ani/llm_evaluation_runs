Design a sequential Verilog module named 'spanning_tree_k_blue' that determines if an undirected graph (up to 8 nodes) has a spanning tree with exactly k blue edges.

Inputs:
input clk              // clock signal
input rst_n            // active-low reset
input start            // pulse high to begin computation
input [2:0] n          // number of nodes (2-8)
input [3:0] m          // number of edges (1-16)
input [2:0] k          // target blue edges (0-7)
input [15:0][7:0] edges  // packed edge data: {color[7], unused[6:3], node1[2:0], node0[2:0]}
                         // R=0, B=1, nodes are 3-bit indices (0-7)

Outputs:
output reg result      // 1=possible, 0=impossible
output reg done        // high when computation completes

Behavior:
1. On reset, set result=0, done=0
2. When start pulses high:
   a. Parse input edges into internal representation
   b. Compute min_blue: Minimum possible blue edges using Union-Find favoring Red edges
   c. Compute max_blue: Maximum possible blue edges using Union-Find favoring Blue edges
   d. Set result = (min_blue <= k <= max_blue) ? 1 : 0
   e. Assert done after 32 clock cycles
3. Done remains high until next reset or start.

Implementation notes:
- Use two Union-Find instances (one min, one max)
- Initialize Union-Find arrays on start
- Edge processing order doesn't matter for min/max bounds
- Latency fixed at 32 cycles (sufficient for 8-node graphs)
