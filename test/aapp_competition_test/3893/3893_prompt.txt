Design a combinational Verilog module named 'count_separating_roads' that determines how many roads separate two points in a plane. The module takes two coordinate points (home and university) and up to 8 road definitions.
Module interface:
module count_separating_roads(
  input signed [15:0] x1,  // Home x-coordinate (16-bit signed)
  input signed [15:0] y1,  // Home y-coordinate (16-bit signed)
  input signed [15:0] x2,  // University x-coordinate (16-bit signed)
  input signed [15:0] y2,  // University y-coordinate (16-bit signed)
  input signed [15:0] a [0:7],  // Road coefficients (8 elements)
  input signed [15:0] b [0:7],
  input signed [15:0] c [0:7],
  output reg [3:0] count   // Separation count (0-8 roads)
);

Behavioral description:
For each road i (0-7), compute two values: home_value = a[i]*x1 + b[i]*y1 + c[i] and university_value = a[i]*x2 + b[i]*y2 + c[i]. If the signs of these two values are different (using MSB as sign indicator), increment the count. Roads with zero coefficients should be ignored (per problem guarantees). The module should process all 8 roads in parallel using combinational logic. Output count should be the total number of roads where the home and university lie on opposite sides.

Implementation note: Use sign bits (home_value[15] ^ university_value[15]) to detect opposite sides and sum all valid cases.
