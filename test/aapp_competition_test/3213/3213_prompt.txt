Design a sequential Verilog module named 'bat_spell_optimizer' that selects spell steps to maximize final value mod 2^S. 
Module interface:
module bat_spell_optimizer(
  input clk, // system clock
  input rst_n, // active-low reset
  input start, // pulse high to begin optimization
  input [3:0] S, // strength (1-15, 4-bit width)
  input [7:0] steps, // 8-step sequence (0=+, 1=x, 1 bit per step)
  output reg [7:0] result, // optimized step sequence (0=o, 1=keep)
  output reg done // high when computation complete
);

Behavioral description:
- On reset: result=0, done=0
- When start=1: Begin processing steps using following rules:
  1. State machine tracks current power (4-bit value mod 2^S)
  2. For each step in sequence (MSB first):
      - Option 1: Keep step (update power +=1 or *=2 mod 2^S)
      - Option 2: Skip step (power unchanged)
  3. Choose option that maximizes final power (break ties by preferring keeping steps)
- After processing all 8 steps:
   - Generate result pattern (1=keep, 0=skip) based on optimal path
   - Assert done=1
- Latency: Result valid 16 clock cycles after start (2 cycles per step)
- Power calculation: Initial power = 1
- Implementation suggestion: Use pipeline stages or state machine with step counter

Acceptable simplifications:
- Fixed input size (8 steps)
- Limited strength S (4 bits)
- Final result selection based on maximum modulo value

Format notes:
- steps[7:0] format: step0=bit7 (first), step7=bit0 (last)
- result[7:0] format: bit7=step0 decision, bit0=step7 decision (1=keep)
- All power calculations done modulo 2^S
