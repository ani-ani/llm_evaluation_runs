Design a combinational Verilog module named 'dice_reroll_optimizer' that calculates the optimal number of dice to re-roll.

Inputs:
  input [2:0] K,           // Number of dice (2 to 6)
  input [5:0] T,           // Target sum (K <= T <= 36)
  input [17:0] first_roll,  // 6 dice values (3 bits each): first_roll[2:0]=die0, [5:3]=die1, ..., [17:15]=die5

Output:
  output reg [2:0] best_r  // Optimal number of dice to re-roll (0-6)

Behavior:
1. For each possible r (0 to current K):
   a) Evaluate all possible combinations of K-r dice to keep
   b) For each combination:
      i) Sum kept dice
      ii) Compute S = T - sum_keep (required sum from rerolled dice)
      iii) If r <= S <= 6*r, add precomputed rank(S,r) to r_score
2. Select smallest r with highest score (precomputed rank table represents roll probability approximation)

Precomputed rank values should be hardcoded using Case statements for r=0-6 and S_reroll ranges. Output best_r in same cycle.
