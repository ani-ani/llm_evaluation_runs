Design a sequential Verilog module named 'love_potion_counter' that counts contiguous segments of chemicals with sum equal to a power of k.
Inputs:
  input clk, // clock
  input rst_n, // active-low reset
  input start, // pulse high to start computation
  input [7:0] a [0:7], // 8 chemicals (8-bit signed)
  input [7:0] k // base for power calculations (8-bit signed)
Outputs:
  output reg [15:0] count, // total valid segments
  output reg done // high when computation complete

Behavior:
1. On reset or when !start, module stays in IDLE state.
2. When start=1, begin processing:
    a. Compute prefix sums (s[0] = 0; s[i+1] = s[i] + a[i])
    b. Precompute x = k^p for p=0 to MAX_P (until overflow), store in ROM
    c. For each s[i], check (s[i] - x_j) exists in previous prefix sums count
3. Use sum register (16-bit signed) and dictionary for sum counts (16-entry memory)
4. Output valid after 200 cycles (latency) with total count

Timing:
- Output 'done' signal asserts when result is valid (200 cycles after start)
- Use states: IDLE, PREP_POWERS, CALC_PREFIX, CHECK_SUMS, DONE
- Dictionary implemented as 16-entry memory with parallel comparators
- MAX_P = 16 powers limitation (avoid overflow beyond 16 bits)
