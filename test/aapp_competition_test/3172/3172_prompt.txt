Design a sequential Verilog module named 'max_fruits_sliced' that computes the maximum number of unit-radius circles (fruits) intersected by any straight line.

Module interface:
module max_fruits_sliced(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [2:0] n, // Number of fruits (1-8)
  input [31:0] x [0:7], // Q16.16 fixed-point x coordinates (8 fruits)
  input [31:0] y [0:7] // Q16.16 fixed-point y coordinates (8 fruits)
  output reg [3:0] max_count, // Maximum fruits sliced (0-8)
  output reg done // High when computation complete
);

Behavioral description:
- Starting with start=1, computes for 225 cycles (max latency for n=8)
- Examines all circle pairs (C(n,2)*2 lines) then counts fruits sliced by each line
- Uses fixed-point arithmetic with Q16.16 representation: 1.0 = 0x00010000
- Distance comparison uses squared values to avoid sqrt operations
- Updates max_count when higher count found
- Output done=1 and max_count valid after 225 cycles

State machine requirements:
- States: IDLE, PROCESS_PAIRS, CHECK_LINES, FINISH
- PROCESS_PAIRS state iterates through all fruit pairs (i,j)
- CHECK_LINES state evaluates both tangent lines per pair against all fruits
- Implementation: 1 fruit comparison per clock cycle, folded logic
