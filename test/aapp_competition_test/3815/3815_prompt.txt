Design a sequential Verilog module named "alternating_sum_mod" that computes the alternating sum S = Σ(s_i * a^(n-i) * b^i) mod 997, where s is k-periodic.

Module interface:
module alternating_sum_mod(
  input clk,           // System clock
  input rst_n,         // Active-low reset
  input start,         // Start computation (pulse high)
  input [14:0] n,      // Max value 32767 (15-bit)
  input [15:0] a,      // Base a (16-bit)
  input [15:0] b,      // Base b (16-bit)
  input [3:0] k,       // Period (1-16, 4-bit)
  input [15:0] s,      // Sign bits (s[0] to s[k-1]: 1='+', 0='-') (16-bit)
  output reg [9:0] result,  // Result mod 997 (10-bit)
  output reg done      // High when computation completes
);

Behavior:
1. On reset, all registers clear.
2. When start=1, begin computation using inputs n,a,b,k,s.
3. Compute sum S = Σ_{i=0 to n} (s_i * a^(n-i) * b^i) mod 997
   - s is k-periodic: s_i = s[i mod k] (s[bit i mod k]: 1='+', 0='-') 
4. Operation completes in k + (n/k)*3 clock cycles.
5. Output 'result' valid when done=1.
Implementation hints:
- Use modular exponentiation with mod 997 for a^(n-i) and b^i
- Precompute the periodic pattern coefficients first
- Sum terms iteratively using a state machine with stages
- Ensure all operations use mod 997 to prevent overflow.

Notes:
- All operations must be in mod 997 (10-bit results)
- Use combinational logic for modular multiplication
- The module must complete within 5000 cycles for k=16.
