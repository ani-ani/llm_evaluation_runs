Design a sequential Verilog module named 'rectangle_overlap_point' that finds a point belonging to at least (n-1) rectangles.
Module interface:
module rectangle_overlap_point(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [2:0] n, // Number of rectangles (3 bits, max 8)
  input [31:0] rect_x1 [0:7], // x1 coordinates (32-bit signed)
  input [31:0] rect_y1 [0:7], // y1 coordinates (32-bit signed)
  input [31:0] rect_x2 [0:7], // x2 coordinates (32-bit signed)
  input [31:0] rect_y2 [0:7], // y2 coordinates (32-bit signed)
  output reg [31:0] point_x, // Found x coordinate
  output reg [31:0] point_y, // Found y coordinate
  output reg done // High when computation completes
);

Behavior description:
1. On reset: Clear all registers and set done=0.
2. When start=1: Begin computation with the input rectangles.
3. Algorithm:
   a. Compute global max_x1 (max rect_x1[i])
   b. Compute global max_y1 (max rect_y1[i])
   c. Compute global min_x2 (min rect_x2[i])
   d. Compute global min_y2 (min rect_y2[i])
   e. For each rectangle i (0-7):
      i. Check if rectangle[i] contains the point (max_x1, max_y1)
      ii. Track second-max_x1/second-min_x2/second-max_y1/second-min_y2 when excluding i
4. Output first valid point where (excluded_max_x1 <= excluded_min_x2) && (excluded_max_y1 <= excluded_min_y2).
5. Set done=1 and output valid point coordinates.
Latency: 1 cycle per rectangle + 2 cycles setup (max 10 cycles total). Output valid when done=1.
