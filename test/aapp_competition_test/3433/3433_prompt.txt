Design a sequential Verilog module named 'maze_joe_escape' that determines if Joe can exit a 4x4 maze before fire reaches him.

Module interface:
module maze_joe_escape(
  input clk,                // clock
  input rst_n,              // active-low reset
  input start,              // pulse high to start calculation
  input [15:0][1:0] grid_i, // 4x4 maze flattened (2 bits per cell: 00=wall, 01=open, 10=Joe, 11=fire)
  output reg [3:0] time_o,  // escape time (0-15 minutes)
  output reg impossible_o,  // high when escape impossible
  output reg done_o         // high when calculation complete
);

Behavior:
1. Module simulates Joe's movement and fire spread minute-by-minute
2. On start pulse:
   - Load initial grid state
   - Reset timers
3. Each clock cycle advances simulation by 1 minute:
   a. Fire spreads to all adjacent open squares
   b. Joe moves to any adjacent open square
   c. Edge squares are escape points
4. Output results:
   - If Joe reaches any edge square at time T: time_o = T, impossible_o = 0
   - If fire reaches Joe first: impossible_o = 1
5. Latency: Complete within 16 cycles (worst-case for 4x4 maze)
6. done_o goes high when simulation completes

Note: Consider multiple fire sources spreading simultaneously. Use BFS-like parallel processing limited to 4x4 grid.
