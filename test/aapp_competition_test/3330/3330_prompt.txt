Design a sequential Verilog module named 'potato_store_optimizer' that computes the minimal product of two store average prices.

Inputs:
  input clk          // clock
  input rst_n        // active-low reset
  input start        // pulse high to start computation
  input [2:0] N      // number of bags (2-4)
  input [1:0] L      // min bags for one store (1 <= L < N)
  input [3:0][7:0] a // bag potato counts (4 bags max, 1-8 each)
  input [3:0][19:0] c // bag prices (4 bags, 1-128 each)

Outputs:
  output reg [31:0] min_product  // Q16.16 fixed-point result
  output reg done                 // high when computation completes

Behavior:
1. On reset: Clears min_product and done
2. When start goes high:
   - Iterates through all 2^N possible bag assignments
   - For each assignment where count=K for store1 (K>=L or K<=N-L):
     a) Compute store1: total_potatoes = sum(a_i where bag_i in store1), total_price = sum(c_i where bag_i in store1)
     b) Compute store2: sum of remaining bags
     c) Calculate P1 = (total_price1 * 16\'h10000) / total_potatoes1   [Q16.16 fixed-point division]
     d) Calculate P2 similarly for store2
     e) Compute product = (P1 * P2) >> 16  [Fixed-point multiplication]
   - Track minimum product across all valid assignments
3. Timing: Requires 2^N * 6 + 2 cycles to complete (max 4-bit N = 16*6+2=98 cycles)
4. Assert 'done' for 1 cycle when complete with final result

Implementation notes:
- Use combinational logic for subset iteration and calculations
- Use 16.16 fixed-point (32-bit) for all calculations
- Handle division via iterative subtraction or lookup table
- Compare/store minimum via registered comparison
