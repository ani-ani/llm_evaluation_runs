Design a sequential Verilog module named 'crush_joongoon' that computes the smallest t satisfying the crush relationship conditions.

Inputs:
  input clk,          // Clock
  input rst_n,        // Active-low reset
  input start,        // Start computation (pulse to begin)
  input [2:0] crunch_arr [0:7], // Array of 8 3-bit crush indices [0-7]

Outputs:
  output reg [15:0] t,     // Computed result (-1 is 0xFFFF)
  output reg done,         // High when computation complete

Behavior:
1. On reset: Clear all internal state and set t=0, done=0.
2. When start is asserted: Begin computation.
3. Find all cycles in the crunch_arr graph (8 nodes max):
   - For each unvisited node, traverse until cycle is detected.
   - If cycle length is odd, use cycle length; if even, use cycle_length/2.
4. Compute LCM of all adjusted cycle lengths.
5. If any invalid cycle (not returning to start), output t=0xFFFF (-1).
6. Set done=1 when complete (within 100 cycles max).

Timing:
- New calculation starts when start is pulsed.
- Result available after variable latency (max 100 cycles).
- Done asserts when output is valid.
