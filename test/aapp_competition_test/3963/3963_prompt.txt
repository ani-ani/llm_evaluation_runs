Design a sequential Verilog module named 'coin_change' that calculates the number of ways to pay m tugricks using n types of coins with constraints.

Module interface:
module coin_change(
  input clk,            // system clock
  input rst_n,          // active-low reset
  input start,          // start computation
  input [2:0] num_coins, // number of coin types (1-8)
  input [7:0] a [0:6],  // denomination ratios (a1-a7) for n>=2
  input [7:0] b [0:7],  // coin counts (b1-b8)
  input [7:0] m,        // target amount (0-255)
  output reg [29:0] result, // result % 1e9+7
  output reg done       // high when complete
);

Behavioral description:
1. On reset: Initialize internal DP array (d[0] = 1, others 0)
2. When start is asserted:
   - Process coin types in order (i=0 to num_coins-1)
   - For each coin type i>0 with a[i-1] != 1:
      - Compress DP array using denomination ratio a[i-1]
   - Convolve current DP array with supply limit b[i] secured
3. Result available m <= 255 cycles after start (depends on input size)
4. All arithmetic operations use modulo 1e9+7

Implementation requirements:
- Use blocking assignments for combinatorial logic
- Use non-blocking assignments for sequential logic
- Include explicit FSM for state management (IDLE, PROCESSING, DONE)
- L parameter bound tracking (max sum b[i] ≤ 2040)
