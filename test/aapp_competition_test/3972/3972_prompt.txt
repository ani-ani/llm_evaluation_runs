Design a sequential Verilog module named 'sequence_counter' that calculates the number of valid sequences (mod 10^9+7) for a given n (4-bit input).

Module interface:
module sequence_counter(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [3:0] n, // Scaled to 4-bit (1 <= n <= 8)
  output reg [29:0] result, // 30-bit output for modulo 10^9+7
  output reg done // High when computation completes
);

Behavior description:
1. Implements DP algorithm: result = (dp[n] % 1000000007) where:
   - dp[1] = 1
   - dp[2] = 4
   - dp[i] = dp[i-1]*2 + dp[i-2] for i >= 3 (simplified logic)
2. Latency: Computes result in i+2 clock cycles where i is n value
3. States: IDLE (wait for start), COMPUTE (process DP), DONE (output ready)
4. All assignments use non-blocking operators
5. Power-of-2 array sizing (max n=8 → 4 bits)
6. Output valid when done=1, remains until next start

Timing requirements:
- Computation starts at rising edge when start=1
- Output valid 8 clock cycles after start assertion
- Maintain result until next computation starts
