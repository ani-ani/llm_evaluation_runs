Design a sequential Verilog module named "friendship_validator" that checks if students' friendship claims meet group constraints.

Inputs:
input clk, // clock
input rst_n, // active-low reset
input start, // start processing
input [3:0] n, // number of students (max 8, 4 bits)
input [3:0] p, // max group size (≤15)
input [3:0] q, // max external edges (≤15)
input [7:0] friends [0:7], // 8x8-bit array: friends[i] = bitmask of student i's friends

Outputs:
output reg decision, // 1=dete∩tion required, 0=valid partition exists
output reg done // high when computation complete

Behavior:
1. On reset or power-up: decision=0, done=0
2. When start=1, begin validation process
3. Compute whether exists any partition that satisfies:
   - Groups size ≤ p
   - Max q external friend edges per group
4. Uses student friendship data (friends array)
5. After processing (n+2 cycles), set done=1 and output decision
6. Note: Symmetric friendships enforced - must match friendship claims

Timing:
- Starts processing on rising edge when start=1
- 8 clock cycles processing time for n=8
- done asserts on cycle n+2 (e.g., 10 cycles for n=8)

Constraints:
- Assume p + q ≤ 15 (as problem constraints)
- Supports n=1-8 students (using lowest 3 bits for indexing)
- Group partitions must satisfy all size constraints and friendship symmetry
