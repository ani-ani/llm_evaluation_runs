Design a combinational Verilog module named 'hanabi_hints' that calculates the minimum number of hints required to identify cards.

Module interface:
module hanabi_hints(
  input [2:0] num_cards,  // 1-8 cards (3-bit unsigned)
  input [47:0] cards,     // 8 cards max (6 bits per card: 3-bit color + 3-bit value)
  output [3:0] min_hints  // Minimum hint count (0-10)
);

Behavioral description:
- Colors encoded as: 000=R, 001=G, 010=B, 011=Y, 100=W (values 101-111 unused)
- Values encoded as: 001=1, 010=2, 011=3, 100=4, 101=5 (values 000,110-111 unused)
- For all 1024 possible 10-bit hint masks (bit[9:5]=colors, bit[4:0]=values):
  1. For each card pair (i,j), check if they can be distinguished using current mask
  2. Mask is valid if ALL distinct card pairs are distinguishable
- min_hints = popcount of smallest valid mask

Card distinguish condition:
Cards i,j are distinguishable if either:
1. Different colors AND color hint exists for i or j
2. Different values AND value hint exists for i or j
3. Either card has at least one revealed attribute via mask",
