Design a sequential Verilog module named 'dog_chain_calculator' to compute the minimum dog chain length. Inputs: clk (clock), rst_n (active-low reset), start (initiate computation), L[11:0] (lawn area). Outputs: chain_length[7:0] (chain length), done (high when computation completes).

Behavior:
1. When start is asserted, begin computation:
   a. Calculate temp = L * 226 (fixed-point substitute for 2L/π ≈ 2L*113/355)
   b. Divide temp by 355, if remainder exists increment quotient (rounded ceil)
   c. Find smallest integer r where r*r >= quotient
2. Use a state machine: IDLE, COMPUTE, DIVIDE, SQRT, DONE
3. Provide chain_length = r
4. Assert 'done' for 1 cycle after completion
5. Latency: Result valid 10 cycles after start (approximate timing for calculations).

Module interface:
module dog_chain_calculator(
  input clk,
  input rst_n,
  input start,
  input [11:0] L,
  output reg [7:0] chain_length,
  output reg done
);
