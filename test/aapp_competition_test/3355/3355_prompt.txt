Design a sequential Verilog module named 'scavenger_hunt' that solves a scaled version of the scavenger hunt problem (n=4).
Module interface:
module scavenger_hunt(
  input clk, // System clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [10:0] total_time, // Max total time T
  input [10:0] travel_matrix [0:5][0:5], // 6x6 flattened travel times (locations 4=start,5=end)
  input [6:0] p_i [0:3], // Points for tasks 0-3
  input [10:0] t_i [0:3], // Task durations for tasks 0-3
  input [10:0] d_i [0:3], // Task deadlines (0x7FF for no deadline)
  output reg [8:0] max_points, // Maximum possible points (0-400)
  output reg [3:0] task_set, // Optimal task bitmask (bit0=task0)
  output reg done // High when computation completes
);

Behavior: When start is asserted, compute the maximum points possible within total_time considering travel_matrix and task deadlines. Uses state machine to evaluate all 16 possible task combinations (0000-1111). For each valid set:
1. Verifies path from start (loc4) to end (loc5) exists within T
2. Checks path meets all task deadlines using combinatorial checks
3. Tracks maximum points with priority for lex-smaller task sets
Latency: Output valid 16 clock cycles after start. Assign max_points=0 if no valid path exists.
Implementation: Use 4-bit combination counter (state), parallel path evaluation with travel time accumulator, deadline checker, and comparison logic.
