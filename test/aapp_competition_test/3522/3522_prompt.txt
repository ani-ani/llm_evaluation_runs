Design a combinational Verilog module named 'battery_allocation' that calculates the minimal maximum difference between pairs of batteries allocated to machines.

Module interface:
module battery_allocation(
  input [63:0] batteries_packed,  // 8 batteries × 8 bits: [63:56]=bat0, [55:48]=bat1, ...[7:0]=bat7
  output [7:0] d                  // Maximum difference between paired chips
);

Behavioral description:
1. Unpack 64-bit input into 8 batteries (8-bit each)
2. Sort batteries in ascending order using a sorting network
3. Form 4 machine pairs: (sorted[0] and sorted[1]), (sorted[2] and sorted[3]), etc.
4. Calculate differences between each pair
5. Output the maximum difference value.
The module must be purely combinational (no clock needed). Use power-optimized comparator structures.
