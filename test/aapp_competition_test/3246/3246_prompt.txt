Design a sequential Verilog module named 'word_descrambler' that deciphers scrambled text using a dictionary.
Module interface:
module word_descrambler(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start processing
  input [127:0] scrambled_str, // 16-character fixed input (8-bit per char)
  input [63:0] dict_words [0:7], // 8 dictionary words (8 chars each)
  input [2:0] word_count, // Actual dictionary words (0-7)
  output reg [127:0] deciphered_str, // Output string
  output reg [1:0] status, // 00:busy, 01:done, 10:ambiguous, 11:impossible
  output reg [3:0] output_length // Valid characters in output
);

Behavior description:
1. On reset, all outputs go to zero.
2. When start is asserted:
   a. Process scrambled_str to find valid word splits using fixed 8-word dictionary
   b. Each word must match first/last letters and have correct inner letters
   c. Compute signature (first_char, last_char, inner_letter_counts) for matching
   d. Identify all possible valid splits in <= 256 cycles
3. Output requirements:
   - deciphered_str: Valid solution with spaces added between words
   - status: ambiguous (10) if multiple solutions, impossible (11) if none
4. Latency: Result available within 256 cycles after start assertion
5. Implementation constraints:
   - Max input length: 16 chars (scrambled_str)
   - Dictionary size: 8 words max (dict_words)
   - Each dictionary word: max 8 characters
   - Use 16-character output (deciphered_str) with space separators
6. Processing logic:
   - Use a finite state machine to try possible word splits
   - Compare letter signatures via parallel matching circuits
   - Track multiple potential solutions in a register array
7. Special cases:
   - Single-letter words must match exactly
   - Two-letter words require exact match (no inner letters)
   - Prioritize longest valid words first
