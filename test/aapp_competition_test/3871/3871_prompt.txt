Design a sequential Verilog module named 'max_profit_calculator' that computes the maximum show profit for up to 8 candidates with aggressiveness levels <=8.

Inputs:
  input clk,             // clock signal
  input rst_n,           // active-low reset
  input start,           // start calculation (pulse high for 1 cycle)
  input [2:0] num_candidates,  // actual n (1-8)
  input [3:0] l_i [0:7], // aggressiveness levels (4 bits per candidate)
  input [15:0] s_i [0:7], // recruitment costs (16-bit signed)
  input [15:0] c_v [0:15] // profitability values (16-bit signed, indexes 0-15)

Outputs:
  output reg [31:0] max_profit, // final result (32-bit signed)
  output reg done               // high when result is valid

Behavior:
1. On reset, all internal states reset to initial values.
2. When start is pulsed high:
   a. Processes candidates in reverse order (index 7 to 0)
   b. Implements DP[k][cnt] state tracking maximum profit
   c. Uses a state machine with three 16-entry DP tables (prev, current, next)
3. Internal aggressiveness levels track up to n+m=16 possible values (4-bit)
4. Fights are resolved by merging same-level participants (level upgrades)
5. Maximum latency: 100 clock cycles for n=8 calculation
6. Done signal asserts when calculation completes

Implementation constraints:
- DP state stored in 16x32-bit registers (k:0-15, cnt:0-8)
- Sequential processing using candidate index counter (3-bit)
- Profit calculations use 32-bit signed arithmetic
