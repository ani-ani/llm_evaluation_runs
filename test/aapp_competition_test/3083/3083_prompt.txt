Design a sequential Verilog module named 'playlist_finder' that finds a 9-song playlist path with consecutive transitions and unique artists from up to 16 songs.

Module interface:
module playlist_finder(
  input clk,                       // clock signal
  input rst_n,                     // active-low reset
  input start,                     // start computation
  input [3:0] max_songs,          // number of songs (9-16)
  input [15:0][3:0] artist_ids,    // artist ID per song (4-bit IDs)
  input [15:0][3:0] t_counts,      // transition counts per song (0-4)
  input [15:0][3:0][3:0] next_ids, // max 4 transitions/song (4-bit IDs)
  output reg [3:0] playlist [0:8], // 9-song playlist (4-bit IDs each)
  output reg done,                 // high when computation complete
  output reg found                 // 1 if valid playlist found, 0 for fail
);

Behavior: When start pulses high, search for any valid 9-song path where:
1. Each consecutive song has valid transition (next_ids constraint)
2. All 9 artists are unique (track with 16b bitmask)
Use depth-first search with maximum 16 songs and 4 transitions/song. Valid path stored in playlist when found=1 and done=1. If no path found after exhaustive search, done=1 and found=0. Maximum search depth: 9 songs. Latency: Variable (assert done when complete, max 5000 cycles). Store next_ids as 16x4x4 array (song x transition x ID). Use state machine with IDLE, SEARCHING, FOUND, FAIL states.

Initialize all song data on module power-up. Assume song IDs are 0-15.
