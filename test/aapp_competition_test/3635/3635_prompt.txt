Design a sequential Verilog module named 'max_executives' that computes the maximum number of executives (k) for fair banana distribution.

Inputs:
- input clk: clock signal
- input rst_n: active-low asynchronous reset
- input start: starts computation (assert high for 1 cycle)
- input [3:0] N: number of briefcases (1-8)
- input [15:0] bananas [0:7]: array of banana counts (up to 65535)

Outputs:
- output reg [3:0] k: max executives (valid when done=1)
- output reg done: computation complete (high when result valid)

Behavior:
- On start pulse:
  * Initialize K=0 
  * Initialize current_sum=0, last_sum=0
  * Initialize index=0, valid_segments=0
- Sequentially process briefcases from 0 to N-1:
  1. Accumulate current_sum += bananas[index] 
  2. When current_sum >= last_sum: increment valid_segments,
     set last_sum = current_sum, reset current_sum=0
  3. Increment index 
- Result k = valid_segments when all briefcases processed
- Max executives is valid after 2*N+2 cycles (worst case 18 cycles)
- Module uses state machine with states: IDLE, INIT, ACCUM, COMPARE, DONE.
- Implement with synchronous logic sensitive to posedge clk.
