Design a sequential Verilog module named 'max_bling_calculator' that computes the maximum Bling achievable in up to 8 days. The module must operate as follows:

Inputs:
input clk // system clock
input rst_n // active-low asynchronous reset
input start // pulse high to start computation
input [2:0] days_remaining // remaining days (1-8)
input [15:0] initial_bling // current Bling (0-65535)
input [6:0] initial_fruits // current fruits (0-100)
input [6:0] t0 // trees yielding today (0-100)
input [6:0] t1 // trees yielding in 1 day (0-100)
input [6:0] t2 // trees yielding in 2 days (0-100)

Outputs:
output reg [15:0] max_bling // final maximum Bling
output reg done // high when computation is complete

Behavior:
- On reset, all internal registers and outputs are cleared.
- When start is pulsed high, the module begins processing day-by-day.
- Each day consists of:
  1. Harvest phase: Add fruits from t0 trees (3 per tree). Update t0, t1, t2 by shifting (t0 becomes t1, t1 becomes t2, t2 becomes 0). Same logic for exotic trees.
  2. Action phase:
     a. If Bling >=400, buy one exotic fruit (costs 400 Bling) and plant it if remaining days >=3, otherwise sell it immediately.
     b. For all normal and exotic fruits: plant if remaining days (including current day) >=3, else sell.
- The module uses a state machine with three states: IDLE (wait for start), PROCESSING (iterate days), DONE (output result).
- Processing takes exactly 'days_remaining' clock cycles (each day processed in one cycle).
- After processing all days, 'done' is asserted and 'max_bling' holds the result.

Note: Exotic fruit trees have their own counters (exotic_t0, exotic_t1, exotic_t2) that operate parallel to normal trees. Each planted exotic fruit creates an exotic tree in t2 (as it takes 3 days to yield).
