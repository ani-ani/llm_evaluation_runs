Design a sequential Verilog module named 'rocket_safety_checker' that determines if a rocket configuration is safe.
Module interface:
module rocket_safety_checker(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // start computation
  input [3:0] n, // engine1 points count (3-8)
  input [3:0] m, // engine2 points count (3-8)
  input [15:0] engine1_x [0:7], // engine1 x coords (8 points)
  input [15:0] engine1_y [0:7], // engine1 y coords
  input [15:0] engine2_x [0:7], // engine2 x coords (8 points)
  input [15:0] engine2_y [0:7], // engine2 y coords
  output reg result, // 0='NO', 1='YES'
  output reg done // high when computation complete
);

Behavioral description:
1. The module computes convex hulls for both engines (max 8 points each)
2. Compares hull structures:
   - For 2-point hulls: check distance squared equality
   - For 3+ points: create feature vectors of (distance_sq, dot_product)
   - Check circular equivalence using Z-algorithm
3. Output result=1 if hull structures match, 0 otherwise
4. Computation completes within 100 clock cycles after start assertion
5. Implement convex hull using Graham scan with fixed-point arithmetic
