Design a sequential Verilog module named 'loot_divider' that calculates the minimum loot thieves must leave behind when splitting coins of denominations 2^i.

Module interface:
module loot_divider(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [2:0] k, // Number of denominations (1-8)
  input [7:0] x [7:0], // 8-element array of coin counts (each 8-bit)
  output reg [31:0] left_behind, // Result
  output reg done // High when computation completes
);

Behavioral description:
1. On reset or power-up: reset all registers, left_behind=0, done=0
2. When start=1: begin processing coin counts starting from 2^0 up to 2^7
3. Use a finite state machine to iterate through denominations:
   - STATE_IDLE: Wait for start signal
   - STATE_PROCESS: For each denomination (i=0 to k-1):
        a. Calculate current sum: coins = x[i] + carry_in
        b. If coins % 2 != 0: add one coin to left_behind (2^i) and subtract 1 from coins
        c. carry_out = coins >> 1 (to next denomination)
        d. Repeat until all k denominations processed
   - STATE_DONE: Set done=1 and output_result=left_behind
4. Requires 1-9 clock cycles (max 8 denoms + done state)
5. All calculations using combinational logic within state transitions
6. Result provides actual value (not modded) - testbench handles modulus.
