Design a sequential Verilog module named purchase_outcome_decoder that computes card distribution outcomes for purchases.

Inputs:
- input clk,
- input rst_n, // active-low reset
- input start, // start computation
- input [3:0][15:0] child_count, // 4 children's final counts (index 0-3)
- input [2:0] purchase_count, // number of purchases (0-5)
- input [5:0][1:0][1:0] purchase_pairs // max 6 purchases [purchase][0/1] = child_id (2-bit)

Outputs:
- output reg [5:0][1:0] outcome, // outcome per purchase (0/1/2)
- output reg done // high when computation complete

Behavior:
1. On reset: clear all internal state
2. When start is asserted:
   - Begin processing purchases in order for purchase_count cycles
   - For each purchase (a = purchase_pairs[i][0], b = purchase_pairs[i][1]):
        a. Compute required_a = child_count[a] - current_a
        b. Compute required_b = child_count[b] - current_b
        c. outcome assignment:
           - required_a > required_b || (required_a == required_b && a < b) → outcome[i] = 2
           - required_b > required_a → outcome[i] = 0
           - Else → outcome[i] = 1
        d. Update internal current_a/current_b counters based on outcome
3. Assert done after purchase_count + 1 clock cycles with outcomes valid
Latency: Output valid after purchase_count + 1 clock cycles.
