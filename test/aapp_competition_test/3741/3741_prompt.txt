Design a sequential Verilog module named 'shortest_cycle_detector' that finds the length of the shortest cycle in a graph constructed from 8 nodes based on non-zero bitwise AND between 16-bit inputs.

Module interface:
module shortest_cycle_detector(
  input clk, 
  input rst_n, 
  input start, 
  input [15:0] a0, 
  input [15:0] a1, 
  input [15:0] a2, 
  input [15:0] a3, 
  input [15:0] a4, 
  input [15:0] a5, 
  input [15:0] a6, 
  input [15:0] a7, 
  output reg [4:0] cycle_len, 
  output reg done 
);
Behavioral description:
- On reset (rst_n=0), initialize all registers and set done=0.
- When start is asserted, begin processing.
- Construct an 8x8 adjacency matrix where edge[i][j]=1 if i≠j and (ai & aj ≠ 0).
- Perform BFS/DFS from each node to detect cycles and track shortest cycle length.
- Output: cycle_len=0 for no cycle (-1), otherwise [3-8] for cycle lengths.
- Assert done=1 when result is ready after 50 clock cycles (fixed latency).
- Use FSM with states: IDLE, BUILD_GRAPH, SEARCH_CYCLES, DONE.
