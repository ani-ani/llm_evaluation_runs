Design a sequential Verilog module named 'stamp_nub_minimizer' that finds the minimum number of nubs ('#' symbols) on a stamp that could produce a given paper mark when stamped exactly twice. All grids are fixed size (max 8x8).
Module interface:
module stamp_nub_minimizer(
  input clk, // clock signal
  input rst_n, // active-low reset (asynchronous)
  input start, // pulse high to begin computation
  input [7:0] grid_height, // paper height (1-8)
  input [7:0] grid_width, // paper width (1-8)
  input [63:0] paper_mark, // flattened grid (row-major, 1-bit per cell: 1='#', 0='.')
  output reg [3:0] min_nubs, // minimum number of stamp nubs (0-64)
  output reg done // high when computation complete
);

Behavioral description:
- Paper mark dimensions are limited to 8x8 (grid_height/grid_width specify actual size)
- The module computes min_nubs: minimal # of nubs in any stamp pattern that
  could create the paper_mark when stamped twice (overlap allowed)
- Implementation must:
  1. Iterate through possible stamp heights (1 to grid_height)
  2. For each stamp height, iterate stamp widths (1 to grid_width)
  3. Check all possible stamp patterns of current size (brute force or smart)
  4. For each pattern, check all valid placements on the paper
  5. Verify if two stamp placements could produce paper_mark
  6. Track minimum nubs count across all valid patterns
- Worst-case latency acceptable (e.g., thousands of cycles)
- Use a state machine with counter logic for iteration control
- Algorithm outline:
      IDLE → INIT → TRY_STAMP_SIZE → TRY_PATTERN → CHECK_OVERLAP → RECORD_MIN → DONE
- Use combinational logic where possible, pipelined pattern checking if feasible
- Note: Two stamps must completely cover all '#' marks on paper with possible overlap
