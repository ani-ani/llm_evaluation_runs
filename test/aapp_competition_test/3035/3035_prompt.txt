Design a sequential Verilog module named "lemonade_trader" that calculates the maximum obtainable blue lemonade from up to 8 children with color exchanges.

Inputs:
input clk,                // clock signal
input rst_n,              // active-low reset
input start,              // pulse high to start computation
input [3:0] color_ids [0:7], // array of 4-bit color IDs (0:pink, 1:blue, others)>
input [31:0] rates [0:7], // exchange rates in Q16.16 fixed-point format (16.16 bits)
input [2:0] num_children,  // number of trades (0-8)

Outputs:
output reg [31:0] max_blue_q16, // max blue lemonade in Q16.16 format
output reg done            // high when computation complete

Behavior:
1. Upon reset, all outputs go to zero (max_blue_q16 <= 0, done <= 0)
2. When start is pulsed high:
   a. Initialize with 1.0 litre pink lemonade (0x00010000 in Q16.16)
   b. Evaluate all possible trade sequences (up to 8 steps) to find maximum blue lemonade
   c. Cap result at 10.0 litres (0x000A0000 in Q16.16)
3. Output valid when done=1 (latency is combinatorial but wrap in register)
4. Module must complete computation within 256 clock cycles for worst-case 8 children.

Color ID mapping:
- 0: pink (initial)
- 1: blue (target)
- 2-15: other colors

Fixed-point specifications:
- All calculations must use Q16.16 format (32-bit total, 16 integer + 16 fractional bits)
- 1.0 litre = 0x00010000
- 10.0 litres = 0x000A0000
- Exchange rates stored in Q16.16 format (R = X ⇒ rate_q16 = X * 65536)
