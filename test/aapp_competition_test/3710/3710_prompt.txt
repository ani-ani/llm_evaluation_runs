Design a sequential Verilog module named 'remainder_game_decider' that determines if there exists a winning strategy as per the problem.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // high to start computation
input [3:0] n // max 8 numbers (n ≤ 8)
input [15:0] k // value k (16-bit)
input [15:0] c_i [0:7] // input array of up to 8 numbers (each 16-bit)

Outputs:
output reg result // 1=Yes, 0=No
output reg done // high when computation complete

Behavior: When start is asserted, the module computes x = LCM(gcd(k, c_i[0]), ..., gcd(k, c_i[n-1])) and checks if x equals k. The module must finish within 150 clock cycles maximum.

States: IDLE, INIT, COMPUTE_GCD, COMPARE, DONE. Use iterative gcd computation (Euclid's algorithm) with maximum 16 cycles per gcd operation. The done signal must be set high for 1 cycle when the result is ready.

Note: The array c_i is presented as a fixed-size 8-element storage. Only the first n elements are considered (0 ≤ index < n).
