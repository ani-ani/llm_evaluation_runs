Design a Verilog module named 'min_papers_average' that finds the minimal count of papers (1-5) to achieve a Q12.10 fixed-point average P.

Module interface:
module min_papers_average(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // start computation
  input [21:0] P_fixed, // Q12.10 format (P * 1024)
  output reg [4:0] ones, twos, threes, fours, fives, // counts per paper type (0-31)
  output reg done // high when solution found
);

Behavior:
- When start is asserted, begins search for minimal total papers
- Implements 5 nested loops (for fives downto ones) with max count 31 each
- For each combination, checks if (sum(values) * 1024) == (total_count * P_fixed)
- Outputs first minimal-count solution found (priority to higher value papers)
- Latency: Variable (depends on solution), done asserts within 2000 cycles max for P=1-5
- Use state machine with: IDLE, SEARCH, COMPUTE, CHECK, DONE states
- Internal computation requires 20-bit precision for sum comparisons
