Design a sequential Verilog module named 'tape_art_decoder' that reconstructs tape application instructions for a 16-inch plank.

Inputs:
input clk,           // clock signal
input rst_n,         // active-low reset
input start,         // initiates computation (pulse high)
input [3:0] n,       // plank length (1-16 inches)
input [3:0] c[0:15], // color sequence (16-element array, 4 bits/element)

Outputs:
output reg [3:0] instr_l[0:15], // instruction L values (16 possible instructions)
output reg [3:0] instr_r[0:15], // instruction R values
output reg [3:0] instr_c[0:15], // color values
output reg [4:0] instr_count,   // number of instructions (0-16)
output reg done,                // high when computation complete
output reg impossible           // high when artwork is impossible

Behavior:
1. On start pulse, analyzes 'c[0:n-1]' to create instructions
2. Each color must appear in exactly one contiguous segment (last occurrence wins)
3. Instructions must be output in reverse application order (last applied first)
4. After analysis: 
   - If impossible: set impossible=1, instr_count=0
   - Else: fill instruction arrays and set instr_count
5. Latency: 30 clock cycles max, done asserts when complete

Implementation notes: 
- Use a state machine with: IDLE, SCAN_FIRST_LAST, CHECK_CONSISTENCY, BUILT_INSTRUCTIONS, DONE
- Maintain first/last occurrence registers for each color (16 colors)
- Verify color consistency: each position must equal the last applied color's value
