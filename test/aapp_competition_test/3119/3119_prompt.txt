Design a sequential Verilog module named 'guitar_hero_scorer' that calculates the maximum score achievable in a scaled-down Guitar Hero scenario.

Inputs:
input clk,                     // Clock
input rst_n,                   // Active-low reset
input start,                   // Start computation
input [3:0] n_notes,           // Number of notes (1-16)
input [1:0] p_phrases,         // Number of SP phrases (0-4)
input [15:0] notes[15:0],      // Note timestamps (16-bit values)
input [15:0] sp_starts[3:0],   // SP phrase start times (16-bit)
input [15:0] sp_ends[3:0],     // SP phrase end times (16-bit)

Outputs:
output reg [7:0] max_score,    // Maximum achievable score
output reg done                // High when computation complete

Behavior:
1. On reset or power-up, set max_score = 0 and done = 0
2. When start is asserted:
   a. Iterate through all 2^p_phrases possible SP activation decisions
   b. For each combination:
      - Calculate valid charging periods (accounting for phrase degradation)
      - Determine total charge time available
      - Evaluate all possible SP activations within timing constraints
      - Calculate score for current activation strategy (2x points during SP activation)
      - Update max_score if current strategy yields higher score
3. After evaluating all combinations (~16 cycles for p_phrases=4), assert done
4. max_score remains valid until next start pulse

Timing:
- Computation completes within 20 clock cycles after start is asserted (for p <=4)
- Inputs must remain stable during computation
- Output valid at done assertion edge

Notes:
- SP activation degrades phrases if overlapping with positive SP meter
- Score doubles notes hit during SP activation (must check time ranges)
- Maximum n_notes=16, p_phrases=4, 16-bit time values\
