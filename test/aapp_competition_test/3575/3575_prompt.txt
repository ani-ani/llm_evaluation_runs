Design a sequential Verilog module named 'alice_bob_meet' that computes expected meeting time for Alice and Bob moving on a 4-station graph.

Module interface:
module alice_bob_meet(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // start calculation
  input [15:0] adjacency, // adjacency matrix flattened (4x4 stations)
  input [1:0] alice_start, // Alice's initial station (2 bits)
  input [1:0] bob_start, // Bob's initial station (2 bits)
  output reg [31:0] expected_time, // Q16.16 fixed-point (0xFFFFFFFF means never meet)
  output reg done // high when computation complete
);

Behavioral description:
1. The module implements a state machine to compute the expected meeting time
2. Precompute transition probabilities for all 4x4=16 possible state pairs
3. Use fixed-point arithmetic (Q16.16) for probability calculations
4. If stations are disconnected, output 0xFFFFFFFF after detection
5. Latency: Complete within 16 clock cycles after start assertion

State machine states:
IDLE -> INIT -> CALCULATE -> FINISH
When done asserts, expected_time is valid. Clock rises should advance state machine.
