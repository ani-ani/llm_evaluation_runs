Design a sequential Verilog module named 'longest_path_to_1' that finds the longest path ending at city 1 in a maximum 8-node graph.

Inputs:
input clk,                 // clock signal
input rst_n,              // active-low reset
input start,              // pulse to start computation
input [2:0] node_count,   // number of cities (2-8)
input [15:0][7:0] edges,  // 16 roads max: each 8-bit entry = {3'bA, 3'bB, 1'bunused, 1'bvalid}

Outputs:
output reg [4:0] path_length, // longest path length (0-31)
output reg done            // high when computation complete

Behavior:
1. On reset: path_length=0, done=0
2. When start=1: begin BFS-style traversal from all nodes to node 1 (ID 000)
3. Track edge usage (road reuse prohibited)
4. Implement cycle handling via adjacency matrix (8x8)
5. Result ready in ≤100 cycles (worst-case for N=8)

Timing:
- Output valid 100 cycles after start assertion
- done flag asserts with valid result

Notes:
- Each edge stored as {3-bit city A, 3-bit city B}
- Roads are bidirectional (store both directions in adjacency matrix)
- Exploit road limit per ring by tracking branches separately
