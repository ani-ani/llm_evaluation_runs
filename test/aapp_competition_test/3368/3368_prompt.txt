Design a sequential Verilog module named 'animal_sanctuary_restore' that checks if misplaced animals can be properly relocated following movement restrictions.

Module interface:
module animal_sanctuary_restore(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start computation
  // Enclosure config (4 enclosures max):
  input [1:0] correct_animal [0:3], // Correct animal type per enclosure (2-bit enum)
  input [1:0] current_count [0:3], // Current animals per enclosure (2-bit, 0-4 animals)
  input [3:0][1:0] current_animals, // Packed 4 slots x 2 bits (max 4 animals total)
  output reg [1:0] result, // 00:FALSE_ALARM, 01:POSSIBLE, 10:IMPOSSIBLE
  output reg done // High when result valid
);

Parameter animal encoding: 00-monkey, 01-lion, 10-penguin, 11-elephant

Behavior: On start, module checks if:
1. All animals already correct -> output FALSE_ALARM (00)
2. Else, if movement graph forms exactly one cycle where each node points to another,
   output POSSIBLE (01)
3. If graph contains multiple cycles/singletons -> IMPOSSIBLE (10)

Timing: Requires <= 16 clock cycles after start assertion. Use state machine with:
IDLE -> VERIFY_CORRECT -> BUILD_GRAPH -> CHECK_CYCLES -> DONE
Animal mappings must be processed iteratively using counters and registers.
