Design a Verilog module named 'rebus_solver' that determines if a rebus equation can be solved.
Module interface:
module rebus_solver(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // pulse to start computation
  input [3:0] num_terms, // number of question marks (1-16)
  input [15:0] n, // target value (1-65535)
  input [15:0] sign_pattern, // 1=positive, 0=negative for each term [bit0=first_term]
  output reg [15:0] solution [0:15], // solution values (1-n)
  output reg possible, // 1 if solvable
  output reg done // high when computation completes
);

Behavior:
- Sequential module using non-blocking assignments
- Implements rebus solving algorithm with these steps:
  1. Calculate minimal sum (all terms=1) based on sign_pattern
  2. Distribute remaining difference (n - min_sum) across terms, respecting their sign
  3. Check if solution exists within n constraints
- Latency: Computation completes within 16 clock cycles (one per term)
- On start pulse: clears solution, done=0
- After computation: possible=1 if solution exists, done=1
- solution[] contains valid values when done is high
- Reset initializes all outputs to zero
