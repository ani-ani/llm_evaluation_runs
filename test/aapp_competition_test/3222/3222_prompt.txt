Design a Verilog module named 'cycle_partition' that determines if a 4-node directed graph can be partitioned into cycles covering all nodes.
Inputs:
input clk,
input rst_n,
input start, // start computation
input [15:0] adj_matrix_flat, // adjacency matrix flattened as 16 bits (4x4 graph)
Outputs:
output reg done, // high when computation complete
output reg valid_partition, // "Yeah!" case (0=valid partition found, 1=invalid)
output reg [3:0] node_list, // first cycle found (for test validation)
output reg [1:0] cycle_size // size of first found cycle

Behavior:
1. On reset or power-up, set outputs to 0
2. When start goes high:
   a. Load adj_matrix_flat into 4x4 adjacency matrix
   b. Compute if graph can be partitioned into cycles covering all 4 nodes
   c. After 10 clock cycles, set done=1 and output results
3. valid_partition=0 means valid cycle partition exists, 1 means impossible (output "Yeah!")
4. node_list shows nodes in first found cycle in traversal order (LSB to MSB)
5. cycle_size indicates number of nodes in first cycle (2,3 or 4)

Implementation notes:
- Use state machine with 10 cycle latency
- Priority: Find 2-node cycles first then larger cycles
- Must cover all 4 nodes exactly once
