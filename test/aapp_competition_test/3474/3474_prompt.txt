Design a combinational Verilog module named 'laser_reflection_calculator' that calculates the reflected laser hit point on an infinite wall at x=0. All coordinates use Q16.16 fixed-point format (32-bit signed: 16 integer, 16 fractional bits).

Inputs:
input [31:0] x1,  // Mirror endpoint 1 x-coordinate
input [31:0] y1,  // Mirror endpoint 1 y-coordinate
input [31:0] x2,  // Mirror endpoint 2 x-coordinate
input [31:0] y2,  // Mirror endpoint 2 y-coordinate
input [31:0] px,  // Shooter position x
input [31:0] py,  // Shooter position y

Outputs:
output reg valid_hit,         // 1 if hit possible, 0 for "can't hit"
output reg inf_low,          // 1 if lower bound is -infinity
output reg inf_high,         // 1 if upper bound is +infinity
output reg [31:0] y_low,     // Lower y-bound (valid when inf_low=0)
output reg [31:0] y_high     // Upper y-bound (valid when inf_high=0)

The module should compute the reflection geometry where:
1. Calculate the mirror line equation from (x1,y1) to (x2,y2)
2. Find reflection of shooter position (px,py) over mirror line
3. Calculate intersection between reflected line (shooter to reflected point) and wall at x=0
4. Determine hit range on wall (y coordinates), handling edge cases
5. Output valid_hit=0 if no valid reflection hits wall, set status flags for infinite ranges

Note: All calculations must use Q16.16 fixed-point arithmetic. Handle division using 32.32 intermediate precision. Significant parallelism encouraged for coordinate calculations.
