Design a sequential Verilog module named 'lamp_illumination_checker' that determines if lamps on an n x n grid (max n=4) can be oriented without row/column conflicts.

Module interface:
module lamp_illumination_checker(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // pulse to start computation
  input [2:0] grid_size, // n (max 4)
  input [2:0] lamp_reach, // r (<= n)
  input [2:0] num_lamps, // k (<=8)
  input [2:0] lamp_rows [0:7], // 8 lamp positions
  input [2:0] lamp_cols [0:7], 
  output reg result, // 1=possible, 0=impossible
  output reg done // high when computation completes
);

Behavioral description:
1. On reset or power-up: clear all internal state
2. When start is asserted:
   - Load input parameters into registers
   - Initialize conflict detection logic
3. Process lamps via state machine:
   - States: IDLE, LOAD, CHECK_ROW, CHECK_COL, EVALUATE
   - Test all possible lamp orientations (row/column) 
   - Check illumination overlaps using grid_size and lamp_reach
   - Detect if any square gets illuminated by >1 lamp in same row/column direction
4. After processing all lamps (max 8), set result:
   - 1 if valid orientation exists
   - 0 if conflict unavoidable
5. Assert 'done' signal when result is valid
Latency: Output valid within 64 clock cycles after start.
