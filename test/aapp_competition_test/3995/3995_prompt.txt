Design a Verilog module named 'min_unique_substring' that generates a binary string with specified minimal unique substring length.

Inputs:
- [3:0] n: Length of output string (4 bits, valid range 1-16)
- [3:0] k: Required minimal unique substring length (4 bits, must satisfy k <= n and (n%2) == (k%2))

Output:
- [15:0] s: Generated binary string (16-bit, active-high with s[0] as first character)

Behavior:
Given (n,k), generate string s of length n where:
1. When k = n: s = all 1's
2. Else: Create repeating pattern of ((n-k)/2) zeros followed by 1
Use parameter a = (n - k) / 2. s = ("0"*a + "1") repeated to fill n bits.
Example: n=5, k=3 → a=1 → pattern "01" → "01010"

Module interface:
module min_unique_substring(
  input [3:0] n,
  input [3:0] k,
  output [15:0] s
);
