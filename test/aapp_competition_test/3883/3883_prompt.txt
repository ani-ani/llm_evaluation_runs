Design a sequential Verilog module named 'polyline_xfinder' that calculates the minimal positive x value for a polyline passing through point (a, b) using fixed-point arithmetic.

Module interface:
module polyline_xfinder(
  input clk, // Clock signal
  input rst_n, // Active-low reset
  input start, // Pulse high to start computation
  input [23:0] a, // X-coordinate (24-bit unsigned integer)
  input [23:0] b, // Y-coordinate (24-bit unsigned integer)
  output reg [63:0] x, // Q32.32 fixed-point result (32 integer, 32 fractional bits)
  output reg valid // High when result is valid, low when no solution
);

Behavioral description:
1. On reset or idle, all outputs are zero.
2. When start is asserted:
   a. If b > a, set valid=0 after 1 cycle (no solution)
   b. Else compute two potential x values:
      i. x1 = (a + b)/(2*k1) where k1 = ⌊(a + b)/(2*b)⌋
      ii. If possible, x0 = (a - b)/(2*k0) where k0 = ⌊(a - b)/(2*b)⌋
   c. Result is min(x0, x1) considering valid values
3. Implement fixed-point division using 32-cycle iterative algorithm
4. After 64 clock cycles, output valid=1 with Q32.32 result (or valid=0 if no solution)
5. All internal calculations use 64-bit Q32.32 fixed-point representation
6. Unusable x0 cases (k0 ≤ 0) should be ignored",
