Design a Verilog module named 'wiring_possibilities' that computes the number of valid apparatus wirings (mod 1000003) given up to 2 photos for 4 switches/lights.

Module interface:
module wiring_possibilities(
  input clk,               // clock signal
  input rst_n,             // active-low reset
  input start,             // start computation
  input [1:0] m,           // number of photos (0-2)
  input [3:0] photo1_sw,   // photo1 switch states
  input [3:0] photo1_lgt,  // photo1 light states
  input [3:0] photo2_sw,   // photo2 switch states
  input [3:0] photo2_lgt,  // photo2 light states
  output reg [19:0] result,// result modulo 1000003
  output reg done           // high when computation complete
);

Behavioral description:
- On start signal, module checks all 24 possible wiring permutations (4-switch to 4-light mappings)
- For each permutation, verify against all supplied photos (0-2):
  - For each photo, verify permuted switches match light states
- Count valid permutations that satisfy ALL photos
- Return (count % 1000003) after processing all permutations
- Module requires ~50 clock cycles to complete:
  - 24 permutations * 2 photos = 48 checks + overhead
- Use light-weight permutation generation with hardcoded mapping logic
- done signal asserts for 1 cycle when result is valid
