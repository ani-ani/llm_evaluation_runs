Design a sequential Verilog module named 'frog_regent' that computes proclamation sequences to transform frog arrangements for N=8 frogs.

Inputs:
input clk, // Clock
input rst_n, // Active-low reset
input start, // Start computation
input [3:0] init_seq [7:0], // Initial sequence (8 frogs, IDs 1-8)
input [3:0] target_seq [7:0] // Target sequence (8 frogs, IDs 1-8)

Outputs:
output reg [3:0] proclamation, // Current proclamation output (0 when done)
output reg done // High when entire sequence computed

Behavior:
1. When start=1, load init_seq and target_seq.
2. Module uses reverse simulation algorithm: from target sequence, undo proclamations until reaching initial sequence.
3. Each proclamation output is produced sequentially once per clock cycle when done=0.
4. After last proclamation, set done=1 and hold proclamation=0.
5. Allows max 16 proclamations (4-bit counter).

Timing:
- Each proclamation output appears 1 cycle after computation starts or previous proclamation.
- Latency: 1-16 cycles depending on required proclamations.

Implementation:
- Use a state machine: IDLE, COMPUTE, OUTPUT, DONE
- Maintain current sequence (8x4-bit registers)
- Reverse simulation: For n=1 to max_proclamations, find appropriate frog to "un-jump" from current sequence.
