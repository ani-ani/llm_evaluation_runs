Design a sequential Verilog module named 'max_flow' that computes the maximum flow from source to sink in an 8-node graph. Inputs: clk, rst_n (active low), start (initiates computation), node_count (3-bit input), edge_count (4-bit input), edges (16×48-bit memory: 16 edges × [3b u, 3b v, 16b cap]). Outputs: flow (16-bit maximum flow value), done (high when computation completes).

Module interface:
module max_flow(
  input clk,
  input rst_n,
  input start,
  input [2:0] node_count,
  input [3:0] edge_count,
  input [47:0] edges [0:15],
  output reg [15:0] flow,
  output reg done
);

Behavioral description:
- On reset, all registers are cleared and done=0
- When start is asserted:
  Initializes adjacency matrix
  Implements Ford-Fulkerson algorithm with BFS for augmenting paths
  Max possible flow is limited by 20-bit calculation (16-bit output)
- Completion: done signal asserts after 256 clock cycles maximum
- flow output remains valid until next reset/starts
Warning: Only computes flow value (not full edge list)
