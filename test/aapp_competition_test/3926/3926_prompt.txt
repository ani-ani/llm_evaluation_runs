Design a Verilog module named `maze_navigator` that counts reachable cells in an 8x8 maze with constrained left/right moves.

Module interface:
module maze_navigator(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [2:0] start_row, // Starting row (0-7)
  input [2:0] start_col, // Starting column (0-7)
  input [2:0] max_left, // Max left moves (0-7)
  input [2:0] max_right, // Max right moves (0-7)
  input [63:0] grid, // Flattened 8x8 maze (1 bit per cell: 0=free, 1=obstacle)
  output reg [5:0] reachable_count, // Number of reachable cells (0-64)
  output reg done // High when computation completes
);

Behavior:
1. On reset or power-up: Initialize all registers.
2. When start==1: Begin BFS traversal from (start_row, start_col).
3. Algorithm:
   - Track visited cells using 64-bit register
   - Track left/right move counts for each cell (3-bit counters)
   - Process cells in BFS order (priority: up/down moves first)
   - For each direction: check bounds, obstacles, and move budget
4. Output reachable_count after processing all accessible cells.
5. Module completes in <= 64 clock cycles after start is asserted
6. Use non-blocking assignments for all state updates

State machine states:
  IDLE -> PROCESSING -> DONE
Waveform expectations:
- done asserts exactly 1 cycle when computation finishes
- reachable_count becomes valid when done asserts
