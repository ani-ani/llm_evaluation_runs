Design a combinational Verilog module named 'palindrome_string_gen' that finds a string meeting these requirements:
1. Length N (3-bit input, 1-8)
2. Exactly K distinct characters (3-bit input, 1-5)
3. Longest palindromic substring length P (3-bit input, 1-8)

Inputs:
input [2:0] N,
input [2:0] K,
input [2:0] P

Outputs:
output reg [39:0] out_str,  // 8 chars * 5 bits each (32+8 unused bits)
output reg impossible        // 1 if no solution exists

Behavior:
- The module should output an 8-character string (5 bits per char) where only first N characters are valid
- Use precomputed patterns stored in lookup tables for all possible valid (N,K,P) combinations up to 8
- Assign impossible=1 when no string satisfies conditions
- Implement truth tables for all 8x5x8=320 possible input combinations
- Characters encoded as 5-bit values (0=a, 1=b, ..., 25=z)

Precomputed Examples:
N=6,K=5,P=3 → "rarity" (17,0,17,8,17,24) with added zero padding
N=5,K=3,P=5 → "madam" (12,0,3,0,12) with padding
N=9,K=8,P=1 → Scale to N=8,K=5,P=1 (modify constraints)
