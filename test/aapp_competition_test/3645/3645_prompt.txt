Design a sequential Verilog module named 'number_guesser' that analyzes a circular array to find uniquely identifiable numbers.

Module interface:
module number_guesser(
  input clk, 
  input rst_n, 
  input start, 
  input [3:0] n, // valid elements (2-8) 
  input [7:0] array [0:7], // circular 8-element array 
  output reg [7:0] valid_numbers [0:7], // output storage 
  output reg [3:0] count, // valid count (0 for none) 
  output reg done // computation complete 
);

Behavior:
1. On reset (rst_n=0): Clear outputs (count=0, done=0).
2. On start pulse: Analyze first 'n' array elements.
3. For each unique integer X in array:
   - Check if ALL occurrences of X satisfy:
     * For ANY query integer Y, there exists only ONE candidate X remaining
     * Considering ALL possible X/Y occurrence pairs
4. Store valid integers in 'valid_numbers' sorted in increasing order.
5. Computation completes within 50 cycles for worst-case n=8.
6. Outputs remain valid until next start pulse.

Implementation requirements:
- Use state machine with states: IDLE, COUNT_SAMPLES, CHECK_CONDITION, SORT_OUTPUT, DONE
- All outputs registered
- Proper pipeline stall/start handling
- Must handle circular indexing (position n-1 adjacent to position 0)
