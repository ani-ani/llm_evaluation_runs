Design a sequential Verilog module named 'travel_frustration_minimizer' that finds the minimal frustration path from country 1 to country n (max 5 nodes) with up to 8 flights.

Module interface:
module travel_frustration_minimizer(
  input clk,              // system clock
  input rst_n,            // active-low reset
  input start,            // pulse high to start computation
  input [2:0] target_n,   // destination country (value 1-5)
  input [31:0] flight_table [0:7][0:3], // [8 flights][a:3b, b:3b, s:7b, e:7b] (a,b: country IDs, s: departure, e: arrival)
  output reg [31:0] min_frustration, // accumulated T^2 sum
  output reg done         // high when computation finished
);

Behavioral description:
1. Implements modified Dijkstra's algorithm with priority on minimal t^2 sum.
2. Maximum 5 nodes (3-bit addressing).
3. Maintain 5x32-bit frustration array (initially all MAXINT except country 1=0).
4. At each clock cycle, process all possible flights (8 max) from current nodes.
5. Compute wait time (flight_departure - last_arrival) and frustration.
6. Update frustration array if new path has less accumulated frustration.
7. Mark done when all paths to target_n have been evaluated.
Timing: Results valid within 15 clock cycles after start. Use states: IDLE, LOAD, PROCESS, FINISH. Reset initializes all registers.
