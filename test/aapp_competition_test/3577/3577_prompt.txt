Design a sequential Verilog module named 'plant_flowers' that tracks new flowers from plant stem intersections. Use active-low reset and store up to 8 plants.

Module interface:
module plant_flowers(
    input clk,                       // clock
    input rst_n,                     // active-low reset
    input start,                     // start processing
    input [7:0] L,                   // left stem (1 <= L < R)
    input [7:0] R,                   // right stem (L < R <= 255)
    output reg [4:0] num_flowers,    // number of new flowers (max 15)
    output reg done                  // done flag (high for 1 cycle)
);
Behavior:
1. Reset (rst_n=0): Clear plant memory and set count=0
2. On start pulse:
   a. Combinationally compute flowers: for all stored plants, count where L is between (Lj,Rj) OR R is between (Lj,Rj)
   b. Output result immediately on num_flowers
3. Next rising edge:
   a. Store new plant if count < 8
   b. Increment plant count
   c. Pulse done=1 for 1 cycle
Maximum plants: 8, coordinates: 8-bit. Plants stored in registers L_arr[0:7], R_arr[0:7]. Use 3-bit counter for current count (0-7).
