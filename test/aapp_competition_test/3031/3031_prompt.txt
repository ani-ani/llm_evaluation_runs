Design a sequential Verilog module named 'good_node_finder' that identifies all good nodes in a small tree where:
- Tree has maximum 8 nodes (3-bit IDs)
- Each edge has a color ID (3-bit)
- Good nodes are those where all paths from root have no consecutive same colors

Module interface:
module good_node_finder(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // start computation
  input [2:0] edge_count, // number of edges (n-1, 0-7)
  input [2:0] node_a [0:7], // parent nodes (max 8 edges)
  input [2:0] node_b [0:7], // child nodes
  input [2:0] color [0:7], // edge colors
  output reg [7:0] good_nodes, // bitmask of good nodes (1-indexed)
  output reg done // high when computation complete
);

Behavioral description:
- On reset, clear all outputs
- When start is asserted:
  - For each node (1-8), traverse all paths starting from it
  - Check that all paths have no consecutive edges with same color
  - Node is 'good' if it passes these checks
- Use a state machine with:
  - IDLE: Wait for start
  - CHECK_NODE: Process each node (3-bit counter)
  - TRAVERSE: Check paths from current node (child color tracking)
  - DONE: Assert done and output results
- Latency: Completion within 256 cycles maximum
- good_nodes output is 8-bit mask where bit 0 = node1, bit1 = node2, etc.
