Design a Verilog module named 'partner_diversity' that computes the maximum diversity after awakening up to k partners.

Module interface:
module partner_diversity(
  input clk,  // Clock signal
  input rst_n,  // Active-low reset
  input start,  // Start computation
  input [7:0] partner0_g, input [7:0] partner0_p, input [7:0] partner0_ga, input [7:0] partner0_pa,  // Partner 0 characteristics (0 when not awakenable)
  input [7:0] partner1_g, input [7:0] partner1_p, input [7:0] partner1_ga, input [7:0] partner1_pa,  // Partner 1 characteristics
  input [7:0] partner2_g, input [7:0] partner2_p, input [7:0] partner2_ga, input [7:0] partner2_pa,  // Partner 2 characteristics
  input [7:0] partner3_g, input [7:0] partner3_p, input [7:0] partner3_ga, input [7:0] partner3_pa,  // Partner 3 characteristics
  input [1:0] k,  // Maximum awakenings allowed (0-3)
  output reg [2:0] diversity,  // Result diversity (0-4)
  output reg done  // High when computation completes
);

Behavioral description:
- The module should compute the maximum diversity d(S) for 4 partners with up to k awakenings
- Diversity is defined as the largest set where no partner dominates another (both Frag and Step strictly greater)
- When start is asserted, the module begins processing
- Should consider all possible awakening combinations (2^4=16 possibilities with up to k awakenings)
- For each combination, compute whether awakened/normal state meets domination conditions
- Find the maximum non-dominated set size across all valid awakening choices
- Output 'diversity' result and assert 'done' after 20 clock cycles
- Use a state machine with IDLE, CALCULATING, DONE states to control operation
