Design a sequential Verilog module named 'grid_solver' that determines if a 4x4 grid can be solved with minimum row/column increments. Inputs: clk, rst_n (active low), start (begin computation), grid input as 4x4 array of 8-bit values (grid[0][0] to grid[3][3]).

Outputs: valid (high when done), error (high if impossible), move_count[7:0] (valid moves when no error).

Behavior: On start, the module subtracts row minima then column minima. If all grid cells become zero, output move_count = sum(row_mins) + sum(col_mins) with error=0. Otherwise, error=1. Computation completes in 20 cycles max after start assertion. Reset initializes all registers.

Module interface:
module grid_solver(
  input clk, 
  input rst_n, 
  input start, 
  input [7:0] grid [0:3][0:3], 
  output reg valid, 
  output reg error, 
  output reg [7:0] move_count 
);
