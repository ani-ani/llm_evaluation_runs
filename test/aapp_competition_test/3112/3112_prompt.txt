Design a sequential Verilog module named 'conveyor_scheduler' that calculates the maximum active producers without belt conflicts.
Inputs:
  input clk,              // clock signal
  input rst_n,            // active-low reset
  input start,            // start computation
  input [2:0] N,          // junctions (3 bits, max 8)
  input [1:0] K,          // producers (2 bits, max 4)
  input [3:0] M,          // conveyor belts (4 bits, max 16)
  input [15:0][1:0] edges // 16 edges (each 2*3 bits: a[2:0],b[2:0])
Outputs:
  output reg [1:0] max_producers, // result (max 4)
  output reg done           // high when computation complete
Behavior: 
1. On reset: clear all states
2. When start asserted:
   a) Find shortest paths from each producer (1-K) to warehouse (junction N)
   b) Calculate time slots when each belt would be used
   c) Detect conflicts between producers' belt usage patterns
   d) Find maximum subset of producers with no overlapping belt usage
3. Algorithm:
   - Use BFS for path finding (limited to 8-node graph)
   - Track belt usage patterns as modulo schedules (period = K)
   - Compare producer schedules using conflict detection logic
4. Timing: Output valid 64 clock cycles after start with result
5. Implementation: Use state machine with states IDLE, FIND_PATHS, CHECK_CONFLICTS, CALC_RESULT, DONE
