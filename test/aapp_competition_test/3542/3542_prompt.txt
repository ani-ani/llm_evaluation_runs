Design a sequential Verilog module named 'wire_routing' that finds the minimum wire length for connecting two point pairs on an 8x8 grid without shared vertices.

Module interface:
module wire_routing(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [2:0] n, // Grid rows (2-7)
  input [2:0] m, // Grid columns (2-7)
  input [5:0] a1, // {x1[2:0], y1[2:0]}
  input [5:0] a2, // {x2[2:0], y2[2:0]}
  input [5:0] b1, // {x3[2:0], y3[2:0]}
  input [5:0] b2, // {x4[2:0], y4[2:0]}
  output reg [5:0] result, // {1'b0, length[4:0]} or 6'b100000 for impossible
  output reg done // High when result valid
);

Behavior: On start, compute minimum Manhattan paths for A and B pairs that don't share any vertices. Output 5-bit length + 1-bit valid flag. Latency: Output valid within 256 cycles after start. Use Manhattan distance with path validation.
