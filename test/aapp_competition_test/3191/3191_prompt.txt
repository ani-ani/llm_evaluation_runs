Design a Verilog module named crashing_line_cost that computes the minimal worst-case time to find a crashing line using optimal printf placement strategy.

Inputs:
  input [3:0] n,   // Number of code lines (1-16)
  input [31:0] r,  // Compile/run time until crash
  input [31:0] p   // Time to add printf statement

Output:
  output reg [31:0] cost  // Minimal worst-case search time

Behavioral description:
The module computes T(n) = 0 when n = 1. For n > 1, it evaluates all possible k (1 ≤ k ≤ n-1) splits where k is number of printf statements. For each k, the worst-case segment size after split is ceil(n/(k+1)). The cost for that k is p*k + r + T(ceil(n/(k+1))). The module calculates cost for each k and outputs the minimum value.

Implementation note:
This is a combinational module. Precompute T values from n=1 upwards using the recurrence relation and select output based on input parameters.
