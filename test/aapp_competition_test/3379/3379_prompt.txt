Design a sequential Verilog module named 'max_kahn_sources' that finds the maximum source set size during topological sorting.

Module interface:
module max_kahn_sources(
  input clk, 
  input rst_n, 
  input start, 
  input [2:0] num_nodes, // max 8 nodes (0-7)
  input [5:0] num_edges, // max 56 edges (for n=8)
  input [2:0] edge_src [0:55], // flattened edges (src)
  input [2:0] edge_dst [0:55], // flattened edges (dst)
  output reg [3:0] max_S_size, // max possible sources (0-8)
  output reg done
);

Behavioral description:
1. On reset or start=0, initialize all registers
2. When start=1:
   a. Build adjacency matrix (8x8 reg) and in-degree count (8x4-bit reg)
   b. Initialize source set S with nodes having zero in-degree
   c. Initialize max_S_size with current |S|
   d. Iteratively:
      i. Remove a node α from S
      ii. Decrement in-degree of its neighbors
      iii. Add new sources to S
      iv. Track maximum |S| encountered
   e. Continue until S is empty
3. Output max_S_size when done=1 after ~50 cycles (8 nodes * 6 cycles/node)

Implementation notes:
- Use a state machine: IDLE, INIT, PROCESS, DONE
- Represent graph with 8x8 adjacency matrix
- Track in-degrees in 4-bit registers (max 7 in-degree)
- Use parallel comparators to detect new sources
- Maintain max_S_size register that tracks maximum |S| encountered
- Node removal order doesn't affect max size tracking (only size matters)
