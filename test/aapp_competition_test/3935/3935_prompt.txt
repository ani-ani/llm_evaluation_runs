Design a Verilog module named 'bipartite_graph_eraser' that finds minimum elements to erase for graph bipartition.

Module interface:
module bipartite_graph_eraser(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // start processing
  input [15:0] data_in, // input element (16-bit)
  output reg [15:0] erased_element, // current erased element (0 if none)
  output reg element_valid, // high when erased_element valid
  output reg [3:0] erased_count, // total erased count (3-bit width for up to 15 elements)
  output reg done // high when processing complete
);

Behavior:
1. On reset, clear all internal state
2. Accept 8 input elements sequentially (each applied with data_in when start high)
3. For each element, calculate exponent of 2 (count trailing zeros) in data_in
4. Track group sizes by exponent (max exponent value: 15, 4-bit counters)
5. After all inputs, find group with max elements
6. Output elements not in max group sequentially (one per clock cycle)
7. Set done high after all erased elements output

Latency: Takes 8 cycles to load inputs, plus up to 8 cycles for output (total max 16 cycles)
State Machine:
- IDLE: Wait for start
- LOAD: Capture 8 input elements (one per cycle)
- PROCESS: Calculate max group and prep outputs
- OUTPUT: Send erased elements one per cycle
- DONE: Signal completion
