Design a sequential Verilog module named 'max_card_score' that computes the maximum card arrangement score.
Inputs:
  input clk,              // Clock
  input rst_n,            // Active-low reset
  input start,            // Start computation (pulse high to begin)
  input [7:0] a,          // Number of 'o' cards (0-255)
  input [7:0] b           // Number of 'x' cards (0-255)
Outputs:
  output reg signed [16:0] max_score,  // Maximum score (signed 17-bit)
  output reg done          // High when computation completes
Functionality:
1. On reset or power-up: max_score=0, done=0.
2. When start is pulsed high:
   - For group counts i from 2 to min(a+2, b+1):
      * Compute v1 = (a+2-i)(a+2-i) + (i-2)
      * Split b: quo=b/i, rem=b%%i
      * Compute v2 = rem*(quo+1)(quo+1) + (i-rem)*(quo*quo)
      * Track max(v1 - v2)
   - After all iterations, output final max_score and assert done.
3. If a=0, max_score=-b*b. If b=0, max_score=a*a. (Special cases)
Timing:
  - Computation starts on rising edge after start assertion
  - Done asserts after MAX_ITERATIONS clock cycles (16 cycles) + 1 cycle special cases
Implementation Notes:
  - Use signed arithmetic for score differences
  - Implement division via iterative subtraction (or small lookup table if needed)
