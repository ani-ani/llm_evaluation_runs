Design a sequential Verilog module named 'cake_partition_checker' that determines if m straight cuts divide n candles into unique regions.
Module interface:
module cake_partition_checker(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [2:0] n, // Number of candles (1-8)
  input [1:0] m, // Number of cuts (1-4)
  input [15:0] r, // Cake radius (0-65535)
  // Candle coordinates: 8 max, each has x[15:0], y[15:0]
  input [15:0] candle_x[0:7],
  input [15:0] candle_y[0:7],
  // Cut coefficients: 4 max, each has a[7:0], b[7:0], c[15:0]
  input [7:0] cut_a[0:3],
  input [7:0] cut_b[0:3],
  input [15:0] cut_c[0:3],
  output reg result, // 1=yes, 0=no
  output reg done // High when computation completes
);

Behavioral description:
1. Compute ax + by + c sign for each candle and cut (30-bit signed math)
2. Generate 4-bit signature per candle (1 bit per cut)
3. Check all candles have unique signatures
4. Result asserts when done=1, after 25 clock cycles

Latency: 2 cycles per candle (8 candles * 3 operations) + 1 comparison cycle = 25 cycles (1 cycle reset, 16 calculation, 8 check).
