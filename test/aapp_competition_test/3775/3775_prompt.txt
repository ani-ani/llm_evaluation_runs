Design a combinational Verilog module named 'participant_deduction' that determines the shared number between two participants based on communicated pairs.
Module interface:
module participant_deduction(
  input [3:0] n,          // First participant pairs count (1-8)
  input [3:0] m,          // Second participant pairs count (1-8)
  input [63:0] a_pairs,   // 8 pairs (16 x 4-bit numbers, each pair = {x,y}[7:0])
  input [63:0] b_pairs,   // Same for second participant
  output [3:0] result     // 1-9=number, 0=both know, 15=-1
);
Behavior:
1. Treat a_pairs as 8 consecutive pairs (pair0=bits[63:56], pair1=bits[55:48], etc)
2. For i in 0-7 and j in 0-7: Compare a_pair[i] with b_pair[j] if (i < n) && (j < m)
3. For each valid pair comparison:
   - Skip if identical pairs
   - If exactly one common number (A,B -> A in B or B in A):
     * Add to global candidates set
     * Record as possible for current a_pair and b_pair
4. Final decision:
   - If |candidates|==1 → output number
   - Else if all a_pairs' possible set ≤1 && all b_pairs' possible set ≤1 → output 0
   - Else → output 15 (-1)
The module must compute result combinationally without clocks.
