Design a Verilog module named 'graph_color' that computes the minimum coloring of an undirected graph with up to 8 vertices.

Module interface:
module graph_color(
  input clk,           // Clock signal
  input rst_n,         // Active-low reset
  input start,         // Start computation (pulse high)
  input [2:0] n_val,   // Number of vertices (2-8)
  input [63:0] adjacency, // Adjacency matrix (8x8 flattened)
  output reg [3:0] colors, // Minimum color count result
  output reg done      // High when computation complete
);

Behavioral description:
- On reset, set colors=0 and done=0
- When start is detected:
  1. Begin graph coloring algorithm using greedy method or backtracking
  2. Compute minimum colors needed for the given adjacency matrix
  3. Validate no adjacent vertices share same color (edges defined by adjacency)
  4. When complete, assert done and output colors on next clock cycle
- Algorithm must complete within 1024 cycles (suitable for N=8)
- Only consider first n_val vertices (ignore higher matrix bits when n_val<8)
- adjaceny[i*8 + j] bit indicates edge between vertex i and j (symmetric)
- Each vertex can have maximum 7 edges (connected graph assumption)
