Design a sequential Verilog module named 'card_shuffle_counter' that determines the minimum number of riffle shuffles needed to transform a sorted deck into a given permutation.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [3:0] card_in // current card value (1-8) presented sequentially
input valid // indicates card_in is valid

Outputs:
output reg [1:0] result // minimum shuffles needed (0-3)
output reg done // high when computation complete

Behavioral Description:
The module receives 8 cards sequentially (values 1-8) representing a permutation. It must determine the minimum number of shuffles (0-3) needed to achieve this ordering from sorted 1,2,3,4,5,6,7,8.

Algorithm Approach:
- Store the 8-card permutation in a buffer
- Check if already sorted (0 shuffles)
- For 1 shuffle: Check if permutation can be formed by one split/interleave
- For 2 shuffles: Check if permutation can be unshuffled twice
- For 3 shuffles: Otherwise output 3

A permutation can be unshuffled if cards maintain relative order within each half of some split.

Implementation uses a state machine with states:
- IDLE: Wait for start
- COLLECT: Receive 8 cards
- CHECK_0: Verify if sorted
- CHECK_1: Verify if 1 shuffle achievable
- CHECK_2: Verify if 2 shuffles achievable
- DONE: Output result

Latency: Result valid 20 clock cycles after start asserted.

Signal widths:
- card_in: 4 bits (values 1-8)
- result: 2 bits (0-3)
- Internal buffer: 8 x 4-bit registers

The module should use combinational logic for the shuffle checking conditions.
