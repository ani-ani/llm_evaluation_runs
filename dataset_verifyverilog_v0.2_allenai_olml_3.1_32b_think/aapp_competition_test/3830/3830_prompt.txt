Design a sequential Verilog module named 'snake_exhibition' that determines the number of returnable rooms in a circular snake exhibition.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [2:0] n // Number of rooms (scaled to max 8)
input [7:0] s // String representing belt states (8 bits, 1 bit per room). 0='-', 1='<', 2='>'

Outputs:
output reg [3:0] result // Number of returnable rooms (max 8)
output reg done // High when computation complete

Behavior:
A room is returnable if:
1. The belt leaving the room (index i) is '-' (off), OR
2. The belt entering the room (index i-1) is '-' (off), OR
3. Both adjacent belts are '<' (anticlockwise), OR
4. Both adjacent belts are '>' (clockwise).

The module should use a state machine with states: IDLE, PROCESSING, DONE.
In the PROCESSING state, iterate through 'n' rooms (indices 0 to n-1). For each room, check the conditions and increment 'result'.
Latency: Result valid X clock cycles after start asserted (dependent on n).
