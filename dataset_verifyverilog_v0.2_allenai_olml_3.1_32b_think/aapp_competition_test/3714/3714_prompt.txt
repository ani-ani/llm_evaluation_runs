Design a sequential Verilog module named 'crush_game' that implements the simplified Crush Game problem for a small fixed graph.

The module finds the smallest t (t >= 1) such that for each person x, if x starts a round and y becomes the Joon-Joon, then starting from y returns to x. This requires detecting all cycles in the graph and computing LCM of adjusted cycle lengths (odd cycles use full length, even cycles use half length). If any node is not part of a valid cycle reaching back to itself, output -1.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [3:0] n // number of people (max 16)
input [15:0] crush [15:0] // array of crush values (0-indexed, max 16 nodes)

Outputs:
output reg [31:0] result // result t or -1
output reg done // high when computation complete

Specify latency: Result valid 256 clock cycles after start asserted.
Use state machine with states: IDLE, INIT, CHECK_CYCLES, COMPUTE_LCM, DONE.

Behavioral Description:
1. On start, validate input: n must be <= 16.
2. Check if all nodes reach a valid cycle back to themselves within n steps. If any node fails (or forms a path not leading to self-cycle), set result = -1.
3. For each valid cycle, calculate its length.
4. Adjust cycle length: if even, divide by 2; if odd, keep as is.
5. Compute LCM of all adjusted cycle lengths.
6. Output the final LCM value.

Implementation notes:
- Use state machine for sequential control
- Use internal registers for cycle detection
- Compute GCD for LCM calculation
- All indices are 0-based internally
