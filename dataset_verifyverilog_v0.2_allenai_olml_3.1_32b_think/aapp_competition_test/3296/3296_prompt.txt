Design a sequential Verilog module named 'permutation_counter' that counts permutations of N elements with order exactly K.

Problem Adaptation:
- N is limited to 3 bits (1 to 7)
- K is limited to 6 bits (1 to 8)
- No modulo arithmetic needed (small outputs)
- Implement cycle decomposition logic:
  1. Generate all partitions of N
  2. For each partition, check if LCM of cycle lengths equals K
  3. Calculate number of permutations for that partition

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [2:0] N // Number of elements (1 to 7)
input [5:0] K // Target order (1 to 8)

Outputs:
output reg [31:0] result // Result count
output reg done // Computation complete

Latency: 1000 clock cycles (worst case for N=7, K=8)

Implementation Details:
- Use state machine: IDLE -> GENERATE_PARTITIONS -> CHECK_LCM -> CALCULATE -> DONE
- Pre-compute factorials (0! to 7!)
- Use cycle length partition generator (max 7 elements)
- LCM computation for up to 7 numbers (cycle lengths)
- Calculate partition count: N! / (prod(c_i^{m_i} * m_i!)) where m_i is count of cycles of length i
- Result is sum over valid partitions

The module should be fully combinational within each state, advancing on clock edges.
