Design a sequential Verilog module named 'chile_shortest_path' that computes shortest paths for a scaled-down version of the Chile travel problem.

The module implements Dijkstra's algorithm to find the shortest time from city 1 to all other cities. The graph has at most N=8 nodes.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [7:0] valid_nodes // Bitmask indicating which cities exist (0-indexed, city 1 is bit 0)

// City data arrays (8 cities maximum, index 0 to 7)
// Index 0 corresponds to city 1 in the problem description
input [15:0] y_coords [0:7] // y-coordinates (scaled integers)
input [15:0] d_mins [0:7] // minimum flight distances
input [15:0] r_times [0:7] // fixed travel times

Outputs:
output reg [15:0] dist [0:7] // Shortest time to each city (0xFFFF if unreachable)
output reg done // High when computation is complete

Behavior:
1. The module initializes distance to city 0 (city 1 in problem) to 0, all others to infinity (0xFFFF).
2. It iteratively selects the unvisited node with the smallest tentative distance.
3. For the selected node u, it updates distances to all nodes v where |y[u] - y[v]| >= d[u].
   Edge weight = r[u] + |y[u] - y[v]|.
4. Runs for a fixed maximum of 8 iterations to ensure termination.
5. Outputs updated distances to 'dist' array when done goes high.

Latency: Approximately 100-200 clock cycles depending on internal state machine implementation.

State Machine States: IDLE, SELECT_MIN, UPDATE_NEIGHBORS, CHECK_COMPLETION, FINISHED.
