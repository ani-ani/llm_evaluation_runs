Design a Verilog module named 'GnomeDamageOptimizer' that solves the optimal gnome grouping problem using binary search.

Problem: Find max damage with n gnomes, m groups, and k damage per bolt. The optimal strategy involves finding a batch size x such that the damage function is maximized.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start calculation
input [63:0] n // Total gnomes (up to 1e9)
input [63:0] m // Number of groups (up to 1e7)
input [63:0] k // Damage per bolt (up to 1e7)

Outputs:
output reg [63:0] max_damage // The calculated maximum damage
output reg done // High when calculation is complete

Internal Logic:
The module should implement a binary search for the optimal batch size x (number of gnomes per group, assuming equal division except for remainders).
1. The search range is from low=1 to high=n/m (integer division).
2. In each clock cycle, calculate the damage for the midpoint of the current range using combinational logic.
3. Compare the damage of the midpoint and its right neighbor (mid+1) to determine the gradient.
4. Update the search range (low or high) based on the gradient.
5. When the search range collapses (low >= high), the optimal x is found. Calculate the final damage using the exact formula and assert 'done'.

The combinational damage calculation for a given batch size x must handle:
- R = ceil(n/x) (rounds up)
- Base damage = n * R
- Reduction due to batching = (x * R * (R-1)) / 2
- Bolt penalty = k * sum of remaining enemies over m-1 turns (use iterative subtraction logic in hardware or simplified formula)

Timing: This is a multi-cycle operation. Expect 100+ cycles depending on the width of n. Ensure the state machine handles IDLE, SEARCH, and DONE states correctly.
