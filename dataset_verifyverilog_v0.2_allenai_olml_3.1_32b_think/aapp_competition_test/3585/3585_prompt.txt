Design a sequential Verilog module named 'bag_capacity' that calculates the maximum number of bags for which you can determine the fake bag in m weighings with k coins per bag.

The problem mathematically reduces to computing: Result = (2m + 1)^k

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [7:0] m // Number of weighings (scaled, max 8)
input [3:0] k // Number of coins per bag (scaled, max 4)

Outputs:
output reg [31:0] result // Result modulo 998244353
output reg done // High when computation complete

Specification:
- Use a sequential state machine to compute (2*m + 1)^k iteratively.
- Since m <= 8 and k <= 4, the base is <= 17 and exponent <= 4.
- Maximum intermediate value: 17^4 = 83521, which fits in 17 bits.
- However, output is modulo 998244353. Even though raw value fits, we perform modulo arithmetic.
- State machine states: IDLE, CALC_BASE, MULTIPLY, DONE.
- In IDLE: Wait for start signal.
- In CALC_BASE: Compute base = (2*m + 1).
- In MULTIPLY: Perform k multiplications of result by base, updating result = (result * base) % 998244353.
- In DONE: Assert done signal.
- Latency: Approximately k+2 clock cycles after start.
- Use non-blocking assignments for sequential logic.
