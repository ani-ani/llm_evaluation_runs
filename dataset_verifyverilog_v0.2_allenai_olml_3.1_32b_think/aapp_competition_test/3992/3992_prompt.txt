Design a sequential Verilog module named 'chocolate_distribution' that computes the minimum seconds needed to rearrange chocolates so all boxes are divisible by some k > 1.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [7:0] n // Number of boxes (max 16)
input [15:0] sum_total // Total sum of chocolates
input [7:0] a [0:15] // Array of 16 values, each 0-255

Outputs:
output reg [31:0] result // Minimum seconds needed
output reg done // High when computation complete
output reg no_solution // High if no solution exists

Latency: Approximately 100 clock cycles (depends on number of prime factors).

Algorithm:
1. If sum_total == 1, return -1 (no solution).
2. Find all prime factors of sum_total (max 4-5 factors for small sums).
3. For each prime factor p:
   - Calculate cost using the residue method:
     - Maintain running remainder r = (r + a[i]) % p
     - Cost contribution for each step: min(r, p - r)
   - Track minimum cost across all primes.
4. Return minimum cost.

Implementation details:
- Use a state machine: IDLE, FACTORIZE, CALCULATE_COST, DONE
- Factorize state: Extract prime factors of sum_total
- Calculate state: Iterate through array a, compute costs for each prime
- Store intermediate results in registers
- Use combinational logic for modulo and min operations

The module should handle up to 16 input values with maximum value 255.
