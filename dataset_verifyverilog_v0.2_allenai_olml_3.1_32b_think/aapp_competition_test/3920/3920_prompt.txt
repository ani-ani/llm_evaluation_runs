Design a combinational Verilog module named 'hexagon_triangles' that calculates the number of 1x1 triangles in a hexagon with equal angles (120 degrees) and integer side lengths.

The hexagon is split into unit equilateral triangles by lines parallel to the sides. The number of triangles is given by the formula:
Count = (a1 + a2 + a3)^2 - a1^2 - a3^2 - a4^2
where a1 through a6 are the side lengths in clockwise order.

Inputs:
input [7:0] a1 // side length 1 (0-255)
input [7:0] a2 // side length 2 (0-255)
input [7:0] a3 // side length 3 (0-255)
input [7:0] a4 // side length 4 (0-255)
input [7:0] a5 // side length 5 (0-255)
input [7:0] a6 // side length 6 (0-255)

Outputs:
output [31:0] count // total number of unit triangles

The module should be purely combinational. The maximum intermediate value is approximately (3*255)^2 = ~585,225, so a 20-bit result is sufficient, but we use 32 bits for safety. Input constraints are scaled to 8-bit (0-255) to fit hardware constraints while preserving the problem's mathematical structure.
