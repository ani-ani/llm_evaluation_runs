Design a sequential Verilog module named 'word_guess_solver' that implements a simplified word game solver.

The module processes a hidden word pattern with some revealed letters and a list of candidate words, finding letters that are guaranteed to be present in all valid candidates.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [4:0] n // word length (max 16)
input [127:0] hidden_pattern // hidden word packed into 128 bits (16 chars * 8 bits)
input [4:0] m // number of words (max 16)
input [127:0] word_list [0:15] // array of 16 words, each 128 bits

Outputs:
output reg [3:0] result_count // number of guaranteed letters
output reg done // high when computation complete

Specify latency: Result valid 20 clock cycles after start asserted.

Behavioral Description:
1. When start is asserted, the module reads the hidden pattern and word list.
2. Filter words: A word is valid if:
   - At revealed positions (where hidden_pattern has non-*) matches exactly
   - At unknown positions (where hidden_pattern has *), the letter is NOT in the set of already revealed letters
3. For all valid words, extract the letters at unknown positions.
4. Calculate the intersection of these letters across all valid words.
5. Output the count of letters in the intersection.

The module should use a state machine with states: IDLE, LOAD, FILTER, INTERSECT, DONE.

Use ASCII encoding (8 bits per character). '*' is represented as 0x2A.

Use byte-addressable access for the pattern and word list.

Example: hidden_pattern "a**d" (n=4) with words "abcd", "acbd".
Revealed: 'a', 'd'. Unknown positions: 1, 2.
Valid words: Both pass reveal checks.
Unknown letters: "abcd" -> {'b','c'}, "acbd" -> {'c','b'}.
Intersection: {'b','c'}.
Result count: 2.
