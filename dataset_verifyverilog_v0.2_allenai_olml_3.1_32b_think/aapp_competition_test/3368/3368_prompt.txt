Design a sequential Verilog module named 'sanitaire' that determines if all misplaced animals can be returned to proper enclosures under movement restrictions.

Inputs:
input clk // clock signal
input rst_n // active-low reset  
input start // start computation
input [7:0] enclosure_count // number of enclosures (N ≤ 4)
input [7:0] animal_count // total animals (M ≤ 8)
input [7:0] correct_animal [0:3] // correct animal per enclosure (8-char name hashed to 8-bit)
input [7:0] num_animals [0:3] // count of animals per enclosure
input [7:0] animal_types [0:7] // flattened list of animal types across all enclosures
input [7:0] enclosure_idx [0:7] // which enclosure each animal belongs to

Outputs:
output reg [1:0] result // 0=FALSE ALARM, 1=POSSIBLE, 2=IMPOSSIBLE
output reg done // high when computation complete

Behavior: 
- Latency: ~20 clock cycles after start
- Use IDLE, BUILD_GRAPH, CHECK_CONNECTIVITY, DONE states
- Hash animal names to 8-bit values: sum of ASCII mod 256
- Build adjacency matrix for 4x4 enclosures
- A enclosure has incorrect animals if any animal != correct_animal[i]
- Edge from i to j if enclosure i contains animals belonging to j (i≠j)
- Check if all enclosures with incorrect animals form connected component
- If no incorrect animals → FALSE_ALARM
- If connected → POSSIBLE
- If disconnected but has incorrect → IMPOSSIBLE
