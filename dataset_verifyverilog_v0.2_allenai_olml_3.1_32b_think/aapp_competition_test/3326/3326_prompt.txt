Design a sequential Verilog module named 'monotonic_subgrids' that counts monotonic subgrids in a small 4x4 grid.

The module should handle:
- A 4x4 grid of 8-bit numbers (range 0-255)
- Check all possible subgrids (rows and columns subsets)
- A subgrid is monotonic if each selected row is either strictly increasing OR strictly decreasing, AND each selected column is either strictly increasing OR strictly decreasing

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [7:0] grid [0:3][0:3] // 4x4 grid, 8-bit values

Outputs:
output reg [15:0] result // count of monotonic subgrids (max: 81 subgrids)
output reg done // high when computation complete

Latency: Result valid 100 clock cycles after start asserted.

Implementation details:
1. The module iterates through all possible subsets of rows and columns
2. For each subgrid, extract the selected elements in order
3. Check monotonicity: For rows, each row in subgrid must be strictly increasing OR strictly decreasing
4. For columns, each column in subgrid must be strictly increasing OR strictly decreasing
5. If both conditions are satisfied, increment result counter
6. Use a state machine with states: IDLE, SETUP, CHECK_ROWS, CHECK_COLS, INCREMENT, DONE
7. Implement parallel comparators for small subgrids (max 4x4)

Edge cases:
- 1x1 subgrids are always monotonic
- Single row or single column subgrids only need row or column checks respectively
- Empty subsets are not considered (non-empty subgrids only)

Example:
For grid [[1,2,5],[7,6,4],[9,8,3]], all 49 subgrids are monotonic.

Signal widths:
- Grid values: 8 bits
- Result counter: 16 bits (sufficient for up to 255 subgrids)
- Row/column indices: 2 bits (for 4 rows/columns)
- Subgrid dimension counters: 2 bits each
