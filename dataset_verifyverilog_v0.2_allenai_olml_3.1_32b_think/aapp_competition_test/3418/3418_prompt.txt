Design a sequential Verilog module named 'lucky_numbers_supply' that counts the number of 'lucky numbers' with n digits.

A lucky number has the property that for each k from 1 to n, the number formed by its first k digits is divisible by k.

For HDL feasibility, we scale to support n up to 8 digits.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [3:0] n // number of digits (1-8)

Outputs:
output reg [31:0] supply // count of lucky numbers
output reg done // high when computation complete

Latency: Result valid approximately 64 clock cycles after start asserted (8 positions × 8 states)

Specification:
- Use state machine with states: IDLE, COUNTING, DONE
- Use dynamic programming approach: for each digit position i (1 to n), track remainders mod i
- At position i, valid digits are those that form a number divisible by i
- Count all valid sequences that satisfy divisibility at each step
- Store counts for each remainder state for current position
- Output the sum of counts after position n

Implementation Details:
- Use iterative approach: for each position, compute next state from previous
- Position 1: digits 1-9 (no leading zero), count those divisible by 1 (all of them)
- Position 2: from each valid position-1 state, try digits 0-9, check if (prev*10 + digit) % 2 == 0
- Position 3: similar check with modulus 3, and so on
- Use combinational logic to compute next counts for each remainder
- Maximum remainder at position i is i-1
- Store counts in registers, update each cycle

Example: For n=2, answer is 45 (numbers 10,12,14,...,98 where first digit divisible by 1, two-digit number divisible by 2)
For n=3, answer is 150

Module must compute supply count correctly for given n.
