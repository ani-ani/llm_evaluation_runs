Design a sequential Verilog module named 'media_companies' that solves the Equestria Games broadcasting problem.

Problem Adaptation:
- Stadium has N=8 sectors (instead of up to 200,000)
- Each sector has a team ID represented as 4 bits (supporting values 0-15)
- Minimum K sectors required per media company (K parameter, 1-8)
- Minimum C distinct colors required per media company (C parameter, 1-8)
- The stadium is a ring, so we need to handle circular ranges
- We want to find the maximum number of non-overlapping valid ranges

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [3:0] k_min // minimum sectors (K)
input [3:0] c_min // minimum distinct colors (C)
input [7:0][3:0] sectors // array of 8 sectors, each with 4-bit team ID

Outputs:
output reg [3:0] max_companies // maximum number of media companies
output reg done // high when computation complete

Specification:
1. The module must handle the ring structure by considering the stadium as sectors[0:7] and sectors[0:3] again (duplicated start)
2. For each possible starting position i (0-7), consider ranges of length K that wrap around
3. A valid range has at least C distinct colors
4. Find the maximum number of non-overlapping valid ranges
5. Use a sliding window approach with state machine
6. For distinct color counting, use parallel comparison logic
7. Latency: Result valid within 128 clock cycles after start asserted

State Machine States:
- IDLE: Wait for start signal
- INIT: Initialize search parameters
- CHECK_RANGE: Check each possible range starting position
- COUNT_COLORS: Count distinct colors in current range
- VALIDATE: Determine if range is valid
- SELECT: Greedily select non-overlapping valid ranges
- DONE: Finalize result

Implementation Details:
- Use 8-bit shift register or window buffer for sliding window
- For color counting: compare each element against others in window
- Handle circular ranges by duplicating first K-1 elements at end
- Greedy selection: always pick earliest valid range, skip K sectors, repeat

Fixed-Point:
Not applicable for this problem - all integers.
