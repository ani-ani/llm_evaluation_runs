Design a sequential Verilog module named 'baron_munchausen' that implements a simplified search for the integer n such that S(a*n) = S(n)/a (where S(x) is sum of digits).
Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [3:0] a // multiplier (2 to 9)
Outputs:
output reg [15:0] result // the found n (or -1 if none)
output reg done // high when computation complete

Behavioral Description:
The module should search for n in the range [0, 9999] that satisfies the equation S(a * n) * a == S(n).
It uses a state machine with states: IDLE, CALCULATE, CHECK, NEXT, FOUND.
In IDLE: wait for start.
In CALCULATE: Compute product = a * n. Compute sum_n = sum of digits of n. Compute sum_an = sum of digits of product.
In CHECK: Check if (sum_an * a == sum_n). If true, go to FOUND. Else go to NEXT.
In NEXT: Increment n. If n <= 9999, go to CALCULATE. Else go to DONE (with result -1).
In FOUND: Set result = n, done = 1.

The sum of digits logic should work on numbers up to 20 bits (max product 9*9999=89991).
Max latency: ~50,000 cycles.
