Design a sequential Verilog module named 'bst_insertion' that implements binary search tree insertion with depth tracking for a maximum of 8 nodes (N=8).

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation (pulse high for one cycle to start)
input [7:0] data_in // Next number to insert (1-8)

Outputs:
output reg [7:0] cumulative_depth // The sum of depths of all inserted nodes
output reg done // High when insertion is complete (valid after 10 clock cycles)

Specifications:
- The tree stores values 1 through 8. Each value is inserted exactly once.
- The first inserted value becomes the root (depth 0).
- Subsequent values are inserted by traversing the tree: compare with current node, go left if value < node, right if value > node.
- When insertion location is found, increment cumulative_depth by the insertion depth.
- Depth starts at 0 for root, increments by 1 for each level traversed.
- Insertion requires traversing the tree structure.
- Use a state machine with states: IDLE, LOAD_ROOT, SEARCH_INSERT, UPDATE_DEPTH, DONE.
- Use a combinational block to determine the next node based on current node and input value.
- Store the tree structure in registers: 8 node registers [7:0] node_val[0:7], and 8 parent/child pointer arrays.
- Latency: 10 clock cycles from start to done.
- After 8 insertions, the tree is full; subsequent insertions should be ignored (stay at current cumulative_depth).

Implementation Details:
- Use node indices 0-7 to represent nodes in memory.
- Maintain array: node_val[0:7] (values stored, 0 means empty).
- Maintain array: left_child[0:7] (index of left child, 0xFF if none).
- Maintain array: right_child[0:7] (index of right child, 0xFF if none).
- Track insertion_count to know if tree is full.
- Track current_node_index during search.
- Track current_depth during traversal.

Edge Cases:
- Inserting the same value twice (should not happen per spec, but handle gracefully)
- Empty tree (root insertion)
- Full tree (ignore further insertions)
