Design a sequential Verilog module named 'extremely_cool_checker' that determines if a submatrix is 'extremely cool' (a Monge array).

Definition: A matrix is extremely cool if for every 2x2 submatrix:
[[a, b],
 [c, d]]
It holds that a + d <= b + c.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start verification
input [3:0] rows // Number of rows in submatrix (max 8)
input [3:0] cols // Number of columns in submatrix (max 8)
input [7:0] matrix_data [0:63] // Flattened 8x8 matrix (64 elements). Only first rows*cols elements are valid.

Outputs:
output reg is_cool // High if submatrix is extremely cool
output reg done // High when verification complete

Behavior:
The module must check all possible 2x2 submatrices within the specified rows and columns.
For each 2x2 submatrix at (r, c) where r < rows-1 and c < cols-1:
  a = matrix_data[r*8 + c]
  b = matrix_data[r*8 + (c+1)]
  c_val = matrix_data[(r+1)*8 + c]
  d = matrix_data[(r+1)*8 + (c+1)]
  Check: a + d <= b + c_val

If any check fails, is_cool goes low.
Use a state machine: IDLE -> CHECKING -> DONE.
Latency: Approximately (rows-1)*(cols-1) + 4 cycles.
All arithmetic is signed 8-bit (2's complement).

Assume matrix_data is provided as a flattened array. The module should iterate through the valid region.

State Machine:
- IDLE: Wait for start. Initialize indices.
- CHECKING: Iterate through r=0 to rows-2, c=0 to cols-2. Check condition.
- DONE: Set done=1, hold result.

If rows < 2 or cols < 2, immediately set is_cool=1 and done=1.
