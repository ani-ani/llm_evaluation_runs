Design a sequential Verilog module named 'factorial_trailing' that implements the following simplified problem:
Given a small integer n (1 ≤ n ≤ 15), compute the last 3 digits before trailing zeroes in n!.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [4:0] n // integer n (5 bits for 0-31, enough for 0-15)

Outputs:
output reg [11:0] result // the last 3 digits (each digit is 4 bits, BCD format)
output reg done // high when computation complete

Behavioral Specification:
The module should compute n! using a sequential state machine, then remove all trailing zeroes (divide by 10 until not divisible by 10), then extract the last 3 decimal digits of the remaining number.

Required States:
- IDLE: Wait for start signal
- COMPUTE_FACT: Calculate factorial iteratively (multiplication cycle)
- REMOVE_ZEROES: Remove trailing zeroes (divide by 10 while divisible)
- EXTRACT_DIGITS: Extract last 3 decimal digits
- DONE: Set done flag

Latency: Result valid 100 clock cycles after start asserted (maximum for n=15).

Implementation Details:
- Use 64-bit internal register to store factorial (fits 15! = 1.3e12)
- Use counter for iterative multiplication
- After computing factorial, repeatedly divide by 10 while modulo 10 equals 0
- Convert remaining number to last 3 digits (BCD format: 12 becomes 0x012)
- Output format: 3 BCD digits packed in 12 bits

Constraints:
- n input range: 1 to 15
- Internal multiplication handles up to 15! which fits in 64 bits
- Final result is always a positive integer with at most 3 digits
- Handle n=1 case: 1! = 1, no trailing zeroes, output 1 (0x001)
