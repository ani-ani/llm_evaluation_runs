Design a sequential Verilog module named 'dance_complexity' that calculates the complexity of a dance assignment defined by XOR with a given binary mask.

Problem Description:
Given a binary number x of length n (0 < n <= 8), members i from MDC dance with member (i XOR x) from NFC. The complexity is the number of pairs (a, b) and (c, d) such that a < c and b > d. The result must be modulo 1000000007.

Algorithm Insight:
The complexity can be calculated as the sum of contributions from each bit position. If the k-th bit of x (from left, 0-indexed) is '1', the contribution is 2^k * 4^(n - k - 1). We will compute this sum.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [7:0] x_mask // 8-bit binary mask (MSB corresponds to the string start, pad right with 0s if shorter)
input [2:0] n // The actual length of the binary string (1-8)

Outputs:
output reg [31:0] result // The calculated complexity modulo 10^9 + 7
output reg done // High when computation is finished

Latency:
Result valid 10 clock cycles after start asserted (allowing for modular exponentiation steps).

Behavior:
The module should iterate through the bits of x_mask corresponding to length n. For each bit that is 1, it calculates term = (2^k * 4^(n-k-1)) % MOD and adds it to the result. Since 4^(N) can be large, use modular exponentiation or pre-computed lookup tables for powers of 4 up to 2^7. Use an iterative state machine to handle the addition and multiplication loop.

State Machine:
IDLE: Wait for start signal.
CALCULATE: Process bits, compute term, add to result.
DONE: Assert done signal.

Note:
Input values are raw integers. Output is modulo 1000000007.
