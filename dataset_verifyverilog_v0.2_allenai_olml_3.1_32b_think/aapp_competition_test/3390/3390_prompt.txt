Design a sequential Verilog module named 'longest_menu' that finds the maximum number of dishes in a menu without repetition from a directed graph of compatibilities.

The problem is adapted as follows:
- Maximum n = 8 nodes (dishes numbered 0-7)
- Maximum m = 32 edges (compatibilities)
- Input graph is provided via 8x8 adjacency matrix
- Node 0 represents dish 1, node 1 represents dish 2, etc.
- Uses Floyd-Warshall algorithm to compute longest paths

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [2:0] num_nodes // actual number of nodes (1-8)
input [7:0][7:0] adjacency_matrix // 8x8 boolean matrix, adjacency_matrix[i][j] = 1 if edge i->j exists

Outputs:
output reg [3:0] result // maximum path length (1-8)
output reg done // high when computation complete

Latency: 256 clock cycles after start asserted (for Floyd-Warshall iterations)

Behavioral Description:
1. On start signal, initialize distance matrix:
   - dist[i][i] = 1 for all i
   - dist[i][j] = 2 if edge i->j exists
   - dist[i][j] = 0 otherwise

2. Run Floyd-Warshall algorithm to find longest paths:
   For k from 0 to num_nodes-1:
     For i from 0 to num_nodes-1:
       For j from 0 to num_nodes-1:
         if dist[i][k] > 0 and dist[k][j] > 0:
           dist[i][j] = max(dist[i][j], dist[i][k] + dist[k][j] - 1)

3. Find maximum value in dist matrix (excluding zeros)

4. Store result and set done = 1

Use state machine with states: IDLE, INIT, K_LOOP, I_LOOP, J_LOOP, FIND_MAX, DONE

Note: Since we're solving longest simple path in DAG-like subgraphs with limited cycles, Floyd-Warshall adapted for path counting gives correct results for the adapted constraints.
