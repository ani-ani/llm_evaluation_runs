Design a sequential Verilog module named 'coloring_counter' that computes the number of ways to paint N squares (N <= 8) satisfying M conditions, modulo 10^9+7.

Inputs:
input clk
input rst_n
input start
input [2:0] N // Number of squares (1 to 8)
input [7:0] M_i // Number of conditions (0 to 16)
input [2:0] l_i // Start of interval for current condition
input [2:0] r_i // End of interval for current condition
input [1:0] x_i // Required colors (1, 2, or 3)

Outputs:
output reg [29:0] result // Count modulo 10^9+7
output reg done

Behavior:
The module processes conditions sequentially. It stores the active conditions using internal arrays.
It implements a state machine to iterate through all colorings of N squares (3^N possibilities).
For each coloring, it checks all M stored conditions.
If valid, it increments the count.
The result is output modulo 10^9+7.
Latency: Approximately 3^N * M cycles after start.

Constraints:
- N is small (<=8), so 3^N <= 6561.
- M is small (<=16).
- Conditions are stored in a buffer during setup.
- Use a valid bit for condition storage.

The state machine should have states: IDLE, SETUP, CHECK_COLORING, UPDATE_RESULT, DONE.
During SETUP, load conditions into internal storage.
During CHECK_COLORING, generate current coloring bits.
During UPDATE_RESULT, validate and add to sum.
