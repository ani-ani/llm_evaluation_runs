Design a combinational Verilog module named 'arithmetic_book' that counts the number of subarrays (of length at least 2) where the sum equals the product.

Inputs:
input [4:0] n // Number of elements (2 to 16)
input [31:0] numbers [0:15] // Array of 16 32-bit integers

Outputs:
output reg [7:0] count // Number of valid subarrays

The module should:
1. Iterate through all possible subarrays of length >= 2
2. For each subarray, compute the sum and product of elements
3. Compare sum and product, increment count if they are equal
4. Return the total count

Constraints:
- Maximum array size: 16 elements
- Maximum subarray length: 16 elements
- Each number is a positive integer <= 10000 (scaled from original)
- Use 64-bit registers for sum and product to avoid overflow
- The module is purely combinational

Behavioral description:
For each valid start index i (0 to n-2) and each valid end index j (i+1 to n-1):
  - Compute sum = sum(numbers[i] to numbers[j])
  - Compute product = product(numbers[i] to numbers[j])
  - If sum == product, increment result

Note: Since this is combinational logic, it will synthesize to parallel comparators for small n.
