Design a sequential Verilog module named 'rating_equalizer' that implements a simplified version of the rating equalization algorithm.

The module manages 4 friends (n=4) with 4-bit ratings (0-15). It iteratively finds the friends with the highest ratings and reduces them by 1 (minimum 0) until all ratings are equal or 64 steps are reached.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [3:0] r0, r1, r2, r3 // Initial ratings of the 4 friends (0-15)

Outputs:
output reg [3:0] final_rating // The equalized final rating
output reg [5:0] match_count // Number of matches played (max 64)
output reg [3:0] match_friend0, match_friend1, match_friend2, match_friend3 // Bitmap of friends in current match
output reg done // High when computation is complete

Behavior:
The module uses a state machine (IDLE, CHECK, UPDATE, DONE). 
In CHECK state, it compares ratings to find the maximum value and identifies which friends have that value.
If all ratings are equal, transition to DONE.
In UPDATE state, it determines the party to play against. To maximize the final rating, the algorithm should target the highest rated players:
- If 3 or more friends share the max rating, reduce all of them.
- Otherwise, reduce the top 2 friends.
- Ratings cannot go below 0.
After update, increment match_count and repeat. Stop if match_count reaches 64.

The result (final_rating and match_count) should be valid when done is high.
Output match_friendX signals represent the party bitmap for the most recent match. 
Specify latency: Result valid approximately 64*10 clock cycles after start.
