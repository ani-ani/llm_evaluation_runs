Design a sequential Verilog module named 'network_unused_switches' that identifies switches that can never be part of an optimal path from switch 1 to switch n, given the total length of the path and the number of hops. 

The module implements a simplified version of the problem where the graph is small (up to 8 nodes). The graph is provided as an adjacency matrix of edge weights (valid weights are 1-127, invalid are 0), along with a separate hop matrix. The module computes the Pareto frontier of (length, hops) pairs for all paths from 1 to n using a state machine, then checks each node if it lies on any valid Pareto-optimal path.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [2:0] num_nodes // Number of nodes (up to 8)
input [6:0] length_matrix [8:0][8:0] // Adjacency matrix for edge weights (0 means no edge). Indices 1 to 8 map to switches 1-8. Index 0 unused.
input [2:0] hop_matrix [8:0][8:0] // Adjacency matrix for hop counts (always 1 if edge exists).

Outputs:
output reg valid // High when outputs are valid
output reg [7:0] unused_mask // Bitmask where bit i is 1 if switch i+1 is unused

Specify latency: Result valid 2000 clock cycles after start asserted.

The module should:
1. Use a state machine to compute shortest paths (min length) and min hops from 1 to all nodes, and from all nodes to n.
2. Identify the Pareto frontier of valid (total_length, total_hops) pairs for the 1-to-n path.
3. Iterate through all nodes and edges to check if any path through the node falls on the Pareto frontier.
4. Set unused_mask bits for switches that are never on any Pareto-optimal path.

Assume fixed-point arithmetic is not needed as inputs are integers.
