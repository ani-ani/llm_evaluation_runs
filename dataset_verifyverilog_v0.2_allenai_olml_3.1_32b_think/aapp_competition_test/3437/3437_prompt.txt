Design a combinational Verilog module named 'vacuum_tubes' that selects four tubes to maximize total length under distance constraints.

Problem Adaptation:
- N = 8 tubes maximum (fixed-size input array)
- L1, L2 ≤ 255 (8-bit values, representing scaled distances)
- Tube lengths ≤ 255 (8-bit values)
- Goal: Find two pairs (i,j) and (k,l) where all indices are distinct, sum(tube_i + tube_j) ≤ L1, sum(tube_k + tube_l) ≤ L2, maximizing total sum
- Use exhaustive parallel search with priority encoder logic

Inputs:
input [7:0] L1 // Distance constraint 1 (mm, scaled)
input [7:0] L2 // Distance constraint 2 (mm, scaled)
input [2:0] valid_count // Number of valid tubes (3-8)
input [7:0] tube_0 // Tube length 0
input [7:0] tube_1 // Tube length 1
input [7:0] tube_2 // Tube length 2
input [7:0] tube_3 // Tube length 3
input [7:0] tube_4 // Tube length 4
input [7:0] tube_5 // Tube length 5
input [7:0] tube_6 // Tube length 6
input [7:0] tube_7 // Tube length 7

Outputs:
output [9:0] total_length // Maximum total length of 4 tubes (max 4*255=1020)
output impossible // High if no valid pair combination exists

The module should:
1. Generate all possible pairs (i,j) where i < j, i,j < valid_count
2. For each pair1 and pair2 with all 4 indices distinct:
   - Check sum1 = tube_i + tube_j ≤ L1
   - Check sum2 = tube_k + tube_l ≤ L2
   - Calculate total = tube_i + tube_j + tube_k + tube_l
3. Use combinational logic to find maximum total
4. Set impossible high if no valid combination found
5. Output total_length in binary (not fixed-point since all integer)

Implementation strategy:
- Use generate blocks or explicit comparison for all C(8,4)=70 combinations
- Use reduction AND/OR logic to validate constraints
- Use priority tree to select maximum total
- All logic purely combinational (no clock)
