Design a sequential Verilog module named 'digit_product_distribution' that computes the final digit resulting from repeated multiplication of nonzero digits for numbers in a given range.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation for current range
input [15:0] L // Lower bound of range (16-bit unsigned)
input [15:0] R // Upper bound of range (16-bit unsigned)

Outputs:
output reg [15:0] result // Packed count: {a1[3:0], a2[3:0], ..., a9[3:0]}. Each count is 4 bits (max 15).
output reg done // High when computation complete

Behavioral Description:
The module iterates through all integers x from L to R (inclusive). For each x, it computes the final digit by:
1. Isolating nonzero digits of current number
2. Multiplying them together
3. Repeating until result is single digit (1-9)

Internal Logic:
- Use a state machine: IDLE -> ITERATE -> PROCESS_NUMBER -> UPDATE_COUNT -> CHECK_DONE -> DONE
- Track current number (current_x) from L to R
- For each number, use a temporary register (temp_val) for digit product calculation
- Use a digit extraction loop: extract digits, filter zeros, multiply
- After multiplication, if result >= 10, repeat
- Maintain 9 counters (4-bit each) for digits 1-9
- Since R-L <= 65535, max 65536 iterations
- Max 5 iterations per number for 16-bit numbers (product decreases rapidly)
- Output packs 9 nibbles (4-bit) into 36-bit result (truncated to 16-bit for simplicity, or use full width)

Note: Result output is 16-bit for this specification, mapping to 9 counts of 4 bits each.
Module should reset counters on start.
