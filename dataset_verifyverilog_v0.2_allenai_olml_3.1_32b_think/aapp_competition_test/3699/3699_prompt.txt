Design a combinational Verilog module named 'bottle_collector' that computes the minimum total distance for two agents (Adil and Bera) to collect bottles and drop them at a recycling bin. The module uses Q16.16 fixed-point arithmetic and handles a maximum of 8 bottles.

Inputs:
input [31:0] ax, ay // Initial position of Adil (Q16.16 format)
input [31:0] bx, by // Initial position of Bera (Q16.16 format)
input [31:0] tx, ty // Recycling bin position (Q16.16 format)
input [2:0] n // Number of bottles (0 to 7)
input [7:0][31:0] bottle_x // Array of bottle x-coordinates (Q16.16)
input [7:0][31:0] bottle_y // Array of bottle y-coordinates (Q16.16)

Outputs:
output [31:0] min_distance // Minimum total distance in Q16.16 format

The module should:
1. Calculate Euclidean distance between two points using integer arithmetic with scaling
2. Compute base cost: 2 * sum(dist(bin, bottle_i)) for all bottles
3. Calculate savings if Adil or Bera picks up a bottle directly (dist(bin, bottle) - dist(agent, bottle))
4. Find the optimal assignment considering:
   - One agent picks one bottle directly (best savings for Adil or Bera)
   - Both agents pick one bottle each (best two savings if bottles are different)
   - Fallback to single best savings if bottles overlap
5. Return base_cost - max_possible_savings

Use combinational logic only (no clock). Implement helper functions for distance calculation and maximum finding. The module must handle the case where n=0,1,2...7 bottles. For Q16.16 fixed-point: real value = integer_value / 65536.0. Input coordinates are already scaled. Output must be in Q16.16 format.

Distance calculation: sqrt((x2-x1)^2 + (y2-y1)^2) should be approximated using integer arithmetic or shift-based approximation for hardware efficiency. Use 32-bit intermediates and 64-bit multiplies before square root.
