Design a combinational Verilog module named 'min_ticket_cost' that computes the minimum cost for Sajjad to visit all schools.

The problem reduces to computing the mathematical formula: floor((n-1)/2) = (n-1) >> 1

Inputs:
input [16:0] n // number of schools (1 to 100000, needs 17 bits)

Outputs:
output [15:0] cost // minimum ticket cost

The module should compute cost = (n - 1) / 2 using integer division.
For n=2: cost = 0 (0000)
For n=10: cost = 4 (0100)
For n=1: cost = 0 (edge case)
For n=99999: cost = 49999

Since this is a purely mathematical computation with no sequential logic needed, implement this as a single combinational assignment using right shift operator for division by 2.

Note: n can be up to 100,000 (0x186A0), requiring 17 bits. Output can be up to 49999 (0xC34F), requiring 16 bits.
