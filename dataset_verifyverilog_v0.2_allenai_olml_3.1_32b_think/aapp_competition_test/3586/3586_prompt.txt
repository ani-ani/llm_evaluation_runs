Design a sequential Verilog module named 'find_largest_d' that implements the adapted algorithm: find the largest d such that a + b + c = d where a, b, c, d are distinct elements from a set of 8 integers.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [23:0] data_in // input number (24-bit signed)
input [2:0] index // index for storing data (0-7)
input write_en // write enable for storing input

Outputs:
output reg [23:0] result // largest d found
output reg valid // high when valid solution found
output reg done // high when computation complete

Specifications:
- Store up to 8 numbers in internal registers (24-bit signed each)
- On write_en: store data_in at location index
- On start: perform triple nested loop search (i=0 to 7, j=0 to 7, k=0 to 7, l=0 to 7)
- Check: if i,j,k,l all distinct AND data[i] + data[j] + data[k] == data[l]
- Track maximum data[l] found across all valid combinations
- Use state machine with states: IDLE, WRITE_MODE, COMPUTE (with nested loop states), DONE
- Result is 24-bit signed (can represent -8388608 to 8388607)
- Latency: approximately 4096 clock cycles worst case for all permutations
- If no solution found: valid=0, result=0
- Input numbers are scaled down from original problem (max 8 elements instead of 4000)

Nested loop implementation strategy:
- Use counter variables i,j,k,l as state machine sub-states
- For each iteration, check distinctness and sum equality
- Update max_d whenever a valid solution is found
- Fixed-size 8-element array enables fully combinational checks
