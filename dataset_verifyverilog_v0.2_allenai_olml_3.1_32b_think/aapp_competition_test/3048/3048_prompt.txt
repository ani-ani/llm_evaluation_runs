Design a combinational Verilog module named 'optimal_paths_length2' that counts optimal paths of length exactly 2 in a tree.

Inputs:
input [15:0] adj_matrix [0:15] // 16x16 adjacency matrix, adj_matrix[i][j]=1 if nodes i and j connected
input [3:0] num_nodes // actual number of nodes (1-16)

Outputs:
output [15:0] result // total count of optimal paths of length 2

The module computes the result purely combinationally:
1. For each node i (0 to num_nodes-1), count its degree by summing adj_matrix[i][j] for all j
2. For each node, compute degree * (degree - 1)
3. Sum these values across all nodes

Note: The tree property ensures all paths counted are optimal. Output is the sum of d*(d-1) for all nodes, where d is the degree.

Example: For N=3 with edges (1-2, 1-3), adjacency matrix has rows: [0,1,1], [1,0,0], [1,0,0]. Degrees: 2,1,1. Answer: 2*(1) + 1*0 + 1*0 = 2.
