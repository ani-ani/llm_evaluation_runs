Design a sequential Verilog module named 'knight_arrangements' that counts valid knight placements on an n×m chessboard where no two knights attack each other. Knights attack in L-shapes (2×3 rectangles).

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [1:0] n // number of rows (1-4)
input [3:0] m // number of columns (1-16, scaled from original 10^9)

Outputs:
output reg [29:0] result // result modulo 10^9+9
output reg done // high when computation complete

Specification:
- The module should compute the number of ways to place knights on an n×m board such that no two knights attack each other
- Knights attack each other if placed at opposite corners of a 2×3 rectangle
- Each tile can have at most one knight
- Output should be modulo 10^9+9 (1000000009)
- For n=1: simple case - any column can be 0 or 1 (empty or knight), but adjacent knights are allowed since 2×3 attack requires 2 rows
- For n>1: use state DP where each state represents a column's knight arrangement (bitmask of n bits)
- Transition: two consecutive columns must not create 2×3 L-shape attacks
- Latency: approximately m clock cycles for iterative DP
- Use state machine: IDLE, COMPUTE_COL, OUTPUT
- Implementation: iterate through columns, maintaining DP table for all 2^n possible states
- Each state transition checks if adjacent columns form valid 2×3 attack patterns
- For 2×3 attack: knights at (r1,c1) and (r2,c2) attack if |r1-r2|=2 and |c1-c2|=1, OR |r1-r2|=1 and |c1-c2|=2
- Since we process column-by-column, we mainly need to check |r1-r2|=1 and |c1-c2|=2 patterns between current and prev-prev column
- Keep DP[2^n] array that stores ways to reach each state
- For each new column, compute new DP based on valid transitions from previous column states
- Use modulo arithmetic with modulus = 1000000009
- Input m is scaled down to fit in 4 bits (max 16)
