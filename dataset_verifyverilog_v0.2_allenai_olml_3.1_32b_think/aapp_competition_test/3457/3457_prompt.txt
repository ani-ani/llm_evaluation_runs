Design a sequential Verilog module named 'hopscotch_paths' that computes the number of distinct paths from (0,0) to (N,N) with minimum hop constraints.

Module Specification:
- Parameter: MAX_N = 8 (maximum coordinate value)
- Inputs:
  input clk // clock signal
  input rst_n // active-low reset
  input start // start computation
  input [3:0] N // target coordinate (scaled to 1-8)
  input [3:0] X // minimum x-increase per hop
  input [3:0] Y // minimum y-increase per hop
- Outputs:
  output reg [31:0] result // final count modulo 1000000007
  output reg done // high when computation complete

Algorithm:
Use dynamic programming with 2D array dp[i][j] = number of ways to reach point (i,j).
Recurrence: dp[i][j] = sum of dp[i'][j'] for all i' ≤ i-X and j' ≤ j-Y (when i≥X, j≥Y)
Base case: dp[0][0] = 1
Result: dp[N][N] modulo 1000000007

Implementation Details:
- Use state machine with states: IDLE, INIT, LOOP_I, LOOP_J, COMPUTE_SUM, DONE
- Internal memory: reg [31:0] dp [0:8][0:8]
- Use nested loops to iterate i from 0 to N, j from 0 to N
- For each (i,j), if i≥X and j≥Y, compute sum of dp[i'][j'] for i' from 0 to i-X, j' from 0 to j-Y
- Perform modulo 1000000007 after each addition to prevent overflow
- Latency: approximately 1000 cycles for N=8, X=1, Y=1
- Done signal goes high when dp[N][N] is computed and available on result
