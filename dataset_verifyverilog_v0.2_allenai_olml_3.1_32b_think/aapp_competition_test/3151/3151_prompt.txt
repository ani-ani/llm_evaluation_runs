Design a sequential Verilog module named 'swimming_hall' that solves the architect's problem of finding square building and pool dimensions.

Problem: Given n, find m and k such that n = m^2 - k^2, where m and k are non-negative integers and m > k.

Mathematical insight: n = m^2 - k^2 = (m-k)(m+k). Let i = m-k and j = m+k, then i*j = n.
We need i*j = n and both (i+j) and (j-i) to be even (so m and k are integers).

Inputs:
input clk // clock signal
input rst_n // active-low reset  
input start // start computation
input [7:0] n // number of tiles, scaled to 8-bit max 255

Outputs:
output reg [7:0] m // building side length
output reg [7:0] k // pool side length
output reg valid // high when solution found
output reg impossible // high when no solution exists
output reg done // high when computation complete

Specify latency: Maximum 256 clock cycles after start asserted (iterates up to n).

Module behavior:
- Use state machine with states: IDLE, CHECK_FACTOR, FOUND, IMPOSSIBLE
- In CHECK_FACTOR state: iterate i from 1 to n (or sqrt(n) equivalent)
- For each i, check if i divides n: if (n % i == 0)
- Compute j = n / i
- Check if (i+j) is even and (j-i) is even
- If valid: compute m = (i+j)/2, k = (j-i)/2
- If no valid factor found after checking all: set impossible
- Use combinational logic for division and modulo operations
- Output valid result when found, set done signal

Edge cases:
- n=1: m=1, k=0 is valid (1^2 - 0^2 = 1)
- n=2: no solution (impossible)
- n=3: m=2, k=1 (4-1=3)
- n=4: m=2, k=0 (4-0=4)

The module should be purely sequential with FSM controlling the iteration process.
