Design a sequential Verilog module named 'max_average_subarray' that finds the maximum average of a consecutive subarray of length at least K.

Problem Adaptation:
- N is fixed to 8 (max array size)
- K is fixed to 3 (minimum subarray length)
- Input values are 8-bit integers (0-255)
- Output is Q8.8 fixed-point (8 integer, 8 fractional bits)
- Algorithm: We will use a simplified approach of checking all possible subarrays of length >= K and computing their averages using fixed-point division.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [2:0] n // Number of elements (fixed to 8)
input [2:0] k // Minimum length (fixed to 3)
input [7:0] data_in // Input data value
input [2:0] index // Index for data input
input write_en // Write enable for loading array

Outputs:
output reg [15:0] result // Maximum average in Q8.8 format
output reg done // High when computation complete
output reg valid // High when result is valid

Implementation Details:
1. Store array of 8 elements in internal registers
2. Use state machine: IDLE, LOAD, COMPUTE, DIVIDE, DONE
3. In COMPUTE state, iterate through all subarrays of length >= K (3 to 8)
4. Calculate sum for each subarray and compute average = sum / length
5. Use fixed-point division (shift for powers of 2 or iterative subtraction)
6. Track maximum average found
7. Output in Q8.8 format

Module Specification:
- Clock frequency: 100MHz
- Latency: Maximum 1000 cycles for worst case
- Reset: Active low, initializes all registers to zero
- Result format: Q8.8 (multiply decimal by 256 for representation)

Example: For array [2, 4, 3, 4] (N=4, K=2), subarray [4, 3, 4] has average 11/3 = 3.666. In Q8.8: 3.666 * 256 = 939 (0x03AB).
