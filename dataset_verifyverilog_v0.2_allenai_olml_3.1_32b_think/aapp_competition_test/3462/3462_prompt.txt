Design a sequential Verilog module named 'file_pattern_matcher' that implements a simplified file pattern matching system with wildcard (*) support.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start matching process for current file
input [7:0] pattern_char // current character of pattern (8-bit ASCII)
input [7:0] file_char // current character of file name (8-bit ASCII)
input pattern_valid // high when pattern_char is valid
input file_valid // high when file_char is valid
input pattern_end // high when end of pattern reached
input file_end // high when end of file name reached

Outputs:
output reg match_result // high if pattern matches file (valid after done)
output reg done // high when matching complete for current file
output reg need_more_chars // high when module needs more chars to continue

Behavior:
This module implements wildcard pattern matching where '*' matches zero or more characters.
It processes one character at a time per clock cycle.

Algorithm (simplified):
- Pattern matching is done iteratively with a state machine
- '*' can match zero or more characters
- Regular characters must match exactly
- Module processes characters sequentially from inputs
- After processing all characters, match_result indicates success

State Machine:
- IDLE: Waiting for start signal
- PATTERN_READ: Reading pattern character
- FILE_READ: Reading file character  
- WILDCARD_MATCH: Processing '*' wildcard
- COMPARE: Comparing individual characters
- DONE: Final state with match result

Latency: Approximately 8-16 clock cycles after start (depends on string lengths)

Implementation Notes:
- Use internal buffers to store pattern and filename (max 8 characters each)
- Process characters sequentially
- For '*' wildcard: attempt both zero-character match and one-or-more character match
- Output need_more_chars to request additional characters from testbench
- All inputs arrive one character per cycle when valid is high

The module should handle:
- Pattern "*.*" matching "main.c" and "a.out"
- Pattern "*a*a*a" matching "aaa", "aaaaa", "abababa"
- Patterns without wildcards (exact match)
- Patterns with only wildcards (always match)
