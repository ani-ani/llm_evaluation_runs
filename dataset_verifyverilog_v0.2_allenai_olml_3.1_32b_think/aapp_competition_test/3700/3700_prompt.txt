Design a combinational Verilog module named 'toy_shop' that computes the number of valid pairs of toys with costs summing to k.

Problem Statement:
Given n toys with costs 1, 2, ..., n, find the number of pairs (a, b) such that:
- a + b = k
- 1 ≤ a < b ≤ n
- Pairs (a, b) and (b, a) are considered the same
- a = b is not allowed

Inputs:
input [31:0] n // number of toys (1 to 2^32-1)
input [31:0] k // target sum (1 to 2^32-1)

Output:
output [31:0] count // number of valid pairs

Combinational Logic:
The module should compute the result purely combinationally (no clock needed).

Mathematical Formula:
For a valid pair (a, b) with a < b and a + b = k:
- a must satisfy: 1 ≤ a < k/2
- b = k - a must satisfy: b ≤ n and b > a
- From b ≤ n: k - a ≤ n → a ≥ k - n
- From a < b: a < k/2
- So valid range for a is: max(1, k-n) ≤ a < k/2
- Number of integer values in this range is: max(0, floor((k-1)/2) - max(1, k-n) + 1)

Edge Cases:
- If k ≤ 2: no valid pairs (since a < b and a ≥ 1, so b ≥ 2, but a < b means a < 2, so a=1, b=1 is invalid)
- If k > 2*n - 1: no valid pairs (max sum is n + (n-1) = 2n-1)
- Result must be non-negative

Implementation:
Use intermediate registers to avoid overflow during computation:
- Compute min_a = max(1, k-n)
- Compute max_a = floor((k-1)/2)  (largest a such that a < b)
- If min_a > max_a, result is 0
- Else result = max_a - min_a + 1

Note: All values are 32-bit unsigned integers. No floating-point needed.
