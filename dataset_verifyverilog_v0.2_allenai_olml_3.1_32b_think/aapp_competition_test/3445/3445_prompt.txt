Design a sequential Verilog module named 'courier_partition' that finds the optimal division of customers to minimize the maximum delivery time.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [2:0] num_customers // actual number of customers (3-8)
input [9:0] customer_x [0:7] // x-coordinates of 8 customers (0-1023)
input [9:0] customer_y [0:7] // y-coordinates of 8 customers (0-1023)

Outputs:
output reg [9:0] min_max_diameter // result: minimal maximum diameter
output reg done // high when computation complete

Specify latency: 256 * (8*8) clock cycles after start asserted (approximately 16384 cycles).

Behavior:
- Enumerates all 2^N possible partitions (where N = num_customers)
- For each partition:
  - For group 1 (bit=1) and group 2 (bit=0):
    - If group has 0 or 1 customer: diameter = 0
    - If group has ≥2 customers: compute max Manhattan distance between any two customers in that group
    - Manhattan distance = |x1-x2| + |y1-y2|
  - Take maximum of the two group diameters
- Track the minimum across all partitions
- Output the optimal result

Use state machine with states: IDLE, INIT_PARTITION, COMPUTE_DIAMETER_1, COMPUTE_DIAMETER_2, UPDATE_MIN, NEXT_PARTITION, DONE.

Implementation notes:
- Use nested loops: outer for partition enumeration, inner for pairwise distance calculations
- Store current best result and update when finding smaller maximum diameter
- Handle variable number of customers using num_customers input
- All arithmetic is integer-based
