Design a sequential Verilog module named 'exam_builder' that assigns unique operations to a small set of number pairs.

Inputs:
input clk          // Clock signal
input rst_n        // Active-low reset
input start        // Start computation
input [7:0] a0, b0 // Pair 0 operands (signed 8-bit)
input [7:0] a1, b1 // Pair 1 operands
input [7:0] a2, b2 // Pair 2 operands
input [7:0] a3, b3 // Pair 3 operands
input [7:0] a4, b4 // Pair 4 operands
input [7:0] a5, b5 // Pair 5 operands
input [7:0] a6, b6 // Pair 6 operands
input [7:0] a7, b7 // Pair 7 operands

Outputs:
output reg [7:0] res0, res1, res2, res3, res4, res5, res6, res7 // Result values
output reg [2:0] op0, op1, op2, op3, op4, op5, op6, op7        // 000:+, 001:-, 010:*
output reg done                                              // High when solution found
output reg impossible                                       // High if no solution

The module must compute operation results for all 8 pairs and select operators such that all 8 results are unique. Since the input range is small (-128 to 127) and operations produce a limited set of values, parallel computation is feasible.

Algorithm:
1. Combinational block: Calculate all 3 results (+, -, *) for each of the 8 pairs.
2. State Machine:
   - IDLE: Wait for start signal.
   - SELECTION: Iterate through pairs (0 to 7). For each pair, check the 3 possible results. If a result is NOT already marked as used (in a register array tracking used values), select that operation, store the result, and mark the result as used. Move to next pair.
   - IMPOSSIBLE: If any pair has no available unique result, assert impossible flag.
   - DONE: If all pairs assigned, assert done flag.

Timing: Result valid 20 clock cycles after start asserted.

Note: Since we are working with small numbers, the 'used' check can be a linear search through a small register file of 8 stored results (or a simple comparator tree). For this spec, assume a simple state machine that tries to pick the first available unique result for each pair sequentially.

Special handling: Subtraction operands might be negative. Ensure proper signed arithmetic.
