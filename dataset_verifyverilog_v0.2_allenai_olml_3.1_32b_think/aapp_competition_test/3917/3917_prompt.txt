Design a sequential Verilog module named 'min_pair_distance' that computes the minimum squared distance between any pair of distinct points (i, prefix_sum[i+1]) for a small array of up to N=8 elements.

The problem is based on finding min (i-j)^2 + (prefix_sum[i+1] - prefix_sum[j+1])^2.
Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [3:0] n // Number of valid elements (2 to 8)
input signed [15:0] a [0:7] // Array of 8 signed 16-bit values

Outputs:
output reg [31:0] min_dist // Minimum squared distance found
output reg done // High when computation complete

Behavioral Description:
The module uses a state machine to compute the prefix sums and then the minimum distance.
1. State IDLE: Wait for start signal. When start goes high, transition to CALC_PREFIX.
2. State CALC_PREFIX: Compute prefix sums in 8 cycles. Store prefix[i] = sum(a[0] to a[i-1]). 
   So prefix[0] = 0, prefix[1] = a[0], prefix[2] = a[0]+a[1], etc.
   Store these in a register array prefix_reg[0:8].
   Transition to CALC_DIST when done.
3. State CALC_DIST: Compute minimum distance using a nested loop over valid indices 0 to n-1.
   Outer loop index i from 0 to n-2, inner loop j from i+1 to n-1.
   Calculate diff_i = i, diff_j = prefix[i+1] - prefix[j+1].
   Compute dist = diff_i^2 + diff_j^2.
   Update min_dist with the minimum found.
   Use a state variable to track indices i and j.
   Transition to DONE when loops complete.
4. State DONE: Set done high. Wait for start to go low to return to IDLE.

Specifications:
- Use 2's complement for signed arithmetic.
- Latency: Approximately 20-25 clock cycles (1 for reset, up to 8 for prefix sum, up to 28 for distance calc (8 nodes = 28 pairs), 1 for done).
- Ensure n is clamped to max 8.
- The input array 'a' is available at the start and should be read into internal registers if necessary, though here we can index it directly.
- Intermediate calculations: use 32-bit width for sums and distances to prevent overflow given inputs +/- 10000 and indices up to 7. Max difference approx 80000, squared approx 6.4e9 (< 2^32).
