Design a sequential Verilog module named 'bracket_fix_checker' that determines if a bracket sequence can be made correct by moving at most one bracket.

The module processes a fixed-width 8-character bracket sequence character-by-character.

Inputs:
input clk // clock signal
input rst_n // active-low reset  
input start // start processing
input [7:0] char_in // current character (8-bit ASCII, only '(' = 0x28 or ')' = 0x29 used)
input valid_in // high when char_in is valid

Outputs:
output reg result // 1 = Yes (can be fixed), 0 = No
output reg done // high when computation complete (after 8 characters)

Behavior:
- Uses state machine: IDLE, PROCESSING, DONE
- Tracks running balance (4-bit counter, range -8 to +8)
- Tracks minimum balance encountered (4-bit signed)
- After processing 8 characters:
  - result = 1 if (balance == 0) AND (min_balance >= -1)
  - result = 0 otherwise
- Character encoding: '(' = 8'h28, ')' = 8'h29
- Latency: 8 clock cycles + 1 cycle for final evaluation

Fixed-point: Not applicable (this is a combinatorial/sequential problem)

State machine:
- IDLE: Wait for start signal, initialize counters
- PROCESSING: Process each character (8 cycles total)
- DONE: Latch final result, wait for reset

Implementation notes:
- Use signed arithmetic for balance to handle negative values
- Increment balance by +1 for '(', -1 for ')'
- Update min_balance whenever balance decreases
- Counter for character position (3-bit, 0-7)
