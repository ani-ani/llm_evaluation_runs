Design a sequential Verilog module named 'lossy_sort' that computes the minimum digit changes to sort a sequence of numbers.

Module Specifications:
- Input clock and reset
- Input n (2 bits, max 5) and m (3 bits, max 3)
- Input current_number (10 bits, representing 0-999)
- Input load: pulse to load next number
- Output result_number (10 bits, sorted sequence output)
- Output done: high when sequence complete
- Output changes_count (8 bits): total digit changes needed

Implementation Details:
- Use state machine: IDLE, LOAD, COMPUTE, OUTPUT, DONE
- Process 5 numbers sequentially
- For each position, compute minimal changes needed to maintain non-decreasing order
- Track previous output value to ensure sorted property
- Count digit changes by comparing current number to desired output
- Latency: approximately 20 clock cycles

Internal Registers:
- prev_value (10 bits): previous output value
- total_changes (8 bits): accumulated digit changes
- position_counter (3 bits): current position (0-4)
- current_input (10 bits): currently loaded input number
- current_output (10 bits): computed output for current position

Algorithm sketch:
1. For each position i from 0 to n-1:
2. Load input[i]
3. Find smallest valid v >= prev_value that minimizes digit changes from input[i]
4. Output v, add changes to total
5. Update prev_value = v
6. When done, output total_changes

Digit change calculation:
- Convert numbers to 3-digit strings
- Count positions where digits differ
- For example: 111 to 001 = 2 changes

Edge cases:
- First number: keep as-is (0 changes)
- Subsequent: must be >= previous value
- Use brute force: try all values from prev_value to 999, pick one with minimum changes

For 10-bit values representing 3-digit numbers:
- value = 100*a + 10*b + c where a,b,c are digits 0-9
- digit_changes(x, y) = count of differing digits in 3-digit representation

Module interface:
module lossy_sort(
    input clk,
    input rst_n,
    input start,
    input [1:0] n,           // number of values (0-4, representing 1-5)
    input [2:0] m,           // digits per number (0-2, representing 1-3) - not used in logic but kept for interface
    input [9:0] current_number,
    input load,
    output reg [9:0] result_number,
    output reg [7:0] changes_count,
    output reg done
);

The module should work with the provided test cases.
