Design a combinational Verilog module named 'longest_repeated_substring' that finds the longest substring that occurs more than once in a fixed-width string.

The module implements a simplified version for strings up to 16 characters. It uses a parallel comparison approach to check all possible substrings.

Inputs:
input [127:0] char_array // Packed 16x8-bit array representing input string (16 characters, ASCII lowercase 'a'-'z'). Characters are packed as char_array[7:0] = first character, char_array[15:8] = second character, etc. Unused positions should be filled with null bytes (0x00).
input [3:0] valid_len // The actual length of the input string (1-16).

Outputs:
output [127:0] result_string // The longest repeated substring, packed as 16x8-bit array. Result is left-aligned with null bytes (0x00) for unused positions.
output [3:0] result_len // Length of the result substring (0-16).

The module should:
1. Iterate through all possible substring lengths from 15 down to 1 (descending order).
2. For each length, check all possible starting positions for that substring.
3. For each substring, compare it with all subsequent substrings (including overlapping ones).
4. If a match is found, that substring is a candidate. Among candidates of the same length, select the lexicographically first one.
5. Output the longest found substring and its length.
6. If no repeated substring is found (should not happen per constraints), output all zeros.

Use parallel combinational logic with nested loops unrolled. Implement lexicographical comparison using a priority encoder structure that checks character by character (a < b < c ...).

The module must be purely combinational - no clock or state machine needed for the small scale.
