Design a combinational Verilog module named 'bipartite_set_optimizer' that computes the minimum subset of numbers to remove to make the graph bipartite.

Inputs:
input [15:0] valid_in // Mask indicating which of the 16 inputs are valid
input [63:0] numbers_in [0:15] // Array of 16 unsigned integers (64-bit)

Outputs:
output [15:0] remove_mask // Mask indicating which inputs should be removed
output [63:0] removed_values [0:15] // Values of removed numbers (valid only where remove_mask is high)

Behavior:
The module computes the number of trailing zeros (ctz) for each valid input number.
It then finds the ctz value that occurs most frequently.
Finally, it identifies all input numbers whose ctz does NOT match the most frequent ctz.
Those numbers are marked for removal in 'remove_mask', and their values are passed to 'removed_values'.

Implementation details:
- Use a priority encoder logic or loop to find ctz for each number.
- Use 64 counters (one for each possible ctz value 0-63) to tally frequencies.
- Use comparators to find the maximum frequency and the corresponding ctz.
- Compare each input's ctz against the winning ctz to set the remove_mask.

Example:
If inputs are [1, 2, 3, 4]:
1 (binary 1) -> ctz = 0
2 (binary 10) -> ctz = 1
3 (binary 11) -> ctz = 0
4 (binary 100) -> ctz = 2
Counts: ctz0=2, ctz1=1, ctz2=1. Max is ctz0.
Keep numbers with ctz0 (1 and 3). Remove 2 and 4.
Remove mask: 0010 (binary for indices 1 and 3? No, depends on indexing).
Indices 0:1, 1:2, 2:3, 3:4.
Remove indices 1 and 3. Mask = 1010.
