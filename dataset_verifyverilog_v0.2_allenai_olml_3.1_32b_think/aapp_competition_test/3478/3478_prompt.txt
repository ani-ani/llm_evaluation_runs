Design a sequential Verilog module named 'graph_partition' that determines if a graph of n cities can be partitioned into three cliques (Arya, Sansa, Jon) such that City 1 is in Arya, City 2 is in Sansa, and all sets are cliques. The module uses a brute-force state machine to search for a valid partition for small n (<= 4). 

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [3:0] n // Number of cities (max 4)
input [3:0] m // Number of roads
input [5:0] edges [15:0] // Flattened edge list, max 16 edges. Each edge is {u[1:0], v[1:0]} (assuming max 4 cities)

Outputs:
output reg valid // High if valid partition found
output reg [3:0] arya_set // Bitmask for Arya's cities
output reg [3:0] sansa_set // Bitmask for Sansa's cities
output reg done // High when search complete

Behavior:
The module should maintain an adjacency matrix for the graph. It then iterates through all possible 3-colorings (assignments of nodes to sets A, S, J) respecting constraints (1 in A, 2 in S). For each assignment, it verifies that all assigned sets are cliques (every pair of nodes in a set must be connected by a road). 

State Machine: IDLE, SETUP_ADJ, GENERATE_PERMUTATION, CHECK_CLIQUE, UPDATE_RESULT, DONE.
Limit n to 4 for hardware feasibility. 
Latency: Result valid within 5000 cycles after start asserted.
