Design a sequential Verilog module named 'apple_collector' that computes the number of apples Arcady collects.

Problem Context:
A rooted tree with N nodes is given. Initially, each node has 1 apple. Every second, apples roll down to their parent. If multiple apples meet at a node, they annihilate pairwise (parity check). We need to find the total number of apples collected at the root (node 1) over time.

Algorithm:
1. The process is equivalent to calculating the XOR sum (parity) of the number of nodes at each depth level of the tree. If the number of nodes at a depth is odd, 1 apple reaches the root from that depth; if even, 0.
2. The module will compute depths of all nodes relative to root (depth 0).
3. It will then count nodes per depth.
4. Finally, it sums the parities of these counts.

Module Specifications:
- Input: Parent array `p` for nodes 2 to N (N is fixed at 16). The array has 15 elements, representing parents of nodes 2..16.
- Input: `start` signal to begin computation.
- Output: `result` (number of collected apples).
- Output: `done` signal.

Constraints:
- N = 16 (nodes 1 to 16).
- Tree depth <= 8.
- Max nodes per depth <= 16.

Behavior:
The module uses a state machine:
- IDLE: Wait for start.
- CALC_DEPTH: Iterate through nodes 2 to 16, computing their depth by traversing up to the root. Store depths in a buffer.
- COUNT_LAYER: Iterate through depths, count nodes per depth.
- SUM_PARITY: Iterate through counts, sum up odd counts.
- DONE: Set done flag.

Inputs:
input clk
input rst_n
input start
input [3:0] p_addr // Address to write parent (0..14 for nodes 2..16)
input [3:0] p_data // Parent index (1..15)
input p_write // Write enable for parent array

Outputs:
output reg [3:0] result // Result (max 16)
output reg done

Internal Registers (needed for implementation):
- parent_mem [14:0][3:0]: Stores parent relationships.
- depth_mem [15:0][3:0]: Stores depth of nodes 1..16 (index 0 unused or mapped).
- count_mem [7:0][3:0]: Stores count of nodes at each depth level (max 8 levels).
- Various counters and state variables.

Latency: Approximately 200 clock cycles.
