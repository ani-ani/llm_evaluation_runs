Design a sequential Verilog module named 'square_killer_finder' that finds the largest square submatrix (size 2-16) that is 180-degree rotationally symmetric in a 16x16 binary matrix.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [15:0] matrix_row [15:0] // 16 rows of 16-bit binary values (each row is 16 bits)

Outputs:
output reg [4:0] max_size // maximum square killer size found (0 if none, 2-16 valid)
output reg done // high when computation complete

Latency: Result valid approximately 4096 clock cycles after start (check all positions)

Behavior:
1. The module searches for largest square submatrix with size >= 2 that is invariant under 180-degree rotation
2. For each possible size s from 16 down to 2, and each valid top-left position (i,j)
3. Check if the s×s square centered at (i,j) is rotationally symmetric:
   - Element at (i+r, j+c) must equal element at (i+s-1-r, j+s-1-c) for all 0<=r,c<s
4. Use a state machine: IDLE, CHECK_SIZE, CHECK_POSITION, CHECK_SYMMETRY, DONE
5. Start checking from largest size (16) downward to find maximum faster
6. For symmetric check, compare pairs in parallel where possible
7. Output max_size = 0 if no square killer found

Special consideration: Single cells (size 1) don't count as killers per problem statement.
