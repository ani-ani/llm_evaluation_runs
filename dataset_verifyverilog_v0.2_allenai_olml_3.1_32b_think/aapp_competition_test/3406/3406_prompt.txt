Design a combinational Verilog module named 'castle_danger_checker' that determines if a castle lies inside or on the border of a non-degenerate quadrilateral formed by 4 Nazi troops.

The problem is adapted for N=4 Nazi troops (exactly 4 points forming a single quadrilateral) and S=4 castles (for testability).

The quadrilateral is non-degenerate (no three points collinear, edges don't intersect except at vertices).

The castle is in danger if it lies inside or on the border of the quadrilateral.

Inputs (all in Q16.16 fixed-point format):
input [31:0] n1_x, n1_y // Nazi troop 1 coordinates
input [31:0] n2_x, n2_y // Nazi troop 2 coordinates
input [31:0] n3_x, n3_y // Nazi troop 3 coordinates
input [31:0] n4_x, n4_y // Nazi troop 4 coordinates
input [31:0] c1_x, c1_y // Castle 1 coordinates
input [31:0] c2_x, c2_y // Castle 2 coordinates
input [31:0] c3_x, c3_y // Castle 3 coordinates
input [31:0] c4_x, c4_y // Castle 4 coordinates

Outputs:
output [3:0] danger // danger[0]=1 if castle 1 is in danger, etc.

Behavioral Description:
The module should determine if each castle lies inside or on the border of the quadrilateral formed by n1, n2, n3, n4.

Since edges cannot intersect (except at vertices), the quadrilateral is simple. A point is inside or on the border if it is on the same side of all edges when traversing the perimeter.

The module should:
1. For each castle, compute orientation tests relative to the quadrilateral edges
2. Check if all orientations are non-negative or all are non-positive (for convex polygon)
3. Output danger bits accordingly

Note: Q16.16 format means coordinates are stored as (value * 65536). Integer part is upper 16 bits, fractional is lower 16 bits.

Example: For a point at (3.5, 2.25):
- 3.5 * 65536 = 0x00038000
- 2.25 * 65536 = 0x00024000

The module must be purely combinational.
