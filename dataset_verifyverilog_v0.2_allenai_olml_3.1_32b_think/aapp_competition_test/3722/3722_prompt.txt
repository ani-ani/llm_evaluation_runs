Design a sequential Verilog module named `string_generator` that counts the number of unique strings of length N generated by a recursive rule starting from "AB".

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [6:0] N // Target string length (scaled down to max 128)
input [7:0] c_AA, c_AB, c_BA, c_BB // Insertion characters for pairs 'AA', 'AB', 'BA', 'BB'. Values are 0 for 'A', 1 for 'B'.

Outputs:
output reg [29:0] result // Result modulo 10^9+7
output reg done // High when computation complete

The module must implement the logic derived from the Python solutions:
1. Determine the pattern of the rule table (4 characters) and map it to one of three cases:
   - Case 0 (Constant 1): Rules lead to unique strings being the same for any length.
   - Case 1 (Power of 2): Result is 2^(N-3).
   - Case 2 (Fibonacci): Result follows an additive pattern F(N) = F(N-1) + F(N-2).

Specifically, the logic for pattern detection is:
- If (c_AB == 0 and c_AA == 0) or (c_AB == 1 and c_BB == 1), the answer is always 1.
- Else, check the middle two rules (c_BA relative to c_AB).
  - If c_BA differs from c_AB, it's the Power of 2 case.
  - Otherwise, it's the Fibonacci-like case.

Latency: Result valid within 130 clock cycles after start asserted (enough to compute up to N=128 for the Fibonacci case).
Use a state machine with states: IDLE, DECODE, ITERATE, DONE.

For the ITERATE state:
- If Power of 2 case: Use a shift register or counter to compute 2^(N-3).
- If Fibonacci case: Iterate N-3 times updating two registers (similar to F[i] = F[i-1] + F[i-2]).

Constraints:
- Use parameter MOD = 1000000007.
- All arithmetic must be done modulo MOD.
- Handle N=2 or N=3 explicitly as 1.
