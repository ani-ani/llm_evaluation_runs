Design a combinational Verilog module named 'magic_color_counter' that counts the number of magical colors in a subtree.

A magical color is defined as a color that appears an odd number of times in the subtree.

Inputs:
input [3:0] flat_tree [255:0] // Flattened tree storage (max 16 nodes, max 256 elements for padding). Node 1 is at index 0.
input [7:0] query_start_idx // Start index in flat array (inclusive)
input [7:0] query_end_idx // End index in flat array (exclusive)
input [2:0] num_colors // Number of active colors (1 to 4)

Outputs:
output reg [3:0] magical_count // Number of magical colors

Behavior:
The module must compute the result combinationally (no clock).
1. Iterate through the range [query_start_idx, query_end_idx).
2. For each node in the range, get its color (value 1 to 4).
3. Maintain a parity bit for each color (1 to 4).
4. If a color appears an odd number of times, it is magical.
5. Sum up all magical colors.

Use a generate loop or a tree of XOR reductions to compute parity for each color across the specified range.

Constraints:
- Max 16 nodes.
- Max 4 distinct colors (represented as values 1-4).
- Tree structure is pre-flattened into flat_tree array. Subtree of a node is a contiguous block in this array.
- The query range is defined by query_start_idx and query_end_idx.
- Input 'flat_tree' contains the node colors. 0 means empty/sentinel.

Example Logic:
If query range covers indices 0 to 3 containing values 1, 2, 1:
Color 1 appears 2 times (even) -> Not magical.
Color 2 appears 1 time (odd) -> Magical.
Magical count = 1.
