Design a combinational Verilog module named 'chemistry_table' that solves the adapted chemistry table problem for N=8 columns.

Problem: Given 3 rows of 8 numbers each (values 1-8), find the minimum number of columns to delete so that when remaining columns are sorted, all three rows become identical. This is equivalent to finding the largest subset of columns where the multiset of values in each row is the same.

Inputs:
input [7:0] row1_val_0, row1_val_1, row1_val_2, row1_val_3, row1_val_4, row1_val_5, row1_val_6, row1_val_7 // First row (permutation of 1-8)
input [7:0] row2_val_0, row2_val_1, row2_val_2, row2_val_3, row2_val_4, row2_val_5, row2_val_6, row2_val_7 // Second row
input [7:0] row3_val_0, row3_val_1, row3_val_2, row3_val_3, row3_val_4, row3_val_5, row3_val_6, row3_val_7 // Third row

Outputs:
output [3:0] min_deletions // Minimum columns to delete (0-8)

Implementation Strategy:
Since N=8 is small, implement exhaustive search over all 2^8=256 possible column subsets using combinational logic:

1. For each of the 256 possible subsets (represented by 8-bit mask):
   - Extract selected columns from all three rows
   - Count frequency of each value (1-8) in each row
   - Compare the three frequency profiles
   - If all three match, the subset is valid

2. Find the largest valid subset size (max_popcount) among all valid masks

3. Output min_deletions = 8 - max_popcount

For frequency counting:
- Each row needs 8 counters (one per value 1-8)
- Each counter needs 3 bits (can count 0-8)
- Compare all 24 counters pairwise (row1 vs row2, row2 vs row3)

Use case statements or lookup tables to map values to indices.

The module should be purely combinational - output is available after all comparisons complete.
