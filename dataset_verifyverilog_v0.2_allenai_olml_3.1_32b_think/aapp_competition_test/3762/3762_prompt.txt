Design a sequential Verilog module named 'perfect_sets' that counts perfect sets (XOR-closed subsets) with elements ≤ k.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [15:0] k // maximum value (scaled to 16-bit)

Outputs:
output reg [31:0] result // count modulo 1000000007
output reg done // high when computation complete

Behavior: A perfect set S is closed under XOR (a,b ∈ S ⇒ a xor b ∈ S). All such sets must contain 0. The algorithm uses DP processing bits from MSB to LSB, tracking the number of basis vectors and whether the current prefix equals k's prefix.

Specify: Result valid 64 clock cycles after start asserted (processing 16 bits with state machine).
Use state machine with states: IDLE, PROCESS_BIT, COMPUTE_DONE.

DP recurrence per bit i (from 15 down to 0):
- If current bit of k is 0: only option is to not add new basis element, existing basis elements can contribute 0 or 1 in this bit position
- If current bit of k is 1: two cases - tight (bit must match) or loose (bit can be 0)

For each state transition, compute contributions using modular arithmetic (mod 1000000007).

The module should:
1. Reset to IDLE state
2. On start, load k and initialize DP state
3. Process 16 bits sequentially
4. Compute final answer as sum over all valid basis counts
5. Output result modulo 10^9+7
