Design a sequential Verilog module named 'garland_complexity' that computes the minimum complexity of a garland with missing bulbs.

Problem Adaptation:
- Input size limited to N=16 positions
- Max missing bulbs limited to 8
- Complexity is the number of adjacent pairs with different parity (odd/even)
- 0 represents a missing bulb to be filled

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [4:0] n // Number of bulbs (1 to 16)
input [15:0][4:0] p // Array of 16 positions, values 0 to 16 (0 means missing)

Outputs:
output reg [5:0] result // Minimum complexity (0 to 16)
output reg done // High when computation complete

Latency: Result valid ~32 clock cycles after start asserted.

Implementation Details:
1. Count total odd/even numbers available in 1..N
2. Count fixed odd/even numbers already in array
3. Count missing positions (zeros)
4. Use DP state machine with states: IDLE, COUNT_PAIRED, CALCULATE, DONE
5. Track: index position, used_odds, used_evens
6. DP dimensions: position (0-16), used_odds (0-8), current_parity (0/1)
7. DP stores minimum transitions so far
8. Output minimum complexity after processing all positions

The module should:
- Wait for start signal
- Process the array sequentially
- Use internal SRAM for DP table: [17][9][2] for positions, used odds, last parity
- Transition between states to fill DP table
- Return final minimum complexity

Use state machine with states: IDLE, PREPARE, DP_FILL, FINALIZE, DONE.
