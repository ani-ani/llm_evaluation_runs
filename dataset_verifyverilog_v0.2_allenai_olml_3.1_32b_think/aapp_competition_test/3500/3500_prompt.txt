Design a combinational Verilog module named 'bingo_tie_check' that checks if two 8x8 bingo cards can result in a tie.

Inputs:
input [6:0] card1_row0 // Row 0 of card 1, 8 numbers, each 7-bit (1-64 range)
input [6:0] card1_row1
input [6:0] card1_row2
input [6:0] card1_row3
input [6:0] card1_row4
input [6:0] card1_row5
input [6:0] card1_row6
input [6:0] card1_row7
input [6:0] card2_row0 // Row 0 of card 2
input [6:0] card2_row1
input [6:0] card2_row2
input [6:0] card2_row3
input [6:0] card2_row4
input [6:0] card2_row5
input [6:0] card2_row6
input [6:0] card2_row7

Outputs:
output tie_possible // 1 if a tie is possible, 0 otherwise
output [2:0] tie_row1 // Row index (0-7) of winning row in card 1
output [2:0] tie_row2 // Row index (0-7) of winning row in card 2
output [6:0] last_number // The last number called that causes the tie

The module checks if there exists a pair of rows (r1 from card1, r2 from card2) such that they can be completed simultaneously. A tie is possible if:
1. The two rows share at least one common number (which will be the last number called)
2. All other numbers in both rows can be called before the last number

The module should perform this check in a fully combinational manner. Since we have 8 rows per card, there are 64 possible row pairs to check. The logic should iterate through these pairs and output the first valid combination found.

For example:
If card1 row 2 contains {11, 25, 40, 49, 61} and card2 row 4 contains {10, 25, 31, 57, 64}, they share number 25. If 25 is called last, and all other numbers (11, 40, 49, 61, 10, 31, 57, 64) are called earlier, both rows complete simultaneously, resulting in a tie.
