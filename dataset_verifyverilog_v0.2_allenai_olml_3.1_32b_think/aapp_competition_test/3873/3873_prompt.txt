Design a sequential Verilog module named 'swap_generator' that determines if a valid swap sequence exists for a given n and generates the swaps.

The problem states that for a permutation of size n, we need to perform exactly one swap for every pair (i, j) with i < j such that the permutation remains unchanged. This is only possible if n ≡ 0 or 1 (mod 4).

For valid n, the swaps are generated by processing 4-element blocks. For each block starting at index k (where k is a multiple of 4), we generate a specific sequence of 6 swaps involving indices k, k+1, k+2, k+3. If n mod 4 = 1, there is an unpaired element at index 0 that participates in specific cross-block swaps with each 4-element block.

Module Interface:
input clk: System clock
input rst_n: Active-low reset
input start: High to start generation
input [9:0] n: Input permutation size (supports up to 1000)

output reg valid: High if n mod 4 is 0 or 1 (generation possible)
output reg [9:0] a_out: First index of current swap pair (0-based)
output reg [9:0] b_out: Second index of current swap pair (0-based)
output reg out_valid: High when a_out and b_out contain a valid swap
output reg done: High when all swaps for this n have been generated

Behavior:
1. When start is high, check if n mod 4 is 0 or 1. If not, set valid=0 immediately and done=1.
2. If valid, set valid=1 and begin generating swaps.
3. Generate swaps in order: first all swaps for block 0 (indices 0-3), then block 4 (indices 4-7), etc. If n mod 4 = 1, index 0 is special: generate cross-swaps with each block immediately after that block's internal swaps.
4. Internal swaps for a block starting at k are:
   - (k, k+2), (k+1, k+3)
   - (k, k+1), (k+2, k+3)
   - (k, k+3), (k+1, k+2)
5. Cross swaps (if n mod 4 = 1): for each block k, after its internal swaps, generate (0, k), (0, k+1), (0, k+2), (0, k+3).
6. Ensure no duplicate swaps. The total count is n*(n-1)/2.
7. Use a state machine to iterate through blocks and generate pairs.

Latency: 1 clock cycle per output pair. Start to first output: 2 cycles.

State Machine States:
- IDLE: Wait for start
- CHECK: Compute n mod 4
- BLOCK: Process a 4-element block
- CROSS: Generate cross-swaps with index 0 (if n mod 4 = 1)
- DONE: All swaps generated
