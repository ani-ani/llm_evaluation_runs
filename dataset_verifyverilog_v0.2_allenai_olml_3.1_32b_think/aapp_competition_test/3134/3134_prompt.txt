Design a sequential Verilog module named 'matrix_recovery' that recovers a binary matrix from row and column parities with constraints.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [3:0] row_parity // 4-bit row parities (LSB = row 1)
input [3:0] col_parity // 4-bit column parities (LSB = col 1)

Outputs:
output reg [15:0] matrix_out // 16-bit matrix, row-major order (row0[3:0], row1[3:0], etc)
output reg valid // high when solution found
output reg impossible // high when no solution exists
output reg done // high when computation complete

Latency: Up to 128 clock cycles (worst case search)

State Machine: IDLE, SEARCH, VALIDATE, COMPLETE, IMPOSSIBLE

Behavior:
1. In SEARCH state, systematically generate candidate matrices with maximum 1's
2. Try matrices with 16 ones, then 15, etc., maintaining lexicographic ordering
3. In VALIDATE state, check row and column parities
4. If valid, output matrix and set valid=1
5. If exhaust all possibilities, set impossible=1

For 4x4 matrix: 
- Matrix bits: M[3:0]=row0, M[7:4]=row1, M[11:8]=row2, M[15:12]=row3
- Row parity: XOR of bits in each row
- Column parity: XOR of M[i*4+0], M[i*4+1], etc across all rows

Goal: Maximum 1's, then minimum binary value (lexicographic order).
