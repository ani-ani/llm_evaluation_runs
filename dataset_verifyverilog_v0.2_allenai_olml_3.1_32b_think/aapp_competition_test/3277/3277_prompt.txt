Design a sequential Verilog module named 'ks_smooth_min_changes' that computes the minimum changes to make an array K_S-smooth.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [7:0] data_in // current array element value (0-255)
input [5:0] N // array size (1-64)
input [3:0] K // period length (1-8)
input valid_in // data_in is valid
output reg ready // ready to accept new data

Outputs:
output reg [7:0] min_changes // minimum changes needed
output reg done // high when computation complete

Specification:
- The module receives N elements sequentially via data_in with valid_in pulses
- After all N elements are received (when ready goes low), compute minimum changes
- Result valid when done=1
- Algorithm: Group elements by index % K, for each group find mode, changes = group_size - mode_count
- Use state machine: IDLE, RECV, COMPUTE, DONE
- Compute mode per group using frequency counting (values 0-255)
- Latency: ~64 + K*256 clock cycles worst case
- Module should handle K≤8, N≤64, values 0-255
