Design a sequential Verilog module named 'sym_trans_count' that computes the number of symmetric, transitive, but non-reflexive relations on a set of size n.

The mathematical formula derived is a recurrence relation based on partitioning:
Let T(n) be the count. The recurrence is:
T(n) = n * T(n-1) + Sum_{k=1 to n-1} ( C(n-1, k-1) * 2^(n-k) * T(n-k) )? No, simpler is using the table from the Python code.

The Python code computes a table A[n][k] such that the answer is A[n][n-1].
Recurrence for A:
A[0][0] = 1
A[i][0] = A[i-1][i-1]
A[i][j] = (A[i][j-1] + A[i-1][j-1]) mod P

Inputs:
input clk // Clock
input rst_n // Active-low reset
input start // Start computation
input [3:0] n // Size of set (1 to 8)

Outputs:
output reg [29:0] result // Result modulo 10^9+7 (fits in 30 bits)
output reg done // High when computation complete

Behavior:
The module should implement a state machine to compute the table A iteratively up to n=8.
Latency: Approximately 50 clock cycles.
States: IDLE, INIT, ROW_LOOP, COL_LOOP, CALC, DONE.

Use 30-bit width for arithmetic (since mod 10^9+7 < 2^30).
Max n is 8.
Result should be A[n][n-1].
