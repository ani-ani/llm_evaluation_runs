Design a sequential Verilog module named 'minimal_max_sum' that computes the minimal maximal sum when pairing two arrays.

The algorithm:
1. Sort array A in ascending order
2. Sort array B in descending order
3. Pair elements: A[i] + B[i] for each i
4. Find maximum sum among all pairs

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [6:0] a_in // new A value (0-100, needs 7 bits)
input [6:0] b_in // new B value (0-100, needs 7 bits)
input data_valid // indicates a_in and b_in are valid

Outputs:
output reg [7:0] result // maximal sum (max 100+100=200, needs 8 bits)
output reg done // high when computation complete
output reg error // high if more than 8 values provided

Latency: approximately 8 clock cycles for input, 12 cycles for sorting, 8 cycles for max calculation. Total ~30 cycles after start.

Behavior:
- Module accumulates up to 8 pairs (N=8) when data_valid is high
- When all data received or N pairs accumulated, starts computation
- Uses bubble sort to sort array A ascending
- Uses bubble sort to sort array B descending
- Calculates max of A[i] + B[i] for i=0 to 7
- Output result available when done=1
- Reset clears all buffers and state

Use state machine with states: IDLE, COLLECT, SORT_A, SORT_B, CALCULATE, DONE

Implementation notes:
- Store arrays in 8x7 bit buffers
- Use comparators for sorting logic
- Track max sum during final calculation phase
- Bubble sort requires multiple cycles per pass
