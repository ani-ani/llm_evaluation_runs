Design a sequential Verilog module named 'mst_weight' that computes the weight of a Minimum Spanning Tree for up to 8 points using Manhattan distance and Kruskal's algorithm.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [2:0] n_points // number of points (1-8)
input [9:0] points [0:7] // array of 8 points, each point is 10 bits representing concatenated x,y (x[9:5], y[4:0])

Outputs:
output reg [15:0] mst_weight // total weight of MST
output reg done // high when computation complete

Specifications:
- The module computes Manhattan distance between all pairs of points
- Uses Kruskal's algorithm with Union-Find to find MST
- Edges are sorted by weight using a bubble sort network (8 elements max)
- Manhattan distance: |x1 - x2| + |y1 - y2|
- Each point coordinate is 5 bits (0-31 range, scaled from original)
- Maximum edge weight: 62 (31+31)
- Output is the sum of selected edge weights

Implementation Details:
1. Extract x and y coordinates from input points
2. Compute all possible edges (max 28 edges for 8 points)
3. Store edges as {weight, u, v} tuples
4. Sort edges by weight using bubble sort
5. Process edges in sorted order using Union-Find
6. Add edge weight to MST total if it connects disjoint components
7. Complete when N-1 edges are selected

State Machine States:
- IDLE: Wait for start signal
- EXTRACT: Extract coordinates from points
- COMPUTE_EDGES: Calculate Manhattan distances for all pairs
- SORT_EDGES: Sort edges by weight
- KRUSKAL: Process sorted edges and build MST
- DONE: Result ready

Latency: Approximately 200 clock cycles after start asserted.
