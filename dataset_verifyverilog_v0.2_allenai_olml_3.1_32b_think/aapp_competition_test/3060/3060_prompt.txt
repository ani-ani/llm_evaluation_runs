Design a sequential Verilog module named 'kth_sequence' that generates the kth lexicographically valid sequence of length n-1 where n=5 (so length=4). Each element is between 1 and 4 (n-1). A sequence is valid if no contiguous subarray sum is divisible by 5.

Inputs:
input clk // clock signal
input rst_n // active-low reset  
input start // start computation
input [31:0] k // kth sequence index (1-based)

Outputs:
output reg [3:0] result // 4 elements, each 4 bits (values 1-4)
output reg valid // high when output is valid
output reg done // high when computation complete

Specification:
- n is hardcoded to 5, so sequence length is 4
- Each element ranges from 1 to 4 (n-1)
- Valid sequence rule: no contiguous subarray sum is divisible by 5
- Use state machine: IDLE, COUNTING, CHECKING, OUTPUT
- Count valid sequences in lexicographical order until reaching k
- For checking: compute all contiguous subarray sums and verify none % 5 == 0
- Output the kth sequence element by element
- Latency: approximately 1000-5000 cycles for k up to ~10000

Algorithm:
1. In IDLE: wait for start signal
2. In COUNTING: Generate sequences lexicographically (1,1,1,1 to 4,4,4,4)
3. In CHECKING: Verify validity by checking all contiguous subarray sums
4. If valid, increment counter. When counter == k, capture sequence
5. In OUTPUT: Stream out the sequence elements

Use nested loop structure with state machine to enumerate and check.
