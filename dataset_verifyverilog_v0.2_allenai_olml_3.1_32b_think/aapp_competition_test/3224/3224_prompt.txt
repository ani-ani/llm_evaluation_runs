Design a combinational Verilog module named 'circumsphere_center' that computes the center of a sphere passing through four 3D points.

Inputs:
input signed [7:0] p1_x, p1_y, p1_z  // Point 1 coordinates
input signed [7:0] p2_x, p2_y, p2_z  // Point 2 coordinates
input signed [7:0] p3_x, p3_y, p3_z  // Point 3 coordinates
input signed [7:0] p4_x, p4_y, p4_z  // Point 4 coordinates

Outputs:
output [31:0] center_x  // Q16.16 format
output [31:0] center_y  // Q16.16 format
output [31:0] center_z  // Q16.16 format

The module should compute the circumsphere center using the following method:
1. Form 3 equations by subtracting point 1's equation from points 2, 3, 4:
   2(xj - xi)x + 2(yj - yi)y + 2(zj - zi)z = xj² - xi² + yj² - yi² + zj² - zi²
2. This creates a 3x3 linear system Ax = b
3. Solve using Cramer's rule or matrix inversion
4. All intermediate calculations use Q16.16 fixed-point arithmetic
5. Input integers are converted to Q16.16 by shifting left 16 bits
6. Output center coordinates are in Q16.16 format

Note: The module must be purely combinational with no clock or reset.
Use 64-bit intermediate values to prevent overflow during multiplication.
Scale factors: multiply by 65536 (2^16) for fixed-point conversion.
For matrix operations, handle division by computing determinants carefully.
