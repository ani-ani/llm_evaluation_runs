Design a sequential Verilog module named 'bracket_converter' that converts balanced parentheses to a fixed-width alternative bracket notation.

The module processes up to 8 bracket pairs with fixed 8-bit indices (simplified from variable-length decimal).

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [7:0] char_in // input character ('(', ')', or null-terminated)
input [3:0] char_valid // high when char_in is valid

Outputs:
output reg [63:0] result // packed 8-character output buffer (8 chars * 8 bits)
output reg [3:0] result_len // length of output in characters
output reg done // high when computation complete
output reg error // high if input is unbalanced or too long

The module should:
1. Accept a stream of parentheses characters via char_in
2. Track bracket pairs using a stack (max 8 levels deep)
3. Generate headers in format: start,end: where start and end are 8-bit values
4. Store result in 64-bit output buffer (8 characters max for small inputs)
5. Complete within 64 clock cycles max

Algorithm:
- Use state machine: IDLE, READ_CHARS, PROCESS, OUTPUT
- Maintain stack of bracket positions (depth 0-7)
- When closing bracket is found, generate header for matching open bracket
- Headers are output in order of opening brackets (not closing)
- For simplicity, use fixed 8-bit indices instead of variable-length decimal
- Fixed format: each header uses exactly 5 characters: 1 char index, 1 char ',', 1 char index, 1 char ':', 1 char null

Example: For () with fixed 8-bit: '0,0:' (4 chars)

Latency: Result valid 50 clock cycles after start asserted.
Use state machine with states: IDLE, READ, PROCESS, OUTPUT.
