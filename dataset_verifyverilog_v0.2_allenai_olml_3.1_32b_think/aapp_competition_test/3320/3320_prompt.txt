Design a sequential Verilog module named 'or_path_calculator' that computes minimum bitwise OR path costs between all pairs of nodes in a small fixed graph.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [3:0] node_count // number of nodes (2-8)
input [3:0] edge_count // number of edges (1-16)
input [15:0] edges [0:15] // packed edges: {src[3:0], dst[3:0], weight[15:0]}
input [3:0] query_s // source node for query
input [3:0] query_t // target node for query

Outputs:
output reg [15:0] result // minimum OR path cost
output reg done // high when computation complete

Behavior: The module must compute the minimum cost path between all pairs of nodes where path cost is bitwise OR of edge weights. Use a modified Floyd-Warshall algorithm with 8 nodes max. The module should:
1. Initialize distance matrix with infinity (0xFFFF) except diagonal (0) and direct edges
2. Iterate through k=0 to 7, update dist[i][j] = min(dist[i][j], dist[i][k] | dist[k][j])
3. After 8 iterations, extract result for (query_s, query_t)
4. Result should be valid 50 clock cycles after start

Use state machine with states: IDLE, INIT, PROCESSING, DONE. The module handles up to 8 nodes and 16 edges. Edge weights are 16-bit integers. Result is 16-bit integer.
