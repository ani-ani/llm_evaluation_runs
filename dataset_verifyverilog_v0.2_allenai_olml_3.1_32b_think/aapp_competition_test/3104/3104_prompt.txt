Design a sequential Verilog module named 'equation_solver' that solves a simplified version of the problem: find the minimum splits to make string A equal to sum S.

The module handles:
- Input string A: 8 characters max (fixed-width 8 bytes)
- Input target S: 8-bit value (0-255)
- Output: Result string with '+' inserted and '=' with target value

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [63:0] a_in // 8 ASCII characters packed into 64 bits
input [7:0] s_in // target sum value

Outputs:
output reg [255:0] result // result string (32 ASCII chars max)
output reg done // high when computation complete

Latency: Result valid ~100 clock cycles after start asserted.

Behavior:
1. Parse the 64-bit input into 8 ASCII digits
2. Use dynamic programming with state machine to find minimal splits
3. Consider splits at positions 1 through 7
4. Reconstruct the solution string
5. Output format: digit(s)+digit(s)+...=value

Implement as sequential with states: IDLE, PARSE, COMPUTE, RECONSTRUCT, DONE.
Use combinational logic for DP table lookups.
