Design a sequential Verilog module named 'playlist_solver' that searches for a path of exactly 9 nodes in a directed graph where consecutive nodes are connected by edges, and all 9 nodes must have distinct artist IDs.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [6:0] n // number of songs (1-100, valid if n >= 9)
input [3:0] num_edges_1, num_edges_2, ..., num_edges_100 // number of outgoing edges for each song (max 40)
input [6:0] edge_1_1, edge_1_2, ..., edge_1_40 // edges from song 1 (each is target song index 1-100)
input [6:0] edge_2_1, edge_2_2, ..., edge_2_40 // edges from song 2
...
input [6:0] edge_100_1, edge_100_2, ..., edge_100_40 // edges from song 100
input [4:0] artist_1, artist_2, ..., artist_100 // artist ID for each song (0-25 representing 'a'-'z')

Outputs:
output reg found // high when valid playlist found
output reg [6:0] song_1, song_2, ..., song_9 // the 9 songs in playlist order
output reg searching // high while searching

Behavior:
- The module implements a backtracking search with depth limit 9.
- Use a depth-first search (DFS) state machine that explores paths starting from each node.
- Track visited artists using a 26-bit mask (one bit per artist 'a'-'z').
- Track current path and depth (1-9).
- When depth reaches 9, assert found and output the path.
- If search completes without finding, the module should be able to restart.
- Use state machine with states: IDLE, INIT_START, SEARCH, CHECK_EDGE, FOUND, FAIL.
- Latency: Variable (up to thousands of cycles), but result valid when found goes high.
- For testing, assume n=10, artist IDs 0-9, edges provided as arrays.

Implementation details:
- Use stack-based DFS or recursive state machine (converted to iterative).
- At IDLE: Wait for start signal.
- At INIT_START: Initialize search from node 1 (or iterate through all starting nodes).
- At SEARCH: Try current node's edges.
- At CHECK_EDGE: Verify edge leads to node with unvisited artist, increment depth.
- At FOUND: Output path, set found=1.
- At FAIL: If no path found, eventually return to IDLE.
- Artist IDs are 0-25, but for testing with 10 songs, use IDs 0-9.
