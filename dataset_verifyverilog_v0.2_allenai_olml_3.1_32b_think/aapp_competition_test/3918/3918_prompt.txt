Design a sequential Verilog module named 'min_error_calculator' that implements the error minimization algorithm.

Problem: Given two arrays A and B of size n, we need to minimize E = sum((A[i] - B[i])^2) after performing exactly k operations (k = k1 + k2). Each operation reduces the absolute difference of one element by 1.

Adaptation: Arrays have max 8 elements (N=8). Values are 16-bit signed integers. Max operations K=128 (scaled from k1+k2 <= 1000).

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [5:0] k_total // total operations to perform (0-63, scaled from k1+k2)
input [2:0] n // number of elements (1-8)
input signed [15:0] a [0:7] // array A, 8 elements, 16-bit signed
input signed [15:0] b [0:7] // array B, 8 elements, 16-bit signed

Outputs:
output reg [31:0] result // final error E = sum((a[i]-b[i])^2)
output reg done // high when computation complete

Behavior:
1. Compute initial differences d[i] = |a[i] - b[i]| (16-bit absolute values)
2. For each of k_total operations:
   - Find the index with maximum d[i] value
   - If max d[i] > 0: decrement it by 1
   - If max d[i] == 0: increment it to 1 (or keep 0, but algorithm prefers 1)
3. After all operations, compute E = sum(d[i]^2) for i=0 to n-1

Spec:
- Use state machine: IDLE, COMPUTE_DIFF, FIND_MAX, UPDATE, CALCULATE_RESULT, DONE
- In IDLE: wait for start signal
- In COMPUTE_DIFF: calculate all |a[i] - b[i]| differences
- In FIND_MAX: find index of maximum difference (use sequential search)
- In UPDATE: decrement max difference (or set to 1 if it was 0)
- Track operation count and loop back to FIND_MAX until k_total operations done
- In CALCULATE_RESULT: compute sum of squares of final differences
- In DONE: assert done signal
- Latency: approximately k_total + 16 clock cycles after start
- Use signed arithmetic for differences, unsigned for result (32-bit)
- Module should handle n elements (1-8), ignore elements beyond n
