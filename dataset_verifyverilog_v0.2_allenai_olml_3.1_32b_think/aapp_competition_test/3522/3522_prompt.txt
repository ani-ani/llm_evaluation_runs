Design a sequential Verilog module named 'chip_allocator' that computes the minimum difference d in power outputs between paired chips in machines.

Problem Adaptation:
- Maximum 2 machines (n=2)
- Maximum 3 batteries per chip (k=3)
- Total batteries: 12 (max)
- Power outputs scaled to 8-bit values (0-255)
- Output d is minimum difference in power outputs

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [5:0] total_batteries // actual count (max 12)
input [7:0] battery_powers [0:11] // array of 12 battery power values

Outputs:
output reg [7:0] min_difference // computed minimum d
output reg done // high when computation complete

Latency: Result valid 12 clock cycles after start asserted.

Algorithm:
1. Sort the 12 battery power values using insertion sort state machine
2. Pair adjacent sorted batteries (batteries at indices 0-1, 2-3, ..., 2nk-2, 2nk-1)
3. Each pair forms the minimums of two chips in a machine (since sorted array, pairing adjacent elements yields minimal differences)
4. Compute differences between paired minimums
5. Find maximum of these differences (which is minimized by this pairing strategy)

State Machine:
- IDLE: Wait for start signal
- SORTING: Sort battery powers using bubble sort (12 passes, O(n^2))
- PAIRING: Compute differences between adjacent elements (indices 0&1, 2&3, etc.)
- FIND_MAX: Find maximum difference
- DONE: Set done signal

Implementation Details:
- Use bubble sort for simplicity with 12*12 = 144 cycles worst case
- In PAIRING state, iterate through sorted array and compute battery_powers[i+1] - battery_powers[i] for i = 0, 2, 4, 6, 8, 10 (but only considering first 2*n*k elements)
- Track maximum difference encountered
- Result is the maximum of paired differences

Key Insight: After sorting batteries ascending, pairing adjacent elements (i.e., (0,1), (2,3), (4,5), ...) ensures that the minimums of each chip pair are as close as possible, minimizing the maximum difference between paired chips.
