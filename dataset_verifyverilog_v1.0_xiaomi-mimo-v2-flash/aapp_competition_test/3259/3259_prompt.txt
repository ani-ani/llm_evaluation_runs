**Module Interface:**
- **Inputs:**
  - `clk`: System clock
  - `rst_n`: Active-low reset
  - `start`: 1-cycle pulse to initiate operation
  - `op_type`: 1-bit (0 for Update, 1 for Query)
  - `L`, `R`: 10-bit unsigned (0..1023, mapping 1-based input to 0-based index)
  - `A`, `B`: 16-bit unsigned
- **Outputs:**
  - `result`: 32-bit unsigned (Sum or unused)
  - `done`: 1-bit, high for 1 cycle when finished

**Internal Logic:**
- Use a single BRAM for `arr` (1024 x 16 bits).
- Update operation: Iterate `i` from `L-1` to `R-1`. Calculate `k = i - (L-1) + 1`. Compute `val = (k * A)`. If `val >= B`, `val = val - B` (simulated modulo). Write to BRAM.
- Query operation: Iterate `i` from `L-1` to `R-1`. Accumulate `arr[i]` into `result`.
- **Timing:** Start asserted, waits for `done`. Update takes `(R-L+1)` cycles. Query takes `(R-L+1)` cycles.
- **Constraints:** Max window size 1024. Max A, B 16-bit.
