You are to design a Verilog module that computes the number of entirely unsorted permutations of a sequence.

**Problem Simplification:**
- Input array size N ≤ 12 (scaled down from 5000)
- Input values are small integers 0-15 (scaled down from 1e9)
- Output is modulo 10^9+9 (approx 2^30)
- Compute using Dynamic Programming (DP) approach

**Algorithm:**
1. Sort the input array to get multiset counts
2. Use DP with states: (position_index, previous_element_index, mask_of_used_elements)
3. An element is sorted if it is a local minimum (left neighbor ≤ it, right neighbor ≥ it)
4. We need permutations where NO element is sorted
5. Use inclusion-exclusion or direct DP counting invalid permutations

**Exact Interface:**
- Inputs:
  - `clk`: Clock, rising edge
  - `rst_n`: Active-low synchronous reset
  - `start`: Start pulse (1 cycle)
  - `data_in[0:11]`: Array of 12 input values (4-bit each, total 48-bit input vector)
- Outputs:
  - `result`: 32-bit result modulo 10^9+9
  - `done`: High when result is valid (1 cycle)
- Timing: Start asserted, then done asserted within 2000 cycles
- Reset: Sets all registers to 0, done=0

**Implementation Details:**
- Precompute sortedness conditions
- Use 3-stage pipeline: Input parsing → DP computation → Result formatting
- Modular arithmetic using 32-bit addition/multiplication with modulo 10^9+9
- State machine to control DP iterations
- Memory: Use distributed RAM for DP table (max 12*12*4096 states ≈ 600k bits)

**Constraints:**
- Clock frequency: 100 MHz (10ns period)
- Total cycles budget: 2000
- Resource: Must fit in medium FPGA
- No external memory, all internal BRAM/DSP
