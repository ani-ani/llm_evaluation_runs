Design a Verilog module that solves the ice cream transfer problem using BFS to find reachable amounts and decodes the path into actions. 

**Interface:**
- Inputs: `clk`, `rst_n` (active-low sync reset), `start` (1-cycle pulse)
- Parameters: `NUM_BOTTLES` (max 4), `MAX_VOLUME` (max 16), `TARGET_T` (max 256)
- Bottle volumes (scaled): `vol_0`, `vol_1`, `vol_2`, `vol_3` (8-bit each)
- Target T: `target_t` (8-bit)
- Outputs: `result` (8-bit: 0=impossible, 1=possible), `done` (1-cycle pulse)

**Behavior:**
1. On `start`, initialize BFS queue (width 8 bits per state).
2. State encoding: bitmask of which bottles are full (4 bits) + total liquid amount (8 bits). Total bits = 12.
3. BFS depth limited to 256 steps. Target check: if total liquid == `target_t`, set `result=1` and `done=1`.
4. Transitions: Fill any empty bottle (add volume), Empty full bottle (subtract volume), Transfer between bottles (update amounts). 
5. If BFS completes without reaching T, set `result=0` and `done=1`.
6. Path reconstruction: Store parent pointers in 16-bit buffer (max 256 states) to trace back from target state.
7. Actions output via a separate interface (not required in this module, only feasibility check).

**Timing:** start->done within 256 cycles. Reset clears all registers to 0.
