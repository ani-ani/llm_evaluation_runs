Implement a Verilog module that finds the largest rectangular submatrix (within an 8x8 input matrix) that satisfies the 'Monge property'. The Monge property states that for any 2x2 submatrix:
A[0][0] + A[1][1] <= A[0][1] + A[1][0]

Inputs:
  clk: rising edge
  rst_n: active-low synchronous reset
  start: 1-cycle pulse to start processing
  matrix[63:0][7:0]: 8x8 array of 8-bit signed integers (packed as 512 bits total)
  rows: 3-bit input (number of active rows, 1-8)
  cols: 3-bit input (number of active columns, 1-8)

Outputs:
  result: 8-bit unsigned integer (max elements in valid submatrix)
  done: 1-cycle pulse indicating completion

Algorithm:
1. On start, latch inputs.
2. Iterate over all possible top-left corners (r1, c1) and bottom-right corners (r2, c2) where r2 > r1 and c2 > c1.
3. For each candidate submatrix, verify the Monge property for all internal 2x2 submatrices (checking A[i][j] + A[i+1][j+1] <= A[i][j+1] + A[i+1][j]).
4. If valid, calculate area (rows * cols) and track the maximum found.
5. Output max area when done.

Timing Constraints:
- Reset: 2 cycles, sets result=0, done=0
- Processing: Start triggers calculation. Done pulses after checking all submatrices.
- Max latency: 5000 cycles (sufficient for 8x8 brute force)
- Result is valid when done=1.

Note: Input matrix is provided as a flat array or vector. Since 8x8=64 elements of 8 bits = 512 bits, use a 512-bit input vector 'matrix_flat' where index i corresponds to row i/8, col i%8.
