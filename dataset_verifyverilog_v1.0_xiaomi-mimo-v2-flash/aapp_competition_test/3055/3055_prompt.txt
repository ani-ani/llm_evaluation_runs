Design a Verilog module that determines the smallest prefix uniquely identifying 'ThoreHusfeldt' from a list of names.

**Interface:**
- Inputs: clk, rst_n (active-low), start (1-cycle pulse)
- Input Data: name_char (8-bit ASCII), name_valid (1-bit), name_index (7-bit, 0-99)
- Output: result_char (8-bit), result_valid (1-bit), done (1-cycle when finished)
- Special signals: is_first (1-bit), has_thoreh_above (1-bit), has_thore_above (1-bit)

**Behavior:**
1. **Reset:** done=0, result_char=0, result_valid=0, state=IDLE
2. **Input Processing:**
   - Names are streamed in via name_char/name_valid/name_index
   - Store 'ThoreHusfeldt' (14 chars) as reference: {0x54,0x68,0x6f,0x72,0x65,0x48,0x75,0x73,0x66,0x65,0x6c,0x64,0x74}
   - Track position of ThoreHusfeldt in the list (target_index)
3. **Logic:**
   - After all names read, compare names before target_index
   - **Case 1:** If target_index == 0 → Output 'Thore is awesome' (7 chars: 0x54,0x68,0x6f,0x72,0x65,0x20,0x69...)
   - **Case 2:** If any name above has prefix 'ThoreHusfeld' (13 chars) → Output 'Thore sucks' (11 chars)
   - **Case 3:** Find smallest k (1-14) such that no name above has prefix of length k of 'ThoreHusfeldt'
4. **Output:** Stream result bytes sequentially, set result_valid=1 for each byte, done=1 after last byte
5. **Constraints:**
   - Names max 100 chars, but only first 14 chars matter for comparison
   - n ≤ 100 names
   - Process sequentially with 200-cycle timeout
   - Use 8-bit ASCII byte arrays for storage
   - Implement FSM with states: IDLE, READ_NAMES, FIND_INDEX, COMPARE_PREFIX, OUTPUT_RESULT
