Implement a Verilog module that finds the closest handsome number to a given input N, where a handsome number has alternating even/odd digits. The solution must:

1. Scale input: Accept N as 64-bit unsigned (≤16 decimal digits)
2. Implementation strategy: 
   - Convert N to decimal digits array (max 16 digits)
   - Check if N is handsome: scan digits for parity alternation
   - If handsome, return N as single result
   - If not handsome: brute-force search outward from N
   - Search for closest handsome numbers by checking N-1, N+1, N-2, N+2...
   - Track best distances and results (up to 2 closest numbers)
   - Search limit: 1000 iterations per direction (configurable)

3. Interface:
   - Inputs: clk, rst_n, start (1-cycle pulse), n_in[63:0] (input number)
   - Outputs: result0[63:0], result1[63:0] (0 if only one), count[1:0] (0, 1, or 2), done (1-cycle pulse)
   - Timing: start->done within 1000 cycles
   - Reset: done=0, count=0, results=0

4. Hardware implementation:
   - Use finite state machine (FSM)
   - Store digits in 16x4-bit array (digit 0-15, value 0-9)
   - Parity check: digit[0] for even/odd
   - Comparator: 64-bit addition/subtraction
   - Search loop with bounded iteration (max 1000 cycles)
   - Result packing into 64-bit outputs

5. Constraints:
   - All arithmetic within 64-bit
   - Digit array: 16x4 bits
   - FSM states: IDLE, CHECK_HANDESSOME, SEARCH_UP, SEARCH_DOWN, DONE
   - Pipeline: one comparison per clock cycle
