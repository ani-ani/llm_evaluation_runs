Implement a Verilog module that reconstructs a cube from 8 vertices where coordinates per vertex may be permuted. Input: 8 sets of 3 coordinates (each 32-bit signed). Output: YES/NO and 8 valid cube vertices if possible.

Specification:
- Input interface: 8 vertices, each as 3 32-bit signed integers (240 bits total)
- Output interface: 8 vertices, each as 3 32-bit signed integers (240 bits total) + valid flag
- Algorithm: Exhaustive search over all 6^8 = 1.6M permutations (6 permutations per vertex)
- Validation: Check squared distances between all pairs: must have exactly 3 equal edges (side squared), 3 equal face diagonals (2×side²), and 1 space diagonal (3×side²) for each vertex
- Scaled constraints: 32-bit coordinates, squared distances fit in 64-bit
- Timing: Process within 10,000 cycles
- Control: start pulse, done signal, result valid when done=1
- Reset: Initialize all outputs to zero

Implementation approach:
1. Store input vertices in 8×3 32-bit registers
2. Generate 6 permutations for each vertex (fixed LUT for index transformations)
3. For each combination, compute all pairwise squared distances (8 vertices, 28 pairs)
4. Check if distances match cube pattern: 12 edges (value S), 12 face diagonals (2S), 4 space diagonals (3S)
5. Output first valid configuration found
6. If none found, output NO

Note: Use combinatorial logic for permutations and distance checks, sequential FSM for search iteration.
