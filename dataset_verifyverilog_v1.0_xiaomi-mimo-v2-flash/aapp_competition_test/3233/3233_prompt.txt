Design a Verilog module that counts scary subarrays for a fixed N=16 array with distinct values 1-16.

A subarray is scary if its leftmost element is the median of its elements. Since all elements are distinct, only odd-length subarrays can be scary. For an odd-length subarray of length L, the median is the element at position L/2 in sorted order.

The module should work for N=16 with values 1-16 (distinct). The counting can be done combinatorially for all possible subarrays.

Key insight: For a subarray starting at index l (0-based) and ending at index r (0-based) with length len = r-l+1 (must be odd), element at position l is the median if and only if exactly (len-1)/2 elements in the subarray are less than p[l], and exactly (len-1)/2 elements are greater than p[l].

Since N=16 is small, we can check all possible odd-length subarrays (l ≤ r, length odd).

Interface:
  Input: p[0:15] - 16 x 4-bit array (values 1-16)
  Output: scary_count - 10-bit (max 16*8/2 = 136 subarrays, fits in 10 bits)

Implementation approach:
  1. For each starting index l (0 to 15)
  2. For each ending index r (l to 15) where (r-l+1) is odd
  3. Count elements less than p[l] in subarray p[l..r]
  4. Count elements greater than p[l] in subarray p[l..r]
  5. If count_less == count_greater, increment scary_count

Use combinational logic with bounded loops (max 16 iterations per loop). The result should be available combinatorially or within a few cycles.

Note: Length 1 subarrays (l==r) are always scary since count_less=0 and count_greater=0.

Input constraints: Values 1-16, distinct. All subarrays fit in 16 elements.
Output: scary_count between 0 and 136.

Design: Combinational circuit that computes result based on p[0:15] inputs.
