Implement a Verilog module that finds the maximum perimeter of a rectangle consisting entirely of '.' cells in an R x C grid, where R and C are fixed at 8. The grid is provided as an 8x8 array of 1-bit inputs per row (0 for blocked, 1 for free). Use a 2D prefix sum approach over the 8x8 grid to check rectangle validity in O(1) per rectangle. Iterate over all possible top-left (r1, c1) and bottom-right (r2, c2) corners where r1 <= r2 and c1 <= c2. For each valid rectangle (all cells free), calculate perimeter = 2 * ((r2 - r1 + 1) + (c2 - c1 + 1)). Track the maximum perimeter. Output the maximum perimeter as a 16-bit unsigned integer. Interface: Inputs: clk (1-bit), rst_n (1-bit, active-low), start (1-bit, 1-cycle pulse), grid[7:0][7:0] (8x8-bit array, 0=blocked, 1=free). Outputs: result (16-bit), done (1-bit, pulses high for 1 cycle when result is valid). Timing: The module should complete within 256 cycles after start. On reset, result=0, done=0. Use combinational logic for prefix sums and a finite state machine to iterate over rectangles. Ensure no combinational loops. Provide detailed module specification with state definitions and control logic description.
