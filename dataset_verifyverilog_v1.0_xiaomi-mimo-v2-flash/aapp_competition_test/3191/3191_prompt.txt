Implement a Verilog module that computes the minimum worst-case time to find a crashing line using optimal printf placement strategy.

SPECIFICATION:
- Input: n (number of code lines, 1-1024), r (compile/run time, 0-255), p (printf time, 0-255)
- Output: Minimum worst-case time (16-bit)
- Algorithm: Dynamic Programming
  - Base case: If n=1, time=0 (no need to add printf, already known)
  - If n>1: Try all split positions k (1 to n-1)
    - Time = p (add printf) + r (run) + max(T(k), T(n-k))
    - Choose k that minimizes this value
  - T(n) = min over all k of [p + r + max(T(k), T(n-k))]
- Constraints: n ≤ 1024, r,p ≤ 255
- Interface:
  Inputs:
    clk: clock (rising edge)
    rst_n: active-low synchronous reset
    start: 1-cycle start pulse
    n: 10-bit input (0-1023, valid range 1-1024)
    r: 8-bit input
    p: 8-bit input
  Outputs:
    result: 16-bit output (minimum worst-case time)
    done: 1-cycle pulse when result is valid
- Timing: Start-to-done within 5000 cycles
- Reset: When rst_n=0, clear all internal state, done=0, result=0
- Implementation Notes:
  - Use DP table of size 1025 (10-bit index)
  - Precompute or compute iteratively during operation
  - For each n from 2 to max_n, compute T[n] using previous values
  - Output T[n] when computation completes

Please provide the module implementation.
