Design a Verilog module that computes the longest increasing path in an N*N grid (N=8 max) with specific jump constraints. The grasshopper starts at (R,C) and can jump to adjacent rows/columns with specific distance rules: if jumping to adjacent row (|r1-r2|=1), must jump at least 2 columns (|c1-c2|>1); if jumping to adjacent column (|c1-c2|=1), must jump at least 2 rows (|r1-r2|>1). The petal values must strictly increase.

Module Interface:
- Inputs:
  - clk, rst_n: standard synchronous signals
  - start: 1-cycle pulse to start computation
  - grid[8][8]: 64x8-bit array representing petal values (scaled to fit 8 bits)
  - start_r: 3-bit starting row (0-7)
  - start_c: 3-bit starting column (0-7)
- Outputs:
  - result: 8-bit maximum path length
  - done: 1-cycle pulse indicating completion

Implementation Requirements:
1. Use dynamic programming approach: dp[r][c] = longest path starting from (r,c)
2. Initialize all dp values to 1
3. Process cells in descending order of petal values (simulated via 64 iterations)
4. For each cell, check all valid jumps and update dp values
5. Valid jumps:
   - Row jumps: delta_r = ±1, delta_c = ±2, ±3, ±4, ±5, ±6, ±7 (within bounds)
   - Column jumps: delta_c = ±1, delta_r = ±2, ±3, ±4, ±5, ±6, ±7 (within bounds)
   - Must check bounds: new position within 0-7
   - Must check petal increase: grid[new_r][new_c] > grid[current_r][current_c]
6. Complexity: 8x8 grid = 64 cells, each checking ~14 jumps = ~896 operations
7. Use 1024 cycle timeout maximum
8. Output dp[start_r][start_c]
9. All widths: grid values 8-bit, positions 3-bit, dp values 4-bit (max path 64)
10. Use blocking assignment for sequential updates

Verilog module should be synthesizable and implement the DP algorithm using finite state machine with loops.
