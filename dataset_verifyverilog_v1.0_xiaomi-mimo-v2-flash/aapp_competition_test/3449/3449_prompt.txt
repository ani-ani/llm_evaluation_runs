Design a Verilog module `light_fence` that calculates the total fencing cost for a light grid. The grid is fixed at 8x8 cells, with border cells always sufficient. Light levels are computed using fixed-point arithmetic (Q16.16) to avoid floats. The minimum light level B and ceiling height H are inputs. The light strength grid is an 8x8 matrix of 4-bit values (0-9). The module must compute light levels for each internal cell (excluding border) by summing contributions from all lights. Use integer arithmetic by scaling the formula: contribution = (strength * 1000) / (x^2 + y^2 + H^2). If a cell's total light < B * 1000, it is 'dark'. Calculate fencing cost: for each internal edge between two adjacent cells, if either cell is dark, cost += 11; else cost += 43. Output total cost as a 16-bit value. Inputs: clk, rst_n, start, B (4-bit), H (3-bit), grid (8x4-bit array). Output: result (16-bit), done (1-cycle pulse). Timing: reset low for 2 cycles, then start high for 1 cycle, done goes high within 200 cycles when calculation is complete. All arithmetic must be integer-based; no floating point.
