You are to design a Verilog module that computes the maximum flow and minimum cost flow in a directed graph. Constraints: max nodes N=16, max edges M=32. Node indices are 0..15. Capacities are 8-bit (0-255), costs are 8-bit (0-255). The flow value F is 16-bit. 

**Interface:**
Inputs:
  clk: Clock signal
  rst_n: Active-low synchronous reset
  start: 1-cycle pulse to start computation
  num_nodes: 4-bit (2-16)
  edges_u[31:0]: 32x4-bit array of source nodes
  edges_v[31:0]: 32x4-bit array of destination nodes
  edges_c[31:0]: 32x8-bit array of capacities
  edges_w[31:0]: 32x8-bit array of costs
  num_edges: 5-bit (0-32)
  s: 4-bit source node
  t: 4-bit sink node

Outputs:
  max_flow: 16-bit result (integer)
  min_cost: 32-bit result (integer) 
  done: 1-cycle pulse (asserted when computation finishes)

**Implementation Requirements:**
1. Use an adjacency matrix representation internally for residual graph capacities (16x16, 8-bit width).
2. Use a residual cost matrix (16x16, 8-bit width).
3. Implement an iterative Edmonds-Karp algorithm (BFS for augmenting paths) modified to track minimum cost.
   - Since costs are positive, shortest augmenting path (BFS on cost) gives min-cost flow.
   - Use Bellman-Ford or Dijkstra-like approach to find the path with minimum cost per unit flow in the residual graph.
   - Iteratively find augmenting path from s to t with minimum cost, update residual capacities and total cost.
4. Max iterations: 256 cycles (since max flow is capped by capacity sums).
5. State machine required to handle initialization, path search, augmentation, and completion.
6. Internal counters for cycles must saturate at 256.
7. Output 'done' when all iterations complete or no augmenting path exists.
8. On reset: max_flow=0, min_cost=0, done=0.

**Timing:**
- Computation must complete within 10,000 clock cycles for any input within limits.
- Result is valid when done=1.

**Behavior:**
For the sample input with 4 nodes, 4 edges, source 0, sink 3, the module should output max_flow=4 and min_cost=140.
