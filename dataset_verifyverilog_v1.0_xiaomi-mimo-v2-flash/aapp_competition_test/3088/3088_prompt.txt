Design a Verilog module that computes the largest number achievable by performing exactly k swaps on the digits of an 8-digit input number. Constraints: max 8 digits, max 16 swaps. The module should find the maximum value reachable in exactly k swaps, not less, ensuring no leading zero.

Interface:
- Inputs: 
  * clk: clock signal (rising edge active)
  * rst_n: active-low asynchronous reset
  * start: 1-cycle pulse to initiate computation
  * digits_in[0:7][3:0]: 8x4-bit array representing input digits (0-9)
  * num_digits[2:0]: 3-bit input, actual number of digits (1-8)
  * k[4:0]: 5-bit input, number of swaps to perform (0-16)
- Outputs:
  * digits_out[0:7][3:0]: 8x4-bit array of resulting digits
  * valid: 1-bit, indicates valid output
  * done: 1-cycle pulse when computation finishes

Timing: start->done within 200 cycles, sample digits_out when valid=1 and done=1. Reset: valid=0, done=0, all outputs zero.

Algorithm: Use a FIFO-like state cache (max 64 states) to track current permutations and remaining swaps. Each state contains: current digit array (8x4 bits) and swaps left (4 bits). Process states iteratively, generating new states by swapping digits at all possible pairs. Keep track of best solution for exactly k swaps. The module should use a simple iterative approach with bounded loops (max 100 iterations) instead of recursion.
