Implement a Verilog module to solve the assignment problem maximizing the product of probabilities.

Specifications:
- N ≤ 20, fixed to maximum 20 (array size 20x20)
- Input probabilities are integers 0-100 (percentages)
- Convert percentages to Q8.8 fixed-point (0-256.0)
- Output: Maximum product as percentage with 0.01% resolution (Q8.8 scaled back)

Module Interface:
Inputs:
  clk: system clock
  rst_n: active-low synchronous reset
  start: 1-cycle pulse to start computation
  prob[19:0][19:0]: 20x20 array of 8-bit probabilities (0-100)
  n: 5-bit value (1-20), number of agents and missions

Outputs:
  result: 16-bit fixed-point Q8.8 percentage (0-256.0, 0.01% resolution)
  done: 1-cycle pulse indicating valid result
