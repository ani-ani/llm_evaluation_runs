Verilog module to count valid binary sequences satisfying range constraints.

Interface:
- Inputs: clk (1-bit, posedge), rst_n (1-bit, active-low async), start (1-bit, pulse), n (4-bit, 1-16), m (5-bit, 1-32)
- Constraints inputs: For each of 32 hints, provide l (4-bit), r (4-bit), type (1-bit: 0=same, 1=different). Since m varies, use a fixed-size array for all hints and valid mask.
  - Hint arrays: hint_l[31:0][3:0], hint_r[31:0][3:0], hint_type[31:0] (1-bit), hint_valid[31:0] (1-bit)
- Output: result (16-bit, mod 1e9+7), done (1-bit, pulse)

Behavior:
1. Build conflict graph of size n (nodes 1..n). For each 'different' hint [l,r]: force edges between all pairs (u,v) with l≤u<v≤r (conflict: cannot be equal). For 'same' hint: treat as union constraints.
2. Model as 2-SAT or graph coloring: Since binary, 'same' implies x_u = x_v. 'different' implies x_u ≠ x_v.
3. Use Union-Find for 'same' equivalence, then check 'different' constraints: if any pair in same set has 'different', return 0.
4. Count connected components after merging 'same' pairs. Each component can be assigned 0 or 1, so 2^components mod MOD.
5. If conflict (different constraint within same component), result=0.

Constraints:
- n ≤ 16, m ≤ 32 (scaled down from 5e3/1e6)
- Hint ranges: l,r 1-16
- Timing: Complete within 256 cycles after start
- Reset: done=0, result=0, state=IDLE
- No unbounded loops; fixed-size arrays for hints.

Algorithm details:
- Use adjacency matrix for conflicts (16x16 bits).
- Union-Find on 16 nodes.
- Iterate hints: for 'same' hints, union l-1 and r-1 (0-indexed).
- For 'different' hints, after unions, check all pairs in range; if in same set, conflict.
- Count sets: use bitset to track parent representatives.
- Compute 2^count mod MOD (MOD=1e9+7).

Edge cases:
- m=0: result=2^n
- Conflicts: result=0
- Overlapping hints handled by union-find.
