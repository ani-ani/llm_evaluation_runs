Implement a Verilog module for Maximum Independent Set on a fixed-size graph.

**Problem**: Given a connected, simple undirected graph with n vertices (1≤n≤16) and m edges (n-1 ≤ m ≤ n+15), find the size of the maximum independent set.

**Algorithm**:
1. Input graph as adjacency matrix (binary)
2. For each subset of vertices (bitmask from 0 to 2^n-1):
   - Check if subset is independent (no two vertices connected)
   - If independent, count set bits (size)
3. Track maximum size found

**Interface**:
- Inputs:
  - `clk`, `rst_n`: Standard clock and active-low reset
  - `start`: 1-cycle pulse to start computation
  - `n`: 4-bit input for number of vertices (1-16)
  - `adj_matrix[255:0]`: 16x16-bit packed adjacency matrix where `adj_matrix[i*16 + j] = 1` if edge between vertex i and j (0-indexed). Bits unused when n<16 must be 0.

- Outputs:
  - `result`: 8-bit value (maximum independent set size)
  - `done`: 1-cycle pulse indicating computation complete

**Timing Requirements**:
- Reset: 2 cycles, `done=0`, `result=0`
- Computation: `start` asserted for 1 cycle, then `done` asserted within 1000 cycles
- Result valid only when `done=1`

**Hardware Constraints**:
- Use iterative approach (no recursion)
- Maximum 256 iterations (2^8 for n≤16)
- Registers: 16-bit mask counter, 8-bit max_size, temporary registers
- Combinational logic for independence check

**Operation Sequence**:
1. On `start`, reset state
2. Iterate mask from 0 to (1<<n)-1
3. For each mask, check if independent:
   - For each pair (i,j) where both bits set in mask and i<j:
     - Check if adj_matrix[i*16+j] == 1
     - If any edge exists, mask invalid
4. If valid, count bits and update max_size
5. When all masks checked, assert `done` for 1 cycle

    input clk,
    input rst_n,
    input start,
    input [3:0] n,
    input [255:0] adj_matrix,
    output reg [7:0] result,
    output reg done
);
