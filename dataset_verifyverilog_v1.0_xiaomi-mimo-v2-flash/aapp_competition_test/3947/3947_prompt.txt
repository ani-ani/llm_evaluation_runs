Implement a Verilog module that computes the maximum score for the array removal game described. 

**Input Constraint**: n ≤ 16 (scaled down from 500k). Values are positive integers fitting in 16 bits.

**Algorithm Specification**: 
The input array `arr` is processed from left to right using a stack.
1. Initialize stack with the first element `arr[0]`.
2. For `i` from 1 to `n-1`:
   - While stack size > 1 AND the top element `s[-1]` is less than or equal to both `arr[i]` and the next-to-top element `s[-2]`:
     - Add `min(arr[i], s[-2])` to the total score.
     - Pop the top element from the stack.
   - Push `arr[i]` onto the stack.
3. After processing all input elements, the stack contains the remaining elements.
4. For the remaining elements in the stack (indices 1 to `k-2` where `k` is stack size), add `min(stack[i-1], stack[i+1])` to the score.
5. The total accumulated score is the output.

**Interface**:
- **Inputs**:
  - `clk`, `rst_n`: Standard synchronous control signals.
  - `start`: 1-cycle pulse to start processing.
  - `n`: 4-bit integer (number of elements).
  - `arr`: 16-bit array of size 16. `arr[i]` is the i-th input value.
- **Outputs**:
  - `result`: 32-bit integer (accumulated score).
  - `done`: 1-cycle pulse indicating result is valid.

**Timing**: The module should assert `done` within 256 clock cycles after `start`.

**Behavior**: 
- On reset (`rst_n` low), `result` = 0, `done` = 0, internal state reset.
- When `start` is high, load `arr` into internal storage and begin the stack processing FSM.
- The stack must be implemented using registers (e.g., `stack_vals`, `stack_ptr`).
- The accumulator must be wide enough to hold the sum (32-bit is safe).

**Constraints**:
- Use pure combinational logic for comparisons and additions within cycles.
- Do not use external memories or dynamic allocation; use fixed-size registers.
- Assume n > 0 for valid inputs.
