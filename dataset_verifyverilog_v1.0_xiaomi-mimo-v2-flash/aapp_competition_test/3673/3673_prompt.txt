Implement a Verilog module that finds the K-th root permutation of a given permutation. Given a permutation 'a' (where a[i] is the destination of i after K moves), find a permutation 'p' such that applying p K times results in 'a'. Constraints: N <= 16, K <= 256 (scaled from 10^9). 

Input interface:
- clk, rst_n: standard synchronous reset
- start: 1-cycle pulse to start computation
- n: 4-bit input (1-16)
- k: 8-bit input (1-256)  
- a[0:15]: 16x4-bit array (1-16 values, 0-indexed from 1)

Output interface:
- result[0:15]: 16x4-bit array (the permutation p)
- done: 1-cycle pulse when computation complete
- valid: high when result is valid

Implementation requirements:
1. Decompose input permutation 'a' into disjoint cycles
2. For each cycle of length L, compute its K-th root modulo L
3. The K-th root of a cycle can be computed as: shift position by (K mod L) steps backwards
4. Use iterative state machine with cycle detection
5. Complete within 1000 clock cycles
6. Use 4-bit registers for indices and 8-bit for K
7. Handle N=1 edge case

Testbench constraints:
- Test with N=6, K=2, a=[3,4,5,6,1,2] (1-indexed, convert to 0-indexed internally)
- Expected result: [5,6,1,2,3,4] (1-indexed)
- Include invalid cases that return valid=0
