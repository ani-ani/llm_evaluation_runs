Implement a Verilog module that counts palindromic strings containing a subsequence.

SCALED SPECIFICATIONS:
- N: 0 to 4 (string length limit)
- String S: 4 characters max, capital letters 'A'-'Z'
- Output modulo: 10^9+7 (30-bit arithmetic)
- Palindrome length: 2*N (max 8 characters)
- Alphabet: 26 letters

INPUTS:
- clk: System clock
- rst_n: Active-low async reset
- start: 1-cycle pulse to start computation
- s_chars[25:0]: 26-bit vector representing input string S (bit i=1 means letter ('A'+i) exists)
- s_len[2:0]: Length of S (0-4)

OUTPUTS:
- result[29:0]: 30-bit count modulo 10^9+7
- done: 1-cycle pulse when result valid (within 256 cycles)

ALGORITHM (Iterative DP):
1. Maintain DP table dp[pos][match] where:
   - pos: 0 to N (positions in palindrome half)
   - match: 0 to 4 (characters of S matched)
   - Value: count of ways
2. Initialize dp[0][0] = 1
3. For each position pos from 0 to N-1:
   - For each letter (A-Z):
     - Update dp[pos+1][new_match] += dp[pos][match]
     - new_match = match + 1 if letter matches next needed char
4. After N steps, sum dp[N][all_match] * 26^(N-match) for match=0..4
5. Multiply by 26^N for second half of palindrome
6. Return sum modulo 10^9+7

TIMING:
- Reset: 2 cycles, clears all state
- Start->Done: Max 256 cycles
- Result valid when done=1

CONSTRAINTS:
- Use 30-bit registers for counts
- Implement modulo arithmetic with 10^9+7
- State machine for sequence control
- Fixed 4-step computation for N=4 maximum
- 26^N precomputed for N=0..4 (1, 26, 676, 17576, 456976)
