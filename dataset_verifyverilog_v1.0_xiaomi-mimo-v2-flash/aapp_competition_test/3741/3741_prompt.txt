Design a Verilog module that finds the length of the shortest cycle in an undirected graph where nodes are connected if their integer values have a non-zero bitwise AND.

### Constraints & Scaling:
- Input size: Process up to **N=16** non-zero integers (stored in 64-bit registers).
- Integer width: **64-bit** values (input as 64-bit vectors).
- Graph: Up to 16 nodes, adjacency is implicit via bitwise AND.
- Output: Cycle length (3 to 16), or -1 (0xFFFF) if no cycle.
- Algorithm: 
  1. **Pre-check**: If any bit (0-63) is set in 3+ numbers, the shortest cycle is 3. Output 3 immediately.
  2. **Graph Construction**: For all pairs (i, j), if (val[i] & val[j]) != 0, set edge[i][j] = 1.
  3. **BFS**: Run BFS from each node (source) to find the shortest cycle passing through that node.
     - Use `group` and `dist` arrays (size 16) to track BFS layers and parents.
     - Cycle detected when reaching an already visited node `v` that is not the immediate parent.
     - Cycle length = `dist[u] + dist[v] + 1`.
     - Stop early if cycle length = 3 is found (optimized).

### Interface:
- **Inputs**:
  - `clk`, `rst_n`: Standard synchronous controls.
  - `start`: 1-cycle pulse to initiate computation.
  - `data_in [63:0]`: 64-bit input integer. Valid when `wr_en` is high.
  - `wr_en`: Pulse to load `data_in` into the internal array (wraps around 0-15).
  - `num_nodes [3:0]`: Number of valid nodes (1-16).
- **Outputs**:
  - `result [15:0]`: Shortest cycle length (1-16) or 0xFFFF for -1.
  - `done`: 1-cycle pulse asserted when result is valid.

### Implementation Details:
1. **Storage**: Array `vals[0:15]` of 64-bit registers.
2. **Control**: FSM with states IDLE, CHECK_BITS, BUILD_GRAPH, BFS_LOOP, UPDATE_MIN, FINISH.
3. **BFS Logic**:
   - Iterate `src` from 0 to `num_nodes-1`.
   - Initialize `dist` array to 0xFFFF (infinity) and `parent` array.
   - Set `dist[src] = 0`. Push `src` to FIFO.
   - Process queue: Pop `u`. For each neighbor `v` (bit check `vals[u] & vals[v]`):
     - If `dist[v] == 0xFFFF`: Set `dist[v] = dist[u] + 1`, `parent[v] = u`, push to FIFO.
     - Else if `parent[u] != v`: Cycle found. Length = `dist[u] + dist[v] + 1`. Update `min_cycle`.
4. **Timing**: Target < 5000 cycles for 16 nodes. Max depth 16.
5. **Reset**: Clears `vals` array, `min_cycle`, and FSM state.
