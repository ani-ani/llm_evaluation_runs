You are to implement a Verilog module that computes the maximum number of bags for which the fake bag can be determined given m weighings and k coins per bag, modulo 998244353.

The mathematical formula is: max_bags = (2*m + 1)^k mod 998244353

Constraints:
- m, k are positive integers in range [1, 10^6]
- Result must be modulo 998244353
- Use 32-bit arithmetic for intermediate calculations
- Modular exponentiation required for large exponents

Interface Specification:
Inputs:
  clk: clock signal for sequential logic
  rst_n: active-low synchronous reset
  start: 1-cycle pulse to initiate calculation
  m_in: 32-bit input for number of weighings
  k_in: 32-bit input for number of coins per bag

Outputs:
  result: 32-bit output containing the result modulo 998244353
  done: 1-cycle pulse indicating calculation complete

Timing:
- When start=1, latch inputs m_in and k_in
- Calculate (2*m + 1) mod 998244353 first
- Then compute (base)^k using modular exponentiation
- Maximum execution time: 1000 cycles for k up to 10^6
- Set done=1 when result is valid, result stays constant until next start

Reset Behavior:
- On rst_n=0, clear all internal state
- done=0, result=0, ready for new calculation
- Minimum 2 cycles of reset required

Implementation Details:
- Use sequential logic (FSM) for modular exponentiation
- Base = (2*m + 1) % MOD
- Exponent = k
- MOD = 998244353 (prime)
- Handle large exponent with binary exponentiation (bit-by-bit)
- Use 64-bit registers for multiplication to avoid overflow before modulo
- Output result modulo 998244353

Module Declaration:
module max_bags_finder(
    input clk,
    input rst_n,
    input start,
    input [31:0] m_in,
    input [31:0] k_in,
    output [31:0] result,
    output done
);

Implementation should:
1. Wait for start pulse
2. Compute base = (2*m_in + 1) % MOD
3. Perform modular exponentiation: base^k_in mod MOD
4. Output result when done
5. Return to idle state waiting for next start
