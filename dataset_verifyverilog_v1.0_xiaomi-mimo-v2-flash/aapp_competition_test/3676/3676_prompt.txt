Implement a Verilog module `polygon_counter` that counts the number of valid polygons in an R x C grid (1 <= R,C <= 4). A valid polygon is defined as a non-empty subset of grid cells that is:
1. Connected (4-neighbors).
2. Has no holes (every background cell not in the subset must be connected to the grid border).

**Interface:**
- Inputs: `clk`, `rst_n` (active-low async reset), `start` (1-cycle pulse).
- Parameters: `R` (1..4), `C` (1..4).
- Outputs: `result` (16-bit), `done` (1-cycle pulse).

**Behavior:**
1. On `start` assertion, reset state and begin enumeration.
2. Generate all 2^(R*C) subsets (0 to (1<<(R*C))-1).
3. For each subset, check validity:
   a. Must contain at least 1 cell.
   b. Check connectivity (4-neighbors) using DFS/BFS logic or iterative neighbor checks.
   c. Check for holes: Identify all 'background' cells (not in subset). If any background cell is not connected to the grid border (edge cells are border), it is a hole. Subset is invalid if holes exist.
4. Increment `result` counter for valid subsets.
5. Set `done` high for 1 cycle when enumeration finishes.

**Constraints:**
- Max cycles: ~10,000 (enough for 65536 states * 16 cells).
- Use iterative logic, no recursion.
- All signals must fit in standard Verilog types (use 16-bit for counters).
- R*C <= 16.

**Example Timing:**
- Start asserted at Cycle 0.
- Done asserted at Cycle N (approx 65k).
- Result valid when Done=1.

**Implementation Hint:**
Iterate `mask` from 0 to (1<<(R*C))-1. Inside the loop, validate `mask`. Use a flattened index `idx = r*C + c`. Neighbors: up, down, left, right (handle boundaries). For hole check, perform BFS on background cells starting from all border cells; any unvisited background cell indicates a hole.
