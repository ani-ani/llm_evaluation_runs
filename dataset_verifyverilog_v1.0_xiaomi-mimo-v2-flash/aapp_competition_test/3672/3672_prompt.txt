Design a Verilog module to determine if Zax and Xaz can coexist on El-gă-rizm. This is a bipartite graph coloring problem where islands are nodes and shared resources are edges.

**Problem Adaptation:**
- Maximum islands: 16 (scaled from 1M)
- Maximum resources: 16 (scaled from 1M)
- Maximum resources per island: 8
- Graph representation: Edge list (pairs of islands sharing a resource)

**Algorithm:**
1. Input: List of edges between islands (each edge represents a shared resource)
2. Perform BFS/DFS coloring to check if graph is bipartite
3. Output YES (1) if bipartite, NO (0) if not

**Interface Specification:**
Inputs:
  clk: Rising edge clock
  rst_n: Active-low synchronous reset
  start: 1-cycle pulse to start computation
  edge_count: 4-bit input (0-15 edges)
  edge_i_j: 5-bit vector [4:0] for each edge (i in [4:2], j in [1:0], 2-bit island indices for up to 4 islands, scaled)

Outputs:
  result: 1-bit (1 = YES, 0 = NO)
  done: 1-cycle pulse when computation complete

**Timing:**
- start -> done: within 100 cycles
- Reset: 2 cycles, done=0, result=0

**Implementation Details:**
- Use 4-bit color array for 16 islands (2 colors: 0=Zax, 1=Xaz)
- Use 4-bit queue for BFS (circular buffer, max 16 elements)
- Use 4-bit visited array (one-hot per island)
- Process edges sequentially, checking for conflicts
- State machine: IDLE -> LOAD -> CHECK -> DONE

**Module Signature:**
module coexistence_check (
    input clk, rst_n, start,
    input [3:0] edge_count,
    input [4:0] edge_i_j[0:15], // 16 edges, 5 bits each
    output reg result, done
);

**Required:**
- No external memory, all state in registers
- Fixed iteration bounds
- Detect coloring conflicts: if edge connects same-color islands, fail
- Output 1 for YES (bipartite), 0 for NO (non-bipartite)
