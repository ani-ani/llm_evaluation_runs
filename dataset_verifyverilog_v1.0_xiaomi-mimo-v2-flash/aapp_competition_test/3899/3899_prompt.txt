Implement a Verilog module to solve the optimization problem for n tasks. The goal is to find the minimum average compute power per processor (scaled by 1000) for the first execution round.

You are given:
- n: number of tasks (1 to 50)
- power[i]: 8-bit integers (1 to 100) scaled by 1000 internally for precision
- processors[i]: 8-bit integers (1 to 100)

The problem is to partition tasks into groups of size 1 or 2 for computers, where the second task in any pair must have strictly less power than the first. Only the first tasks in each group contribute to the average calculation. The first task can be any task. We need to select a subset of tasks to be 'first tasks' such that:
1. They can be paired with remaining tasks (where second task < first task in power)
2. The weighted average (sum of powers / sum of processors) of selected first tasks is minimized

Key Constraints:
- Max n = 50
- Power values: 1-100 (scale by 1000 for integer math: 1000-100000)
- Processors: 1-100
- Total processor sum max: 50*100 = 5000 (use 13 bits)
- Total power sum max: 50*100000 = 5,000,000 (use 23 bits)
- Output: ceiling of (sum_power * 1000 / sum_processors) as integer

Implementation Strategy:
1. Sort tasks by power descending
2. Use DP state: dp[p][s] = minimum total power to achieve processor sum 's' using 'p' tasks from a prefix
3. Transition: For each task, update DP states considering it as first or second task
4. At the end, compute min over valid states of ceil(power*1000/processors)
5. Use fixed-point arithmetic with Q16.16 for division if needed

Interface:
- Inputs: clk, rst_n, start, n[5:0], power[0:49][7:0], processors[0:49][7:0]
- Outputs: result[31:0] (the final answer), done
- Timing: Start signal triggers computation, done goes high when complete (within 2000 cycles)

Note: The algorithm requires sorting and DP. Implement sorting network for up to 50 elements (or use combinational logic with state machine). Use iterative DP with state machine. The DP table needs to track min power for each processor sum, updating as we process tasks.
