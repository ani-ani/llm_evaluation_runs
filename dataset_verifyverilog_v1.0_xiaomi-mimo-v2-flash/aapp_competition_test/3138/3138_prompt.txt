Implement a Verilog module that counts the number of subarrays (contiguous ranges of at least 2 elements) where the sum equals the product.

Constraints:
- Input array size: Max 16 elements (fixed width 4 bits for length)
- Element values: Max 1024 (10 bits), scaled down from original 10^9 to fit hardware
- Result: Count of valid subarrays (max possible is ~120 for 16 elements, fits in 8 bits)

Module Interface:
- Inputs:
  - clk: System clock (rising edge triggered)
  - rst_n: Active-low asynchronous reset
  - start: 1-cycle pulse to start calculation
  - arr[0:15]: 16 inputs, 10-bit each, representing the array elements (indexed 0 to 15)
  - len: 4-bit input, actual length of the array (number of valid elements in arr)
- Outputs:
  - result: 8-bit output, count of subarrays where sum equals product
  - done: 1-cycle pulse asserted when calculation is complete

Behavior:
1. On reset (rst_n=0), set done=0, result=0.
2. When start=1, capture input array values and length.
3. Iterate through all possible subarray start indices i (0 to len-2) and end indices j (i+1 to len-1).
4. For each subarray, calculate the sum and the product of elements from i to j.
   - Sum: 16-bit accumulator (max sum 16*1024=16384)
   - Product: 32-bit accumulator (max product 1024^16 is huge, but we can cap at a safe upper bound like 2^32-1 to avoid overflow logic; since we only compare to sum which is small, we can stop accumulating if product exceeds a safe threshold).
5. If sum == product, increment the result counter.
6. The calculation should complete within 2000 clock cycles.
7. Assert done=1 for exactly one cycle when the counting is finished.

Implementation Notes:
- Use simple FSM: IDLE -> CALCULATING -> DONE.
- Use nested loops for indices i and j.
- Use sequential logic for accumulation to avoid combinational path delays.
- Since the problem asks for ranges of at least 2 pages, the inner loop starts from i+1.
