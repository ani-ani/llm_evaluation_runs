Design a Verilog module to count Pythagorean triples modulo n where n is between 2 and 256. The module should compute the number of triples (a,b,c) where 1 <= a,b,c <= n-1, a <= b, and (a^2 + b^2) % n == c^2 % n.

Interface:
- Inputs: clk, rst_n, start, n (8-bit)
- Outputs: result (16-bit), done (1-cycle pulse)
- Timing: Start a single computation when start=1. The computation completes within 2000 cycles. done=1 when result is valid. Result is 0 after reset.
- Algorithm: Use triple nested loops for a, b, c with bounds (0 to n-1). For each combination, check condition using modulo arithmetic. Use 16-bit registers for intermediate squares and sums. Count valid triples in a 16-bit counter.
- Implementation: Use FSM with states: IDLE, COMPUTE, DONE. COMPUTE state iterates through a (0..n-1), b (a..n-1), c (1..n-1). Check condition ((a*a + b*b) % n) == ((c*c) % n). Increment count on match.
- Constraints: n is max 256. All arithmetic on 16-bit wires. No external memory. Reset clears result and state.
