Design a Verilog module that finds the minimum number of moves to sort a permutation by moving elements to ends. The core observation is: find the longest contiguous subsequence of values [v, v+1, ..., v+k-1] that appear in strictly increasing order of positions in the input. The answer is n - length of this subsequence.

For HDL implementation with n=16:
1. Input: p[15:0] - 16-element permutation (each 4 bits, values 1-16)
2. Compute position array: For each value v (1-16), store its original position (0-15)
3. Find longest contiguous increasing sequence: Iterate v from 1 to 16, track current length (starts at 1), increment if pos[v] > pos[v-1], else reset to 1
4. Output: result = n - max_length (8 bits, 0-16)

Module Interface:
- Inputs: p[15:0] (each 4 bits), clk, rst_n, start (1-cycle pulse)
- Outputs: result[7:0], done (1-cycle pulse)
- Timing: start->done within 100 cycles
- Implementation: Use FSM with states IDLE, LOAD_POS, FIND_SEQ, COMPUTE, DONE. Use 16x4-bit position memory. Use 4-bit comparators and 4-bit counters for length tracking. result = 16 - max_len.
