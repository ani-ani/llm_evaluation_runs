Implement a Verilog module that simulates Mr. Turtle's drawing problem on a fixed 6x8 grid. The module should process commands to generate a path, then compute the earliest and latest timestep the marker can dry out to match the target pattern.

**Interface:**
- Inputs: `clk`, `rst_n` (active-low sync reset), `start` (1-cycle pulse)
- Commands: 5 commands of type `cmd_dir [1:0]` (0=up, 1=down, 2=left, 3=right) and `cmd_dist [7:0]` (1-100)
- Target Pattern: 6x8 grid of `target_grid [47:0]` (1 bit per cell, row-major order, 1=marked '#', 0=blank '.')
- Output: `min_time [7:0]` (0-255), `max_time [7:0]` (0-255), `valid` (1 if solution found), `done` (1-cycle when finished)

**Behavior:**
1. On `start` high, reset internal state and begin processing.
2. Generate path coordinates (x,y) starting at (0,5) [bottom-left]. Process 5 commands sequentially (10 cycles delay).
3. For each timestep t=1..T (where T is path length, max 100), determine which cells are marked (visited at or before t).
4. Compare marked cells against `target_grid`. Find all valid drying times t where marked cells == target_grid.
5. If valid times exist, set `min_time` to smallest valid t, `max_time` to largest valid t, `valid`=1. Else `valid`=0.
6. Set `done`=1 for 1 cycle after computation.

**Constraints:**
- Grid: Fixed 6 rows x 8 cols (48 cells).
- Commands: Exactly 5 commands, distances scaled to max 100 to fit 8-bit.
- Path Length: Max 100 steps (scaled from 1M).
- Timing: Operation completes within 500 cycles. No external memory.
- Reset: `done`=0, `valid`=0, outputs zeroed on reset (2 cycles).
