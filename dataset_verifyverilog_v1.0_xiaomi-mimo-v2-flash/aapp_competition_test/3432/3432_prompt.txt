Design a Verilog module 'min_max_sum' that processes N rounds of A/B pairs to find minimal maximal sum for optimal pairing.

### Core Logic
For each round, receive (A, B) pair. Store numbers in arrays. Sort A ascending, B descending. Compute max of A[i] + B[i] for i=0 to N-1. This is the minimal maximal sum.

### Constraints
- N (number of rounds) ≤ 100,000 but each round processes only 2 numbers
- A, B values: 1-100 (7 bits)
- Max N for simulation: 16 rounds (array size 16)
- Clock: 100MHz (10ns period)

### Interface
Inputs:
  - clk: system clock (rising edge)
  - rst_n: active-low synchronous reset
  - start: 1-cycle pulse to start processing
  - A: 7-bit input number (1-100)
  - B: 7-bit input number (1-100)
  - valid_in: 1-bit flag, high when A/B are valid

Outputs:
  - result: 16-bit result (max sum, range 2-200)
  - done: 1-cycle pulse, high when result is ready
  - ready: 1-bit flag, high when module accepts new input

### Timing & Handshake
1. Wait for start=1 at reset
2. For each valid_in=1 with ready=1, accept (A,B) pair
3. After N pairs processed, compute result
4. Assert done=1 for one cycle with valid result
5. ready=0 during computation, high when accepting inputs

### Implementation Details
1. Use 16-element arrays for A_vals and B_vals (max N=16)
2. Counter to track number of inputs received (0-15)
3. State machine: IDLE → ACCEPTING → SORTING → COMPUTING → DONE
4. Sorting: Compare-exchange network for small arrays (16 elements)
5. Computation: Pipe through adders and compare tree
6. Use 8-bit storage (values 1-100 fit in 7 bits, 8-bit for simplicity)
7. Result width: 8+8=16 bits

### Reset Behavior
- done = 0, result = 0, ready = 1
- All counters and state registers cleared
- Arrays initialized to zero

### Required Output Signal
Complete Verilog module with all signals above.
