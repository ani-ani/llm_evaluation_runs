Implement a Verilog module that solves the wolf-sheep-cabbage crossing problem. Given counts of wolves (W), sheep (S), cabbages (C), and boat capacity (K), determine if a valid crossing sequence exists without leaving incompatible items unsupervised.

**SCALED INPUTS (8-bit):**
- W, S, C, K: 8-bit unsigned integers (0-255)

**LOGIC:**
The problem reduces to checking if the boat capacity is sufficient to prevent dangerous states. Key conditions:
1. If K=0: Impossible (NO)
2. If K >= (W+S+C): YES (all in one trip)
3. If K=1: Only possible if no conflicts exist (e.g., S=0 or (W=0 and C=0))
4. If K>=2: Generally YES, except specific edge cases:
   - If W>0, S>0, C>0 and K=1: NO
   - If K=2 and counts are such that splits leave dangerous states

For K>=2, the standard solution works: transport items while maintaining safe states (no wolf-sheep or sheep-cabbage pairs left unsupervised unless K > 1 allows separation).

**MODULE INTERFACE:**
Inputs:
  W[7:0]: number of wolves
  S[7:0]: number of sheep  
  C[7:0]: number of cabbages
  K[7:0]: boat capacity

Outputs:
  result: 1-bit (1=YES, 0=NO)
  done: 1-bit (always 1, combinatorial logic)

**IMPLEMENTATION GUIDANCE:**
Use combinational logic with case analysis. The core insight: with K>=2, you can always separate wolves and sheep, or sheep and cabbages, by making strategic trips. The only impossible cases are K=0, or K=1 with all three items present, or specific capacity mismatches that force dangerous states. The module should implement a simplified decision tree checking:
- If K=0: NO
- Else if K >= W+S+C: YES
- Else if K=1: YES only if S=0 or (W=0 and C=0)
- Else if K=2: Check if W>0, S>0, C>0 - if so, requires careful analysis, but typically YES if max(W,S,C) <= 2
- Else (K>=3): YES (standard solution exists)

Return result=1 for YES, 0 for NO. The done signal is always 1 since it's combinatorial.
