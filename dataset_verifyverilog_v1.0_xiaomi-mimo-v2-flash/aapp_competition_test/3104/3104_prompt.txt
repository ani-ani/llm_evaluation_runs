Design a Verilog module `partition_addition` that solves the partition problem. 

**Interface:**
- Inputs: `clk`, `rst_n`, `start` (1-cycle pulse).
- `digits_in`: Array of 24 inputs, each 8-bit (representing ASCII '0'-'9').
- `len_in`: 5-bit input indicating number of valid digits.
- `target_sum`: 16-bit input.

- Outputs: `result_str`: Array of 48 outputs, each 8-bit (ASCII characters).
- `result_len`: 6-bit output indicating length of result string.
- `done`: 1-cycle pulse indicating valid result.

**Logic:**
1. On `start` asserted, load inputs.
2. Use a state machine (FSM) to perform a search (DFS or BFS) for valid partitions.
3. **Scaling:** Since full 1000-digit DP is too large, implement a backtracking search with a maximum recursion depth of 24 (scaled down from 1000).
4. **Target:** Target sum is scaled to fit 16 bits. The search finds a sequence of substrings whose integer values sum to `target_sum`.
5. **Output:** Construct the string `term1+term2+...=target` in the `result_str` array.
6. **Timing:** Operation must complete within 10,000 cycles.

**Constraints:**
- Use iterative logic or bounded loops (max 24 digits).
- Avoid unbounded memory; use registers for path tracking.
- Module must be synthesizable.
