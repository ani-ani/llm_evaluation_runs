Implement a Verilog module that finds the maximum value of f(l, r) = sum_{i=l}^{r-1} |a[i] - a[i+1]| * (-1)^(i-l) for any 1 ≤ l < r ≤ n. The array a has n elements (2 ≤ n ≤ 16). Input a[i] ranges from -10^9 to 10^9.

The algorithm:
1. Compute differences d[i] = |a[i] - a[i+1]| for i = 0 to n-2
2. Create two arrays:
   - ev[i] = d[i] * (-1)^i (starting with positive at i=0)
   - od[i] = d[i] * (-1)^(i+1) (starting with negative at i=0)
3. Find maximum subarray sum for both ev and od using Kadane's algorithm
4. Return the maximum of the two results

Interface:
- Inputs:
  - clk: system clock, rising edge
  - rst_n: active-low synchronous reset
  - start: 1-cycle pulse to start computation
  - n: 4-bit input (2-16)
  - a[0:15]: 16-element array, each 32-bit signed
- Outputs:
  - result: 32-bit signed maximum value
  - done: 1-cycle pulse when result is valid

Timing Requirements:
- start asserted for 1 cycle
- done asserted within 100 cycles after start
- result valid when done=1
- Reset: done=0, result=0, minimum 2 cycles

Constraints:
- Use 32-bit signed arithmetic for all intermediate values
- Use 32-bit registers for prefix sums and maximums
- Implement both ev and od cases
- Use a single processing loop that iterates through n-1 elements
- Maximum cycles: 100
- Pipeline the difference computation and Kadane's algorithm
