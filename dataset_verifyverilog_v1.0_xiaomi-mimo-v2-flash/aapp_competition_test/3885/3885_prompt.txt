Implement a Verilog module that calculates the minimum cost to visit all schools, given the number of schools `n`. The problem is modeled as a Minimum Spanning Tree (MST) on a complete graph where the edge weight between schools `i` and `j` is `(i + j) % (n + 1)`. Through mathematical analysis, the minimum total cost for `n` schools is `(n - 1) // 2`.

The module must:
1. Accept input `n` as a 17-bit unsigned integer (since max `n` is 100,000, requiring 17 bits).
2. Perform a single-clock-cycle calculation: `result = (n - 1) / 2` (integer division).
3. Output the `result` as a 17-bit unsigned integer.
4. Include standard synchronous logic with `clk` and active-low `rst_n`.
5. Include a `start` signal to trigger the calculation.
6. Include a `done` signal that pulses high for one cycle when the calculation is complete and `result` is valid.
7. The calculation latency should be minimal (ideally 1 cycle after start).

**Interface Specification:**
- Inputs:
  - `clk`: System clock, rising edge triggered.
  - `rst_n`: Active-low synchronous reset.
  - `start`: 1-cycle pulse to initiate calculation.
  - `n`: 17-bit input representing the number of schools.
- Outputs:
  - `result`: 17-bit output containing the minimum cost.
  - `done`: 1-cycle pulse indicating the result is valid.

**Implementation Details:**
- The logic for `(n - 1) // 2` can be implemented by right-shifting `(n - 1)` by 1 bit.
- Ensure `n` is greater than 0. Handle `n=1` case where result is 0.
- Since `n` is unsigned, subtract 1 from `n` first, then shift right.
- Use non-blocking assignments for sequential logic.
- Ensure `result` and `done` are registered outputs.

**Timing:**
- `start` triggers the operation.
- `done` goes high 1 clock cycle later.
- Reset clears `done` and sets `result` to 0.

**Example:**
- If `n` = 10, `result` should be 4.
- If `n` = 2, `result` should be 0.
- If `n` = 1, `result` should be 0.
