Design a Verilog module that generates swap pairs for a permutation of size n (n <= 8). The module should implement the logic to output all pairs (a, b) with a < b such that performing these swaps preserves the permutation (requires an even number of swaps). For n where n % 4 > 1, output 'NO' (represented as a 2-bit value: 2'b00 for NO, 2'b01 for YES). For valid n, output the pairs. Since O(n^2) pairs are too many for a fixed-size output, we will implement a state machine that generates pairs sequentially and asserts 'valid' when a pair is ready. The module takes 'n' (3 bits) as input and outputs 'pair_a', 'pair_b' (3 bits each), 'valid' (1 bit), and 'possible' (1 bit). The sequence must cover all pairs (i, j) for i < j exactly once. The algorithm must ensure the permutation returns to original. For n % 4 == 0 or n % 4 == 1, it's possible.

Interface:
- Inputs: clk, rst_n, start, n[2:0]
- Outputs: pair_a[2:0], pair_b[2:0], valid, done, possible
- Timing: When start is asserted, the FSM begins. If possible is 0, done is asserted immediately. If possible is 1, valid pulses for each pair. done is asserted when all pairs are generated. max pairs for n=8 is 28, so max cycles 28 + overhead.
- Reset: All outputs 0, possible 1.
- Constraint: n <= 8 (to fit in 3 bits). If n > 8, treat as invalid (possible=0).
