Implement a Verilog module that computes for each road in a small directed graph, the number of shortest paths containing that road. The graph has at most 16 nodes and 32 edges.

**Input Interface:**
- `clk`, `rst_n`: Standard synchronous control
- `start`: 1-cycle pulse to begin computation
- `num_nodes`: 4-bit input (1-16)
- `num_edges`: 5-bit input (1-32)
- For edges, you receive 32 ports of type `edge_in` (each 32-bit wide) packed as: {16-bit unused, 5-bit destination, 5-bit source, 6-bit length}

**Output Interface:**
- `result`: 32-bit output, providing the answer for the current edge (in order)
- `result_valid`: 1-bit pulse when result is ready for current edge
- `edge_done`: 1-bit pulse when all edges are processed
- Timing: start->edge_done within 10,000 cycles

**Algorithm (Scalable for N≤16, M≤32):**
1. Use Floyd-Warshall (O(N³)) to compute all-pairs shortest distances: `dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])` with N=16 => 4096 iterations max.
2. For each source S (1 to N), compute shortest path counts from S to all nodes using DP:
   - Initialize `cnt[S][*] = 0`, `cnt[S][S] = 1`
   - Relax edges: `cnt[S][v] += cnt[S][u]` if `dist[S][u] + w == dist[S][v]`
3. For each source S, compute reverse counts: `rev[S][v]` = number of shortest paths from v to T (for all T), computed similarly but on reversed graph.
4. For each edge (u->v, w), if it lies on any shortest path (i.e., `dist[S][u] + w + dist[v][T] == dist[S][T]` for some S,T), then the total count for this edge is sum over all (S,T) where condition holds: `cnt[S][u] * rev[S][v]`. Sum all such contributions modulo 1e9+7.

**Hardware Constraints:**
- Use block RAM for `dist[16][16]` (256 entries, 24-bit width).
- Use distributed RAM for `cnt[16][16]` and `rev[16][16]` (512 entries, 32-bit width).
- Implement Floyd-Warshall with 3 nested loops (k,i,j) using state machine.
- For edge counting: iterate over all S (1..N), compute cnt and rev arrays, then for each edge check all T (1..N). Total iterations: N * (N² for DP + M*N for counting) = 16*(256 + 32*16) = 12,288 cycles max.
- All arithmetic uses 32-bit unsigned with modulo 1e9+7 (1000000007).
- Reset: clear all RAMs, set `edge_done=0`, `result_valid=0`.
