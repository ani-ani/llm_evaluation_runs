Implement a Verilog module that computes the number of ways to assign plaque numbers satisfying the given constraints.

Problem Analysis:
- We need to compute: (k^(k-1) * (n-k)^(n-k)) % 1000000007
- This follows from counting functional graphs where nodes 1..k form a rooted tree pointing to node 1, and nodes k+1..n form a rooted tree with no connection to 1.

Module Interface:
- Inputs:
  * clk: clock signal (rising edge active)
  * rst_n: active-low synchronous reset
  * start: 1-cycle pulse to start computation
  * n_in: 10-bit input (1 ≤ n ≤ 1000)
  * k_in: 10-bit input (1 ≤ k ≤ 8)
- Outputs:
  * result: 32-bit output containing the answer modulo 1000000007
  * done: 1-cycle pulse indicating result is valid

Timing Constraints:
- Start asserted for 1 cycle when inputs are ready
- Computation completes within 1000 cycles
- Reset: 2 cycles minimum, sets result=0, done=0

Implementation Requirements:
- Use modular exponentiation to compute powers
- MOD = 1000000007 (32-bit constant)
- Handle base cases: when n==k (k^(k-1)), when k==1 (1^0 * (n-1)^(n-1))
- Pipeline the two multiplications if needed
- Use 32-bit arithmetic for all operations

Notes:
- k^(k-1) requires exponentiation with exponent up to 7
- (n-k)^(n-k) requires exponentiation with exponent up to 992
- Intermediate values must fit 32-bit before modulo
- Output 0 for invalid inputs (k > n or k < 1)
