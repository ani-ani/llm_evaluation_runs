Design a Verilog module that simulates the Trash card game between Theta and a Friend using a fixed 52-card deck represented as a 52x4-bit array (card codes: 0=2, 1=3, ..., 9=T, 10=J, 11=Q, 12=K, 13=A). The module should implement the turn-based logic where players alternate drawing from the deck index. 

Interface:
Inputs:
  clk: rising edge
  rst_n: active-low reset
  start: 1-cycle pulse to start simulation
  deck[51:0][3:0]: 52-card deck, each card 4 bits

Outputs:
  result: 2-bit (00=Theta wins, 01=Friend wins, 10=Draw/Error, 11=Invalid)
  done: 1-cycle high when game ends

Constraints:
- Theta's 10 cards: deck[9:0] (slot 0-9)
- Friend's 10 cards: deck[19:10] (slot 0-9)
- Draw pile: deck[20:51]
- Slots: 4-bit status per slot (0=empty, 1=face-down, 2=face-up/filled)
- Jack (10) logic:
  - Theta: Minimize unfilled slots (count face-down + face-up in that slot)
  - Friend: Always fill lowest unfilled slot
- Wildcards/Ace handling: Slots 0-4 (Ace-5), 5-9 (6-10)
- Game ends when any player has all slots filled (status=2)
- Max 52 cycles to complete

Algorithm Steps:
1. Reset: Initialize player slots to 1 (face-down), deck_idx=20, active_player=0 (Theta), result=Invalid
2. Start: Begin simulation on rising edge after start pulse
3. Turn Loop (FSM):
   - Draw card from deck[deck_idx], increment deck_idx
   - If card is Q(11) or K(12): Discard, switch player, return to draw
   - If card is J(10): 
     - Apply strategy to select slot, mark slot as 2, check win
   - If card is A-T (0-9):
     - Map to slot: card 0-4 -> slot 0-4, card 5-9 -> slot 5-9
     - If slot already filled (status=2): Discard, switch player
     - Else: Uncover face-down card at that slot, place drawn card (status=2), check win
4. Win Check: If all 10 slots are status=2, set result and done=1
5. Timing: done pulses high after max 52 cycles from start

Note: Implement iterative loop structure with cycle counter. Use lookup tables for card-to-slot mapping.
