Implement a Verilog module for a simplified tree-based army movement cost calculator. 

**Constraints:**
- Input tree has exactly 8 nodes (fixed). Use an adjacency list representation.
- Edge costs and army counts are 16-bit unsigned integers.
- Total armies and demands are bounded by 256.
- Tree structure is fixed for the testbench (no dynamic input parsing).

**Algorithm:**
1. The tree is a rooted binary tree (Node 1 is root).
2. For each node, calculate `net = current_armies - required_armies`.
3. Propagate the net flow up the tree. The cost is the sum over all edges of `abs(flow) * edge_cost`.

**Module Interface:**
- **Inputs:**
  - `clk`, `rst_n`: Standard synchronous control signals.
  - `start`: 1-cycle pulse to start computation.
  - `parent_idx[2:0]`: Index of the parent node (0 to 7). Valid for nodes 1-7.
  - `edge_cost[15:0]`: Cost associated with the edge to the parent.
  - `army_curr[15:0]`: Current armies at the node.
  - `army_req[15:0]`: Required armies at the node.
  - `valid_input`: Indicates valid input data for the current node.
- **Outputs:**
  - `result[31:0]`: Minimum total movement cost.
  - `done`: 1-cycle pulse indicating calculation is complete.

**Implementation Details:**
- Use a sequential state machine to iterate through all 8 nodes.
- Maintain a lookup table for net flow values (16-bit signed).
- Accumulate the cost: `cost += abs(net_flow * edge_cost)`.
- The module should handle the fixed tree structure internally.

**Testbench Expectation:**
The testbench will initialize the 8-node tree data (structure from Example 2), assert `start`, and verify that `result` matches the expected minimum cost (9 in the scaled example).
