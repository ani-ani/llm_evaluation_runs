Design a Verilog module that generates coordinates for n knights in a pattern that ensures the final configuration meets the requirement. The module should implement the following algorithm:

1. Calculate `groups = n / 3` (integer division)
2. Calculate `remainder = n % 3`
3. For each group i from 0 to groups-1:
   - Output knight at (2*i, 0)
   - Output knight at (2*i + 1, 0)
   - Output knight at (2*i + 1, 3)
4. For the remainder knights (0 to remainder-1):
   - Output knight at (2*groups + i, 0)

All coordinates are non-negative and bounded by 2*groups (max ~666 for n=1000). The output coordinates should be generated sequentially with each knight's coordinates output over consecutive clock cycles.

Interface Specification:
Inputs:
  clk: rising edge clock
  rst_n: active-low synchronous reset
  start: 1-cycle pulse to start generation
  n: 10-bit unsigned input (1-1000, as n ≤ 1000)
Outputs:
  x: 11-bit signed output coordinate (range 0 to ~666)
  y: 2-bit signed output coordinate (0 to 3)
  valid: 1-bit output, high when coordinates are valid
  done: 1-cycle pulse when all n knights have been output

Timing:
- start triggers the generation
- After start, valid should be high on every cycle
- Coordinates should be output one knight per cycle
- done should pulse high for one cycle exactly n cycles after start
- After done, valid should be low until next start
- Maximum n is 1000, so maximum cycles needed is 1000

Implementation Notes:
- Use a counter to track which knight is being generated (0 to n-1)
- Use another counter for groups and remainder
- Compute x and y based on the current knight index
- The pattern ensures at least floor(n²/10) knights in final configuration
