Implement a Verilog module that determines if an input string is a 'mirror' word.

**Inputs:**
  `clk`: System clock, rising edge
  `rst_n`: Active-low synchronous reset
  `start`: 1-cycle pulse to start processing
  `len`: 4-bit unsigned integer (1-16 characters)
  `char_data`: 16x8-bit array (packed or unpacked) representing the string. Only the first `len` characters are valid. Indices correspond to input string position (0 to 15).

**Outputs:**
  `result`: 1-bit output (1 for YES, 0 for NO)
  `done`: 1-cycle pulse indicating valid result

**Functionality:**
The module must perform two checks on the input string:
1. **Symmetry Check:** The string must be a palindrome. Compare `char_data[i]` with `char_data[len - 1 - i]` for all `0 <= i < len/2`.
2. **Mirror Validity Check:** Every character in the string must belong to the set of valid mirror characters: {'A', 'H', 'I', 'M', 'O', 'T', 'U', 'V', 'W', 'X', 'Y'}. These correspond to ASCII values 65, 72, 73, 77, 79, 84, 85, 86, 87, 88, 89.

**Logic:**
- Use an FSM (Start, Compare, Result).
- Since the input size is small (max 16 chars), you can implement parallel comparisons or a single comparator state iterating over indices.
- Use a combinational lookup table (case statement or logic) to verify if a character is valid.
- If any check fails (mismatch or invalid character), `result` should be 0.
- If all checks pass, `result` should be 1.
- `done` should pulse high for one cycle after the FSM completes.
- On `rst_n`, outputs should reset to 0.

**Constraints:**
- Input string length `len` is between 1 and 16.
- Input characters are uppercase ASCII (8-bit).
- Complete the operation within 32 clock cycles.
