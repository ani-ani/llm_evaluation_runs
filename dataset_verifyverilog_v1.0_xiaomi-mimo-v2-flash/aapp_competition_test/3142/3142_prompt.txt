Implement a Verilog module that counts numbers in [A, B] with digit sum S and finds the minimum such number. Use digit DP with fixed 15-digit numbers (A, B < 10^15). Input constraints: A, B, S scaled to Q8.8 fixed-point (A, B: 16-bit, S: 8-bit). Output: count (16-bit) and minimum number (32-bit). Use iterative state machine with 16 iterations for digits (0-15). Interface:

Inputs:
  clk: rising edge
  rst_n: active-low async reset
  start: 1-cycle pulse
  A[15:0]: 16-bit input A
  B[15:0]: 16-bit input B  
  S[7:0]: 8-bit target sum

Outputs:
  count[15:0]: 16-bit count of valid numbers
  min_num[31:0]: 32-bit minimum number (or 0 if none)
  done: 1-cycle pulse when valid

Timing: start->done within 256 cycles
Reset: Initialize all registers to 0, done=0, count=0, min_num=0

Algorithm:
1. Decompose A and B into 15 digit arrays (MSB first)
2. DP state: position (0-15), tight_lower, tight_upper, current_sum
3. Iterate positions 0..14, for each compute valid digits
4. Count: sum of valid completions
5. Min: track minimum valid number (largest position first)
6. Output when done=1

Implementation notes:
- Use 4-bit digit arrays for 15 digits
- Saturate digit sum at 135 (8-bit)
- Use 32-bit registers for min number accumulation
- State machine: IDLE -> DECODE -> DP_COMPUTE -> OUTPUT
