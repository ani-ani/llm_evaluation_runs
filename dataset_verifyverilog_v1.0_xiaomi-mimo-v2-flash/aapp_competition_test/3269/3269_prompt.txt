Design a Verilog module to compute the sum of distances between all pairs of numbers in an interval [A, B], where the distance between two numbers is the sum of absolute differences of their digits (with leading zeros). Scale inputs to 4-digit numbers (0-9999) to fit hardware constraints. Compute distance between two 4-digit numbers: |a3-b3| + |a2-b2| + |a1-b1| + |a0-b0|. Sum over all pairs (i,j) where A ≤ i < j ≤ B. Compute sum modulo 1000000007.

Inputs:
  clk: rising edge
  rst_n: active-low sync reset
  start: 1-cycle pulse to start computation
  A[3:0]: 4-bit digits for upper bound A (A3 = most significant)
  B[3:0]: 4-bit digits for upper bound B (B3 = most significant)
  len: 4-bit (1-4) indicating number of significant digits (0-9999 max)

Outputs:
  result: 32-bit (mod 1e9+7 fits in 32 bits)
  done: 1-cycle pulse when result is valid

Constraints:
  A ≤ B ≤ 9999 (scaled from 10^50000)
  Compute all pairs: O(N^2) with N = B-A+1 ≤ 16
  Result modulo 1000000007
  Start->done within 10,000 cycles
  Reset: done=0, result=0, min 2 cycles

Implementation approach:
  1. Convert A, B to integers (0-9999)
  2. Iterate i from A to B
  3. For each i, iterate j from i+1 to B
  4. For each pair (i,j), compute digit distance:
     - Extract digits: i3,i2,i1,i0 and j3,j2,j1,j0
     - Distance = |i3-j3| + |i2-j2| + |i1-j1| + |i0-j0|
  5. Accumulate sum modulo 1000000007
  6. Output result and assert done

Note: Since B-A+1 ≤ 16, total pairs ≤ 120. Each distance ≤ 36 (9*4), total sum ≤ 4320, well within 32-bit range before modulo.
