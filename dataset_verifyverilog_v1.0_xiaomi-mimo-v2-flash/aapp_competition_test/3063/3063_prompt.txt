Implement a Verilog module to calculate the minimum money required to pay all debts in a town where each person owes money to exactly one other person. The problem reduces to finding the sum of minimum debt amounts for each cycle in the functional graph (as each cycle needs at least one external payment equal to the minimum debt in that cycle).

### Interface Specification
**Inputs:**
- `clk`: System clock (rising edge)
- `rst_n`: Active-low synchronous reset
- `start`: 1-cycle pulse to start computation
- `N`: 4-bit integer (number of people, 2-16)
- `debt_to[15:0]`: 16x4-bit array, person `i` owes to `debt_to[i]` (0-indexed)
- `debt_amt[15:0]`: 16x16-bit array, amount `i` owes to `debt_to[i]` (0-65535)

**Outputs:**
- `result`: 16-bit output (minimum total money needed)
- `done`: 1-cycle pulse when computation finishes

**Timing:**
- Start to Done: ≤ 1024 cycles
- Reset: 2 cycles, sets all outputs to 0
- Sample `result` when `done` is high

### Implementation Guidelines
1. Treat input as functional graph: each node `i` has exactly one outgoing edge to `debt_to[i]`
2. Detect cycles using iterative DFS/Floyd's cycle detection
3. For each cycle found, find minimum debt amount in that cycle
4. Sum the minimums across all cycles
5. Use 16-bit registers for amounts, 4-bit for node IDs
6. Use state machine: IDLE, INIT, CYCLE_DETECT, COMPUTE, DONE
7. Bounded to 16 nodes, iterative (no recursion)
8. Output `result` holds value until next `start` pulse
