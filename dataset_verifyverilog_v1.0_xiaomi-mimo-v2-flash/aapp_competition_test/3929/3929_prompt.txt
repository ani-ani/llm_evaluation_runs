You are to implement a Verilog module `deque_seq` that computes the number of valid deque sequences where the K-th element eaten is 1, modulo 10^9+7, for N up to 16 and K up to 16.

**Interface:**
- Inputs:
  - `clk`: Clock, rising edge active
  - `rst_n`: Active-low synchronous reset
  - `start`: 1-cycle pulse to start computation
  - `n_in`: 5-bit unsigned input (N, 1-16)
  - `k_in`: 5-bit unsigned input (K, 1-16)
- Outputs:
  - `result`: 32-bit unsigned result (modulo 10^9+7)
  - `done`: 1-cycle pulse indicating valid result

**Implementation Details:**
- Use a combinational or sequential DP approach with bounded loops (max 16 iterations).
- Implement modulo 10^9+7 arithmetic using 32-bit additions and multiplications.
- State machine: `IDLE`, `COMPUTE`, `DONE`.
- In `COMPUTE` state, iterate i from 1 to K-1, j from 2 to N, updating DP table as per the DP recurrence: `dp[i][j] = (dp[i-1][j] + prefix_sum[N] - prefix_sum[j]) % MOD`.
- Use registers to store DP table (size K x N, 32-bit each).
- Ensure timing: start to done within 200 cycles.
- Reset: done=0, result=0, state=IDLE.
