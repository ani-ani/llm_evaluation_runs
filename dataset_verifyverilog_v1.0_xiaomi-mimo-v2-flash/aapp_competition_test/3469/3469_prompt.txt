Implement a Verilog module `gon_win_probability` that computes probability Gon wins in a coin-flipping game with patterns g and k. Input patterns g and k are strings of 'H'/'T' up to length 20, but we fix maximum length to 8 for hardware: g/k up to 8 chars, encoded as 8-bit arrays (H=0, T=1). Coin probability p is scaled as integer P = round(p*1000) (e.g., 0.5->500), to represent 0.001 precision. Use Markov chain with states = suffix length (0-8) plus a bitmask of which prefixes of g/k have been matched in the last 8 chars. Output probability as 16-bit fixed-point Q8.8 (scale 256). Compute using iterative method: precompute transition probability matrix (edges between states) via FSM matching; state transitions update suffix and match status, with absorption for g-only, k-only, both (draw). Since max 256 states (2^(8+3)=2048), but limit to 256 for 8-bit prefix masks, compute expected probability via 1000 iterations or fixed-point Gaussian elimination for small system. Module inputs: clk, rst_n, start, g_arr[7:0] (8-bit, 1-char per bit), k_arr[7:0], P (10-bit, 0-1000). Output: result[15:0] (Q8.8), done (1-cycle). Timing: compute within 10,000 cycles using O(S^2) updates where S≤256. Reset: all zero. Use 16-bit arithmetic for probabilities, clamp overflows. Handle identical patterns: if g==k, probability 0.
