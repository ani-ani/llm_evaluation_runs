Implement a Verilog module that determines if Slavko can win and his optimal word. Given N (even, 2-16) and a string of N lowercase letters. Mirko always takes the rightmost letter. Slavko can choose any remaining letter. Goal: Slavko's word should be lexicographically smallest possible, and check if it beats Mirko's word.

Interface:
- Inputs: clk, rst_n, start (1-cycle pulse)
- char_in: 8-bit ASCII (single letter per cycle, continuous input stream)
- len: 4-bit input (number of letters, even, 2-16)
- Outputs: result (8x8-bit packed array, Slavko's 8-char word), done (1-cycle pulse), win (1-bit, 1 if Slavko wins)

Behavior:
1. On start, reset internal state. Accept N letters via char_in (one per clock cycle). Store in buffer.
2. After N cycles, process: N/2 turns total (Mirko+Slavko each N/2 letters).
3. Simulation: Maintain a deque/array of remaining letters. Each turn:
   - Mirko's turn: Remove rightmost letter (append to his word).
   - Slavko's turn: Find the smallest available letter (lexicographically) in the remaining sequence and remove it (append to his word).
4. After all letters processed, compare words: Slavko wins if his word < Mirko's word alphabetically.
5. Output Slavko's word (packed into 8x8-bit result) and win flag.
6. done=1 when complete (after ~16+N/2 cycles from start).

Constraints: Max N=16, so 8 letters per player. Use 8-bit wide char storage. Implement loop with 16-cycle maximum. Use simple linear scan for minimum each turn (bounded 16*8 cycles).
