Design a Verilog module that converts a repeating decimal string to a reduced fraction (numerator/denominator). The input is provided as separate signals: a 12-bit integer representing the decimal number without the decimal point (scaled by 10^fraction_digits), a 4-bit integer for the total number of fractional digits, and a 4-bit integer for the number of repeating digits. The module should output 32-bit numerator and denominator, and a done signal. The algorithm: Let A = total fractional digits, B = repeating digits. The decimal value is X / 10^A, where X includes the repeating part. The integer value is: Let N1 = integer part * 10^A + non-repeating fractional part, N2 = repeating part. The value = N1/10^A + N2/(10^A * (10^B - 1)). Combine into single fraction: numerator = N1*(10^B - 1) + N2, denominator = 10^A * (10^B - 1). Reduce by dividing by GCD. Compute GCD iteratively. Assume A ≤ 11, B ≤ A, values fit in 32 bits (max ~2^32). Use fixed-width arithmetic (16-32 bits). Interface: Inputs: clk, rst_n, start, total_digits[3:0], repeat_digits[3:0], scaled_value[11:0] (decimal without point). Outputs: numerator[31:0], denominator[31:0], done (1-cycle pulse). Timing: start->done within 500 cycles. Reset: all outputs 0.
