Design a Verilog module to solve the circular traversal problem for determining minimum and maximum stops to return to start given constraints.

**Problem Specification:**
Given `n` (number of restaurants, 1-64) and `k` (distance between restaurants, 1-1024), and distances `a` and `b` (0-512) to nearest restaurant for start and first stop positions respectively. The circle has total circumference `C = n * k`. Sergey travels in steps of length `L` (unknown but consistent) until returning to start. We need to find min and max number of stops `x` and `y`.

**Algorithm Adaptation:**
1. The possible positions for start `s` are at distance `a` from any restaurant: `s ∈ { (i*k ± a) mod C }` for i in 0..n-1.
2. The possible positions for first stop `p` are at distance `b` from any restaurant: `p ∈ { (i*k ± b) mod C }` for i in 0..n-1.
3. The step size `L` is the distance `(p - s) mod C` (considering direction). Since Sergey returns to start, `L` must be a divisor of `C`? Actually, the condition is `m * L ≡ 0 mod C`. The number of stops is `C / gcd(C, L)`.
4. We need to iterate over all combinations of `s` and `p`, compute `L`, then `stops = C / gcd(C, L)`, and find min/max.

**Verilog Interface:**
Inputs:
  clk: rising edge
  rst_n: active-low synchronous reset
  start: 1-cycle pulse to initiate calculation
  n[5:0]: unsigned (1-64)
  k[9:0]: unsigned (1-1024)
  a[8:0]: unsigned (0-512)
  b[8:0]: unsigned (0-512)

Outputs:
  result_min[31:0]: unsigned (minimum stops)
  result_max[31:0]: unsigned (maximum stops)
  done: 1-cycle pulse when calculation complete

**Internal Logic Requirements:**
1. Pre-calculate total circumference `C = n * k` (15-bit max).
2. Use Finite State Machine (FSM) to iterate over `i` from 0 to `n-1` (max 64 iterations).
3. For each `i`, calculate 4 combinations of `(s, p)` offsets:
   - Offset types: `+a, -a` for start, `+b, -b` for stop.
   - Compute `L = (p_offset - s_offset) mod C`.
   - Compute `g = gcd(C, L)` using a sequential Euclidean algorithm (max 15 bits).
   - Compute `stops = C / g` (use division logic or lookup).
4. Accumulate min and max across all valid `L` (skip `L=0`).
5. Output `result_min` and `result_max` when `done` is asserted.

**Constraints:**
- All arithmetic on scaled integers (16-32 bit).
- Max cycles: 10,000 (for 64 iterations * GCD/Div).
- State machine must handle reset (reset min=INF, max=0).
