Implement a Verilog module that simulates antimatter droplet collisions with sensors. The module should process a fixed number of droplets (max 16) and sensors (max 16) with 8-bit coordinates.

### Interface:
- **Inputs**: 
  - `clk`, `rst_n`: Standard clock and active-low reset
  - `start`: 1-cycle pulse to begin processing
  - `d_x`, `d_y`: 8-bit arrays [0:15] representing droplet coordinates
  - `s_x1`, `s_x2`, `s_y`: 8-bit arrays [0:15] representing sensor coordinates
  - `num_droplets`: 4-bit (0-15)
  - `num_sensors`: 4-bit (0-15)
- **Outputs**:
  - `result`: 8-bit output for the y-coordinate of collision (0 if none)
  - `done`: 1-cycle pulse when result is valid

### Functionality:
For each droplet (in order 0 to 15, but only process first `num_droplets`):
1. Find all sensors that the droplet hits (sensor y < droplet y, sensor x1 <= droplet x <= sensor x2)
2. Among those, pick the sensor with the HIGHEST y-coordinate (closest to droplet)
3. If found, output that sensor's y-coordinate. Otherwise output 0.

### Constraints:
- Coordinate range: 0-255 (8-bit unsigned)
- Max 16 droplets, max 16 sensors
- Process sequentially: one droplet per 16 cycles, then done
- Use combinational logic for collision detection
- No sensors touch, no droplets start on sensors

### Timing:
- Start to done: within 256 cycles (16 droplets × 16 cycles each)
- Done pulse is exactly 1 cycle
- Result is valid only when done=1
- Reset clears all internal state
