Create a Verilog module `spanning_tree_check` that determines if a spanning tree exists with exactly `k` blue edges in a graph of up to 16 nodes.

### Interface Specification:
- **Inputs**:
  - `clk`: System clock (positive edge triggered)
  - `rst_n`: Active-low synchronous reset
  - `start`: 1-cycle pulse to initiate computation
  - `n`: 4-bit unsigned (2-16 nodes)
  - `k`: 4-bit unsigned (0-15 blue edges desired)
  - `blue_adj`: 16x16 bit matrix, where `blue_adj[i][j] = 1` if blue edge exists between node i and j (0-indexed)
  - `red_adj`: 16x16 bit matrix, where `red_adj[i][j] = 1` if red edge exists between node i and j (0-indexed)
- **Outputs**:
  - `result`: 1-bit valid output (1 if possible, 0 otherwise)
  - `done`: 1-cycle pulse indicating result is valid

### Implementation Requirements:
1. **Graph Representation**: Use 16x16 adjacency matrices for blue and red edges (packed 256-bit vectors or individual 1-bit signals).
2. **Spanning Tree Logic**: Since n ≤ 16, the solution space is bounded. Implement a state machine that:
   - Iterates through all possible blue edge combinations (max 15 edges in tree)
   - For each combination, check if it forms a spanning tree (n-1 edges, connected)
   - The state machine should explore edge selections systematically.
3. **Key Constraint**: The tree must have exactly `k` blue edges. If `k >= n` or `k < 0`, result is immediately 0.
4. **Hardware Optimization**: 
   - Use BFS/DFS connectivity check for each candidate edge set
   - Limit iterations to ≤ 256 cycles
   - Use 4-bit counters for node traversal
5. **Reset Behavior**: On reset, clear all registers, result=0, done=0
6. **Timing**: Computation must complete within 256 clock cycles after start=1

### Interface Details:
- `blue_adj` and `red_adj` are 16x16 matrices. Each row can be represented as a 16-bit vector.
- Node indices are 0-indexed in hardware (convert input 1-indexed values by subtracting 1).
- The graph is guaranteed to be connected and simple (no multi-edges).

Provide only the Verilog module implementation (no testbench code).
