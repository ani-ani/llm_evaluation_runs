Design a Verilog module that counts the number of connected components (stellar bodies) in a blurred image. The image is provided as a grid of 16x16 pixels (R=16, C=16), where each pixel is an 8-bit grayscale value (0-255). A pixel is considered part of a star if its value is above a threshold (e.g., 128). The input grid is stored in a flattened array 'img_in' of 256 elements (8-bit each). The module should perform 4-connected component labeling (up, down, left, right) and output the count of distinct components as an 8-bit result. 

Inputs:
  clk: clock (rising edge)
  rst_n: active-low synchronous reset
  start: 1-cycle pulse to start processing
  img_in[255:0]: flattened 256x8-bit array input

Outputs:
  result: 8-bit count of connected components
  done: 1-cycle pulse when processing is complete

Behavior:
  - On reset: done=0, result=0, internal state reset
  - On start: begin processing the 16x16 grid
  - Threshold: any pixel value > 128 is considered 'on'
  - Algorithm: Use iterative scanning and union-find logic to label 4-connected regions
  - Processing must complete within 10000 clock cycles
  - Output result valid only when done=1

Constraints:
  - 16x16 grid size is fixed
  - 8-bit pixel width
  - 8-bit result width (supports up to 255 components)
  - Maximum 10000 cycles for completion
  - Use bounded loops (max 256 iterations per phase)
