Design a Verilog module to solve the wheel rotation problem with constraints: strings have length N (2 ≤ N ≤ 8, scaled from 5000), wheels are strings of 'A','B','C' encoded as 2-bit values (0=A,1=B,2=C). You may rotate each wheel left/right by 1 position (circular). Goal: find minimum rotations so each column has distinct letters (3 different), or return -1 if impossible. Interface:

Inputs:
- clk: clock signal
- rst_n: active-low reset
- start: 1-cycle pulse to start computation
- wheel0[0:7][1:0]: 8x2-bit array for first wheel
- wheel1[0:7][1:0]: 8x2-bit array for second wheel  
- wheel2[0:7][1:0]: 8x2-bit array for third wheel
- length: 3-bit input (actual string length, 2-8)

Outputs:
- result: 4-bit output (minimum rotations, -1 encoded as 15)
- done: 1-cycle high when computation complete

Algorithm: Brute-force all possible rotations. For each wheel, try 0 to N-1 left rotations (or right, equivalent). For each combination, check if all columns have distinct letters (values differ). Compute total rotations = sum of absolute rotation amounts (each rotation = 1 step). Find minimum. Output -1 (15) if no valid configuration.

Timing: Within 256 cycles after start. Reset: result=0, done=0, state=0. Use sequential logic with FSM.
