Design a Verilog module that determines if two sequences of statues (represented as integer arrays) on a cycle of islands are rearrangable via sliding moves. The input arrays include a 0 representing an empty pedestal.

**Core Logic (Adapted for Hardware):**
1.  **Input Handling**: Receive two arrays of size `N` (fixed at 16 elements). Each element is 8 bits wide (statues 0-255). The value 0 represents the empty pedestal.
2.  **Preprocessing**: Extract the non-zero elements from both arrays into temporary buffers `seq_A` and `seq_B` (max length 15). If the number of non-zero elements differs, the answer is impossible.
3.  **Rotation Check**: To check if `seq_A` is a rotation of `seq_B`:
    *   Find the index in `seq_B` where `seq_A[0]` is located.
    *   Shift `seq_B` cyclically so that `seq_A[0]` is at the start.
    *   Compare the shifted `seq_B` with `seq_A` element by element.
4.  **Bounded Iterations**: Since `N` is capped at 16, a simple iterative FSM (Finite State Machine) is sufficient. The FSM will handle extraction and comparison in a fixed number of clock cycles (max 256).

**Interface Specification:**
- **Inputs**:
  - `clk`, `rst_n`: Standard synchronous control.
  - `start`: 1-cycle pulse to initiate the operation.
  - `arr_in_0` to `arr_in_15`: 16 parallel 8-bit inputs for the current configuration.
  - `arr_tgt_0` to `arr_tgt_15`: 16 parallel 8-bit inputs for the target configuration.
- **Outputs**:
  - `result`: 1-bit output. 1 if YES (rearrangement possible), 0 if NO.
  - `done`: 1-cycle pulse indicating valid result.

**Implementation Constraints**:
- Use a Fixed-Point approach where integers are treated as raw bit values.
- Implement a Moore/Mealy FSM with states: IDLE, EXTRACT_A, EXTRACT_B, FIND_IDX, COMPARE, and FINISH.
- Loop bounds are strictly defined by `N=16`.
- Output `result` must be held stable until the next start.
