Implement a Verilog module that determines if two consecutive months in a non-leap year can start on two specific days of the week.

**Input Format:**
Two 3-bit inputs representing days of the week (Monday=0, Tuesday=1, Wednesday=2, Thursday=3, Friday=4, Saturday=5, Sunday=6).

**Logic:**
The lengths of non-leap year months modulo 7 are: Jan(31)=3, Feb(28)=0, Mar(31)=3, Apr(30)=2, May(31)=3, Jun(30)=2, Jul(31)=3, Aug(31)=3, Sep(30)=2, Oct(31)=3, Nov(30)=2.
For consecutive months M and M+1, if M starts on day `d1`, M+1 starts on day `(d1 + days_in_M % 7) % 7`.
Valid offsets between starting days are {0, 2, 3}.

**Module Interface:**
- Inputs: `day1` (3-bit), `day2` (3-bit)
- Output: `possible` (1-bit)

**Operation:**
1. Calculate difference: `diff = (day2 - day1) % 7`.
2. Set `possible = 1` if `diff` is 0, 2, or 3. Otherwise 0.

**Constraints:**
- Use combinational logic.
- Handle unsigned arithmetic correctly.
- No clock or reset needed.
