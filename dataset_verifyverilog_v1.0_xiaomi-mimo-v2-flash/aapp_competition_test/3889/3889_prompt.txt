Design a Verilog module that checks if a string of characters contains at least one character that appears 2 or more times.

The input string contains lowercase Latin letters ('a'-'z'). The problem asks: can all puppies be recolored to one color? The answer is 'Yes' if there is at least one character with frequency >= 2, or if n == 1.

Module Specification:
- Inputs: clk (pos-edge), rst_n (active-low), start (1-cycle pulse)
- Input data: s_0 to s_15 (16 wires, each 8-bit ASCII code). Only the first 'len' characters are valid, the rest should be ignored.
- Input: len (4-bit integer, range 1-16) indicating the number of valid characters.
- Outputs: result (1-bit, 1 for Yes, 0 for No), done (1-cycle pulse when valid)

Implementation Requirements:
1. Use a 26-element array to store counts of each character ('a' = 0, ..., 'z' = 25).
2. On start, reset the counts and a counter for the current character index (0 to len-1).
3. For each valid character s_i, increment the corresponding count in the array.
4. After processing all characters, check if any count in the array is >= 2.
5. Also check if len == 1, in which case result should be 1.
6. Output result and done signals.
7. Timing: start->done should be within 200 cycles.
8. Reset: done=0, result=0, all counters zero.

Interface:
- 26x4-bit array 'counts' (internal)
- 4-bit index 'i' for processing
- 8-bit registered input buffer for s_i
- FSM states: IDLE, PROCESSING, CHECKING, DONE

Testbench must handle: 1-16 characters, random strings, edge cases (n=1, all unique, duplicates).
