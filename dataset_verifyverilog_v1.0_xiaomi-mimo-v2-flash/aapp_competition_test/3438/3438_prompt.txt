Implement a hardware module that computes the minimum number of cache misses (object reads) for the optimal caching algorithm given perfect future knowledge. Scale constraints: cache_size ≤ 4, num_objects ≤ 16, num_accesses ≤ 16. Use fixed-size arrays. 

Interface Specification:
Inputs:
  clk: rising edge clock
  rst_n: active-low synchronous reset (minimum 2 cycles)
  start: 1-cycle pulse to begin computation
  cache_size[3:0]: number of objects that fit in cache (1-4)
  num_objects[4:0]: total objects in system (≤16)
  num_accesses[4:0]: number of accesses to process (≤16)
  access_seq[15:0][4:0]: array of 16 accesses, each 5-bit object ID
Outputs:
  result[4:0]: minimum cache misses count (0-16)
  done: 1-cycle pulse indicating valid result

Behavior:
- When start=1, load inputs and begin computation
- Implement Belady's optimal algorithm: For each cache miss, choose to evict the object whose next use is farthest in the future
- Use lookahead: for each access position, find next occurrence of each cached object
- Finite state machine: IDLE → LOAD → COMPUTE → DONE
- For each access: check if object in cache; if yes (hit) - continue; if no (miss) - increment miss counter and update cache
- For eviction decision: examine future accesses to determine next use of each cached object
- All arrays must be individual wires/reg arrays, not packed
- Clock domain: single clock, synchronous design
- Timing: from start=1 to done=1 should complete within 1000 clock cycles

Important constraints:
- Use bounded loops (max 16 iterations for accesses)
- Use lookup tables for next-use tracking
- Cache represented as 4x5-bit array (stores object IDs)
- Future access position stored as 5-bit value (0-31)
- Do not use dynamic memory - all sizes fixed
- Reset: all outputs 0, done=0, internal state cleared

Provide Verilog module specification only, no implementation code.
