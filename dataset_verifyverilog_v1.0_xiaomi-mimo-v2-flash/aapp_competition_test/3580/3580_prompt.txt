Implement a Verilog module that processes a query to find the longest consecutive subsequence starting at a given index with elements from a subset. 

## Specifications

**Interface:**
- Inputs: `clk` (1-bit), `rst_n` (1-bit), `start` (1-bit, single-cycle pulse)
- Configuration (set before `start`):
  - `a_len` (8-bit, n ≤ 16)
  - `q_idx` (8-bit, query index to process, 0-based)
  - `query_i` (8-bit, start index, 1-based → convert to 0-based internally)
  - `query_m` (4-bit, subset size ≤ 16)
- Data inputs (assign before `start`):
  - `arr_a[0:15]` (16x8-bit array): sequence elements
  - `arr_b[0:15]` (16x8-bit array): subset elements for current query
- Outputs:
  - `result` (8-bit): longest consecutive length (0 to 15)
  - `done` (1-bit): pulses high for 1 cycle when calculation completes

**Behavior:**
1. On `start` pulse, assert `done` and `result` become valid within ≤100 cycles.
2. Starting from `query_i` (convert to 0-based index), iterate through `arr_a` sequentially.
3. For each position `pos`, check if `arr_a[pos]` exists in `arr_b`.
4. Continue until first mismatch or end of array (len = `a_len`).
5. Output length of matched prefix.

**Implementation Notes:**
- Use sequential logic with a finite state machine (FSM).
- Max array size = 16, max subset size = 16.
- All values fit in 8 bits.
- At start: `done` = 0, `result` = 0.
- Reset: clears internal state.
- Use 2 internal counters: current position, iteration counter for subset matching.
- For subset matching: use parallel comparators or sequential scan (max 16 cycles).

**Timing:**
- Reset: 2 cycles minimum, `done` = 0, `result` = 0.
- After `start`, `done` pulses high after calculation.
- Sample `result` when `done` = 1.

**Key constraints:**
- `a_len` ≤ 16, `query_i` ≤ `a_len`.
- `query_m` ≤ 16.
- Sum of all queries' m ≤ 105, but we process one query per instance.
- Values: 8-bit unsigned integers (0-255).
