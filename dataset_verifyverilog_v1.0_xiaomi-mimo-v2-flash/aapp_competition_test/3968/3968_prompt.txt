Create a Verilog module for virus spread simulation using fixed-point times and bit vectors. Constraint: N <= 16 (node count), D <= 50 (days). Scales: s_i, t_i (0-10^9) mapped to Q16.16 fixed-point (16.16 bits). Contact logic: two nodes i,j infected if time intervals [s_i, t_i] and [s_j, t_j] overlap (including boundaries). Infection propagation is BFS-like: on each day, uninfected nodes in contact with any infected node become infected next day.

Interface:
Inputs:
  clk: rising edge
  rst_n: active-low synchronous reset
  start: 1-cycle pulse to start simulation
  N: 4-bit (1-16), number of people
  D: 6-bit (1-50), number of days
  initial_infected_count: 4-bit (1-16)
  initial_infected_idx[15:0]: 16-bit mask where bit i=1 means person i+1 is initially infected (1-indexed)
  s_arr[15:0]: 16x32-bit array, entry times (Q16.16)
  t_arr[15:0]: 16x32-bit array, exit times (Q16.16)

Outputs:
  result_mask: 16-bit, bit i=1 if person i+1 is infected after D days
  done: 1-cycle pulse when simulation completes
  busy: high while processing

Timing:
  start -> done within 2000 cycles (max 16*16*D comparisons)
  Result valid when done=1

Reset:
  result_mask = 0, done = 0, busy = 0

Algorithm Spec (simplified HW):
1. Input stage: Store s/t arrays (Q16.16) in 16x32-bit RAMs
2. Contact Graph: For N nodes, compute overlap matrix M[N][N] where M[i][j]=1 if intervals overlap
   - Overlap logic: !(t_i < s_j || t_j < s_i) (unsigned compare)
   - Use 16-bit comparators (scaled Q16.16)
3. Simulation: Maintain infected_mask (16-bit)
   - Initialize infected_mask = initial_infected_idx (mask)
   - Loop D times:
     - Compute new_infected = 0
     - For each node j (0 to N-1) not in infected_mask:
       - For each node i in infected_mask:
         - If M[i][j]==1: set bit j in new_infected
     - infected_mask = infected_mask | new_infected
4. Output: result_mask = infected_mask

Constraints:
- N <= 16, D <= 50 -> max iterations 50*16*16 = 12800
- Time values: Q16.16 (32-bit total, 16 integer, 16 fraction)
- Use comparators for interval overlap (s_i <= t_j and s_j <= t_i)
- No random number generation
- All operations combinational or sequential with bounded loops
