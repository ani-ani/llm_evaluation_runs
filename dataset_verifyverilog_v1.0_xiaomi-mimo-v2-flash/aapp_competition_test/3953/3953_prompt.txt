Implement a Verilog module that solves the 'Purification' puzzle. The goal is to select cells to cast spells such that all cells in the grid are purified. If impossible, output -1.

You must support n up to 8 (scaled from 100). The input grid is a fixed 8x8 array of 1-bit flags (0='.', 1='E').

**Logic Rules:**
1. If every row contains at least one '.' (safe cell), the optimal solution is to pick one '.' from each row. Output n pairs (row, col).
2. Else if every column contains at least one '.' (safe cell), the optimal solution is to pick one '.' from each column. Output n pairs (row, col).
3. Otherwise (there exists a row full of E AND a column full of E), output a single -1.

**Interface:**
Inputs:
  - clk, rst_n: Standard clock and active-low reset.
  - start: 1-cycle pulse to begin processing.
  - grid[0:7][0:7]: 64-bit input matrix. Bit 0 is row 0 col 0. (Bit indexing: row-major, flat array).
  - n: 4-bit integer representing the grid size (1-8).

Outputs:
  - out_row, out_col: 4-bit integers (valid when out_valid=1).
  - out_valid: 1-bit flag indicating output is valid.
  - done: 1-cycle pulse set at the end of operation. If impossible, done=1 and out_valid=0.
  - impossible: 1-bit flag, asserted if result is -1.

**Timing:**
- Operation must complete within 256 clock cycles.
- Outputs are streamed (1 cycle per pair) for valid solutions.

**Module Definition:**
module purification_sol (
    input wire clk,
    input wire rst_n,
    input wire start,
    input wire [63:0] grid,
    input wire [3:0] n,
    output reg [3:0] out_row,
    output reg [3:0] out_col,
    output reg out_valid,
    output reg done,
    output reg impossible
);
