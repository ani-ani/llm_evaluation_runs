Implement a Verilog module that counts the number of distinct GCD values over all contiguous subarrays of a given sequence.

Problem Constraints:
- n (sequence length) <= 16
- Sequence values <= 255 (8-bit unsigned)
- GCD result fits in 8 bits (since inputs are 8-bit)
- Clock frequency: 100 MHz

Module Interface:
- Inputs:
  - clk: System clock (rising edge)
  - rst_n: Active-low synchronous reset
  - start: Start signal (1-cycle pulse)
  - arr: Array of 16 8-bit integers (arr_0 to arr_15). Valid entries: arr_0 through arr_(n-1).
  - len: 4-bit integer (1-16), length of the sequence

- Outputs:
  - result: 8-bit integer, count of distinct GCD values
  - done: 1-cycle pulse when computation is complete

Timing:
- Start pulse initiates the computation
- Computation completes within 1000 clock cycles
- Result is valid when done is high
- Reset (rst_n=0) clears result to 0 and done to 0

Algorithm (Iterative):
1. Initialize distinct_count = 0, gcd_set = empty (implemented as a bit vector of size 256)
2. For each starting index i from 0 to n-1:
   a. current_gcd = 0
   b. For each ending index j from i to n-1:
      i. current_gcd = gcd(current_gcd, arr[j])
      ii. Mark current_gcd in gcd_set
3. Count marked bits in gcd_set to get distinct_count

Implementation Details:
- Use a 256-bit vector as a lookup table for distinct GCDs (bit set if that value has been seen)
- Implement GCD using an iterative Euclidean algorithm or a pre-computed LUT for 8-bit numbers
- Use nested loops with bounded counters (0-15)
- State machine states: IDLE, CALCULATING, COUNTING, DONE

Notes:
- Since n <= 16 and values <= 255, the maximum distinct GCD count is 256.
- The GCD of 0 and x is x. Initialize current_gcd to 0.
- Use blocking assignments for state logic, non-blocking for outputs.
