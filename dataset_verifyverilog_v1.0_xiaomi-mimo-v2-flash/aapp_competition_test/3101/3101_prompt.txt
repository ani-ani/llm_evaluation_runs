Implement a Verilog module that determines if a sorted array of 8-bit unsigned integers can be made unsorted by changing exactly one digit of one number, where digits are decimal positions. Simplified interpretation: For each number, try changing its least significant decimal digit to any other digit (0-9), avoiding leading zeros. Check if the array becomes unsorted (i.e., b[i] > b[i+1] for some i). Return the first valid modification found.

Inputs:
  clk: rising edge | rst_n: active-low sync reset
  start: 1-cycle pulse initiating computation
  arr[0:7]: 8x8-bit array of sorted integers (0-255)
  n: 4-bit count (2-8)
Outputs:
  result_arr[0:7]: 8x8-bit output array (modified or original)
  valid: 1-bit flag (1 if solution found)
  done: 1-cycle pulse when computation complete

Implementation Notes:
- For each position i (0 to n-1), extract the number arr[i]
- For each possible digit change of the LSB decimal digit (0-9):
  - Compute new_val by replacing the decimal ones place
  - Ensure no leading zero issue (ignore since we're modifying single digit within width)
  - Create candidate array with this change
  - Check if candidate array is NOT sorted (i.e., candidate[j] > candidate[j+1] for some j)
  - If unsorted, set result_arr to candidate and valid=1
- If no modification works, valid=0, result_arr unchanged
- Process requires bounded loops: 8 positions × 10 digit changes × 7 comparisons = 560 operations
- All within 100 cycles

Timing: start->done within 100 cycles, sample result when done=1
Reset: done=0, valid=0, result_arr=0, min 2 cycles
