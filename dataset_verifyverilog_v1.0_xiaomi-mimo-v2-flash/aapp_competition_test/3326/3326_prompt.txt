Implement a Verilog module that counts monotonic subgrids for a fixed 3x3 grid (hardcoded). Each cell contains a 4-bit value (1-9). The module must iterate over all 63 non-empty subsets of rows (0-2) and columns (0-2), construct the subgrid, check if each row/column in the subgrid is monotonic (strictly increasing or decreasing), and count valid subgrids.

Interface:
- Inputs: clk (clock), rst_n (active-low reset), start (1-cycle pulse)
- Outputs: result (8-bit count), done (1-cycle when finished, sample result here)
- Internal: Hardcoded 3x3 grid with 4-bit values from example

Implementation details:
1. State machine with states: IDLE, INIT, CHECK_SUBGRID, COUNT, FINISH
2. Use bit masks for row/col subsets: iterate 1 to 63 for each
3. For each subgrid, extract values to temporary array (max 3x3=9 elements)
4. Check monotonicity: For each row/column in subgrid, verify strictly increasing OR strictly decreasing
5. Count valid subgrids in 8-bit register
6. Timing: start->done within 256 cycles
7. Reset: done=0, result=0, minimum 2 cycles

Hardcoded grid values (row-major, 4-bit each):
Row0: 1, 2, 5
Row1: 7, 6, 4
Row2: 9, 8, 3

The module should use combinational logic for monotonicity checking and sequential logic for iterating subsets.
