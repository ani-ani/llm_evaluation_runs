Design a Verilog module for ski slalom speed selection. Constraints: W, vh up to 10^8 (scale to 32-bit), N<=16 gates, S<=32 skis, gate coordinates y_i up to 10^8 (scale to 32-bit), x_i up to 10^8. Use Q16.16 fixed-point for distance/speed calculations. Input: W[31:0], vh[31:0], gate_x[0:15][31:0], gate_y[0:15][31:0], N[4:0], skis[0:31][31:0], S[5:0]. Output: best_speed[31:0], valid (1-bit). Operation: On start signal, iterate through each ski speed s_j (1..1e6), for each ski check feasibility through all N gates: starting position unconstrained, vertical distance delta_y = y_i - y_{i-1}, time = delta_y / s_j, max horizontal movement = vh * time, check if gate interval [x_i, x_i+W] intersects reachable interval from previous position. Use fixed-point division (Q16.16). If feasible, track minimal s_j. Reset: clear best_speed, valid=0. Done: valid=1 when complete, best_speed=0 if impossible. Use state machine: IDLE -> CHECK_SKI -> CHECK_GATE -> UPDATE_BEST -> DONE. Max 256 cycles.
