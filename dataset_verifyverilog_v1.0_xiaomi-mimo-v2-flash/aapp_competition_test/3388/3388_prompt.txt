Design a Verilog module that simulates Julia's betting strategy for up to 16 players and 256 matches to find the guaranteed lead duration. Inputs are Julia's score (32-bit) and 15 other player scores (32-bit each). The module should simulate matches sequentially: in each cycle, it identifies the max score among other players, determines the majority bet, updates scores (with worst-case outcome where Julia loses), and checks if Julia is still in lead (Julia's score >= all others). It should stop when lead is lost or max matches reached. Output the count of matches where lead was guaranteed (up to 255).

Interface:
- Inputs: clk (posedge), rst_n (active-low), start (1-cycle pulse), julia_score [31:0], other_scores [14:0][31:0]
- Outputs: result [7:0] (match count), done (1-cycle high when finished)
- Timing: start triggers simulation, done within 256 cycles. Reset initializes to 0.
- Constraints: Clock period 10ns. Implementation: Use FSM to track state, score registers, and match counter. Worst-case: assume others bet optimally against Julia (majority loses). Fixed-point not needed, 32-bit integers sufficient.
