Implement a Verilog module that computes the maximum number of students Frank can take on an excursion.

**Problem Analysis:**
- Input: N students (1 ≤ N ≤ 16) with attributes: height (0-300), sex (M/F), music style (encoded 0-7), sport (encoded 0-7).
- Rule: Two students cannot both be selected if they are a potential couple. A potential couple violates ALL 4 conditions: height diff ≤ 40cm, opposite sex, same music, different sport.
- This is an Independent Set problem. Convert to Maximum Bipartite Matching: Split students into Male (left) and Female (right) sets. For each Male-Female pair, if they violate rules (i.e., they CAN be a couple), add an edge. Max Independent Set = N - Max Matching.

**Module Interface:**
- Inputs: `clk`, `rst_n` (active-low sync reset), `start` (1-cycle pulse)
- Parameters: `MAX_N = 16`, `CLK_DELAY = 200` cycles
- Data Inputs (Sampled when `start=1`):
  - `h[0:MAX_N-1]` : 9-bit heights (0-511)
  - `sex[0:MAX_N-1]` : 1-bit (0=M, 1=F)
  - `music[0:MAX_N-1]` : 3-bit music style code
  - `sport[0:MAX_N-1]` : 3-bit sport code
- Outputs:
  - `result[7:0]` : Maximum eligible students (0-16)
  - `done` : 1-cycle pulse when result is valid

**Implementation Steps:**
1. **Edge Construction:** When `start=1`, store inputs into internal registers.
2. **Bipartite Matching:** Iterate through all Male-Female pairs (M=0..N-1, F=0..N-1).
   - Check 4 conditions:
     a. `abs(h[M] - h[F]) > 40` -> No couple (Good)
     b. `sex[M] == sex[F]` -> No couple (Impossible in bipartite, skip)
     c. `music[M] != music[F]` -> No couple (Good)
     d. `sport[M] == sport[F]` -> No couple (Good)
   - If ALL 4 are false (i.e., `abs(h)<=40`, `sex diff`, `music same`, `sport diff`), they CAN be a couple. Add edge (M, F).
3. **Hungarian/DFS Matching:** Implement a simple DFS-based augmenting path algorithm for maximum matching. Since N ≤ 16, a naive O(N^3) approach is acceptable.
   - Maintain `matchL[0:N-1]` and `matchR[0:N-1]` arrays initialized to -1.
   - For each male `u`, try to find an augmenting path to an unmatched female.
4. **Result Calculation:** 
   - `MaxMatching` = count of matched pairs.
   - `result` = `N - MaxMatching`.
5. **Control Logic:** Use a finite state machine (FSM) with states: IDLE, BUILD_EDGES, MATCHING, CALCULATE, DONE.
   - IDLE: Wait for start.
   - BUILD_EDGES: Populate adjacency matrix (16x16 bits).
   - MATCHING: Run matching algorithm for all males.
   - CALCULATE: Compute N - matching_count.
   - DONE: Assert `done` and hold result.

**Timing Constraints:**
- Reset: 2 cycles, sets `done=0`, `result=0`.
- Operation: Start to Done within 500 cycles.
- Ensure all combinational logic paths are bounded by `CLK_DELAY`.
