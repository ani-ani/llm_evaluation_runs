Implement a Verilog module that finds the maximum and minimum reachable vertex count from source 's' in a mixed graph (directed + undirected edges) by orienting undirected edges. Constraints: n (vertices) <= 16, m (edges) <= 16. Use a fixed-size adjacency matrix representation. The module must perform a BFS/DFS traversal for two passes: one maximizing reach (including traversal via undirected edges in any direction) and one minimizing reach (including only directed edges or orienting undirected edges away from 's'). Output the maximum reach count, the orientation string for max reach, the minimum reach count, and the orientation string for min reach. Use a clocked state machine to sequence the computations.

Inputs:
  clk: System clock (50MHz)
  rst_n: Active-low synchronous reset
  start: 1-cycle pulse to start processing
  n_in: 4-bit integer (1-16)
  m_in: 4-bit integer (1-16)
  s_in: 4-bit integer (1-16)
  edge_type[15:0]: 16-bit vector, bit i indicates type of i-th edge (1=directed, 2=undirected)
  edge_u[15:0]: 16 x 4-bit vector for edge source vertices
  edge_v[15:0]: 16 x 4-bit vector for edge target vertices

Outputs:
  max_reach: 5-bit count
  min_reach: 5-bit count
  max_orient[15:0]: 16-bit orientation string (1=+, 0=-)
  min_orient[15:0]: 16-bit orientation string (1=+, 0=-)
  done: 1-cycle high when computation complete

Behavior:
  1. Reset: done=0, outputs zero.
  2. Wait for start. On start, latch inputs.
  3. Pass 1 (Max): Initialize visited bits to 0. BFS/DFS from s. For each undirected edge traversed, set orientation to allow forward traversal (assign '+'). Count visited nodes.
  4. Pass 2 (Min): Initialize visited bits. BFS/DFS from s. For undirected edges, only traverse if oriented away from s (set orientation accordingly). Count visited nodes.
  5. Output results and assert done.

Timing: Done should be asserted within 1024 clock cycles after start.
