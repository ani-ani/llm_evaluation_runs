Given constraints: N ≤ 5000 points, coordinates in [-1000.0, 1000.0] with 6 decimal digits. Scale coordinates to fixed-point Q16.16 (32-bit signed: 16 integer bits, 16 fractional bits). Maximum magnitude ~1000 × 65536 ≈ 65.5 million, which fits in 26 bits; use 32-bit signed arithmetic. For the MEC computation, use a bounded iterative algorithm (e.g., 100 iterations) that converges to the minimum circle radius by trying candidate diameters from projected point pairs. Since N=5000, O(N^2) is too large for 100 cycles; instead, use a fixed set of candidate circles derived from the convex hull (approximate with 32 points max) or random sampling (8 points). For each axis, compute the MEC radius over projected points, then compute diameter = 2 × radius. Finally, take the minimum diameter across the three axes.

Compute MEC radius via iterative approximation: maintain current best radius, test if all points fit within radius r from some center (cx, cy). Clamp all values to 32-bit signed. The final output diameter is the minimum of the three diameters.
