Implement a Verilog module for the chocolate box problem with constraints: n ≤ 16 boxes, each a_i ≤ 255 (8-bit). Goal: Find minimum moves (adjacent swaps) to make all box counts divisible by some k > 1 (divisor of total sum S). If S = 0 or no valid k, output -1. Algorithm: 1. Calculate total sum S. 2. Find all prime factors of S (limit 8 factors). 3. For each divisor k > 1, compute min moves: Iterate through boxes, maintain remainder r = (current_count + accumulated_previous) % k. Cost for current box: if r <= k/2, move r pieces left (cost r); else move (k - r) pieces right (cost k - r). Accumulate cost. 4. Find min cost across divisors. Output -1 if impossible (e.g., S=0 or S=1).

Interface:
- Inputs: clk, rst_n, start (1-cycle pulse)
- Inputs: arr[0:15] (16x8-bit array), len (4-bit, 1-16)
- Outputs: result (16-bit signed for cost, -1 for impossible), done (1-cycle when valid)
- Timing: start->done within 200 cycles

Implementation details:
- Use 16x8-bit BRAM for input array.
- Sum calculation: 24-bit accumulator (max 16*255=4080 fits 12-bit, but use 24 for safety).
- Prime factor extraction: Iterative trial division up to sqrt(sum). Max 8 factors.
- Per divisor cost: Iterate i from 0 to len-1. Maintain running remainder (mod k). Cost calculation uses comparison with k/2.
- Min cost: Keep track of global minimum.
- If total sum is 0 or 1, result is -1 immediately.
- Output -1 if no divisors > 1 found.
