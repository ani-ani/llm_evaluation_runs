Design a Verilog module that determines if two strings are equivalent under the following definition: Strings a and b are equivalent if (1) they are identical, or (2) their lengths are even, and splitting them into halves (a1,a2) and (b1,b2) results in either (a1 equiv b1 AND a2 equiv b2) OR (a1 equiv b2 AND a2 equiv b1).

Adaptation: Since unbounded recursion is not hardware-friendly, assume the input length N is a power of 2 (e.g., 8, 16) and fits within a small lookup table (max 16 chars). The implementation should use an iterative bottom-up approach similar to the sorting network method: compare string segments of increasing size (1, 2, 4, 8, ... up to N). For each segment size, the module should perform a sort (lexicographically) of the two halves of the segment, but specifically for the equivalence check, we compare the canonical form of the strings. 

Simplification: We will compute the canonical representation (smallest lexicographical form) of the input strings using a sorting network logic. If the canonical representations are equal, the strings are equivalent.

Interface Specification:
- Inputs:
  - clk: System clock
  - rst_n: Active-low synchronous reset
  - start: 1-cycle start signal
  - str_a[0:15]: 16x8-bit input string (ASCII), stored as 16 separate 8-bit inputs or packed into a 128-bit bus (specify as 16 individual inputs `str_a_0`...`str_a_15`)
  - str_b[0:15]: 16x8-bit input string
- Outputs:
  - is_equivalent: 1-bit result (1=YES, 0=NO)
  - done: 1-cycle signal indicating calculation is complete

- Constraints:
  - String length N is fixed at 16 characters (power of 2).
  - Implementation must use combinational logic or a fixed-state FSM for the sorting/conparison network (depth log2(N) = 4 stages).
  - Total cycles from start to done: < 50.
  - The logic should first normalize the strings: for each block size doubling, compare the left and right halves; if left > right, swap them logically (without physically moving data, just by selection logic). The final sorted configuration determines equivalence.
