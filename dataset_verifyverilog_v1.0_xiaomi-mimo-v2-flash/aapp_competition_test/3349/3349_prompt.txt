Design a Verilog module to reconstruct a sentence from a no-vowels message using a dictionary. The module must select the reconstruction with the largest total vowel count.

**Input Constraints:**
- Dictionary: 1 to 16 words.
- Word Length: 1 to 16 uppercase letters.
- Message: 1 to 64 uppercase consonants.
- Data Width: 8 bits per character (ASCII).

**Interface:**
- `clk`: System clock (rising edge).
- `rst_n`: Active-low synchronous reset.
- `start`: 1-cycle pulse to start processing.
- `msg_len`: 6-bit input (message length 1-64).
- `word_count`: 4-bit input (dictionary size 1-16).
- `msg_char[0:63]`: 64x8-bit input array (the message).
- `dict_word[i].char[0:15]`: 16x16x8-bit input array (dictionary words). Each word has up to 16 chars.
- `dict_word[i].len`: 16x4-bit input array (lengths of dictionary words).
- `dict_word[i].vowels`: 16x6-bit input array (vowel counts for each dictionary word).
- `result_word_idx[0:15]`: 16x4-bit output array (indices of words in the solution).
- `result_len`: 4-bit output (number of words in solution).
- `done`: 1-cycle pulse when processing is complete.
- `valid`: Output valid flag (1 if a valid solution exists).

**Functional Specification:**
1.  **Reset:** When `rst_n` is low, outputs `result_len`, `valid`, and `done` must be 0.
2.  **Processing:** On `start` pulse, begin processing. The module must identify a sequence of dictionary words such that their concatenated consonant strings equal the input `msg_char`.
3.  **Optimization:** Among all valid sequences, choose the one with the maximum sum of `dict_word[i].vowels`. Ties may be broken arbitrarily.
4.  **Output:** When finished, assert `done` for 1 cycle. `result_len` contains the number of words used. `result_word_idx[0..result_len-1]` contains the indices (0-based) of the selected words. `valid` should be 1 if a solution is found (guaranteed by problem statement).
5.  **Timing:** Processing must complete within 2048 clock cycles.

**Implementation Notes:**
- Use a lookup table or iterative matching for dictionary words.
- Since the message length is limited to 64 and words to 16, a brute-force search with pruning or dynamic programming is feasible in hardware.
- You must implement the vowel counting logic to compare candidate solutions.
