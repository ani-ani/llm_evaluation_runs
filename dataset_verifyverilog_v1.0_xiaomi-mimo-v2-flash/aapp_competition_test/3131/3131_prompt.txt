Design a Verilog module that calculates the sum of maximum values across all combinations of K keys from N keys, modulo 1000000007.

**Module Interface:**
- Inputs:
  - `clk`: Clock signal (rising edge triggered)
  - `rst_n`: Active-low synchronous reset
  - `start`: 1-cycle start pulse
  - `arr[0:7]`: 8x8-bit array of key values (N≤8)
  - `k_select`: 3-bit select for K (K≤3)
- Outputs:
  - `result`: 32-bit output sum modulo 1000000007
  - `done`: 1-cycle pulse indicating completion

**Functionality:**
1. On `start` pulse, capture input array `arr` and K value from `k_select`
2. Generate all C(N,K) combinations of K keys
3. For each combination, find the maximum key value
4. Sum all maximum values across all combinations
5. Output result modulo 1000000007
6. Set `done=1` for one cycle when calculation completes

**Constraints:**
- N is limited to 8 (bits [2:0] from input array size)
- K is limited to 3 (bits [2:0] from k_select)
- Key values are 8-bit unsigned (0-255)
- Total combinations: C(8,3)=56 maximum
- Result is 32-bit unsigned, modulo 1000000007 (0x3B9ACA07)
- Timing: `start` to `done` within 256 cycles maximum

**Implementation Guidance:**
- Use combinational logic or FSM for combination generation
- Implement a sorting network or comparator tree to find maximum in each combination
- Use binary representation for combination generation (loop through all bit patterns with K bits set)
- Accumulate sum with modulo operation after each addition
- Reset behavior: `done=0`, `result=0`, accumulator=0, state=IDLE

**Hardware Considerations:**
- Fixed-size arrays: `arr[0]` through `arr[7]` are separate signals
- Combinational logic may be preferred for small N and K
- Sequential implementation can use state machine with up to 56 states
- Ensure no overflow in intermediate calculations (use 32-bit for accumulation)

**Edge Cases:**
- K=0 or K>N: Should handle gracefully (return 0)
- All values zero: Return 0
- Duplicate values: Count each occurrence separately
- Maximum values: 0xFFFFFFFF modulo 0x3B9ACA07

**Testbench Expectations:**
The testbench will:
- Provide input values on `arr[0:7]` and `k_select`
- Assert `start` for one clock cycle
- Wait for `done` signal with timeout
- Read `result` when `done` is high
- Verify against expected sum

**Example:**
For N=5, K=3, arr=[2,4,2,3,4]:
- Combinations: (0,1,2)->max=4, (0,1,3)->max=4, (0,1,4)->max=4, etc.
- Sum of max values = 39
- Result = 39 (no modulo needed for small sum)

Please design the module accordingly.
