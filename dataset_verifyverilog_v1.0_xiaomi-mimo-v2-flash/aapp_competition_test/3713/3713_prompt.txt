Implement a Verilog module `alt_subseq` that computes the length of the longest alternating subsequence achievable by flipping a contiguous substring of a binary string.

**Interface Specification:**

**Inputs:**
- `clk`: 1-bit, System clock (rising edge triggered)
- `rst_n`: 1-bit, Active-low synchronous reset
- `start`: 1-bit, 1-cycle pulse to initiate computation
- `n`: 6-bit, Length of the binary string (1 ≤ n ≤ 64)
- `data`: 64-bit, The binary string data (stored in bit-vector, valid bits [n-1:0])

**Outputs:**
- `result`: 7-bit, The computed maximum alternating subsequence length
- `done`: 1-bit, High for 1 cycle when `result` is valid

**Functionality:**
1. The module must be fully synchronous.
2. When `start` is high, it samples `n` and `data`.
3. The module must calculate the number of positions `i` where `data[i] != data[i-1]` for `1 ≤ i < n`. Let this count be `C`.
4. It must identify if there exists a position `i` where `data[i] == data[i-1]`. Let existence of such a collision be `has_collision`.
5. The logic for the result is:
   - Base length is `C + 1`.
   - If `has_collision` is true, add `2` to the base length.
   - If `has_collision` is false but the string length `n > 1`, add `1` (implying a collision at the ends if strictly alternating).
   - Clamp the final result to `n` (maximum possible length).
6. Signal `done` goes high exactly one cycle after the computation finishes. Computation should take a fixed number of cycles (e.g., 50 cycles) to cover the iteration for `n=64`.

**Implementation Constraints:**
- Use an iterative or combinatorial approach suitable for `n` up to 64.
- Handle edge cases: `n=1` (result is always 1).
- Ensure no timing violations.

**Reset Behavior:**
- On reset (`rst_n` low), `result` and `done` are 0, internal counters reset.
