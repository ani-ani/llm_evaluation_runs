You are to design a Verilog module that solves the alien surgery puzzle for a 2x(2k+1) grid where k ≤ 3 (maximum grid size 2x7 = 14 cells, with 13 organs + 1 empty). The grid contains organs numbered 1 to 4k+1 (13 for k=3) and one empty cell represented as 0. The goal is to rearrange the grid to the target configuration:

- Row 0: organs 1 to 2k+1 (1..7 for k=3) in order
- Row 1: organs 2k+2 to 4k+1 (8..13 for k=3) in order from right to left, with empty (0) in the rightmost position

Valid moves:
1. Slide organ left/right into empty space (always allowed if adjacent)
2. Slide organ up/down into empty space ONLY if empty is in leftmost column (j=0), rightmost column (j=2k), or center column (j=k)

Interface:
- Inputs: clk, rst_n, start (1-cycle pulse)
- Grid input: 2x7 array of 8-bit unsigned values (0 for empty, 1-13 for organs). Pack into signals arr_0 to arr_13 (14 signals, each 8-bit)
- Outputs: result (0=failed, 1=complete), done (1-cycle when valid), moves_out (512-bit packed sequence, see below)

Constraints:
- Maximum move sequence length: 256 moves
- State encoding: current position of empty cell (row 0/1, col 0-6)
- Algorithm: Bounded DFS with backtracking, max depth 256
- Optimization: Use Manhattan distance heuristic for pruning

Output format: The module must output a packed sequence of moves. Each move uses 2 bits: 00=up, 01=down, 10=left, 11=right. Pack 256 moves into a 512-bit output. Also provide a done signal when solution found.

Implementation details:
1. Convert grid to 1D array of 14 cells (7 cells per row)
2. Target configuration is pre-computed and stored in ROM
3. Implement move validity check based on empty cell position
4. Implement DFS with depth limit 256
5. If no solution within 256 moves, output result=0
6. If solution found, set result=1 and output packed moves

Note: For k>3, the module should handle the case but with reduced search depth (use k parameter). For k=3, search depth 256 is sufficient for most cases.
