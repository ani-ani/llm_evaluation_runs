Implement a Verilog module that reconstructs Anatoly's corrupted tree traversal code and the original tree from observed outputs.

### Specifications:

**Inputs:**
- `clk`: System clock (rising edge)
- `rst_n`: Active-low synchronous reset
- `start`: 1-cycle pulse to start reconstruction
- `pre_obs`, `in_obs`, `post_obs`: 26x8-bit arrays containing observed output strings (ASCII uppercase letters). Fixed length 26, padded with null (0).
- `n`: 5-bit input (4-26) indicating actual tree size

**Outputs:**
- `done`: 1-cycle pulse when reconstruction complete
- `valid`: High when reconstruction found
- `call_seq`: 24-bit output encoding the 6 calls (4 bits each: 0=Pre, 1=In, 2=Post)
- `tree_pre`, `tree_in`, `tree_post`: 26x8-bit arrays containing the reconstructed tree traversals
- `tree_size`: 5-bit output

**Interface Requirements:**
- Process: When start=1, search through all 720 permutations of 6 calls (Pre/In/Post repeated exactly twice each)
- For each permutation, attempt to reconstruct a binary tree with n nodes that produces the observed outputs
- Tree nodes: Uppercase letters 'A'-'Z', unique per tree
- Output ordering: Alphabetically first tree (preorder, then inorder)
- Reconstruction constraints:
  1. Each traversal uses exactly 2 recursive calls total across all 3 functions
  2. The print position in each function is fixed (pre: root-first, in: root-middle, post: root-last)
  3. Recursive calls can be to any of the three functions
- Timing: Complete search within 10,000 cycles (for n=26, 720 permutations × ~14 operations)
- Reset: done=0, valid=0, all arrays cleared

**Algorithm:**
1. Parse observed strings (extract unique letters, verify n matches)
2. Generate all permutations of 6 calls from {Pre, In, Post} with exactly 2 of each
3. For each permutation, construct the call graph for each traversal
4. Attempt tree reconstruction using stack-based matching against observed outputs
5. Verify candidate tree against all 3 observed outputs
6. Track alphabetically first valid tree
7. Output results when best found

**Signal Widths:**
- `n`: 5 bits (0-31)
- `call_seq`: 24 bits (6 × 4-bit)
- `permutation_idx`: 10 bits (0-719)
- `node_idx`: 5 bits (0-31)
- ASCII char: 8 bits

**Control Flow:**
- State machine: IDLE → GENERATE_PERM → VERIFY_TREE → EVALUATE → OUTPUT
- Max 720 iterations for permutation search
- Each tree verification: O(n) stack operations

**Implementation Notes:**
- Precompute all valid call permutations (20 distinct sequences of 6 calls with 2×Pre, 2×In, 2×Post)
- Use iterative stack for tree traversal simulation (no recursion)
- Compare generated outputs character-by-character with observed
- For alphabetical ordering: compare strings lexicographically during evaluation
- When multiple trees match, keep the one with minimal preorder, then minimal inorder

**Performance:**
- Clock domain: Single clock
- Throughput: One reconstruction per start pulse
- Latency: <10,000 cycles for n≤26
- Resource: ~20 permutations × tree reconstruction logic
