Implement a Verilog module that computes the minimum time for Packmen to eat all asterisks on a 1D grid. The grid length is fixed at 16 cells. The input is a 16-element array of 4-bit values representing cell states: 0='.', 1='*', 2='P'. The module should use binary search over time T (0 to 255 cycles) and a check logic that simulates the greedy eating strategy.

Interface:
- Inputs:
  - clk: System clock
  - rst_n: Active-low asynchronous reset
  - start: 1-cycle pulse to start computation
  - field[15:0][3:0]: 16x4-bit array representing the grid state
- Outputs:
  - result: 8-bit output (minimum time)
  - done: 1-cycle pulse asserted when result is valid
  - busy: Indicates computation is in progress

Implementation Details:
1. The field has a fixed size of 16 cells. The positions of Packmen and asterisks are encoded in the 4-bit field array.
2. Use binary search to find the minimum time T (0 to 255).
3. For each candidate T, implement a checker that simulates the greedy algorithm:
   - Iterate through Packmen (in order of position).
   - For each Packman, calculate how many asterisks it can eat within time T.
   - Asterisks must be eaten in order of position.
   - A Packman at position `p` can eat an asterisk at position `a` if `|p - a| <= T`.
   - The checker should update a pointer to the next uneaten asterisk.
4. If all asterisks are eaten within T, the time is feasible.
5. The binary search should converge to the minimum feasible T.

Constraints:
- Maximum number of Packmen: 16
- Maximum number of asterisks: 16
- Time T is bounded to 8 bits (0-255).
- The design should be purely combinational for the check logic, controlled by the main FSM.
- The module must complete within 512 clock cycles.

Note: The input `field` is static during the computation. The `start` signal initiates the binary search process.
