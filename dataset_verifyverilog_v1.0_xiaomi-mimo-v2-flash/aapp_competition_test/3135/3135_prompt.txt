Implement a Verilog module that computes the signed binary representation with minimal non-zero digits and lexicographically smallest output. 

Specification:
- Input: binary string (100 bits max) as parallel 8-bit ASCII characters `char_in[0:12]` (13 chars for '0'/'1' plus newline, but we scale to 128-bit vector) or 100-bit binary vector.
- Given constraints, we use a 100-bit input `n_bin` (MSB first).
- Output: signed binary string `result[0:127]` (128-bit vector, ' ', '+', '-', '0') or 104-bit (13 chars).
- But simpler: Input is 100-bit vector. Output is 100-bit vector representing signed bits (+1, 0, -1).
- Operation: When `start` goes high, compute representation. Assert `done` when finished (within 500 cycles).
- Algorithm: Dynamic programming with state `carry` (0 or 1). Transition: for each bit (LSB to MSB), try options. Track minimal non-zeros and lexicographic precedence.
- Since DP is iterative, implement a sequence of 100 states. State: `pos`, `carry`, `best_count`, `best_val` (packed for lexicographic).
- For hardware efficiency: 100 cycles, single iteration.
- Output `res_bits[99:0]` where 0=0, 1='+', 2='-' (2-bit packed).
- Inputs: `rst_n`, `clk`, `start`, `n_bin[99:0]`. Outputs: `done`, `res_bits[99:0]`.
