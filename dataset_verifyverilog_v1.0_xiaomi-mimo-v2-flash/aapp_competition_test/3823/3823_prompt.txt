Design a Verilog module to solve the rounding optimization problem. Input: n (1-2000) and 2n numbers. Adaptation: Process numbers in batches of 8 (max 2000/8=250 cycles) using a fixed-point representation Q8.8 for fractional parts (0.000-0.999). Core algorithm: Extract fractional parts of numbers (0-999 scaled). Let K = count of non-integer numbers. The problem is to choose 'p' numbers (0 <= p <= min(n, K)) to ceil and (K-p) to floor, minimizing |sum_ceil_fractions - p|. This is a DP: sum_dp[i][j] = min difference using first i fractions with j chosen to ceil. Implement as a streaming DP with 16-bit accumulators. Output the minimal absolute difference as Q16.16 fixed-point.

Interface:
- Input: clk, rst_n, start (1-cycle pulse), n[15:0], data_in[15:0] (concatenated fraction scaled to 0-1000)
- Output: result[31:0] (fixed-point Q16.16), done (1-cycle pulse)
- Timing: Start signal initiates processing. done asserted when result is valid (within 1000 cycles). reset sets done=0, result=0.
- Constraints: n<=2000, fractions 0-999 (scaled), DP state array size 2048x2048 (use external memory or simplifed to 1D rolling array). Use 16-bit signed arithmetic for differences. Output formatted to 3 decimal places (simulated by scaled output). Model: Compute sum of all fractional parts (S). Iterate p from max(0, K-n) to min(n, K), calculate |S - p| and track minimum.
