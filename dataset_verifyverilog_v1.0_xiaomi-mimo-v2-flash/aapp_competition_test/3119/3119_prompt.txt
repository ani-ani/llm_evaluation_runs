Design a Verilog module to compute the maximum score in a rhythm game with Star Power phrases. Simplify constraints: max 16 notes, max 16 phrases, timestamps fit in 16-bit, max cycles 1024. Implement a greedy/state machine that iterates through phrases, tracks optimal score and remaining SP charge using 16-bit registers. Use a 100MHz clock. Interface: Inputs: clk, rst_n, start, notes[0:15] (16x16-bit), num_notes[3:0], phrases_start[0:15] (16x16-bit), phrases_end[0:15] (16x16-bit), num_phrases[3:0]. Outputs: result[23:0] (max score fits in 24 bits), done (1-cycle). Timing: Start pulse begins computation; done pulses after ≤1024 cycles. Reset sets all to zero. Logic: For each phrase, consider activating SP before it starts to maximize notes doubled within overlapping region, respecting SP charge duration. Use fixed-point arithmetic (Q16.0) for time. Core algorithm: 1) Count base score (n). 2) For each phrase, compute best activation time to maximize doubled notes from that phrase's notes, adding to score. 3) Sum maximum possible doubled notes. Implement as iterative loop over phrases with bounded inner loop over notes.
