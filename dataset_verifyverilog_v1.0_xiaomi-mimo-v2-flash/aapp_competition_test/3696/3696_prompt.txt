Design a Verilog module that generates two polynomials with coefficients in {-1, 0, 1} satisfying specific properties for Euclidean algorithm steps. The module should implement an iterative generation process based on Fibonacci-like sequences of polynomial pairs.

**Module Specification:**
- **Inputs:**
  - `clk`: System clock (rising edge)
  - `rst_n`: Active-low synchronous reset
  - `start`: Start signal (1-cycle pulse)
  - `n`: 8-bit unsigned input (1-150), represents desired Euclidean algorithm steps

- **Outputs:**
  - `result_valid`: High when valid output polynomial coefficients are available
  - `poly1_coeff_count`: 5-bit (0-31) indicating number of coefficients for polynomial 1
  - `poly1_coeffs[30:0]`: 31-bit packed coefficient array (index 0 = constant term, index 30 = highest degree)
  - `poly2_coeff_count`: 5-bit (0-31) indicating number of coefficients for polynomial 2
  - `poly2_coeffs[30:0]`: 31-bit packed coefficient array

**Constraints:**
- Coefficients are 2-bit signed values (-1, 0, 1) packed into 31 coefficients (31*2 = 62 bits)
- Maximum degree supported: 30
- Maximum n: 150
- Timing: Complete within 1000 cycles after start
- Reset: Clear all state, done=0, result_valid=0

**Algorithm:**
Implement the polynomial generation algorithm:
1. Initialize: A = [1], B = [1] (polynomials as coefficient lists)
2. For i from 1 to n:
   - Compute new_A = [0] + A (shift A right by 1, add 0 at beginning)
   - Compute new_B = A
   - For each coefficient in B: add it to corresponding position in new_A
   - Check if all coefficients in new_A are in {-1, 0, 1}
   - If yes: A = new_A, B = new_B
   - If no: try with subtraction instead
   - Update registers
3. Output polynomials with leading coefficient = 1

**Implementation Details:**
- Use FSM with states: IDLE, COMPUTE, CHECK, UPDATE, OUTPUT
- Store polynomials as packed arrays of 2-bit signed values
- Implement coefficient operations in combinational logic
- Use bounded loops (max 150 iterations)
- Verify leading coefficient is 1 before output
