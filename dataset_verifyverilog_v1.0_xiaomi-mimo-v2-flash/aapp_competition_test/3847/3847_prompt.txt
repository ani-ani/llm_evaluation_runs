Implement a module that finds the maximum area subrectangle where sum ≤ x.

Constraints:
- n, m ≤ 16 (scaled down from 2000)
- a_i, b_j ≤ 2000 → use 16-bit integers
- x ≤ 2×10^9 → use 32-bit integers
- Output area ≤ 256 (16×16)

Algorithm:
1. For each possible length L from 1 to n, compute min_sum_a[L] = minimum sum of any contiguous subarray of a with length L
2. For each possible length L from 1 to m, compute min_sum_b[L] = minimum sum of any contiguous subarray of b with length L
3. Find max(i×j) where min_sum_a[i] × min_sum_b[j] ≤ x

Interface:
  Inputs:
    clk: rising edge
    rst_n: active-low sync reset (min 2 cycles)
    start: 1-cycle pulse to start computation
    n: 4-bit (1-16) - number of elements in array a
    m: 4-bit (1-16) - number of elements in array b
    a[0:15]: 16×16-bit - array a values
    b[0:15]: 16×16-bit - array b values
    x: 32-bit - threshold value
  
  Outputs:
    result: 16-bit - maximum area (0-256)
    done: 1-cycle pulse when result is valid

  Timing:
    - start->done within 5000 cycles
    - Sample result when done=1

  Reset:
    - rst_n=0: done=0, result=0, internal state reset
    - Reset must last at least 2 clock cycles

  Implementation notes:
    - Use 2D combinational logic or sequential state machine
    - Precompute min_sum arrays in first ~100 cycles
    - Then compute max area in next ~100 cycles
    - Total cycles ≤ 5000
    - Use 32-bit arithmetic for multiplication to avoid overflow
    - Clamp all sums to 32-bit range
