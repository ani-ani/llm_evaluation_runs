Implement a Verilog module to count untileable cells in a street string using tile patterns. Constraints: N≤16 (fixed), total pattern length ≤128, each pattern ≤16 chars. Use a bitmask approach where each bit represents a covered position. Interface: inputs: clk, rst_n, start, street[0:15] (16x8-bit characters), pattern_len[0:7] (8 patterns), patterns[0:7][0:15] (8x16x8-bit chars), M (4-bit pattern count). Output: result (16-bit count, since N≤16). Operation: On start=1, compute coverage by checking all patterns against all positions. For each pattern and position match, set corresponding bits in coverage mask. After processing all patterns, count zeros in coverage mask. Timing: start->done within 256 cycles. Reset clears all state. Implementation hint: Use combinatorial matching for each (pattern, position) pair, OR into coverage register. Then popcount complement.
