Implement a Verilog module to solve the 'Banana Briefcase' problem. The goal is to partition the array of N briefcases into the maximum number of contiguous segments (K) such that the sum of bananas in each segment is non-decreasing from the first segment (least evil executive) to the last segment (most evil executive).

**Scaling & Constraints:**
- Input N is limited to 16 (scaled from 3000).
- Input banana counts are limited to 16-bit integers (scaled from 10^9).
- The module must compute the maximum number of executives K (0 to 16).
- Use a sequential FSM approach with `clk` and `rst_n`.
- Operation: Assert `start` high for one cycle with inputs valid. Wait for `done` signal. Result is available at `result` when `done` is high.

**Algorithm (DP / Greedy Logic):**
1.  Compute prefix sums of the array to quickly calculate segment sums.
2.  Iterate through possible lengths of the first segment (from 1 to N).
3.  For each first segment length, determine the maximum number of subsequent segments that can form a non-decreasing sequence. This requires a sub-logic: for a given minimum required sum `min_sum` and starting index `idx`, find the smallest ending index `j` such that `sum(idx...j) >= min_sum`. If found, increment count and update `min_sum` to this new sum, repeat.
4.  Track the maximum count found across all valid first segment lengths.
5.  Since N is small (16), a fully unrolled hardware implementation or an FSM iterating through states is feasible. A sequential FSM is preferred to save resources.

**Interface:**
- Inputs:
  - `clk`: System clock, rising edge.
  - `rst_n`: Active-low asynchronous reset.
  - `start`: 1-cycle pulse to start computation.
  - `N`: 4-bit unsigned integer (number of briefcases, max 16).
  - `arr`: Array of 16 elements, each 16-bit unsigned integer. 
- Outputs:
  - `result`: 5-bit unsigned integer (maximum number of executives, max 16).
  - `done`: 1-cycle pulse indicating computation complete and result valid.

**Timing:**
- `start` to `done` within 1000 clock cycles.
- Reset sets `done` to 0 and `result` to 0.
