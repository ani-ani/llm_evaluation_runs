Design a combinational Verilog module named 'cube_fold_detector' that determines if a 6x6 grid of unit squares can be folded into a cube.

Input:
  input [35:0] grid // Flattened 6x6 grid (row-major order) where 1'b1 = '#', 1'b0 = '.'
Output:
  output foldable // 1 if pattern can fold into cube, 0 otherwise

Behavior:
- The module compares the input grid against all 11 valid rotation/reflection variants of cube nets
- Outputs 1 when input matches any valid cube net pattern
- No clock required - purely combinational logic
Notes:
- Precompute all 11 base net patterns and their 24 possible transformations (rotations/flips)
- Store valid patterns in internal lookup tables/comparator logic
