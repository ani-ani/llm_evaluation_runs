Design a sequential Verilog module named 'path_counter' that calculates the number of distinct hopscotch paths from (0,0) to (N,N) with minimum hop increments (X,Y) modulo 1000000007.

Module interface:
module path_counter(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [3:0] N, // Max 8 (scaled from original 1e6)
  input [3:0] X, // Min x-hop (1≤X≤N)
  input [3:0] Y, // Min y-hop (1≤Y≤N)
  output reg [31:0] result, // Path count modulo 1000000007
  output reg done // High when computation completes
);

Behavioral description:
1. Uses an 8x8 DP grid (memory [0:8][0:8] of 32-bit unsigned)
2. Initialize DP[0][0] = 1, others 0 when start asserted
3. For each grid position (i,j) compute path count as:
   DP[i][j] = (Σ DP[a][b] where (0≤a≤i-X, 0≤b≤j-Y)) mod 1000000007
4. Compute sequentially with state machine:
   States: IDLE, INIT, PROCESS, COMPLETE
5. Latency: Completes in 72 cycles after start (max 8x8=64 grid points + overhead)
6. Result valid when done=1
