Design a sequential Verilog module named 'taboo_string_finder' that finds the longest binary string not containing any taboo substrings.
Module interface:
module taboo_string_finder(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // start computation
  input [1:0] n_taboos, // number of taboo strings (0-3)
  input [3:0] taboo0, // 4-bit taboo string 0
  input [3:0] taboo1, // 4-bit taboo string 1
  input [3:0] taboo2, // 4-bit taboo string 2
  input [3:0] taboo3, // 4-bit taboo string 3
  output reg [7:0] result, // result (LSB-aligned)
  output reg found, // 1 = finite solution, 0 = infinite length possible (-1)
  output reg done // high when complete
);
Behavior:
When start is asserted:
1. Check if any taboo string is prefix of another (indicates forbidden loop)
2. If finite solution possible (finite automaton cycle detection):
   - Find the longest possible binary string up to 8 bits
   - Break ties by lexicographic order (0 < 1)
   - Output via result with found=1
3. Else (infinite length possible): found=0, result undefined
Latency: Output valid within 32 clock cycles. Use states: IDLE, CHECK_TAIL, GENERATE, TEST, DONE.
All strings are bit-aligned (no padding). Comparisons are exact substring matches.
