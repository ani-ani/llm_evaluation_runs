Design a sequential Verilog module named 'max_box_piles' that computes the number of maximum-sized distinct box piles modulo 1000000007.

Module interface:
module max_box_piles(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [2:0] n, // Number of boxes (3-8)
  input [5:0] a [7:0], // Box values (8 x 6-bit)
  output reg [31:0] result, // Result modulo 10^9+7
  output reg done // High when computation completes
);

Behavior description:
1. On reset, clear all internal registers.
2. When start is asserted:
   a. Build divisibility graph (8x8 adjacency matrix)
   b. Find weakly connected components (WCC) using iterative DFS
   c. Compute dynamic programming states for each WCC
   d. Calculate total permutations with combinatorial logic
3. Modules takes 100-200 clock cycles to complete (exact latency not critical)
4. Output 'done' asserted when result is valid
5. All arithmetic uses modulo 1000000007 operations

Implementation notes:
- Use fixed 8-node graph with 6-bit node values
- Implement DFS with stack-based iterative approach
- DP table unrolled for max m=7 elements (from WCC analysis)
- Combinatorial block for nCr pre-calculation
- Use 32-bit modular arithmetic throughout
