Design a sequential Verilog module named 'xorbonacci_queries' that calculates the XOR of subsequences in a scaled-down xorbonacci sequence.

Module interface:
module xorbonacci_queries(
  input clk,
  input rst_n,
  input start,
  input [1:0] K,          // Current max K=4 (values 1-4)
  input [7:0] a1, a2, a3, a4,  // Initial terms (unused terms ignored)
  input [1:0] Q,          // Number of queries (1-4)
  input [3:0] l1, r1,      // Query 1 parameters (max index=16)
  input [3:0] l2, r2,      // Query 2 parameters
  input [3:0] l3, r3,      // Query 3 parameters
  input [3:0] l4, r4,      // Query 4 parameters
  output reg done,
  output reg [7:0] res1,   // Query 1 result
  output reg [7:0] res2,   // Query 2 result
  output reg [7:0] res3,   // Query 3 result
  output reg [7:0] res4    // Query 4 result
);

Behavior:
1. On active-low reset (rst_n=0), reset all registers
2. When start=1:
   a. Precompute xorbonacci sequence for indices 1-16
   b. Store sequence in register array x[1..16]
   c. Compute XOR results for all Q queries (index bounds l_i to r_i)
   d. Assert done=1 when complete
3. Computation steps require multiple cycles:
   - Sequence generation takes 16 cycles
   - Query results computed after sequence generation
4. Each x_n term (n > K) is calculated as x[n] = x[n-1] ^ x[n-2] ^ ... ^ x[n-K]
5. Per-query result is the XOR of all terms from x[l] to x[r] inclusive

Latency:
- Sequence generation: 16 cycles
- Query processing: 1 additional cycle after sequence complete
- Total maximum latency: 17 cycles after start asserted
