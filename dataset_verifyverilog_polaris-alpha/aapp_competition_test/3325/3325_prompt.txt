Design a sequential Verilog module named 'water_height_calculator' that computes the water height in a convex polygon aquarium tank using fixed-point arithmetic and binary search.

Inputs:
input clk,              // clock signal
input rst_n,            // active-low reset
input start,            // pulse high to start computation
input [3:0] N_vertices, // number of polygon vertices (4-8)
input [15:0] D_depth,   // tank depth (Q16.16 format, 16 integer + 16 fractional bits)
input [15:0] L_liters,  // water amount (Q16.16 format)
input [11:0] vertices [0:7][0:1] // vertex coordinates (x,y) [12-bit signed]

Outputs:
output reg [15:0] height, // water height in cm (Q16.16 format, display fixed 2 decimal places)
output reg done          // high when computation complete

Behavioral description:
1. The module first precomputes polygon segments and relevant geometry
2. Implements binary search with fixed 16 iterations to find water level
3. Uses Q16.16 fixed-point arithmetic for all calculations
4. Processes one iteration per clock cycle
5. Water height (h) is found when L_water = D * total_area(h)

Timing requirements:
- Latency: 16 clock cycles (after start assertion)
- Reset behavior: clears all internal registers when rst_n low
- Done signal asserts when result is ready (height valid for 1 cycle)

Fixed-point format note:
- All computations use Q16.16 format (e.g., 20.83 cm = 0x0014D70A)
- Display 2 decimal places by truncating fractional bits
