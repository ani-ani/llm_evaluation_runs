Design a sequential Verilog module named 'min_plus_adder' that finds the minimal '+' insertions in a digit sequence to reach target sum S.

Module interface:
module min_plus_adder(
  input clk, // Clock signal
  input rst_n, // Active-low reset
  input start, // Start computation
  input [3:0] digit_count, // Actual digit count (1-8)
  input [7:0][3:0] digits, // Up to 8 digits (4-bit each, MSB first)
  input [15:0] target_sum, // Target S value
  output reg [6:0] plus_positions, // Split positions between digits (bitmask)
  output reg [3:0] plus_count, // Number of '+' inserted
  output reg [15:0] computed_sum, // Sum of split segments
  output reg done // High when computation completes
);

Behavior: Starts computation when 'start' is asserted. Uses BFS-like state machine to test split combinations ordered by '+' count. Outputs first valid solution with minimal '+' operations. Latency: Worst-case 128 cycles. Reset initializes all outputs to zero.
