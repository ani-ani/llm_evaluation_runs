Design a sequential Verilog module named 'house_envy_solver' that calculates the maximum final house height after remodeling iterations.

Inputs:
input clk       // system clock
input rst_n     // active-low reset
input start     // start signal (pulse high to begin)
input [2:0] n   // number of houses (1-8, actual = n+1 since index starts at 0)
input [31:0] k   // envy factor in Q16.16 fixed-point format
input [31:0] h0  // initial height of house 0 (Q16.16)
input [31:0] h1  // initial height of house 1
input [31:0] h2  // ... up to house 7 (all Q16.16)
input [31:0] h3
input [31:0] h4
input [31:0] h5
input [31:0] h6
input [31:0] h7

Outputs:
output reg [31:0] max_height // max final height (Q16.16)
output reg done               // high when result valid

Behavior:
1. On reset: All registers cleared, done=0
2. When start=1: Begin 100 iterations of house height updates
3. Each iteration updates all houses sequentially (left-to-right)
4. House 0 uses 0 as left neighbor, house n uses 0 as right neighbor
5. Update rule for house i: new_h_i = max(current_h_i, (left + right)/2 + k)
   Q16.16 calculations: sum left+right must maintain 33 bits before division
6. After 100 iterations: find maximum height among all houses
7. Assert done=1 and output max_height

Latency: Results available after 100*(n+1) + 2 clock cycles
Note: Fixed-point arithmetic must maintain Q16.16 precision throughout
