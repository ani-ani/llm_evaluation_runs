Design a Verilog module named 'eurus_function' that computes the iterated totient function Φ m times (m = min((k+1)/2, 16)) or until result=1.

Module interface:
module eurus_function(
  input clk,
  input rst_n,
  input start,
  input [15:0] n,
  input [7:0] k,
  output reg [15:0] result,
  output reg done
);

Behavior description:
1. On reset (rst_n=0), set state to IDLE, result=0, done=0
2. When start=1: set current_value = n and compute steps = min((k+1)>>1, 16)
3. Over 16 cycles maximum: load Φ(current_value) from ROM each cycle
4. Stop early if current_value=1 or step counter reaches 0
5. Output final value when done and assert done=1

Euler totient Φ values must come from 64KB ROM (precomputed for 0-65535). Module should have 16 cycle maximum latency.
