Design a combinational Verilog module named 'quadcopter_path_length' that calculates the minimal quadcopter path length using the following algorithm:
1. Compute absolute differences between inputs: dx = |x1 - x2|, dy = |y1 - y2|
2. Add 1 to each difference: dx_inc = dx + 1, dy_inc = dy + 1
3. Apply minimum value constraint: dx_final = (dx_inc < 2) ? 2 : dx_inc, dy_final = (dy_inc < 2) ? 2 : dy_inc
4. Calculate total path length: path_length = 2 * (dx_final + dy_final)

Module interface:
module quadcopter_path_length(
  input signed [7:0] x1, // 8-bit signed start x
  input signed [7:0] y1, // 8-bit signed start y
  input signed [7:0] x2, // 8-bit signed flag x
  input signed [7:0] y2, // 8-bit signed flag y
  output [10:0] path_length // 11-bit unsigned path length
);
