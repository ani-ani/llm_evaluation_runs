Design a sequential Verilog module named 'store_path_detector' that determines shopping path uniqueness from limited inputs.

Inputs:
input clk,      // Clock
input rst_n,  // Active-low reset
input start,   // Start processing (pulse high)
input [1:0] num_stores,  // N = 4 max (0-3 stores)
input [3:0][1:0] store_ids,  // 4 stores max (0-3)
input [3:0][1:0] item_ids,   // 4 items max (0-3)
input [3:0][1:0] bought_list, // 4 bought items max (0-3 IDs)
input [1:0] num_bought,   // M = 4 max

Outputs:
output reg [1:0] result,  // 00=impossible, 01=unique, 10=ambiguous
output reg done            // High when complete

Behavior:
1. On reset: clear all states
2. When start=1: 
   a. Interpret store_ids[i] and item_ids[i] defining inventory (store_i carries item_i)
   b. Process bought_list items in order:
      - Each item must be available at current store or later
      - Track possible valid purchase paths
3. After M+2 cycles, output:
   - 00 if no valid path exists
   - 01 if exactly one valid path
   - 10 if multiple paths
4. Maximum supported: 4 stores, 4 items in inventory, 4 purchased items
