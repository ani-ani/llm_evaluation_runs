Design a sequential Verilog module named 'evolution_validator' that checks if fossil sequences can form two evolutionary paths leading to current species.

Module interface:
module evolution_validator(
  input clk, // Clock signal
  input rst_n, // Active-low reset
  input start, // Start computation
  input [15:0] current_seq, // Current species sequence (8 chars, 2 bits/char: 00=A, 01=C, 10=M)
  input [7:0][15:0] fossil_seqs, // 8 fossil sequences (each 16 bits)
  input [3:0] num_fossils, // Number of fossils (0-8)
  output reg possible, // 1=possible, 0=impossible
  output reg [3:0] s1, // Path1 count
  output reg [3:0] s2, // Path2 count
  output reg [7:0] path1_mask, // Fossil indices in path1 (1=included)
  output reg [7:0] path2_mask, // Fossil indices in path2 (1=included)
  output reg done // High when computation complete
);

Behavior: Upon start signal, determine if fossils can be assigned to two insertion-based evolutionary paths ending at current_seq. Compute for maximum 8 fossils (num_fossils) and 8-character sequences. Only parent-child relationships where one string can be formed by inserting one character into the other are considered. Result available after 256 clock cycles max. Use active-low asynchronous reset. Output masks represent fossil assignments.
