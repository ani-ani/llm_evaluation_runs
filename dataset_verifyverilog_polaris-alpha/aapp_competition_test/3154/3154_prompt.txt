Design a sequential Verilog module named 'toy_assignment' that solves the adapted toy assignment problem.

Module interface:
module toy_assignment(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // pulse high for 1 cycle to start computation
  input [3:0] in_kid_id, // 4 kids (2 bits), MSB ignored for 4 kids
  input [3:0] in_toy_id, // 4 toys (2 bits)
  input [15:0] in_event_time, // playtime event timestamp (scaled to 16 bits)
  input [2:0] in_event_count, // max 8 events (3 bits)
  output reg [7:0] assignments, // 2 bits per kid [kid1_toy, kid2_toy, kid3_toy, kid4_toy]
  output reg impossible_flag, // high=no valid assignment found
  output reg done // high when computation complete
);

Behavioral description:
1. The module processes up to 8 playtime events to compute each kid's toy preferences and envy relationships
2. Valid assignments must satisfy:
   a) Each kid assigned exactly one toy
   b) No toy assigned to multiple kids
   c) No envy condition: For every assigned toy T to kid B, no kid A has higher playtime with T than B
3. Compute valiation steps:
   a) Compute total play durations for each (kid, toy) pair
   b) Create preference matrix based on first playtimes
   c) Enumerate possible assignments (brute-force for 4x4 scale) and verify constraints
4. If no valid assignment is found, assert impossible_flag

Operation sequence:
- Start signal triggers computation (must pulse for 1 cycle)
- On reset: clear all internal state
- Latency: Toy assignment computed in 256 cycles max (due to small kid/toy count)
- When done is asserted: valid assignments or impossible flag available next cycle
