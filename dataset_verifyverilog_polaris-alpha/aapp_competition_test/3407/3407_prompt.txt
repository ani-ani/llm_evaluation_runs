Design a sequential Verilog module named 'tree_coordinate_placement' that calculates node positions for a 8-node tree.

Inputs:
input clk, // Clock
input rst_n, // Active-low reset
input start, // Start computation
input [2:0] node_count, // Number of nodes (2-8)
input [7:0][7:0] adj_matrix, // Adjacency matrix (1=connected)

Outputs:
output reg [15:0] x_coords [0:7], // Q8.8 fixed-point coordinates
output reg [15:0] y_coords [0:7], // Q8.8 fixed-point coordinates
output reg done // High when computation complete

Behavioral requirements:
1. Assign coordinates to nodes such that connected nodes are exactly 1.0mm apart (Q8.8 value 0x0100 = 1<<8)
2. Output coordinates must satisfy:
   a. Minimum node distance ≥ 0.0039mm (Q8.8 value 0x0001)
   b. Coordinates within ±127.996mm (Q8.8 range 0x8000 to 0x7FFF)
3. Compute positions using breadth-first placement from node 0 (root at origin)
4. Module must complete within 50 clock cycles after start assertion
5. Use fixed-point arithmetic for all calculations

Implementation notes:
- Node 0 is always at (0,0)
- Place children at 45° increments from parent (8 possible directions)
- Store coordinates as Q8.8: [15:8]=integer, [7:0]=fraction
- Use iterative state machine with coordinate rounding if needed
