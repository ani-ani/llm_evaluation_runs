Design a sequential Verilog module named 'function_decomposition' that checks if valid functions g and h exist based on input f.
Module interface:
module function_decomposition(
  input clk,               // clock signal
  input rst_n,             // active-low reset
  input start,             // starts computation when high
  input [2:0] f [0:7],     // input function f(n) (n=8 fixed)
  output reg [2:0] m,      // output size (1 ≤ m ≤ 8)
  output reg [2:0] g [0:7],// output function g(n)
  output reg [2:0] h [0:7],// output function h(m)
  output reg valid_out     // valid=1 when solution exists
);

Behavioral description:
1. On rst_n=0, reset all outputs to 0 and internal state
2. On start=1:
   a. Verify that for each i (0-7), f[f[i]] == f[i] and f[i] == fixed point (h elements)
   b. Collect unique fixed points where f[i]=i into h array
   c. If any condition fails: set valid_out=0, m=0
   d. Else:
      - Set m = number of fixed points
      - For each i: g[i] = index of f[i] in h + 1
3. Requires 5 clock cycles: 1 for reset, 2 for checks, 1 for solution construction, 1 for output
4. Output valid at cycle 5 after start asserted. All arrays are 3-bit values.
