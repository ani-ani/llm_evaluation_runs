Design a sequential Verilog module named 'cfg_substring_matcher' that finds the longest valid substring matching given CFG rules.
Module interface:
module cfg_substring_matcher(
  input clk, 
  input rst_n, 
  input start, 
  input [263:0] rules, // 8 rules * 33 bits (5-bit head + 28-bit production)
  input [95:0] text_line, // 16 chars * 6 bits (a-z + space)
  output reg [95:0] longest_substr, 
  output reg valid, 
  output reg done 
);

Behavior:
- On start pulse, find longest substring in text_line that can be generated by CFG
- Rules format: rules[32:0] = first rule (5-bit head + 4x7-bit chars)
  - Each char: bit[6]=1 for variable, bits[5:0]=value (5-bit var or 6-bit terminal)
- Start variable is head of first rule
- Implementation strategy:
  1. Check all substrings from longest (16-char) to shortest (1-char)
  2. For each substring, try ≤16 derivation steps using rules
  3. First valid substring found is the result
- Timing: Results valid ≤256 cycles after start
- Outputs:
  - valid=1 if non-empty substring found, 0 otherwise (output NONE in software)
  - longest_substr contains matched characters (padded with zeros)
  - done=1 when computation completes
Use active-low synchronous reset (rst_n).
