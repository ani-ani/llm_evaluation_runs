Design a combinational Verilog module named 'doll_average_counter' that counts consecutive subsequences with average >= P.

Inputs:
input [15:0] p_value, // Threshold P (16-bit value)
input [7:0][15:0] prices, // 8-day price history (each 16-bit)

Output:
output [5:0] count // Number of valid subsequences (max 36)

Behavior:
For all possible consecutive subsequences in the 8-element prices array (lengths 1-8):
1. Sum all elements in subsequence
2. Calculate average (sum / subsequence_length)
3. Compare average to p_value
4. Count all subsequences where average >= p_value

Implementation notes:
- Use division-free comparison: sum >= p_value * subsequence_length
- All math operations should use 32-bit intermediate values to prevent overflow
- Count all valid consecutive subsequences (different start/end positions)
