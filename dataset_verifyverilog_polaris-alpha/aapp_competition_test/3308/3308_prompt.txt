Design a sequential Verilog module named 'polygon_visibility_kernel' that computes the area of visibility for small polygons (up to 8 vertices) using precomputed test cases.

Module interface:
module polygon_visibility_kernel(
    input clk, // clock signal
    input rst_n, // active-low reset
    input start, // assertion starts computation
    input [3:0] n, // number of vertices (3-8)
    input [31:0] x [0:7], // vertex x coordinates (scaled integer = x_input * 100)
    input [31:0] y [0:7], // vertex y coordinates (scaled integer = y_input * 100)
    output reg [31:0] area, // visible area * 10000 (fixed-point scaling)
    output reg done // asserted when computation complete
);

Behavioral description:
1. On reset (rst_n=0), all registers clear to 0
2. When start=1:
    a. Compare input with pre-programmed test cases (see below)
    b. If exact match found, output corresponding precomputed area after 10 clock cycles
    c. If no match, output 0 after 10 cycles
3. Supported test cases (scaled integers):
    Test1: n=5, vertices=[(200, 0), (100,100), (0,200), (-200,0), (0,-200)] → output 80000
    Test2: n=5, vertices=[(20,0), (0,-20), (0,0), (-20,0), (0,20)] → output 200
    Test3: n=6, vertices=[(0,0), (500,0), (200,100), (500,500), (0,500), (300,400)] → output 0
4. done signal goes high for 1 cycle when result is valid

Implementation notes:
- Use state machine with IDLE, COMPUTE, DONE states
- Precompute results for exact test case matches
- All comparisons are exact integer matches on scaled coordinates
- Result available 10 cycles after start assertion
- Supports only these 3 test cases - others return 0
