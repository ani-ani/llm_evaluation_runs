Design a combinational Verilog module named 'escape_calculator' that computes the minimal required escape speed for scaled-down city (max 4 nodes, 4 roads).
Inputs:
input [1:0] n; // number of nodes (2-4)
input [1:0] e; // num exits (1-4)
input [3:0][3:0][6:0] roads; // 4x4 adjacency matrix (road lengths in hm, 7 bits per edge)
input [3:0] exits; // bitmask of exit nodes (4 bits)
input [1:0] b_start; // brothers' start node (2 bits)
input [1:0] p_start; // police start node (2 bits)
Outputs:
output [31:0] min_speed; // Q16.16 fixed-point (0xFFFF_FFFF = impossible)
Behavior:
1. Compute shortest distances from b_start to all exits using roads
2. Compute shortest distances from p_start to all exits
3. For each exit: if (police_time > 0 & brothers_time > 0) require speed >= (brothers_dist * 160.0) / police_dist
4. Output minimal required speed Q16.16 (0xFFFFFFFF if no valid exit)
