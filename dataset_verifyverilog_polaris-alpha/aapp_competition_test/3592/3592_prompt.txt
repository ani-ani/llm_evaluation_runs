Design a sequential Verilog module named 'pita_pizza_calculator' that finds all combinations of pitas and pizzas sold given total profit.

Module interface:
module pita_pizza_calculator(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // start calculation
  input [13:0] total_profit, // in cents (0-10000 = $0-$100.00)
  input [9:0] pita_profit, // profit per pita in cents (1-1000 = $0.01-$10.00)
  input [9:0] pizza_profit, // profit per pizza in cents (1-1000)
  output reg [6:0] pita_count, // number of pitas (0-100)
  output reg [6:0] pizza_count, // number of pizzas (0-100)
  output reg valid, // high when values are output valid
  output reg done // high when calculation complete
);

Behavioral description:
1. Module searches through all possible pita counts (0-100) when started
2. For each pita count (0 to 100), calculate temp = total_profit - (pita_count * pita_profit)
3. If temp is non-negative and divisible by pizza_profit (temp mod pizza_profit == 0):
   Calculate pizza_count = temp / pizza_profit
   If pizza_count <= 100: output (pita_count, pizza_count) on next clock edge with valid=1
4. Signal done=1 when search completes with all combinations output
5. Pipeline stages: Results found in same cycle as comparator check
6. All outputs are registered. Latency: 1 cycle per pita count (max 101 cycles) plus output cycles
7. Reset: When rst_n=0, all outputs reset to 0 and FSM returns to idle state.
8. Valid combinations must be output in increasing pita_count order.
