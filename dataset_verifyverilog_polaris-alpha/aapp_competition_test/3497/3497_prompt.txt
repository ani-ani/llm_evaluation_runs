Design a sequential Verilog module named 'pig_escape_calculator' that calculates the minimum wolves to remove for P pigs to escape a tree of up to 8 nodes.

Module interface:
module pig_escape_calculator(
  input clk,              // clock
  input rst_n,            // active-low reset
  input start,            // start computation
  input [2:0] v,          // total vertices (3-8)
  input [2:0] p,          // number of pigs (3-8)
  input [31:0] edges_vec, // flattened edge pairs [u3,v3,u2,v2,u1,v1,u0,v0]
  input [23:0] pigs_vec,  // pig positions as 3-bit packed [p7..p0]
  input [23:0] wolves_vec,// wolf positions as 3-bit packed [w7..w0]
  output reg [2:0] result, // min wolves to remove
  output reg done          // high when computation complete
);

Behavioral description:
1. On reset: clear all state.
2. When start=1: parse edges_vec into adjacency list for an 8-node tree.
3. For each pig position (up to 8 pigs):
   a. Find all leaf nodes reachable from current pig without passing wolves
   b. Record required wolf removals for each path
4. Calculate minimum wolf removals covering all pigs' requirements
5. Result should be valid 24 cycles after start assertion.
6. Output done=1 when result is ready.

Design assumptions:
- Tree maximum size=8 nodes, pig count=3-8
- Wolves are at all non-pig nodes
- All nodes/pigs are addressed with 3-bit values
- Each edge stored as two 3-bit fields in edges_vec
