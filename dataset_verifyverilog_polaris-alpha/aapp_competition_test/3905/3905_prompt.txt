Design a sequential Verilog module named 'min_data_centers' that finds the minimum subset of data centers to shift maintenance while preserving data availability.

Inputs:
input clk, // clock signal
input rst_n, // active-low reset
input start, // start computation
input [2:0] n, // number of data centers (2-8)
input [3:0] m, // number of clients (1-16)
input [2:0] h, // day length in hours (2-8)
input [7:0][2:0] u_array, // maintenance times [1..n]
input [15:0][5:0] client_pairs // {client1_c1[2:0], client1_c2[2:0], ...}

Outputs:
output reg [2:0] k, // solution size (1-8)
output reg [7:0] solution_set, // bitmask of centers (1-indexed)
output reg done, // high when computation complete
output reg valid // solution is valid

Behavior:
1. On reset: Initialize all outputs to 0.
2. On start: Build directed graph where edge A→B exists if (u_A + 1) % h == u_B.
3. Find strongly connected components (SCC) using iterative DFS.
4. Select smallest SCC with zero out-degree.
5. Output bitmask of nodes in selected SCC (1-indexed).

Latency: Output valid 256 cycles after start asserted. Use states: IDLE, BUILD_GRAPH, FIND_SCCS, CALC_OUTDEG, SELECT_SCC, DONE.

Constraints:
- Maximum 8 data centers (n ≤ 8)
- Maximum 16 clients (m ≤ 16)
- Hours 2 ≤ h ≤ 8 (3-bit)
Client pairs check modulo relationship only when both datacenters exist.
