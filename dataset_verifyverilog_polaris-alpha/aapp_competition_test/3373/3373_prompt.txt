Design a sequential Verilog module named 'longest_balanced_parentheses' that finds the maximum balanced length from up to 3 pieces.

Inputs:
  input clk,           // clock
  input rst_n,         // active-low reset
  input start,         // pulse high to start computation
  input [1:0][5:0] pieces, // Array of 3 pieces (6-bit strings) - '('=1, ')'=0

Outputs:
  output reg [4:0] max_length, // Maximum balanced length (0-30)
  output reg done               // High when computation complete

Behavior:
1. Precompute for each piece:
   - balance = count(1) - count(0)
   - max_valid = longest balanced substring length
   - is_balanced = 1 if entire piece is balanced
2. Implement DP state machine tracking:
   - current_balance (4-bit signed: -8 to +7)
   - current_length (5-bit)
3. Iterate through piece combinations for 3 clock cycles
4. Result available 4 cycles after start, done=1

Timing:
- Start pulse must be held for 1 cycle
- Output valid when done=1 (latency=4 cycles)
