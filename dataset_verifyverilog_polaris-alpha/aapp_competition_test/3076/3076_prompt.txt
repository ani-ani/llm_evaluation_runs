Design a sequential Verilog module named 'knapsack_solver' that solves the bounded knapsack problem for small inputs.

Input specifications:
- Maximum 8 jewels (parameter N=8)
- Maximum 8 knapsack sizes (parameter K=8)
- Jewel sizes (s) up to 8 bits (1-255)
- Jewel values (v) up to 8 bits (1-255)

Module interface:
module knapsack_solver(
  input clk,
  input rst_n,
  input start,
  input [2:0] jewel_count,  // 0-7 jewels (use 3 bits)
  input [7:0] jewel_sizes [0:7],  // 8 jewels, 8 bits each
  input [7:0] jewel_values [0:7],  // 8 jewels, 8 bits each
  output reg [10:0] dp_table [0:7],  // DP results for k=1-8 (11-bit sums)
  output reg done
);

Behavioral description:
1. On reset (rst_n=0), clear dp_table to 0
2. When start=1:
   a. Initialize DP table with zeros
   b. For each jewel (0 to jewel_count-1):
      i. For each knapsack size from K down to jewel_size:
         - Update dp_table[i] = max(current_value, dp[i - size] + value)
   c. Process one jewel per clock cycle
3. Assert done after (jewel_count + 2) cycles
4. dp_table holds final results, starting index 0 = size1, up to index7 = size8

Timing:
- Inputs stable before start asserted
- Output valid when done=1, latency = (jewel_count + 2) cycles
