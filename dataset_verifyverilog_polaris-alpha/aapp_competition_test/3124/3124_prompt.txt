Design a sequential Verilog module named "ivana_game" that calculates how many starting positions give Ivana a winning chance against optimal play. Scale problem to N=8.
Inputs:
- input clk 
- input rst_n 
- input start 
- input [2:0] n (number count, 1-8)
- input [9:0] nums [0:7] (8 numbers, each 10-bit)
Outputs:
- output reg [3:0] win_count (0-8 possible winning starts)
- output reg done (high when computation complete)\
Behavior:
1. When start asserts, begin computing winning moves
2. For each starting position i (0 to n-1), simulate optimal game: \
    - Track remaining numbers and current odd counts
    - Alternate moves (Ivana first) choosing optimal available positions
    - Compare final odd counts to determine if Ivana wins/draws
3. Result valid after maximum 16 clock cycles
4. Use circular buffer indexing to handle circular arrangement
5. Module should compare all 8 possible starts in parallel when possible
