Design a sequential Verilog module named 'button_assigner' that computes the maximum number of valid assignments (k).

Module interface:
module button_assigner(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start signal (pulse high to begin)
  input [15:0] grid, // Flattened 4x4 grid (each row 4 bits: Y=1, N=0)
  output reg [2:0] k, // Max valid assignments (0-4)
  output reg done // High when computation completes
);

Behavior:
1. On reset: k <= 0, done <= 0
2. When start pulse received:
   - Initialize internal adjacency matrix
   - Find max unique assignments via iterative matching
3. Output k becomes valid when done=1
4. Implementation must use a state machine with states:
   IDLE, FIND_MATCH, UPDATE_MATRIX, DONE
5. Matching algorithm should identify perfect assignment patterns in the grid
6. Core operation must complete within 8 clock cycles after start
Note: Implementation should model bipartite matching with preference tracking.
