Design a Verilog module 'lang_divider' that solves a scaled-down version of the Gridnavia language problem. The module takes grid dimensions and cell data, outputs three language grids if possible.

Inputs:
input clk, // Clock
input rst_n, // Active-low reset
input start, // Start computation
input [1:0] n, // Grid rows (2-bit, 1-4)
input [1:0] m, // Grid cols (2-bit, 1-4)
input [15:0] grid_data, // Flattened grid (row-major, 16-bit for 4x4 grid)

Outputs:
output reg valid, // High when output ready
output reg [15:0] lang_a, // Arwegian grid (1=A, 0=.)
output reg [15:0] lang_b, // Banish grid (1=B, 0=.)
output reg [15:0] lang_c, // Cwedish grid (1=C, 0=.)
output reg impossible_flag // High if no solution exists

Behavior:
1. On reset or when start=0, all outputs = 0
2. When start=1: Begin computation
3. Implements three hardcoded patterns:
   - Pattern 1: A=left cols, B=center cols, C=right cols
   - Pattern 2: A=top rows, B=middle rows, C=bottom rows
   - Pattern 3: A=border cells, B=inner cells
4. Checks which pattern (if any) satisfies:
   - For 1s: Only one language present
   - For 2s: At least two languages present
   - All languages form connected regions
5. Outputs first valid pattern found
6. If none valid after checking all patterns, assert impossible_flag
7. All outputs stable by 3 clock cycles after start
Timing:
- Start pulse must be held high for >=3 cycles
- Output valid at cycle 3 after assertion
- Each language region must remain connected even if grid smaller than 4x4
