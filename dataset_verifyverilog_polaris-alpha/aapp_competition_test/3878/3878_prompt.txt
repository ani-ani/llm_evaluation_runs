Design a sequential Verilog module named 'min_clique_steps' that finds the minimum steps to connect all guests.
Inputs:
   input clk,            // clock
   input rst_n,          // active-low reset
   input start,          // begin computation (pulse)
   input [2:0] n,        // number of guests (1-8)
   input [4:0] m,        // number of edges (0-28)
   input [2:0] u_in,     // edge endpoint u (3 bits)
   input [2:0] v_in,     // edge endpoint v (3 bits)
   input edge_valid,     // edge data valid
Outputs:
   output reg [3:0] step_count,  // minimum steps required (0-8)
   output reg [2:0] guest_steps [0:7],  // selected guest IDs
   output reg done       // high when computation completes

Behavior:
1. Wait for start signal. On start pulse:
   a. Initialize adjacency matrix from input edges (u_in, v_in) when edge_valid=1
   b. Process edges for m clock cycles (edge_valid must cycle with each edge)
2. Compute minimum steps using dynamic programming with bitmask states (256 states for n<=8)
3. After computation, assert done and output step_count and guest_steps
4. Latency: Maximum 300 clock cycles after last edge input

Algorithm overview:
- Use bitmasks to represent friendship groups
- DP[mask] stores minimal steps to achieve 'mask' group
- For each state, expand by selecting guests to merge friend groups
- Record optimal path to full connection (mask=0xFF)
