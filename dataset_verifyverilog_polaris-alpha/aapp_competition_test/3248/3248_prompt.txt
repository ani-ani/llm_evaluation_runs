Design a sequential Verilog module named 'untileable_cell_counter' that computes the number of street cells not coverable by any tile pattern. Input constraints: street length ≤16 chars, ≤4 tile patterns, each pattern ≤16 chars.

Module interface:
module untileable_cell_counter(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // start computation
  input [3:0] street_len, // street length (1-16)
  input [3:0] num_patterns, // number of tile patterns (1-4)
  input [15:0][4:0] street_chars, // 16x5b char array (ASCII a-z)
  input [3:0][3:0] tile_lens, // 4x4b tile lengths
  input [3:0][15:0][4:0] tile_patterns, // 4 tiles x 16x5b chars
  output reg [4:0] untileable_count, // result (0-16)
  output reg done // high when result valid
);

Behavior:
1. On reset or when !start: Initialize all coverable flags to 0
2. When start asserted:
   - For each tile pattern: check every possible starting position in street
   - Mark matching positions by setting coverable flags
3. After processing all patterns: count unmarked positions
4. Assert 'done' when complete (max 16*4*16 = 1024 cycles latency)

Implementation note:
Use a state machine with: IDLE, CHECK_TILES, COUNT, DONE states.\
