Design a Verilog module named 'path_sum_optimizer' that calculates the minimal total path length from factorial nodes to P.

Module interface:
module path_sum_optimizer(
  input [3:0] k [0:7], // Up to 8 fragments (4 bits each, 0-15)
  input [2:0] num_fragments, // Actual fragment count (0-8)
  output [6:0] min_sum
);

Behavior:
1. Precompute prime exponents for each k! (primes 2,3,5,7,11,13)
2. For each fragment, load precomputed prime exponents
3. Sum exponents across all fragments for each prime
4. Calculate minimal sum by checking majority exponents at each prime level

Note: Includes internal lookup table for k! prime exponents (k=0-15). Module is purely combinational.
