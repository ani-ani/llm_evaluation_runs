Design a sequential Verilog module named 'trade_matcher' that finds the longest matching trade sequence from two start positions in a 16-character string. Module interface:
module trade_matcher(
  input clk,
  input rst_n,
  input start,
  input [3:0] i,
  input [3:0] j,
  output reg [3:0] max_length,
  output reg done
);

Behavior:
- Pre-loaded string: ABABABcABABAbAba (16 chars)
- On start pulse: begin comparing s[i+k] == s[j+k] for k=0,1,...
- When mismatch found or end reached: output k as max_length
- Set done=1 for 1 cycle when complete
- Assume 2-cycle latency (result valid 2 cycles after start)

Character storage (ASCII):
reg [7:0] s[0:15] = {"A","B","A","B","A","B","c","A","B","A","B","A","b","A","b","a"};

Implementation:
- Use equals comparators for each potential k index
- Break on first mismatch or max length reached
- Handle wrap-around protection (i+k < 16)
- Sequential operation recommended using counter
