Design a sequential Verilog module named 'min_effort_balancing' that calculates the minimum effort Barry needs to make the sequence impossible to balance.

Module interface:
module min_effort_balancing(
  input clk,                   // clock signal
  input rst_n,                 // active-low reset
  input start,                 // pulse high to start computation
  input [2:0] k_in,            // max Bruce operations (0-8)
  input [7:0] seq_bits,        // packed 8-bit sequence (0='(', 1=')')
  input [7:0][10:0] costs,     // 8 cost values (11-bit signed each)
  output reg [10:0] min_effort, // resulting minimal effort (11-bit signed)
  output reg impossible_flag,   // high when result is '?'
  output reg done              // high when computation complete
);

Behavioral Description:
1. The module operates sequentially and requires start pulse to begin.
2. Computes required flips by:
   a. Tracking balance count while scanning sequence
   b. Collecting flipping candidates when unexpected ')' occurs
3. If required_flips > k_in:
   - Set impossible_flag=1, min_effort=0
4. Else:
   - Sort cumulative costs of possible barrier positions (first 'required_flips' positions)
   - Sum lowest 'k_in - required_flips + 1' costs
5. Output becomes valid 15 clock cycles after start assertion.
6. Uses fixed array sizes for 8-element processing with comparison-based min selection.
Timing:
- Start pulse should be held high for 1 cycle.
- Computation completes 15 cycles after start (done asserted).
- Outputs remain stable until next start.
Reset:
- All registers reset to 0 on active-low reset (rst_n=0)."
