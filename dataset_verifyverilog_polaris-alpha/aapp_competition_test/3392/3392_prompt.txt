Design a sequential Verilog module named 'max_tree_group' that finds the largest connected group of trees that will eventually reach equal height.

Module interface:
module max_tree_group(
  input clk,
  input rst_n,
  input start,
  input [19:0] h_matrix [0:15], // 4x4 matrix flattened (each cell 20-bit initial height)
  input [19:0] v_matrix [0:15], // 4x4 matrix flattened (each cell 20-bit growth rate)
  output reg [4:0] max_group_size, // Max connected group size (0-16)
  output reg done // High when computation completes
);

Behavior:
- On reset: Clear all internal states
- When start goes high: Begin processing
- Algorithm:
  1. For all adjacent cell pairs, compute whether they can be equal:
     a. If v_i == v_j, equal if h_i == h_j
     b. Else check if (h_j - h_i) and (v_i - v_j) have same sign and non-zero t
  2. Create adjacency matrix based on valid equal-height pairs
  3. Find largest connected component using iterative BFS
- Output max_group_size when done
- Latency: 300 cycles (pipelined for 4x4 matrix)

Implementation notes:
- Use fixed-point comparison with 20-bit integer math
- Precompute adjacency relationships in first 50 cycles
- Use visited flags and component counters during BFS
- Max supported matrix: 4x4 (16 elements)
