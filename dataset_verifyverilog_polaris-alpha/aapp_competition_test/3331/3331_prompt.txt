Design a Verilog module named 'horse_chase' that computes capture time for optimally moving cows and horse.

Module interface:
module horse_chase(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // start computation (pulse high)
  input [3:0] L, // trail length (1-15 meters)
  input [3:0] A, // cow A position (0 <= A <= L, distinct)
  input [3:0] B, // cow B position (0 <= B <= L, distinct)
  input [3:0] P, // horse initial position (0 <= P <= L, distinct)
  output reg [4:0] time_out, // capture time (0-31 minutes)
  output reg done // high when computation complete
);

Behavior:
- On reset, all registers initialize to 0
- When start pulse is detected:
  - Load initial positions (A_curr=A, B_curr=B, P_curr=P)
  - Reset time_out to 0
- Each clock cycle represents 1 simulation minute:
  1. Cows move optimally: cow positions move 0/1m towards horse
  2. Horse moves optimally: choose direction to maximize escape time
  3. Check capture condition (cow at horse position)
  4. If captured: latch time_out and assert done
  5. Else: increment time_out

Movement rules:
- Cows move 1m towards horse if distance > 1, else stay
- Horse can move 2m unless in cow position (then 1m), choosing direction to maximize minimum distance to cows while respecting [0,L] boundaries.
- Capture occurs if any cow position equals horse position after horse moves.

Implementation note:
Use a state machine with states: IDLE, INIT, PROCESS, CAPTURED.
Latency: Worst-case 15 cycles (for L=15) + 1 cycle start detection.
