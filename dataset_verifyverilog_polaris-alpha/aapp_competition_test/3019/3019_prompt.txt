Design a sequential Verilog module named 'max_revenue_calculator' to find maximum revenue from selling data pieces under the new contract terms.

Inputs:
- clk: system clock
- rst_n: active-low reset
- start: pulse high to begin computation
- [2:0] N: number of data pieces (1-5 max)
- [9:0] S0, S1, S2, S3, S4: data properties (0-1000 value)

Outputs:
- [7:0] max_rev: maximum revenue achieved
- done: high when computation completes

Functionality:
1. Module calculates maximum revenue by trying all possible customer assignments for data pieces.
2. Each assignment corresponds to distributing N items to N customers (represented by N^N possible assignments).
3. For each assignment:
   a. Calculate sum of S_i values for each customer
   b. For each sum >1: lookup distinct prime factor count from precomputed ROM
   c. Accumulate counts across all customers
4. Track & output maximum accumulated count across all assignments.

Timing:
- Computation starts when 'start' is pulsed high
- 'done' asserts after approximately 3200 cycles for N=5
- Uses internal ROM for prime factors (address 0-5000 covers possible sums)

Implementation Notes:
- Base-N counter used to generate all assignments (N=1-5)
- States: IDLE, INIT, COMPUTE_SUMS, PRIME_LOOKUP, UPDATE_MAX, DONE
- Address calculation for ROM: (group_sum) where group_sum = Σ(assigned S_i)
