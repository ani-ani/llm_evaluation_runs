Design a sequential Verilog module named 'coprime_pairs_counter' that counts coprime pairs (x,y) where x ∈ [a,b], y ∈ [c,d].

Module interface:
module coprime_pairs_counter(
  input clk,               // clock
  input rst_n,             // active-low reset
  input start,             // start computation
  input [3:0] a,           // lower bound of x (4 bits)
  input [3:0] b,           // upper bound of x (4 bits)
  input [3:0] c,           // lower bound of y (4 bits)
  input [3:0] d,           // upper bound of y (4 bits)
  output reg [7:0] count,  // result count (8 bits)
  output reg done           // completion flag
);

Behavioral description:
1. On reset (rst_n=0), reset all internal registers, count=0, done=0
2. When start=1:
   a. Iterate through all x between a and b (inclusive)
   b. For each x, iterate through all y between c and d (inclusive)
   c. For each (x,y) pair, compute gcd combinatorially
   d. If gcd==1, increment count
3. Done signal goes high when last pair is processed
4. Operation takes (b-a+1)*(d-c+1) clock cycles
5. Use 2D iterative logic with x/y counters and gcd calculator
6. For gcd computation: Implement combinational Euclid's algorithm for 4-bit inputs.

Implementation note: Use a state machine with states IDLE, COMPUTING, DONE.
