Design a Verilog module named 'tv_coverage' that calculates coverage length of television transmitters. Use Q12.4 fixed-point format (16-bit: 12 integer, 4 fractional bits). All values multiplied by 16 (e.g., 6.0 = 0x0060).

Module interface:
module tv_coverage(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [4:0] city_length, // Max 31 units (5-bit)
  input [0:7] has_transmitter, // 8 buildings mask (1-bit per building)
  input [4:0] building_pos[0:7], // Positions (5-bit each)
  input [4:0] building_height[0:7], // Heights (5-bit each)
  output reg [15:0] coverage_length, // Q12.4 format
  output reg done // High when computation complete
);

Behavior:
1. On start, compute covered length by transmitters
2. Each transmitter illuminates segments unobstructed by buildings
3. Calculate covered areas using line-of-sight checks between buildings
4. Merge overlapping covered segments
5. Output should be valid 16 clock cycles after start is asserted.
6. Use pipelined fixed-point arithmetic for coverage calculations.
