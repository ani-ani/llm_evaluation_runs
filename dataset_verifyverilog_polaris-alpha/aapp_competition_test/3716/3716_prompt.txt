Design a combinational Verilog module named 'max_triple_lcm' that finds the maximum LCM of any three numbers in the range [max(1,n-7), n].

Inputs:
  input [7:0] n  // Input value (1 <= n <= 255)

Outputs:
  output [23:0] max_lcm  // Maximum LCM found (24-bit width)

Behavioral description:
1. Consider all combinations (i,j,k) where n-7 <= i,j,k <= n (with i >= j >= k, k >= 1)
2. For each triplet, compute LCM(i,j,k) = LCM(i, LCM(j,k))
3. GCD calculation: gcd(a,b) = gcd(b,a%b) until b==0
4. Track and output the maximum LCM value found

Implementation notes:
- Use combinational logic only (no clock)
- Input constrained to 8 bits (maximum n=255)
- Output must support up to 255*254*253 ≈ 16M (24 bits)
- Parallel computation preferred but can use nested loops in generate blocks
