Design a Verilog module named 'defective_cell_enclosure' that calculates minimum panels required to contain defective cells in a 4x4x4 grid.

Module interface:
module defective_cell_enclosure(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // triggers computation
  input [2:0] num_cells, // number of defective cells (0-8)
  input [7:0][2:0][1:0] cell_coords, // 8 cells, each with [x[1:0], y[1:0], z[1:0]]
  output reg [7:0] panels, // total panels needed
  output reg done // high when computation completes
);

Behavior:
- The module maintains a 4x4x4 grid memory (64-bit) where each bit represents cell status (1=defective).
- On reset: clear grid memory
- On start: load defective cells into grid (based on num_cells and cell_coords)
- After loading: scan entire grid (16 clocks for loading + 64 clocks for processing)
- For each defective cell: count adjacent defective cells (max 6 neighbors), subtract shared panels from starting count of 6
- Output the total panel count when done is asserted
- Computation completes in maximum 80 clock cycles after start
- Done remains high for one cycle when result is valid

Implementation notes:
- Use state machine with states: IDLE, LOAD, COUNT, DONE
- Use counters to track grid coordinates (x[1:0], y[1:0], z[1:0])
- Address grid memory using 6-bit index (4x4x4=64 cells)
- Check all 6 possible neighbors (x±1, y±1, z±1) during counting phase
