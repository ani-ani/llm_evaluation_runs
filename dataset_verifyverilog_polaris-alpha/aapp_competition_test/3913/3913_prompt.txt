Design a sequential Verilog module named 'word_guess_analyzer' that determines valid guess letters.
Inputs:
  input clk, // clock
  input rst_n, // active-low reset
  input start, // pulse to start computation
  input [3:0] n, // word length (1-16)
  input [95:0] revealed_chars, // 16 positions, each 6 bits {1'b is_revealed, 5'b char}
  input [3:0] m, // number of words (1-16)
  input [79:0] word_data, // current word input (16 chars * 5 bits)
  input word_valid // high when word_data is valid
Outputs:
  output reg [4:0] result, // count of valid letters (0-26)
  output reg done // high when computation completes
Behavior:
1. On reset, clear internal state
2. When start is pulsed:
   a. Process each valid word (via word_valid) and check:
      i. Must match revealed non-* positions
      ii. Hidden positions (*) must not contain revealed letters
   b. Collect hidden letters from valid words (letters in * positions)
   c. Compute intersection across all valid words
   d. Output intersection size when done
Timing:
- Processes 1 word per clock cycle after word_valid is asserted
- Result valid 2 cycles after last word is processed
- Max latency: 18 cycles (16 words + setup)
