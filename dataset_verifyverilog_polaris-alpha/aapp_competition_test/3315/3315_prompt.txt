Design a sequential Verilog module named 'loda_teleportations' that computes the longest valid subsequence of strings.
Inputs:
  input clk,               // Clock signal
  input rst_n,             // Active-low reset
  input start,             // Pulse high to start computation
  input [7:0] string_count, // Number of strings (1-8)
  input [15:0][7:0] strings [0:7], // 8 strings (16 chars max each), ASCII encoded
  input [4:0] lengths [0:7]      // Length of each string (1-16)
Outputs:
  output reg [3:0] max_length, // Longest valid subsequence length
  output reg done            // High when computation complete

Behavior:
1. On reset or power-up: Reset all internal registers
2. On start pulse: Compute compatibility matrix (8x8 bits) where
   matrix[i][j] = 1 if j>i and strings[j] starts with AND ends with strings[i]
3. Compute longest path in the directed acyclic graph between nodes
4. Result valid after 50 cycles (worst-case path calculation)
5. 'done' signal goes high for 1 cycle when result is ready

Implementation Notes:
- Strings are compared character-by-character (first 'lengths[i]' chars matter)
- Use fixed-size 8x8 adjacency matrix
- Limit maximum string length to 16 characters using 'lengths' input
- Longest path computation may use parallel path evaluation or iterative DFS
