Design a sequential Verilog module named 'incremental_double_free_string' that implements the following behavior:
- Inputs: clk (clock), rst_n (active-low reset), start (start pulse), [1:0] k (2-bit input for k value, valid range 1-2), [9:0] n (10-bit input for n index, 1 ≤ n ≤ 1024)
- Outputs: reg [14:0] string_out (3 characters × 5 bits each), reg done (high when output valid), reg err (high if invalid result)

Behavior:
1. On reset (rst_n=0), outputs clear to 0
2. When start=1 arrives:
   a. For k=1: If n ≤ 26, output single character (5 bits) in LSB positions (bits [4:0]), set done=1 and err=0 after 1 clock cycle
   b. For k=2: If n ≤ 650, calculate ordered triplet string (format: A-B-A where A,B are distinct letters), store as 3×5-bit characters in [14:10], [9:5], [4:0], set done=1 and err=0 after 1 clock cycle
   c. For k invalid or n exceeding counts (n>26 when k=1 or n>650 when k=2): Set err=1 and done=1
3. Latency: Outputs valid 1 clock cycle after start assertion
4. Character encoding: 'a'=1, 'b'=2, ..., 'z'=26 (5-bit unsigned)

Calculation logic (combinational when start=1):
- For k=1: string_out[4:0] = (n ≤ 26) ? n : 0
- For k=2:
   temp = n - 1
   first_char = temp / 25 + 1   // Integer division
   rem = temp % 25
   second_char = (rem >= first_char - 1) ? rem + 2 : rem + 1
   string_out = {first_char[4:0], second_char[4:0], first_char[4:0]}
