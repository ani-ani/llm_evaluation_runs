Design a Verilog module named 'allergen_test_optimizer' that computes minimal test days. Inputs: clk, rst_n, start, k[2:0] (number of allergens 1-4), D1[2:0]..D4[2:0] (1-7 day durations). Outputs: done, T[4:0] (result days).

Specification:
- Sequential module: Requires 3 clock cycles latency
- On reset: Clear internal state
- When start=1: Begin computation
  Cycle 1: Check all allergen pairs for overlapping patterns
  Cycle 2: Determine minimal T meeting constraints
  Cycle 3: Output T valid with done=1
Constraints:
- Each allergen's active window must have ≥1 unique day
- Minimize total days while meeting uniqueness
- Parallel checks for all (permutated) allergen pairs
Example: For k=3, Ds=(2,2,2) → T=5 days
Module interface:
module allergen_test_optimizer(
  input clk,
  input rst_n,
  input start,
  input [2:0] k,
  input [2:0] D1,
  input [2:0] D2,
  input [2:0] D3,
  input [2:0] D4,
  output reg done,
  output reg [4:0] T
);
