Design a sequential Verilog module named 'plant_replanner' that calculates the minimum number of plants to replant based on species order.

Module interface:
module plant_replanner(
  input clk,                  // clock signal
  input rst_n,                // active-low reset
  input start,                // start computation
  input [1:0] species_data [0:15],  // 16-entry species array (each 2 bits)
  output reg [4:0] replant_count,    // min plants to replant (0-16)
  output reg done                     // high when computation complete
);

Behavior:
1. When start=1, module calculates longest non-decreasing subsequence (LNDS) length in species_data
2. replant_count = 16 - LNDS_length
3. Processing takes exactly 16 clock cycles after start
4. Use internal registers to track current sequence position and max subsequence length
5. done asserts for 1 cycle when calculation completes

Timing:
- Reset: All registers clear on rst_n=0
- Start: Begin processing on rising edge when start=1
- Output: Valid at replant_count when done=1 (16 cycles after start)
