Design a Verilog module named 'jon_snow_rangers' that processes strength modifications for Jon Snow's rangers.

Module interface:
module jon_snow_rangers(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // init computation
  input [3:0] k, // operations count (0-15)
  input [9:0] x, // XOR value (0-1023)
  input [9:0] a0, a1, a2, a3, a4, a5, a6, a7, // ranger strengths (max 8 rangers)
  output reg [9:0] max_strength, // maximum strength
  output reg [9:0] min_strength, // minimum strength
  output reg done // high when results valid
);

Behavioral description:
1. On reset, all outputs set to 0
2. When start=1, module performs k operations sequentially (1 per clock cycle):
   a. Sort strengths in ascending order
   b. Apply XOR with x to every alternate element (indices 0,2,4,6)
3. After k operations, output final max/min strengths
4. done signal asserts for 1 cycle when results valid

Timing requirements:
- Requires k+2 clock cycles:
   - 1 cycle to load inputs
   - k cycles for operations
   - 1 cycle for final max/min calculation
- Output valid when done=1

Implementation notes:
- Use parallel sorting network for 8 elements (fixed latency 1 cycle)
- Internal storage for current strengths
- FSM states: IDLE, PROCESSING, FINAL_CALC, DONE
- All assignments must be non-blocking inside always blocks
