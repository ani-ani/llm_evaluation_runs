Design a sequential Verilog module named 'dragon_subsequence' that finds the maximum length of non-decreasing subsequence after optimal reversal.

Module interface:
module dragon_subsequence(
  input clk, // clock signal
  input rst_n, // active-low reset (async)
  input start, // pulse high for 1 cycle to start computation
  input [7:0] seq, // 8-bit input where each bit represents value (0=1, 1=2)
  output reg [3:0] max_length, // maximum subsequence length (4 bits)
  output reg done // high when computation complete
);

Behavioral description:
1. On reset (rst_n=0), initialize all registers
2. When start=1, begin processing the 8-element sequence (seq[7:0])
3. Maintain four 4-bit state registers tracking:
   a) Current max for type 1-only
   b) Current max for type1→type2
   c) Current max for type1→type2→type1
   d) Current max for type1→type2→type1→type2
4. Process one element per clock cycle using the following logic:
   if current element == 1:
     state_a <= state_a + 1
     state_c <= max(state_b + 1, state_c + 1)
   else:
     state_b <= max(state_a + 1, state_b + 1)
     state_d <= max(state_c + 1, state_d + 1)
5. After processing all 8 elements (takes 8 cycles):
   max_length <= max(state_a, state_b, state_c, state_d)
   done <= 1
6. done remains high until next start pulse.
Latency: Result available 8 clock cycles after start pulse. Use a counter to track processing steps.
