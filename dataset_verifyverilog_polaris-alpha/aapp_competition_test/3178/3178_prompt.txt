Design a sequential Verilog module named 'city_decoration' that finds the minimal decoration cost for a small city graph.
Inputs:
  input clk,            // Clock signal
  input rst_n,          // Active-low reset
  input start,          // Start computation (pulse high)
  input [5:0][1:0] edges, // 6 roads (0: unused, 1-4: node indices in packed form [a,b], a< b<4) 
  input [2:0] m_actual  // Actual number of roads used (1-6)
Outputs:
  output reg [4:0] min_cost, // Minimum valid cost (5-bit signed: valid 0-12 or -1)
  output reg done            // High when computation complete
Behavior:
1. On start pulse, begin exhaustive search of all 3^6 decoration combinations
2. For each combination: check (1) adjacent road constraints per node, (2) cycle sum constraints
3. Constraints revised for hardware: 
   - Adjacent roads (same node): (a+b) mod 3 !=1
   - Any cycle in the 4-node graph must have odd sum
4. Compute minimal valid cost. If none valid, output -1
Latency: Maximum 729 cycles (3^6) plus 3 cycles for initialization. Done asserts when result ready.
