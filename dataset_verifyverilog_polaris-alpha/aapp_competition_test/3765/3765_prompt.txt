Design a sequential Verilog module named 'rectangle_extensions' that finds the minimal extension count.

Inputs:
   input clk,                  // clock
   input rst_n,                // active-low reset
   input start,                // pulse high to start computation
   input [31:0] a, b, h, w,    // target rectangle and initial field sizes
   input [15:0][31:0] factors, // 16 extension factors (max problem size)
   input [4:0] num_factors     // actual number of factors (1-16)

Outputs:
   output reg [4:0] min_count, // minimal extensions needed (0-16 or 31 for -1)
   output reg done             // high when computation completes

Behavior:
1. When start pulses high, initialize state with (h,w) and (w,h) configurations.
2. For each extension from 1 to num_factors (sorted desc):
   a. Generate new dimensions by applying factor to either dimension
   b. Track reachable (h,w) pairs in each step
3. Check after each extension if any configuration satisfies:
   (h >= a && w >= b) || (h >= b && w >= a)
4. min_count becomes current extension count when conditions met
5. If no solution after num_factors, set min_count=31 (representing -1)

Timing:
- Latency: Variable (finished in num_factors+2 cycles after start)
- Requires 1 start pulse to initiate
- Sorts factors internally in descending order

State Machine States:
   IDLE, SORT, PROCESS, CHECK, DONE

Key Simplifications:
- Limited to max 16 extensions
- Uses 32-bit arithmetic with early termination
