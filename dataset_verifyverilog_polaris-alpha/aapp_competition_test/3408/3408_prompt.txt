Design a combinational Verilog module named 'wildcard_matcher' that checks how many of 4 predefined 4-character words match a given pattern. Each character is encoded as 5 bits (0-25 for letters, 26 for wildcard '*').

Module interface:
module wildcard_matcher(
  input [3:0][4:0] word0, // Word0 [char3,char2,char1,char0]
  input [3:0][4:0] word1, // Word1 [char3,char2,char1,char0]
  input [3:0][4:0] word2, // Word2 [char3,char2,char1,char0]
  input [3:0][4:0] word3, // Word3 [char3,char2,char1,char0]
  input [3:0][4:0] pattern, // Pattern [char3,char2,char1,char0]
  output reg [2:0] match_count
);

Behavior: For each of the 4 words, compare all characters to the pattern. A word matches only if for every position i: (pattern[i] == 5'd26) || (wordX[i] == pattern[i]). Output the count of matching words (0-4). Implement using parallel comparators. All logic must be combinational.
