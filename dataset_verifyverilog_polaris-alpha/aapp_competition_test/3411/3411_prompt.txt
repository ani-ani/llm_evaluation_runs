Design a sequential Verilog module named 'alternating_chain' that computes minimal time to make comment chain alternating with maximum 8 comments.

Inputs:
input clk, // clock
input rst_n, // active-low reset
input start, // pulse high to start computation
input [2:0] n, // number of comments (1-8)
input [15:0] c, // account creation time (1-65535)
input [15:0] r, // reporting time (1-65535)
input [7:0] scores [0:7], // 8x8-bit signed scores (-128 to 127)

Outputs:
output reg [31:0] min_time, // minimal time in seconds
output reg done // high when computation complete

Behavior:
1. On start pulse, module begins processing the n-element comment chain
2. Implements decision logic to choose between:
   a) Voting operations: count votes needed per comment to make non-zero with correct sign
   b) Removal operations: cost r per removed comment
3. Computes minimal time considering possible vote/remove combinations for alternate signs

Timing:
- Latency: 32 clock cycles maximum (1 cycle per comment + overhead)
- Output min_time valid when done=1

Notes:
- Alternate chain requires non-zero elements with adjacent opposite signs
- Voting cost per account: c (can vote multiple comments per account)
- Report cost: r per comment removal
- Operations can be combined in any order
