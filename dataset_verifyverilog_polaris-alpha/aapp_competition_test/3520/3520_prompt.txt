Design a sequential Verilog module named "pill_scheduler" that computes maximum lifespan using up to 4 pills.

Module interface:
module pill_scheduler(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // pulse high to start computation
  input [31:0] n, // base lifespan (0-65535 scaled by 2^16 in Q16.16)
  input [31:0] c, // switch cost (0-65535 scaled by 2^16 in Q16.16)
  input [31:0] pill1_t, // pill1 introduction time (Q16.16)
  input [31:0] pill1_x, // pill1 x value (Q16.16)
  input [31:0] pill1_y, // pill1 y value (Q16.16)
  input [31:0] pill2_t,
  input [31:0] pill2_x,
  input [31:0] pill2_y,
  input [31:0] pill3_t,
  input [31:0] pill3_x,
  input [31:0] pill3_y,
  input [31:0] pill4_t,
  input [31:0] pill4_x,
  input [31:0] pill4_y,
  output reg [31:0] max_lifespan, // Q16.16 format
  output reg done // high when computation complete
);

Behavior:
- Upon start pulse, compute maximum possible lifespan using at most 4 available pills
- Use state machine with states: IDLE, CALC_DELAYS, EVAL_PATHS, DONE
- Model pill choices as path selection with switching penalties
- Calculations use fixed-point arithmetic (Q16.16 format)
- Output valid 16 clock cycles after start assertion
- Must handle pill introduction times in increasing order
