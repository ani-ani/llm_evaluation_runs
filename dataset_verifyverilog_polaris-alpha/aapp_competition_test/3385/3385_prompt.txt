Design a combinational Verilog module named 'costume_parity_solver' that calculates the number of valid costume assignments for a ring of up to 8 children given parity constraints.
Inputs:
    input [2:0] n,              // Number of children (1-8)
    input [2:0] l_array[0:7],   // l_i values (each 0-7)
    input [2:0] r_array[0:7],   // r_i values (each 0-7)
    input [7:0] x_array         // x_i parity bits (bit i = x_i)
Output:
    output [31:0] result       // Number of valid assignments modulo 10^9+7

Behavior: For each possible costume assignment (8-bit vector), check all n segment constraints. A segment for child i includes (i-l_i mod n) to (i+r_i mod n) children. If parity of the segment matches x_i for all i, count it. Output the total count modulo 1000000007.
