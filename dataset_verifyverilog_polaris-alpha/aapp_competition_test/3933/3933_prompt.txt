Design a sequential Verilog module named 'temperature_predictor' that implements Vasya's weather forecasting method with these constraints:
Inputs:
input clk (1-bit clock),
input rst_n (1-bit active-low reset),
input start (1-bit start signal),
input [11:0] temp_0, temp_1, temp_2, temp_3, temp_4, temp_5, temp_6, temp_7 (8x12-bit signed temperatures),
input [2:0] n (3-bit input 2-8 days valid)
Outputs:
output reg [11:0] prediction (12-bit signed result),
output reg done (1-bit high when computation completes)

Behavior: On start signal, check if temperatures[0:n-1] form arithmetic progression. If yes: prediction = temp[n-1] + common_difference. Else: prediction = temp[n-1].
Latency: Result valid after 8 clock cycles max. Use a state machine with IDLE, COMPARE, CALCULATE, DONE states. Treat all temperatures as signed integers. Common difference = temp[1] - temp[0]. Array indices beyond n should be ignored.
