Design a sequential Verilog module named 'pipe_clean_scheduler' that determines if robots can clean all intersections without collisions. The module should support up to 8 wells and 8 pipes.

Inputs:
input clk,            // clock
input rst_n,          // async active-low reset
input start,          // pulse high to start computation
input [2:0] num_wells, // number of wells (1-8)
input [2:0] num_pipes, // number of pipes (1-8)
input [15:0] well_x [0:7], // Q12.4 fixed-point X coordinates for wells
input [15:0] well_y [0:7], // Q12.4 fixed-point Y coordinates for wells
input [2:0] pipe_start [0:7], // well index (0-7) for each pipe start
input [15:0] pipe_end_x [0:7], // Q12.4 X coordinates for pipe ends
input [15:0] pipe_end_y [0:7]  // Q12.4 Y coordinates for pipe ends

Outputs:
output reg result,    // 1=possible, 0=impossible
output reg done       // high when computation complete

Behavior:
1. On start pulse:
   - Build adjacency matrix P (8x8) where P[i][j]=1 if pipe i and j intersect (excluding shared wells)
   - Perform bipartite check on the resulting graph
2. Intersection detection:
   - Convert Q12.4 to integer coordinates during computation (ignore fractional)
   - Use line segment intersection algorithm for integer coordinates
3. Bipartite check:
   - Use iterative BFS with color mapping (0=uncolored, 1/2=colors)
   - Handle up to 8 pipes (nodes)

Timing:
- Computes result within 256 cycles after start
- Done signal asserted for 1 cycle when result is valid

Note: All coordinates use Q12.4 format (12 integer bits, 4 fractional bits).
