Design a Verilog module named 'longest_repeating_substring' that finds the length of the longest substring appearing at least twice.

Inputs:
  input clk // clock signal
  input rst_n // active-low reset
  input start // start computation
  input [15:0][7:0] str // fixed string of 16 characters (padded with zeros if shorter)
  input [3:0] length // actual string length (1-16)

Outputs:
  output reg [3:0] max_len // longest repeating substring length (0-15)
  output reg done // high when computation complete

Functionality:
1. On reset, set max_len = 0 and done = 0
2. When start is asserted:
   a. Check all possible substrings from longest to shortest
   b. For current_len = min(length-1,15) downto 1:
      - Compare all possible pairs of substrings of length current_len
      - If any duplicate found:
          * Set max_len = current_len
          * Set done = 1
          * Terminate processing
   c. If no duplicates found after checking all lengths:
          * Set max_len = 0
          * Set done = 1

Latency: Result valid within 256 clock cycles after start assertion (9-bit counter required).
