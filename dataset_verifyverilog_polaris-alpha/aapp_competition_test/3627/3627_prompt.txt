Design a Verilog module named 'minimum_climbing_energy' that
calculates the minimum initial energy needed to complete the climb.

Module interface:
module minimum_climbing_energy(
  input clk,
  input rst_n,
  input start,
  input [3:0] R,  // rows (2-4)
  input [3:0] C,  // columns (2-4)
  input [4:0] grid [0:15][0:15],  // flattened to 16x5b (max 4x4 grid)
  input [15:0] E_mask,  // End positions (1-hot per column)
  input [15:0] S_mask,  // Start positions (1-hot per column)
  output reg [7:0] min_energy,
  output reg done
);

Behavior:
- On reset: Initialize all energy states to maximum value (255)
- When start pulse is detected:
  1. Mark all start positions (S_mask) with initial energy 0
  2. Propagate energy values through grid for up to R*C*8 clock cycles
  3. For each cell, consider all 4-direction neighbors
  4. Energy required = max(current energy + cell_cost, 0)
  5. Implement parallel relaxation for all cells
- Done signal pulses when propagation completes
- Result is maximum energy requirement among all E positions

Timing:
- Input setup: 2 cycles before start
- Computation completes within 8*R*C clock cycles
- Output valid 1 cycle after done assertion

Note: Grid flattened as row-major 16 entries (each 5b signed).
Max supported grid size: 4x4 (R and C values ignore above 4)
