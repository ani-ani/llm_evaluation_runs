Design a sequential Verilog module 'min_energy_calculator' that computes minimum explosification energy. Inputs: clk, rst_n, start signal, n (3-bit), eight 16-bit energy values a[0]-a[7], and 4-bit query input k. Output: 32-bit min_energy with valid signal.

Module interface:
module min_energy_calculator(
  input clk,               // clock
  input rst_n,             // active-low reset
  input start,             // start computation
  input [2:0] n,           // neutron threshold (1-8)
  input [15:0] a0, a1, a2, a3, a4, a5, a6, a7, // energy values for k=1-8
  input [3:0] k_query,     // query neutron count (1-16)
  output reg [31:0] min_energy, // result
  output reg ready,        // precomputation complete
  output reg valid         // output valid
);
Behavior:
1. On reset: ready=0, valid=0
2. When start asserted: load a0-a7 into dp[1]-dp[8], precompute dp[9]-dp[16] using dp[i+j] = min(dp[i] + dp[j]) for all splits
3. Precomputation requires 16 clock cycles - ready asserts when done
4. Query k_query when ready=1 - output dp[k_query] on next cycle with valid=1
Timing: New results appear 2 cycles after query input when ready.
