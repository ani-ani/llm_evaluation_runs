Design a combinational Verilog module named 'min_lifts' that calculates a simplified shelf rearrangement cost.

Module interface:
module min_lifts(
  input [2:0] curr_shelf0_pos0, curr_shelf0_pos1, // current state shelf0 [pos0, pos1] (3-bit: 0=empty, 1-4=book ID)
  input [2:0] curr_shelf1_pos0, curr_shelf1_pos1, // current state shelf1 [pos0, pos1]
  input [2:0] targ_shelf0_pos0, targ_shelf0_pos1, // target state shelf0 [pos0, pos1]
  input [2:0] targ_shelf1_pos0, targ_shelf1_pos1, // target state shelf1 [pos0, pos1]
  output reg [2:0] min_lifts_out // -1 (3'b111) or minimal lifts estimate
);

Behavior description:
1. Verify total books match: non-zero count in current == target states
2. Check book positions: count mismatches between current and target
3. If valid arrangement possible (book IDs match): output mismatch_count
4. If impossible (different book sets): output 3'b111 (-1)
NOTE: Simplified logic ignores sliding moves - counts all displacements as lifts.

Fixed shelf dimensions: 2 shelves x 2 positions each
