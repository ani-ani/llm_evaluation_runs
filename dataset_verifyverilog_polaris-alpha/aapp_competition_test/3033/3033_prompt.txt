Design a sequential Verilog module named 'digit_product_solver' that finds the smallest positive integer X whose digits in base B multiply to N.

Module interface:
module digit_product_solver(
  input clk,          // clock signal
  input rst_n,        // active-low reset
  input start,        // start computation
  input [3:0] B,      // base (2-16)
  input [15:0] N,     // target product (1-65535)
  output reg [31:0] X,// result (0 if impossible)
  output reg impossible, // 1 if no solution
  output reg done      // high when computation complete
);

Behavioral description:
1. On reset: Clear all outputs and internal states
2. When start=1: Compute smallest X using algorithm below
3. Algorithm:
   a. Factorize N into digits (factors between 2 and B-1)
   b. Combine factors into digits <= B-1
   c. Sort digits to form smallest number (ascending order with trailing zeros)
   d. Output the number in base B (converted to decimal) or mark impossible
4. Latency: Result valid within 32 clock cycles after start

Implementation notes:
- Precompute valid factors (2-15 digits) using lookup tables
- Use successive division from highest possible digit (B-1 down to 2)
- If remaining N=1 after factorization, X is formed by sorted digits
- If impossible, set impossible=1 and X=0
- Support bases 2 through 16 (input B)
- All digits must be < B
