Design a sequential Verilog module named 'grey_cell_counter' that counts grey cells visited in K steps using zig-zag traversal.

Inputs:
  input clk,              // clock signal
  input rst_n,            // active-low reset
  input start,            // start computation (pulse high)
  input [7:0] R,          // rows (0-255)
  input [7:0] C,          // columns (0-255)
  input [15:0] K          // steps to count (1 to R*C)

Outputs:
  output reg [15:0] count,// grey cell count
  output reg done         // high when completed

Operation:
1. On reset or power-on, initialize count = 0, done = 0
2. When start asserted:
   a. Initialize step = 0, i = 0, j = 0, direction = 1 (right)
   b. Begin traversal: for each clock cycle, when step <= K
3. Traversal logic:
   - At each clock cycle:
     a. If step == K: assert done and stop
     b. Else: check current cell (grey if (i & j) == 0)
     c. Increment step counter
     d. Move to next cell:
        * RIGHT direction (j < C-1): j = j + 1
        * RIGHT (j == C-1): i = i + 1, toggle direction left
        * LEFT direction (j > 0): j = j - 1
        * LEFT (j == 0): i = i + 1, toggle direction right
4. Variable latency: Result valid after K+1 clock cycles.
5. Done remains high after completion until next reset/start.
