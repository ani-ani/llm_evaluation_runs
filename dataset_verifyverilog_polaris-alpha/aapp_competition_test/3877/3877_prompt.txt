Design a combinational Verilog module named 'bit_range_count' that calculates the number of 1s in a sequence derived from input n within a given range.

Module interface:
module bit_range_count(
  input [15:0] n,   // Original number (0 to 65535)
  input [4:0] l,    // Range start (1-32, 1-indexed)
  input [4:0] r,    // Range end (>= l, <=32)
  output reg [4:0] count  // Number of 1s in positions [l:r]
);

Behavior description:
For each bit position i (0 to 15) in n:
  1. Compute period = 2^(i+1)
  2. Compute start_offset = 2^i - 1
  3. Count occurrences where position mod period == start_offset within [l-1:r-1] (0-indexed)
  4. Multiply count by bit_value (n[i]) and accumulate
The module must compute this without clock cycles (combinational logic). Use bitwise operators and arithmetic to implement counting logic.
Ensure output count is the sum of all active bit contributions.
