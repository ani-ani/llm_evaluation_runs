Design a sequential Verilog module named 'sticker_message_assembler' that finds the minimal cost to assemble a message using up to 4 stickers with a maximum of 2 layers.
Module interface:
module sticker_message_assembler(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // starts computation when high
  input [63:0] message, // 8-character ASCII message (1 char per byte)
  input [2:0] num_stickers, // 0-4 stickers
  input [31:0] sticker_word_0, // 4-character sticker (padded with spaces)
  input [15:0] sticker_price_0,
  input [31:0] sticker_word_1,
  input [15:0] sticker_price_1,
  input [31:0] sticker_word_2,
  input [15:0] sticker_price_2,
  input [31:0] sticker_word_3,
  input [15:0] sticker_price_3,
  output reg done, // high when computation finished
  output reg [15:0] min_cost, // minimal cost (valid only when done=1)
  output reg impossible // high when solution impossible
);

Behavioral description:
- When start is asserted, compute minimal cost using DP with state tracking per position
- Each message position can be covered by 0/1/2 stickers
- Compare sticker substrings to message substrings (allow partial overlaps)
- Max message length: 8 chars, max sticker length: 4 chars, max 4 stickers
- Result available within 64 clock cycles (8 positions * 4 stickers * 2 layers)
- Use 16-bit cost arithmetic (max price 65535)
- Output impossible=1 if no valid solution exists
- Reset all outputs to zero when rst_n=0
