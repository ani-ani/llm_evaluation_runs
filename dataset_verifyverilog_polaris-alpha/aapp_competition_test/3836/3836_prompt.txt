Design a sequential Verilog module named 'debate_selector' that selects up to 8 spectators to maximize total influence while satisfying support constraints. The module takes spectator data inputs sequentially and outputs the maximum possible influence.

Module interface:
module debate_selector(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // pulse high to begin processing
  input [1:0] view_in, // political views (00, 01, 10, 11)
  input [12:0] influence_in, // 13-bit influence value (0-8191)
  input valid_in, // high when input data is valid
  output reg [12:0] max_influence, // maximum valid total influence
  output reg done // high when computation complete
);

Behavioral description:
1. Collect up to 8 spectator entries on rising clock edges when valid_in=1
2. When start=1, compute the optimal selection:
   a) Always include all '11' viewers first
   b) Pair '10' and '01' supporters (equal count of each)
   c) Add highest influence remaining viewers (from '00', '10', '01') up to constraints
3. Constraints: (2*supporters_for_Alice >= total) && (2*supporters_for_Bob >= total)
4. Output valid after 50 clock cycles max (done=1 pulse) with max_influence
5. If impossible, output max_influence=0
