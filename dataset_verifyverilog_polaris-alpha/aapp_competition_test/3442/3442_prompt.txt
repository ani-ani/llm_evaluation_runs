Design a sequential Verilog module named 'sheldon_checker' that determines if a 16-bit number matches the Sheldon binary pattern (alternating runs of N 1's and M 0's).

Module interface:
module sheldon_checker(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // start processing
  input [15:0] num, // input number to check
  output reg done, // high when check complete
  output reg is_sheldon // 1 if number is Sheldon number
);

Behavioral description:
- On reset or power-up: clear all registers
- When start is asserted: begin binary pattern analysis
- Processes bits from MSB to LSB (excluding leading zeros)
- Checks for pattern: N 1's followed by M 0's followed by N 1's... with at least one run of 1's
- Takes exactly 16 clock cycles to complete after start
- Outputs result on 'is_sheldon' when 'done' is high
States required:
  IDLE, FIRST_RUN_1, MEASURE_0, MEASURE_1, CHECK, DONE
Required functionality:
1. Skip leading zeros
2. Measure first run of 1's (sets N)
3. Measure next run of 0's (sets M if exists)
4. Verify subsequent runs alternate between N 1's and M 0's
5. Final run can be either N 1's or M 0's
6. Handle cases with only one run of 1's (special Sheldon case)
Timing: Result valid 16 cycles after start assertion.
