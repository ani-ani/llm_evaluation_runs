Design a sequential Verilog module named 'zamboni_controller' that simulates the PacMan zamboni algorithm for a max 8x8 ice rink with 16-step limit.

Module interface:
module zamboni_controller(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // start signal
  input [2:0] r, // rows (3-bit, max 8)
  input [2:0] c, // columns (3-bit, max 8)
  input [2:0] start_i, // start row (1-8)
  input [2:0] start_j, // start column (1-8)
  input [3:0] n, // num steps (4-bit, max 16)
  output reg [4:0] grid [0:7][0:7], // 8x8 grid (5 bits: 0=., 1=@, 2-27=A-Z)
  output reg done // high when finished
);

Behavior:
- Starts at position (start_i-1, start_j-1) when start is asserted
- Initial direction: up (00), color starts at 'A' (value 2)
- For each of numSteps iterations:
  1. Move stepSize steps in current direction (wrapping edges with modulo)
  2. Rotate direction 90° clockwise (00→01→10→11→00)
  3. Update color to next letter (wrap Z→A)
  4. Increment stepSize
- Each movement step updates current cell with current color
- Final position marked with '@'
- Implement with state machine and counter logic
- Final result available when done=1 (latency ~ (n^2)/2 cycles approx)
- All grid positions initialized to '.' (0) on reset

Direction encoding:
00 - up, 01 - right, 10 - down, 11 - left
