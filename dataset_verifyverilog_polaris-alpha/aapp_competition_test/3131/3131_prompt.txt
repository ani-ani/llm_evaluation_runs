Design a sequential Verilog module named 'piano_key_sum' that calculates the sum of maximum values for all combinations of K piano keys from N valid keys.

Module interface:
module piano_key_sum(
  input clk,              // System clock
  input rst_n,            // Active-low reset
  input start,            // Start calculation pulse
  input [2:0] N,          // Number of valid keys (1-8)
  input [2:0] K,          // Keys pressed per combination (1-8)
  input [31:0] keys [7:0], // Array of 8 key values (32-bit each)
  output reg [31:0] result, // Computed sum modulo 1000000007
  output reg done          // Asserted when computation complete
);

Behavior:
1. On reset (rst_n=0): result=0, done=0
2. When start=1: Begin computation
3. Uses internal 8-bit combination_mask (0-255) to generate all possible key combinations
4. For each combination_mask:
   a. Check if (count of set bits in combination_mask[7:0] &= (1<<N)-1) == K
   b. If true: Find maximum value among selected keys
   c. Accumulate maximum into result reg with modulo 1000000007
5. Processes 1 combination per clock cycle (256 max cycles)
6. Asserts 'done' when all combinations processed

Timing:
- Inputs sampled at positive clock edge
- Latency: 2-258 clock cycles (1 cycle init + 256 combinations)
- New computation can start when done=1

Note: All additions performed modulo 1000000007 (0x3B9ACA07)
