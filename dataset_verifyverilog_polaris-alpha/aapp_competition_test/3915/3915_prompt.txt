Design a sequential Verilog module named "prime_palindrome_compare" that finds the maximum n up to 1000 where π(n) * q ≤ rub(n) * p.

Input signals:
input clk,             // System clock
input rst_n,           // Asynchronous active-low reset
input [15:0] p,        // Numerator (1 ≤ p ≤ 10000)
input [15:0] q,         // Denominator (1 ≤ q ≤ 10000)
input start,           // Start computation (pulse high)

Output signals:
output reg [9:0] result,// Maximum n meeting condition
output reg done        // Asserted high when computation completes

Behavioral description:
1. Precomputes primes up to 1000 using embedded Sieve of Eratosthenes
2. Iterates from n=1 to 1000 over multiple clock cycles
3. At each n:
   - Counts primes (π)
   - Counts palindromes (rub)
   - Checks if π*q ≤ rub*p (using cross-multiplication)
4. Updates result whenever condition is met
5. Completes in 1000 clock cycles after start
6. Should infer block RAM for prime lookup table of 1000 bits

Timing:
- Reset initializes counters to zero
- On start pulse: begin iteration from n=1
- Output valid 1001 cycles after start (n results registered at each step)
- done asserts for 1 cycle at completion
