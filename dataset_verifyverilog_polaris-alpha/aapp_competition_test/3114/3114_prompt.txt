Design a Verilog module named 'directed_strong_connect' that checks if roads in a connected undirected graph can be directed to maintain strong connectivity.
Inputs:
  input clk,
  input rst_n,
  input start,  // Assert high to begin processing
  input [15:0] adj_matrix  // 4x4 adjacency matrix (1 bit per pair, symmetric)
Outputs:
  output reg possible,  // 1=YES, 0=NO
  output reg [15:0] directed_graph,  // Directed adjacency matrix output
  output reg done  // High when computation complete

Behavior:
1. Module accepts 4-node undirected graph via 4x4 adj_matrix (0s on diagonal)
2. When start=1, checks all edges (pairs where adj_matrix[i][j]=1):
   a. Temporarily remove each edge
   b. Check if remaining graph is still connected
   c. If any edge causes disconnection (bridge), possible=0
3. If no bridges (possible=1), output directed_graph:
   - Perform simple direction assignment (all edges directed away from node 0)
4. Latency: 16 cycles max (4 nodes * \u003c=4 edges)
5. Reset (rst_n=0) clears all outputs and internal state
