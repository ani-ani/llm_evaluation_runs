Design a sequential Verilog module named 'typo_checker' that identifies similarly spelled words using single-character edit rules.

Module interface:
module typo_checker(
  input clk, // Clock signal
  input rst_n, // Active-low reset
  input start, // Start computation
  input [7:0] char_in, // ASCII character input (lowercase)\//n  input word_end, // High for one cycle when word ends
  output reg done, // High when all comparisons complete
  output reg [15:0] matches [15:0][15:0] // match[i][j]=1 if word i similar to word j
);
Behavioral Description:
1. Stores up to 16 words (each up to 8 alphabetic characters).\//n2. Processes inputs until *** marker is detected (represented by all-zero char_in with word_end).
3. Compares each stored word pair (word A vs word B) to check if they differ by:
   - Single character delete
   - Single character insert
   - Single character replace
   - Adjacent character transpose
4. Latency: Output valid 16 clock cycles after start when input words stored.\//nImplementation Requirements:
- Store words as 8x8-bit arrays (64 bits per word)
- Use edit distance=1 logic (only single edits allowed)
- Output matches[i][j] = 1 whenever word i and j are similar (i < j)
