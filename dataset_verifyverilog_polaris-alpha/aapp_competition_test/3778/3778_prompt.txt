Design a sequential Verilog module named 'boomerang_target_config' that implements a simplified target configuration solver.
Inputs:
input clk,       // clock signal
input rst_n,     // active-low reset
input start,     // start computation (pulse high one cycle)
input [2:0] n,   // number of columns (1-8)
input [1:0] a_0, // column 0 hit count (0-3)
input [1:0] a_1,
input [1:0] a_2,
input [1:0] a_3,
input [1:0] a_4,
input [1:0] a_5,
input [1:0] a_6,
input [1:0] a_7
Outputs:
output reg valid,        // high when solution valid
output reg failed,       // high when no solution exists
output reg [2:0] t_row, // target row (1-8 when t_valid high)
output reg [2:0] t_col, // target column (1-8 when t_valid high)
output reg t_valid,      // target valid pulse (high one cycle per target)
output reg done          // high when processing complete
Behavior:
- At clock edge: If rst_n=0, reset all registers. If start=1, begin processing columns from index 0 to n-1 with propagation delay.
- Processes columns in reverse order (n-1 down to 0) as per problem requirements.
- Maintains state for pending connections (twos/threes requiring targets).
- Output sequence: All valid targets listed via t_row/t_col with t_valid pulses (1 per target) followed by done assertion. If failed, set failed=1 and done=1 with no target outputs.
- Latency: Requires maximum n+3 cycles after start. Each target coordinate appears one cycle after previous in output sequence.
- On completion: asserts done=1 for one cycle, then returns to idle state.
Constraints:
- Maximum n=8 (3-bit indices)
- Each row/column contains at most 2 targets (enforced internally)
- Outputs valid=1 on successful solution, failed=1 when impossible.
