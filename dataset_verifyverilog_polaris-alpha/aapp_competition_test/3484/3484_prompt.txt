Design a sequential Verilog module named 'superdoku_solver' that determines if a 4x4 grid with k pre-filled rows can form a Latin square and generates a valid solution using cyclic rotations.

Interface:
module superdoku_solver(
  input clk,  // Clock
  input rst_n,  // Active-low reset
  input start,  // Start computation (pulse high) 
  input [2:0] k,  // Number of pre-filled rows (0-4)
  input [31:0] grid_in,  // Flattened 4x4 grid (FOR RECEPTION ONLY)
  output reg valid_out,  // 1 = solution exists
  output reg [31:0] grid_out,  // Flattened 4x4 solution
  output reg done  // High when computation completes
);

Behavior:
1. When start is pulsed high:
   - Check first k rows for duplicate values within rows or columns
   - If duplicates detected: valid_out=0, done=1 (next cycle)
2. If valid: 
   - Copy pre-filled rows to output
   - Generate remaining rows by rotating previous row left by 1 position
   - Example: row1=1234 -> row2=2341 -> row3=3412 -> row4=4123
3. Output valid_out=1 and completed grid_out when done raised
4. Pipeline latency: done asserts 4 cycles after start for k=4, fewer cycles for smaller k

Bit assignments:
- Each cell = 2 bits (values 1-4 represented as 0-3 +1)
- grid_in/grid_out layout: [row0_c0,row0_c1,row0_c2,row0_c3,...,row3_c3]
- Duplicate checks use comparison networks for small rows/columns
