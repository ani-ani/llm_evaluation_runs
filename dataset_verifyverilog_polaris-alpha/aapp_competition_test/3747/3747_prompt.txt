Design a sequential Verilog module named 'bulbasaur_counter' that counts how many times the word "Bulbasaur" can be formed from input letters.

Module interface:
module bulbasaur_counter(
  input clk, // clock signal
  input rst_n, // active-low synchronous reset
  input start, // pulse high to begin processing
  input [5:0] str_len, // input string length (max 64)
  input [7:0] char_in, // current ASCII character input (requires valid_char=1)
  input valid_char, // high when char_in is valid
  output reg [7:0] bulbasaur_count, // number of "Bulbasaur" formations
  output reg done // high when computation complete
);

Behavioral description:
1. On reset or power-up, reset all counters.
2. When start pulses high:
   a. Initialize counters: B=0, u=0, l=0, b=0, a=0, s=0, r=0
   b. Begin processing characters one per clock cycle when valid_char=1
3. For each valid character:
   a. If char_in matches 'B','u','l','b','a','s','r' (case-sensitive):
      i. Increment corresponding counter
   b. Decrement remaining character count
4. After all characters processed:
   a. Calculate min(B, u/2, l, b, a/2, s, r) using integer division
   b. Output result on bulbasaur_count
   c. Pulse done high for 1 cycle

Latency: 64 clock cycles (max) for processing + 3 cycles for min calculation. Output valid 67 cycles after start.
