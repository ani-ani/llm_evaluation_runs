Design a sequential Verilog module named 'robot_position_checker' to determine if robot reaches target (a,b) after repeating commands.

Module interface:
module robot_position_checker(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // start computation
  input signed [15:0] a, // target x coordinate (16-bit signed)
  input signed [15:0] b, // target y coordinate (16-bit signed)
  input [15:0][1:0] cmd_string, // 16 command characters (2 bits each: U=00,D=01,L=10,R=11)
  output reg result, // 1 if reachable, 0 otherwise
  output reg done // high when computation complete
);

Behavior:
- On reset, initialize all registers
- When start=1:
  1. Compute cumulative positions after each command (x_steps[0-15], y_steps[0-15])
  2. After full command cycle, store total displacement (dx, dy)
  3. For each intermediate position (x_steps[i], y_steps[i]):
     a. Solve k such that: x_steps[i] + k*dx = a AND y_steps[i] + k*dy = b
     b. If valid non-negative integer k exists, set result=1
- Total latency ≤ 32 cycles. Result valid when done=1.
- Use state machine with states: IDLE, COMPUTE_STEPS, CHECK_CONDITIONS, DONE",
