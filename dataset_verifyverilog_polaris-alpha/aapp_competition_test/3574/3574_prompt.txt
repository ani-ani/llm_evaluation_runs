Design a combinational Verilog module named "magical_subarray" that finds the longest magical contiguous sub-array within a given query range.

A sub-array [a_i, a_{i+1}, ..., a_j] is magical if ∀k∈[i,j], min(a_i,a_j) ≤ a_k ≤ max(a_i,a_j).

Module interface:
module magical_subarray(
  input [7:0][7:0] arr,       // 8-element array (each element 8-bit unsigned)
  input [2:0] L,             // Query start (1-based index, 3-bit)
  input [2:0] R,             // Query end (1-based index, 3-bit)
  output reg [2:0] max_len   // Longest magical sub-array length in [L,R]
);

Behavior description:
1. Convert 1-based indices L/R to 0-based (subtract 1)
2. For all possible sub-arrays [i,j] within [L,R]:
   - Check if min(arr[i], arr[j]) ≤ all elements [i..j] ≤ max(arr[i], arr[j])
3. Find the maximum length j-i+1 of valid magical sub-arrays
4. Output must be combinationally computed.

Implementation notes:
- Use parallel comparators and nested loops unrolled for 8 elements
- Suggested approach: Generate all possible pairs i,j (i≤j) within [L,R]
  and check the magical condition in parallel for max length calculation.
