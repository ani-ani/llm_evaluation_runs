Design a sequential Verilog module named 'book_presentations' that calculates minimum presentations (bipartite graph maximum matching).
Module interface:
module book_presentations(
  input clk,          // system clock
  input rst_n,        // active-low reset
  input start,        // start computation
  input [15:0] bipartite_graph, // 4 boys x 4 girls (row-major: boy[3:0] x girl[3:0])
  output reg [2:0] max_matching,// matching size (0-4)
  output reg done      // result valid signal
);

Behavior description:
1. On reset (rst_n=0): Reset internal state, done=0, max_matching=0
2. When start=1: Begin computing maximum bipartite matching
3. Must complete within 16 clock cycles
4. Assert done=1 for 1 cycle with result when complete
5. Implement Hopcroft-Karp algorithm adaptation for 4-node graphs
6. Use state machine with matching tables for boys/girls
7. Input format: bipartite_graph[boy_index*4 + girl_index] (1=edge exists)
