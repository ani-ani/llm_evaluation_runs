Design a Verilog module named 'max_operations' that calculates the maximum number of valid division operations on a 4-element integer array with up to 4 good pairs. The module should be sequential and process factorizations through bipartite matching.

Inputs:
clk: clock signal
rst_n: active-low async reset
start: pulse to begin processing
arraysize [1:0]: number of elements (2-4)
paircount [1:0]: number of good pairs (1-4)
array1 [7:0] to array4 [7:0]: four 8-bit input numbers
pair1_i [1:0] to pair4_i [1:0]: pair indices i (0..3)
pair1_j [1:0] to pair4_j [1:0]: pair indices j (0..3)

Outputs:
result [7:0]: maximum operation count
done: high when computation completes

Behavior:
1. On start pulse, finds all prime factors for each array element (primes < 256)
2. Builds bipartite graph between even-index and odd-index factor slots
3. Uses iterative matching algorithm to find maximum bipartite matches
4. Outputs match count as result
5. Latency: ≤16 cycles after start
6. Use state machine with IDLE, FACTORIZE, BUILD_GRAPH, MATCHING, DONE states
