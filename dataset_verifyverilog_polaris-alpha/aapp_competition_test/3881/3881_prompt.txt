Design a sequential Verilog module named 'string_compressor' that computes the number of valid n-length strings compressible to 'a' using given operations.
Module interface:
module string_compressor(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // start computation
  output reg [15:0] result, // number of valid strings (max 46656)
  output reg done // high when computation complete
);

Behavioral description:
- Operations are predefined: 36 possible rules (2-char input, 1-char output) stored in 9-bit ROM.
- On start, iterate through all 6^n possible input strings (each char 3 bits, total 18 bits for n=6).
- For each string: perform compression steps until length=1 or no rule applies.
- Count strings that reduce to 'a'.
- n=2-6 supported by internally fixed parameter (change manually per test case).
- Result valid in ~46656*(n) cycles after start asserted (use counter-based implementation).
Latency: 6^6 * 5 = 233,280 cycles maximum latency.
Assume operation rules are hardcoded in ROM before synthesis.
