Design a sequential Verilog module named 'hash_word_counter' that calculates the number of N-length lowercase letter words with specific hash K modulo 2^M using dynamic programming. The hash is computed iteratively for each character position: hash_i = ((hash_{i-1} * 33) XOR (letter_ord)) % (2^M).

Module interface:
module hash_word_counter(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // pulse high to start computation
  input [3:0] N, // word length (1-10)
  input [24:0] K, // target hash value (0 <= K < 2^M)
  input [4:0] M, // modulo exponent (6-25, MOD = 2^M)
  output reg [46:0] count, // number of valid words
  output reg done // high when computation complete
);

Behavior:
1. Upon reset, all internal registers are cleared.
2. When start is pulsed high:
   a. Initialize DP table (size (N+1) x (2^25)) to track hash state counts.
   b. For each character position (1 to N):
      i. For each possible hash value from previous step:
         - For each lowercase letter (1-26):
            * Compute new_hash = (prev_hash*33) XOR letter_ord modulo 2^M
            * Accumulate counts
   c. After N steps, store DP[N][K] as final count.
3. Output 'count' and assert 'done' after N+2 clock cycles (1 for reset, N for processing, 1 for output).
Use non-blocking assignments and a state machine with states: IDLE, INIT, PROCESSING (N cycles), DONE.
