Design a sequential Verilog module named 'verse_pattern_matcher' that checks text against syllable patterns.

Module interface:
module verse_pattern_matcher(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start processing
  input [3:0][3:0] pattern, // 4 lines of syllable counts (4-bit per line)
  input [3:0][15:0][7:0] text_lines, // 4 lines, 16 chars each (ASCII)
  output reg match, // 1=YES, 0=NO
  output reg done // High when processing complete
);

Behavior:
1. On reset or power-up, set match=0 and done=0
2. When start=1:
   a. Process each text line sequentially:
      - Count vowels ('a','e','i','o','u','y')
      - Compare count to corresponding pattern line
   b. If ALL line counts match pattern, set match=1
   c. Set done=1 when complete
3. Processing completes in 20 clock cycles max (5 per line)

Implementation requirements:
- Use a state machine with states: IDLE, COUNT_VOWELS, COMPARE, DONE
- Use 4-bit counters per line to match pattern range (0-15)
- Treat character case uniformly (input is lowercase as per problem)
- Terminate early if any mismatch found
- Reset all state variables on rst_n=0
