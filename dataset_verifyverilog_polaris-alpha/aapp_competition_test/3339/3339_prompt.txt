Design a sequential Verilog module named "evenland_solution" that computes the number of ways to select roads for destruction in undirected graphs.
Module interface:
module evenland_solution(
  input clk,              // clock signal
  input rst_n,            // active-low reset
  input start,            // start computation
  input [2:0] n,          // number of intersections (max 8)
  input [3:0] m,          // number of roads (max 15)
  input [89:0] edges,     // packed edges (6 bits per edge * 15 edges)
  output reg [29:0] way, // number of ways mod 1000000009
  output reg done         // high when computation complete
);

Behavior description:
1. On reset (rst_n=0), initialize all internal registers and set done=0.
2. When start=1:
   a. Unpack edges into an 8x15 incidence matrix (even if n<8/m<15) where rows=intersections, columns=roads.
   b. Perform Gaussian elimination over GF(2) to compute matrix rank (max 8 cycles)
   c. Compute result = 2^(m - rank) mod 1000000009 using a lookup table
   d. Output result to 'way' and assert done=1 for 1 cycle.
3. Latency: Maximum 16 clock cycles (8 for GE + fixed overhead) after start assertion.

Implementation details:
- Edge unpacking: Each edge uses 6 bits [5:3] for node_a and [2:0] for node_b (1-based indexing)
- GF(2) row operations must maintain reduced row echelon form during elimination.
- Precompute powers of 2 mod 1000000009 for exponents 0-15
