Design a sequential Verilog module named 'unique_substrings' that processes 8-character strings ensuring all 5 substrings of length 4 are unique. Input characters are 5-bit values (0-25 for a-z).^
Module interface:^
module unique_substrings(^
  input clk,^
  input rst_n,^
  input start,^
  input [39:0] chars_in, // 8 chars (5 bits each)^
  output reg [39:0] chars_out, // rearranged string^
  output reg valid, // 1 = valid solution, 0 = impossible^
  output reg done // pulses high when complete^
);^
Behavior:^
1. On start, counts character frequencies (max 26 types)^
2. If any char appears >4 times: valid=0, chars_out=0^
3. Else: sorts characters then interleaves [first_half, second_half_reversed]^
4. Checks all 5 substrings for uniqueness^
5. Valid high only if solution found, done pulses after 20 cycles^
Latency: 20 clock cycles after start assertion.
