Design a sequential Verilog module named 'ad_remover' that processes a 16x16 ASCII grid to detect and remove ad images.

Interface:
module ad_remover(
  input clk,               // clock signal
  input rst_n,             // active-low reset
  input start,             // pulse high to begin processing
  input [7:0] grid [0:15][0:15],  // 16x16 ASCII input grid (8-bit chars)
  output reg [7:0] out_grid [0:15][0:15], // processed output grid
  output reg done          // high when processing complete
);

Behavioral Description:
1. Detect all images: Axis-aligned rectangles bordered by '+' (ASCII 43) that are at least 3x3
2. Track validity for each image via 8-entry LUT (max 8 images):
   - Check if image interior contains any invalid chars (excludes: A-Za-z0-9, '?', '!', ',', '.', ' ')
3. Among invalid images, flag smallest by area (width * height)
4. Replace flagged image's border and interior with spaces (ASCII 32)
5. Processing takes <= 256 cycles (16x16 grid * 1 cycle per cell)
6. Implement as 3-stage pipeline:
   - Stage 1: Border detection and image boundary recording
   - Stage 2: Parallel validity checks for all detected images
   - Stage 3: Area comparison and final grid modification
7. Use image boundary registers: [left, right, top, bottom] (4 bits each) per image entry
