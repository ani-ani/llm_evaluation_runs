Design a sequential Verilog module named 'max_non_square' that finds the largest non-square number in an 8-element array.

Module interface:
module max_non_square(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // start signal
  input signed [15:0] arr [0:7], // 8x16-bit signed array
  output reg signed [15:0] result, // max non-square found
  output reg done // high when result valid
);

Behavioral description:
1. When start is asserted, the module begins processing.
2. The module uses an internal state machine with these states: IDLE, COMPARE(8 cycles), DONE.
3. Each COMPARE cycle processes one array element (index 0-7):
   a. Negative numbers automatically qualify as non-squares
   b. For non-negative numbers: computes if the number is a perfect square
      by verifying if y = floor(sqrt(x)) satisfies y*y == x
4. Maintains maximum qualified value in a register.
5. After processing all 8 elements, asserts 'done' and outputs result on the 9th clock cycle.
6. Square root calculation must be combinational logic with ≤180 comparators.

Timing requirements:
- Output becomes valid 8 clock cycles after start assertion
- done signal asserts 1 cycle after final comparison
