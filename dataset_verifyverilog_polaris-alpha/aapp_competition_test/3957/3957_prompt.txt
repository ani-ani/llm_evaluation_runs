Design a sequential Verilog module named 'max_university_pairs' that calculates the maximum total distance of university pairings in a tree.

Module interface:
module max_university_pairs(
  input clk,                 // clock signal
  input rst_n,               // active-low reset
  input start,               // start computation
  input [2:0] node_count,    // actual nodes used (max 8)
  input [7:0] univ_mask,     // 8-bit mask where 1=has university
  input [7:0][2:0] adj_list, // 8-entry adjacency list (each entry 3-bit neighbor ID)
  output reg [4:0] max_sum,  // maximum total distance (5-bit)
  output reg done             // high when computation complete
);

Behavioral description:
1. The module should implement a simplified version of the problem with up to 8 nodes and 4 universities.
2. Operation:
   a) On reset: Initialize all registers
   b) On start: Perform BFS traversal to compute parent-child relationships
   c) Process nodes in reverse BFS order to calculate subtree university counts
   d) Accumulate total distance using min(child_count, total_universities - child_count) for each edge
   e) Assert 'done' when result is ready
3. Implementation strategy:
   - Use state machine with states: IDLE, TRAVERSE, COUNT_SUBTREES, CALC_SUM, FINISH
   - Parent tracking: 8-entry memory (3-bits per entry)
   - Subtree counts: 8-entry memory (3-bits per entry)
4. Timing: Result available after 15 clock cycles maximum from start assertion.
