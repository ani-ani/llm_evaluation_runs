Design a sequential Verilog module named 'function_counter' that counts valid functions modulo 1e9+7.
Module interface:
module function_counter(
  input clk,              // clock
  input rst_n,            // active-low reset
  input start,            // start computation
  input [4:0] p,          // prime (3 <= p <= 31)
  input [4:0] k,          // parameter (0 <= k < p)
  output reg [29:0] result, // count % 1e9+7
  output reg done         // high when done
);

Behavior:
1. On reset or idle, wait for start=1
2. When start=1:
   a. If k=0: Compute result = p^(p-1) mod 1e9+7
   b. If k=1: Compute result = p^p mod 1e9+7
   c. Else: Find smallest t>0 where k^t % p == 1 (multiplicative order), then compute c=(p-1)/t, s=p^c mod 1e9+7
3. Assert done when result is ready

Latency: Maximum 31 cycles for order-finding + 31 cycles for exponentiation (62 cycles worst-case). Use iterative calculation with modular multiplication.
