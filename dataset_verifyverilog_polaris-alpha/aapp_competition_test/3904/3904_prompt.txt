Design a sequential Verilog module named 'bracket_correction' that calculates the minimum reordering time for a bracket sequence.

Module interface:
module bracket_correction(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // start processing
  input [3:0] seq_len, // sequence length (1-16)
  input [15:0] bracket_seq, // packed bracket sequence (1= '(', 0=')')
  output reg [4:0] result, // correction time or -1
  output reg done // high when computation complete
);

Behavioral description:
1. On reset: result=0, done=0
2. When start is asserted:
   a. Verify seq_len is even and equal number of '(' and ')'
   b. If invalid, set result=5'b11111 (-1 in 5-bit 2's comp) 
   c. Else process the sequence over multiple clock cycles
3. Processing:
   - Track bracket balance within [-16,16] range
   - Detect contiguous segments with negative balance
   - Accumulate lengths of these segments as total time
4. Output valid 1 cycle after last character processed.
5. Latency: seq_len + 3 clock cycles max.
