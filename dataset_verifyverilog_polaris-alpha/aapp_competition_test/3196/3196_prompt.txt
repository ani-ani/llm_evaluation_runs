Design a sequential Verilog module named 'graph_path_counter' that counts distinct routes from node 1 to node 2 in a directed graph with max 4 nodes and 8 edges.
Module interface:
module graph_path_counter(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // assertion starts computation
  input [1:0] N, // number of towns-1 (0:1 town, 3:4 towns)
  input [2:0] M, // number of roads (1-8)
  input [31:0] edges // packed 8 edges: [3:0]=edge0_A,edge0_B; ... [31:28]=edge7_A,edge7_B
  output reg done, // high when computation complete
  output reg [31:0] result // [31]: 1=inf, else [30:0]=path_count mod 1e9
);
Behavior:
1. On start: load N, M, parse edges into adjacency matrix counts
2. Detect cycles reachable from node 0 (town 1) to node 1 (town 2)
3. If cycle found: set result[31]=1
4. Else: compute all simple paths count via DP, store mod 1e9 in result[30:0]
5. Latency: done asserts within 16 cycles after start assertion
Implement using FSM with states: IDLE, INIT, BUILD_ADJ, CYCLE_DETECT, COUNT_PATHS, DONE
