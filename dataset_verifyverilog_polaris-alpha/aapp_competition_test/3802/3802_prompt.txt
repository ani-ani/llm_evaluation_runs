Design a sequential Verilog module named 'virus_free_lcs' that finds the longest common subsequence (LCS) of two 8-character strings without containing a virus substring.
Module interface:
module virus_free_lcs(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // start computation
  input [7:0][7:0] s1, // first string (8 ASCII chars)
  input [7:0][7:0] s2, // second string (8 ASCII chars)
  input [7:0][7:0] virus, // virus substring (max 8 chars)
  output reg [63:0] result, // output LCS (8 chars packed as 64 bits)
  output reg done, // high when computation complete
  output reg valid // 1=valid LCS, 0=no solution
);

Behavior:
1. Precomputes KMP failure function for virus substring
2. Uses 3D DP table (8x8x8) tracking:
   - s1 position (3 bits)
   - s2 position (3 bits)
   - virus match state (3 bits)
3. Iterates through all positions over multiple cycles
4. After DP table filled, backtraces to reconstruct LCS
5. Output valid after 600 cycles max (512 states + traceback)
6. If no valid LCS exists, set valid=0 and result=0

Implementation notes:
- Use states: IDLE, KMP_PREPROCESS, DP_FILL, BACKTRACE, DONE
- All strings are fixed-length (pad unused chars with zeros)
- Strings compared using ASCII values (8 bits per char)
