Design a Verilog module named 'widget_packing' that computes the minimal empty squares for widget packing.
Module interface:
module widget_packing(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // pulse to start computation
  input [31:0] N, // number of widgets (up to 2^32-1)
  output reg [31:0] empty_squares, // minimal empty squares result
  output reg done // high when computation complete
);

Behavior:
1. On reset (rst_n=0), set outputs to 0, halt any computation
2. When start=1, begins computation:
   a. Compute H0 = floor(approx sqrt(N/2)) using 5-step binary approximation
   b. Check 4 H values: H0-2, H0-1, H0, H0+1 (clamped to min=1)
   c. For each valid H (satisfying H/2 ≤ W ≤ 2H):
      i. Compute W = ceil(N/H)
      ii. Adjust W to be within [ceil(H/2), 2H]
      iii. Calculate empty = W*H - N
   d. Track minimum empty value across valid H candidates
3. After 32 clock cycles, output minimal empty_squares and assert done=1

Assume 32-bit unsigned arithmetic for all operations. Use internal counters for iteration steps.
