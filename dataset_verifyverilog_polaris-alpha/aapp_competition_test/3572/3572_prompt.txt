Design a Verilog module named 'race_checker' that determines if a Hamiltonian cycle of exact length L exists for 4 control points.

Module interface:
module race_checker(
  input clk, // Clock signal
  input rst_n, // Active-low reset
  input start, // Start computation
  input [15:0] L, // Target distance (16-bit unsigned)
  input [15:0] dist_matrix [0:3][0:3], // 4x4 distance matrix (each entry 16-bit unsigned)
  output reg result, // 1 if possible, 0 if impossible
  output reg done // High when computation completes
);

Behavioral description:
1. The module should check all possible cycles for 4 points (total of 6 permutations). Start is fixed as point 0.
2. For each permutation (1-2-3-0, 1-3-2-0, etc.):
   a. Calculate total distance: dist[0][p1] + dist[p1][p2] + dist[p2][p3] + dist[p3][0]
   b. Compare against L
3. Output result=1 if any permutation matches L exactly, 0 otherwise
4. Sequential operation: Requires up to 10 clock cycles (reset, 6 permutations checks, final output)
5. On reset: All internal registers cleared, done=0
6. When start=1: Begin computation, set done=0
7. When computation completes: Set done=1 and hold result until next reset
8. Use a state machine with these states: IDLE, CALC_PERM_1, CALC_PERM_2, ..., CHECK_DONE
