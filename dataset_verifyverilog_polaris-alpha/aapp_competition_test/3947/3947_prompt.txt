Design a sequential Verilog module named 'max_removal_score' that calculates the maximum removal score from a fixed-size array using hardware-optimized stack processing.

Module interface:
module max_removal_score(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // start computation
  input [3:0] n, // array size (1-8)
  input [15:0] array_in [7:0], // 8-element array (16-bit each)
  output reg [18:0] max_score, // maximum score (19-bit)
  output reg done // high when computation completes
);

Behavioral description:
1. On reset: all registers cleared, done=0
2. When start is asserted:
   - Initialize stack with array elements
   - Process elements in sequence using stack operations
   - Score is accumulated by min(stack[-2], current_element) for eligible removals
3. Implement state machine:
   - States: IDLE, INITIALIZE, STACK_PROCESS, FINAL_PROCESS, DONE
4. Algorithm:
   a) Process input array (n elements) by pushing to stack
   b) While stack size >1: remove elements where stack[-1] <= min(stack[-2], next_in)
   c) Accumulate score += min(stack[-2], next_in) for each removal
   d) After main processing, handle remaining stack elements
5. Complete within 100 clock cycles (max latency)
6. Result available in max_score when done=1
