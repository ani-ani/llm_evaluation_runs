Design a Verilog module named 'team_selector' that finds optimal employee teams with dependency constraints.

Module interface:
module team_selector(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // pulse to start computation
  input [2:0] k, // team size (1-8)
  input [2:0] n, // number of employees (1-8)
  input [15:0] s_arr [0:7], // salaries (16-bit each)
  input [15:0] p_arr [0:7], // productivities (16-bit each)
  input [2:0] r_arr [0:7], // recommenders (employee numbers)
  output reg [31:0] max_ratio, // Q16.16 fixed-point format
  output reg done // high when result valid
);

Behavior:
1. When start=1, begin computation.
2. Module tests all possible subsets of first 'n' employees.
3. For each subset:
   - Validate 1) exactly 'k' members selected
   - Validate 2) all selected employees have recommender=0 or in subset
4. For valid subsets:
   - Calculate sum_p = sum(selected p_arr)
   - Calculate sum_s = sum(selected s_arr)
   - Track subset with maximum sum_p/sum_s ratio using fraction comparison
5. After all subsets (256 max), perform division: max_ratio = (best_sum_p << 16) / best_sum_s
6. Assert done=1 for 1 cycle when complete (requires ~1024 cycles + division latency)

Notes:
- sum_p/sum_s ratio comparisons use cross-multiplication to avoid division
- Fixed-point division uses iterative algorithm (32 cycles)
- Outputs held until next start pulse"
