Design a sequential Verilog module named 'non_wool_sequence_counter' that computes the number of non-wool sequences mod 1000000009 for n≤16, m≤16.

Module interface:
module non_wool_sequence_counter(
  input clk,
  input rst_n,
  input start,
  input [3:0] n,      // max sequence length 16 (4 bits)
  input [15:0] m,    // max 2^16-1 elements (16 bits)
  output reg [31:0] result, // mod 1000000009 (32 bits)
  output reg done
);

Behavior: 
1. On reset (rst_n=0), set result=0, done=0
2. When start=1:
   a. Compute k = (2^m - 1) %% 1000000009
   b. For i in 0 to n-1:
       result = (result * (k - i)) % 1000000009
3. Set done=1 when complete

Latency: n+2 cycles (1 cycle init, n cycles multiplication, 1 cycle finish)
Use FSM: IDLE(0), INIT(1), COMPUTE(2), DONE(3)
Use modular multiplication for 32-bit operations.

ASSERTIONS:
- n ≤ 16
- Optimize for max 16 cycles compute state
