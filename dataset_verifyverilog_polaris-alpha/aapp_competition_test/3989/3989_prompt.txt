Design a Verilog module named 'div7_digit_rearranger' that takes an 8-digit input and rearranges it to be divisible by 7.

Input requirements:
- Input must contain exactly one each of digits 1,6,8,9 and four additional arbitrary digits (0-9)
- No leading zeros in input or output

Module interface:
module div7_digit_rearranger(
  input [31:0] digits_in,  // 8-digit input (4-bits per digit, MSD-first)
  output reg [31:0] rearranged_out  // 32-bit output (8 digits)
);

Behavioral description:
1. Remove 1,6,8,9 from input digits leaving remaining 4 digits
2. Compute (remaining_num * 10000) % 7 using mod-efficient calculation
3. Use precomputed permutations map:
   - permutation[7] = {1869, 1968, 1689, 6198, 1698, 9861, 1896} (encodings stored in ROM)
4. Select permutation where: (current_remainder + (perm*1)) %7 == 0
5. Output format: remaining_digits_sorted_desc + selected_perm + trailing_zeros (if any)

Implementation notes:
- Use combinational logic - no clock required
- Precompute all 5040 permutations modulo 7 for 1689 combos and store mapping
- Sort remaining digits in descending order before processing
- Process zeros last
