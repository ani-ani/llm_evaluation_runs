Design a sequential Verilog module named 'mirko_game_solver' that finds Mirko's starting number

Module interface:
module mirko_game_solver(
  input clk,                      // system clock
  input rst_n,                    // active-low reset
  input start,                    // pulse high to start processing
  input [7:0] K,                  // window size [1-150]
  input [7:0] L,                  // required happy count [0-K]
  input [7:0] M,                  // happy threshold [1-150]
  output reg [15:0] result,       // solution (start number or -1)
  output reg done                  // high when result valid
);

Behavior:
- On reset: result=0, done=0
- When start=1: Begin search from S=1 upwards
- For each candidate S (<=65535): Check K numbers [S, S+K-1]
  - Happy if (num <= M) or (num is prime)
  - Count happy numbers in window
  - If count == L: Output S, assert done=1
  - Else: Increment S and continue
- If S>65535: Output -1, assert done=1
- done remains high until next start

Timing:
- Variable operation latency (depends on found S)
- Prime check implements trial division (2 to sqrt(num)) per number

State machine states:
  IDLE, CHECK_S, CHECK_NUM, CHECK_PRIME, UPDATE, DONE
