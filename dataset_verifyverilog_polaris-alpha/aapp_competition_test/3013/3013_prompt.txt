Design a Verilog module named 'spiral_exit_point' computing the detachment point.
Module interface:
module spiral_exit_point(
  input clk, // system clock
  input rst_n, // active-low reset
  input start, // pulse high to start computation
  input [31:0] b_q248, // spiral parameter in Q24.8 format (24 integer, 8 fractional bits)
  input [31:0] tx_q248, // target x in Q24.8 (range -10,000 to 10,000)
  input [31:0] ty_q248, // target y in Q24.8 format
  output reg [31:0] x_out_q248, // computed x exit point
  output reg [31:0] y_out_q248, // computed y exit point
  output reg done // high when computation completes
);

Behavioral description:
1. On start pulse, begin iterative Newton-Raphson solver (16 iterations max)
2. Use 16-bit angle precision (phi) with Q8.8 format for angular operations
3. Compute spiral coordinates: r = b * phi
4. Compute tangent direction using numerical differentiation
5. Check projectile trajectory intersection with target
6. Requires 128 clock cycles from start to done (8 cycles per iteration)
7. Use ROM-based lookup tables for sin/cos approximations (12-bit address)
8. Fixed-point arithmetic operations for Q24.8 and Q8.8 formats
9. Reset sets all outputs to 0, done=0

Functional requirements:
- Target Q24.8 format must support values in [-10000, 10000]
- Error tolerance: Results must be within 0.0001 (absolute error) of reference
- Support minimum b = 0.01 (Q24.8 value = 0x0000019)
