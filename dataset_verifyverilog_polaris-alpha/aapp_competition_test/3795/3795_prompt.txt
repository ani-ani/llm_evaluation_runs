Design a sequential Verilog module named 'currency_exchange' that minimizes remaining rubles after currency exchange. 

Inputs:
  input clk,             // clock
  input rst_n,           // active-low reset
  input start,           // start signal (pulse high to begin)
  input [15:0] n,        // initial rubles (1-65535)
  input [7:0] d,         // dollar rate (30-100)
  input [7:0] e          // euro rate (30-100)

Outputs:
  output reg [15:0] min_rubles, // minimized rubles result
  output reg done                // high when computation completes

Behavior:
1. When start=1, compute minimal remaining rubles using: min_rubles = min((n - i*5*e) % d) for i=0 to min(n/(5*e), 256)
2. Process completes in ≤ 256 cycles
3. Output 'done' pulses high for 1 cycle when result is ready
4. If remainder becomes 0 at any iteration, finish early

Implementation:
- 5*e cannot exceed 500 (needs 9 bits: [8:0] e5)
- Use 16-bit subtractors and comparators
- Sequential state machine with IDLE, CALC, DONE states
- Use 8-bit counter for iterations (max 256 steps)
