Design a Verilog module named "team_rating_equalizer" that implements the friend rating equalization algorithm for FIXED 4 players.

Module interface:
module team_rating_equalizer(
  input clk,                // 125 MHz system clock
  input rst_n,              // active-low reset
  input start,              // pulse high to start processing
  input [7:0] r0,           // rating for player 0 (8-bit unsigned)
  input [7:0] r1,           // rating for player 1
  input [7:0] r2,           // rating for player 2
  input [7:0] r3,           // rating for player 3
  output reg [7:0] final_R, // final equal rating
  output reg [3:0] match_vec, // current match vector (1 bit per player)
  output reg valid_match,     // high when match_vec is valid
  output reg done             // high when ratings equalized
);

Required behavior:
1. On reset (rst_n low), set all outputs to 0
2. When start is pulsed high:
   - Load initial ratings into internal registers
   - Begin processing matches
3. Algorithm operation:
   a. While max(r0-r3) != min(r0-r3):
      i. Select between 2-5 players with highest ratings (with 0 being 4th player limit)
      ii. Decrement their ratings (minimum 0)
      iii. Output match vector for current match (valid_match pulses high for one cycle)
   b. When equalized:
      i. Output final rating in final_R
      ii. Set done high
4. Output timing:
   - match_vec/valid_match update on clock edge (sync output)
   - Processing completes within 100 cycles

Implementation notes:
- Use an FSM to track: INIT, FIND_MAX, SELECT_PLAYERS, UPDATE, CHECK, DONE states
- Maintain 4 x 8-bit registers for current ratings
- Max player selection logic must always choose between 2-4 players per match
- Support back-to-back operation (startable after done is set)
