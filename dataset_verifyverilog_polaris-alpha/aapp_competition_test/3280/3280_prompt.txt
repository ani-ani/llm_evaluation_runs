Design a Verilog module named 'show_recorder' that calculates maximum recordable shows for scaled inputs.
Module interface:
module show_recorder(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // start computation
  input [2:0] n, // number of shows (1-8)
  input [1:0] k, // number of slots (1-4)
  input [31:0] show_times[0:15], // flat array: show_times[2*i] = x_i, show_times[2*i+1] = y_i
  output reg [2:0] count, // maximum shows recorded
  output reg done // high when computation complete
);

Behavior:
1. On reset: clear internal state, done=0
2. On start pulse: begin processing
3. First sort shows by end time (y_i) using bubble sort
4. Then allocate shows to slots using greedy algorithm: for each show, check if it can fit in any slot (x_i >= slot's last end time)
5. Maintain k slot trackers with their last end times
6. Output count of allocated shows when done
7. Latency: sorting (64 cycles worst for n=8) + allocation (8 cycles) = max 72 cycles from start
Use states: IDLE, SORTING, ALLOCATING, DONE.
Assume all inputs stable until done asserted.
