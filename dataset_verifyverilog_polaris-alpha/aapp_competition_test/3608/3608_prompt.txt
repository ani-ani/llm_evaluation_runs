Design a Verilog module named 'task_selector' that computes the number of ways to choose tasks with difficulty constraints. The module must implement the following:
- Inputs: clk (clock), rst_n (active-low reset), start (start computation), a[7:0][31:0] (8x32-bit exact difficulty counts), b[6:0][31:0] (7x32-bit flexible difficulty counts).
- Outputs: result[31:0] (32-bit result modulo 1000000007), done (high when computation completes).

Behavior:
1. When start is asserted, compute result using recurrence relation:
   dp[0] = 1
   dp[1] = a[0] * dp[0] (mod 1e9+7)
   For i >= 2: dp[i] = (dp[i-1] * a[i-1] + dp[i-2] * b[i-2]) mod 1000000007
2. Process all 8 elements (fixed N=8).
3. Use a state machine:
   - IDLE: Wait for start
   - PROCESSING: Compute dp values sequentially (1 cycle per step)
   - DONE: Assert result and done signal
4. Latency: +10 cycles (reset:2, compute:8)

Module interface:
module task_selector(
  input clk,
  input rst_n,
  input start,
  input [7:0][31:0] a,
  input [6:0][31:0] b,
  output reg [31:0] result,
  output reg done
);
