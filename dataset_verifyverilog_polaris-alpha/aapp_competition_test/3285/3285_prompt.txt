Design a sequential Verilog module named 'sds_finder' that finds the minimal step n where m first appears in the smallest different sequence (SDS).

Module interface:
module sds_finder(
  input clk,                   // clock signal
  input rst_n,                 // active-low reset
  input start,                 // start computation (pulse high)
  input [6:0] r,               // initial value A1 (1-100)
  input [7:0] m,               // target value (1-255)
  output reg [4:0] n,          // result step (1-16)
  output reg done              // high when computation completes
);

Behavioral description:
1. On reset or power-on: Initialize all registers
2. When start is asserted:
   a. Initialize A_current = r
   b. Initialize used_values[255:0] with 1 << r set
   c. Initialize used_diffs[255:0] with 0
   d. Set current_step = 1
3. At each clock cycle:
   a. If current_step <= 16 and !done:
      i. Check if m is in used_values OR used_diffs - if found, set n = current_step and done=1
      ii. Else: Find smallest d >0 not in used_values or used_diffs
      iii. Update A_next = A_current + d
      iv. Update used_values with A_next
      v. Compute all new differences |A_next - existing values| and update used_diffs
      vi. Increment current_step
4. If current_step >16 without finding m, set n=16 and done=1 (saturation)

Timing: Maximum latency 16 clock cycles after start is asserted.
Note: Store used values and differences using 256-bit registers (1 bit per possible value 0-255)
