Design a sequential Verilog module named 'palindrome_parts' that finds the minimum number of equal-length palindromes from a rearranged string. String length n (max 16) must be divisible by k.
Inputs:
  input clk,                 // clock
  input rst_n,               // active-low reset
  input start,               // pulse high to start processing
  input [3:0] n,             // string length (1-16)
  input [15:0][7:0] s,       // string characters (ASCII)
Outputs:
  output reg [3:0] k,        // number of palindromes (1-16)
  output [15:0][7:0] parts,  // palindromes (16 chars each)
  output reg done            // high when computation completes

Behavior:
1. On reset: clear all outputs, done=0
2. When start=1:
   a. Count character frequencies (case-sensitive)
   b. Calculate min k where:
      - k >= number of odd-frequency chars
      - n mod k = 0 (equal-length parts)
   c. Distribute characters to form k palindromes:
      - Each palindrome has length n/k
      - Rearrange characters optimally
3. Output valid 100 cycles after start. Done signal pulses for 1 cycle.
4. Use shift registers/FSM for palindrome construction.

Implementation notes:
- Support max n=16 (4-bit width)
- Characters stored as ASCII (8 bits)
- Internal storage for 16 character frequency counters (6-bit each)
- Use state machine: IDLE, COUNT, CALC_K, BUILD, DONE
- Fixed latency: 100 clock cycles max
