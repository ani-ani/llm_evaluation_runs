Design a sequential Verilog module named 'cup_probability' that computes the irreducible fraction p/q modulo 10^9+7 after processing a_k exponents.

Module interface:
module cup_probability(
  input clk, // system clock
  input rst_n, // active-low reset
  input start, // pulse high to begin computation
  input [3:0] k, // number of exponents (1-8, 0=invalid)
  input [15:0] a [0:7], // 8-element array of 16-bit exponents (unused elements when k<8)
  output reg [31:0] p, // numerator mod 10^9+7
  output reg [31:0] q, // denominator mod 10^9+7
  output reg done // high when computation completes
);

Behavior:
1. On reset or start=0: all outputs=0, done=0
2. When start=1:
  - Compute β = (2^(product of a_i) / 2) mod 10^9+7
  - Compute parity_flag = 1 if any a_i is even else -1
  - Compute α = (β + parity_flag) * 3^{-1} mod 10^9+7
3. Timing: Takes k+3 clock cycles (1 init + k exponent steps + 1 modular step + 1 output)
4. Implementation:
  - Use sequential modular exponentiation
  - Multiply exponents cyclically over k cycles
  - Store parity flag during exponent processing
  - Final p=α and q=β when done=1
5. Constants:
  mod = 32'd1000000007
  inv2 = 32'd500000004 (2^{-1} mod 10^9+7)
  inv3 = 32'd333333336 (3^{-1} mod 10^9+7)
6. Output done signal remains high until next start.
