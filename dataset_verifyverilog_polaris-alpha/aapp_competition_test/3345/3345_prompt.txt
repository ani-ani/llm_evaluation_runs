Design a sequential Verilog module named 'dog_walk_distance' that calculates the minimum distance between two dogs walking their fixed-length paths.

Module interface:
module dog_walk_distance(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Pulse high to start computation
  // Shadow39;s path (max 16 points)
  input [3:0] shadow_segment_count, // Number of segments = points-1 (1-15)
  input [15:0] shadow_x [0:15], // X coordinates (Q16.16)
  input [15:0] shadow_y [0:15], // Y coordinates (Q16.16)
  // Lydia39;s path (max 16 points)
  input [3:0] lydia_segment_count, // Number of segments = points-1 (1-15)
  input [15:0] lydia_x [0:15], // X coordinates (Q16.16)
  input [15:0] lydia_y [0:15], // Y coordinates (Q16.16)
  output reg [15:0] min_distance, // Minimum distance (Q16.16)
  output reg done // High when computation complete
);

Behavior description:
1. On reset: Clear done flag and internal state
2. When start=1: Load path data and begin computation
3. Compute minimum Euclidean distance between dogs:
   a. For each Shadow segment (0 to shadow_segment_count)
   b. For each Lydia segment (0 to lydia_segment_count)
   c. Calculate closest approach between line segments
   d. Track global minimum with Q16.16 fixed-point
4. Output valid after max 225*(calculation cycles) 
Latency: Result available after 3500 clock cycles max.
Fixed-point format: All coordinates and distances use Q16.16 (16 integer bits, 16 fractional bits).
