Design a sequential Verilog module named 'number_display_processor' that implements instruction execution logic.
Inputs:
input clk,             // system clock
input rst_n,           // active-low reset
input start,           // start execution when high
input [7:0] input_num, // number N to display (0-255)
Outputs:
output reg [7:0] display_out, // value sent to display
output reg done               // high when DI executed

Behavior:
- Three 8-bit registers: A, X, Y
- Stack: 40 x 8-bit memory (depth 40) with stack pointer
- Implement all instruction types (PH, PL, AD, ZE, ST, DI)
- Execute instructions in sequence until DI encountered
- After reset (rst_n=0):
  * Registers initialized to unknown (simulate X value)
  * Stack pointer reset to 0 (empty)
- When start=1: Begin executing instruction sequence
- Latency: Variable cycles (1-40) depending on instruction count
- DI instruction: Sets display_out <= reg_value and done <= 1

Implementation requirements:
- Use finite state machine with states: IDLE, FETCH, EXECUTE, DONE
- Stack operations must handle underflow (PL when empty causes done=1)
- AD instruction computes (stack[sp-1] + stack[sp-2]) modulo 256
- Non-blocking assignments for sequential logic
