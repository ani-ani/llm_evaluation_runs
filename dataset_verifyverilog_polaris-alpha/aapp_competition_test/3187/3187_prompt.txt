Design a sequential Verilog module named 'protest_location_optimizer' that finds the optimal protest location meeting distance constraints.

Module interface:
module protest_location_optimizer(
  input clk,                         // System clock
  input rst_n,                       // Active-low reset
  input start,                       // Start computation
  input [2:0] n,                     // Number of citizens (1-8)
  input [7:0] data_x [0:7],          // Citizen x coordinates (8x8-bit)
  input [7:0] data_y [0:7],          // Citizen y coordinates (8x8-bit)
  input [7:0] d,                     // Maximum travel distance
  output reg [11:0] total_distance,  // Minimal total distance
  output reg impossible,             // 1 = no valid location
  output reg done                    // 1 = computation complete
);

Behavior:
1. On reset, clear all outputs and internal registers.
2. When start is asserted:
   a. Sort x and y coordinate arrays using 8-element sorting networks
   b. Calculate x_med = sorted_x[3] and y_med = sorted_y[3] (median for n=8)
   c. For each citizen:
      - Calculate individual distance = |x_i - x_med| + |y_i - y_med|
      - Check distance <= d for all citizens
   d. If all citizens within max distance:
      - Sum individual distances => total_distance
      - Set impossible=0
      Else: Set impossible=1, total_distance=0
   e. Assert done for 1 cycle when complete (20 clock latency)

Timing:
- Computation starts on rising edge of 'start'
- Output valid 20 clock cycles after start assertion
- All outputs maintain value until next computation
