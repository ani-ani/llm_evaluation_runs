Design a Verilog module named 'pikeman' that calculates maximum solvable problems and minimum penalty using scaled parameters.

Module interface:
module pikeman(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // start computation
  input [3:0] N, // number of problems (max 8)
  input [15:0] T, // total contest time (max 65535)
  input [6:0] A, // generator param (max 127)
  input [6:0] B, // generator param (max 127)
  input [6:0] C, // generator param (max 127, C >= t0)
  input [6:0] t0, // initial time (max 127)
  output reg [3:0] num_problems, // solved count (0-8)
  output reg [29:0] penalty, // penalty mod 1000000007
  output reg done // high when computation complete
);

Behavioral description:
1. On start pulse:
   - Generate sequence t[0] to t[N-1], each t_i = ((A*t_{i-1} + B) % C) + 1
   - Store in 8-element array (7-bit elements)
2. Sort array in ascending order using 7-stage bubble sort (N=8 requires ~56 cycles)
3. Accumulate sorted times until total exceeds T:
   - Count max problems solvable (num_problems)
   - Sum times with rolling modulo 1000000007 (penalty)
4. Output valid when done=1 (expected latency ~100 cycles)
Use state machine with states: IDLE, GENERATE, SORT, ACCUMULATE, DONE.
