Design a sequential Verilog module named 'color_code_verifier' that checks whether a given sequence is a valid n-bit color code with palette P.

Module interface:
module color_code_verifier(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // start verification
  input [3:0] n, // number of bits (support up to 4)
  input [3:0] p, // palette size (1-4)
  input [15:0] palette, // bitmask where palette[i-1]=1 means i is in P
  input [15:0][3:0] sequence_in // 16 elements of 4-bit values
  output reg valid, // 1 if valid color code, 0 if invalid
  output reg done // asserted when verification complete
);

Behavioral description:
- When start is asserted, begin verification of the 2^n-length sequence
- On each clock cycle, compare i-th and (i+1)-th elements
- Calculate Hamming distance between consecutive elements
- Check if distance is present in palette bitmask
- If any invalid transition found, assert valid=0 and done=1
- For n=4, verification completes in 15 clock cycles after start
- If all transitions valid, assert valid=1 and done=1
- If n < 4 (test case), only verify first 2^n elements
- Reset should clear all internal state and outputs
