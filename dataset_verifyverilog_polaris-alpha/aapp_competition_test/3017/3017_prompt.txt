Design a sequential Verilog module named 'count_power_substrings' that counts numbers from 0 to n containing a given power-of-2 substring.

Module interface:
module count_power_substrings(
  input clk,              // clock signal
  input rst_n,            // active-low reset
  input start,            // start computation
  input [15:0] n,         // max number to check (0 ≤ n ≤ 65535)
  input [4:0][3:0] power_str, // 5-digit BCD substring (each digit 4 bits, MSD first)
  input [2:0] substr_len  // actual substring length (1-5)
  output reg [16:0] count, // match count
  output reg done          // high when computation completes
);

Behavior:
- On reset: count=0, done=0, internal state=IDLE
- When start=1: begin counting numbers k from 0 to n (inclusive)
- For each number k: convert to 5-digit BCD (padded with leading zeros)
- Check if any contiguous sub-digits of k's 5-digit representation match power_str[0:substr_len-1]
- If match found, increment count
- After processing k == n: assert done=1 and hold count

Implementation notes:
- Use a state machine: IDLE, CONVERT_BCD (optional), CHECK_SUBSTRING, INCREMENT, DONE
- Conversion to BCD can use combinational logic or unrolled double dabble
- Substring check must compare all possible starting positions (0 to 5 - substr_len)
- Latency: Requires ~1 cycle per number + 1 cycle startup
