Design a Verilog module named 'elder_scroll_display' that implements a simplified viewport text display with scroll position calculation.
Inputs:
input clk,                // clock
input rst_n,              // active-low reset
input start,             // pulse high to start processing
input [3:0] view_w,      // viewport width (3-8 chars)
input [2:0] view_h,      // viewport height (3-5 lines)
input [2:0] first_line,  // starting line index (0-7)
input [15:0][7:0] text_lines [0:7],  // 8 lines of text (16 chars each, 7-bit ASCII)
Outputs:
output reg [7:0][7:0] display_out [0:4],  // 5 viewport lines (8 chars each)
output reg [3:0] thumb_pos,              // scroll thumb position (0-4)
output reg done                         // high when output is valid

Behavior:
1. On start pulse:
   a. Process text_lines through line-wrapping algorithm:
      - Words separated by spaces (0x20)
      - Wrap lines when next word exceeds view_w
      - Truncate words longer than view_w
   b. Store wrapped lines in internal buffer (max 8 lines)
   c. Compute thumb_pos = ((view_h-3)*first_line)/(total_lines-view_h) (integer division)
   d. Extract view_h lines starting at first_line for display_out
2. Timing:
   - Takes 15 clock cycles to process (done pulses 1 cycle after completion)
   - Inputs captured at start rising edge
3. Scrollbar symbols:
   - Top: ^ (0x5E)
   - Thumb: X (0x58) at thumb_pos
   - Bottom: v (0x76)
   - Other lines: space (0x20)
4. Display border format excluded (focus on text content)
