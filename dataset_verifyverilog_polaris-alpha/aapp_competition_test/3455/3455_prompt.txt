Design a Verilog module named 'lane_safety_calculator' that computes the maximum safety factor for an autonomous car switching from lane 0 to lane N-1.

Module interface:
module lane_safety_calculator(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // start computation
  input [1:0] N, // number of lanes (2-4) - 2 bits
  input [2:0] M, // total cars (1-5) - 3 bits
  input [9:0] R, // sensor range (1-1024) - 10 bits
  input [1:0] car_lane [0:4], // 5 cars, 2 bits each
  input [9:0] car_length [0:4], // 5 cars, 10 bits each
  input [9:0] car_distance [0:4], // 5 cars, 10 bits each
  output reg [31:0] safety_factor, // Q16.16 fixed-point
  output reg impossible, // 1 if no path exists
  output reg done // high when computation complete
);

Behavioral description:
- Computes maximum safety factor (minimum distance to any car during lane transitions)
- Uses fixed-point Q16.16 format (16 integer + 16 fractional bits)
- Compares car positions considering sensor range limit (areas beyond R considered occupied)
- Implements sequential state machine: IDLE, CALC_PATHS, FIND_MAX_MIN, DONE
- Latency: 3 cycles from start assertion to done
- Safety factor = max(min distance) across valid transition paths from lane0 to laneN-1
- If no valid path exists, set impossible=1 and safety_factor=0
