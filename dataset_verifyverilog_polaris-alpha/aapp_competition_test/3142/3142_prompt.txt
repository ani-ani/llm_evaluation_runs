Design a sequential Verilog module named 'digit_sum_finder' that counts numbers in range [A,B] with digit sum S and finds the smallest such number.
Inputs:
  input clk,                // clock
  input rst_n,              // active-low reset
  input start,              // start computation
  input [15:0] A,           // range start (0-9999)
  input [15:0] B,           // range end (>= A)
  input [5:0] S             // target digit sum (1-36)
Outputs:
  output reg [13:0] count,  // number of matches (0-10000)
  output reg [15:0] smallest_num, // smallest matching number
  output reg done           // high when computation completes
Behavior:
1. On reset, all outputs go to 0.
2. When start is asserted:
   - Initialize current_num = A
   - count = 0
   - smallest_num = 65535 (invalid)
3. For each clock cycle while current_num <= B:
   a. Split current_num into 4-digit BCD: thousands + hundreds + tens + units
   b. Calculate digit_sum = thousands + hundreds + tens + units
   c. If digit_sum == S:
      - Increment count
      - Update smallest_num if current_num < smallest_num
   d. Increment current_num
4. When current_num > B, set done=1 (hold until reset)
Latency: Completes in (B-A+1) clock cycles maximum. Special case if A>B completes immediately.
Digit Extraction:
  - thousands = current_num / 1000
  - hundreds = (current_num % 1000) / 100
  - tens = (current_num % 100) / 10
  - units = current_num % 10
