Design a sequential Verilog module named 'pillar_collapse' that determines which internal pillar to remove to cause maximum destruction.
Module interface:
module pillar_collapse(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [3:0] n, // Number of pillars (1-8)
  input [15:0] b [0:7], // Pillar strengths (8 elements, 16-bit each)
  output reg [3:0] max_damage, // Max destruction count
  output reg [3:0] pillar_idx, // Optimal pillar index (0-7)
  output reg done // High when computation complete
);

Behavioral description:
1. On reset: Clear all outputs and internal states
2. When start is asserted:
   a. Iterate over each possible pillar removal (0 to n-1)
   b. For each removal case:
      i. Simulate weight redistribution
      ii. Calculate how many pillars collapse (pressure > strength)
      iii. Track the maximum destruction count and corresponding index
3. After all cases processed:
   a. Output max_damage and associated pillar_idx
   b. Assert done signal

Latency requirement: Output valid within 100 clock cycles after start
Note: Pressure distribution logic - each pillar supports 1000 kN per unit area where area extends halfway to adjacent pillars. When a pillar is removed, neighbors must support additional area.
