Design a sequential Verilog module named 'max_substring_rearrange' that optimizes a binary string to maximize occurrences of a target substring.

Module interface:
module max_substring_rearrange(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // pulse high to start computation
  input [15:0] s_in, // input schedule string (left-aligned)
  input [4:0] s_len, // actual length of s_in (1-16)
  input [15:0] t_in, // target substring (left-aligned)
  input [4:0] t_len, // actual length of t_in (1-16)
  output reg [15:0] result, // optimized output string
  output reg ready // high when output valid
);

Behavioral description:
1. Operation starts on start pulse (1 cycle)
2. Counts number of '0's in s_in and t_in
3. Calculates maximum repeatable suffix from t_in using prefix function (for overlaps)
4. Constructs output with sequence:
   a. One full t_in copy (if counts allow)
   b. Repeatedly append the maximum overlap suffix from step 3
   c. Append remaining '0's followed by remaining '1's
5. Adjusts all operations to preserve original '0'/'1' counts

Timing:
- Output valid 16-32 cycles after start pulse
- ready goes high when computation completes

Specifications:
- Use bit-level operations for counting and string manipulation
- Implement centralized FSM with states: IDLE, COUNT, PREFIX_CALC, BUILD_RESULT, DONE
- Pad unused output bits with zeros
