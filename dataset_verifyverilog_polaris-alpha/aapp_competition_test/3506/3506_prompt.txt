Design a sequential Verilog module named 'cheer_scheduler' that calculates optimal football cheerleading outcomes for an 8-minute game (4-min halves).

Inputs:
input clk,              // clock
input rst_n,            // active-low reset
input start,            // start computation
input [1:0] n,          // Sportify cheerleaders (0-3, ONLY n=1 SUPPORTED)
input [2:0] t,          // minutes per cheerleader (1-7, use t=3 for testing)
input [1:0] m,          // opponent intervals (0-3)
input [3:0] interval_0_a, interval_0_b,  // opponent interval 0 (minutes 0-7)
input [3:0] interval_1_a, interval_1_b,  // opponent interval 1
input [3:0] interval_2_a, interval_2_b,  // opponent interval 2

Outputs:
output reg [2:0] sportify_goals,  // goals scored (0-4 max)
output reg [2:0] spoilify_goals,  // goals scored (0-4 max)
output reg done                   // high when result ready

Behavior:
1. Compute opponent cheer counts (0-3 per minute) from input intervals
2. Generate ALL valid Sportify schedules (3-minute slots for single cheerleader)
3. For each schedule:
   a. Compute Sportify cheers (0/1 per minute)
   b. Compare cheer counts minute-by-minute
   c. Track 2-min streaks PER HALF (minutes 0-3 and 4-7)
   d. Score goals when 2 consecutive mins favor one team
4. Select result with max(sportify_goals-spoilify_goals), then max(sportify_goals)

Timing:
- Latency: 100 cycles max (asserts done when complete)
- All intervals must satisfy a < b and 0 ≤ a,b ≤ 8
