Design a Verilog module named 'tram_explosion_counter' that calculates explosion count for a simplified 4x4 grid.
Ports:
input clk, // clock signal
input rst_n, // active-low reset
input start, // start computation
input [1:0] rows, // log2(4)=2 bits (1-4 rows)
input [1:0] cols, // log2(4)=2 bits (1-4 cols)
input [15:0][1:0] grid, // flattened 4x4 grid (0=empty, 1=X, 2=L)
output reg [1:0] explosions, // max 3 explosions
output reg done // high when complete
Behavior:
1. On reset: explosions=0, grid registers initialized.
2. Start=1 begins processing:
   a. Compute squared Euclidean distance between all X and L
   b. For each seat L, count how many X have this as closest seat
   c. For each seat: if multiple equal min-distance X, increment explosions
   d. Remove involved X/L from next round
   e. Repeat until no more seats or people left
3. Algorithm uses Q16.16 fixed-point (32-bit total: 16.16)
4. Use 5 processing states: IDLE, COMPUTE_DIST, FIND_MIN, CHECK_COLLISION, UPDATE_GRID
5. Output 'done' pulses after final explosion count (5 cycles max)
