Design a Verilog module named 't9_keypad' that implements a simplified T9 keypad optimizer.
Inputs:
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start processing
  input [7:0][7:0] dict [0:7], // 8 dictionary words (8 chars each, 8-bit ASCII)
  input [7:0][7:0] query_word, // Query word (8 chars max)
Outputs:
  output reg [7:0] key_seq [0:31], // Key sequence (32 elements max)
  output reg [5:0] seq_len, // Sequence length
  output reg done // Asserted when result ready

Behavior:
1. On reset, clear outputs
2. When start asserted:
   a. Map each character of query_word to digits (2-9) using fixed mapping
   b. Split into consecutive parts matching dictionary words
   c. For each split part:
      - Find its position in the dictionary (0=most common)
      - Compute minimal U/D presses: min(pos, 8-pos-1) 
   d. Choose chain of parts with minimal total presses: (word length + U/D count + R presses between parts)
3. Format output per spec:
   - Digits 2-9 as ASCII chars (e.g., 8'h32)
   - 'R' as 8'h52
   - U/D presses as sequences: 'U' (8'h55) + ASCII count digits
4. Sequence available 10 cycles after start with done asserted

Note: Dictionary matching is exact (case-sensitive). Limit splits to maximum 4 parts.
