Design a sequential Verilog module named 'strange_rectangle_counter' that counts distinct point sets selectable via rectangular areas for up to 8 points.

Module interface:
module strange_rectangle_counter(
  input clk, // Clock signal
  input rst_n, // Active-low reset
  input start, // Start computation
  input [7:0] point_x [0:7], // X-coordinates (8 points, 8-bit each)
  input [7:0] point_y [0:7], // Y-coordinates (8 points, 8-bit each)
  input [2:0] num_points, // Actual number of points (1-8)
  output reg [15:0] count, // Result count of distinct sets
  output reg done // High when computation complete
);

Behavior:
1. On reset or startup: Initialize all registers.
2. When start is high:
   a. Sort points by Y-coordinate in descending order (using bubble sort)
   b. Process points from highest to lowest Y:
      i. Activate current point's X-coordinate in active list
      ii. Update count using current active X-coordinates
3. Computation completes after 200 clock cycles max.
4. Assert done when result is ready (count valid).
