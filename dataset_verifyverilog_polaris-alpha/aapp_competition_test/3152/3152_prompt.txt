Design a Verilog module named 'consecutive_subsequence_cost' that calculates the sum of costs for all consecutive subsequences of an array.
Inputs:
  input clk,              // clock
  input rst_n,            // active-low reset
  input start,            // start computation
  input [2:0] N,          // array size (1-8)
  input [7:0] element_0,   // array elements (max 8 elements)
  input [7:0] element_1, 
  input [7:0] element_2, 
  input [7:0] element_3, 
  input [7:0] element_4, 
  input [7:0] element_5, 
  input [7:0] element_6, 
  input [7:0] element_7, 
Outputs:
  output reg [29:0] result,  // sum modulo 1e9 (last 9 digits)
  output reg done          // high when result ready

Behavior:
- Supports arrays up to 8 elements, each 8-bit (1-255)
- Computes sum = Σ (min(sub) * max(sub) * length(sub)) for all consecutive subsequences
- Outputs sum % 1_000_000_000 (last 9 digits)

Latency:
- Result valid within (N*(N+1))/2 + 5 clock cycles after start
- Use state machine with states: IDLE, COMPUTE_MIN_MAX, ACCUMULATE, FINISH

Implementation notes:
1. Iterate through all start indices (0 to N-1)
2. For each start, iterate through end indices (start to N-1)
3. Compute min, max, and length (end-start+1) for current subsequence
4. Accumulate min * max * length into running sum
5. Apply modulo 1e9 operation before output
