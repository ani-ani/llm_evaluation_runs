Design a sequential Verilog module named 'lunch_bill_processor' that finds acceptable beverage/main dish pairs for a fixed lunch price P under the following constraints:
1. Beverage < main dish (B < M)
2. All digits in B, M and P must be unique (no duplicates across any entries)
3. Output pairs sorted by increasing beverage price

Module interface:
module lunch_bill_processor(
  input clk,              // System clock
  input rst_n,            // Active-low reset
  input start,            // Start computation (P must be stable)
  input [7:0] P,          // Fixed lunch price (≤255)
  output reg [7:0] B_out, // Beverage price (valid when valid=1)
  output reg [7:0] M_out, // Main dish price (valid when valid=1)
  output reg valid,       // Pulsed high for 1 cycle per valid pair
  output reg done,        // High when processing complete
  output reg [7:0] count  // Total valid pairs found
);

Behavior:
- When reset, all outputs = 0 (except rst_n asynchronous)
- On start=1: Iterate B from 1 to P/2 (B < M condition)
- Each clock cycle:
  • Compute M = P - B (ignore if B >= M)
  • Check all digits in B/M/P are unique
  • If valid: Output B/M, pulse valid=1, increment count
  • Increment B each cycle until B > P/2
- Assert done=1 when finished

Digit uniqueness:
- Extract 3 digits from B (hundreds/tens/units) and M (same)
- P digits extracted once at start (hundreds/tens/units)
- All 9 digits (3 per value) must be unique (use 10-bit flag vector)
- Zeros are valid digits and must be unique
