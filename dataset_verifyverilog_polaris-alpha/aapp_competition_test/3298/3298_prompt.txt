Design a combinational Verilog module named 'unsorted_perm_count' that computes the number of entirely unsorted permutations for unique element sequences.

Module interface:
module unsorted_perm_count(
  input [2:0] n,      // Sequence length (1-8)
  output reg [31:0] count  // Number of unsorted permutations
);

Description:
The output count must equal the number of permutations with no sorted elements, precomputed as follows:
- n=1: 0
- n=2: 0
- n=3: 2
- n=4: 14
- n=5: 90
- n=6: 646
- n=7: 5242
- n=8: 47622
Implement using a lookup table. Array contents are irrelevant (assumes unique elements).
