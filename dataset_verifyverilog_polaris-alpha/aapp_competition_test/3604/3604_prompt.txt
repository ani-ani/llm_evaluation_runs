Design a Verilog module named 'sensor_clique_finder' that finds the largest subset of sensors (8 max) where each pair is within squared distance d_sq.

Module interface:
module sensor_clique_finder(
  input clk, // Clock (unused in combinational implementation)
  input rst_n, // Active-low reset (connect to 1 if unused)
  input [2:0] n, // Number of sensors (3 bits, max 8)
  input [15:0] d, // Max distance (unsigned)
  input [7:0][15:0] x_pos, // Array of 8 x-coordinates (16-bit signed)
  input [7:0][15:0] y_pos, // Array of 8 y-coordinates (16-bit signed)
  output reg [3:0] subset_size, // Size of largest clique (0-8)
  output reg [7:0] subset_mask // One-hot mask of selected sensors (bit 0 = sensor 1)
);

Behavior:
1. Compute adjacency matrix where adj[i][j] = 1 when squared distance ≤ d^2
2. Check all possible 2^8 subsets (unrolled combinatorial logic)
3. For each subset: verify subset is a clique (all pairs connected)
4. Track largest valid clique size and corresponding sensor mask
Note: Squared distance = (x_i-x_j)^2 + (y_i-y_j)^2 (use 32-bit intermediates)
Latency: Full combinatorial (single-cycle evaluation)
