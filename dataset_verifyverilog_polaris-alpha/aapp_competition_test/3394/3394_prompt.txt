Design a sequential Verilog module named 'pizza_delivery_optimizer' that calculates the maximum customer wait time for scaled problem parameters.

Module interface:
module pizza_delivery_optimizer(
  input clk,                   // Clock signal
  input rst_n,                 // Active-low reset
  input start,                 // Start computation
  input [1:0] node_count,      // Number of nodes (2-4)
  input [2:0] edge_count,      // Number of edges (1-4)
  input [3:0][1:0] edge_src,   // Source nodes (4 edges max)
  input [3:0][1:0] edge_dest,  // Destination nodes (4 edges max)
  input [3:0][7:0] edge_weight,// Edge weights (0-255)
  input [1:0] order_count,     // Number of orders (1-3)
  input [2:0][7:0] order_spawn,// Order placement time (3 orders max)
  input [2:0][1:0] order_loc,  // Order locations (3 orders max)
  input [2:0][7:0] order_ready,// Order ready time (3 orders max)
  output reg [7:0] max_wait,   // Maximum wait time
  output reg done              // Computation complete
);

Behavioral description:
1. Precompute all-pairs shortest paths using scaled Floyd-Warshall algorithm.
2. Process orders in strict FIFO sequence according to ready times.
3. Track current delivery location and time.
4. For each order, calculate delivery time as max(current_time, t_i) + travel_time
5. Compute wait time = delivery_time - s_i
6. Maintain maximum observed wait time.

Latency: Output valid within 200 clock cycles after start assertion.
Module should implement states: IDLE, LOAD_DATA, COMPUTE_GRAPH, PROCESS_ORDERS, DONE.
Use distance matrix size [3:0][3:0][7:0] for 4-node graph (node indices 0-3 where pizzeria=0).
