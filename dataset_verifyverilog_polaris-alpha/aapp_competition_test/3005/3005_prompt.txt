Design a sequential Verilog module named "string_factoring_weight" that calculates the weight of a maximal factoring for up to 16-character strings.

Module interface:
module string_factoring_weight(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // start calculation
  input [3:0] length, // input string length (1-16)
  input [7:0] chars [15:0], // 16x8-bit ASCII characters
  output reg [4:0] weight, // resulting weight
  output reg done // high when calculation complete
);

Behavioral description:
- On reset, initialize all registers
- When start is asserted:
  1. Find all possible irreducible factorings by checking substring repetitions
  2. Calculate weights for each valid factoring (number of unique characters, ignoring repetitions)
  3. Track minimum weight found
- Algorithm: Use a state machine that:
  a) Iterates through possible substring lengths (1 to length/2)
  b) Compares all possible substrings for repetition patterns
  c) Calculates weight for irreducible factorings
  d) Stores the minimum weight encountered
- Only consider factorings where the same substring appears consecutively at least twice
- Output valid after maximum 256 clock cycles when done is asserted
- Assume all characters are uppercase letters (ASCII 0x41-0x5A)
