Design a sequential Verilog module named 'ncpc_partition' that finds the smallest division year Y for up to 6 participants.

Inputs:
input clk,               // Clock
input rst_n,            // Active-low reset
input start,            // Start computation
input [2:0] n,          // Number of participants (4-6)
input [2:0] a, b,        // Participant pair (1-6)
input [5:0] year,        // Meeting year (0-60 represents 1948-2008)
input valid_pair,        // High when pair/year data is valid

Outputs:
output reg [5:0] Y,     // Smallest valid year (0=1948, 60=2008)
output reg impossible,  // High when no solution exists
output reg done         // High when computation completes

Behavior:
1. On reset: Clear all internal state.
2. When start=1: Begin processing.
3. During valid_pair=1: Store meeting year for pair (a,b) in adjacency matrix (max 6x6 entries).
4. After all pairs stored: Iterate through possible Y values (1948-2008) checking:
   - Whether exists partition where Group A (pre-Y meetings) size ≤ floor(2n/3)
   - Group B (post-Y meetings) size ≤ floor(2n/3)
   - All pairs in same group obey meeting year constraints
5. Find and output smallest Y meeting conditions or set impossible=1.
6. Assert done when complete.

Timing:
- Latency: Up to 60*(2^6) = 3840 cycles worst-case (for 6 participants)
- Input pairs accepted over multiple cycles using valid_pair
- Starts computation when start asserted

Implementation note: Use adjacency matrix stored in register array (15 entries for all possible pairs in 6 participants).
