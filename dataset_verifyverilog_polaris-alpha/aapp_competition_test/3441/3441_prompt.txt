Design a sequential Verilog module named 'max_road_counter' that calculates the maximum number of new one-way roads that can be added without creating new round trips.

Module interface:
module max_road_counter(
  input clk, // Clock signal
  input rst_n, // Active-low reset
  input start, // Start computation
  input [7:0] adjacency_matrix, // 8x8 adjacency matrix (1-bit per cell, row-major)
  input [4:0] current_road_count, // Current roads count (0-16)
  output reg [5:0] max_new_roads, // Result: maximum new roads
  output reg done // High when computation complete
);

Behavior:
1. On reset, clear all internal states
2. When start=1:
   a. Compute Strongly Connected Components (SCCs) for the input graph
   b. Construct DAG of SCC components
   c. Calculate: total_possible = n*(n-1) - current_road_count
      minus (sum(s² for SCC sizes s) - existing internal edges)
      minus (cross_SCC_edges - existing cross edges)
   d. Output result when complete
3. Latency: Valid output appears 20 cycles after start assertion

Implementation notes:
- Max 8 towns (n=8) represented by 3-bit indices
- Use iterative SCC detection optimized for small graphs
- SCC computation uses edge-parallel adjacency checking
- Maintain component labels in 8x3-bit register array
- Output limited to 6 bits (0-63 possible new roads)
