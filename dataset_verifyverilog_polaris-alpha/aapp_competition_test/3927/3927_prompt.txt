Design a sequential Verilog module named 'weight_identifier' that finds the maximum number of identifiable weights after one query.
Inputs:
input clk // Clock
input rst_n // Active-low reset
input start // Start computation
input [3:0] n // Number of weights (1-8)
input [31:0] weights // 8x4-bit weights flattened (weights[31:28]=a7, ..., [3:0]=a0)
Outputs:
output reg [3:0] result // Maximum identifiable weights (0-8)
output reg done // High when computation complete

Functionality:
1. On reset: result=0, done=0
2. When start=1: Compute maximum weights where a sum k*m exists that identifies unique subsets.
3. Algorithm: For each possible k (1 to n), m=weight*count combinations, check whose subset sums have exactly binom(cnt, k) solutions.
4. Set result to maximum such count.
5. Raise 'done' after 100 cycles (fixed latency).

Constraints:
- Precomputed binom table for n≤8
- Subset sums computed via iterative parallel adders
- Only consider weights ≤15 (4-bit inputs)
