Design a combinational Verilog module named 'bonbon_arrangement' that determines if a valid bonbon arrangement exists.

Inputs:
  input [1:0] r      // Number of rows (2 bits, valid range 2-4)
  input [1:0] c      // Number of columns (2 bits, valid range 2-4)
  input [4:0] a      // Count of A-flavor bonbons (5 bits)
  input [4:0] b      // Count of B-flavor bonbons (5 bits)
  input [4:0] c_in   // Count of C-flavor bonbons (5 bits)

Output:
  output possible   // High (1) if valid arrangement exists, low (0) otherwise

Behavior:
The module calculates total bonbons = r * c and compares each flavor count against half this total. If a, b, and c_in are all <= (r*c)/2, possible is driven high. Otherwise, possible is driven low. The calculation uses integer arithmetic (no floating point).
