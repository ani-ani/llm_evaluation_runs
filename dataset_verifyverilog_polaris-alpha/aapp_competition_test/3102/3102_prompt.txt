Design a Verilog module named `house_number_counter` that counts valid house numbers in a range [L,R] (16-bit inputs) meeting these criteria: 1) No digit contains '4', and 2) Count of 6/8 digits equals count of other digits (excluding leading zeros).

Module interface:
module house_number_counter(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start processing
  input [15:0] L, // Lower bound
  input [15:0] R, // Upper bound
  output reg [15:0] count, // Valid house count
  output reg done // High when counting complete
);

Behavior:
1. On reset: count=0, done=0, state=IDLE
2. When start=1: current_number = L, count=0, state=COUNTING
3. Each cycle: Check if current_number ≤ R
  - Convert to 5-digit decimal (handle leading zeros)
  - Skip number if any digit is '4'
  - From first non-zero digit, count 6/8 digits (lucky) and others (non-lucky)
  - If lucky_cnt == non_lucky_cnt, count += 1
  - Increment current_number
4. When current_number > R: done=1, state=IDLE
Latency: R-L+2 cycles (1 cycle setup + 1 per number + 1 cycle done)
