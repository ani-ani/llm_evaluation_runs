Design a sequential Verilog module named 'collatz_sum' that computes the sum S of f(X) values from X=L to X=R, where f(X) counts steps to reach 1 (even: X/=2, odd: X+=1).

Module interface:
module collatz_sum(
  input clk,               // clock
  input rst_n,             // active-low reset
  input start,             // start computation (pulse high)
  input [15:0] L,          // interval start (1-65535)
  input [15:0] R,          // interval end (L <= R)
  output reg [20:0] S,     // accumulated sum (max 21 bits)
  output reg done          // high when computation complete
);

Behavioral description:
- On reset: Initialize all registers
- On start pulse: Begin processing X from L to R inclusive
- For each X value: Calculate f(X) via iterative steps (add 1 when odd/divide when even)
- Accumulate f(X) results into S register
- Assert 'done' when all X in [L,R] processed
- Compute f(X) with max 32 iterations per value (output stays 0 until done)

Implementation notes:
- Use a state machine with states: IDLE, COMPUTE_FX (for current X), SUM_LOOP
- Requires internal counters for current X and iteration count
- Parameter MAX_ITER=32 (6-bit counter sufficient)
- No modulus required since sum S < 2^21 (2097152)
