Design a sequential Verilog module named 'robotic_arm_controller' that calculates segment positions to minimize distance to target using fixed-point arithmetic.

Module interface:
module robotic_arm_controller(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // start calculation
  input [2:0] N, // number of segments (1-8)
  input [15:0] L_0, // segment 0 length (Q16.0)
  input [15:0] L_1, // segment 1 length
  input [15:0] L_2, // segment 2 length
  input [15:0] L_3, // segment 3 length
  input [15:0] L_4, // segment 4 length
  input [15:0] L_5, // segment 5 length
  input [15:0] L_6, // segment 6 length
  input [15:0] L_7, // segment 7 length
  input [31:0] target_x, // Q16.16 format
  input [31:0] target_y, // Q16.16 format
  output reg [31:0] x_0, y_0, // segment 1 tip
  output reg [31:0] x_1, y_1, // segment 2 tip
  output reg [31:0] x_2, y_2, // ...
  output reg [31:0] x_3, y_3, 
  output reg [31:0] x_4, y_4, 
  output reg [31:0] x_5, y_5, 
  output reg [31:0] x_6, y_6, 
  output reg [31:0] x_7, y_7, // last segment tip
  output reg done // high when done
);

Behavioral description:
1. On reset or when start=0, clear all outputs
2. When start=1, compute segment positions sequentially over 8 clock cycles
3. Implement vector direction adjustment: Each segment position = previous position + (unit_vector * L_i)
4. Unit vector should point towards target from current position
5. Fixed-point operations: use Q16.16 format (32-bit) for coordinates
6. Perform magnitude scaling: calculate unit vector by normalizing (dx, dy)
7. If current-to-target distance < 0.01 (Q16.16: 655), point directly towards target
8. Each segment position calculation takes 1 clock cycle after start
9. Done signal goes high after N clock cycles (latency = N)
10. Must support N=1 to N=8 segments
11. Segment lengths L_i are Q16.0 format (integer only)
