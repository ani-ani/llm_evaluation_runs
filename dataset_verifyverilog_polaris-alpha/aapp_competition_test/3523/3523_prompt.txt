Design a sequential Verilog module named 'coin_payer' that calculates maximum coins for exact payment.

Inputs:
input clk, // clock
input rst_n, // active-low reset
input start, // pulse high to start computation
input [7:0] P, // price (0-255 cents)
input [3:0] N1, // count of 1c coins (0-15)
input [3:0] N5, // count of 5c coins (0-15)
input [3:0] N10, // count of 10c coins (0-15)
input [3:0] N25, // count of 25c coins (0-15)

Outputs:
output reg [5:0] coins_used, // max coins used (0-60)
output reg impossible, // high when no solution
output reg done // high when computation complete

Behavior:
1. On reset: all outputs = 0
2. When start is pulsed:
   - Compute maximum coins using greedy approach (25c→10c→5c→1c)
   - Use min(available_coins, remaining_P / denomination) for each step
   - Total computation takes 4 clock cycles after start
3. On cycle 4:
   - If remaining P == 0: set coins_used = total coins used
   - Else: set impossible = 1
   - Assert done = 1 for one cycle
4. State machine has 4 states: IDLE, CALC_25, CALC_10, CALC_5, CALC_1

Timing:
- Output valid 4 cycles after start assertion
- done pulses high for 1 cycle when result ready
