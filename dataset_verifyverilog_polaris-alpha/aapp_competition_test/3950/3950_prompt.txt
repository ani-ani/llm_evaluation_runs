Design a sequential Verilog module named 'query_array_validator' that verifies if an array can be produced by query operations.

Module interface:
module query_array_validator(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start validation
  input [2:0] n, // Array size (1-8 elements)
  input [5:0] q, // Max query value (1-63)
  input [5:0] a0, input [5:0] a1, input [5:0] a2, input [5:0] a3, // Array elements [0:3]
  input [5:0] a4, input [5:0] a5, input [5:0] a6, input [5:0] a7, // Array elements [4:7]
  output reg valid, // 1 if array can be produced
  output reg [5:0] restored_0, restored_1, restored_2, restored_3, // Restored array output
  output reg [5:0] restored_4, restored_5, restored_6, restored_7,  // [4:7]
  output done // High when validation complete
);

Behavior:
1. On start pulse, validate an array of size n where:
   - Elements are between 0 and q (0 means any 1-q)
   - Ensure there\'s at least one occurrence of q (adjust if missing zero exists)
   - Enforce the peak condition: values must not decrease before current peak\'s last occurrence
2. Implements the core algorithm from Python code with:
   - Stack-based peak tracking (max depth 4)
   - Zero replacement strategy
3. Latency: Output valid after 32 clock cycles max
4. On completion:
   - valid=1 if possible, with restored array
   - valid=0 if impossible (restored_* outputs undefined)
5. Uses 2 state bits: IDLE=0, PROCESSING=1, DONE=2

Timing:
- Start must be held high for 1 cycle
- Processing begins next cycle, takes ceil(n+log2(n)) cycles
- Done asserts for 1 cycle when complete

Implementation note: Use non-blocking assignments for all state changes.
