Design a sequential Verilog module named 'sign_distance_average' that calculates the average distance between all pairs of signs in a road network tree.

Module interface:
module sign_distance_average(
    input clk, // Clock signal
    input rst_n, // Active-low reset
    input start, // Start computation
    input [1:0] n, // Number of ports (2-4)
    input [15:0] dist_matrix [5:0], // Flattened distance matrix (6 elements)
    output reg [31:0] avg_distance, // Q16.16 fixed-point format
    output reg done, // High when computation complete
    output reg impossible // High if calculation impossible
);

Behavior:
1. On reset or when start=0, clear internal states
2. When start=1:
   a. Reconstruct tree from distance matrix
   b. Calculate pairwise distances between all signs
   c. Compute average of all sign pairs
3. Output final average in Q16.16 format
4. Set done=1 when complete (takes 20 cycles max)
Note: Output impossible=1 if topology cannot be determined (input validation assumed valid per problem constraints).

Implementation requirements:
- Use iterative algorithms bounded by small n (max 4 ports)
- Sign locations calculated as integer steps along edges
- Fixed-point division for final average calculation",
