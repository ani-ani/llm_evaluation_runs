Design a Verilog module named 'worst_rank_calculator' that computes the worst possible rank for the first contestant.

Ports:
input clk,               // clock signal
input rst_n,             // active-low reset
input [3:0] num_contestants, // number of contestants (2-4)
input [3:0] num_contests,    // number of contests (2-4)
input [6:0] scores [0:3][0:3], // 4 contestants x 4 scores (7-bit each, 0-101)
output reg [2:0] worst_rank,  // worst possible rank (3-bit)
output reg done               // high when computation complete

Operation:
1. Calculate current aggregate scores (sum top 4 scores) for all contestants
2. Simulate worst-case scenario for final contest:
   - Other contestants may get maximum possible points (101) in final contest
   - You get 0 points (non-participation)
3. Compute final aggregates and determine your rank
4. Handle ties per problem rules (rounded up average points for tied ranks)

Timing:
- On reset: clear all registers
- Inputs should be stable for 1 cycle after rst_n deassertion
- Computation completes in 10 cycles max
- done signal asserts when worst_rank is valid

Scaling constraints:
- Max 4 contestants, max 4 contests
- Scores stored as 7-bit values (0-101)
- Aggregates computed as 9-bit sums (0-404)
