Design a sequential Verilog module named 'bug_fix_predictor' that computes the expected maximum severity of fixed bugs.
Inputs:
  input clk,             // clock
  input rst_n,           // active-low reset
  input start,           // pulse high to start computation
  input [15:0] f,        // Q16.16 (0x0000 to 0x10000 represents 0.0-1.0)
  input [15:0] p [2],    // 2-element array of Q16.16 probabilities
  input [13:0] s [2],    // 2-element array of severities (0-10000)
Outputs:
  output reg [31:0] expected_severity, // Q16.16 result
  output done            // high when computation completes

Functionality:
- Computes expected severity for B=2 bugs, T=2 hours
- Uses dynamic programming with state machine
- Fixed-point arithmetic for probabilities (Q16.16)
- Output valid 4 clock cycles after start assertion, done signals completion

Operation steps:
1. On reset, all registers cleared (IDLE state)
2. When start=1, start computation (compute base cases)
3. Iterate through possible T=1 to T=2 hours using DP
4. For each state, compute optimal bug selection choice
5. After 4 clock cycles, output result and assert done
