Design a combinational Verilog module named 'reconstruct_ring' that reconstructs a 4-element number ring from their neighbor sums.

Inputs:
  input [31:0] y0, // First number in new ring
  input [31:0] y1, // Second number
  input [31:0] y2, // Third number
  input [31:0] y3  // Fourth number

Outputs:
  output [31:0] x0, // First original number
  output [31:0] x1, // Second original
  output [31:0] x2, // Third original
  output [31:0] x3  // Fourth original

Behavior:
1. Compute sum_y = y0 + y1 + y2 + y3
2. Compute S = sum_y / 3 (integer division, guaranteed divisible by input)
3. Assign outputs:
   x0 = S - y2
   x1 = S - y3
   x2 = S - y0
   x3 = S - y1

The module must be purely combinational with no clock or reset.
