Design a Verilog module named 'max_card_damage' that calculates the maximal damage Jiro can receive in the card game.

Module interface:
module max_card_damage(
  input clk,          // Clock
  input rst_n,        // Active-low reset
  input start,        // Start computation
  // Jiro's cards (4 max):
  input [3:0] jiro_cnt,      // Number of Jiro cards (0-4)
  input [3:0][15:0] j_strength, // Card strengths
  input [3:0] j_type,         // 0=DEF, 1=ATK
  // Ciel's cards (4 max):
  input [3:0] ciel_cnt,      // Number of Ciel cards (0-4)
  input [3:0][15:0] c_strength, // Attack strengths
  // Output:
  output reg [15:0] damage,  // Max damage result
  output reg done            // Computation done
);

Behavioral description:
1. On reset, all registers clear and FSM resets to IDLE
2. When start=1:
   a. Sort Jiro's DEF/ATK cards and Ciel's attack cards in ascending order
   b. Compute two strategies:
      i. Destroy all DEF cards first, then ATK cards
      ii. Directly attack ATK cards with strongest Ciel cards
   c. Calculate max damage between two strategies
3. Output valid 20 clock cycles after start asserted
4. done=1 when result is ready, stays high until next start

Implementation constraints:
- Maximum 4 cards for both players
- 16-bit strength values (max 65535)
- Sort using iterative bubble sort over multiple cycles
- Damage calculation uses saturating arithmetic
- FSM states: IDLE, SORT_JIRO, SORT_CIEL, CALC_STRAT1, CALC_STRAT2, DONE
