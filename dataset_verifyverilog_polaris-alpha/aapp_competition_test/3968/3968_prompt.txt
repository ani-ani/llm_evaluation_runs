Design a sequential Verilog module named 'virus_spread_tracker' that models virus spread over D days (max 3 days) for 8 people.
Module interface:
module virus_spread_tracker(
  input clk,                         // clock signal
  input rst_n,                       // active-low reset
  input start,                       // pulse high to begin computation
  input [1:0] days,                  // D value (0-3 days)
  input [7:0] initial_infected,       // 1-bit per person (bit0=person1)
  input [15:0] s [0:7],              // entry times (16-bit each)
  input [15:0] t [0:7],              // exit times (16-bit each)
  output reg [7:0] infected_mask,    // 1-bit per infected person
  output reg done                    // high when computation complete
);

Behavior:
1. On reset, clear infected_mask and done.
2. When start pulse is detected:
   - Load initial_infected into current_infected register
   - Initialize day counter to 0
3. Each clock cycle after start:
   a. For all uninfected people: Check time overlap with ANY infected person
   b. Set next_infected = current_infected OR new infections
   c. Increment day counter
   d. When day counter == days: set infected_mask and assert done
4. Time overlap definition:
   Two people (i,j) overlap if:
   (s[i] <= t[j] && t[i] >= s[j]) OR (s[i] == t[i] && s[i] == s[j])

Timing:
- Output valid 3 clock cycles after start (1 cycle init + D cycles processing + 1 cycle output)
- Maintain done signal until next start
