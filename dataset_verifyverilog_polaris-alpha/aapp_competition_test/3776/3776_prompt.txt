Design a combinational Verilog module named 'clock_corrector' that adjusts displayed digits with minimal changes.

Module interface:
module clock_corrector(
  input [3:0] hour_tens, // 1st digit of hour (0-2 for 24hr)
  input [3:0] hour_units, // 2nd digit of hour (0-9)
  input [3:0] min_tens,   // 1st digit of minutes (0-5)
  input [3:0] min_units,  // 2nd digit of minutes (0-9)
  input is_24h_format,    // 1=24-hour clock, 0=12-hour
  output [3:0] corr_hour_tens,
  output [3:0] corr_hour_units,
  output [3:0] corr_min_tens,
  output [3:0] corr_min_units
);

Behavioral description:
- First correct minutes (both digits must form 00-59):
  - If min_tens > 5, change to 5 (minimal change)
  - Always keep min_units below 10 (but correct digit if >9)
  - If min_units >9, set to 0 (if tens=5) or original units (else)
- Correct hours based on format:
  FOR 24-hour format (is_24h_format=1):
    - If hour_tens >2: change to 0 (if units>3) or 1 (if units<=3)
    - If hour_tens==2 and hour_units>3: change tens to 0-1 with minimal digit changes
  FOR 12-hour format (is_24h_format=0):
    - Change hour_tens to 0 if hour >12
    - If hours==00: change to 01
    - If hours>12: set to minimal change (e.g., 13→01, 20→10)
- For all corrections, implement minimal digit changes per the problem statement.
