Design a Verilog module named 'gwen_flower_sequence' with a fixed sequence length of 4 flowers (n=5). The module takes a 5-bit index k (1-based) and outputs the kth valid sequence in lexicographical order. All valid sequences are precomputed for n=5 and stored in ROM.

Module interface:
module gwen_flower_sequence(
  input clk, // Clock signal
  input rst_n, // Active-low reset
  input [4:0] k, // Index input (range 1-31)
  output reg [7:0] sequence, // 4 flowers packed as {flower0[1:0], flower1[1:0], flower2[1:0], flower3[1:0]}
  output reg valid // High when output is valid
);

Behavior:
- On reset (rst_n=0), outputs cleared
- On clock edge, ROM lookup completes in 1 cycle
- Each flower uses 2 bits (values 1-4, invalid 0 used for reset)
- Contains precomputed valid sequences in ROM ordered lexicographically
- Output becomes valid on cycle after k input changes
Precomputed sequences include:
  k=1 → 1,1,1,1 (8'b01_01_01_01)
  k=16 → 3,3,3,3 (8'b11_11_11_11)
  k=22 → 4,3,4,2 (8'b100_11_100_10)
