Design a Verilog module named 'bracket_converter' that converts balanced parentheses strings (up to 8 chars) into alternative notation.
Module interface:
module bracket_converter(
  input clk, 
  input rst_n, 
  input start, 
  input [7:0] input_str, 
  output reg [511:0] output_buf, 
  output reg [5:0] output_len, 
  output reg done 
);

Behavior description:
1. Handles inputs of 8 balanced parentheses characters ("(" = 1, ")" = 0 can be pre-encoded)
2. On start=1, processes string to generate header pairs \"start,end:\" for each matched pair
3. Uses stack approach (max depth 4) to track matching indices
4. Computes absolute positions considering preceding header lengths
5. Latency: Worst-case 16 clock cycles (2 cycles per character)
6. Results available at output_buf when done=1
7. output_len indicates valid bytes in output_buf (each ASCII char = 8 bits)
8. Must produce shortest possible header sequence
