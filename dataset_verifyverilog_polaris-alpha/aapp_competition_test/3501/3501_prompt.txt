Design a combinational Verilog module named 'camel_order_verifier' that counts camel pairs with identical order across three bets (max 8 camels).

Module interface:
module camel_order_verifier(
  input [2:0] n,  // Number of camels (2-8)
  input [23:0] jaap_bet,  // 8x3-bit camels [MSB: a1 a2 ... a8 LSB]
  input [23:0] jan_bet,  // Same format
  input [23:0] thijs_bet,  // Same format
  output [4:0] count  // Result count (0-28)
);

Behavior:
1. Parse input bets (treat first 'n' camels as valid, ignore others)
2. Build position tables for each camel (1-8) in each bet
3. Count all c < d pairs (1 ≤ c < d ≤ n) where:
   - c appears before d in ALL THREE bets
4. Output number of qualifying pairs
Position extraction: For each bet, assign pos[a_i] = i (for 0 ≤ i < n)
