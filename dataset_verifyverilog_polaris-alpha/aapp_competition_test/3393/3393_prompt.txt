Design a sequential Verilog module named 'course_optimizer' that finds the minimal difficulty sum for k courses considering Level I/II prerequisites.

Inputs:
input clk,           // clock
input rst_n,         // active-low reset
input start,         // start computation (pulse high for 1 cycle)
input [3:0] n,        // number of courses (max 8)
input [3:0] k,        // courses to select (k ≤ n)
input [7:0][9:0] difficulties,  // 8 courses x 10-bit difficulties (max 1024)
input [7:0] is_level1, // 1-bit per course: 1=Level I, 0=not
input [7:0] is_level2, // 1-bit per course: 1=Level II, 0=not
input [7:0] pair_id,   // 3-bit per course: group Level I/II pairs (0=no pair)

Outputs:
output reg [12:0] min_sum, // minimum difficulty sum (13-bit)
output reg done             // high when result valid

Behavior:
1. On start pulse: Compute minimal sum for k courses considering:
   - Taking Level II requires its Level I counterpart (both count toward k)
2. Use a state machine with:
   - STATES: IDLE, CALCULATE, DONE
   - Compute all valid course combinations (respecting prerequisites)
   - Select combination with minimal difficulty sum
3. Additional logic:
   - Each Level I/II pair a unique pair_id (non-zero)
   - When forming combinations:
     * Can't select Level II alone (must select its paired Level I)
     * Selecting a pair counts as 2 courses toward k
     * Can select Level I without the Level II counterpart
4. Latency: Output valid 16 clock cycles after start assertion.
5. Assume setup: Inputs remain stable until done asserted.
