Design a sequential Verilog module named 'almost_palindrome_counter' that counts almost palindromic substrings in fixed-length strings.

Module interface:
module almost_palindrome_counter (
  input clk, // clock
  input rst_n, // active-low reset
  input start, // start computation
  input [5:0] str_len, // actual string length (1-8 chars)
  input [2:0] L, // query start index (1-based, 3 bits)
  input [2:0] R, // query end index (1-based, 3 bits)
  input [7:0][4:0] char_array, // 8 characters (5-bit encoded: a=0, z=25)
  output reg [5:0] count, // almost palindromic substring count
  output reg done // high when computation complete
);

Behavior:
- On reset: Outputs zero, done=0
- When start=1: Begin processing the string segment from index L-1 to R-1
- Implements 5-cycle latency:
  1. Cycle 1: Precompute all substring start/end indices (from L-R)
  2. Cycle 2: For each substring, check for exact palindrome
  3. Cycle 3: For non-palindromes, check if single swap can make palindrome
  4. Cycle 4: Accumulate counts of valid substrings
  5. Cycle 5: Final count valid on "count", done=1

Almost Palindrome Specification:
A substring qualifies if either:
1. It is a palindrome (char[i] ≡ char[len-1-i] for all i)
2. After swapping exactly one pair of characters, it becomes a palindrome
