Design a sequential Verilog module named 'garbage_bags' that calculates the minimum number of garbage bags required.
Module interface:
module garbage_bags(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // pulse high to start computation
  input [15:0] k, // bag capacity (16-bit)
  input [15:0] days_data [0:15], // garbage per day (16 entries*16b)
  input [3:0] n, // actual number of days (1-16, 4-bit)
  output reg [31:0] total_bags, // 32-bit bag count
  output reg done // high when computation complete
);

Behavioral Description:
The module must implement a state machine with three states:
IDLE (waits for start signal),
PROCESSING (computes bag counts),
DONE (output valid).
Algorithm:
1. On start: Initialize total_bags = 0, current_leftover = 0, day_counter = 0
2. For each day until day_counter = n:
   a. current_total = days_data[day_counter] + current_leftover
   b. Add (current_total / k) to total_bags (integer division)
   c. current_leftover = current_total % k
   d. If current_leftover != 0 and day_counter != n-1: continue
   e. If current_leftover != 0 and day_counter == n-1: add 1 bag
   f. If current_total < k and current_leftover != 0: add 1 bag and reset leftover
3. Output total_bags after n+1 clock cycles with done=1
