Design a Verilog module named 'interesting_problemset' that determines whether there exists a non-empty subset of problems that is interesting for experienced teams. The subset is interesting if every team knows at most half of the problems in the subset.
Module interface:
module interesting_problemset(
  input [15:0] valid, // 1-bit for each problem (1 if present)
  input [63:0] problems, // 16 problems, each 4 bits (problems[3:0] = problem0, problems[7:4]=problem1, etc.)
  output result // 1 if YES, 0 if NO
);

Behavior:
- Check if any valid problem is all zeros (problem[i] == 4'b0000).
- Check for any two different valid problems i and j where (problem[i] & problem[j]) == 4'b0000.
- If either condition is met, result = 1; else, result = 0.
- The module is purely combinational.
