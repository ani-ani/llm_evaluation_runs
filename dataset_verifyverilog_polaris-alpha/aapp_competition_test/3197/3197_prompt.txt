Design a sequential Verilog module named 'group_trip_solver' that finds max participants meeting dependency constraints within bus capacity.

Module interface:
module group_trip_solver(
  input clk,
  input rst_n,
  input start,
  input [2:0] k,
  input [2:0] preferences [0:7],  // 8 participants, each with 3-bit dependency
  output reg [3:0] max_count,
  output reg done
);

Behavior:
1. On reset: clear all states, outputs to 0
2. When start=1: begin computation
3. Iterate through all 256 possible participant subsets (8-bit mask) 
4. For each subset, verify: 
   a) If participant i in subset → preferences[i] in subset 
   b) Subset size ≤ k 
5. Track largest valid subset size across all combinations
6. Output result in max_count with done=1 after 260 cycles (all 256 subsets + setup)
Latency requirements:
- Result available at cycle 260 after start assertion
- Use states: IDLE(0), ITERATE(1), CHECK(2), COMPARE(3), DONE(4)
