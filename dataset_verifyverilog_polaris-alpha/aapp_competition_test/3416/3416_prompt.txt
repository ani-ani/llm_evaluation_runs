Design a sequential Verilog module named 'train_route_optimizer' that calculates minimum flights and visitable airports in a 4-city rail system.
Inputs:
  input clk,              // Clock
  input rst_n,            // Active-low reset
  input start,            // Start computation
  input [3:0] num_cities, // Number of cities (1-4)
  input [15:0] adj_matrix // 4x4 adjacency matrix (adj_matrix[4*i + j] = rail from i+1 to j+1)

Outputs:
  output reg [1:0] min_flights, // Minimum flights needed (0-3)
  output reg [3:0] airports,    // Visit mask (airports[0]=city1 ... [3]=city4)
  output reg done                // High when computation completes

Behavior:
1. On reset or idle, outputs = 0
2. On start pulse:
   a. Find longest train path length (k) in directed acyclic graph
   b. Set min_flights = num_cities - k - 1
   c. Set airports mask for all cities appearing in any minimal route
3. Use state machine with states: IDLE, PROCESSING, DONE
4. Maximum latency: 16 clock cycles (2^4 nodes)

Note: Algorithm must track reachable nodes during all optimal paths. Implement with parallel path tracking and topological sorting principles adapted for 4-node graphs.
