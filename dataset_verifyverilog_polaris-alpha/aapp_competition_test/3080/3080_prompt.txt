Design a sequential Verilog module named 'snack_distribution' that counts valid k-snack configurations for a DAG of up to 8 areas.
Module interface:
module snack_distribution(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start processing query
  input [7:0][7:0] adjacency, // 8x8 adjacency matrix (1-bit edges)
  input [2:0] k, // Number of snack stands to select (1-4)
  input [2:0] a, // Number of target areas (1-8)
  input [2:0][2:0] targets, // Up to 8 target areas (3-bit IDs each)
  output reg [6:0] count, // Valid configuration count (up to 70)
  output reg done // High when computation complete
);

Behavior:
1. Precomputes all paths from root (area 0) to target nodes using BFS-like traversal
2. For each k-sized subset of nodes (1 <= k <= 4):
   a. Verifies all paths to target areas have exactly 1 snack in the subset
   b. Checks all snacks in subset are on some path to targets
3. Implements combinatorial validation with parallel path checks
4. Latency: Result valid within 256 clock cycles after start asserted.
5. Use hierarchical state machine with states: IDLE, INIT, PATH_COMPUTE, SUBSET_GEN, VALIDATE, UPDATE_COUNT, DONE.
6. Use 3-bit node IDs and 6-bit counters for selections.
