Design a sequential Verilog module named 'stone_game_winner' to determine the winner of the stone game.

Inputs:
- clk        // clock signal
- rst_n      // active-low reset
- start      // pulse high for 1 clock cycle to start computation
- [3:0] n    // number of piles (1-8)
- [7:0][15:0] stones   // 8-element array of 16-bit unsigned integers (values 0-65535)

Outputs:
- outcome   // 1-bit result: 1='sjfnb' (win), 0='cslnb' (lose)
- done      // high when computation complete

Behavior:
1. On start pulse:
   a. Sort the stones array in ascending order (using bubble sort or similar)
   b. Check these losing conditions (any true ⇒ outcome=0):
      i. More than one duplicate pair exists
      ii. Exactly one duplicate where (duplicate_value - 1) is present
      iii. More than one pile with 0 stones
2. If no losing condition:
   a. Compute adjusted_sum = Σ(after_sort[i] - i) for i=0 to n-1
   b. Set outcome = (adjusted_sum % 2 == 1)
3. Assert 'done' 40 cycles after start

Timing:
- All operations complete within 40 clock cycles
- Use 3 states: IDLE (wait for start), PROCESSING (sort & compute), DONE (output ready)
- Sorting must complete in ≤32 cycles
- Use non-blocking assignments for sequential logic
