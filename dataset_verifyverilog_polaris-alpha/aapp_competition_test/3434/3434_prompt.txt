Design a sequential Verilog module named 'explosion_probability' to calculate the probability of destroying all opponent minions under scaled constraints.

Module interface:
module explosion_probability(
  input clk,               // System clock
  input rst_n,             // Active-low reset
  input start,             // Start computation
  input [1:0] num_my_minions,  // Your minion count (0-2)
  input [1:0] num_opp_minions, // Opponent minion count (0-2)
  input [1:0] my_health_1, // Health of minion 1 (1-3, 0 if unused)
  input [1:0] my_health_2, // Health of minion 2 (1-3, 0 if unused)
  input [1:0] opp_health_1,// Opponent minion 1 health (1-3, 0 if unused)
  input [1:0] opp_health_2,// Opponent minion 2 health (1-3, 0 if unused)
  input [1:0] d,           // Damage units (1-3)
  output reg [31:0] prob,    // Probability result in Q16.16 format
  output reg done           // Computation complete flag
);

Behavioral description:
1. Module implements a state machine to simulate all possible damage sequences
2. Processes one damage unit per clock cycle, tracking remaining minions
3. Uses Q16.16 fixed-point format for probability accumulation
4. Supports max 2 minions per player with health values 1-3
5. Result available within (d+3) clock cycles after start signal
6. Done signal asserts when computation completes
7. Probability computed by summing valid outcomes where all opponent minions die
8. Output absolute error \u003c 0.0001 in Q16.16 format
