Design a sequential Verilog module named 'attendance_min_time' that computes the minimal inspection count for scaled-down attendance verification.

Inputs:
- input clk
- input rst_n (active-low reset)
- input start (pulse to begin computation)
- input [2:0] m (number of list entries, 1-8)
- input [2:0] n (number of students, 1-8)
- input [2:0] a [0:7] (attendance list, first 'm' valid)
- input [2:0] b [0:7] (initial queue, first 'n' valid)

Outputs:
- output reg [7:0] k (minimal inspection count)
- output reg done (high when complete)

Behavior:
1. On reset: Initialize state to IDLE, k=0, clear internal registers
2. When start=1:
   a. Load 'a' and 'b' into internal memories
   b. Begin processing list front-to-back
   c. For each clock cycle:
      i. Compare queue front with current list entry
     ii. If match: Remove from both queue and list (shift queue left)
    iii. If no match: Move front student to queue end
     iv. Increment k counter every comparison
3. Complete when all list entries processed (assert done)

Latency: Variable (worst-case ≈ m*n*8 cycles)
States: IDLE, LOAD, PROCESS, DONE
Queue implemented as circular buffer with head/tail pointers.
