Design a Verilog module named 'canyon_mapper' that computes the smallest square map side length for a 4-vertex convex polygon.
Inputs:
input clk, // clock
input rst_n, // active-low reset
input start, // start processing
input [15:0] x0, y0, x1, y1, x2, y2, x3, y3 // Q8.8 fixed-point coordinates (effectively -128 to 127.996) 
Outputs:
output reg [31:0] side_length, // Q16.16 fixed-point (0 to 255.999 with 16 fractional bits)
output reg done // high when computation complete
Behavior:
1. On reset, all outputs set to 0 until start asserted.
2. After start, compute bounding box: find min_x, max_x, min_y, max_y from all vertices.
3. Compute width = max_x - min_x, height = max_y - min_y.
4. Side length = max(width, height).
5. Output done=1 and side_length after 10 clock cycles.
Notes:
- Coordinates interpreted as Q8.8 (-128 to 127.996)
- All arithmetic uses signed fixed-point with proper bit expansion.
- Comparative operations use full signed comparison.
