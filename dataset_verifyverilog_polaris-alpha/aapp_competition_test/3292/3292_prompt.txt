Design a sequential Verilog module named 'name_ordering_counter' that calculates valid arrangements.

Module interface:
module name_ordering_counter(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [3:0][31:0] names, // 4 names (32b each: 4 ASCII chars)
  output reg [15:0] count, // Result (mod 1e9+7 not needed for small N)
  output reg done // High when result valid
);

Behavior:
1. On reset: count=0, done=0
2. When start=1:
   a. Group names by common prefixes (max 2 levels): first char then second char
   b. Compute product of factorials of group sizes at each level
   c. Output final product to count after 5 clock cycles
3. done=1 when result valid

Implementation notes:
- Use ROM lookup tables for factorials (1!=1, 2!=2, 3!=6, 4!=24)
- Compare first two characters for grouping
- Max group size=4 (input has exactly 4 names)
- Use hierarchical state machine: IDLE->GROUP1->GROUP2->CALC->DONE
- Latency: 5 cycles after start assertion.
