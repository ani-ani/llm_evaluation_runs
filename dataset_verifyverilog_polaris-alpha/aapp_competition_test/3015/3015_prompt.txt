Design a sequential Verilog module named 'hamster_navigator' that computes the time for Harry to reach his bed under alternating hemisphere control.

Module interface:
module hamster_navigator(
  input clk, // Clock signal
  input rst_n, // Active-low reset
  input start, // Start computation (pulse high)^
  input [1:0] start_node, // 2-bit start ball (0-3)
  input [1:0] bed_node, // 2-bit bed ball (0-3)
  input [15:0] graph_data, // Packed graph edge: {2'bstart, 2'bend, 4'bweight} [max 16 edges]^
  input [3:0] edge_count, // Number of valid edges (0-15)
  output reg [15:0] min_time, // Computed time to bed (0-65535)
  output reg infinity, // High if no valid path
  output reg done // High when computation complete
);

Behavior:
1. On reset, initialize all states. On start pulse:
2. Process up to 4 nodes using modified BFS for alternating turns (left=minimizing, right=maximizing).
3. Represent state as {current_node[1:0], turn} (turn: 0=left hemisphere, 1=right).
4. For each state, store best known time using RAM/registers.
5. Iterate for up to 8 steps (2 cycles per node) to detect cycles.
6. If bed_node is reached within 8 steps, output time; else set infinity=1.
7. Assert done after 16 clock cycles max. Use state machine: IDLE, CALC, DONE.

Note: Graph RAM stores adjacency list with packed format. Edge weights are 4-bit (1-15). Max 16 edge entries.
