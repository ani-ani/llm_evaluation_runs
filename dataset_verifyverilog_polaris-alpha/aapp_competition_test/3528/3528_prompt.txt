Design a sequential Verilog module named 'convex_hull_area' that computes nail removal sequence areas.

Module interface:
module convex_hull_area(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // pulse high to start processing
  input [2:0] num_nails, // number of nails (3-8)
  input [7:0][15:0] nail_x, // 8 x-coordinates (16-bit each)
  input [7:0][15:0] nail_y, // 8 y-coordinates (16-bit each)
  input [5:0][1:0] remove_seq, // 6 removal steps (00=L,01=R,10=U,11=D)
  output reg [35:0] area, // x10 scaled area (integer part in [35:4])
  output reg valid, // high when area is valid
  output reg done // high when all areas computed
);

Behavior:
1. On start pulse, load initial nail coordinates
2. For each in remove_seq[0] to remove_seq[5]:
   a. Remove extreme nail (L/R/U/D) from current set
   b. Compute convex hull of remaining points (up to 16 cycles)
   c. Calculate shoelace formula area multiplied by 10
   d. Output area with valid=1 for one cycle
3. After 6 removals, assert done
Latency: 6x (1 removal + 16 hull + 1 area calc cycles) + 1 init = ~110 cycles max.
Implementation note: Use iterative convex hull with fixed 8-point storage.
