Design a sequential Verilog module named 'escape_network' that computes minimal added edges to make a tree graph 2-edge-connected.
Module interface:
module escape_network(
  input clk, // system clock
  input rst_n, // active-low reset
  input start, // starts computation when high
  input [2:0] n, // number of nodes (2-8)
  input [2:0] h, // headquarters node ID
  input [41:0] edges, // 7 edges packed as [a0,b0,a1,b1,...,a6,b6] (each 3 bits)
  output reg [2:0] m, // number of edges to add (0-7)
  output reg [41:0] added_edges, // result edges (same packing as input)
  output reg done // high when results valid
);

Behavior:
1. On reset (rst_n=0), sets m=0, added_edges=0, done=0
2. When start=1 begins processing:
   - Parses input edges into adjacency list for n-node tree
   - Detects all bridge edges using iterative DFS (max depth 8)
   - Computes minimal additional edges to eliminate all bridges
3. Latency: max 128 cycles (8 nodes × 16 steps)
4. Output format: added_edges packed as 7 × [3'ba,3'bb], valid in first m entries
5. Implementation hint: Use state machine with IDLE, DFS_TRAVERSE, BRIDGE_DETECT, CONNECT_COMPONENTS states. Edge augmentation should connect leaves of bridge tree.
