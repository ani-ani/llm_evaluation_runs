Design a sequential Verilog module named 'task_threshold' that finds the minimal average power threshold for 4 tasks.

Module interface:
module task_threshold(
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [31:0] power [0:3], // Task power requirements (4 tasks)
  input [7:0] processors [0:3], // Processor counts (4 tasks)
  output reg [31:0] result, // Computed threshold ×1000
  output reg done // High when computation complete
);

Behavior:
1. On start pulse, computes minimal possible threshold where sum(power_first_tasks)/sum(processors_first_tasks) meets constraints
2. Evaluates valid task pairings (each computer 1-2 tasks with second task < first)
3. Computes ceil((sum_power / sum_processors) × 1000)
4. Output valid 50 cycles after start assertion with done=1

Implementation notes:
- Uses sorting network to order tasks by descending power
- Evaluates 2^4=16 possible pairings
- Maintains minimum valid threshold
