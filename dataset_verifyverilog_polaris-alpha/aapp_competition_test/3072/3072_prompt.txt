Design a sequential Verilog module named 'max_table_perimeter' that finds the maximum table perimeter in an 8x8 grid. Module interface:
module max_table_perimeter(
  input clk,
  input rst_n,
  input start,
  input [63:0] grid_flat,  // Flattened grid (row-major: grid_flat[7:0]=row0, 0=free, 1=blocked
  output reg [5:0] max_perimeter,
  output reg done
);

Functionality:
1. On reset (rst_n=0), reset internal state
2. When start=1, begin scanning all possible rectangles in grid
3. For each rectangle (defined by top-left [i,j] and bottom-right [k,l]):
   a. Check if all cells in rectangle are free (0)
   b. Calculate perimeter as 2*((k-i+1)+(l-j+1)) - 1
   c. Track maximum perimeter value
4. Output final max_perimeter when done=1

Behavior:
- Latency: Maximum 4096 cycles (cover all 8x8 rectangles)
- Uses 4 nested loops for i,k (rows) and j,l (cols)
- Implement as state machine: IDLE, CALCULATING, DONE
- done asserts for 1 cycle when complete

All signals must be registered. Use non-blocking assignments.
