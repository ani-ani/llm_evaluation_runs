Design a sequential Verilog module named 'penguin_plaque_counter' that calculates the number of valid plaque configurations as per the problem conditions.

Module interface:
module penguin_plaque_counter(
  input clk,
  input rst_n,
  input start,
  input [4:0] n,       // Max value 16 (5-bit)
  input [3:0] k,       // Max value 8 (4-bit)
  output reg [31:0] result,  // 32-bit output
  output reg done
);

Behavioral description:
1. On active-low reset (rst_n=0), set all registers to 0.
2. When start=1:
   a. Compute A = (k^(k-1)) mod 1000000007
   b. Compute B = ((n-k)^(n-k)) mod 1000000007 (with 0^0 treated as 1)
   c. Compute result = (A * B) mod 1000000007
3. Operations must complete within 25 clock cycles max
4. 'done' signal asserts when result is ready
5. Use parameter M = 32'd1000000007 for modulus
6. Implementation requires:
   - Sequential multiplier for modular exponentiation
   - FSM with states: IDLE, CALC_A, CALC_B, MULTIPLY, DONE
7. Handle special cases:
   - When k=0: Treat as invalid (result=0)
   - When n=k: Compute B=1 (0^0)

Note: Exponentials computed via iterative multiplication with modulo reduction in each step.
