Design a sequential Verilog module named 'age_base_finder' that finds the largest base b where:
1. A 16-bit input age y written in base b contains only digits 0-9
2. The digits interpreted as base-10 number are ≥ input threshold ℓ

Module interface:
module age_base_finder(
  input clk,          // clock
  input rst_n,        // active-low reset
  input start,        // start computation (pulse)
  input [15:0] y,     // age value (base 10)
  input [15:0] l,     // minimum acceptable value
  output reg [15:0] b, // largest valid base found
  output reg done      // high when computation completes
);

Behavior:
- On reset: b=0, done=0
- When start=1: initialize search with current_base = min(y, 256)
- Sequentially decrement base from initial value to 2:
  1. Decompose y into digits for current_base
  2. Verify all digits ≤ 9 (fail if any digit >9)
  3. Convert digits to base-10 number (d0*10 + d1 for 2-digit cases)
  4. Check if ≥ l threshold
- First valid base meeting both conditions sets b=current_base, done=1
- If no valid base found (impossible per constraints), output b=0

Latency: Worst-case ~256*16 cycles (base search * digit steps). Output valid when done=1.
