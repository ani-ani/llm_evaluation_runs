Design a Verilog module named 'laser_target_checker' that determines if 6 targets can be hit with at most two laser shots.

Module interface:
module laser_target_checker(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // high to start computation
  input [4:0] x_coords [0:5], // array of 6 signed x coordinates (5-bit 2's complement)
  input [4:0] y_coords [0:5], // array of 6 signed y coordinates (5-bit 2's complement)
  output reg done, // high when computation complete
  output reg success // 1=possible, 0=impossible
);

Behavioral description:
- When start is asserted, check if all 6 points can be hit by either:
  1. A single line, or
  2. Two distinct lines (each covering some subset of points)
- Use a state machine with these states:
  IDLE: Wait for start signal
  CHECK_SINGLE_LINE: Check if all points are colinear (forms one line)
  CHECK_DUAL_LINES: Brute-force first line through 3 points, check remaining points form line
  COMPLETE: Set done
- Algorithm logic (for 6 points):
  1. First check if all points lie on a single line (return success=1)
  2. For 3 combinations of points (e.g., points 0-1-2, 0-1-3, 1-2-3):
    a. Find line through these points
    b. Check how many points lie on this line
    c. If remaining points form a single line (or ∅), return success=1
  3. Try at most 3 line combinations before concluding failure
Latency: Output valid within 16 clock cycles. Use geometric line formula: (y2-y1)*(x3-x1) = (y3-y1)*(x2-x1) for colinear check.
