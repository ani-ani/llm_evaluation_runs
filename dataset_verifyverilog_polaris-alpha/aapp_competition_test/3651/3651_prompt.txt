Design a sequential Verilog module named 'galactic_path_optimizer' that computes the minimal path distance touring 4 planets with single-use portals.

Input interface:
input clk // system clock
input rst_n // active-low reset
input start // high to begin computation
input [8:0] x1, y1, z1 // home planet (2^9 covers 0-511)
input [8:0] x2, y2, z2 // planet 2
input [8:0] x3, y3, z3 // planet 3
input [8:0] x4, y4, z4 // planet 4

Output interface:
output reg [31:0] min_distance // Q16.16 fixed-point (16 int, 16 frac)
output reg done // high when computation finishes

Behavioral requirements:
1. Calculate all 6 pairwise Euclidean distances between planets:
   - Use Q16.16 fixed-point format (store squared distances as 32-bit ints)
   - Distance between planet i and j: sqrt((xi-xj)^2 + (yi-yj)^2 + (zi-zj)^2)
   - Store distances in fixed-point format using 32-bit registers
2. Evaluate all 6 possible portal usage patterns (portal can bridge any two unused portals)
3. Compute total distance for each permutation:
   - Must return to home planet
   - Portals enable zero-cost jumps between connected planets but collapse after use
4. Maintain minimum distance using comparators
5. Complete within 50 clock cycles after start assertion

Timing:
- Clk-to-output delay: 1ns
- Output valid 50 cycles after start asserted
