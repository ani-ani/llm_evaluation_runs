Design a sequential Verilog module named 'josip_painter' that finds the closest paintable image to a target.

Module interface:
module josip_painter(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // start processing
  input [63:0] target_image, // flattened 8x8 image (MSB-first row-wise)
  output reg [6:0] min_difference, // maximum possible is 64 (7 bits)
  output reg [63:0] output_image, // resulting paintable image
  output reg done // high when computation complete
);

Behavioral description:
1. The module should implement Josip's painting process for images up to 8x8 (N=8)
2. Use a state machine to iteratively process image quadrants (recursion translated to iteration)
3. For each 2^k x 2^k sub-square (starting with k=3 for 8x8):
   a. If k=0 (1x1), directly use target pixel
   b. Else try all valid white/black selections in quadrants
   c. Choose quadrant assignments that minimize difference
4. Output stored minimal difference and constructed image

Timing:
- Computation starts when 'start' is asserted high
- Output becomes valid after maximum 100 clock cycles
- Assert 'done' when results are ready

Note: Design should handle N=1/2/4/8 cases internally. Input image should be treated as NxN (padded upper bits ignored when N<8).
