Design a sequential Verilog module named 'constrained_mst' that finds the minimum spanning tree under special edge constraints for a small graph.
Module interface:
module constrained_mst(
  input clk,
  input rst_n,
  input start,
  // Configuration
  input [2:0] num_nodes,
  input [3:0] num_edges,
  input [2:0] num_special,
  input [2:0] required_mix_edges,
  // Special nodes (3-bit IDs)
  input [2:0] special1,
  input [2:0] special2,
  input [2:0] special3,
  // Edge list (8 edges max)
  input [2:0] edge1_a, [2:0] edge1_b, [6:0] edge1_cost,
  ...
  input [2:0] edge8_a, [2:0] edge8_b, [6:0] edge8_cost,
  output reg [10:0] total_cost,
  output reg done,
  output reg error
);
Behavior:
- Implements modified Kruskal's algorithm with edge type constraint
- Accepts graphs with up to 8 nodes and 8 edges
- Requires exactly 'required_mix_edges' edges between special and regular nodes
- Outputs minimum cost on success, or sets error=1 if no valid spanning tree
- Latency: Computes in 128 clock cycles maximum after start
Timing:
- On start pulse: Load new configuration and begin computation
- After 128 cycles: Sets done=1 and valid output for 1 cycle
Reset:
- Reset initializes all registers and clears outputs (active low)

Implementation Notes:
1. Represent graph with sorted edge list and adjacency markers
2. Track edge types (special-regular or other) during selection
3. Use UFDS (Union-Find) structure with 8-element memory
4. Implement priority queue for edge selection with branch constraints
