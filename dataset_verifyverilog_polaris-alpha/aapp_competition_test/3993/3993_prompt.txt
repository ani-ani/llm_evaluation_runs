Design a Verilog module named 'page_operations_counter' that calculates the number of operations to discard all special items from pages.
Module interface:
module page_operations_counter(
  input clk, // Clock signal
  input rst_n, // Active-low reset
  input start, // Start computation
  input [7:0] n, // Total items (max 256)
  input [7:0] m, // Number of special items (max 8)
  input [7:0] k, // Page size (max 8 positions)
  input [7:0] p_data, // Special item position input
  input p_valid, // Item data valid
  output reg [3:0] out_op, // Operation count (max 8 operations)
  output reg done // High when computation complete
);

Behavioral description:
1. On reset (rst_n=0), set out_op=0, done=0
2. When p_valid=1, store up to 8 sorted special items in internal memory
3. When start=1, begin operation count process:
   a. Initialize shift=0, op_count=0, current_index=0
   b. Compute first_page = (p_mem[0] - shift - 1)/k
   c. Count all consecutive items in the same shifted page (p_mem[i] - shift <= (first_page + 1)*k)
   d. Update shift += num_discarded, op_count +=1
   e. Repeat until all items processed (current_index >= m)
4. Output op_count on out_op and assert done=1 after 3 clock cycles latency
5. For sequential logic: Use non-blocking assignments (<=) and 8-item internal memory
Timing requirement: Complete computation within (m+1) clock cycles after start asserted.
