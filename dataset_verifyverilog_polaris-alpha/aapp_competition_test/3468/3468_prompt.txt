Design a Verilog module named 'app_installer' that determines the optimal installation order of up to 8 apps (fixed input size) given space constraints.

Input specifications:
- Fixed input size for 8 apps:
  input clk,          // clock
  input rst_n,        // active-low reset
  input start,        // pulse high to start computation
  input [9:0] c,      // available disk space (0-1023 MB)
  input [9:0] d1, s1, // download & storage for app 1
  input [9:0] d2, s2, // download & storage for app 2
  ... [repeat for d3s3 .. d8s8] ...

Output specifications:
- output reg [3:0] max_count, // number of installed apps (0-8)
- output reg [3:0] order [0:7], // installation order (app indices 1-8)
- output reg done      // high when computation complete

Behavioral description:
1. When start is pulsed high:
   - Sorts apps by (storage_size - download_size) in increasing order (minimize immediate space usage).
   - Attempts installation in this order, checking remaining space after each app.
2. Space requirement for each app: must have >= max(d, s) space before installation.
3. After installation, consumes 's' MB from available space.
4. Computes maximum apps that can be installed in this order.
5. Outputs 'max_count' and 'order' with installation sequence.
6. Output 'done' pulses high for 1 cycle when complete (after 12 clock cycles).

Notes:
- For same (s-d) values, preserve input order
- If no apps can be installed, max_count=0 and done pulses high
- Use combinatorial logic for sorting comparison and space checks
- Sequential control for state transitions
