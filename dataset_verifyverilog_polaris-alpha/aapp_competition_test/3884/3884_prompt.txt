Design a sequential Verilog module named 'rocket_fuel_calc' that calculates the minimum fuel required for Natasha's journey.
Inputs:
input clk         // clock signal
input rst_n       // active-low reset
input start       // start calculation
input [3:0] n     // number of planets (2-8)
input [15:0] m    // payload mass (1-1000)
input [15:0] a [7:0]  // takeoff coefficients (8 values)
input [15:0] b [7:0]  // landing coefficients (8 values)

Outputs:
output reg [39:0] fuel   // minimum fuel 
output reg done          // calculation complete (1 when finished)

Behavior:
1. When start is asserted, begin computation
2. Use Q16.16 fixed-point for all fuel calculations (32-bit total)
3. Compute fuel via iterative calculation: For each planet i (0 to n-1):
   - Burn fuel during takeoff: fuel -= (fuel + m)/a_i
   - Burn fuel during landing: fuel -= (fuel + m)/b_i
4. Iteration must complete in 1 cycle per planet (16 total cycles)
5. If any a_i or b_i == 1 during computation, output fuel = 40'hFF_FFFF_FFFF
6. done signal asserts when calculation completes (16 cycles after start)
7. All calculations use non-blocking assignments and registered outputs
8. Reset behavior: outputs reset to 0 when rst_n=0

Latency:
16 clock cycles from start assertion to valid output (n=8 worst case)
