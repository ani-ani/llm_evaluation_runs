Design a sequential Verilog module named 'convex_score_sum' that computes the sum of scores for all convex polygon subsets of up to 8 points.
Inputs:
  input clk,             // clock
  input rst_n,           // active-low reset
  input start,           // start computation
  input [3:0] x[0:7],    // x-coordinates (4-bit each)
  input [3:0] y[0:7]     // y-coordinates (4-bit each)
Outputs:
  output reg [29:0] sum, // result modulo 998244353
  output reg done        // high when computation completes

Behavior:
- When 'start' is asserted, begin computation.
- Compute total valid subsets as (2^8 - 1 - 8 - 28) = 219.
- For each pair of points, count collinear points and subtract 2^c - c - 1 per line.
- Use combinational logic for point comparisons and sequential accumulation.
- Result appears on 'sum' after 20 clock cycles with 'done' asserted.
- All arithmetic modulo 998244353.
