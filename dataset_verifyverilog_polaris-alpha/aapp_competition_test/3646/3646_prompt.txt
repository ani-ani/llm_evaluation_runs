Design a sequential Verilog module named 'frog_jump_max_distance' that finds the farthest reachable pebble index from the first pebble.

Jump condition: Pebble j is reachable from i iff spots[i] + spots[j] == j_index - i_index

Module interface:
module frog_jump_max_distance(
  input clk, // system clock
  input rst_n, // active-low reset
  input start, // pulse high to start computation
  input [3:0] N, // number of pebbles (1-16)
  input [15:0] spots [0:15], // spot counts for up to 16 pebbles
  output reg [3:0] max_distance, // 0-based index of farthest reachable pebble
  output reg done // high when computation complete
);

Behavioral description:
- On reset: Initialize all states and set max_distance=0
- When start is asserted:
  1. Use BFS starting from pebble 0 (leftmost)
  2. Track reachable nodes in a visited array
  3. For each reachable node, check valid jumps using the condition spots[current] + spots[test] == test_index - current_index
  4. Store the maximum reachable index
  5. Assert "done" when BFS completes
- Latency: Worst-case N clock cycles (due to BFS levels) - valid result appears when done=1
- Implementation suggestions:
  • Use LFSR or counter for BFS queue
  • Parallel jump condition checking between current node and all others
  • Store visited flags in a 16-bit register
  • Calculate max_distance whenever a new node is visited
