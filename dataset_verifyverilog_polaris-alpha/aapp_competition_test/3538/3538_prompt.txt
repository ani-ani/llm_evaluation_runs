Design a sequential Verilog module named 'frog_escape' that calculates the maximum number of frogs escaping a pit through optimal stacking.
Module interface:
module frog_escape(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // start computation
  input [2:0] num_frogs, // number of frogs (1-8)
  input [15:0] pit_depth, // pit depth in µm (16-bit)
  input [15:0] l_data [0:7], // leap array (8x16-bit)
  input [15:0] w_data [0:7], // weight array (8x16-bit)
  input [15:0] h_data [0:7], // height array (8x16-bit)
  output reg [3:0] escaped_count, // frogs saved (0-8)
  output reg done // high when done
);

Behavioral requirements:
1. On reset or power-up: Initialize all registers
2. When start is asserted:
   a. Sort frogs by weight (lightest first) using bubble sort
   b. Calculate escape count:
      i. Maintain a "carry weight" value for stack
      ii. For each frog in sorted order:
          - If frog can carry current stack weight (w_data[i] > carry_weight) and can escape thru stack (h_stack + l_data[i] > pit_depth):
            * Increment escaped_count
          - Else:
            * Add frog height to h_stack if it can carry current weight
            * Add frog weight to carry_weight
3. Output complete after 40 clock cycles (done signal asserted)
4. Use 16-bit internals for all calculations
5. States: IDLE, SORT, PROCESS, DONE
