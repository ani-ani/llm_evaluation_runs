Design a sequential Verilog module named 'hill_houses' that computes minimum excavation time for building k houses.
Inputs:
  input clk, // Clock
  input rst_n, // Active-low reset
  input start, // Start computation
  input [15:0] hills [0:7] // 8 hills with 16-bit heights (zero-padded if n<8)
Outputs:
  output reg [31:0] results [0:3], // 4 results for k=1 to k=4 (ceil(8/2))
  output reg done // High when computation complete

Behavior:
1. On reset or power-up: Initialize all results to 0, done=0
2. When start=1: Begin DP computation. Use FSM with states: IDLE, COMPUTE, DONE
3. Algorithm: Implement scaled DP where dp[k][i] = min time to build k houses in first i hills.
4. Output valid after 100 clock cycles max (all k computed). Done asserts for 1 cycle when complete.
5. Support n=8 max: first n hills in input array (remaining zeroed).
6. Computes exactly ceil(n/2) results based on actual n (n=num_nonzero_hills).
