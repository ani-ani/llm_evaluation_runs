Design a combinational Verilog module named 'unicyclic_counter' that counts spanning unicyclic subgraphs for graphs with up to 4 vertices and 6 edges (all possible edges for V=4).

Module interface:
module unicyclic_counter(
  input [2:0] V,                 // Number of vertices (3 bits, valid values 1-4)
  input [2:0] E,                 // Number of edges (3 bits)
  input [5:0][1:0] edge_list,    // Packed edge list (6 edges * 2 vertices, each vertex 2 bits)
  output reg [29:0] cycle_count  // Result modulo 10^9+7 (30 bits)
);

Behavioral description:
- The module must compute the number of edge subsets that form spanning unicyclic subgraphs
- A valid subset must:
  1. Connect all vertices into exactly one component
  2. Contain exactly one cycle (n_edges == n_vertices for unicyclic graph)
- Consider all 2^E possible edge subsets (for given E edges)
- Use combinatorial logic to check each possible subset
- Implement cycle/connectivity checks for small graphs (V <= 4) via parallel evaluation
- Output result modulo 1,000,000,007 (10^9+7)
- Assume edges are undirected and each vertex is represented by 2 bits (values 1-4)
- Edge list is packed as 6 entries of [A,B] pairs (each 2 bits), unused edges should be ignored based on E
- The module must complete calculation combinationally (no clocks needed)
