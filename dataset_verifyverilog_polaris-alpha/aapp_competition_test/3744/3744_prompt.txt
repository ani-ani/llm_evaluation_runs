Design a sequential Verilog module named 'team_selector' that finds optimal student teams for programming (p=2) and sports (s=2) from 8 students.

Module interface:
module team_selector(
  input clk, // Clock input
  input rst_n, // Active-low reset
  input start, // Start computation
  input [7:0] a [0:7], // Programming skills (8 students)
  input [7:0] b [0:7], // Sports skills (8 students)
  output reg [10:0] max_strength, // Maximum total strength (11-bit)
  output reg [7:0] prog_team, // 1-hot encoded programming team
  output reg [7:0] sport_team, // 1-hot encoded sports team
  output reg done // High when computation complete
);

Behavioral description:
1. On reset, all outputs go to 0 and FSM returns to IDLE state
2. When start is asserted:
   a. Compute optimal team selection to maximize (sum(a[prog_team]) + sum(b[sport_team]))
   b. Ensure no student is in both teams (prog_team & sport_team == 0)
   c. Must select exactly 2 programming and 2 sports students
3. Algorithm:
   - Iterate through valid combinations using optimized combinatorial logic
   - Compare and track maximum strength
4. Output valid after 5 clock cycles:
   - max_strength: Sum of selected skills
   - prog_team: 8-bit one-hot encoding (bit 0 = student 1, bit 7 = student 8)
   - sport_team: 8-bit one-hot encoding
   - done: Asserted when results are ready
5. State machine:
   - IDLE: Wait for start
   - CALC: Compute all valid combinations (4 cycles)
   - OUTPUT: Present results (1 cycle)
