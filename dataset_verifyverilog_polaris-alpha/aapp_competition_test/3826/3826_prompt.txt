Design a sequential Verilog module named 'min_subsegment_removal' that finds the minimum subsegment size to remove for unique remaining elements.

Module interface:
module min_subsegment_removal(
  input clk,
  input rst_n,
  input start,
  input [2:0] n,
  input [31:0] a[0:7],
  output reg [3:0] min_size,
  output reg done
);

Behavioral description:
- On reset (rst_n=0), reset all internal states and outputs
- When start=1, begin computation:
  1. If all elements already unique: min_size=0, done=1 in next cycle
  2. Else, check all possible subsegments (l,r) where 0≤l≤r<n
  3. For each subsegment, check if remaining elements are unique
  4. Track the smallest (r-l+1) that satisfies uniqueness
- Use a state machine with states: IDLE, CHECK_UNIQUE, CALCULATE, DONE
- Max latency = 41 cycles (for n=8: 8*8 + setup cycles)
- Done flag asserts when computation completes

Implementation Notes:
- Store input array in 8x32 reg
- Use separate FSMs for subsegment iteration and uniqueness checking
- Use parallel comparators for uniqueness checks on small arrays
- Output min_size represents minimal removal length (0 if already unique)
