Design a sequential Verilog module named 'vote_swap_optimizer' that calculates the minimum swaps needed for party 1 victory.
Inputs:
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // start computation
  input [31:0] input_str // 16 voter/teller positions (2 bits per position: 0=teller, 1=party1, 2=party2)
Outputs:
  output reg [4:0] min_swaps, // minimum swaps needed (0-31)
  output reg is_impossible, // high if impossible
  output reg done // high when computation completes

Behavior:
- Accepts 16-position input (16x2 bits packed into 32-bit input_str)
- Processes voter/teller sequence to compute if party 1 can win
- Tracks current vote counts and teller scoring points during simulation
- Implements logic to try different teller positions (via adjacent swaps) and measure point outcomes
- Minimum swaps result valid 100 cycles after start assertion. Implement with state machine: IDLE, INIT, MOVE_TELLERS, COUNT_VOTES, COMPARE_SCORES, DONE
- If all teller positions examined with no valid solution, set is_impossible high
- Use 8-bit counters for party1/party2 votes and 4-bit point counters
