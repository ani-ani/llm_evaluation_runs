Design a sequential Verilog module named 'min_turning_circuit' that finds the minimal turning Eulerian circuit in a scaled graph.

Module interface:
module min_turning_circuit(
  input clk, 
  input rst_n, 
  input start, 
  input [3:0] node_count, 
  input [3:0] edge_count, 
  input [15:0] node_x[0:7], 
  input [15:0] node_y[0:7], 
  input [2:0] edges[0:15][0:1], 
  output reg [31:0] min_angle, 
  output reg done
);

Behavior: 
1. On reset (rst_n=0), reset internal state to idle
2. When start=1: 
   - Precompute all angles between consecutive edges at each node using Q16.16 fixed-point
   - Bruteforce search through all possible Eulerian circuits (max 8 nodes, 16 edges)
   - Calculate total turning angle in Q16.16 for each path (sum of absolute angles between consecutive edges)
   - Track minimal turning sum 
3. Output 'done' signal when complete (expected latency: 1024 cycles)
4. Output min_angle contains minimal turning sum in Q16.16 format

Note: 
- All coordinates handled as Q16.16 (integers multiplied by 65536)
- Angles calculated using fixed-point arctangent approximations
- Graph must have exactly 2 or 4 edges per node (Eulerian condition)
- Max 8 nodes, 16 edges (3-bit node indices)
