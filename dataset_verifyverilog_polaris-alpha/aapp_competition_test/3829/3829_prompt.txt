Design a sequential Verilog module named 'dice_expectation' that computes the expected maximum of m-faced die tossed n times using Q16.16 fixed-point.

Inputs:
input clk,          // system clock
input rst_n,        // active-low reset
input start,        // pulse high to start computation
input [2:0] m,      // dice faces (1-8)
input [3:0] n       // toss count (1-16)

Outputs:
output reg [31:0] result,  // Q16.16 result (expectation * 65536)
output reg done          // high when computation complete

Behavioral description:
1. When start is asserted: reset accumulation registers
2. Compute expectation using: E = m - sum((i/m)^n) for i=1 to m-1
3. Use Q16.16 fixed-point representation for all values
4. Operations:
   a. Precompute 1/m in Q16.16 format (65536/m)
   b. For each i from 1 to m-1:
      i. Compute (i * 1/m) in Q16.16
      ii. Raise to nth power via iterative multiplication (n cycles)
      iii. Subtract from m' sum
5. Compute final result E when all terms processed

Timing:
- 2 cycle latency for 1/m computation
- Maximum 16 cycles per exponentiation (per i term)
- Done pulses high 1 cycle after last term processed
- Worst-case latency: 1 + (m-1)*(n+1) + 2 cycles
