Design a Verilog module named 'trash_game' implementing a simplified Trash card game.

Module interface:
module trash_game(
  input clk, // system clock
  input rst_n, // active-low reset
  input [3:0] card_in, // serial card input (ASCII: '1'-'9','A','T','J','Q','K')
  input card_valid, // high when card_in valid
  output reg theta_win, // 1 if theta wins
  output reg friend_win // 1 if friend wins
);

Behavior description:
- Represents simplified game with 4 slots per player (IDs 1-4)
- Slot requirements: (1: A/1), (2: 2), (3: 3), (4: 4/any with wild)
- Uses first 4 cards as theta\'s face-down cards, next 4 as friend\'s
- Remaining cards form draw pile
- State machine tracks:
   * Players\' filled slots (2x4 bits)
   * Turn state (Theta/Friend turn start, drawing, processing)
   * Discard pile (stored when invalid cards played)
- Theta uses Jacks optimally (selects lowest ID slot if multiple choices)
- Friend always uses Jacks in lowest available slot
- Game continues serially until one player fills all 4 slots
- Output asserts when winner detected (game stops) 
Timing requirements:
- All state transitions occur on rising clock edge
- card_in sampled only when card_valid=1 during draw phases
- Game begins on reset deassertion, takes variable cycles (3-30)\
