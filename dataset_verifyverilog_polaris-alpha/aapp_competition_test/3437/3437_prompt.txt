Design a sequential Verilog module named 'max_tube_pairs' that finds the maximum total length of four tubes satisfying sum constraints.

Inputs:
  input clk              // clock signal
  input rst_n            // active-low reset
  input start            // pulse high to start computation
  input [13:0] L1        // max sum for first pair (14-bit, 0-10000)
  input [13:0] L2        // max sum for second pair (14-bit, 0-10000)
  input [7:0][13:0] tubes // 8 tube values (each 14-bit width)

Outputs:
  output reg [15:0] max_total // maximum valid sum (16-bit)
  output reg impossible       // high when no valid pairs
  output reg done             // high when computation complete

Functionality:
1. Module stores tube lengths in internal registers on start pulse
2. Checks ALL possible combinations of 4 distinct tubes (8 choose 4 = 70 combos):
   a. For each combo, generates all 3 ways to split into two pairs
   b. Checks if any split satisfies: sum(pair1) <= L1 AND sum(pair2) <= L2
   c. Tracks maximum total sum of all four tubes that meets constraints
3. After 3 clock cycles (pipelined comparison stages):
   - If valid solution found: max_total = sum, impossible = 0
   - Else: max_total = 0, impossible = 1
   - done pulses high for 1 cycle

Implementation Note:
Use parallel comparators and pipeline stages for efficient checking. Store best solution in maximum register.
