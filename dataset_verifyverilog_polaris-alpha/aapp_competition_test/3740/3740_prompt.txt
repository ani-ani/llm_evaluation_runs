Design a Verilog module named 'digit_sum_pair_counter' that counts pairs (l,r) where sum of digit counts from l to r equals S (mod 1e9+7).
Module interface:
module digit_sum_pair_counter(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // start computation
  input [15:0] S_in, // scaled input (1-50000)
  output reg [31:0] count, // result count % (10**9+7)
  output reg done // high when computation complete
);

Behavior:
1. On reset: count=0, done=0
2. When start=1: begin computation
3. Iterate l from 1 to (2*S_in) maximum
4. For each l: accumulate digit counts until sum >= S_in
5. For each matching sum=S_in: increment count
6. Output count mod 1000000007 after computation
Latency: Approximately S_in*3 clock cycles
State machine states: IDLE, INIT_L, SUM_DIGITS, CHECK_SUM, NEXT_L, FINISH
Digit count calculated as: ceil(log10(l)) using comparators
