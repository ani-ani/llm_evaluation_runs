Design a sequential Verilog module named "route_min_max_angle" that finds the route minimizing maximum turning angle under a distance limit.

Module interface:
module route_min_max_angle(
  input clk,                    // clock
  input rst_n,                  // active-low reset
  input start,                  // start computation
  input [2:0] max_junctions,    // actual junction count (2-8)
  input [15:0] D_max,           // max allowed distance (11-bit effective)
  input [31:0] junctions [0:7], // 8 junctions: [x:16][y:16]
  input [5:0] roads [0:15],     // 16 roads: [src:3][dst:3]
  input [3:0] road_count,       // actual roads (1-16)
  output reg [15:0] max_angle,  // Q8.8 fixed-point (degrees)
  output reg impossible,        // no valid route
  output reg done               // computation complete
);

Behavior:
- After reset, wait for start signal
- Compute path from junction 0 to max_junctions-1 with total distance <= D_max
- Minimize the maximum turning angle between consecutive roads
- Angles computed using fixed-point vector math (dot products)
- Latency: Max 256 cycles (8*16*2) after start
- Output valid when done=1 (impossible=1 if no route)
- Fixed-point: Q8.8 format (256 = 1.0 degree, 90.0deg = 23040)

Implementation notes:
- Use state machine: IDLE, LOAD, PROCESS, DONE
- Store graph as adjacency list in registers
- Implement priority queue for path exploration
- Precompute all road vectors and angles
- Compare angles using Q8.8 fixed-point arithmetic",

@cocotb.test()
async def test_route_angle(dut):

    def q8_8_to_deg(val):
        return val / 256.0

        (1, 2),  # 1->2
        (2, 3),  # 2->3
        (2, 4),  # 2->4
        (3, 4)   # 3->4
    ]
    
    # Test cases: (D_max, expected angle/"Impossible")
    test_cases = [
        (500, deg_to_q8_8(90.0)),
        (450, deg_to_q8_8(126.86989765)),
        (440, "Impossible")
    ]
    
    clock = Clock(dut.clk, 10, units="ns")

    dut._log.info(f"{passed}/{len(test_cases)} tests passed")
