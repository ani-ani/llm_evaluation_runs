Design a sequential Verilog module named 'grade_rounder' that implements rounding optimization for decimal grades.
Module interface:
module grade_rounder(
  input clk,              // clock signal
  input rst_n,            // active-low reset
  input start,            // pulse high to start processing
  input [3:0] grade_len,  // length of grade (1-15 chars)
  input [119:0] grade_in, // 15 ASCII chars (8-bits each, MSB aligned)
  input [2:0] t_in,       // max rounding steps (0-7)
  output reg [119:0] grade_out, // rounded result
  output reg [3:0] out_len,     // length of result
  output reg done          // high when computation complete
);

Behavior:
1. On start pulse, find first digit after decimal ≥5 within allowed t steps
2. Round at best position considering max t_in steps
3. Propagate carries through integer part if needed
4. Remove trailing zeros after decimal
5. Compute result within max latency = grade_len + 2 clock cycles

Rules:
- Support max 15 character grades (12 digits + 3 fractional by default)
- t_in ≤ 4 (module will use min(t_in,4))
- Use parallel comparison for digit evaluation
- Output must have no trailing zeros after decimal point
- All rounding follows standard competitive programming rules as described.

Implementation note: Use state machine with IDLE, FIND_POSITION, ROUND_PROPAGATE, and TRIM_TRAILING states.
