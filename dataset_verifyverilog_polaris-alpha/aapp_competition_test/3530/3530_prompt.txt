Design a sequential Verilog module named 'fun_maximizer' that computes maximum roller coaster fun values within time constraints.
Module interface:
module fun_maximizer(
  input clk, // clock
  input rst_n, // active-low reset
  input start, // pulse high for 1 cycle to start computation
  input [3:0] num_coasters, // number of coasters (1-4)
  input [6:0] a1, a2, a3, a4, // a_i parameters (7-bit, max 127)
  input [6:0] b1, b2, b3, b4, // b_i parameters (7-bit, max 127)
  input [3:0] t1, t2, t3, t4, // t_i parameters (4-bit, 1-15 min)
  input [3:0] T, // total available time (4-bit, 1-15 min)
  output reg [15:0] max_fun, // 16-bit unsigned result
  output reg done // goes high when result valid
);

Behavioral description:
1. On start pulse:
   - Compute maximum fun achievable within time T using N coasters (N <= 4)
   - Each coaster 'i' can be ridden multiple times with decreasing fun: f(i,k) = a_i - (k-1)^2 * b_i (stop when non-positive)
   - Time consumption for coaster 'i' is t_i per ride
2. Algorithm must implement iterative bounded computation (knapsack-like approach with max T=15)
3. Latency: Result must be available within 64 clock cycles
4. Use state machine with IDLE, CALCULATING, DONE states
5. Implement pipelined/parallel computation where possible
6. All arithmetic is unsigned integer (ignore negative fun cases)
