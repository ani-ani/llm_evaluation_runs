Design a sequential Verilog module named 'elf_seating_simulator' that simulates elf seating order and calculates victory count.

Module interface:
module elf_seating_simulator(
  input clk, // clock signal
  input rst_n, // active-low reset
  input start, // start computation
  input [1:0] n, // number of elf-dwarf pairs (0-3 represents 1-4)
  input [3:0][1:0] a, // elf dwarf preferences (1-based address, 2 bits each)
  input [3:0][31:0] p, // dwarf strengths (32 bits each)
  input [3:0][31:0] v, // elf strengths (32 bits each)
  input [3:0][1:0] elf_order, // elf processing order (2 bits per index)
  output reg [2:0] victory_count, // 0-4 possible wins
  output reg done // high when computation completes
);

Behavior:
On start signal, simulate seating of elves in given elf_order:
1. Reset: all dwarf seats become unoccupied
2. For each elf in elf_order (from 0 to n):
   a. Start at dwarf a[elf] (1-based, convert to 0-based cov
   b. Search next clockwise unoccupied seat (wrap after N)
   c. Mark seat occupied
   d. If elf strength > dwarf strength, increment victory_count
3. Output final count when done asserts
Latency: n+2 cycles after start (1 cycle per elf + setup)
Use states: IDLE, FIND_SEAT (for each elf), DONE.
Store occupied seats in 4-bit register (1 bit per dwarf).
