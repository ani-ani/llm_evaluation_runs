Design a sequential Verilog module named 'domino_tiling_maxsum' that finds the maximum sum covering exactly K=2 dominoes on a 3x4 grid.

Module interface:
module domino_tiling_maxsum(
  input clk, // system clock
  input rst_n, // active-low reset
  input start, // pulse high to start computation
  input [19:0] row0_col0, row0_col1, row0_col2, // 20-bit signed row 0 values
  input [19:0] row1_col0, row1_col1, row1_col2, // 20-bit signed row 1 values
  input [19:0] row2_col0, row2_col1, row2_col2, // 20-bit signed row 2 values
  input [19:0] row3_col0, row3_col1, row3_col2, // 20-bit signed row 3 values
  output reg [23:0] max_sum, // 24-bit signed maximum sum result
  output reg done // goes high when result is valid
);

Behavioral description:
1. The module should implement a dynamic programming solution with the following reduced constraints:
   - Fixed N=4 rows, must handle all layouts from N=1 to N=4
   - Fixed K=2 dominoes (covers exactly 4 cells)
   - Configurable for future expansion via parameters
2. Compute maximum sum by considering all valid domino placements (horizontal and vertical orientations)
3. Domino constraints: No overlapping dominoes, exactly K=2 dominoes placed
4. Latency: Output valid 8 clock cycles after start assertion
5. Implement using state machine with these states:
   IDLE: Wait for start signal
   CALC_ROW0: Process first row
   CALC_ROW1: Process first two rows
   CALC_ROW2: Process rows 0-2
   CALC_ROW3: Final computation
   DONE: Assert done
6. Initialization on reset: Clear all internal state
7. All arithmetic operations should handle signed numbers
