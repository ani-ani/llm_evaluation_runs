Design a Verilog module named 'signed_binary_converter' that converts an 8-bit binary input to minimal signed-digit representation.

Module interface:
module signed_binary_converter(
  input clk,
  input rst_n,
  input start,
  input [7:0] bin_in, // Binary input (MSB first)
  output reg [15:0] signed_out, // Packed output (2 bits per digit: 00='+', 01='-', 10='0')
  output reg done
);

Behavior description:
- Implements carry-propagation algorithm for minimal signed digits
- Processes bits LSB to MSB (1 bit per clock cycle)
- Start pulse initiates conversion (8 cycles latency)
- Output done=1 when result ready (signed_out valid)
- Follows lexicographic order for ties (ASCII: '+' < '-' < '0')

State machine states:
1. IDLE: Wait for start signal
2. PROCESSING: Iterate through bits (index 0 to 7)
3. DONE: Assert done for 1 cycle

Algorithm steps per bit:
- Maintain carry_in (1 bit register)
- For current bit position i (0-7):
  * current_bit = bin_in[7-i] ^ carry_in
  * next_carry = (bin_in[7-i] & carry_in) ? 1 : 0
  * Choose symbol (+,-,0) based on minimal non-zero count
- Update output register and carry at each step
