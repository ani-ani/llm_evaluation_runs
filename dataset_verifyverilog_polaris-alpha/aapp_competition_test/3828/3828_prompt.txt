Design a sequential Verilog module named 'train_sorter' that calculates minimum moves to sort railway cars.

Inputs:
input clk // clock
input rst_n // active-low reset (async)
input start // pulse high to start calculation
input [3:0] n // number of cars (1-16)
input [4:0] car_numbers [0:15] // car values (each 5-bit)

Outputs:
output reg [4:0] min_moves // result
output reg done // high when result valid

Functionality:
1. On reset: clear all internal state, set done=0
2. When start=1:
   a. Create position array: pos[car_value] = index (0-based)
   b. Find longest sequence where pos[i+1] > pos[i] (consecutive car numbers)
   c. Compute min_moves = n - longest_sequence_length
3. Output done=1 when calculation completes

Latency: Result available in (2*n + 5) clock cycles max. Use states: IDLE, LOAD_POS, SCAN_SEQ, DONE. Process up to 16 cars. Unused array elements should be ignored based on n value.
