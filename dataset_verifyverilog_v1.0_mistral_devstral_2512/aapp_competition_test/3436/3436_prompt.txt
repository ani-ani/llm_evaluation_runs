Verilog module specification for computing F_{x,y} modulo 1e9+7.

Module name: compute_F

Ports:
- input clk: clock
- input rst_n: active-low synchronous reset
- input start: start pulse (1 cycle)
- input [3:0] x: x coordinate (1..8)
- input [3:0] y: y coordinate (1..8)
- output [31:0] result: F_{x,y} mod 1000000007
- output done: asserted for 1 cycle when result is ready

Behavior:
- On reset, all state cleared.
- When start is asserted, module computes F_{x,y} using DP.
- Compute in row-major order for i=0..x, j=0..y.
- Use internal dp[0:8][0:8] array.
- Base cases: dp[0][0]=0, dp[0][1]=1, dp[1][0]=1.
- For i>=2, j=0: dp[i][0] = (dp[i-1][0] + dp[i-2][0]) mod MOD.
- For i=0, j>=2: dp[0][j] = (dp[0][j-1] + dp[0][j-2]) mod MOD.
- For i>=1, j>=1: dp[i][j] = (dp[i-1][j] + dp[i][j-1]) mod MOD.
- After computing dp[x][y], assert done for 1 cycle and output result.
- Completion within (x+1)*(y+1) cycles.

Constraints:
- Max x,y = 8, so DP size 9x9.
- MOD = 1000000007, use 32-bit arithmetic.
- State machine states: IDLE, COMPUTE, DONE.
- Ensure no out-of-bounds access (i-2, j-2 within 0..8).
