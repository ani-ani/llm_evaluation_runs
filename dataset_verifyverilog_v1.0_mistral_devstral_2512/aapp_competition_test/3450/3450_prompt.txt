Module to find last 3 digits before trailing zeroes in n!

INTERFACE SPECIFICATION:
  Inputs:
    - clk       : Clock signal (rising edge triggered)
    - rst_n     : Active-low synchronous reset
    - start     : Start pulse (assert for 1 cycle to begin computation)
    - n         : 10-bit input (0-1000, scaled from original 1-10000000)
  
  Outputs:
    - result    : 10-bit result (0-999, representing the 3 digits)
    - done      : Asserted high for 1 cycle when computation completes
  
  Timing:
    - Assert start for 1 clock cycle
    - done will go high when computation completes (within 500 cycles)
    - Sample result on the same cycle done is high
  
  Reset behavior:
    - On rst_n=0: done=0, result=0, internal state cleared
    - Minimum 2 clock cycles of reset required

Algorithm:
1. Compute n! while removing factors of 10 (2×5)
2. Keep product modulo 10000 to maintain sufficient precision
3. Count factors of 2 and 5 separately
4. After computing n!, multiply by 2^(count2-count5) mod 1000
5. Return result mod 1000

Note: n is scaled to 0-1000 to fit hardware constraints
