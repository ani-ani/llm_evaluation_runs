Module: scroll_code_solver

Description:
Counts valid completions of a 3x3 grid with nonzero digits (1-9) satisfying:
- No repeated digits in any row
- For each cell (i,j) not in top row or rightmost column:
  u = grid[i-1][j] must equal l*r, l+r, |l-r|, l/r (if divisible), or r/l (if divisible)
  where l = grid[i][j], r = grid[i][j+1]

Interface:
  Inputs:
    clk         : Clock (rising edge)
    rst_n       : Active-low reset
    start       : Start pulse (1 cycle)
    grid[2:0][2:0][3:0] : 3x3 grid, each cell 4 bits (0-9, 0=unknown)
  Outputs:
    result[15:0]: Number of valid completions
    done        : Asserted when result is valid

Behavior:
- When start=1, begin computation
- Enumerates all 9^N possibilities where N = number of zeros (0-4)
- Checks row uniqueness and L-shape constraints for each candidate
- Outputs count of valid completions
- done=1 when finished (within 10000 cycles)
