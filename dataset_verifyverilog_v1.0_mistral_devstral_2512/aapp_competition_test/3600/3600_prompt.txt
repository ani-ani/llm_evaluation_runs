Drone Placement Problem - Independent Set Checker

Module: DronePlacement

Interface:

Inputs:
- n[3:0]: number of nodes (1-8)
- k[3:0]: desired independent set size (0-8)
- adj[63:0]: adjacency matrix in row-major order; adj[i*8 + j] = 1 if edge between node i (0-7) and node j (0-7).

Output:
- possible: 1 if an independent set of size >= k exists, else 0.

Functionality:
The module computes the size of the maximum independent set (MIS) for the subgraph induced by nodes 0..n-1. It enumerates all 256 possible subsets of the 8 nodes. For each subset, it checks independence by verifying that no two nodes in the subset are adjacent. It keeps track of the maximum independent set size. Finally, it compares the MIS size with k: if MIS >= k, output possible = 1, else 0.

Implementation notes:
- Use combinational logic (no clock).
- The adjacency matrix is flattened: for nodes i and j (0-7), the bit at position i*8 + j indicates an edge.
- For nodes >= n, edges are ignored (the corresponding bits are don't-care).
- The circuit should be synthesized as a single always_comb block with nested loops.
- The output is available after propagation delay.

Example:
For n=4, k=2, and edges: 0-1, 1-2, 2-3 (linear graph), MIS size = 2, so possible = 1.
For n=7, k=4, and the example graph, MIS size = 3, so possible = 0.
