Verilog module: compute_convex_score
Inputs: clk, rst_n, start, N[2:0], x0..x7[15:0], y0..y7[15:0]
Outputs: result[31:0], done
Functionality:
  - Computes score for convex polygons among up to 8 points
  - Base value = (2^N - 1 - N - N*(N-1)/2) mod 998244353
  - For each unique line (i,j) with k>=3 collinear points: subtract (2^k - 1 - k - k*(k-1)/2)
  - Uses state machine with 13 states for iteration and comparisons
  - Collinearity: (x_j-x_i)*(y_k-y_i) == (x_k-x_i)*(y_j-y_i)
  - Modulo handling after each subtraction
