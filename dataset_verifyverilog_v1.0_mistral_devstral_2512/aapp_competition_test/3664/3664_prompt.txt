Module: zamboni

Interface:
- Inputs: clk, rst_n, start, i[7:0], j[7:0], n[7:0]
- Output: done

Internal:
- grid: 8x8 array of 8-bit registers, where value 0 represents '.', 1-26 represent 'A'-'Z', and 27 represents '@'.

Behavior:
The module implements the Pacman's zamboni algorithm on an 8x8 grid. When start is asserted, it initializes the grid, sets the start position, and begins the cleaning process. After n iterations, it marks the final position with '@'. The done signal is asserted when computation is complete.

State Machine:
The state machine has states: IDLE, INIT, CHECK_ITER, MOVE_START, MOVE_STEP, NEXT_ITER, MARK_FINAL, DONE. It uses counters for iterations, stepSize, and move steps. The current position is updated with wrapping at the grid boundaries. The direction rotates after each move, and the color switches to the next letter after each move.

Note: The input i and j are 1-based, so converted to 0-based internally. The color is stored as 0 for A, 1 for B, ..., 25 for Z, but when coloring, value is stored as color+1 (so A=1, B=2, etc.). The final position is set to 27.
