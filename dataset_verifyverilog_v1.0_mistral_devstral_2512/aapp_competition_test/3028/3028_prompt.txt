// Primonimo Solver for 2x2 board, prime p <= 7
// Module computes move counts that win the game.
// Interface:
//   clk, rst_n, start: standard control
//   p: prime number (2,3,5,7)
//   board_0 .. board_3: initial values (row-major)
//   count_0 .. count_3: move counts for each square (0..p-1)
//   solution_exists: 1 if solution found
//   done: 1 when computation finished
// Algorithm:
//   1. Compute target increments d = (p - board) mod p.
//   2. Build matrix A (4x4) where A[row][col] = 1 if variable's row equals equation's row or variable's column equals equation's column, else 0.
//   3. Perform Gaussian elimination over GF(p):
//        - For each column col from 0 to 3:
//            - Find pivot row with A[row][col] != 0.
//            - If none, set x[col]=0 (free variable) and continue.
//            - Swap pivot row to current row.
//            - Normalize pivot row: multiply by inverse of pivot.
//            - For all other rows, subtract multiple of pivot row to zero out column.
//   4. Back-substitute to solve for x.
//   5. If inconsistent (row with all zero A but non-zero d), set solution_exists=0.
//   6. Output x as move counts.
// Implementation notes:
//   - Use state machine with states: IDLE, INIT, FIND_PIVOT, SWAP, NORMALIZE, ELIMINATE, BACK_SUBST, OUTPUT, NO_SOLUTION.
//   - Store matrix and vectors in registers.
//   - Modular arithmetic functions: mod_add, mod_sub, mod_mul, mod_inv.
//   - Since p <= 7, mod_inv can be brute-force.
//   - All operations are combinational within states; use multiple cycles for loops.
