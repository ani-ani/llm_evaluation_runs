Verilog module specification for the scaled-down shortest article problem.

MODULE: shortest_article

INTERFACE:
  Inputs:
    - clk         : Clock signal (rising edge triggered)
    - rst_n       : Active-low synchronous reset
    - start       : Start pulse (assert for 1 cycle to begin computation)
    - n           : 4-bit input, actual number of theorems (≤ 8)
    - num_proofs  : 8 x 4-bit array, num_proofs[i] = number of proofs for theorem i (≤ 4)
    - proof_len   : 8 x 4 x 8-bit array, proof_len[i][j] = length of proof j for theorem i
    - proof_dep   : 8 x 4 x 8-bit array, proof_dep[i][j] = dependency mask for proof j of theorem i
  Outputs:
    - done        : 1-bit, asserted high for 1 cycle when result is valid
    - result      : 16-bit, minimum total length

FUNCTIONALITY:
  The module implements the DP over subsets algorithm:
  1. Initialize dp[0] = 0, dp[others] = INF.
  2. Iterate over all masks from 0 to (1<<n)-1.
  3. For each mask where dp[mask] is not INF, consider adding each theorem i not in mask.
  4. For each i, compute the minimum cost proof whose dependencies are within mask.
  5. If such a proof exists, update dp[mask | (1<<i)] = min(dp[mask | (1<<i)], dp[mask] + cost).
  6. After processing all masks, result = min_{mask with bit0 set} dp[mask].

IMPLEMENTATION NOTES:
  - Use a state machine to iterate over masks and theorems.
  - dp array implemented as 256 x 16-bit registers (or a small RAM).
  - Dependencies are checked using bitwise operations: (dep_mask & ~mask) == 0.
  - All loops have fixed bounds (n ≤ 8, proofs ≤ 4), so synthesis is feasible.
  - The module is sequential; starts on start pulse, asserts done when finished.

STATE MACHINE STATES:
  IDLE, INIT_DP, LOOP_MASK, LOOP_THEOREM, LOOP_PROOF, UPDATE_DP, NEXT_MASK, NEXT_THEOREM, NEXT_PROOF, DONE

TIMING:
  - After start, the module will take several hundred cycles to complete, depending on n.
  - Use a timeout in the testbench to prevent hangs.

RESET:
  - Active-low reset (rst_n) clears all registers and state.
  - Minimum 2 clock cycles of reset recommended.
