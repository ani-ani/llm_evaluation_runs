Module: jeff_rounding

Description: Computes the minimal absolute difference between original sum and rounded sum after performing n floor/ceil operations.

Interface Specification:
  Inputs:
    - clk: Clock signal (rising edge triggered)
    - rst_n: Active-low synchronous reset
    - start: Start pulse (assert for 1 cycle to begin computation)
    - data_in: 32-bit integer input representing a number in thousandths (value = number*1000)
    - data_valid: High when data_in is valid
  Outputs:
    - result: 32-bit integer minimal difference in thousandths (actual = result/1000.0)
    - done: Asserted high for 1 cycle when result is valid

Behavior:
  1. On start, expects n first, then 2n numbers
  2. For each number, extracts fractional part (data_in % 1000)
  3. Counts non-integer numbers (m) and sums fractional parts (T)
  4. Computes L = max(0, m-n), R = min(m,n)
  5. Iterates x from L to R to find min |x*1000 - T|
  6. Outputs result in thousandths

Timing:
  - Assert start for 1 clock cycle
  - Data must be presented one per cycle with data_valid high
  - Computation completes within 2n + (R-L+1) + 5 cycles after start
  - Sample result when done is high
