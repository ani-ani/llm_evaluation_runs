Verilog module specification for Sequential Yahtzee:

MODULE: yahtzee

INTERFACE:
  Inputs:
    - clk: Clock signal (rising edge)
    - rst_n: Active-low reset
    - start: Start pulse (1 cycle)
    - rolls[194:0]: 195-bit packed array of 65 dice rolls, each 3 bits (rolls[2:0] = roll0, rolls[5:3] = roll1, ..., rolls[194:192] = roll64)
  Outputs:
    - total_score[15:0]: Total score for all 13 categories
    - done: Asserted high for 1 cycle when computation completes

FUNCTIONALITY:
  - Processes exactly 13 rounds sequentially
  - Each round uses 5 consecutive rolls (round i uses rolls[i*5 +: 5])
  - Each round corresponds to a fixed category in order:
    Round 0: 1's, Round 1: 2's, ..., Round 5: 6's
    Round 6: 3-of-a-Kind, Round 7: 4-of-a-Kind, Round 8: Full House
    Round 9: Small Straight, Round 10: Long Straight, Round 11: Chance, Round 12: Yahtzee
  - Scoring follows standard Yahtzee rules
  - State machine with 13 states (one per round) plus IDLE and DONE
  - Combinational scoring function for each category
  - Uses bubble sort for straight and full house detection

TIMING:
  - After start pulse, takes 14 cycles (13 rounds + 1 for setup)
  - Result available when done is high

RESET:
  - On rst_n=0: state=IDLE, total_score=0, done=0
  - Minimum 2 cycles of reset required
