Design a Verilog module that counts numbers in [0,n] containing the decimal representation of 2^e as a substring. Use digit DP with KMP automaton.

Interface:
- Inputs: clk, rst_n, start, e[5:0], n_digits[0:18] (each 4-bit BCD digit, most significant first)
- Outputs: count[63:0], done

Behavior:
1. On start, look up decimal string of 2^e and its length m from precomputed ROM
2. Compute KMP transition table for the string
3. Initialize DP: current_dp[tight][started][state] with 64-bit counters
4. For each digit position 0..18:
   - Reset next_dp
   - For each current state and digit d (0-9):
     * Update tight, started, state using automaton
     * Accumulate counts to next_dp
   - Set current_dp = next_dp
5. After all digits, sum counts where state = m
6. Output result and pulse done

Use state machine: IDLE → LOOKUP → INIT_DP → PREPARE_LOOP → ITERATE → SUM → IDLE
