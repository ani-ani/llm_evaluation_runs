Design a Verilog module that evaluates bracket sequences with the following specifications:

## Interface
Inputs:
  - clk: Clock signal (rising edge triggered)
  - rst_n: Active-low synchronous reset
  - start: Start pulse (assert for 1 cycle to begin computation)
  - token_count: 4-bit input (1-16 tokens maximum)
  - token_0 to token_15: 16 individual 10-bit token inputs
    * Each token format: [9:8] type (00=number, 01='(', 10=')'), [7:0] value (only valid for numbers)

Outputs:
  - result: 8-bit computation result (mod 256)
  - done: Asserted high for 1 cycle when computation completes
  - error: Asserted high for 1 cycle if bracket sequence is invalid

## Functionality
The module must evaluate the bracket sequence using a stack-based state machine:
1. Start in addition mode (mode=0)
2. Process tokens sequentially:
   - Number: accumulate with current mode (add/multiply)
   - '(': push state (value, mode), flip mode, reset value to 0 (add) or 1 (multiply)
   - ')': pop state, combine with current value using popped mode
3. All arithmetic uses modulus 256
4. Maximum nesting depth = 4 levels
5. Process one token per clock cycle

## Timing
- Assert start for 1 clock cycle
- Computation completes within 20 clock cycles
- Result and error available when done is high
- Reset clears all state

## Constraints
- Token count: 1-16
- Numbers: 8-bit (0-255)
- Nesting depth: 0-4 levels
- Modulus: 256
