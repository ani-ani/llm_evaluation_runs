Module: m_perfect_checker

Description: Finds minimum operations to make a pair of integers m-perfect by repeatedly replacing one number with the sum.

Interface:
  Inputs:
    - clk: Clock signal
    - rst_n: Active-low reset
    - start: Start computation
    - x_in[63:0]: First integer (signed 64-bit)
    - y_in[63:0]: Second integer (signed 64-bit)  
    - m_in[63:0]: Target value (signed 64-bit)
  
  Outputs:
    - result[31:0]: Minimum operations (-1 if impossible)
    - done: Computation complete

  Functionality:
    1. If max(x,y) >= m: result = 0
    2. If x <= 0 and y <= 0: result = -1
    3. If one negative: make non-negative by repeated addition
    4. Simulate Fibonacci growth until >= m
    5. Maximum iterations: 200 cycles

  Implementation:
    - Use 64-bit signed arithmetic
    - State machine: IDLE → CHECK → NEGATIVE → SIMULATE → DONE
    - Handle overflow with saturation
    - Bounded loop count prevents infinite computation
