Module: SquareKiller
Description: Finds the largest square killer in a binary matrix up to 4x4.

Inputs:
  clk        : Clock signal (rising edge)
  rst_n      : Active-low synchronous reset
  start      : Start pulse (assert for 1 cycle to begin computation)
  row0, row1, row2, row3 : 4-bit rows of the matrix (each bit is a cell)
  R          : Number of rows in the matrix (1..4), 3-bit unsigned
  C          : Number of columns in the matrix (1..4), 3-bit unsigned

Outputs:
  result     : 4-bit signed output. The largest killer size (2..4) or -1 (4'b1111) if none.
  done       : Asserted high for 1 cycle when result is valid.

Behavior:
  The module searches for the largest square submatrix (size >=2) that is symmetric under 180-degree rotation.
  It starts from the largest possible size (min(R,C)) and checks all positions.
  On reset, done=0, result=0.
  When start is asserted, computation begins.
  When done is asserted, result holds the answer.
  If no killer exists, result = -1 (4'b1111).
  The module uses a state machine to iterate over sizes and positions.

Timing:
  - Assert start for 1 clock cycle.
  - done will go high within a bounded number of cycles (worst-case ~100 cycles for 4x4).
  - Sample result on the same cycle done is high.

Reset:
  - On rst_n=0: all state cleared, done=0, result=0.
  - Minimum 2 clock cycles of reset recommended.

Implementation details:
  - The module does not store the matrix; it uses the row inputs directly.
  - The state machine ensures that the largest killer is found first.
  - The result is a signed 4-bit value (range -1 to 4).
