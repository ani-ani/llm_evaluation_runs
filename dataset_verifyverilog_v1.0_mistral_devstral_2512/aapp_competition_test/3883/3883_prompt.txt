Module Name: polyline_solver

Description:
Given two positive integers a and b (1 ≤ a, b ≤ 10^9), find the minimum positive x such that the point (a,b) lies on the polyline passing through (0,0), (x,x), (2x,0), (3x,x), (4x,0), ...

Interface Specification:

Inputs:
- a : 32-bit unsigned integer (first coordinate)
- b : 32-bit unsigned integer (second coordinate)

Outputs:
- valid : 1-bit, asserted high when a ≥ b (solution exists)
- num   : 32-bit unsigned, numerator of x when valid = 1
- den   : 32-bit unsigned, denominator of x when valid = 1

When valid = 1, x = num / den. When valid = 0, num and den are don't-care.

Behavior:
1. If a < b: assert valid = 0.
2. Else:
   - Compute k_max = (a - b) / (2 * b) using integer division.
   - Compute den = 2 * (k_max + 1)
   - Compute num = a + b
   - Assert valid = 1.

All operations are integer; no floating-point arithmetic required in hardware.

Implementation Notes:
- Use 32-bit unsigned registers/wires for all arithmetic.
- Division is integer division (truncates towards zero).
- The computed x is exact as a rational number; the testbench will convert to float for verification.
