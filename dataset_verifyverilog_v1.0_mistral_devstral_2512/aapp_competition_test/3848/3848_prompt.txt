Module: next_tolerable_string

Description:
Finds the lexicographically next tolerable string of the same length. A tolerable string has no palindromic substrings of length 2 or more and uses only the first p letters.

Interface:
- clk: Clock input
- rst_n: Active-low reset
- start: Start computation pulse
- n[3:0]: String length (1-8)
- p[3:0]: Alphabet size (1-8)
- s[0:7][7:0]: Input string characters (ASCII 'a' to 'h')
- result[0:7][7:0]: Output string
- done: Computation complete pulse
- exists: 1 if next string exists, 0 otherwise

Functionality:
1. On start pulse, load input string
2. Process from end to beginning to find increment point
3. Ensure no palindromes (no equal adjacent chars, no equal chars with one between)
4. Fill remaining positions with smallest valid characters
5. Assert done when complete, set exists based on result

Timing:
- Maximum 64 cycles for 8-character string
- Done asserted for 1 cycle when complete
