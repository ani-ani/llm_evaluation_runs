Module: tsp_portal_solver
Description: Solves the TSP with portals for n=4 planets using Manhattan distance.
Inputs:
  - clk, rst_n, start
  - x0,y0,z0, x1,y1,z1, x2,y2,z2, x3,y3,z3 (10-bit coordinates)
Outputs:
  - result (16-bit minimum distance)
  - done (1-cycle high when result ready)
Behavior:
  - On start pulse, inputs are captured and computation begins.
  - The design registers inputs, computes all pairwise Manhattan distances,
    enumerates 6 permutations of planets 1-3, and for each permutation
    calculates the total distance and maximum matching weight (portal savings).
  - The minimum cost (total_distance - max_matching) over all permutations is output.
  - Computation takes one clock cycle after start, then done is asserted.
  - Uses combinational logic for distance calculations and permutation evaluation.

Interface Specification:
  Inputs:
    clk         : Clock, rising edge
    rst_n       : Active-low synchronous reset
    start       : Start pulse, 1 cycle
    x0[9:0]     : x-coordinate of planet 0
    y0[9:0]     : y-coordinate of planet 0
    z0[9:0]     : z-coordinate of planet 0
    x1[9:0]     : x-coordinate of planet 1
    y1[9:0]     : y-coordinate of planet 1
    z1[9:0]     : z-coordinate of planet 1
    x2[9:0]     : x-coordinate of planet 2
    y2[9:0]     : y-coordinate of planet 2
    z2[9:0]     : z-coordinate of planet 2
    x3[9:0]     : x-coordinate of planet 3
    y3[9:0]     : y-coordinate of planet 3
    z3[9:0]     : z-coordinate of planet 3
  Outputs:
    result[15:0]: Minimum total Manhattan distance
    done        : Asserted high for 1 cycle when result is valid

Reset Behavior:
  - On rst_n=0: all registers cleared, done=0, result=0
  - Minimum 2 clock cycles of reset required

Timing:
  - Assert start for 1 clock cycle
  - One clock cycle later, done goes high and result is valid
  - Result remains valid until next start or reset

Note: This module supports exactly 4 planets. For larger n, the same approach
      can be extended by increasing the parameter N and using generate loops.
