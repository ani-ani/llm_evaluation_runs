Design a Verilog module for the Oostende Beach food truck problem.

Module Name: BeachFoodTruck

Parameters:
- N = 5 (number of huts, scaled from original)
- DATA_WIDTH = 8 (bits per hut population)
- IDX_WIDTH = 3 (bits for index, since 5 needs 3 bits)

Inputs:
- clk: clock, rising edge triggered
- rst_n: active-low synchronous reset
- start: start computation pulse (1 cycle)
- addr: [IDX_WIDTH-1:0] address for memory write
- data_in: [DATA_WIDTH-1:0] data to write to hut
- wr_en: write enable, updates hut[addr] = data_in on clock edge

Outputs:
- optimal_pos: [IDX_WIDTH-1:0] optimal food truck position (0 to N-1)
- done: asserted high when computation completes, stays high until next start

Behavior:
1. Memory: N huts stored in internal registers, accessible via addr/data_in/wr_en
2. On start pulse:
   - Compute total population sum = sum(hut[i] for i=0..4)
   - For each position i:
     - Compute diff = max(0, |2*prefix[i] + hut[i] - total| - (hut[i] & 1))
   - Find position i with minimum diff (smallest i if tie)
   - Register result in optimal_pos
   - Assert done=1
3. Reset: clears all huts to 0, done=0, optimal_pos=0

Implementation notes:
- Use combinational logic for diff computation
- Use priority encoder or comparator tree for minimum finding
- State machine: IDLE -> COMPUTE -> DONE -> IDLE
- All arithmetic should handle overflow properly (use 12-bit sums, 13-bit diffs)
