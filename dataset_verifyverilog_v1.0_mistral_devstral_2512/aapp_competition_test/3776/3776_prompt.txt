Module: BrokenClockFix

Description: Implements a broken clock fixer that finds the valid time with minimum digit changes from the input time.

Interface Specification:

Inputs:
  - clk         : Clock signal (rising edge triggered)
  - rst_n       : Active-low synchronous reset
  - start       : Start pulse (assert for 1 cycle to begin computation)
  - format      : 1-bit input (0 for 24-hour, 1 for 12-hour format)
  - time_in     : 16-bit input representing 4 digits: time_in[15:12] = H1, time_in[11:8] = H2, time_in[7:4] = M1, time_in[3:0] = M2

Outputs:
  - time_out    : 16-bit output (same format as time_in)
  - done        : Asserted high for 1 cycle when result is valid

Internal Parameters:
  - MAX_HOURS_24 = 23
  - MAX_HOURS_12 = 12
  - MAX_MINUTES = 59

Behavior:
  - On start pulse, computes the valid time with minimum digit changes
  - For 24-hour: hours 00-23, minutes 00-59
  - For 12-hour: hours 01-12, minutes 00-59
  - Outputs the best matching time as 16-bit packed digits
  - Computation completes within 100 clock cycles

Timing:
  - Assert start for 1 clock cycle
  - done will go high when computation completes
  - Sample time_out on the same cycle done is high

Reset behavior:
  - On rst_n=0: done=0, time_out=0, internal state cleared
  - Minimum 2 clock cycles of reset required
