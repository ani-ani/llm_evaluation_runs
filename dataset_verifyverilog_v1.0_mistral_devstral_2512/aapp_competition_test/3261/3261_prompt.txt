Module: zigzag_grey_counter
Parameters: R=4, C=4 (fixed 4x4 grid), K_WIDTH=16, RESULT_WIDTH=16

Interface:
  Inputs:
    - clk: Clock, rising edge
    - rst_n: Active-low reset, min 2 cycles
    - start: Pulse high for 1 cycle to start
    - K[15:0]: Number of cells to visit (1-16)
  Outputs:
    - result[15:0]: Count of grey cells in first K visits
    - done: High for 1 cycle when result ready

Behavior:
  - Walking pattern: Diagonal zig-zag
    * Even diagonals: (0,d) to (d,0)
    * Odd diagonals: (d,0) to (0,d)
  - Cell is grey if (row & col) == 0
  - Process cells until K visited
  - Reset clears all state

Example: For 4x4 grid, K=6 visits (0,0),(1,0),(0,1),(2,0),(1,1),(0,2). Grey: 5.
