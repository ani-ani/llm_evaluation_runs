module specification: Design a Verilog module that processes queries on a fixed-size array (max 16 elements) with values in range [1,5]. It should support two operations:

1. Update query: Change value at position p (1-indexed) to v
2. Query type 2: Find length of shortest contiguous subarray containing all numbers 1..K

Interface:
- Inputs: clk, rst_n, start, query_type[1:0], update_pos[3:0], update_value[2:0]
- Outputs: result[15:0], done

Timing:
- For update: assert start for 1 cycle with query_type=1, update_pos and update_value set
- For query: assert start for 1 cycle with query_type=2
- done goes high when operation completes

Implementation:
- Store 16-element array in registers
- For query type 2: Use state machine with sliding window (O(N^2) worst case, acceptable for N=16)
- Check all subarrays: for each left index, find shortest right index that contains all numbers
- Output -1 if no such subarray exists

Use 3-bit storage for array values (0-4 representing 1-5). 4-bit positions (0-15).
