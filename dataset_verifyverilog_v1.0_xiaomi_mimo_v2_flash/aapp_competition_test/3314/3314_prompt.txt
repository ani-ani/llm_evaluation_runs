Design a Verilog module that solves the wheel rotation problem with 8 columns. The module should:

INTERFACE:
  Inputs:
    - wheel0[0:7][1:0]: First wheel's letters (8 columns, 2-bit per column: 00=A, 01=B, 10=C)
    - wheel1[0:7][1:0]: Second wheel's letters
    - wheel2[0:7][1:0]: Third wheel's letters
  Output:
    - result[4:0]: Minimum rotations (5-bit, -1 = 11111 for impossible)

FUNCTIONALITY:
  For each combination of rotations (r0, r1, r2 from 0 to 7):
    1. Calculate rotation cost: cost = min(r0,8-r0) + min(r1,8-r1) + min(r2,8-r2)
    2. For column j (0 to 7), compute indices:
       idx0 = (j + r0) % 8
       idx1 = (j + r1) % 8
       idx2 = (j + r2) % 8
    3. Check if wheel0[idx0], wheel1[idx1], wheel2[idx2] are all different
    4. If all 8 columns valid, record cost
  Output minimum cost among valid rotations, or -1 if none.

IMPLEMENTATION:
  Use combinational always block with nested loops (0-7 for each rotation). Precompute costs using: cost = (r <= 4) ? r : (8-r). Check distinctness by comparing 2-bit values (A=00, B=01, C=10). Use 4-bit cost accumulator, 5-bit signed output.
