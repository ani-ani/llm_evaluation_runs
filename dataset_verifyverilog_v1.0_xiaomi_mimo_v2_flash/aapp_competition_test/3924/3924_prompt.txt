Design a sequential Verilog module for garbage disposal with:

Inputs:
  clk, rst_n (active-low reset), start
  n[7:0]: number of days (1-8)
  k[7:0]: bag capacity
  a_0 to a_7[7:0]: garbage per day
Outputs:
  bags[15:0]: minimum number of bags
  done: asserted when computation completes

Behavior:
  - On start pulse, reset and process days 0 to n-1
  - For each day:
    1. Compute bags for leftover from previous day: ceil(last/k)
    2. Use remaining space for today's garbage
    3. Update leftover for next day
  - After last day, dispose any remaining leftover
  - Use 8-bit arithmetic for garbage/bags, 16-bit for total
  - Implement with state machine (IDLE, PROCESSING, DONE)
