Design a Verilog module for finding the largest k-multiple free subset. Scale down: max 16 elements, 16-bit numbers, 16-bit k. Algorithm: 1) Sort array ascending using bubble sort, 2) Traverse sorted array, for each included number x, exclude any x*k from remaining elements. 

INTERFACE SPECIFICATION:
  Inputs:
    - clk         : Clock signal (rising edge)
    - rst_n       : Active-low synchronous reset
    - start       : Start pulse (1 cycle)
    - n           : Number of valid elements (4-bit, 1-16)
    - k           : Multiplier (16-bit)
    - arr_0 to arr_15: 16 input elements (16-bit each)
  Outputs:
    - count       : Result (5-bit, 0-16)
    - done        : Asserted high for 1 cycle when result is valid

  Behavior:
    - Reset: done=0, count=0
    - Start: Loads array, sorts, computes result
    - Done: Asserted after computation (max 500 cycles)
    - Bubble sort: ascending order
    - Marking: Traverse sorted array, for each included x, exclude x*k in remaining elements
