Module: monotone_seq_generator

Purpose: Generates a permutation of 1..N with longest monotone subsequence length exactly K.

Interface:
- Inputs:
  - clk: clock (rising edge)
  - rst_n: active-low synchronous reset
  - start: pulse to start (1 cycle high)
  - N[7:0]: sequence length (1-16)
  - K[7:0]: required monotone length (1-16)
- Outputs:
  - data[7:0]: current output element
  - index[7:0]: current position (0 to N-1)
  - valid: data is valid
  - done: sequence complete
  - error: invalid inputs (K < ceil(sqrt(N)) or K > N)

Behavior:
1. Reset: All outputs zero, done=0, valid=0, error=0
2. Start: Latch N,K, compute min_K = ceil(sqrt(N))
3. If K < min_K or K > N: error=1, done=1, no output
4. Else: Generate sequence:
   - Compute q = N/K, r = N%K
   - Blocks: K blocks, sizes q or q+1
   - Block i: start_num = 1 + i*q + min(i,r)
   - Within block: decreasing from start_num+size-1 down to start_num
   - Output one element per cycle
5. After N cycles: done=1, valid=0
6. Remain in DONE until reset

State Machine: IDLE → INIT → OUTPUT → DONE, with ERROR state for invalid inputs

Implementation must compute division/modulo for K≤16 and sqrt bound. All outputs registered.
