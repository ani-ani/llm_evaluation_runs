MODULE: count_bulbasaurs

DESCRIPTION: Counts how many times the word "Bulbasaur" can be formed from a given string by analyzing character frequencies. The word "Bulbasaur" has the following character counts: B=1, u=2, l=1, b=1, a=2, s=1, r=1.

INTERFACE SPECIFICATION:

  Inputs:
    - clk: Clock signal (rising edge triggered)
    - rst_n: Active-low synchronous reset
    - start: Start pulse (assert for 1 cycle to begin computation)
    - char_array[15:0][7:0]: 16-element array of 8-bit ASCII characters
    - valid_length: 4-bit input indicating number of valid characters (1-16)
  
  Outputs:
    - result: 4-bit output (maximum 8 Bulbasaurs possible with 16 characters)
    - done: Asserted high for 1 cycle when result is valid
  
  Timing:
    - Assert start for 1 clock cycle
    - Computation completes within 20 cycles
    - Sample result on the same cycle done is high
  
  Reset behavior:
    - On rst_n=0: done=0, result=0, internal state cleared
    - Minimum 2 clock cycles of reset required

FUNCTIONAL REQUIREMENTS:
1. Count occurrences of each required character: B, u, l, b, a, s, r
2. Note: 'u' and 'a' each appear twice in "Bulbasaur"
3. Compute minimum of: count_B, count_u//2, count_l, count_b, count_a//2, count_s, count_r
4. Output this minimum value
5. Case-sensitive: only exact matches count
