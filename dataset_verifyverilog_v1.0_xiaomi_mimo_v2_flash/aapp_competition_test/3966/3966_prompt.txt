Design a Verilog module that computes the maximum score for the Appleman and Toastman game, given a small fixed-size array.

Module name: appleman_toastman

Parameters:
  MAX_N = 4        // Maximum number of elements
  DATA_WIDTH = 8   // Bit width of each number
  RESULT_WIDTH = 16 // Bit width of the result

Inputs:
  clk        : Clock signal (rising edge triggered)
  rst_n      : Active-low synchronous reset
  start      : Start pulse (assert for 1 cycle to begin computation)
  len        : Number of valid elements in the array (1 to MAX_N), 3-bit unsigned
  arr_0, arr_1, arr_2, arr_3 : Input array elements, each DATA_WIDTH bits

Outputs:
  result     : 16-bit computation result
  done       : Asserted high for 1 cycle when computation is complete

Behavior:
  The module should compute the maximum possible score using the following algorithm:
    1. Sort the first 'len' elements of the array in non-decreasing order.
    2. Compute the weighted sum: sum_{i=0}^{len-1} sorted_array[i] * (i+2)
    3. Subtract the largest element (which is sorted_array[len-1])
    4. Output the result.

  Example: For len=3 and array [3,1,5], after sorting [1,3,5], weighted sum = 1*2 + 3*3 + 5*4 = 2+9+20=31, then subtract 5 -> 26.

Timing:
  - On reset, the module returns to IDLE state with done=0, result=0.
  - When start is asserted, the module captures the input array and begins computation.
  - The computation may take multiple clock cycles (up to 50 cycles for MAX_N=4).
  - When computation is finished, done is asserted for one cycle and result is valid.
  - The module then returns to IDLE state.

Implementation details:
  - Use a state machine to control the sorting and computation.
  - Implement bubble sort for sorting the array. The sorting should only consider the first 'len' elements.
  - Use registers to store the array during sorting.
  - Use a loop for the weighted sum computation.

Additional notes:
  - The array inputs arr_0..arr_3 are provided in parallel and should be captured when start is asserted.
  - The len input must be between 1 and 4 inclusive. If len is 0 or greater than 4, the behavior is undefined.
  - The result is 16 bits wide, which is sufficient for the scaled-down parameters.
