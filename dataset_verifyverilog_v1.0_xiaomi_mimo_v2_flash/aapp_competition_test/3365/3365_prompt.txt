Module name: MaxScorePartition

Parameters:
- N = 8 (maximum number of elements)
- K = 3 (maximum number of segments)
- VAL_WIDTH = 8 (bit width of input values)
- RESULT_WIDTH = 8 (bit width of result)

Ports:
- input wire clk
- input wire rst_n
- input wire start
- input wire [3:0] n   // actual number of elements (1..8)
- input wire [2:0] k   // actual number of segments (1..3)
- input wire [7:0] arr_0, arr_1, arr_2, arr_3, arr_4, arr_5, arr_6, arr_7
- output reg [7:0] result
- output reg done

Internal signals:
- reg [2:0] state, next_state;
- reg [7:0] seg_score[0:7][0:7]; // segment scores for subarrays i..j
- reg [7:0] temp_min, temp_max;
- reg [3:0] i, j, p, split;
- reg [7:0] current_gcd;
- integer iter;

State encoding:
- IDLE = 0
- PRECOMPUTE = 1
- ENUMERATE = 2
- DONE = 3

Algorithm description:
1. On start pulse (start==1 for one cycle), transition from IDLE to PRECOMPUTE.
2. PRECOMPUTE: Compute seg_score[i][j] for all 0 <= i <= j < n.
   - For each i from 0 to n-1:
       current_gcd = arr_i
       For each j from i to n-1:
           if j > i: current_gcd = gcd(current_gcd, arr_j)
           seg_score[i][j] = largest_prime_factor(current_gcd)  // 0 if current_gcd <= 1
   - After finishing all i,j, transition to ENUMERATE.
3. ENUMERATE: Enumerate all partitions of the n elements into k segments.
   - If k == 1:
        temp_max = seg_score[0][n-1]
   - Else if k == 2:
        temp_max = 0
        for split = 1 to n-1:
            temp_min = min(seg_score[0][split-1], seg_score[split][n-1])
            if temp_min > temp_max: temp_max = temp_min
   - Else if k == 3:
        temp_max = 0
        for i = 1 to n-2:
            for j = i+1 to n-1:
                temp_min = min(seg_score[0][i-1], seg_score[i][j-1], seg_score[j][n-1])
                if temp_min > temp_max: temp_max = temp_min
   - After enumeration, transition to DONE.
4. DONE: Set result = temp_max, assert done = 1 for one cycle, then return to IDLE.

Helper functions:
- gcd(a, b): combinational function using modulo operation, iterates until b==0.
- largest_prime_factor(n): case statement lookup for n in 0..255. For n<2 return 0, else return largest prime divisor.

Reset behavior:
- On rst_n == 0: state <= IDLE, done <= 0, result <= 0, all internal variables cleared.

Timing:
- start must be high for one clock cycle.
- done will be high for one cycle when computation finishes.
- result is valid when done is high.
- Total cycles required: at most 100 cycles (worst-case for n=8, k=3).

Note: The module uses the input n to limit loops; for n < N, the unused arr elements are ignored.
