Create a Verilog module for the bureaucrat stamp problem with the following interface:

Module: bureaucrat_stamp
Inputs:
  - clk: clock signal
  - rst_n: active-low reset
  - start: start computation pulse
  - grid_in[0:7]: 8-bit wide input array for 8x8 grid (8 elements, each 8 bits)
Outputs:
  - min_nubs: 8-bit output for minimum nub count
  - done: computation complete signal

Behavior:
The module should:
1. When start is asserted, read the 8x8 grid pattern
2. Iterate through all possible shifts (dx, dy) from -7 to 7 (excluding 0,0)
3. For each shift, compute the minimal stamp that can produce the pattern
4. Track the minimum number of nubs across all valid shifts
5. Output the result when complete

Implementation should use state machine with bounded loops suitable for hardware synthesis.
