Module: AnthonyCoraGame

Inputs:
  - clk: Clock signal (rising edge)
  - rst_n: Active-low synchronous reset
  - start: Start computation pulse (1 cycle)
  - N: 4-bit input (1-16)
  - M: 4-bit input (1-16)
  - p_in: 32-bit fixed-point Q16.16 probability
  - p_valid: Valid signal for p_in

Outputs:
  - result: 32-bit fixed-point Q16.16 probability
  - done: Asserted when computation complete
  - error: Asserted if N or M out of range (1-16)

Behavior:
  1. Initialize DP table with base cases
  2. Process rounds sequentially (max 31 rounds for N+M≤32)
  3. Update states: dp[i][j] = p*dp[i][j-1] + (1-p)*dp[i-1][j]
  4. Output dp[N][M]

Constraints:
  - Use 32-bit fixed-point arithmetic (Q16.16)
  - State machine: IDLE, LOAD, COMPUTE, FINISH
  - Round counter: 0 to (N+M-1)
  - Timeout: 1000 cycles max
