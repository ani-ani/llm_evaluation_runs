Verilog module specification:

INTERFACE:
  Inputs:
    - clk       : Clock
    - rst_n     : Active-low reset
    - start     : Start pulse
    - s_len[3:0]: Length of string s (1-16)
    - t_len[3:0]: Length of string t (1-16)
    - s_data[15:0]: Packed s (each bit: 0=a, 1=b)
    - t_data[15:0]: Packed t
  Outputs:
    - done      : Computation complete
    - op_count[3:0]: Number of operations
    - operations[15:0]: Packed operations (each 2 bits for length)

ALGORITHM:
  1. Scan strings from right to left
  2. When mismatch found, record swap operation
  3. Continue until strings are pure

IMPLEMENTATION:
  Use state machine with states:
    IDLE, SCAN, SWAP, COMPLETE
  Max operations: 16
  Max string length: 16
