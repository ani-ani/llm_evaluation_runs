### Install: ###
1) Install Icarus Verilog. For windows follow **https://bleyer.org/icarus/ version:v12
2) Install cocotb outside the virtual environment
3) Install other python pkgs from requirements.txt from verifyverilog dataset git.

### Run: ###
1) verifyverilog_generate_rtl.py to generate the rtl from the choosen LLM
1) verifyverilog_check_rtl.py to compile & run testbench verification for the rtl generated by LLM's
