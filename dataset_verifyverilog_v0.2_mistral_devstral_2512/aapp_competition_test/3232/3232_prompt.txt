Design a sequential Verilog module named 'string_rearrange' that implements a substring uniqueness rearrangement for a fixed 8-character string.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [7:0][7:0] char_array // 8 characters, each 8 bits (ASCII)

Outputs:
output reg [7:0][7:0] result // rearranged string of 8 characters
output reg valid // high when valid solution found
output reg no_solution // high when no solution exists
output reg done // high when computation complete

Specifications:
- Input string length N = 8 (even)
- Number of substrings of length N/2 = 4: positions 0-3, 1-4, 2-5, 3-6, 4-7 (5 substrings total)
- Goal: Rearrange characters so all 5 substrings of length 4 are different
- Process: Sort the input characters first, then check if the sorted order creates unique substrings
- If not unique, apply a simple cyclic shift or reverse operation
- Use state machine with states: IDLE, SORT, CHECK, MODIFY, VERIFY, DONE
- Latency: Maximum 200 clock cycles from start to done
- If all characters are the same (e.g., 'zzzzzzzz'), set no_solution high
- Output result in ASCII format

State Machine Behavior:
1. IDLE: Wait for start signal
2. SORT: Sort characters alphabetically using bubble sort (max 8 elements)
3. CHECK: Generate all 5 substrings of length 4 and compare them
4. MODIFY: If duplicates found, apply transformation (reverse or cyclic shift)
5. VERIFY: Check again if all substrings are unique
6. DONE: Set valid/no_solution based on final check

The module should use internal registers to store intermediate states and perform comparisons using combinational logic.
