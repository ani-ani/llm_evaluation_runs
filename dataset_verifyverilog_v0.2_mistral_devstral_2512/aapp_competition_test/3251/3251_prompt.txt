Design a sequential Verilog module named 'longest_interval_chain' that finds the longest sequence of nested intervals where each interval contains the next.

Problem Adaptation:
- Input: N intervals (N≤8) with coordinates A,B (1-255)
- Output: Length K and sequence of intervals (largest to smallest)
- Algorithm: Sort intervals by A ascending, B descending; then find longest decreasing subsequence on B values

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [2:0] num_intervals // number of intervals (1-8)
input [7:0] interval_a [0:7] // left endpoints
input [7:0] interval_b [0:7] // right endpoints

Outputs:
output reg [2:0] result_length // length of longest chain (1-8)
output reg [7:0] result_a [0:7] // left endpoints of result sequence
output reg [7:0] result_b [0:7] // right endpoints of result sequence
output reg done // high when computation complete

Latency: Maximum 100 clock cycles after start asserted.

Module should:
1. Sort intervals by (A ascending, B descending) using state machine
2. Find longest decreasing subsequence on B values using DP
3. Reconstruct and output the sequence
4. Use states: IDLE, SORTING, FINDING_LENGTH, RECONSTRUCTING, DONE
5. Initialize result arrays to zeros
6. Done signal pulses high for one cycle when complete
