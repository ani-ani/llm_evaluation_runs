Design a sequential Verilog module named 'min_trucks_solver' that computes the minimum number of trucks required for delivery in a simplified road network.

The module solves a scaled-down version with these constraints:
- Max nodes: 8 (junctions 0-7)
- Max edges: 8
- Max clients: 4
- Edge weights: 0-15 (4-bit values)

Module Interface:
input clk: Clock signal
input rst_n: Active-low reset
input start: Start computation
input [2:0] num_nodes: Number of nodes in graph (2-8)
input [2:0] num_edges: Number of edges in graph (1-8)
input [2:0] num_clients: Number of clients (1-4)
input [2:0] client_locs [3:0]: Client locations (node indices)
input [2:0] edge_u [7:0]: Edge source nodes
input [2:0] edge_v [7:0]: Edge destination nodes
input [3:0] edge_w [7:0]: Edge weights (0-15)

Outputs:
output reg [2:0] min_trucks: Result (1-8)
output reg done: High when computation complete

Algorithm Steps:
1. Compute shortest paths from warehouse (node 0) to all nodes using parallel relaxation or iterative updates (max 8 cycles for Bellman-Ford)
2. Build the Shortest Path DAG: include edge (u->v) only if dist[u] + weight == dist[v]
3. Compute minimum number of vertex-disjoint paths needed to cover all client nodes in this DAG
4. This equals the minimum path cover problem on a DAG restricted to client nodes
5. Use iterative DP or state machine to find minimum trucks

Behavior: 
- Use state machine with states: IDLE, BUILD_DIST, BUILD_DAG, COMPUTE_RESULT, DONE
- First compute distances from node 0 using 8 iterations (sufficient for N=8)
- Then construct DAG edges where shortest path property holds
- Finally compute minimum path cover for clients using dynamic programming or iterative search
- Result is the minimum number of trucks needed
- Latency: ~64 clock cycles after start asserted
