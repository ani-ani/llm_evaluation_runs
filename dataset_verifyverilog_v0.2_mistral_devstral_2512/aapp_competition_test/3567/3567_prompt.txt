Design a sequential Verilog module named 'character_creator' that implements a character similarity minimization algorithm.

The module finds a k-bit character that minimizes the maximum similarity to n existing characters. Similarity is defined as the number of positions where both characters have the same value (both 1 or both 0).

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [7:0] num_players // number of existing characters (n)
input [7:0] num_features // number of features (k)
input [7:0][7:0] characters // array of n characters, each is k-bit (packed: characters[i] is character i)

Outputs:
output reg [7:0] best_character // the best character found
output reg [7:0] min_max_similarity // the minimum possible maximum similarity
output reg done // high when computation complete

Specification:
- k ≤ 8 bits, n ≤ 8 characters
- For each candidate character (0 to 2^k-1), compute similarity with all existing characters
- Similarity of two k-bit values a and b: count of positions where a[i] == b[i]
- Find the candidate with minimum maximum similarity across all existing characters
- Return the best character and its max similarity

Latency: Maximum 256 clock cycles (iterates through 2^k candidates, k≤8)

State Machine:
- IDLE: Wait for start signal
- INIT_CANDIDATE: Initialize candidate counter and max_sim
- COMPUTE_SIM: Compute similarity with one existing character
- UPDATE_MAX: Update max similarity for current candidate
- NEXT_CANDIDATE: Move to next candidate
- DONE: Set done signal, output results

The module should use combinational logic for similarity calculation and sequential logic for iterating through candidates.
