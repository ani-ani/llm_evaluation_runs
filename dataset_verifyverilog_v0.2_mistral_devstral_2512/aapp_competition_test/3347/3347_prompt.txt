Design a sequential Verilog module named 'gold_stores' that implements a simplified greedy scheduling algorithm for the Atlantis gold store problem.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [7:0] valid_count // number of valid stores (1-8)
input [7:0][15:0] time_array // round-trip times for each store (t_i)
input [7:0][15:0] altitude_array // altitudes for each store (h_i)

Outputs:
output reg [3:0] result // maximum number of stores that can be visited
output reg done // high when computation complete

Specification:
The module should implement the following algorithm:
1. Sort stores by altitude (ascending) using bubble sort
2. Iterate through sorted stores, tracking cumulative time
3. Count stores where (cumulative_time + t_i) <= h_i
4. Return the count

Constraints:
- Maximum 8 stores (valid_count ranges 1-8)
- All values are 16-bit unsigned integers
- Sort should be done in first 8 clock cycles
- Processing should complete within 16 clock cycles total
- Use state machine with states: IDLE, SORT_PHASE, PROCESS_PHASE, DONE

Timing:
- Result valid 16 clock cycles after start asserted
- Sort phase: 8 cycles maximum
- Processing phase: 8 cycles maximum

Fixed-Point Note: This problem uses integer arithmetic, no floating-point conversion needed.
