Design a sequential Verilog module named 'array_specializer' that computes the maximum possible minimum mex for a set of subarray queries and generates the corresponding array.

The module should implement the following logic:
1.  **Input Processing**: Receive 'm' subarray queries (start/end indices). In each clock cycle, one query is provided.
2.  **Logic**: The optimal minimum mex is determined by the minimum length of any subarray query (length = end - start + 1). The generated array should be a repeating pattern of numbers from 0 to (min_length - 1).
3.  **Output**: The module outputs the calculated minimum mex (which equals min_length) and the generated array values.

Constraints:
- Number of elements N = 8
- Number of queries M = 4
- Maximum Query Range = 8 (indices 0 to 7)
- All input indices are 0-based.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // High to start processing queries
input query_valid // High when query inputs are valid
input [2:0] l_i // Left index of current query (0-7)
input [2:0] r_i // Right index of current query (0-7)

Outputs:
output reg [2:0] min_mex // The calculated minimum mex (equal to min subarray length)
output reg [2:0] array_out // The generated array value for current cycle
output reg output_valid // High when min_mex and array_out are valid
output reg done // High when all queries processed and array generation starts

Behavior:
The module has a parameterized number of queries (M=4).
When 'start' is asserted, the module enters a processing state.
For each valid 'query_valid' cycle, it captures l_i and r_i.
It updates 'current_min_length' = min(current_min_length, r_i - l_i + 1).
After M queries are processed, 'min_mex' is set to 'current_min_length'.
Then, the module generates the array output: a repeating sequence 0, 1, ..., current_min_length-1, 0, 1, ... for N cycles.
It asserts 'done' once the sequence generation begins.
Use a state machine: IDLE, READ_QUERIES, COMPUTE, OUTPUT.
Specify latency: Result valid after query processing + N cycles.
