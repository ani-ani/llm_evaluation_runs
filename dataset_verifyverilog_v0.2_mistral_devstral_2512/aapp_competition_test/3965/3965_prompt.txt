Design a sequential Verilog module named 'syllable_checker' that checks if the number of vowels in a text line matches a target pattern. 

The module must process the input text character by character. Since hardware works with fixed-width signals, we will use a fixed-width representation:
- Input text is 16 characters long (128 bits). 
- Vowels are 'a', 'e', 'i', 'o', 'u', 'y'.
- Words separated by spaces are treated as part of the line; the total vowel count of the line is compared to the pattern.
- Words with 0 vowels contribute 0 to the total.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start processing signal
input [7:0] pattern // Target number of vowels (0-100)
input [127:0] line // 16 ASCII characters. Represents the line of text.

Outputs:
output reg match // High if vowel count == pattern
output reg done // High when processing is complete

Behavioral Description:
1. On reset, go to IDLE state.
2. When 'start' is high, transition to a processing state.
3. Scan the 128-bit 'line' input in chunks of 8 bits (1 character).
4. For each character, check if it is a vowel ('a', 'e', 'i', 'o', 'u', 'y'). 
   - ASCII values for vowels (lowercase): 'a'=0x61, 'e'=0x65, 'i'=0x69, 'o'=0x6F, 'u'=0x75, 'y'=0x79.
   - Ignore spaces (0x20) and consonants.
5. Maintain an 8-bit internal counter for vowel count.
6. After 16 characters are checked (or earlier if we optimize, but 16 cycles is fine), compare the counter with 'pattern'.
7. Set 'match' high if they are equal, low otherwise.
8. Set 'done' high for one cycle when finished, then return to IDLE.

Use a state machine with states: IDLE, CHECK_CHAR, DONE.
