Design a sequential Verilog module named 'dice_reroll_optimizer' that computes the optimal number of dice to re-roll.

Inputs:
input clk // clock signal
input rst_n // active-low reset  
input start // start computation
input [7:0] K // number of dice (scaled to max 8)
input [7:0] target // target sum T
input [5:0] initial_rolls [7:0] // initial dice values, 1-6 each, max 8 dice

Outputs:
output reg [3:0] optimal_k // optimal number of dice to re-roll (0-8)
output reg done // high when computation complete

Latency: Approximately 150 clock cycles after start.

The module should:
1. Compute sum of initial dice rolls
2. For each k from 0 to K:
   - For each possible sum of remaining dice (by choosing which k dice to re-roll)
   - Compute probability of k dice achieving (target - remaining_sum)
   - Track the maximum probability and corresponding k
3. Output the k with highest probability (smallest k if tie)

Use DP to compute probability distribution for k dice: dp[k][s] = probability of k dice summing to s
Probabilities can be represented as fixed-point Q16.16 or scaled integers.

Use state machine with states: IDLE, COMPUTE_SUM, CALCULATE_PROBABILITIES, EVALUATE_OPTIONS, DONE.

For probability calculations: each k dice combination has 6^k outcomes. Use lookup tables for small k.

Implement with bounded loop counts for K≤8.
