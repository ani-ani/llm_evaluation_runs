Design a sequential Verilog module named 'garbage_disposal' that computes the minimum number of bags needed to dispose of garbage over n days.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset (1: normal operation, 0: reset)
input start // Start computation (pulse high for one cycle)
input [7:0] n // Number of days (max 16)
input [7:0] k // Bag capacity (max 256)
input [7:0] a_i // Garbage produced on current day (8-bit value, max 255)

Outputs:
output reg [31:0] total_bags // Total bags needed
output reg done // High when computation is complete
output reg [4:0] day_index // Current day index (0 to n-1), valid during processing

Behavioral Description:
The module processes garbage day-by-day. It uses a state machine with states: IDLE, FETCH_DAY, PROCESS_DAY, FINISHED.
1. IDLE: Waits for start signal.
2. FETCH_DAY: Reads the garbage amount for the current day (a_i) from an external memory interface or input stream (here simulated by a_i input changing per cycle).
3. PROCESS_DAY: Calculates bags for current day and carries over remainder.
   - Logic: current_garbage = a_i + carry_from_previous
   - bags_today = current_garbage / k
   - new_carry = current_garbage % k
   - If it's the last day (day_index == n-1), any non-zero carry must use one extra bag.
4. FINISHED: Sets done high and holds total_bags.

The module must accumulate total_bags over the days. It assumes a_i is presented externally for each day index. Since this is a sequential module, it processes one day per clock cycle (or state transition). Total latency is approximately n + 2 cycles.
