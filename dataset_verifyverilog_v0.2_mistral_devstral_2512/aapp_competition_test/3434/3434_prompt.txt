Design a sequential Verilog module named 'explosion_probability' that calculates the probability that all opponent minions are eliminated by a random damage distribution spell.

Inputs:
input clk // clock signal
input rst_n // active-low reset  
input start // start computation
input [2:0] n // number of my minions (1-5)
input [2:0] m // number of opponent minions (1-5)
input [6:0] damage // total damage d (1-100)
input [5:0] my_minions_health [0:4] // health of my minions (1-6), 5 slots
input [5:0] opp_minions_health [0:4] // health of opponent minions (1-6), 5 slots

Outputs:
output reg [31:0] probability // Q16.16 fixed-point probability
output reg done // high when computation complete

Behavior: The module must compute the probability that all opponent minions are eliminated after dealing d units of damage, where each unit randomly hits a living minion. Use dynamic programming with memoization. Represent probabilities as Q16.16 fixed-point format (multiply by 65536). The state can be represented by the multiset of health values of all minions. Since health is 1-6 and max 10 minions, use a compact state encoding. Implement as a state machine: IDLE, BUILD_STATES, COMPUTE_PROB, DONE. The computation involves building a lookup table for state transitions based on which minion receives the next damage unit. Compute probability using recursion/memoization: P(state, remaining_damage) = sum over all living minions of P(next_state, remaining_damage-1) * (1/num_living_minions). When remaining_damage=0, return 1 if all opponent minions dead, else 0. Use iterative DP to avoid recursion in hardware. Latency: result valid within 5000 clock cycles after start.
