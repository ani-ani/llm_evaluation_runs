Design a sequential Verilog module named 'antimatter_rain' that simulates the collision of falling droplets with horizontal sensors on a small 2D grid.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [3:0] num_droplets // Number of droplets (max 8)
input [3:0] num_sensors // Number of sensors (max 8)
input [3:0] drop_x [0:7] // Array of 8 x-coordinates (1-15)
input [3:0] drop_y [0:7] // Array of 8 y-coordinates (1-15)
input [3:0] sensor_x1 [0:7] // Array of 8 sensor left x-coordinates
input [3:0] sensor_x2 [0:7] // Array of 8 sensor right x-coordinates
input [3:0] sensor_y [0:7] // Array of 8 sensor y-coordinates

Outputs:
output reg [3:0] result [0:7] // Disintegration y-coordinate for each droplet (0 if none)
output reg done // High when all droplet results are computed

Behavior:
The module simulates droplets falling vertically (decreasing y). For each droplet, find the first sensor it hits (sensor y-coordinate is lower than droplet y, sensor x-range covers droplet x, sensor is not destroyed). If a sensor is hit, both droplet and sensor are destroyed. Output the sensor's y-coordinate. If no sensor hit, output 0. Process all droplets.

Algorithm:
1. Reset all sensors to active.
2. Iterate through droplets in input order (0 to num_droplets-1).
3. For each active droplet, scan all sensors.
4. Find the highest sensor (largest y) that is active, has y < drop_y, and drop_x in [x1, x2].
5. Record sensor y in result. Mark sensor and droplet as destroyed.
6. After processing all droplets, set done high.

Use state machine: IDLE, READING, PROCESSING, WRITING, DONE.
Latency: Approximately 64 clock cycles for max inputs.
