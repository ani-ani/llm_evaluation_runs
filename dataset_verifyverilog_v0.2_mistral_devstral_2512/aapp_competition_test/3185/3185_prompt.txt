Design a sequential Verilog module named 'factorial_inverse' that calculates the inverse factorial (finds n given n!).

Since arbitrary-precision arithmetic is impossible in hardware for very large numbers, we adapt the problem to work with 64-bit integers (maximum factorial that fits: 20! = 2432902008176640000). We use a lookup-table approach with iterative calculation.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [63:0] target_factorial // The factorial value to find n for (max 20!)

Outputs:
output reg [7:0] result_n // The computed n value
output reg valid // high when result is valid
output reg found // high if target matches a factorial, low if not found

Latency: Up to 22 clock cycles (max N=20) after start is asserted.

Implementation Details:
- Use state machine: IDLE, CALCULATING, CHECKING, DONE
- Iteratively compute factorial(n) for n=1,2,3,... up to 20
- At each iteration, compare current factorial with target
- If match found, output current n and set found=1
- If no match after n=20, set found=0
- Use 64-bit accumulator for factorial calculation
- Handle edge case: 0! = 1

The module should compute the result sequentially using a bounded loop and output the n value when the factorial matches the input.
