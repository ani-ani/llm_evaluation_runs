Design a sequential Verilog module named 'tree_optimizer' that finds the optimal edge removal and addition to minimize the diameter of an 8-node tree.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [2:0] num_nodes // number of nodes (4-8)
input [7:0] edges [14:0][1:0] // up to 14 edges, each edge is pair of node indices (0-7)

Outputs:
output reg [2:0] best_diameter // minimum achievable diameter
output reg [2:0] remove_edge_u, remove_edge_v // edge to remove (nodes 0-7)
output reg [2:0] add_edge_u, add_edge_v // edge to add (nodes 0-7)
output reg done // high when computation complete

Specification:
The module should implement an algorithm to minimize the tree diameter by:
1. Computing all-pairs shortest paths in the original tree
2. For each edge in the tree:
   a. Remove the edge, splitting into two components
   b. Find the center of each component (node minimizing max distance to all nodes in its component)
   c. Connect the centers with a new edge
   d. Compute the new diameter
3. Track the operation that yields minimum diameter

Latency: Approximately 1000 clock cycles for exhaustive search on 8-node tree.

Use state machine with states: IDLE, COMPUTE_DISTANCES, TRY_EDGES, FIND_CENTERS, EVALUATE, UPDATE_BEST, DONE.

Implement with:
- Adjacency matrix storage (8x8)
- Distance matrix (8x8) for Floyd-Warshall or repeated BFS
- Component tracking during edge removal
- Parallel distance computation where possible
- Bounded loops (max 8 nodes, 7 edges to try)

All node indices are 0-based in the implementation.
