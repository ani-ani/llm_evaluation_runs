Design a sequential Verilog module named 'max_points_game' that computes the maximum points in the array removal game.

Problem: Given an array of N positive integers, remove elements one by one. When removing element at index i, gain min(left_neighbor, right_neighbor) points. After removal, elements glue together. Goal: Find maximum total points.

Algorithm (adapted for small N=16):
1. Use a stack-based approach:
   - Process elements left to right
   - While stack size > 1 AND top <= min(current, second_top):
     - Add min(current, second_top) to score
     - Pop stack top
   - Push current to stack
2. After processing all, add points for remaining stack elements (except first and last)
   - For each remaining element (except ends), add min(left, right)

Interface:
Inputs:
input clk // clock signal
input rst_n // active-low reset  
input start // start computation
input [15:0] data_in // current array element (8-bit value in lower byte, index in upper byte)
input valid_in // data_in is valid
input done_in // indicates all inputs provided

Outputs:
output reg [31:0] result // final maximum score
output reg done // high when computation complete
output reg ready // high when ready for next input

Latency: Result valid 128 clock cycles after start (max 16 elements * 8 cycles each).

Internal State Machine:
- IDLE: Wait for start signal
- LOAD: Receive array elements into internal buffer
- PROCESS: Execute stack algorithm
- CALC_REMAINING: Compute final points from remaining stack
- DONE: Output result

Use 16-element internal buffer. Stack operations should be implemented with combinational logic.
Result should be 32-bit unsigned integer.

Constraints:
- N <= 16 (max 16 elements)
- Each element value <= 255 (fits in 8 bits)
- Maximum score fits in 32 bits
- Use synchronous logic with clock and reset
