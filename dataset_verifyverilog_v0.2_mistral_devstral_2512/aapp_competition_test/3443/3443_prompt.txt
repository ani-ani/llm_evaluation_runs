Design a sequential Verilog module named 'symmetry_adder' that computes the minimum number of additional spots needed to make a set of points symmetric (point or line symmetry).

**Simplified Problem**: Given up to 8 points with 16-bit coordinates, find minimum additions needed.

**Inputs**:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [5:0] num_points // number of points (1-8)
input [7:0][15:0] x_coords // x coordinates of points
input [7:0][15:0] y_coords // y coordinates of points

**Outputs**:
output reg [5:0] min_additions // minimum spots to add (0-8)
output reg done // high when computation complete

**Specification**:
The module must determine the minimum number of points to add such that all points (original + added) are symmetric. Symmetry can be:
1. Point symmetry: All points pair up around a center point
2. Line symmetry: All points reflect across a line

**Algorithm**:
1. Iterate through all possible symmetry configurations
2. For point symmetry: Test if centroid of pairs allows remaining points to be paired
3. For line symmetry: Test rational slope lines (0°, 45°, 90°, 135°, and lines passing through midpoints)
4. Calculate required additions: points that cannot be matched
5. Return minimum across all tested configurations

**Latency**: Result valid within 5000 clock cycles after start asserted.

**State Machine States**: IDLE, RESET, CALCULATE_POINT_SYM, CALCULATE_LINE_SYM, FIND_MIN, DONE.

**Implementation Details**:
- Use combinational logic for pair checking
- Sequential logic for iterating through configurations
- Store intermediate results in registers
- Use 6-bit counters for state iteration
- Points can have same x or y coordinates
- Fixed-point or rational arithmetic acceptable
