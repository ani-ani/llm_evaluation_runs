Design a sequential Verilog module named 'bug_fix_scheduler' that finds the minimum number of days to fix all bugs within budget.

Problem Adaptation:
- Maximum 8 students, 8 bugs, max 16 days
- Student ability and bug complexity: 0-255 (8-bit)
- Student cost: 0-65535 (16-bit)
- Budget s: 0-65535
- Algorithm: Binary search days (1-16), greedy assignment

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [7:0] bug_complexity [0:7] // 8 bugs, max complexity 255
input [7:0] student_ability [0:7] // 8 students, max ability 255
input [15:0] student_cost [0:7] // 8 students, max cost 65535
input [15:0] budget // maximum passes allowed

Outputs:
output reg [3:0] min_days // minimum days required (0-16, 0=infeasible)
output reg [2:0] assignment [0:7] // assigned student index (0-7) for each bug
output reg done // high when computation complete
output reg feasible // high if solution exists

Behavior:
1. Sort bugs by complexity descending (combinational logic)
2. Binary search days 1 to 16:
   - For each days value, try greedy assignment:
     - Group bugs into 'days' chunks (ceil(8/days) groups)
     - For each group (highest complexity bugs first):
       - Find cheapest qualified student (ability >= max bug in group)
       - Check if total cost <= budget
3. Store best valid configuration

Latency: Approximately 256 clock cycles (16 days × 16 cycle check)
Use state machine: IDLE, SORT_BUGS, BINARY_SEARCH, CHECK_SCHEDULE, DONE.

Fixed-point note: Costs are integers, no conversion needed.
