Design a sequential Verilog module named 'euclid_poly_builder' that generates two polynomials for Euclid's algorithm benchmarking.

The module should implement an iterative polynomial generation algorithm to find two polynomials A(x) and B(x) such that Euclid's GCD algorithm takes exactly n steps, with all coefficients in {-1, 0, 1} and leading coefficients of 1.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [7:0] n // Number of steps (1-120)

Outputs:
output reg [7:0] deg_a // Degree of polynomial A
output reg [7:0] deg_b // Degree of polynomial B
output reg signed [2:0] a_coeffs [0:120] // Coefficients of A (constant to x^120)
output reg signed [2:0] b_coeffs [0:120] // Coefficients of B (constant to x^120)
output reg done // High when computation complete

Specification:
The module uses an iterative state machine to generate polynomials F_0, F_1, F_2, ..., F_n where:
- F_0(x) = 1 (degree 0)
- F_1(x) = x (degree 1)
- For k >= 2: F_k(x) = x * F_{k-1}(x) + s_k * F_{k-2}(x)
  where s_k = 1 if max_coefficient(x*F_{k-1} + F_{k-2}) <= 1
         s_k = -1 otherwise

After computing F_n and F_{n-1}, assign:
- A = F_n (degree n)
- B = F_{n-1} (degree n-1)

State Machine:
- IDLE: Wait for start signal
- INIT: Initialize F_0 and F_1
- ITERATE: Loop k from 2 to n, computing F_k
- FINAL: Assign outputs
- DONE: Set done signal

Latency: Approximately 3 clock cycles per iteration, so 3*n + 5 cycles total.

Note: Coefficients are stored as signed 3-bit values to hold -1, 0, +1. The a_coeffs and b_coeffs arrays are fixed size 121 (max degree 120).
