Design a sequential Verilog module named 'domino_solver' that finds the minimum sum of visible fields after placing K dominoes on a small grid.

Inputs:
input clk // clock signal
input rst_n // active-low reset  
input start // start computation
input [1:0] K // number of dominoes (1 to 3)
input [3:0][3:0][7:0] grid // 4x4 grid, each cell 8-bit value (0-255)

Outputs:
output reg [15:0] min_sum // minimal sum of visible fields
output reg done // high when computation complete

Specification:
- Grid is 4x4 (16 cells total)
- Each domino covers 2 adjacent cells (horizontal or vertical)
- Dominoes cannot overlap
- K ≤ 3 dominoes
- Cell values are 8-bit unsigned (0-255)
- Output min_sum is 16-bit to accommodate worst case (16*255=4080)

Algorithm:
1. Compute total sum of all cells initially
2. Generate all valid domino placements (24 horizontal + 24 vertical = 48 total possible dominoes)
3. Use iterative state machine to select K non-overlapping dominoes that maximize covered sum (thus minimize visible sum)
4. State machine states: IDLE, CALC_TOTAL, GEN_DOMINOS, FIND_BEST, DONE
5. Latency: approximately 200-300 clock cycles

Implementation details:
- Each domino is represented as pair of 4-bit indices (0-15)
- Keep track of used cells with 16-bit bitmask
- Use nested loops to find best K non-overlapping dominoes
- Result is total_sum - sum_of_covered_cells
