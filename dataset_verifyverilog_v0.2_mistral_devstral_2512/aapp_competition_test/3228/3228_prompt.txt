Design a combinational Verilog module named 'gondola_scheduler' that computes the minimum total waiting time for skiers catching gondolas.

Problem Adaptation:
- Maximum 8 skiers (N=8)
- Gondola travel time T ≤ 16 minutes (scaled from 720)
- Number of gondolas G ≤ 4 (scaled from 400)
- Arrival times are 8-bit values (0-255)
- Each gondola takes 2*T minutes for a round trip
- With G gondolas optimally spaced, departures occur every D = ceil(2*T/G) minutes
- For each skier arriving at time X, the waiting time is (next_departure_time - X)
- next_departure_time is the smallest multiple of D that is ≥ X

Inputs:
input [7:0] arrival_times_0 // First skier arrival time
input [7:0] arrival_times_1 // Second skier arrival time
input [7:0] arrival_times_2 // Third skier arrival time
input [7:0] arrival_times_3 // Fourth skier arrival time
input [7:0] arrival_times_4 // Fifth skier arrival time
input [7:0] arrival_times_5 // Sixth skier arrival time
input [7:0] arrival_times_6 // Seventh skier arrival time
input [7:0] arrival_times_7 // Eighth skier arrival time
input [3:0] valid_skiers // Bitmask indicating which skiers are valid (1=valid, 0=unused)
input [4:0] T // Gondola travel time (1-16)
input [2:0] G // Number of gondolas (1-4)

Outputs:
output [15:0] total_waiting_time // Sum of all waiting times

Implementation Details:
1. Calculate departure_interval = ceil((2*T) / G)
   - Since G is small (1-4), we can compute this as: (2*T + G - 1) / G using integer division
2. For each valid skier:
   - Compute next_departure = ((arrival_time + departure_interval - 1) / departure_interval) * departure_interval
   - If arrival_time is exactly a departure time, next_departure = arrival_time
   - Wait_time = next_departure - arrival_time
3. Sum all wait times for valid skiers
4. Output the total in binary (maximum wait time per skier: departure_interval ≤ 32, with 8 skiers ≤ 256, so 16 bits is sufficient)

The module is purely combinational - no clock or state machine needed.
All arithmetic uses unsigned integers.
