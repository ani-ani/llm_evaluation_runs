Design a sequential Verilog module named 'phone_numbers' that computes the maximum number of phone numbers that can be formed from a set of digit cards.

Problem Analysis:
A phone number is defined as '8' followed by 10 digits (length 11). To maximize the count of phone numbers, we need two resources: one '8' per phone number and 11 total digits per phone number.
The algorithm is: result = min(count_of_eights, floor(total_digits / 11)).

Module Interface:
Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation pulse
input [99:0] digit_vector // 100-bit vector where bit i is 1 if digit i is present

Outputs:
output reg [3:0] result // Maximum number of phone numbers (0-9)
output reg done // High when computation is complete

Behavioral Specification:
The module should be sequential. When 'start' is asserted:
1. Count the number of '8's in the digit_vector.
2. Calculate the total number of cards (population count of digit_vector).
3. Calculate floor(total_cards / 11).
4. Compute result = min(count_of_eights, floor(total_cards / 11)).
5. Assert 'done' signal.

Implementation Constraints:
- Use a state machine: IDLE -> COUNTING -> CALCULATING -> DONE.
- The digit_vector is 100 bits wide. Use a 16-bit counter for population count.
- The result is max 9 (since 100/11 < 10), so a 4-bit output is sufficient.
- Latency: Result valid 120 clock cycles after start asserted (to allow sequential counting).
