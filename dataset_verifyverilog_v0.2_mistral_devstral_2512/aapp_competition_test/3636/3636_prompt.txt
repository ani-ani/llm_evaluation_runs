Design a combinational Verilog module named 'min_obstacles_counter' that counts the number of ways to place the minimum number of obstacles in a 4x4 grid to cover all 2x2 subgrids.

The grid has size N x M where N=4, M=4. A 2x2 block can be placed at positions (i,j) where i ranges from 0 to N-2 and j ranges from 0 to M-2. A 2x2 subgrid is covered if at least one of its 4 cells contains an obstacle.

Inputs:
input clk // clock signal for sequential operation
input rst // reset signal
input [15:0] grid_config // 4x4 grid configuration, 16 bits, 1 = obstacle, 0 = empty

Outputs:
output reg [3:0] min_obstacles // minimum number of obstacles needed
output reg [7:0] count_ways // number of ways to achieve minimum obstacles
output reg valid // high when computation is complete

Implementation Details:
1. The module should be sequential with a state machine: IDLE, CHECK, COUNT, DONE
2. For each of the 9 possible 2x2 subgrid positions in a 4x4 grid, check if the subgrid is covered
3. A 2x2 subgrid at position (i,j) covers cells (i,j), (i,j+1), (i+1,j), (i+1,j+1)
4. Count how many obstacles are in the grid (popcount of grid_config)
5. Find the minimum number of obstacles among all valid configurations that cover all 2x2 subgrids
6. Count how many configurations achieve this minimum

For the 4x4 grid:
- There are 9 possible 2x2 subgrids
- The minimum number of obstacles is 4 (placing obstacles on a diagonal pattern)
- The count of ways should be computed by checking all 2^16 = 65536 possible configurations

Use a counter to iterate through possible configurations or check the given configuration. The module should validate that the input grid configuration covers all 2x2 subgrids and count obstacles.

Latency: Result valid 100 clock cycles after start asserted.

State Machine:
- IDLE: Wait for start signal
- CHECK: Verify all 9 subgrids are covered
- COUNT: Count obstacles in the grid
- DONE: Output results

The module should output the minimum obstacle count and number of ways for the given grid configuration.
