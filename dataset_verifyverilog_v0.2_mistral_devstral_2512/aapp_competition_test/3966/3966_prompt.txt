Design a sequential Verilog module named 'score_calculator' that computes the maximum possible score for the Appleman and Toastman game.

Algorithm Adaptation:
1. Store input numbers in an array of size 8.
2. Sort the array in ascending order using a bubble sort state machine.
3. Compute the weighted sum:
   If n=1: result = a[0]
   If n>1: result = sum(a[i] * (i+2) for i in 0..n-1) - a[n-1]
   (Note: Based on the logic, it calculates sum of (value * weight) where weights start at 2 and increment, then subtracts the largest element once).

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation (loads data, initiates sort)
input [7:0] data_in // Input value for the array (8-bit unsigned)
input [2:0] index_in // Index for inputting data (0 to 7)
input input_valid // High when data_in/index_in are valid

Outputs:
output reg [31:0] result // 32-bit result (enough for sum of 8 numbers up to 10^6)
output reg done // High when computation is complete

Internal Behavior:
- State Machine States: IDLE, LOAD, SORTING, CALCULATING, FINISHED
- Use parameters for array size N=8.
- Bubble Sort: Iterate through the array, swapping adjacent elements if they are out of order. Requires multiple cycles.
- Calculation: Iterate through the sorted array to accumulate weighted sum. Weight starts at 2.

Specify latency: Result valid approximately 200 clock cycles after start asserted (worst case for bubble sort on 8 elements).
