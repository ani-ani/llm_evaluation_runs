Design a sequential Verilog module named 'longest_interesting_subsequence' that finds the longest interesting subsequence for each starting position in a small array.

An interesting sequence of 2K elements means:
- Sum of first K elements ≤ S
- Sum of last K elements ≤ S

For a sequence A of length N, for each starting position i, find the maximum length of an interesting subsequence that starts at i.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [7:0] A [0:15] // 16-element array of 8-bit unsigned integers (max N=16)
input [31:0] S // 32-bit threshold value

Outputs:
output reg [7:0] result [0:15] // results for each starting position (length, 0 if none)
output reg done // high when all results computed

Specify latency: Result valid 256 clock cycles after start asserted (worst case for 16 positions × 16 checks).

The module should use a state machine with states: IDLE, COMPUTE, DONE.

Behavior:
1. For each starting position i from 0 to N-1:
   - Find maximum even length L (2K) such that A[i..i+K-1] sum ≤ S AND A[i+K..i+2K-1] sum ≤ S
   - Store L in result[i]
2. If no valid subsequence, result[i] = 0
3. Set done = 1 when all positions processed

Algorithm approach:
- Use nested loops: outer loop over start positions, inner loop over possible K values
- For each (i, K), compute two sums and check both ≤ S
- Track maximum valid length for each starting position
- Use combinational logic for sum calculation

All values fit in 32-bit, outputs are 8-bit lengths (max 16).
