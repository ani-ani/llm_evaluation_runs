Design a Verilog module named 'card_score_optimizer' that implements a simplified version of the card arrangement scoring problem.

**Problem Definition:**
Given a fixed number of 'o' cards (A) and 'x' cards (B), find the arrangement that maximizes the score:
- Each contiguous block of 'o's of length L contributes +L*L to the score.
- Each contiguous block of 'x's of length L contributes -L*L to the score.

**Constraints (Simplified for HDL):**
- Total cards (A + B) <= 12.
- Input counts A and B are small integers (0 to 12).
- The module must find the maximum possible score among all valid arrangements.

**Module Interface:**
- Inputs: 
  - `clk`, `rst_n`: Standard clock and active-low reset.
  - `start`: Pulse high to start computation.
  - `a_in`: 4-bit input representing the number of 'o' cards (0-12).
  - `b_in`: 4-bit input representing the number of 'x' cards (0-12).

- Outputs:
  - `max_score`: 16-bit signed integer output representing the maximum score.
  - `done`: Signal high when computation is complete.

**Implementation Strategy:**
1. The module should use a state machine (IDLE, PROCESSING, DONE) to handle the computation.
2. Since the total number of cards is small, you can pre-calculate or iterate through possible arrangements to find the maximum score.
3. Consider the strategy: To maximize (sum of o_squares - sum of x_squares), we want to maximize o_squares and minimize x_squares. 
   - Maximize o_squares: Group all 'o's into one block (A^2).
   - Minimize x_squares: Distribute 'x's evenly into as many blocks as possible (since x^2 + y^2 > (x+y)^2 for positive integers). The number of 'x' blocks should be roughly equal to the number of 'o' blocks plus one.
4. The module should calculate the optimal score based on these rules for the given A and B.
5. Output the calculated score.

**Verilog Code Requirements:**
- Use signed arithmetic.
- Specify state machine states.
- Ensure the logic is clocked (sequential) to model a realistic computation unit.
- Latency: Result valid after a fixed number of cycles (e.g., 10-20 cycles) once 'start' is asserted.
