Design a combinational Verilog module named 'tree_checker' that determines if a tree configuration allows arbitrary edge value assignments.

Problem Analysis:
A tree with n nodes allows arbitrary edge value configurations if and only if it has no nodes with degree 2 (for n > 2). This is because degree-2 nodes restrict the degrees of freedom.

Constraints:
- n (number of nodes) <= 16 (scaled down from 10^5)
- Node indices range from 0 to n-1
- Edges connect distinct nodes

Inputs:
input [3:0] n // number of nodes (0-15)
input [3:0] num_edges // number of edges (n-1)
input [5:0] edge_u [15:0] // source nodes of edges, padded if fewer than 16 edges
input [5:0] edge_v [15:0] // destination nodes of edges, padded if fewer than 16 edges

Outputs:
output result // 1 if configuration is achievable (YES), 0 if not (NO)

Behavior:
1. Calculate the degree of each node by counting occurrences in edge_u and edge_v arrays.
2. Check if any node has degree exactly 2.
3. If n == 2, return 1 (always YES).
4. If n > 2 and any node has degree 2, return 0 (NO).
5. Otherwise, return 1 (YES).

Implementation Details:
- Use simple adders to accumulate degrees.
- Use comparators to check for degree == 2.
- The module is purely combinational.
