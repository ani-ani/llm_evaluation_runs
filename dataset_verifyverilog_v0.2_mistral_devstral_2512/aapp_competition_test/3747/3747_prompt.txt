Design a sequential Verilog module named 'bulbasaur_counter' that counts how many times 'Bulbasaur' can be formed from a fixed-width input string.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [127:0] str_input // 16-character string (each char is 8 bits, stored as packed bytes)
input [7:0] str_len // actual length of string (0 to 16)

Outputs:
output reg [7:0] result // maximum number of Bulbasaurs that can be formed
output reg done // high when computation complete

Specify latency: Result valid 20 clock cycles after start asserted.

Use state machine with states: IDLE, COUNTING, COMPUTING, DONE.

Behavior:
- In IDLE: wait for start signal
- In COUNTING: iterate through string (max 16 chars), count occurrences of B, u, l, b, a, s, r
- In COMPUTING: compute result = min(B, u/2, l, b, a/2, s, r) using integer division
- In DONE: assert done and hold result

All arithmetic uses unsigned integers. Character 'a' is ASCII 0x61, 'b'=0x62, 'l'=0x6C, 'r'=0x72, 's'=0x73, 'u'=0x75, 'B'=0x42.

The string is stored as 16 bytes in str_input[127:0], where str_input[7:0] is first character, str_input[15:8] is second, etc.
