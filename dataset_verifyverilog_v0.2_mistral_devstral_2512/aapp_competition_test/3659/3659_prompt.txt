Design a sequential Verilog module named 'bookcase_optimizer' that finds the minimum area for partitioning N books into 3 shelves. 

Problem Adaptation:
- Input: N books (max N=8) with height h[7:0] and thickness t[7:0]
- Objective: Partition books into 3 non-empty shelves S1, S2, S3
- Minimize: (max_h(S1) + max_h(S2) + max_h(S3)) * max(sum_t(S1), sum_t(S2), sum_t(S3))
- All values scaled to fit in 8-16 bits

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [2:0] num_books // number of books (3-8)
input [7:0] heights [0:7] // heights of 8 books (150-300)
input [7:0] thickness [0:7] // thicknesses of 8 books (5-30)

Outputs:
output reg [15:0] min_area // minimum area result
output reg done // high when computation complete

Specify latency: Result valid 12 clock cycles after start asserted.
Use state machine with states: IDLE, PREPROCESS, BRUTE_FORCE_CHECK, UPDATE_MIN, DONE.

Algorithm Description:
1. IDLE: Wait for start signal
2. PREPROCESS: Read all book parameters into registers
3. BRUTE_FORCE_CHECK: Iterate through all possible 3^N assignments (use nested loops or state counter for N=8, 3^8=6561 iterations)
   - Each book assigned to shelf 0, 1, or 2
   - Track: max_height per shelf, total_thickness per shelf
   - Validate: all 3 shelves must have at least 1 book
4. UPDATE_MIN: Update min_area if current assignment is valid and better
5. DONE: Set done flag

Implementation Notes:
- Use 3^N exhaustive search since N≤8 (3^8=6561 is manageable with proper state encoding)
- For each assignment, compute: area = (h0+h1+h2) * max(t0,t1,t2)
- Store min_area in a register, update when better assignment found
- The challenge is handling the 3^N combinations efficiently in hardware

Use state machines with states: IDLE, PREPROCESS, BRUTE_FORCE_CHECK, UPDATE_MIN, DONE.
