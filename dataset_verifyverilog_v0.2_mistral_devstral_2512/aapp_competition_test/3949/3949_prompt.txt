Design a sequential Verilog module named 'monopole_magnet_solver' that determines the minimum number of north magnets required for a simplified monopole magnet problem on a 4x4 grid.

The module processes an input grid of size up to 4x4 stored in a flat array. It must perform three main checks:
1. Contiguous Black Region Counting: Use a Depth-First Search (DFS) approach to count connected components of '#' cells.
2. Row/Column Constraint Validation: Verify that if a row has black cells, they must be contiguous (no gaps). Similarly for columns.
3. Empty Row/Column Consistency: If there is an empty row, there must be an empty column, and vice versa. If one exists without the other, it's invalid.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [5:0] grid_flat [0:15] // Flattened 4x4 grid (16 cells). Each cell is 1 bit: 1=black (#), 0=white (.).

Outputs:
output reg [3:0] result // Minimum number of north magnets (connected components). 4'b1111 indicates error (-1).
output reg done // High when computation is complete

Internal Logic:
- Use a state machine with states: IDLE, CHECK_ROWS, CHECK_COLS, COUNT_COMPONENTS, DONE, ERROR.
- For CHECK_ROWS/CHECK_COLS: Check if black cells are contiguous. A pattern like '# . #' is invalid.
- For COUNT_COMPONENTS: Implement a simple iterative DFS using a small stack (max depth 16) and a visited array (16 bits).
- The module must process the grid and output the count of connected components of black cells, or 4'b1111 (representing -1) if constraints are violated.

Latency: Result valid approximately 100 clock cycles after start asserted (depending on state machine implementation).

Detailed Behavior:
1. IDLE: Wait for start signal.
2. CHECK_ROWS: Iterate through 4 rows. For each row, check if pattern is valid (contiguous black cells). Set error flag if invalid.
3. CHECK_COLS: Iterate through 4 columns. Check pattern validity.
4. CHECK_EMPTY: Verify empty row/column consistency. If (has_empty_row != has_empty_col), error.
5. COUNT_COMPONENTS: Iterate through grid. If cell is black and not visited, increment result and run DFS to mark all connected black cells as visited.
6. DONE: Output result.
7. ERROR: Output 4'b1111.

Note: The input grid_flat is ordered row-major (rows 0-3, columns 0-3).

The module should compute the result sequentially using the state machine.
