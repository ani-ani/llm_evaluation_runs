Design a sequential Verilog module named 'avg_operations' that calculates the average number of operations until termination for coin configurations containing unknown bits.

Problem Context:
Given a binary string with H (heads), T (tails), and ? (unknown), where H=1, T=0. The process is: count number of 1s (k). If k > 0, flip the k-th 1 to 0. Repeat until all 0s. We need the average length over all completions of ?.

Constraints:
- Input string length N = 8 (scaled down from 10^6).
- Input characters: 'H' (1), 'T' (0), '?' (0 or 1).
- Clock frequency: 100 MHz.
- Target latency: < 10,000 cycles for worst case.

Interface:
Inputs:
input clk // System clock
input rst_n // Active low reset
input start // Start computation
input [7:0] char_mask // 1 if character is 'H' or '?', 0 if 'T' (defines valid positions)
input [7:0] head_mask // 1 if character is 'H', 0 otherwise (known heads)

Outputs:
output reg [31:0] result_num // Numerator of average (Q16.16 fixed point)
output reg [31:0] result_den // Denominator (power of 2)
output reg done // High when computation complete

Implementation Details:
1. The module must handle unknown bits ('?') by averaging over all possibilities.
2. For a length-8 string, there are at most 2^8 = 256 possible configurations.
3. For each configuration, calculate the number of operations L(C).
4. Sum L(C) for all valid completions and divide by the number of completions.
5. Use a state machine with states: IDLE, GENERATE_CONFIGS, CALCULATE_LENGTH, ACCUMULATE, DIVIDE.
6. GENERATE_CONFIGS: Iterate through all combinations of ? positions.
7. CALCULATE_LENGTH: Simulate the process for a specific configuration.
   - Count set bits (k).
   - If k > 0, find k-th set bit and clear it.
   - Increment step counter.
   - Repeat until all bits 0.
8. ACCUMULATE: Sum results.
9. DIVIDE: Perform division (or shift if denominator is power of 2).
10. Use Q16.16 for result accumulation if needed, but since we sum integers and divide by power of 2, fixed point is natural.

State Machine:
- IDLE: Wait for start. Reset accumulators.
- GENERATE_CONFIGS: Maintain a counter for '?' positions. Generate next valid 'head_mask' variation.
- CALCULATE_LENGTH: Perform bit counting and flipping loop.
- ACCUMULATE: Add length to total sum.
- DIVIDE: Shift sum to get average (integer division for power of 2).
- DONE: Set done flag.

Output Format:
Result is provided as numerator and denominator. Testbench will compute average = result_num / result_den.
