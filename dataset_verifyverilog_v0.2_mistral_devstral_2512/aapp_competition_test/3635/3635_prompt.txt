Design a sequential Verilog module named 'executive_reward' that implements a simplified version of the banana distribution problem.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [2:0] num_briefcases // Number of briefcases (max 8)
input [23:0] bananas [0:7] // Array of 8 bananas counts, Q16.8 fixed point (scaled by 256)

Outputs:
output reg [7:0] max_executives // Maximum number of executives that can be rewarded
output reg done // high when computation complete

Behavioral Description:
The module calculates the maximum number of executives that can receive bananas such that executives with higher evilness receive at least as many bananas as those with lower evilness. Briefcases must be distributed in contiguous chunks (lowest numbered available first).

Given the constraints of hardware implementation, use a greedy approach:
1. Process briefcases from 1 to N
2. Form groups such that each group sum is >= the previous group sum
3. The number of groups is the number of executives

Algorithm:
- State IDLE: Wait for start signal
- State COMPUTE: Iterate through briefcases and form groups
  - Track current group sum and number of executives
  - When current sum >= previous group sum, start a new group
- State DONE: Output result and wait for reset

Latency: Approximately 64 clock cycles (8*8 iterations max) after start asserted.

The bananas input values are provided in Q16.8 format (16 integer bits, 8 fractional bits) for the hardware implementation. For example, a value of 256 represents 1.0 in the original problem.

The module should handle the case where N < 8 by ignoring extra elements and using only the first N elements of the bananas array.
