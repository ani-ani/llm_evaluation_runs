Design a sequential Verilog module named 'secret_message' that finds the number of occurrences of the most frequent hidden string in a given input string.

A hidden string is a subsequence whose indices form an arithmetic progression. For example, in "aaabb" at indices 1,3,5, the string "aab" is hidden with common difference 2.

The module should process a fixed-width string of maximum length 16 characters using ASCII values.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [7:0] char_in // Current character input (valid when load is high)
input load // Signal to load next character into buffer

Outputs:
output reg [31:0] result // Number of occurrences of the secret message
output reg done // High when computation complete

Behavioral Description:
1. The module first loads up to 16 characters into an internal buffer when 'load' is asserted.
2. After loading, when 'start' is asserted, it enumerates all possible arithmetic progressions of indices within the string length.
3. For each valid progression (starting index i, common difference d, length L >= 1), extract the corresponding subsequence.
4. Maintain a count of occurrences for each unique hidden string encountered.
5. Track and return the maximum count found.

Key Constraints:
- String length is limited to 16 characters
- Characters are ASCII (7-bit, represented as 8-bit values)
- Arithmetic progression common difference d can be from 1 to 15
- Progression length L must be at least 1 and such that i + (L-1)*d < N (where N is actual string length)
- Result must be output in Q16.16 format (though result is an integer, multiply by 65536 for format)

State Machine States:
- IDLE: Wait for start signal
- LOAD: Accepting character input
- PROCESSING: Enumerating progressions and counting
- DONE: Result ready

The module should use a state machine to control the flow and ensure sequential operation.
