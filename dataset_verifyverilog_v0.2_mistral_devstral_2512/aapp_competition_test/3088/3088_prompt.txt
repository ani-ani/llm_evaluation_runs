Design a sequential Verilog module named 'swap_digits_max' that computes the largest number achievable after exactly k swaps of digits in a given number.

**Problem Adaptation**: 
- Input number is a 4-digit decimal number (0000 to 9999) to keep logic tractable.
- Number of swaps k is limited to 1-4 (scaling down from 1-18).
- Each swap exchanges two digits at different positions.
- Result cannot have leading zero (i.e., hundreds digit cannot be 0).
- Output the maximum numerical value achievable.

**Inputs**: 
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation pulse
input [15:0] number_in // Packed 4-digit BCD number, 4 bits per digit
// Example: 1374 is 0x1374 (digits: 1, 3, 7, 4)
input [3:0] k // Number of swaps to perform (1 to 4)

**Outputs**:
output reg [15:0] result // The maximum number achievable
output reg done // High when computation complete

**Latency**: Up to 256 clock cycles worst case (bounded search).

**Behavior**: 
1. Module uses a state machine with states: IDLE, INIT, PROCESSING, DONE.
2. In PROCESSING, it performs a bounded search over valid swap sequences of length exactly k.
3. Use internal registers to store current best result and iterate through permutations.
4. Track number of swaps used.
5. Ensure no leading zero in valid results (i.e., digit[3] != 0).
6. Compare results and store maximum.
7. When done is high, result holds the maximum number found.

**Constraints**:
- Use combinational logic for digit swapping and comparison.
- State machine controls iteration count and termination.
- Handle edge cases: k=0 (no swaps), number already maxed.
- Result format matches input format (16-bit packed BCD).
