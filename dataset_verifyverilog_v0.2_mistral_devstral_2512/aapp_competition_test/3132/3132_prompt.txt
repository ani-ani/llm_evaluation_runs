Design a sequential Verilog module named 'building_detector' that identifies two square buildings in a fixed-size grid.

The module uses a fixed grid size of 16x16. Input is provided as a 2D array of bits where '1' represents a building ('x') and '0' represents empty ('.').

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [15:0] grid_row_0, grid_row_1, ..., grid_row_15 // 16 rows of 16-bit data representing the grid

Outputs:
output reg [3:0] building1_row, building1_col, building1_size // Upper-left corner and size for first building
output reg [3:0] building2_row, building2_col, building2_size // Upper-left corner and size for second building
output reg done // High when computation complete

Behavior:
The module should implement a sequential state machine with states: IDLE, SCAN, VERIFY, OUTPUT.
1. IDLE: Wait for 'start' signal.
2. SCAN: Iterate through the grid (row by row, col by col) to find potential square blocks of '1's. Use a nested loop structure to check square sizes from 1 up to 16.
3. VERIFY: For each potential square, verify that all cells within the square area are '1'. If valid, store it as a building.
4. OUTPUT: Once two distinct buildings are found, assign the outputs and set 'done' high.

The buildings should be distinct (non-overlapping, or considered separate if they are disconnected).

Latency: Result valid approximately 10000 clock cycles after start (allowing for full grid scan).

Fixed-Point Specifications: Not applicable as this is a discrete grid problem.

Initialization: On reset, all outputs should be cleared to 0.
