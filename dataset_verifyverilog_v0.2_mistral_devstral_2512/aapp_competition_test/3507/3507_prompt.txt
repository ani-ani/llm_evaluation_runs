Design a sequential Verilog module named 'wine_arrangements' that counts valid wine box arrangements.

The problem is simplified to:
- R (red boxes) <= 8, W (white boxes) <= 8
- d (max red per pile) = 2
- Piles alternate colors, no adjacent same colors
- Each pile must be non-empty

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [3:0] R // number of red boxes (0-8)
input [3:0] W // number of white boxes (0-8)

Outputs:
output reg [15:0] result // number of valid arrangements (modulo 1024 for small values)
output reg done // high when computation complete

Latency: Result valid ~200 clock cycles after start asserted.

Algorithm (State Machine Approach):
Use dynamic programming with states tracking:
- Current remaining red boxes
- Current remaining white boxes
- Last pile color (0=none/start, 1=red, 2=white)
- Current pile size

Define DP state: dp[red][white][last_color][pile_size] = count
Transitions:
1. Start state: all boxes remaining, no last color
2. Try to form a pile of red (if last != red and pile size <= d):
   - Add 1 to pile size if red remaining
   - If pile complete (cannot add more or limit reached), transition to white-next state
3. Try to form a pile of white (if last != white):
   - Add 1 to pile size (no limit)
   - Transition to red-next state
4. Track count of complete arrangements (red=0, white=0, pile complete)

Implementation Details:
- Use 32-bit state registers for DP
- Precompute valid pile configurations for red (max size 2)
- Iterate through all possible pile sequences
- Output final count

The module should implement this simplified DP algorithm using a finite state machine.
