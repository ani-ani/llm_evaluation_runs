Design a sequential Verilog module named 'grid_computation' that computes F_{x,y} for a modified 2D grid formula where base cases are F[0,0]=0, F[0,1]=F[1,0]=1, and F[i,j] = F[i-1,j] + F[i,j-1] for i,j>=1, with F[i,0] and F[0,i] following the Fibonacci recurrence for i>=2.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [3:0] x // x coordinate (0-15, scaled down from 10^6)
input [3:0] y // y coordinate (0-15, scaled down from 10^6)

Outputs:
output reg [31:0] result // F[x,y] modulo 10^9+7
output reg done // high when computation complete

Specification:
- Scale down: Use 4-bit inputs (max 15x15 grid) instead of 10^6
- Implement a row-by-row computation using a state machine
- Use 16-bit registers to store the current row (each element modulo 10^9+7)
- Latency: Approximately 256 clock cycles for worst case (15x15)
- States: IDLE, COMPUTE_ROW, COMPUTE_CELL, DONE
- In IDLE: wait for start signal
- In COMPUTE_ROW: compute one row of the grid
- In COMPUTE_CELL: compute individual cell value using previous row and current row previous value
- In DONE: assert done signal
- Modulo operation: 10^9+7 = 1000000007, use subtraction-based modulo

The module should:
1. Initialize base cases: F[0,0]=0, F[0,1]=1, F[1,0]=1
2. For row 0: compute Fibonacci sequence F[0,i] = F[0,i-1] + F[0,i-2] for i>=2
3. For row i>=1: compute F[i,0] = F[i-1,0] + F[i-2,0] (Fibonacci), then F[i,j] = F[i-1,j] + F[i,j-1] for j>=1
4. Output the value at position [x,y]
5. All computations done modulo 1000000007
