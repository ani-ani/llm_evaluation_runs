Design a sequential Verilog module named 'trip_planner' that solves the elderly trip problem.

Problem: Given n participants (1-8) where each participant i requires participant x_i to also join, find maximum participants that can join without exceeding k seats (1-8).

Key insight: Each node has exactly one outgoing edge, forming cycles. Must take entire cycles or none.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [2:0] n // number of participants (1-8)
input [2:0] k // bus capacity (1-8)
input [7:0][2:0] x // array of dependencies, x[i] is requirement for participant i+1

Outputs:
output reg [3:0] result // maximum participants that can join
output reg done // high when computation complete

Behavior:
1. Use state machine: IDLE → DETECT_CYCLES → CALCULATE_RESULT → DONE
2. In DETECT_CYCLES state: Find all cycles in the graph
   - Start from each unvisited node and follow edges until cycle detected
   - Track visited nodes to avoid recounting
   - Store cycle sizes in a small buffer (max 8 cycles)
3. In CALCULATE_RESULT state: Find maximum sum of cycle sizes ≤ k
   - For each possible subset of cycles, check if total ≤ k
   - Keep track of maximum valid total
4. Output the maximum count

Latency: Approximately 200 clock cycles worst case

Constraints:
- n and k are at most 8
- x array contains values 1-8 (0-indexed: 0-7)
- Use 3-bit values for participants (since max 8)
- Result needs 4 bits (max 8 participants)

Example:
n=4, k=4, x=[0,1,2,3] → all self-dependencies, 4 cycles of size 1 → result = 4
n=3, k=2, x=[1,2,0] → one cycle of size 3 → result = 0 (cannot take 3 when k=2)

Use state machine with states: IDLE, DETECT_CYCLES, CALCULATE, DONE.
