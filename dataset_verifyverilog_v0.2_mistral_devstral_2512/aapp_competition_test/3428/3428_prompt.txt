Design a combinational Verilog module named 'gcd_distinct_counter' that counts distinct GCD values of all contiguous subarrays.

Inputs:
input [3:0] n // Number of elements (1-4)
input [15:0] a [0:3] // Array of 4 integers, each 16 bits

Outputs:
output [3:0] distinct_count // Number of distinct GCD values

The module should:
1. Compute GCD for all possible contiguous subarrays: [0:0], [0:1], [0:2], [0:3], [1:1], [1:2], [1:3], [2:2], [2:3], [3:3]
2. Use a 4-stage GCD calculator (combinational Euclidean algorithm) for each subarray
3. Store results in a 10-element buffer (max 10 subarrays for n=4)
4. Compare all pairs of computed GCD values to count distinct ones
5. Output the total count of unique GCD values

GCD Algorithm (combinational):
- Use Euclidean algorithm with 16-bit inputs
- For inputs a and b: while b != 0: temp = a % b; a = b; b = temp
- Implement as a nested case statement or combinational loop with fixed iterations (max 16)

Subarray GCD computation:
- Single element: GCD = element itself
- Two elements: compute GCD(a[i], a[i+1])
- Three elements: GCD(a[i], GCD(a[i+1], a[i+2]))
- Four elements: GCD(a[i], GCD(a[i+1], GCD(a[i+2], a[i+3])))

Distinct counting logic:
- Use comparators to check if each GCD value equals any previous unique value
- For each computed GCD, check if it matches any already-counted unique value
- Increment count only for new unique values
- Output final count

This is purely combinational - no clock needed. The module handles arrays up to 4 elements.
