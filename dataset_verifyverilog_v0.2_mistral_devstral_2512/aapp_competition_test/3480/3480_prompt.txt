Design a sequential Verilog module named 'round_generator' that implements a two-voice musical round display generator.

**Problem Analysis:**
The module takes a song defined by syllables and durations, and a delay D. It outputs two lines: the original voice and the overlapping second voice starting after delay D. Constraints are simplified to fixed-size buffers.

**Constraints:**
- Max lines L: 8
- Max syllables per line: 8
- Max syllable text length: 16 characters
- Delay D: 0 to 128 time units
- Duration t: 1 to 128 time units
- Output line width: 200 characters (fixed buffer size)

**Inputs (Control Signals):**
input clk                  // Clock
input rst_n                // Active-low reset
input start                // Start processing the song

**Inputs (Song Data - Loaded sequentially or via memory):**
// For this interface, we assume loading is done via a parallel interface or simplified stream.
// We will define a control interface to accept one syllable at a time.

// Data In Interface (Used to load the song)
input [15:0] data_val      // Data value (time or encoded char)
input [1:0] data_type      // 0: Time, 1: Syllable Char (8-bit), 2: End of Syllable, 3: End of Line
input data_valid           // Data valid strobe

**Outputs:**
output reg [199:0] line1_out // First voice line (ASCII string padded with underscores)
output reg [199:0] line2_out // Second voice line (ASCII string padded with underscores or '/')
output reg output_valid      // High when outputs are ready
output reg done              // High when entire song is processed

**Implementation Details:**
1. **Memory:** Use internal registers to store up to 8 lines, 8 syllables each. Each syllable stores duration (8-bit) and text (16 bytes). Max 16 chars per syllable.
2. **State Machine (FSM):**
   - IDLE: Wait for start.
   - LOAD: Accept data via `data_val`/`data_type` and store in internal buffers. Advance pointers.
   - PROCESS_LINE: Calculate display positions for the current line.
   - DISPLAY: Output the computed `line1_out` and `line2_out`.
   - NEXT_LINE: Move to next line.
   - DONE: Final state.

**Display Logic:**
For the current line (index `l`):
- **Voice 1:**
  - Iterate through syllables in line `l`.
  - Maintain `cursor_pos` (start position of next syllable).
  - Place syllable at `cursor_pos`.
  - Update `cursor_pos`: `cursor_pos += duration_of_syllable`.
  - Append underscores to `line1_out` to fill gaps.
- **Voice 2:**
  - The second voice sings the *same* text but shifted by time `D`.
  - We need to find which syllables start in the time window of line `l`.
  - Let `T_start_l` be the cumulative time before line `l`.
  - Let `T_end_l` be `T_start_l + total_duration_of_line_l`.
  - Second voice starts at `T_start_l + D`.
  - We need to find syllables from the *entire song* that start in `[T_start_l + D, T_end_l + D)`.
  - To simplify: Iterate through ALL syllables of the song. If a syllable's absolute start time `S` satisfies `S >= T_start_l + D` AND `S < T_end_l + D`, it belongs to line 2 output.
  - Calculate `relative_pos = S - (T_start_l + D)`.
  - Place the syllable at `relative_pos` in `line2_out`.
  - If no such syllables, `line2_out = '/'`.

**Simplification for HDL:**
- Instead of processing the whole song at once, we will process one line of the output at a time.
- To support this, the `PROCESS_LINE` state will loop through all stored syllables to find overlaps for the current line.

**Inputs:**

**Outputs:**
- `line1_out` [199:0]: ASCII string for Voice 1.
- `line2_out` [199:0]: ASCII string for Voice 2.

**Internal Logic:**
1. **Storage**: Registers for `syllable_text`, `syllable_time`, `syllable_count`, `line_delay`, `num_lines`.
2. **FSM States**: IDLE, LOAD, CALC_V1, CALC_V2, OUTPUT, NEXT_LINE, DONE.
3. **Load Logic**: 
   - If `data_type` == 0: Store `line_delay` and `num_lines` (packed in `data_in`).

   - If `data_type` == 0 (subsequent): Store time.

4. **Calculation Logic (V1)**:
   - For the current line, calculate cumulative time.
   - Place syllables in `temp_line1` buffer at positions determined by cumulative time (or strictly by duration sum).

   - If `temp_line2` is empty, set to '/'.
