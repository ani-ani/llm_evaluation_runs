Design a sequential Verilog module named 'tweeper_decoder' that identifies encoding patterns for '+' and '-' characters.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start processing
input [7:0] i_char // current input character from I string
input [7:0] o_char // current output character from O string
input [3:0] i_idx // index for input string (0-15)
input [3:0] o_idx // index for output string (0-15)
input i_valid // input char valid
input i_last // last input character
input o_last // last output character

Outputs:
output reg [7:0] enc_plus // encoding for + (8-bit pattern, 0 means empty)
output reg [7:0] enc_minus // encoding for - (8-bit pattern, 0 means empty)
output reg [1:0] result_code // 0=corrupted, 1=valid, 2=any_empty, 3=multiple
output reg done // high when computation complete

The module should:
1. Accept input and output strings character-by-character (max 16 chars each)
2. Track character positions and find all possible single-character substitutions for '+' and '-' that transform I into O
3. Store valid encodings for + and - as 8-bit ASCII values
4. Handle special cases: <empty> (enc=0), <any> (enc=0xFF)
5. Output all valid pairs or corrupted if none
6. Use state machine: IDLE, COLLECT, PROCESS, VALIDATE, DONE
7. Latency: Result valid 256 clock cycles after start

The algorithm should:
- Build a mapping of what each char in I becomes in O
- Check if + and - consistently map to specific patterns
- Handle cases where + or - appear multiple times
- Verify that all non-special characters match exactly
