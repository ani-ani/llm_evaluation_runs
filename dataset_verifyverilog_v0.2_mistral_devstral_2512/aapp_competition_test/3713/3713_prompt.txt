Design a sequential Verilog module named 'hack_cows' that implements the logic to maximize the longest alternating subsequence length by flipping one substring.

The problem is simplified to handle binary strings of maximum length 16 characters.

The logic is:
1. Calculate the original length of the longest alternating subsequence (LAS). For a binary string, this is 1 + number of transitions (positions where s[i] != s[i+1]).
2. A single flip of a substring can increase the LAS length by up to 2 if there are adjacent identical characters (like '00' or '11') somewhere in the string.
3. If the string is already fully alternating (no '00' or '11'), the max increase is 0 (unless length < n, then 0).
4. Final result is LAS + min(2, count_of_adjacent_duplicates).

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [3:0] str_len // Length of the string (max 16)
input [15:0] binary_string // 16-bit input representing the binary string (LSB is start of string, MSB is end, e.g., bit 0 = s[0])

Outputs:
output reg [7:0] result // The maximum possible alternating subsequence length
output reg done // High when computation is complete

Specify latency: Result valid 19 clock cycles after start asserted (16 cycles to scan string + 3 cycles for calculation/output).

Use a state machine with states: IDLE, SCAN_STRING, CALCULATE_RESULT, DONE.

The module should:
1. In IDLE state, wait for start signal.
2. In SCAN_STRING state, iterate through the bits up to str_len to count:
   - Transitions (s[i] != s[i+1]) -> this gives base LAS - 1
   - Adjacent duplicates (s[i] == s[i+1]) -> count of '00' or '11' pairs
3. In CALCULATE_RESULT state, compute: result = (transitions + 1) + min(2, adjacent_duplicates).
4. In DONE state, assert done signal.
