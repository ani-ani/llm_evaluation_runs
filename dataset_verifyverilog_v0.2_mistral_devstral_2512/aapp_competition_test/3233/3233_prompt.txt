Design a sequential Verilog module named 'scary_subarray_counter' that counts scary subarrays in a small array.

Problem Definition:
- An array is scary if its leftmost element is the median of all elements
- For distinct elements: only odd-length subarrays can be scary
- Subarray length 1 is always scary (leftmost = median = only element)

Specifications:
- Input array size: N=8 elements (MAX_N=8)
- Each element is 8-bit unsigned integer (1 to 255)
- All elements guaranteed distinct
- Use combinational logic for comparison (no recursion, bounded loops)

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [2:0] array_length // Actual length of array (1-8)
input [7:0] p_0, p_1, p_2, p_3, p_4, p_5, p_6, p_7 // Array elements

Outputs:
output reg [7:0] scary_count // Number of scary subarrays
output reg done // High when computation complete

Behavior:
The module should compute the number of scary subarrays by:
1. For each starting position l (0 to array_length-1):
2. For each odd length (1, 3, 5, ... up to array_length-l):
3. Check if p[l] is the median of elements p[l] to p[l+length-1]
4. Count if true

For odd length 2k+1:
- Sort the subarray and find median at position k
- p[l] is median iff exactly k elements in subarray are smaller than p[l]

Implementation approach:
- Use state machine: IDLE → PROCESSING → DONE
- For each start position, compare leftmost element with rest of subarray
- Count elements smaller than leftmost in current subarray
- For length 2k+1, check if count == k
- Process at most 8 start positions, each with max 8 comparisons
- Latency: approximately 20-30 clock cycles

State machine:
- IDLE: wait for start signal
- PROCESSING: iterate through subarrays
- DONE: assert done signal

Constraints:
- Use combinational blocks for comparisons
- Unroll loops for small N=8
- All arithmetic in binary (no floating point needed)
- Count fits in 8 bits (max scary subarrays = sum of (array_length+1)/2 for all odd lengths)
