Design a sequential Verilog module named 'dessert_finder' that computes valid beverage-main dish pairs for a given total price P, where:
- The beverage price B < main dish price M
- B + M = P
- All digits in B, M, and P are mutually distinct

The problem is simplified for hardware implementation with:
- P limited to 8-bit values (0-511)
- B and M computed as 9-bit values (0-511)
- Digit checking performed on decimal digits (0-9)
- Output sorted by beverage price B in ascending order
- Maximum 5000 results, but hardware limit is 64 results

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [8:0] P // total price (0-511)

Outputs:
output reg valid // high when result is valid
output reg [8:0] B_out // beverage price
output reg [8:0] M_out // main dish price
output reg done // high when search complete
output reg [6:0] count // number of valid pairs found

Specification:
The module should iterate through all possible B values from 1 to P-1 (or up to 255 for safety). For each B:
1. Compute M = P - B
2. Verify B < M (B < P/2)
3. Extract decimal digits from P, B, and M
4. Check that all digits are mutually distinct (no digit appears in more than one number)
5. If valid, store the pair (B, M) in internal FIFO

The module should use a state machine with states:
- IDLE: Wait for start signal
- COMPUTE: Iterate through B values, check validity
- OUTPUT: Present valid pairs sequentially
- DONE: All pairs processed

For digit extraction, treat numbers as decimal: e.g., P=37 has digits {3,7}, B=8 has digit {8}, M=29 has digits {2,9}. All 7 digits are distinct, so valid.

Result latency: 1000 clock cycles after start (to scan all B values). Use clock divider or counter for iteration.

Note: This is a simplified version where P is small (8-bit), making exhaustive search feasible in hardware. The module should demonstrate the digit distinctness constraint and combinatorial generation of valid pairs.
