Design a sequential Verilog module named 'longest_race_path' that computes the longest path in a small undirected graph ending at node 1 without repeating edges.

The graph is fixed to 8 nodes maximum (nodes 0-7 in hardware, 1-7 in problem map to 1-7, node 0 is unused or maps to 1). The module uses an adjacency matrix to represent edges.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [7:0] adj_matrix [8][8] // 8x8 adjacency matrix, adj_matrix[i][j] = 1 if edge exists

Outputs:
output reg [3:0] max_length // Maximum path length found (4 bits for up to 15 edges)
output reg done // High when computation complete

Behavior:
The module implements an iterative search using a state machine. It explores all simple paths starting from any node (1-7) and ending at node 1 (index 1). It tracks used edges via a bitmask to ensure no edge is traversed more than once. Since the graph is small (8 nodes), the search space is bounded.

State Machine:
- IDLE: Wait for start signal.
- INIT: Initialize search parameters (current node, path mask, etc.).
- SEARCH: Iterate through neighbors, update path, check constraints.
- UPDATE_MAX: Update max_length if a valid path ending at node 1 is found.
- BACKTRACK: Revert state to explore next possibility.
- DONE: Set done signal high.

Latency: Result valid approx 1000-2000 clock cycles after start (depending on graph density).

Constraints:
- Use parameter N = 8 for node count.
- Use internal registers for current node, visited edge mask, current length.
- The adjacency matrix input represents the network.
- Ensure edge non-repetition logic handles undirected nature (edge (u,v) and (v,u) are the same).
- Output path length is the number of edges traversed.
