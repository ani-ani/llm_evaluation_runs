Design a combinational Verilog module named 'duel_game' that determines the winner in a simplified card flipping game.

The game involves n cards arranged in a row, represented as a binary string. The goal is to determine if the first player (Tokitsukaze) can win in exactly one move, or if the second player (Quailty) can force a win, or if the game is a draw (referred to as 'once again').

Simplifications:
- n is fixed at 8.
- k is the number of consecutive cards that can be flipped. Valid range is 1 to n.
- A player wins if they flip k consecutive cards such that all cards end up with the same value (all 0s or all 1s).
- If the first player can win immediately, output 'tokitsukaze'.
- If the first player cannot win immediately, but no matter what the first player does, the second player can always win in the next turn (assuming optimal play), output 'quailty'.
- Otherwise (the game can continue indefinitely or results in a draw), output 'once again'.

Inputs:
input [7:0] card_state // The current state of 8 cards (bit 0 is leftmost card)
input [3:0] k // Number of consecutive cards to flip (1 to 8)

Outputs:
output reg [10*8-1:0] result // The result string. 10 characters max, 8 bits per ASCII char.

Behavior:
1. Check if the first player can win in one move by checking every possible window of size k. 
   - A winning move makes the array uniform (all 0s or all 1s).
   - If a winning move exists, set result to "tokitsukaze".
2. If no immediate win exists:
   - Simulate all possible moves of the first player (flipping any window of size k to 0s or 1s).
   - For each resulting state, check if the second player can win in one move (using the same criteria).
   - If for ALL possible first player moves, the second player CAN win in the next turn, set result to "quailty".
   - If there exists at least one first player move that leaves the second player unable to win immediately, set result to "once again".

ASCII Encoding:
't' = 0x74, 'o' = 0x6F, 'k' = 0x6B, 'i' = 0x69, 's' = 0x73, 'u' = 0x75, 'z' = 0x7A, 'a' = 0x61, 'q' = 0x71, 'l' = 0x6C, 'y' = 0x79, 'n' = 0x6E, 'c' = 0x63, 'e' = 0x65, ' ' = 0x20

Result should be null-padded or space-padded if shorter than 10 chars.
