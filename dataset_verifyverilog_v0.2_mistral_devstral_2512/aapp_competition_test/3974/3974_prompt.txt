Design a sequential Verilog module named 'min_people_finder' that implements the algorithm to find the minimum number of distinct people seen based on entry/exit events.

The module processes a sequence of characters representing '+' (enter) and '-' (exit) events. It calculates the difference between the maximum and minimum values of a running counter initialized at zero. This difference corresponds to the minimum number of distinct people.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset (synchronous)
input start // Start processing the sequence (pulse once)
input [63:0] events // Packed bit vector representing the event sequence. Bit 0 is the first event (MSB). Use 1 for '+', 0 for '-'. Max length 64.
input [5:0] length // Number of valid events in 'events' vector (1 to 64)

Outputs:
output reg [7:0] result // The minimum number of distinct people (max value 64)
output reg done // High when computation is complete and result is valid

Behavior:
1. On reset (rst_n low), set state to IDLE, clear counters and result.
2. When start is high, transition to PROCESSING state.
3. In PROCESSING state, iterate through the 'events' vector bit by bit.
   - If bit is 1 ('+'), increment running counter.
   - If bit is 0 ('-'), decrement running counter.
   - Track the minimum (min_val) and maximum (max_val) values of the running counter throughout the sequence.
   - Use a loop counter to iterate from 0 to length-1.
4. Once all bits are processed, calculate result = max_val - min_val.
5. Transition to DONE state, assert 'done' signal, and output the result.
6. Wait for next start pulse to restart.

Implementation details:
- Use a state machine with states: IDLE, PROCESSING, CALCULATE, DONE.
- Latency: approximately 'length' + 2 clock cycles after start is asserted.
- The running counter starts at 0.
- 'result' is an 8-bit unsigned integer.
