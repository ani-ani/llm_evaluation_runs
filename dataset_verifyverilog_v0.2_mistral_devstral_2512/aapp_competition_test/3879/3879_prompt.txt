Design a sequential Verilog module named 'jackpot_checker' that determines if a set of numbers can be made equal by repeated multiplication by 2 and 3.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [2:0] num_inputs // Number of valid inputs (1-8)
input [15:0] data_in // Current input number
input data_valid // High when data_in is valid

Outputs:
output reg result // High if all numbers can be made equal
output reg done // High when computation complete

Behavioral Description:
The module implements a state machine with states: IDLE, COLLECT, PROCESS, and DONE.

1. IDLE: Waits for 'start' signal.
2. COLLECT: Accepts 'num_inputs' numbers via 'data_in' when 'data_valid' is high. Stores them in a register array.
3. PROCESS: For each stored number, calculates the 'core' by dividing by 2 and 3 until no longer divisible. This is done sequentially for each number to save resources.
   - Core calculation loop: while (num % 2 == 0) num = num / 2; while (num % 3 == 0) num = num / 3.
   - Compare each calculated core with the first number's core.
   - If any mismatch, set a flag indicating failure.
4. DONE: Latch the final result (1 if all cores match, 0 otherwise).

Latency: Result valid 200 clock cycles after start asserted (sufficient for 8 numbers with bit shifting).

Signal Widths:
- 'data_in' is 16 bits wide.
- Internal array 'stored_values' is 8 elements of 16 bits each.
- Internal 'core_calc' is 16 bits.

Constraints:
- Maximum 8 numbers can be processed.
- Each number is 16-bit unsigned integer.
