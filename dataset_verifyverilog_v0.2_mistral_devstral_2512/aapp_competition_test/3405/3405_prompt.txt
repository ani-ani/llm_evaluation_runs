Design a sequential Verilog module named 'digit_rotate_multiplier' that finds all numbers N (up to 4 digits) where N * X equals N with first digit moved to end.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start search
input [31:0] x_fixed // X in Q16.16 format (X * 65536)

Outputs:
output reg [31:0] result // found number (0 if none)
output reg valid // high when result is valid
output reg done // high when search complete

Specify latency: The module should search through 1000-9999 range, taking ~1000 clock cycles. Use a state machine with states: IDLE, CHECK, ROTATE, VERIFY, NEXT, DONE.

Behavior:
1. In CHECK state: Multiply current N by X (fixed-point)
2. In ROTATE state: Compute rotated version of N (move first digit to end)
3. In VERIFY state: Compare product with rotated value
4. If match, output N and continue searching
5. If no match found in range, output 0
6. Process one candidate per clock cycle

For example with X=2.6 (0x0002999A in Q16.16), numbers like 135 should be detected.

The module should maintain:
- Current candidate number (n_current)
- Accumulator for found numbers (output via result)
- Counter for iteration

Use Q16.16 fixed-point multiplication: product = (n * x_fixed) >> 16

Note: Since we're scaling down, focus on 3-4 digit numbers (100-9999 range) which can be processed in reasonable time.
