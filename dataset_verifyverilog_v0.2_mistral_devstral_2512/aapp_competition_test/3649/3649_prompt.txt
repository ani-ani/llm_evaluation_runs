Design a sequential Verilog module named 'bitstring_constructor' that constructs a bit string satisfying specific subsequence count constraints.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [31:0] a // count of '00' subsequences
input [31:0] b // count of '01' subsequences
input [31:0] c // count of '10' subsequences
input [31:0] d // count of '11' subsequences

Outputs:
output reg [7:0] result_string // 8-bit string (max 8 characters)
output reg [2:0] result_length // actual length of string (0-8)
output reg done // high when computation complete
output reg valid // high if solution found

Specify latency: Result valid 100 clock cycles after start asserted.
Use state machine with states: IDLE, CHECK_PARAMS, SOLVE_KL, CONSTRUCT, DONE.

The module should:
1. Check if input counts are consistent with valid k (zeros) and l (ones) counts
2. Solve for k and l from: a = k*(k-1)/2, d = l*(l-1)/2, b = k*l
3. Verify b == c (must be equal for valid solutions)
4. Construct string using k zeros and l ones arranged to match b/c values
5. Return string of length k+l (capped at 8 bits)
6. Handle edge cases: a=0,b=0,c=0,d=0, or a=0,b=0,c=0,d=1 etc.

For construction:
- If b >= k and (b-k) % (k-1) == 0 and k>1: use (k-1) zeros, then '0', then l ones pattern
- Else if c >= k and (c-k) % (l-1) == 0 and l>1: use '1', then k zeros, then (l-1) ones pattern
- Else if b==0 and c==0: use all zeros then all ones (or vice versa)

Output should be in hex format where each bit represents a character. For example, '01001' is 0x09.
Max string length is 8.
