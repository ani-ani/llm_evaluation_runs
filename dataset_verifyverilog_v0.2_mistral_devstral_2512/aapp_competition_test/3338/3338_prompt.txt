Design a sequential Verilog module named 'arcaea_diversity' that computes maximum diversity of partners after awakening up to k partners.

Inputs:
input clk // clock signal
input rst_n // active-low reset  
input start // start computation
input [2:0] n // number of partners (max 8)
input [2:0] k // max awakenings allowed (max 4)
input [7:0] frag [0:7] // Frag values for 8 partners
input [7:0] step [0:7] // Step values for 8 partners  
input [7:0] frag_awaken [0:7] // Awakened Frag values (0 if cannot awaken)
input [7:0] step_awaken [0:7] // Awakened Step values (0 if cannot awaken)

Outputs:
output reg [3:0] result // maximum diversity (0-8)
output reg done // high when computation complete

Latency: Approximately 2^8 * n^2 clock cycles worst case (manageable for n=8)

Behavior:
1. State machine: IDLE → PREPARE → ENUMERATE → COMPUTE → UPDATE → DONE
2. Use binary counter to enumerate all awakening combinations (2^n possibilities, but stop when awakenings > k)
3. For each valid combination, compute diversity:
   - Generate current state of each partner (awakened or not)
   - Use parallel comparators to check pairwise dominance
   - Count partners that form maximum antichain
4. Track maximum diversity across all combinations
5. Output final maximum

Optimization: Use combinational blocks for dominance checking within each state.
