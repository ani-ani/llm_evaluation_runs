Design a sequential Verilog module named 'pythagorean_triple_counter' that counts the number of Pythagorean triples (a,b,c) such that a ≤ b and a² + b² ≡ c² (mod n), where 1 ≤ a,b,c ≤ n-1.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [4:0] n // modulo value (2 ≤ n ≤ 16)

Outputs:
output reg [15:0] count // number of valid triples
output reg done // high when computation complete

Specification:
- The module should iterate through all possible values of a, b, c from 1 to n-1
- For each triple (a,b,c) where a ≤ b, check if (a² + b²) mod n = c² mod n
- Count all valid triples
- Use a state machine with states: IDLE, COMPUTE, DONE
- Latency: Result valid within (n-1)³ clock cycles after start asserted
- Since n ≤ 16, maximum iterations = 4096 cycles
- Use modular arithmetic: compute a² mod n, b² mod n, c² mod n
- All calculations use integer arithmetic with 16-bit width
- For modulo operation, use subtraction-based reduction since n is small

Behavioral Description:
1. In IDLE state, wait for start signal
2. In COMPUTE state:
   - Iterate a from 1 to n-1
   - For each a, iterate b from a to n-1 (ensuring a ≤ b)
   - For each (a,b), iterate c from 1 to n-1
   - Compute a_sq = (a * a) % n
   - Compute b_sq = (b * b) % n  
   - Compute c_sq = (c * c) % n
   - If (a_sq + b_sq) % n == c_sq, increment count
3. After all iterations, transition to DONE state
4. In DONE state, output is valid until reset

Implementation notes:
- Use combinational multipliers for squares
- Use sequential logic for iteration control
- Reset count to 0 on reset
- n must be ≥ 2 and ≤ 16
- All intermediate values fit in 16 bits (max: 15*15=225 for n=16)

Example:
For n=7, count should be 18.
For n=15, count should be 64.

The module should be synthesizable and follow standard sequential design practices.
