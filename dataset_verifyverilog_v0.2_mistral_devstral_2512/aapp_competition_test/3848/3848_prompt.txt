Design a sequential Verilog module named 'next_tolerable_string' that computes the lexicographically next string of length n that avoids palindromic substrings of length 2 or 3.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation signal
input [3:0] n // Length of string (1-16)
input [4:0] p // Alphabet size (1-26)
input [127:0] s_in // Input string as packed bytes (8 bits per char, 16 chars max)

Outputs:
output reg valid // High when result is valid
output reg [127:0] s_out // Output string in same format
output reg no_solution // High if no solution exists

Behavioral Description:
The module should implement the algorithm to find the lexicographically next tolerable string:
1. Start from the rightmost character (index n-1)
2. Try to increment the character at current index to a larger value
3. Check if the new character violates palindrome constraints with previous characters:
   - Cannot be same as previous character (palindrome length 2)
   - Cannot be same as character 2 positions back (palindrome length 3)
4. If valid, fill remaining positions to the right greedily with smallest valid characters
5. If cannot increment current character within bounds, move left and repeat
6. If all positions exhausted, assert no_solution

Use a state machine with states: IDLE, SEARCH, VALIDATE, FILL, DONE, NO_SOLUTION.

Constraints:
- Max string length n = 16
- Max alphabet size p = 26
- Characters are represented as ASCII 'a' + value (0-25)
- Latency: Approximately 16*26*2 clock cycles worst case

The module should use registers to store the working string and index counters.
