Design a sequential Verilog module named 'bonbon_arrangement' that implements a simplified version of the problem.

Problem Specification:
- Grid size is fixed to 4x4 (16 cells).
- Input counts for flavors A, B, C (each <= 5).
- Goal: Fill the 4x4 grid with A, B, C such that no two same characters are adjacent horizontally or vertically.
- The module should perform a search to find a valid arrangement.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // High for one cycle to start the search
input [3:0] count_a // Number of A bonbons required (0-5)
input [3:0] count_b // Number of B bonbons required (0-5)
input [3:0] count_c // Number of C bonbons required (0-5)

Outputs:
output reg [15:0] grid // 16 characters packed into 16*8 bits? No, let's use 4 rows of 4 chars. 
output reg valid // High if a valid arrangement is found
output reg done // High when search is complete

Behavior:
The module uses a state machine to try filling the grid cell by cell (row-major order).
State Machine States: IDLE, SEARCH, VALID_STATE, COMPLETE.

- IDLE: Wait for start signal.
- SEARCH: Iterate through grid positions 0 to 15. At each position, try placing 'A', 'B', 'C' if count permits and adjacent constraints are satisfied.
  - Constraints: Check left neighbor and top neighbor (if they exist).
  - If a placement is valid, decrement the corresponding count and proceed to next cell.
  - If all placements fail at current cell, backtrack to previous cell.
- VALID_STATE: If cell index reaches 15 (last cell filled), check counts (must be 0) and constraints. If valid, copy to output.
- COMPLETE: Set 'done' high. If valid arrangement found, 'valid' is high.

Latency: Result valid within ~5000 cycles (worst case for backtracking on 4x4 grid).

Output Format: 'grid' should represent the 4x4 layout. We can use a 16-byte array or 4x 32-bit registers. Let's use a 16x8-bit memory interface or packed bits.
