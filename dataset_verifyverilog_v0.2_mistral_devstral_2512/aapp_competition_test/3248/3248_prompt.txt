Design a sequential Verilog module named 'untileable_cells' that computes the number of untileable cells in a street given a set of tile patterns.

The module operates on a street of length N (scaled to 16) and M patterns (scaled to 8), each of length L (scaled to 16).

Inputs:

input rst_n // Active-low reset
input start // Start computation
input [5:0] N_valid // Number of valid characters in street (1 to 16)
input [5:0] M_valid // Number of valid patterns (1 to 8)
input [7:0] street_char_0, street_char_1, street_char_2, street_char_3, street_char_4, street_char_5, street_char_6, street_char_7, street_char_8, street_char_9, street_char_10, street_char_11, street_char_12, street_char_13, street_char_14, street_char_15 // Street characters (ASCII values)

Outputs:
output reg [5:0] result // Number of untileable cells
output reg done // High when computation complete

The module should compute the result using a state machine. The logic should:
1. Maintain a 16-bit 'covered' register, initially 0.
2. Iterate through each pattern (0 to M-1).
3. For each pattern, iterate through all valid start positions in the street (0 to N-L).
4. If the pattern matches the street substring starting at that position, set the corresponding bits in 'covered' (from start to start+L-1).
5. After all patterns are checked, count the number of zeros in 'covered' for positions 0 to N-1.

State Machine States: IDLE, CHECK_PATTERN, CHECK_POSITION, MATCH_CHECK, COUNT, DONE.
Latency: Approximately N*M*L cycles plus overhead.
