Design a sequential Verilog module named 'danger_level_calculator' that computes the danger level for each chamber in a small cactus graph.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [2:0] node_idx // current node index (0-7) for adjacency input
input [2:0] neighbor_idx // neighbor node index (0-7)
input [7:0] edge_weight // edge weight between node_idx and neighbor_idx
input edge_valid // indicates valid edge input

Outputs:
output reg [2:0] current_node // node being output
output reg [31:0] danger_level // danger level for current_node (mod 10^9+7)
output reg result_valid // high when danger_level is valid
output reg done // high when all nodes processed

The module should:
1. Accept adjacency information for an 8-node graph
2. Compute shortest path distances between all pairs of nodes
3. For each node, sum distances to all other nodes (danger level)
4. Output results sequentially for each node
5. Use modulo 10^9+7 for final sums

Implementation details:
- Use state machine: IDLE, LOAD_GRAPH, COMPUTE_SHORTEST_PATHS, CALCULATE_SUMS, OUTPUT_RESULTS, DONE
- Store graph as 8x8 adjacency matrix (initialize with large value for no edge)
- Use iterative distance updates (similar to Floyd-Warshall but simplified)
- Clock cycles: ~100-200 for full computation on 8-node graph
- Edge weights are 8-bit (0-255)
- Danger levels can be up to 8*255 = 2040, so 12 bits needed before modulo
- Modulo 10^9+7 = 1000000007, store as 32-bit constant
