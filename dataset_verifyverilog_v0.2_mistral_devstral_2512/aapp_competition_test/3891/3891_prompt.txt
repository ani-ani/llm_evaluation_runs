Design a sequential Verilog module named 'black_square_center' that finds the center of a black square in an n x m grid.

The module scans through the grid cell by cell (row-major order) and tracks the minimum and maximum row and column indices where 'B' (black) cells are found. After scanning the entire grid, it computes the center by averaging the min and max coordinates.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start the scan (assert high for one cycle)
input cell_valid // High when current cell data is valid
input cell_is_black // High if current cell is 'B', low if 'W'
input [7:0] row_index // Current row index (0-based)
input [7:0] col_index // Current column index (0-based)

Outputs:
output reg [7:0] center_row // Center row coordinate (1-based output)
output reg [7:0] center_col // Center column coordinate (1-based output)
output reg done // High when computation is complete

Behavioral Description:
1. The module uses an FSM with states: IDLE, SCANNING, CALCULATING, DONE.
2. In IDLE state, waits for 'start' signal.
3. In SCANNING state, on each clock cycle where 'cell_valid' is high:
   - If 'cell_is_black' is high:
     - Update min_row and max_row based on current 'row_index'
     - Update min_col and max_col based on 'col_index'
4. When scanning is complete (assumed after 32 cycles for 8x8 grid or tracked via external counter), transition to CALCULATING.
5. In CALCULATING state:
   - Compute center_row = (min_row + max_row) / 2 + 1
   - Compute center_col = (min_col + max_col) / 2 + 1
6. Transition to DONE state and assert 'done' signal.
7. Wait in DONE until reset or new start.

Latency: Result valid approximately 34 clock cycles after start (assuming 32 cells for 8x8 grid + 2 cycles for calculation).

Default grid size parameters: N_ROWS = 8, N_COLS = 8 (scalable via parameters).

For the testbench, assume the grid is 8x8 or smaller, and the testbench will drive the inputs in row-major order.
