Design a sequential Verilog module named 'snuke_flip_solver' that calculates the minimum number of operations to flip all cards face down.

Problem Adaptation:
- The input is a set of indices where cards are face up.
- We limit the maximum card index to 16 (system has cards 1..16).
- Operations are flipping p consecutive cards where p is a prime >= 3. 
- Valid p values: 3, 5, 7, 11, 13.
- Maximum consecutive cards to flip: 13.
- The state is represented as a 16-bit vector where bit i is 1 if card (i+1) is face up.
- We use precomputed ROM containing shortest path distances from every state to state 0.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [15:0] card_mask // Bitmask of face-up cards (bit 0 = card 1)

Outputs:
output reg [7:0] result // Minimum number of operations (0-16)
output reg done // High when computation complete

Specification:
- Use a state machine with states: IDLE, LOOKUP, DONE.
- In LOOKUP state, read the precomputed cost from a ROM based on card_mask.
- Latency: 2 clock cycles after start is asserted (1 cycle for LOOKUP, 1 for DONE).
- The ROM is initialized with BFS-computed shortest paths for all 2^16 states.
- Flipping is defined for p in {3, 5, 7, 11, 13}.
- A flip of length p starting at position s flips bits s through s+p-1.
- Valid start positions s are 0 to (16-p).
- The ROM must be synthesized as a lookup table (array logic).
