Design a sequential Verilog module named 'challenge24' that solves the '24 game' with grading.

The module searches through all permutations of 4 input values, all combinations of 3 operators (+, -, *, /), and all parenthesis structures to find the lowest grading expression that evaluates to exactly 24. 

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [7:0] val0 // First base value (1-100)
input [7:0] val1 // Second base value (1-100)
input [7:0] val2 // Third base value (1-100)
input [7:0] val3 // Fourth base value (1-100)

Outputs:
output reg [3:0] min_grade // The minimum grade found (0-15)
output reg found // High when a valid expression is found
output reg done // High when search is complete

Behavior:
1. The module must evaluate all possible expressions using the 4 input values.
2. Permutations: Generate all 24 permutations of the 4 input values. Calculate grade cost based on inversions from original order.
3. Operators: Test all 4^3 = 64 combinations of operators (+, -, *, /). Division is only valid if it divides evenly.
4. Parentheses: Test 5 distinct parenthesis structures:
   - Case 0: ((a op b) op c) op d
   - Case 1: (a op (b op c)) op d
   - Case 2: a op ((b op c) op d)
   - Case 3: a op (b op (c op d))
   - Case 4: (a op b) op (c op d)
   Each case has a specific parenthesis cost: Case 0=0, Case 1=1, Case 2=1, Case 3=2, Case 4=2.
5. Grade: Total grade = permutation_inversion_cost + parenthesis_cost.
6. Result: Track the minimum grade found where the expression equals exactly 24.
7. Division: Only allowed if the divisor divides the dividend evenly (no truncation). Check for divide-by-zero.
8. State Machine: Use states IDLE, LOAD_PERM, CALCULATE, NEXT_OP, NEXT_PERM, DONE.
9. Output: When done is high, min_grade holds the lowest grade (0-15) or 15 if impossible. 'found' is high if a valid expression exists.

Latency: Result valid approximately 50,000 clock cycles after start asserted (allows for full search).
