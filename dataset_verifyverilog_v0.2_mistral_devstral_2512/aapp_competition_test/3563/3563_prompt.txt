Design a sequential Verilog module named 'min_lines_convex' that computes the minimum number of straight lines needed to cover points on the boundary of a convex polygon.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [5:0] n // number of points (max 8)
input [7:0][15:0] x_coords // x coordinates of up to 8 points
input [7:0][15:0] y_coords // y coordinates of up to 8 points

Outputs:
output reg [3:0] result // minimum number of lines (max 8)
output reg done // high when computation complete

Latency: Result valid 200 clock cycles after start asserted.

Behavioral Description:
Since points are on a convex polygon boundary, they form a cyclic sequence. The minimum line cover problem reduces to partitioning this sequence into collinear segments. The algorithm uses a greedy approach:

1. Start from point 0, extend line as far as possible with consecutive collinear points
2. Count one line, then start from next ungrouped point
3. Continue until all points are covered

For collinearity check (three points (x1,y1), (x2,y2), (x3,y3)):
Compute cross product: (x2-x1)*(y3-y1) - (y2-y1)*(x3-x1) = 0

Use state machine with states:
- IDLE: Wait for start signal
- INIT: Initialize pointers and counters
- CHECK_COLLINEAR: Check if next point is collinear with current line
- EXTEND_LINE: Move pointer forward if collinear
- NEW_LINE: Increment line counter and reset current line
- DONE: Set done signal

Handle wrap-around for cyclic nature of convex polygon points.
All coordinates are 16-bit signed integers.
Result is count of lines needed.
