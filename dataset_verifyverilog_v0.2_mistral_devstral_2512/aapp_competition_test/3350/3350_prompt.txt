Design a sequential Verilog module named 'spell_power_calculator' that finds the power of a word, which is the length of the maximum subword of the form ww^Rww^R (where w is any sequence and w^R is its reverse). For a substring to match ww^Rww^R, if w has length L, the total length is 4L.

Simplifications for hardware implementation:
- Maximum input string length: 16 characters (N=16)
- Characters are ASCII bytes (8-bit values)
- w can have maximum length of 4 (so total substring length max 16)
- We check all possible substrings and all possible w lengths (1, 2, 3, 4)
- The module should find the maximum valid substring length (multiple of 4)

Inputs:
input clk // clock signal
input rst_n // active-low reset  
input start // start computation
input [7:0] char_in // current character from input string (sequentially provided)
input [3:0] char_index // index of current character (0 to 15)
input valid_input // high when char_in is valid

Outputs:
output reg [7:0] power // maximum length of valid substring (0, 4, 8, 12, or 16)
output reg done // high when computation complete

Behavior: The module receives characters sequentially (16 total, indexed 0-15). After all characters are received and start is asserted, it should:
1. Check all possible substrings for pattern ww^Rww^R
2. For each substring, check if it can be split as ww^Rww^R where w has length L=1,2,3,4
3. Track the maximum valid length found (must be multiple of 4)
4. Output the result and set done high

Latency: Result valid up to 256 clock cycles after start asserted (allows for sequential checking).

Use state machine with states: IDLE, COLLECTING, CHECKING, DONE.

Example:
Input: "abrahellehhelleh" (hellehhelleh matches with w="helleh", L=6, but for our scale w max 4 chars)
For our 16-char limit, example with w="he": w="he" -> w^R="eh" -> pattern "heehheeh" length 8.
Power is maximum length where pattern exists.

Module should use sequential logic to:
- Store characters in a 16x8-bit memory
- Iterate through all possible substring start positions
- For each start position, iterate through possible substring lengths
- Check if substring matches ww^Rww^R pattern
- Track maximum valid length
- Output result when done
