Design a sequential Verilog module named 'k_mfree_subset' that computes the size of the largest k-multiple free subset.

The module operates on a fixed-size array of N=8 elements. The input integers are limited to 12-bit values (0-4095). The multiplier k is limited to 8 bits (1-255).

Inputs:
input clk              // Clock signal
input rst_n            // Active-low reset
input start            // Start computation pulse
input [7:0] k          // The multiplier k (valid range 1-255)
input [2:0] n          // Number of valid elements in the array (1 to 8)
input [11:0] arr [0:7] // Input array of 8 integers, max value 4095

Outputs:
output reg [3:0] result // Size of the largest k-multiple free subset (max 8)
output reg done         // High when computation is complete

Behavior:
The module should implement a greedy strategy to find the largest subset:
1. Sort the input array in ascending order (bubble sort or similar logic over several cycles).
2. Iterate through the sorted elements, keeping track of selected elements.
3. For each element, if its potential multiple (element * k) has NOT been selected yet, include the element in the subset.
4. If the multiple HAS been selected, exclude the current element.

Latency: The result should be valid approximately 300 clock cycles after 'start' is asserted.
Use a state machine with states: IDLE, SORT, PROCESS, DONE.

Note: Since k is a power of 2 in the simplified test cases (2, 4, 8, etc.), you can optimize multiplication by bit-shifting. However, the module must support arbitrary k in the range 1-255.
