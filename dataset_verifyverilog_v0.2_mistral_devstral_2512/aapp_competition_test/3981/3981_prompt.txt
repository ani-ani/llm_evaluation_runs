Design a sequential Verilog module named 'rocket_safety_checker' that implements a simplified supersonic rocket safety check.

The module should:
1. Accept two engines with up to 8 power sources each (2D coordinates in Q16.16 format)
2. Compute the convex hull for each engine using a simplified iterative algorithm
3. Check if the convex hulls are identical under transformation equivalence
4. Use parallel logic for small input sizes

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [15:0] engine1_x [0:7] // x-coordinates of engine 1 (Q16.16)
input [15:0] engine1_y [0:7] // y-coordinates of engine 1 (Q16.16)
input [2:0] engine1_count // number of valid points in engine 1 (3-8)
input [15:0] engine2_x [0:7] // x-coordinates of engine 2 (Q16.16)
input [15:0] engine2_y [0:7] // y-coordinates of engine 2 (Q16.16)
input [2:0] engine2_count // number of valid points in engine 2 (3-8)

Outputs:
output reg safe // 1 if safe, 0 if not
output reg done // high when computation complete

The module should use a state machine with states: IDLE, FIND_MIN_Y, SORT_POINTS, BUILD_HULL, COMPARE_HULLS, DONE.

Latency: Result valid 200 clock cycles after start asserted.

For fixed-point arithmetic:
- Use Q16.16 format (16 integer bits, 16 fractional bits)
- Input values are already in this format
- Use signed arithmetic for comparisons

The convex hull algorithm should:
1. Find point with minimum y (and minimum x as tiebreaker)
2. Sort remaining points by polar angle around this point (use cross product for comparison)
3. Build hull using Graham scan (limited to 8 points)
4. Compare hulls by checking if they are identical up to translation/rotation
   - For small fixed graphs, check if point sets are congruent

Simplify comparison: Check if hulls have same number of vertices and matching edge lengths/angles.
