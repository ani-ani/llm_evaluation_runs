Design a sequential Verilog module named 'governor_convergence' that computes the minimum months to unify parties.

Inputs:
input clk // clock signal
input rst_n // active-low reset  
input start // start computation
input [3:0] party_vector // 4 bits representing party of each governor (0=Orange, 1=Purple)
input [5:0] edge_mask // 6-bit mask for possible edges in 4-node graph: bits represent (0,1),(0,2),(0,3),(1,2),(1,3),(2,3)

Outputs:
output reg [3:0] months // result: minimum months needed
output reg done // high when computation complete

The module should:
1. Represent a 4-node graph where nodes 0-3 are governors
2. Party vector: bit i is party of governor i
3. Edge mask: if bit k is set, corresponding edge exists (edges: (0,1)=bit0, (0,2)=bit1, (0,3)=bit2, (1,2)=bit3, (1,3)=bit4, (2,3)=bit5)
4. Simulation logic:
   - In each month, find largest connected component of same-party nodes
   - Flip that component to opposite party
   - Alternate starting party each month (Orange first, then Purple, etc.)
   - Stop when all nodes have same party
5. Use state machine: IDLE, FIND_COMPONENTS, FLIP_COMPONENT, CHECK_CONVERGENCE, DONE
6. Compute result in 100 clock cycles max
7. Result is number of months (1-16)

Latency: Result valid 100 clock cycles after start asserted.
Use simple BFS-like logic with registers to track visited nodes and component sizes.
