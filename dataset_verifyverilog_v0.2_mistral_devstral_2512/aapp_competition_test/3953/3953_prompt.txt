Design a sequential Verilog module named 'purification_solver' that finds a solution to the purification problem for a 4x4 grid.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input [3:0] grid_row_idx // Current row index for grid input (0-3)
input [3:0] grid_col_idx // Current col index for grid input (0-3)
input cell_type // 0 for '.', 1 for 'E'

Outputs:
output reg [1:0] result_row [0:3] // Row index of spell for each of 4 spells
output reg [1:0] result_col [0:3] // Col index of spell for each of 4 spells
output reg [2:0] result_count // Number of spells (0-4)
output reg done // High when computation complete
output reg valid // High if solution exists

Specify latency: Result valid 50 clock cycles after start asserted.
Use state machine with states: IDLE, LOAD_GRID, SOLVE, OUTPUT.

Behavioral Description:
The module loads a 4x4 grid of cell types (0 for normal, 1 for evil) into an internal memory.
It then solves the problem by finding 4 spells (one for each row or column) that cover all rows and columns without casting on evil cells.
For a 4x4 grid, the solution can be found by checking two strategies:
1. Select one '.' cell in each row (row-wise strategy).
2. Select one '.' cell in each column (column-wise strategy).
If a row (or column) is full of 'E', that strategy fails.
If both strategies fail, output valid=0.
Otherwise, output the first valid strategy found.
The module should iterate through the grid to load data, then iterate to check conditions.
