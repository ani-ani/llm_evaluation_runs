Design a sequential Verilog module named 'max_payout' that solves a simplified version of the problem.

Problem Definition:
Given n (array size) and a list of m coupons (each with a weight w_i), find the maximum total weight Sereja can pay. This is determined by the maximum number of distinct integers k that can be used in a 'beautiful' array of size n.

Derived Mathematical Property:
The maximum number of vertices (distinct integers) k allowed for a beautiful array of size n follows:
- If k is odd: max vertices = k*(k-1)/2 + 1
- If k is even: max vertices = k*k/2

Algorithm to implement:
1. Input a list of m weights.
2. Sort the weights in descending order.
3. Iterate k from 1 upwards. For each k, calculate the required array size for k distinct integers.
4. If required size <= n, then k distinct integers are possible. 
5. Find the largest k satisfying the condition.
6. Sum the top k weights from the sorted list.

Module Specifications:
- Input: `clk`, `rst_n`, `start` signal.
- Input: `num_n` (12 bits, represents n, max 2000)
- Input: `num_m` (8 bits, represents m, max 100)
- Input: `weights` (100 elements of 16 bits each). Since m can be up to 100, we fix the input array size to 100. Unused elements can be 0.
- Output: `max_sum` (32 bits, cumulative sum of selected weights).
- Output: `done` (1 bit, high when calculation is complete).

Behavior:
1. **Weight Sorting**: Since sorting in hardware is complex for this spec, assume inputs are provided in sorted order (descending). This simplifies the module to focus on the logic of finding k and summing.
2. **Iteration**: In the PROCESSING state, iterate from k=1 to k=num_m.
3. **Calculation**: For each k, calculate the required array size:
   - Check parity of k.
   - If odd: `required = (k * (k - 1)) / 2 + 1`
   - If even: `required = (k * k) / 2`
4. **Comparison**: Compare `required` with `num_n`.
5. **Accumulation**: If `required <= num_n`, add the weight at index (k-1) to the sum.
6. **Completion**: The final accumulated sum is the answer.

State Machine:
- IDLE: Wait for start signal.
- CALC: Iterate k from 1 to num_m, perform calculations, update sum.
- DONE: Assert done signal.

Constraints:
- Use 12-bit width for n (max 4095 covers required values).
- Use 16-bit width for weights (sum fits in 32 bits).
- Use 6-bit counter for k (max 64, covers max distinct values required for n~2000, which is around k=64).
- k reaches at most ~63 for n=2000.

The module should strictly follow the iterative logic described.
