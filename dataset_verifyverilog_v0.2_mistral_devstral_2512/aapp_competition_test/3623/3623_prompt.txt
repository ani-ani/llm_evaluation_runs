Design a sequential Verilog module named 'courtyard_coverage' that calculates the proportion of a square courtyard that is watered by four sprinklers at its corners.

Problem Specification:
- Courtyard is a unit square (1x1) with corners at (0,0), (1,0), (1,1), (0,1)
- Four sprinklers are at the four corners
- Each sprinkler has an angular coverage measured from the wall
- Bottom-right sprinkler at (1,0): covers angle from the right wall (positive x-axis) going counterclockwise
- Top-right sprinkler at (1,1): covers angle from the top wall (positive y-axis) going counterclockwise
- Top-left sprinkler at (0,1): covers angle from the left wall (negative x-axis) going counterclockwise
- Bottom-left sprinkler at (0,0): covers angle from the bottom wall (positive y-axis) going clockwise
- Each sprinkler can spray infinitely far within its angular coverage
- We need to compute the proportion of the square that is covered by at least one sprinkler

Implementation Strategy:
- Use Q16.16 fixed-point format for all calculations
- Input angles are provided in degrees (0-90) as Q16.16 values
- Discretize the courtyard into an 8x8 grid (64 sample points)
- For each grid point, check if it falls within the angular coverage of any sprinkler
- A point is covered if its angle from the sprinkler corner is within the sprinkler's angular range
- Count covered points and divide by 64 to get the proportion

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [31:0] angle_br // bottom-right sprinkler angle (Q16.16)
input [31:0] angle_tr // top-right sprinkler angle (Q16.16)
input [31:0] angle_tl // top-left sprinkler angle (Q16.16)
input [31:0] angle_bl // bottom-left sprinkler angle (Q16.16)

Outputs:
output reg [31:0] proportion // result in Q16.16 format
output reg done // high when computation complete

Behavioral Description:
The module uses a state machine with states: IDLE, CALCULATE_COVERAGE, COMPUTE_RESULT, DONE.
1. IDLE: Wait for start signal
2. CALCULATE_COVERAGE: Iterate through 8x8 grid points (64 iterations)
   - For each point (x, y) where x, y ∈ {0/8, 1/8, ..., 7/8}
   - Check coverage by each sprinkler:
     * Bottom-right (1,0): vector = (x-1, y-0), angle = atan2(y, x-1) from negative x-axis
     * Top-right (1,1): vector = (x-1, y-1), angle = atan2(y-1, x-1) from negative x-axis  
     * Top-left (0,1): vector = (x-0, y-1), angle = atan2(y-1, x) from positive x-axis
     * Bottom-left (0,0): vector = (x-0, y-0), angle = atan2(y, x) from positive x-axis
   - Use lookup table or approximation for arctangent
   - Count points covered by any sprinkler
3. COMPUTE_RESULT: Calculate proportion = (covered_points * 65536) / 64 = covered_points * 1024
4. DONE: Set done signal and wait for reset

Specify latency: Result valid 80 clock cycles after start asserted (64 cycles for grid + 16 cycles for computation).

Fixed-Point Specification:
- All angles and calculations use Q16.16 format
- Input angles in degrees are multiplied by 65536
- For arctangent, we use angle comparison with reference angles 0°, 45°, 90°
- Reference angles in Q16.16: 0 = 0, 45° = 45*65536 = 2949120, 90° = 90*65536 = 5898240
- Point (x,y) where x,y ∈ {0/8,...,7/8} can be represented as Q16.16: x_q = x*8*65536/8 = x*65536

Key Hardware Considerations:
- Use combinatorial logic for coverage checking per point
- Use a counter for grid iteration (6-bit counter: 0-63)
- Use integer arithmetic where possible for speed
- Pre-compute 1/8 = 8192 in Q16.16 format
- For angle comparison, we can use direction checks rather than full arctangent:
   * Bottom-right: check if point is within 45° cone from negative x-axis
   * Top-right: check if point is within angle cone from negative y-axis  
   * Top-left: check if point is within angle cone from positive x-axis
   * Bottom-left: check if point is within angle cone from positive y-axis

Simplified Coverage Logic (combinational per point):
- Bottom-right: covered if (y <= -tan(a) * (x-1)) AND (x <= 1) AND (y >= 0)
- Top-right: covered if (y-1 <= -tan(b) * (x-1)) AND (x <= 1) AND (y >= 0)
- Top-left: covered if (y-1 <= tan(c) * x) AND (x >= 0) AND (y <= 1)
- Bottom-left: covered if (y <= tan(d) * x) AND (x >= 0) AND (y >= 0)

Where tan(angle) is pre-computed or approximated using a small lookup table (90 entries for 0-90° in 1° increments, stored as Q16.16 values). The module will use this LUT for angle calculations.
