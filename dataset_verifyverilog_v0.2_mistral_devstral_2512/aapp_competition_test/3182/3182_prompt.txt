Design a sequential Verilog module named 'right_triangle_counter' that counts the number of right triangles formed by exactly 8 points in a 2D coordinate plane.

Inputs:
input clk // Clock signal
input rst_n // Active-low reset
input start // Start computation
input signed [15:0] points [0:7] // 8 points flattened: {x0,y0,x1,y1,...,x7,y7}

Outputs:
output reg [7:0] count // Number of right triangles found
output reg done // High when computation complete

Specification:
1. The module accepts 8 points where each coordinate is a 16-bit signed integer.
2. Points are provided as a flattened array: points[0]=x0, points[1]=y0, points[2]=x1, points[3]=y1, etc.
3. A right triangle is formed by three distinct points (i, j, k) where the dot product of two edge vectors is zero:
   - Vector AB: (xj-xi, yj-yi)
   - Vector AC: (xk-xi, yk-yi)
   - AB · AC = (xj-xi)*(xk-xi) + (yj-yi)*(yk-yi) = 0
4. Must check all combinations of 3 points from 8 (C(8,3)=56 combinations).
5. For each combination, check if it forms a right triangle at any of the 3 vertices.
6. Latency: 256 clock cycles after start asserted.

State Machine:
- IDLE: Wait for start signal
- PROCESSING: Iterate through point combinations using nested loops
- DONE: Set done high, result available

Implementation Notes:
- Use 3 nested loops: outer for point i, middle for j>i, inner for k>j
- For each triplet, calculate dot products at all 3 vertices
- Use signed arithmetic for coordinates and dot products
- Increment count when right angle detected
- Use a state machine to coordinate the iteration
- Ensure distinct points (i != j != k)

Example:
Points: (4,2), (2,1), (1,3)
Vectors from (4,2): to (2,1) = (-2,-1), to (1,3) = (-3,1)
Dot product: (-2)*(-3) + (-1)*(1) = 6 - 1 = 5 (not right angle)
But checking at (2,1): vectors (4-2,2-1)=(2,1) and (1-2,3-1)=(-1,2), dot=2*(-1)+1*2=0 (right angle)

The module must return count=1 for this example.
