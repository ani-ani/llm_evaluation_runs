Design a combinational Verilog module named 'arpa_food_solver' that solves the Arpa's party problem for small n.

Problem Adaptation:
Given n pairs of guests (boy/girl) sitting at chairs 1 to 2n in a circle, find a food assignment (1 or 2) such that:
1. Boy and his girlfriend have different food types.
2. Among any 3 consecutive chairs, at least two have different food types.

Constraints:
- Fixed n = 4 (hardcoded for this implementation to allow exhaustive search in combinational logic)
- Chairs are numbered 1 through 8
- Input: 4 pairs of chair indices (a_i, b_i) for boys and girls
- Output: Food types (1 or 2) for each pair

Inputs:
input [3:0] pair0_boy_chair,  // Chair index (1-8) of boy in pair 0
input [3:0] pair0_girl_chair, // Chair index (1-8) of girl in pair 0
input [3:0] pair1_boy_chair,
input [3:0] pair1_girl_chair,
input [3:0] pair2_boy_chair,
input [3:0] pair2_girl_chair,
input [3:0] pair3_boy_chair,
input [3:0] pair3_girl_chair

Outputs:
output [1:0] pair0_food, // {boy_food, girl_food} where 1=Kooft, 2=Zahre-mar (binary: 01 or 10)
output [1:0] pair1_food,
output [1:0] pair2_food,
output [1:0] pair3_food
output valid // 1 if a valid solution exists, 0 otherwise

Implementation Details:
- The module should perform an exhaustive search over all 2^8 possible food assignments for the 8 chairs.
- For each assignment, verify:
  a. For each pair (boy_chair, girl_chair), food[boy] != food[girl]
  b. For all i from 1 to 8, consider chairs i, i%8+1, i%8+2. Check that not all three have the same food.
- Since 2^8 = 256 combinations, this is implementable in combinational logic using a loop over the 8-bit state vector or a case statement.
- Output the first valid solution found (priority logic).
- Output format: pair0_food[1] is boy, pair0_food[0] is girl (or similar mapping, be consistent).

Behavior:
If valid is 0, output values are don't care.
If valid is 1, output values satisfy all constraints.
