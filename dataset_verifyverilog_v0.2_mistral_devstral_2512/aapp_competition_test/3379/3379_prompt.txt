Design a sequential Verilog module named 'max_kahn_sources' that computes the maximum possible size of the source set S during Kahn's topological sort algorithm for a small directed acyclic graph.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [2:0] node_count // number of nodes (1-8)
input [2:0] src_node // source node index for edge input
input [2:0] dst_node // destination node index for edge input
input edge_valid // valid edge to add
input edge_complete // all edges have been input

Outputs:
output reg [2:0] max_sources // maximum size of S observed
output reg done // high when computation complete

Specification:
- Support up to 8 nodes (indexed 0-7)
- Accept edges via src_node/dst_node/edge_valid signals
- Once all edges are input (edge_complete=1), compute the answer
- The algorithm should find the maximum number of nodes with zero in-degree that can exist simultaneously during any execution of Kahn's algorithm
- For a DAG, this equals the maximum width of a topological layering
- Use state machine: IDLE (accepting edges), COMPUTING (running Kahn's variants), DONE
- Latency: Result valid within 256 clock cycles after start

Note: This requires tracking in-degrees and exploring the branching choices in Kahn's algorithm to find the maximum simultaneous sources.
