Design a combinational Verilog module named 'unsorted_permutations' that computes the number of entirely unsorted sequences for a small multiset.

Inputs:
input [3:0] n // number of elements (1-8)
input [7:0][31:0] data // array of n 32-bit integers (use only first n elements)

Outputs:
output [31:0] count // number of entirely unsorted permutations modulo 1000000009

The module should:
1. Accept up to 8 integers in data[0] through data[n-1]
2. Generate all permutations of these n elements
3. For each permutation, check if any element is in its 'sorted position'
4. An element at index k is 'sorted' if for all j > k, perm[j] >= perm[k] AND for all j < k, perm[j] <= perm[k]
5. Count permutations where NO element is sorted (entirely unsorted)
6. Return count modulo 1000000009

For example, with input [0,1,2,3] (n=4), output should be 14.
With input [1,1,2,1,1] (n=5), output should be 1.

The module should use combinational logic to enumerate permutations. Since n is small (≤8), this is feasible. Use a multi-stage approach to generate permutations using a state machine or parallel computation.

Hint: Use a next_permutation algorithm implemented as a state machine, or generate all permutations using nested loops unrolled for small n.
