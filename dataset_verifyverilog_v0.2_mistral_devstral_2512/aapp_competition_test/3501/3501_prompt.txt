Design a sequential Verilog module named 'camel_race_bets' that counts pairs of camels appearing in the same order across 3 bets.

Problem Adaptation: Given 3 permutations of N camels (N<=32), count pairs (c,d) where c appears before d in all 3 permutations. This can be computed by iterating through all pairs and checking order consistency.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [4:0] n // number of camels (max 32)
input [4:0] a [0:31] // Jaap's bet: position -> camel
input [4:0] b [0:31] // Jan's bet: position -> camel
input [4:0] c [0:31] // Thijs' bet: position -> camel

Outputs:
output reg [31:0] result // count of consistent pairs
output reg done // high when computation complete

Module Behavior:
1. On start signal, compute all pairs (i,j) where i < j (camels 1..n)
2. For each pair, check if order is consistent in all 3 bets:
   - Get positions: pos_a[i], pos_a[j] from input array a
   - Check pos_a[i] < pos_a[j] for Jaap's bet
   - Similarly check for b and c bets
3. Count pairs where all 3 conditions are true
4. Output result and set done high

Implementation Details:
- Use IDLE, SETUP, CHECK_PAIRS, DONE states
- Use nested loops: outer for i=1 to n-1, inner for j=i+1 to n
- Store position mappings in 32x5-bit arrays during SETUP
- Use combinational logic to check order for each pair
- Latency: Approximately n*(n-1)/2 cycles after start
- Result width: 32 bits (max pairs = 32*31/2 = 496)

The module should:
1. Initialize/clear counters
2. Build position lookup tables for all 3 bets
3. Iterate through all possible pairs
4. Check if order is consistent in all 3 bets
5. Increment counter for consistent pairs
6. Complete and signal done
