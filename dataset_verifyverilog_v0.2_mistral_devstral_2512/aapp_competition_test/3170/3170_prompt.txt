Design a sequential Verilog module named 'trash_game' that simulates the card game 'Trash' between Theta and a Friend.

**Overview:**
The module takes a 416-bit input representing the 52-card deck (10 cards for each player + 32 draw pile cards). It simulates the game turn-by-turn and determines the winner. Theta and the Friend have different strategies for placing Wildcards (Jacks).

**Card Representation:**
- Cards are represented as 4-bit values:
  - 4'd0: Ace (A)
  - 4'd1 to 4'd9: 2-9
  - 4'd10: Ten (T)
  - 4'd11: Jack (J)
  - 4'd12: Queen (Q)
  - 4'd13: King (K)

**Inputs:**
- `input clk`: System clock.
- `input rst_n`: Active-low reset.
- `input start`: High for one cycle to start the simulation.
- `input [415:0] deck`: The shuffled deck. `deck[415:412]` is the first card (Theta's Ace slot face-down), `deck[411:408]` is the second card, etc.

**Outputs:**
- `output reg result`: High if Theta wins, low if Friend wins.
- `output reg done`: High when the game is finished (winner determined).

**Internal Logic & State Machine:**
Use a state machine with states: IDLE, CHECK_WIN, DRAW_CARD, THETA_JACK_STRATEGY, FRIEND_JACK_STRATEGY, PLACE_CARD, DISCARD_TURN, SWITCH_PLAYER.

**Data Structures (Registers):**
- `reg [3:0] theta_slots [0:9]`: Stores the current value in Theta's 10 slots (0 if empty, 1-13 if filled).
- `reg [3:0] friend_slots [0:9]`: Stores the Friend's filled slots.
- `reg [13:0] theta_revealed`: Bitmask of card values (1-13) revealed by Theta (face-up slots or discards).
- `reg [13:1] friend_revealed`: Bitmask of card values revealed by Friend.
- `reg [5:0] deck_ptr`: Pointer to the next card in the deck to draw (initially 20).
- `reg [5:0] current_card`: The card currently being processed (drawn or uncovered).
- `reg [3:0] turn_count`: Safety counter to prevent infinite loops (max 200 turns).
- `reg current_player`: 0 for Theta, 1 for Friend.

**Strategies:**
1. **Friend Strategy**: Always place Jack in the lowest unfilled slot (0-9).
2. **Theta Strategy**: Place Jack in the lowest unfilled slot that minimizes future deadlocks. 
   - Logic: A slot is 'safe' if the card value needed is already in `theta_revealed` (seen in a slot or discard) OR if the card value has NOT been dealt to Theta's face-down slots (impossible to draw, so must be in Friend's slots or discard).
   - Theta checks slots from 0 to 9. If a slot is safe, she fills it.
   - If no safe slot exists, she fills the lowest unfilled slot.
   - Note: We must track which cards are in Theta's initial hand. Since we know the deck, we can extract `theta_initial_hand` (indices 0-20).

**Game Logic Flow:**
1. **Initialization**: On `start`, reset all slots, load `theta_initial_hand` from `deck[415:336]`, set `deck_ptr` to 20, `current_player` to 0.
2. **Turn Loop**:
   a. Check win: If all slots filled for current player, set `result` and finish.
   b. Draw: Read `deck[deck_ptr]`, increment `deck_ptr`.
   c. Process Card:
      - If J (11): Use strategy to pick slot. If all slots full, discard. Else fill slot and repeat with the face-down card from that slot.
      - If Q/K (12/13): Discard, switch player.
      - If 1-10 (0-10): Check if slot `value-1` (or `value-12` for T=10? No, T is 10, index 9) is empty.
         - If empty: Fill it. Uncover face-down card in that slot (from initial hand). Repeat with uncovered card.
         - If filled: Discard, switch player.
3. **Winning**: First to fill 10 slots wins.

**Specifics for Theta's Strategy:**

**Implementation Details:**
- `theta_initial_hand` extraction: `deck[415:336]` (80 bits). 
- `friend_initial_hand`: `deck[335:256]`. 
- `discard_revealed` array: `reg [13:0] discard_revealed`. 
- We need to track which cards are in the discard pile. 
- We also need to know which cards are in the *draw pile* to simulate draws. 
- Since the deck is fixed, we can just read from the `deck` input using `deck_ptr`. 

**Revised Strategy:**
- **Friend**: Jack -> lowest unfilled slot (0-9).
- **Theta**: Jack -> iterate slots 0 to 9. If slot `i` is unfilled: 
   - `req = i+1` (with A=1, T=10). 
   - If `req` is in `theta_revealed` OR `discard_revealed` (meaning she has seen it and can't get it), fill this slot. 
   - If multiple, lowest index. 
   - If none, fill lowest unfilled.

**Module Interface:**
- `module trash_game(clk, rst_n, start, deck, result, done);`

**State Machine:**
- `IDLE`: Wait for start.
- `INIT`: Setup hands.
- `TURN_START`: Check win condition.
- `DRAW`: Read card from `deck` at `deck_ptr`.
- `JACK`: Handle Jack placement (strategy).
- `UNCOVER`: When a slot is filled, read the face-down card from initial hand.
- `DISCARD`: Card goes to discard.
- `SWITCH`: Change player.
- `WIN`: Set result, done.

**Latency:** Result valid after max 2000 cycles (bounded).
