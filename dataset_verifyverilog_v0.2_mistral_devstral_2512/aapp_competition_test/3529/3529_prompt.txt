Design a sequential Verilog module named 'spanning_tree_check' that determines if a spanning tree with exactly k blue edges exists in a small graph.

Inputs:
input clk // clock signal
input rst_n // active-low reset
input start // start computation
input [2:0] n // number of nodes (2-8)
input [4:0] k // desired number of blue edges (0-16)
input [3:0] m // number of edges (1-16)
input [3:0] edge_index // index for loading edges
input edge_valid // valid signal for edge loading
input [2:0] node_u // first node of edge (1-8)
input [2:0] node_v // second node of edge (1-8)
input edge_color // 0 for Red, 1 for Blue

Outputs:
output reg result // 1 if spanning tree with k blue edges exists, 0 otherwise
output reg done // high when computation complete

Behavior:
The module should implement the following algorithm:
1. Load edges into an internal buffer (max 16 edges)
2. Compute min_blue by preferentially selecting Red edges (Kruskal's algorithm)
3. Compute max_blue by preferentially selecting Blue edges (Kruskal's algorithm)
4. Check if k is in range [min_blue, max_blue]

The algorithm uses a Disjoint Set Union (DSU) data structure with 8 nodes.
Edges are stored as {color, u, v} tuples.
Sorting is simplified: for min_blue, sort Red edges before Blue edges.
For max_blue, sort Blue edges before Red edges.

Latency: Approximately 200 clock cycles after start asserted.
Use state machine with states: IDLE, LOAD_EDGES, SORT_EDGES, COMPUTE_MIN, COMPUTE_MAX, CHECK_RESULT, DONE.

For DSU operations (find/union), use iterative logic with loop counters (max 8 iterations).
For edge processing, iterate through sorted edges and perform union operations.
Result is 1 if (k >= min_blue && k <= max_blue), else 0.

Fixed-size arrays:
- Edge buffer: 16 entries, each {color[0], u[2:0], v[2:0]}
- DSU parent array: 8 entries, 3 bits each

Note: Node indices are 1-based (1-8), but stored 0-based (0-7) in hardware for array indexing.
