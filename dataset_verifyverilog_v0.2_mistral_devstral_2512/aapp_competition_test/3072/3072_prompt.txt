Design a combinational Verilog module named 'max_perimeter_rectangle' that finds the maximum perimeter rectangle in an 8x8 binary grid where 0 represents free space and 1 represents blocked space.

The module should check all possible rectangles in the 8x8 grid and find the one with the maximum perimeter that consists entirely of free cells (all 0s). The perimeter of a rectangle with width W and height H is 2*(W+H).

Inputs:
input [7:0] grid [0:7] // 8 rows of 8-bit binary values. Each bit represents a cell: 0=free, 1=blocked

Outputs:
output [6:0] max_perimeter // Maximum perimeter found (0-32, 7 bits sufficient)

The module should be purely combinational.

Behavioral Description:
1. Iterate through all possible rectangle positions and sizes in the 8x8 grid.
2. For each rectangle, check if all cells within it are free (0).
3. Calculate the perimeter for valid rectangles: 2*(width + height).
4. Find and output the maximum perimeter among all valid rectangles.
5. If no free cell exists, output 0.
6. A single free cell has perimeter 4 (1x1 rectangle).
7. The maximum possible perimeter for an 8x8 grid is 30 (7x8 or 8x7 rectangle).

Note: The input is provided as an array of 8-bit vectors where each bit represents a cell in that row.
