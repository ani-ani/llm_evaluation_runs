Design a sequential Verilog module named 'RankingSystem' that calculates the final ranking of contestants in a programming cup after the last contest.

**Scenario**: You are given the scores of 'm' contestants from the first 'n-1' contests (where 2 <= n <= 10 and m is small for this hardware implementation, e.g., m <= 8). You need to determine the rank of the first contestant (you) after the last contest, assuming a specific set of scores for the last contest. The module will accept the scores for all contestants for all contests (including the last one) and output the rank of contestant 0.

**Inputs**:
- `clk`: Clock signal
- `rst_n`: Active-low reset
- `start`: Start computation
- `n`: Number of contests (2 to 10)
- `m`: Number of contestants (2 to 8 for this module)
- `scores [0:7] [0:9] [7:0]`: A 3D array storing scores for up to 8 contestants and 10 contests. `scores[i][j]` is the score of contestant `i` in contest `j`. Unused entries should be 0.

**Outputs**:
- `result_rank`: The final rank of contestant 0 (1-based).
- `done`: High when computation is complete.

**Behavior**:
The module must:
1. Calculate the aggregate score for each contestant. Aggregate score is the sum of the 4 highest scores.
   - Note: The input scores are already the final points (0-101), including the +1 for online/on-site participation if applicable. The problem statement says the input "might not correspond to actual points from a contest" (i.e. rank-to-point conversion might have happened externally), so we simply sum the top 4.
2. Determine the rank of contestant 0. Rank is 1 + the number of contestants with a strictly higher aggregate score.
3. Handle the edge case: If multiple contestants have the same aggregate score as contestant 0, contestant 0 ranks better (strictly higher only).

**Implementation Details**:
- Use a state machine: IDLE -> SORT_SCORES (sort scores for each contestant to find top 4) -> SUM_TOP4 -> COMPARE_RANKS -> DONE.
- For sorting top 4 scores: Since the number of contests (n) is small (max 10), use a sorting network or a small bubble sort state machine.
- For comparison: Iterate through all 'm' contestants and count how many have aggregate > yours.
- Input scores are raw values (integers). No fixed-point conversion needed.
- Latency: Result valid approximately 500-1000 clock cycles after start (due to nested loops for sorting and summing).

**Prompt**: "Design a sequential Verilog module named 'RankingSystem' that computes the rank of the first contestant given scores for 'n' contests and 'm' contestants. Inputs include clock, start, 'n', 'm', and a 3D array of scores. Outputs are the rank and a done signal. The module should first sort the scores for each contestant to find the top 4, sum them to get the aggregate, and then compare the first contestant's aggregate against all others to determine rank."
