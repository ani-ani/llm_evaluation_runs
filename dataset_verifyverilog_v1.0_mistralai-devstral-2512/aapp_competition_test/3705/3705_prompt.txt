Design a Verilog module to compute the maximum number of phone numbers that can be made from digit cards. A valid phone number has length 11 and starts with '8'. Given n cards (n≤100) as a string of digits, output the maximum count.

Problem Analysis:
- Each phone number requires 1 '8' and 10 other digits (total 11 cards)
- The maximum possible phone numbers = min(count of '8's, floor(n/11))
- Since n≤100, n//11 ≤ 9, so the result fits in 4 bits
- '8' is ASCII 0x38, but we can treat it as a 4-bit value 8

Interface Specification:
Inputs:
  clk: clock, rising edge
  rst_n: active-low synchronous reset
  start: start processing (1-cycle pulse)
  digits_in: 100-bit input representing the digit string (8 bits per char, but we only need to check for '8')
  n: 7-bit input (since 100 fits in 7 bits), number of cards

Outputs:
  result: 4-bit output (0-9 phone numbers)
  done: 1-cycle pulse when valid result is ready

Timing:
- Start asserted for 1 cycle
- Within 100 cycles (max n=100), assert done
- When done=1, result holds the answer
- Reset: done=0, result=0

Implementation Details:
- Since n≤100 and string length ≤100, we can process in a single cycle or small FSM
- We need to count how many '8's are in the input string
- We need to compute n//11 (integer division)
- Then take the minimum of these two values
- The input is a 100-bit string where each 8-bit character represents a digit (ASCII 0x30-0x39), but we only care if it equals '8' (0x38)
- To simplify: treat the input as 100 bits where bit i is 1 if character i is '8', else 0
- Count the 1s in the first n bits to get count_8
- Compute n//11 by subtracting 11 repeatedly or using a lookup table
- Compute min(count_8, n//11)

Constraints:
- Clock frequency: assume 100MHz (10ns period)
- Reset: synchronous, active low
- No combinational loops
- All signals properly registered

Edge Cases:
- n < 11: result should be 0 (can't make even one phone number)
- No '8's in input: result should be 0
- More '8's than needed: limited by n//11

Module Name: phone_counter

Please provide the Verilog module implementation.
