Implement a Verilog module that solves the grid coloring problem for a tray of size R x C (max 16x16) with 3 colors (A, B, C). Constraints: no two adjacent cells (horizontally or vertically) have the same color. R and C are even, but inputs will be scaled to fit 16x16. Given counts a, b, c for colors A, B, C respectively. The module should accept R, C (4-bit inputs), a, b, c (16-bit inputs). It should compute a valid arrangement or indicate impossibility. The output is a 256-bit packed array representing the 16x16 grid (16 rows * 16 columns * 4 bits per cell), and a 'valid' flag (1-bit) indicating success. The 4-bit encoding: 0001 = A, 0010 = B, 0011 = C, 0000 = unused. The module should run for a maximum of 256 cycles. The logic must check if a valid arrangement exists based on color counts and grid dimensions. For valid cases, it should construct a repeating pattern that satisfies adjacency constraints (e.g., checkerboard or 2x2 blocks). The interface: Inputs: clk, rst_n, start (1-cycle pulse), R[3:0], C[3:0], a[15:0], b[15:0], c[15:0]. Outputs: grid[255:0], valid, done (1-cycle pulse). Timing: start asserted, valid and done pulse within 256 cycles.
