Design a Verilog module that computes the probability of Anthony winning a game given initial points N and M (1 <= N,M <= 16), and a sequence of N+M-1 round win probabilities. Use dynamic programming where state (a, m) is Anthony's points a and Cora's points m. The recurrence: P(a, m) = p[i] * P(a, m-1) + (1-p[i]) * P(a-1, m), where i = (N-a)+(M-m) is the round number. Base cases: P(>0, 0) = 1, P(0, >0) = 0. The probabilities p[i] are input as 8-bit integer representations of Q8.8 fixed-point values (0.0 to 1.0 scaled by 256). Input: N (4 bits), M (4 bits), p[0:15] (8 bits each, only first N+M-1 are valid). Output: result (16-bit, Q8.8 fixed-point probability). Compute sequentially over 256 cycles using a lookup table for DP states. Start signal initiates computation, done signal goes high when result is valid.
