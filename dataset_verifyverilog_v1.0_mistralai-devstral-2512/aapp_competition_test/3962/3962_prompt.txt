Design a Verilog module that implements a scaled-down version of the dinner seating problem. The problem requires finding the minimum total chairs needed for n guests in circles, given that the i-th guest needs at least l_i chairs to the left and r_i chairs to the right.

The algorithm simplifies to: sort all l_i values, sort all r_i values, compute sum of max(l_i, r_i) for each i, and add n.

**Interface Specification:**

Inputs:
- clk: System clock (rising edge)
- rst_n: Active-low synchronous reset
- start: 1-cycle high to start computation
- l_in[31:0]: Input L value (32-bit, scaled down from max 10^9)
- r_in[31:0]: Input R value (32-bit)
- load_en: 1-cycle high when l_in/r_in are valid for the current guest index

Outputs:
- result[31:0]: The total number of chairs (scaled result)
- done: 1-cycle high when result is valid
- ready: High when module accepts new inputs (during initialization)

**Internal Logic:**
- Accept exactly N=16 guests (fixed compile-time constant).
- Store l and r values in two internal arrays of size 16.
- Use a sorting state machine (e.g., bubble sort or selection sort network) to sort both arrays.
- After sorting, compute the sum of max(l[i], r[i]) + 1 for i=0 to 15.
- Output the total sum.
- The sorting and summation must complete within a bounded number of cycles (e.g., 5000 cycles).

**Timing:**
- Reset clears all internal state and sets done=0.
- When ready=1, the host streams in 16 pairs of (l_in, r_in) over 16 cycles (asserting load_en).
- After loading, the module asserts start to begin processing.
- The module computes for up to X cycles.
- When finished, done pulses high for 1 cycle, and result contains the answer.

**Constraints:**
- N = 16 (compile-time constant)
- DATA_WIDTH = 32 bits (enough for scaled values)
- Total cycles must not exceed 5000.
- Implement sorting using a comparator network or iterative FSM.
