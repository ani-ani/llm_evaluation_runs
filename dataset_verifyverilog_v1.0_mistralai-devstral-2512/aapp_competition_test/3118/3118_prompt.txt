Implement a Verilog module to find the minimal number of alternating shuffles (Alice then Bob) required to return a deck to sorted state. Given permutation arrays for Alice and Bob, find when the combined iteration returns to identity.

Simplify to n≤8 cards. Track cycle lengths using a state machine that applies permutations iteratively.

Interface:
- Inputs: clk, rst_n, start (1-cycle pulse)
- Permutations: Each card position (8 max) represented as 3-bit values in parallel registers
- Alice's permutation: alice_0 to alice_7, each 3-bit
- Bob's permutation: bob_0 to bob_7, each 3-bit
- Length: num_cards (3-bit, value 1-8)

- Output: result (16-bit cycle length, 0 means huge > 10^12)
- Output: done (1-cycle pulse when valid)

Behavior:
1. On start, initialize deck to identity: position i contains card i
2. Apply Alice permutation, then Bob permutation (1 cycle = 2 shuffles)
3. Count iterations until deck returns to identity
4. If count exceeds 2^16-1, output 0 (huge)
5. Stop after max 2^16 iterations

Implementation approach:
- Use FSM with states: IDLE, LOAD, SHUFFLE, CHECK, DONE
- Current deck state: 8x3-bit registers
- Counter: 16-bit iteration counter
- For each iteration, apply permutations using combination logic
- Check if deck equals identity by comparing each position
- Return count when identity reached

Timing: start->done within 2^18 cycles (worst case 2^16 iterations * 2 shuffles each)
Reset: done=0, result=0, counter=0, deck=identity
