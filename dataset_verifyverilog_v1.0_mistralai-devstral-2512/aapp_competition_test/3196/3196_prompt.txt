Design a Verilog module that counts distinct routes in a directed graph from source (town 1) to destination (town 2).

**SCALING & CONSTRAINTS:**
- Max nodes: 16 (N=16)
- Max edges: 32 (M=32)
- Node IDs: 1-16 (encoded as 0-15 internally)
- Count width: 32-bit (handles up to 2^32-1 paths)
- Output: Last 9 digits (modulo 1000000000)
- Infinite detection: Cycle reachable from source AND can reach destination

**INTERFACE:**
- Inputs:
  * clk: global clock (posedge)
  * rst_n: active-low synchronous reset
  * start: 1-cycle pulse to start computation
  * edges_valid: high when edge data is valid
  * src_node: 4-bit (node ID 0-15)
  * dst_node: 4-bit (node ID 0-15)
  * edge_count: 5-bit (0-31, number of edges to load)

- Outputs:
  * result: 32-bit count (mod 1000000000)
  * inf_flag: 1-bit (high if infinite paths detected)
  * done: 1-cycle pulse when computation completes
  * error: 1-bit (high if invalid configuration)

**BEHAVIOR:**
1. Reset: All state cleared, done=0, inf_flag=0, result=0
2. Load phase: When start=1, expect edge_count valid edges sequentially
3. Compute phase: Perform topological sort or cycle detection
4. If cycle exists on any path from source to destination, set inf_flag=1
5. Else count paths using DP (infinite if source=dest or cycles detected)
6. Output result modulo 1000000000
7. Set done=1 for 1 cycle when finished

**IMPLEMENTATION NOTES:**
- Use adjacency list (32 entries max)
- Use visitation states for cycle detection (0=unvisited, 1=visiting, 2=visited)
- Use DP array for path counts (32 entries)
- For large counts, maintain modulo 1000000000
- Total cycles ≤ 256 (16 nodes × 16 operations)
- State machine: IDLE → LOAD_EDGES → DETECT_CYCLES → COUNT_PATHS → DONE

**EDGE LOADING:**
- After start=1, expect edge_count edges
- Each edge: src_node and dst_node are valid for 1 cycle
- Edges are loaded into internal adjacency list

**TEST CASES:**
- Basic: 3 nodes, 2 edges (1→2, 2→3), source=1, dest=3, result=1
- Multiple paths: 4 nodes, edges (1→2, 1→3, 2→4, 3→4), source=1, dest=4, result=2
- Cycle detection: 3 nodes, edges (1→2, 2→3, 3→1), source=1, dest=3, inf_flag=1
- Self-loop: Edge (1→1), source=1, dest=1, inf_flag=1
