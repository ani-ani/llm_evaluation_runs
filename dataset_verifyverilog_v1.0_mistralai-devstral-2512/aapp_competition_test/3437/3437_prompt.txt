Design a Verilog module that solves the vacuum tube length maximization problem. Given N tube lengths (N ≤ 2000, lengths ≤ 10000), find two disjoint pairs of tubes such that: (pair1_sum ≤ L1) AND (pair2_sum ≤ L2), maximizing total length (pair1_sum + pair2_sum). Output 'Impossible' if no solution exists.

**Interface Specifications:**
- **Inputs:**
  - `clk`: System clock (rising edge triggered)
  - `rst_n`: Active-low asynchronous reset
  - `start`: 1-cycle start pulse (triggers computation)
  - `L1 [15:0]`: First distance limit (0-10000)
  - `L2 [15:0]`: Second distance limit (0-10000)
  - `N [10:0]`: Number of tubes (4-2000)
  - `tube_len [15:0]`: Current tube length to be written (1 cycle per tube)
  - `tube_wr_en`: Write enable for tube length (high for 1 cycle per tube)

- **Outputs:**
  - `result [15:0]`: Maximum total length found
  - `done`: 1-cycle pulse when computation complete (result valid)
  - `impossible`: High when no valid solution exists

- **Internal Storage:**
  - Must store all N tube lengths in an internal RAM/register array (max 2000 elements, 16-bit each)

- **Algorithm Requirements:**
  1. **Input Phase:** Accept N tube lengths sequentially via `tube_len` and `tube_wr_en` (requires N clock cycles)
  2. **Computation Phase:** After `start` pulse:
     - Enumerate all possible pairs (i,j) where i < j (O(N^2) complexity, max ~2M pairs)
     - For each pair, calculate sum = length[i] + length[j]
     - Store valid pairs for L1 (sum ≤ L1) and L2 (sum ≤ L2) separately
     - Find the maximum total = (valid L1 pair sum) + (valid L2 pair sum) where all four tubes are distinct
  3. **Output Phase:** Set `result` and `done`/`impossible` signals

- **Performance Constraints:**
  - Computation must complete within 5000 cycles after `start`
  - Clock frequency: 100 MHz (10ns period)
  - Total latency from `start` to `done` ≤ 500 µs

- **Hardware Optimizations:**
  - Use parallel comparators for pair sum checks
  - Implement finite state machine: IDLE → INPUT → COMPUTE → OUTPUT
  - Use fixed-size internal buffers for valid pair storage (e.g., store top K pairs)
  - Consider early termination if best possible sum is found

- **Output Format:**
  - When `impossible` is high, `result` may be undefined
  - When `done` is high, `result` contains the maximum total length (0-40000)
  - If no valid solution exists within constraints, output `impossible=1`, `done=1`
