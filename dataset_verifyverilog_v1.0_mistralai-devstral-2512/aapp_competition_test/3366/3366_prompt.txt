Implement a Verilog module to compute the sum S = f(L) + f(L+1) + ... + f(R) modulo 10^9+7, where f(X) counts iterations until X becomes 1 using the algorithm: while X != 1: if X even: X = X/2 else: X = X+1. Scale inputs to max 255 for hardware feasibility. Use 32-bit registers for arithmetic (result modulo 10^9+7). Use iterative state machine with at most 256*256 cycles.

Interface Specification:
Inputs:
  clk: rising edge clock
  rst_n: active-low synchronous reset
  start: 1-cycle high pulse to start computation
  L: 8-bit input (scaled from 0-255)
  R: 8-bit input (scaled from 0-255, L <= R)
Outputs:
  result: 32-bit sum modulo 10^9+7
  done: 1-cycle high pulse when result is valid (stays high for one cycle, then returns low)

Behavior:
- On reset (rst_n=0): done=0, result=0, all states idle
- On start pulse: Begin computing sum from L to R inclusive
- For each X in [L, R]: apply function f(X) to count iterations
- Sum all f(X) values
- Output result modulo 1,000,000,007 (0x3B9ACA07)
- Use 32-bit unsigned arithmetic with modulo after each addition

Implementation Requirements:
- State machine with states: IDLE, COMPUTING_F, ADDING, DONE
- Iterative f(X) computation requires variable cycles per X
- Use 8-bit register for current X (0-255)
- Use 32-bit register for current sum
- Use 8-bit counter for outer loop (L to R)
- Use 32-bit counter for inner iterations of f(X)
- Total cycles <= 256 * 256 = 65536
- Edge case: X=1 returns 0 iterations
- When X is odd and >1: X = X + 1 (makes it even)
- When X is even: X = X / 2
- Continue until X == 1
