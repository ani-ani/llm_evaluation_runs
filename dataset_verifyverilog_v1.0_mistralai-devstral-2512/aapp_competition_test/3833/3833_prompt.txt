Implement a Verilog module that rearranges a binary string `s` (input resources) to maximize occurrences of substring `t` (target pattern). The core logic is:
1. Compute the prefix function (KMP) of `t` to find the longest proper prefix which is also a suffix (`overlap_len`).
2. Define the repeating part: `t[overlap_len:]`. Let `cnt_0` and `cnt_1` be the counts of '0' and '1' in the repeating part.
3. The strategy is:
   - If `s` has enough '0's and '1's to form `t`, output `t` first.
   - Then, while `s` has enough resources for the repeating part (`cnt_0` zeros and `cnt_1` ones), output the repeating part.
   - Finally, output the remaining '0's followed by remaining '1's.

**Interface:**
- Inputs:
  - `clk`, `rst_n`: Standard synchronous control.
  - `start`: 1-cycle pulse to initiate computation.
  - `t_bits`: Input pattern `t`, packed into a single vector (max 16 bits). Valid bits indicated by `t_len`.
  - `s_cnt0`: 16-bit input, count of '0's in `s`.
  - `s_cnt1`: 16-bit input, count of '1's in `s`.
  - `t_len`: 5-bit input, length of `t` (max 16).
- Outputs:
  - `out_char`: 1-bit, the current character to output (0 or 1).
  - `out_valid`: 1-bit, high when `out_char` is valid.
  - `done`: 1-cycle pulse, high when construction is complete.
- Timing: Start pulse triggers the FSM. The module outputs characters sequentially. The total cycle count depends on string length (max ~32 cycles for small scale).
- Constraints: Assume maximum pattern length of 16 bits for KMP table storage. Max output length is constrained by input counts (max ~128 characters for simulation). State must handle the KMP computation, resource checking, and output generation.
