You are to design a Verilog module that implements a simplified version of the problem for N <= 16. The problem is: Given N dwarves in a circle (indices 0 to N-1) with strengths P[0:N-1]. Given N elves with preferred positions A[0:N-1] (mapped to dwarf indices) and strengths V[0:N-1]. Elves are processed sequentially (index 0 to N-1). Elf i attempts to sit at dwarf index (A[i] - 1). If that dwarf is taken, they move clockwise to (A[i] - 1 + 1) % N, etc., until they find an empty dwarf. Once all elves sit, count the number of pairs where the elf's strength V is greater than the dwarf's strength P. The input order of elves is fixed as index 0 to N-1 (we assume the optimal order is simply the input order, as the problem asks for the maximum victories, but the hardware simply executes the seating process for the given order). 

Interface:
- Inputs: clk, rst_n, start (1-cycle pulse), N (4-bit, 1-16), A[0:15] (16x4-bit, values 1-N), P[0:15] (16x16-bit dwarves strengths), V[0:15] (16x16-bit elves strengths).
- Outputs: result (16-bit victory count), done (1-cycle when valid).
- Behavior: On start, initialize an internal state array `occupied` (16 bits) to 0. Sequentially for elf_idx 0 to N-1: search circularly from (A[elf_idx]-1) % N for an empty slot. Write elf_idx into a matching array at that slot (or just track ownership). After all elves processed, iterate through all dwarves: if owner exists and V[owner] > P[dwarf_idx], increment count. Output count on result and pulse done.
- Constraints: Max latency ~N*N cycles (256 cycles for N=16). Use localparam for max N=16.
