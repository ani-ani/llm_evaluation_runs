Implement a Verilog module that finds starting positions q where a subsequence matches permutation of b.

**SCALED REQUIREMENTS:**
- n, m, p ≤ 16 (original: up to 200,000)
- a_i, b_i ≤ 63 (6-bit, original: up to 1e9)
- Maximum output positions: 16

**INTERFACE:**
Inputs:
  clk: rising edge
  rst_n: active-low sync reset
  start: 1-cycle pulse
  n[3:0], m[3:0], p[3:0]: input sizes
  a[0:15][5:0]: array a (16 elements, 6-bit each)
  b[0:15][5:0]: array b (16 elements, 6-bit each)

Outputs:
  result_count[3:0]: number of valid q values
  result_positions[0:15][3:0]: positions (1-indexed, 4-bit each)
  done: 1-cycle when valid

**ALGORITHM:**
1. For each q in 0..p-1:
   - Extract subsequence c: a[q], a[q+p], a[q+2p], ... (max 16 elements)
   - If length(c) < m: skip
   - Build histogram of first m elements in c
   - Compare with histogram of b
   - If match: record q+1
   - Slide window: remove c[i], add c[i+m] (1 step at a time)
   - Update histogram and check match

**IMPLEMENTATION NOTES:**
- Use histogram comparison for equality check
- Max 16 distinct values (6-bit)
- Fixed arrays: result_positions[15:0] for 16 possible positions
- Timing: start->done within 100 cycles
- Reset: done=0, result_count=0, all result_positions=0
- Use state machine: IDLE, EXTRACT, BUILD_HIST, COMPARE, SLIDE, RECORD
