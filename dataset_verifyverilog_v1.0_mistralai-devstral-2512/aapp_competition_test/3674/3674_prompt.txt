Design a Verilog module that solves the math problem: find smallest m-digit number X such that X = q * (Y * 10^n + p), where Y is the lower (m-n) digits of X. Inputs: m (4-bit), n (4-bit), p (8-bit), q (8-bit), start, clk, rst_n. Output: result (16-bit), done (1-bit). Constraints: m<=16, n<=4, p<=999, q<=255. Algorithm: Iterate candidates from 10^(m-1) to 10^m - 1 (max 65535), compute Y = candidate mod 10^(m-n), check if candidate == q * (Y * 10^n + p). Use bounded loops, no recursion. Timing: start triggers calculation, done=1 when result found or impossible (result=0). Reset: done=0, result=0.
