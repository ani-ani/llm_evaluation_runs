Design a Verilog module that counts distinct intersection/touch points between line segments. Scale coordinates to Q8.8 fixed-point format (8 integer bits, 8 fractional bits) with range [-128, 127.996] matching scaled inputs. Constraints: maximum 16 segments, 128 intersection points per segment pair, maximum 64 coordinates per segment. Module computes all segment-segment intersections using parametric line equations. Output -1 (0xFFFF) for overlapping segments (infinite intersections). Interface:

Inputs:
  clk: system clock, rising edge
  rst_n: active-low synchronous reset
  start: 1-cycle pulse to start computation
  seg_ptr[3:0]: segment index (0-15)
  seg_x0[15:0]: Q8.8 fixed-point x0
  seg_y0[15:0]: Q8.8 fixed-point y0
  seg_x1[15:0]: Q8.8 fixed-point x1
  seg_y1[15:0]: Q8.8 fixed-point y1
  seg_valid: data valid for current seg_ptr

Outputs:
  result[15:0]: number of distinct intersection points (or 0xFFFF for -1)
  done: 1-cycle pulse when result is valid
  busy: high while processing

Protocol:
  1. Reset sets busy=0, done=0, result=0
  2. When start=1, accept 16 segments via seg_ptr (0-15) with seg_valid=1
  3. After all segments loaded, compute all pairwise intersections
  4. Process: Check collinearity, compute intersection using cross products
  5. Handle special cases: parallel (no intersect), coincident (infinite), intersecting at endpoint
  6. Use 16x16-bit signed multipliers for cross products (dx*dy - dy*dx)
  7. Compare Q8.8 intersections to 1e-4 tolerance
  8. Store distinct points in internal register array (128 entries × 32 bits)
  9. Count unique points, output result when done=1
  10. Timing: within 10,000 cycles for 16 segments

Design notes:
  - Use fixed-point arithmetic for line intersection
  - Cross product overflow: use 32-bit intermediate
  - Coincident detection: check if (dx1*dy2 == dy1*dx2) AND segments share segment
  - Point equality: compare both coordinates within ±1 LSB
  - Scaling: -1000000 maps to -128.0, 1000000 maps to 127.996
  - Implement as FSM: LOAD -> COMPUTE -> COUNT -> DONE
  - Store points in distributed RAM, use 128-entry buffer
