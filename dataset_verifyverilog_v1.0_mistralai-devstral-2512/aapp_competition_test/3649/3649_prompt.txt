Implement a Verilog module `find_string` that finds a binary string (max 16 chars) matching pair counts. Inputs are a,b,c,d (4x 16-bit unsigned). Output string as 16x 1-bit array `out_chars` and its length `out_len` (0-16). The string must be valid: count '00', '01', '10', '11' subsequences equal to inputs. If impossible, output empty string (len=0). Constraints: 0 <= a,b,c,d <= 65535. The string length L must satisfy: L-1 <= a+b+c+d <= L*(L-1)/2. Solve by brute force or simple constructive logic: if L is small (<=16), iterate all binary strings of length L (max 2^16=65536 iterations) to find one matching all 4 counts. Use a combinational block for L=1 to 16. Return first match. If no match for any L, set out_len=0.
