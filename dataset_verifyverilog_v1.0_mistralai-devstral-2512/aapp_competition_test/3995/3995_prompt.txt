You are to design a Verilog module that generates a binary string of length 'n' (scaled to max 128) such that the minimal unique substring length is 'k'. 

**Algorithm Logic**:
1. Calculate the block length: `L = (n - k) // 2 + 1`.
2. If `n == k`, the output string is all '1's.
3. Otherwise, create a repeating pattern `P = 00...01` where the number of zeros is `L - 1`. 
4. Repeat the pattern `P` enough times and truncate to length `n`.

**Module Interface**:
- Inputs:
  - `clk`: System clock (required for register pipeline, though algorithm is combinatorial-heavy).
  - `rst_n`: Active-low synchronous reset.
  - `start`: 1-cycle pulse to trigger calculation.
  - `n_in`: 8-bit input (scaled n).
  - `k_in`: 8-bit input (scaled k).
- Outputs:
  - `result`: 128-bit output string.
  - `length_out`: 7-bit output (actual length of string, <= 128).
  - `done`: 1-cycle pulse asserted when result is valid.

**Implementation Details**:
- Handle the `n == k` case.
- Compute `L = (n - k) >> 1 + 1`.
- Construct the base pattern `base_pattern` of length `L` (zero-packed into bits).
- Repetition logic: Since the output is fixed width (128 bits), unroll the repetition loop or use a generate loop for the repeating pattern. Assume `L >= 1` and `n >= k`.
- The result must be packed into the 128-bit bus (LSB or MSB aligned, specify one).
- Timing: `done` should be high for 1 cycle after a few cycles of latency (pipeline the logic).

**Constraints**:
- `n` and `k` inputs are 8-bit (representing 0-255).
- Output `result` is 128-bit fixed width.
- `length_out` tells the valid bits in `result`.
