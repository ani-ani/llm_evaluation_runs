Design a Verilog module that implements the minimum-move solution finder for the grid increment game. Given an N×M grid (scaled to N,M ≤ 4, values ≤ 16) stored in a 16x8-bit RAM, the module must:

1. Input Interface:
   - clk, rst_n: standard synchronous signals
   - start: 1-cycle pulse to begin computation
   - grid[15:0][7:0]: 2D array input (max 4x4, packed into 64-bit reg)
   - n, m: 4-bit row/column counts

2. Algorithm:
   - Try base value x from 0 to 15 (representing potential common offset)
   - For each x:
     a. Compute column increments c_j = g[0][j] - x (must be ≥0)
     b. Compute row increments r_i = min_j(g[i][j] - c_j) (must be ≥0)
     c. Verify: For all i,j: r_i + c_j + x == g[i][j]
     d. If valid, compute total moves: x*min(n,m) + sum(r_i) + sum(c_j)
   - Keep track of minimum valid solution

3. Output Interface:
   - valid: 1-bit, high when solution found
   - moves: 16-bit total moves count
   - is_rows: 1-bit (0=column-first, 1=row-first for tie-breaking)
   - done: 1-cycle pulse when computation completes

4. Implementation Constraints:
   - Use 32-bit fixed-point arithmetic for intermediate sums
   - Implement as FSM with states: IDLE, SETUP_X, COMP_COL, COMP_ROW, VERIFY, UPDATE, OUTPUT
   - Maximum cycles: 1000
   - Memory: Use distributed RAM or registers for grid
   - For x=0..15, use a counter and state machine

5. Timing:
   - start to done: ≤ 100 cycles
   - Reset: All outputs to 0

Write the module specification with exact port names, bit widths, and state machine description.
