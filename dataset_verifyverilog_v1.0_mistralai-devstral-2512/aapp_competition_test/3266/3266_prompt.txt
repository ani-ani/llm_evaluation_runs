Implement a maximum flow calculator using Edmonds-Karp algorithm in Verilog. Constraints: Graph has at most 8 nodes (indexed 0-7). At most 16 edges. Capacity values fit in 8 bits (scaled down from 10^8). Source and sink are single 3-bit inputs. Output max flow value as 16-bit integer. Use synchronous design with start/done signals.

Module Interface:
- Inputs:
  clk: System clock (rising edge)
  rst_n: Active-low async reset
  start: 1-cycle high to start computation
  src: 3-bit source node index
  sink: 3-bit sink node index
  edge_valid: 1-bit flag indicating edge data is valid
  edge_u: 3-bit from node
  edge_v: 3-bit to node
  edge_cap: 8-bit capacity
- Outputs:
  result: 16-bit max flow value (valid when done=1)
  done: 1-cycle high when calculation complete

Algorithm steps:
1. Reset: Initialize flow matrix (8x8) to 0, residual capacity matrix to input capacities
2. While true:
   - Run BFS to find augmenting path from src to sink using residual graph
   - If no path found: break
   - Find bottleneck (min capacity on path)
   - Update residual capacities: forward edges -= bottleneck, backward edges += bottleneck
   - Accumulate total flow
3. Output total flow when done

Implementation notes:
- Use 8x8 matrix for residual capacities (initialize with input edges)
- BFS queue size: max 8 nodes
- Path tracking: store parent for each node during BFS
- Max iterations: 256 (to prevent infinite loops)
- Total flow fits in 16 bits
- Done signal goes high after calculation completes

Edge loading:
- When start=1 and edge_valid=1, load edges into residual capacity matrix
- Assume all edges provided before start goes high
