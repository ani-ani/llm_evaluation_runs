Create a Verilog module 'jack_forest' that computes the maximum total tree population across all species at any single year from year 0 to 1023.

**Constraints:**
- Max N (species): 16
- Max B (plant year): 1023
- Max Y (growth years): 32
- Max I (growth rate): 1023
- Max S (start pop): 1023
- Time horizon: 0 to 1023 (1024 years total)
- Populations fit in 16 bits.

**Algorithm:**
1. For each year `year` from 0 to 1023:
   - Calculate total population for this year by summing contributions from all species.
   - Contribution for species k:
     - If `year < B[k]`: 0
     - Else `t = year - B[k]`
     - If `t <= Y[k]`: Population = `S[k] + t * I[k]`
     - Else: Population = `S[k] + Y[k] * I[k] - (t - Y[k]) * I[k]` (decreases linearly)
2. Track the maximum total population found across all years.

**Module Interface:**
- **Inputs:**
  - `clk`, `rst_n`: Standard clock and active-low reset.
  - `start`: 1-cycle pulse to begin computation.
  - `species_count`: 4-bit (0-16) number of species valid in this cycle.
  - `B_in`, `Y_in`, `I_in`, `S_in`: 10-bit, 6-bit, 10-bit, 10-bit inputs respectively for the current species data. Valid when `start` is high.
- **Outputs:**
  - `result`: 16-bit maximum total population.
  - `done`: 1-cycle pulse indicating computation is complete.

**Implementation Strategy:**
- Use a FSM to iterate through years 0..1023.
- Maintain a storage array (Block RAM) for 16 species: `B`, `Y`, `I`, `S`.
- For each year, iterate through stored species, calculate contribution, sum them up, and compare with the running maximum.
- Since 1024 years * 16 species = 16,384 operations, implement as a pipelined iterative loop (approx 16k cycles latency).
