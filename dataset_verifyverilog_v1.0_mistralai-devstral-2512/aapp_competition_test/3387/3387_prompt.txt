Implement a Verilog module that solves the bandwidth allocation problem using an iterative projection algorithm.

**Problem Adaptation:**
- Scale n (number of species) to max 8 species
- Total bandwidth t: scale to 16-bit unsigned (0-65535)
- Bandwidth per species x_i: 32-bit fixed-point Q16.16
- Constraints a_i, b_i: 16-bit unsigned (0-65535)
- Demand d_i: 16-bit unsigned (0-65535)
- Fair share y_i = t * d_i / sum_d: Q16.16 fixed-point
- Objective: minimize sum((x_i - y_i)^2 / y_i)

**Algorithm:**
1. Compute total demand D = sum(d_i) as 32-bit
2. Compute fair share y_i = (t * d_i * 65536) / D for each i (Q16.16)
3. Initialize x_i = min(max(a_i, y_i), b_i) for each i
4. Compute residual R = t - sum(x_i)
5. If R != 0, distribute residual proportionally to d_i (or inverse quadratic penalty)
6. Project onto bounds: clamp x_i to [a_i, b_i]
7. Iterate 10-16 cycles to converge

**Module Interface:**
- Inputs:
  - clk: clock signal
  - rst_n: active-low async reset
  - start: 1-cycle pulse to start computation
  - n: 4-bit input (number of species, 1-8)
  - t: 16-bit input (total bandwidth)
  - For each species i (0-7):
    - a_i[15:0]: 16-bit lower bound
    - b_i[15:0]: 16-bit upper bound  
    - d_i[15:0]: 16-bit demand weight
- Outputs:
  - x_i[31:0]: 32-bit Q16.16 allocated bandwidth for each species
  - done: 1-cycle pulse when computation complete
  - valid: 1-bit high when x_i outputs are valid

**Timing:**
- Reset: done=0, valid=0, all outputs 0
- After start: within 50-100 cycles, done pulses
- result available when done=1 and valid=1

**Implementation Details:**
- Use 32-bit fixed-point arithmetic (Q16.16)
- Use 32-bit accumulators for sums
- Implement iterative loop (max 16 iterations)
- Each iteration: compute residual, adjust allocations, check bounds
- Convergence criteria: |R| < 2^(-8) or max iterations reached
- Output x_i as 32-bit unsigned fixed-point

**Testbench Requirement:**
The cocotb testbench must:
1. Scale input values to fit 16-bit ranges (0-65535)
2. Assign a_i, b_i, d_i individually per species
3. Use fixed-point conversion for y_i calculation
4. Verify outputs using Q16.16 to float conversion
5. Check relative error tolerance
6. Use helper functions for fixed-point math
7. Include timeout and reset logic
8. Handle optional signals with has_signal()

**Verilog Signal Constraints:**
- All a_i, b_i, d_i: 16-bit unsigned
- t: 16-bit unsigned
- n: 4-bit (max 8)
- x_i: 32-bit Q16.16 (unsigned with fractional part)
- Internal accumulators: 48-bit or 64-bit to prevent overflow
- Control FSM: iterate up to 16 cycles
