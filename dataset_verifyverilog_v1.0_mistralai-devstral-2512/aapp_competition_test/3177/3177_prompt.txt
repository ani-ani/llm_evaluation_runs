Implement a Verilog module `min_swaps` that solves the permutation sort problem via BFS for N=4 (scaling N≤11 to N=4 for hardware feasibility). Input: `clk`, `rst_n`, `start`, permutation `perm[0:3]` (4x4-bit), allowed swaps `swap_a[0:5]`, `swap_b[0:5]` (6 swaps max), `num_swaps` (3-bit). Output: `result` (4-bit min swaps), `done` (1-cycle). Behavior: On start, perform BFS to find minimum swaps to sort `perm` using allowed swaps. Use 16-bit state encoding for 4 elements (4! = 24 states). Limit search depth to 8 cycles. Implement as FSM with state memory. Reset clears all.
