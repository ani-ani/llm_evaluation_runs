Implement a Verilog module that embeds a tree with unit edge lengths. The tree has n nodes (2 ≤ n ≤ 16) and n-1 edges. The graph is a tree.

**Interface:**
- Inputs:
  - `clk`, `rst_n`: Clock and active-low synchronous reset.
  - `start`: 1-cycle pulse to start the computation.
  - `n`: 4-bit input for number of nodes (2-16).
  - `edges_a`, `edges_b`: Arrays of 16 4-bit values representing the tree edges (a_i, b_i). Unused entries should be ignored.
- Outputs:
  - `x_coords`, `y_coords`: Arrays of 16 16-bit signed fixed-point Q8.8 values representing coordinates.
  - `done`: 1-cycle pulse indicating valid output is ready.

**Algorithm (Iterative DFS/BFS):**
1. Parse adjacency list from edges arrays.
2. Start at node 0 (root). Set root at (0,0).
3. Traverse tree. For each child, set its angle based on the angle range allocated to the subtree rooted at that child. Angle range for a subtree is proportional to its size.
4. Child coordinates: `x = parent_x + cos(angle)`, `y = parent_y + sin(angle)`. Since radius is 1, use unit circle approximations.
5. Use fixed-point arithmetic (Q8.8) for all calculations.
6. Signal `done` when all coordinates are computed.

**Constraints:**
- Max cycles: 1024.
- Node count limit: 16.
- Coordinates must be in Q8.8 format.
- No memory read/write logic required, just combinational/sequential processing of edge list.

**Output Format:**
Output the prompt only, no code.
