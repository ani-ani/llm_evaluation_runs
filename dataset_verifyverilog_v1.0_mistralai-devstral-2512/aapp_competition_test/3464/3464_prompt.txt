Design a Verilog module to compute the maximum expected profit for a casino rebate scenario with parameters x (refill percentage) and p (winning probability). Constraints: p < 50%, x in [0, 100). Since the problem is continuous, scale probabilities and percentages to fixed-point integers using Q16.16 format (16 integer bits, 16 fractional bits). For example, p=49.9% becomes 0.499 * 65536 = 32670 (approx). The module should compute the expected value by simulating a bounded number of bets (up to 256) and finding the optimal stopping point using dynamic programming. Inputs: p_fixed (16-bit, representing probability scaled by 65536), x_fixed (16-bit, representing refund percentage scaled by 65536). Output: expected_profit (32-bit, representing Q16.16 value). The module should be combinational; for each possible number of bets n (0 to 255), calculate expected profit based on binomial probabilities (bounded to 8 wins). Use a lookup table for binomial coefficients up to n=256, k=8. The main logic iterates over n from 0 to 255, computes expected loss and rebate, and tracks the maximum expected profit. Outputs the result as a fixed-point value. Timing: Async; Reset: none. Clock: not required (combinational).
