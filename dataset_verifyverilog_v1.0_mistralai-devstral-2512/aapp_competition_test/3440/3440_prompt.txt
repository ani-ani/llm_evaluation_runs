Design a Verilog module `flight_review_planner` that solves the minimum cost review route problem.

**Problem Analysis:**
- N airports (1 to N), Stockholm is node 1.
- R flights to review (mandatory edges).
- F additional flights (optional edges).
- Goal: Start at node 1, traverse all mandatory edges (at least once), return to node 1, minimize total cost.

**Adaptations for Hardware:**
1. **Graph Representation:** Use a cost matrix `cost[N][N]` (N=13, fixed size). Initialize with `INF` (e.g., 16'hFFFF).
2. **Mandatory Edges:** Store as a boolean matrix `mandatory[N][N]`. The requirement "traverse all mandatory edges" is equivalent to visiting all nodes incident to mandatory edges (or ensuring connectivity). Since we must traverse edges, we can model the requirement as visiting all "required nodes". However, the strictest interpretation is that every mandatory edge must be covered. 
   - *Simplification:* Since edges must be traversed, we ensure all nodes involved in mandatory edges are visited. If an edge is isolated (e.g., 4-5 in sample), we must visit both 4 and 5. 
   - *Hardware Logic:* We identify the set of nodes that are "required". A node is required if it appears in any mandatory edge. The path must visit all required nodes.
3. **Shortest Paths:** Precompute all-pairs shortest paths (APSP) using Floyd-Warshall (N=13, small).
4. **TSP Solver:** Use Dynamic Programming (DP) with bitmask.
   - `dp[mask][u]`: Minimum cost to visit the set of nodes in `mask`, ending at node `u`.
   - `mask`: 13-bit integer (bit i set if node i+1 visited).
   - `target_mask`: Bitmask of all required nodes.
   - Start state: `dp[1][0] = 0` (Node 1 is index 0).

**Interface Specification:**
- **Clock & Reset:** Standard synchronous design.
- **Configuration:** 
  - `cost_matrix`: 13x13 array of 16-bit integers (169 ports or flattened). 
  - `required_nodes`: 13-bit mask indicating which nodes must be visited.
  - `start`: Pulse to initiate computation.
- **Output:**
  - `result`: 16-bit total minimum cost.
  - `done`: High when computation finishes.

**Implementation Details:**
- **Phase 1 (Floyd-Warshall):** Run for k, i, j loops (max 13 iterations). Update cost matrix.
- **Phase 2 (DP):** Iterate over masks from 1 to (1<<N). For each mask, iterate over current node `u`. If `dp[mask][u]` is valid, try to extend to next node `v` (where `v` is not in `mask`). Update `dp[mask | (1<<v)][v]`.
- **Phase 3 (Result):** After DP fills all states, find the minimum cost to return to node 0 (Stockholm) from any node `u` in the `target_mask`: `min(dp[target_mask][u] + dist[u][0])`.
- **State Machine:** Use `FSM` states: `IDLE`, `FLOYD_INIT`, `FLOYD_LOOP`, `DP_INIT`, `DP_MASK_LOOP`, `DP_NODE_LOOP`, `RESULT`, `DONE`.
- **Constraints:** N=13 implies 8192 masks. 13 nodes. Loop iterations: 13^3 (Floyd) + 8192*13 (DP) ≈ 110k cycles. Max cycles: 200,000. Widths: Cost 16-bit (max path cost < 13*10000 = 130k < 65535? Wait, 130k > 65535. 
  *Correction:* Max cost might exceed 16-bit. 13 nodes * 10000 = 130,000. 16-bit max is 65535. Need 17 bits. Use 24-bit for safety (Q24.0).
  *Refined widths:* Cost width = 24 bits. Address widths: Node index 4 bits (0-12). Mask 13 bits (use 16-bit reg).

**State Machine States:**

- `LOAD`: Accept configuration data.

- `FINISH`: Compute final result (min loopback).
