Design a Verilog module `factorial_digits` that computes the last 3 digits before trailing zeroes of n! for small n (1 <= n <= 16). Since n can be up to 16 in this implementation, the factorial fits in 64 bits. The module should use an iterative approach (FSM) to compute n! and process trailing zeros.

**Interface:**
Inputs:
  - `clk`: System clock (rising edge)
  - `rst_n`: Active-low asynchronous reset
  - `start`: 1-cycle pulse to start computation
  - `n`: 4-bit unsigned integer (representing 1-16, 0 is invalid)
Outputs:
  - `result`: 12-bit unsigned integer representing the last 3 digits (bits 11:0). If fewer than 3 digits exist, the lower bits hold the value (e.g., 12 becomes 12).
  - `done`: 1-cycle pulse indicating completion and valid result

**Functionality:**
1. On `start` rising edge (while `rst_n` is high), load `n` and reset internal state.
2. Compute factorial iteratively:
   - Initialize `fact = 1`.
   - Loop from 1 to `n`: `fact = fact * i`.
   - Use a 64-bit accumulator for `fact` to avoid overflow for n <= 16.
3. Remove trailing zeros:
   - While `fact % 10 == 0`: `fact = fact / 10` (integer division).
   - Stop when `fact % 10 != 0`.
4. Extract last 3 digits:
   - `result = fact % 1000`.
   - Output as 12-bit integer (0 to 999).
5. Signal `done` high for one cycle when computation finishes.

**Timing:**
- Reset: `done = 0`, `result = 0`.
- Computation time: At most ~30 cycles (n=16, multiplication and division per cycle). Use an FSM to control the loop.
- `start` must be held high for 1 cycle.

**Constraints:**
- Use 64-bit internal registers for `fact`.
- Use binary division/multiplication logic.
- The module should be synthesizable.
- Do not use external memory or lookup tables; compute iteratively.
