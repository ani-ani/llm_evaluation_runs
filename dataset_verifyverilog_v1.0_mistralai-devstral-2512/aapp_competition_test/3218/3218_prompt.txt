Design a Verilog module `hexagon_coloring` that counts valid colorings for a hexagonal grid. 

Interface:
- Inputs: `clk`, `rst_n`, `start` (1-cycle pulse)
- Inputs: `grid_valid[69][0]` (7x7 grid flattened, 1-bit validity), `grid_constraint[69][3]` (3-bit constraint value 0-6 for valid cells, ignore if valid=0). Total 69 cells max for n=7.
- Outputs: `result[16:0]` (17-bit count), `done` (1-cycle pulse when valid).

Implementation Strategy:
1. Treat grid as 7x7 array. Invalid cells (marked by `grid_valid` or outside bounds) act as walls.
2. Use a DFS state machine to traverse potential loop paths.
3. Maintain a `visited` mask (69 bits) and `edge_used` mask (120 bits) to ensure no vertex/edge sharing.
4. Constraint Check: For each cell, count connected used edges. Must match `grid_constraint` if valid (non-negative).
5. Iterative approach: Use stack/FSM to explore paths. Depth bounded by total edges (e.g., 100 cycles).
6. Return total count in `result` when `done` is high.
