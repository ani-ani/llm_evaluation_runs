Implement a Verilog module that computes the inverse factorial (given n! find n). Scale constraints: max n=27 (27! ~ 1.09e28 fits in 95 bits, use 64-bit arithmetic with overflow checking). Use 64-bit internal accumulator (unsigned) and 64-bit input. Interface: input 'x' (64-bit), output 'n' (8-bit, since n≤27), 'valid' (1-cycle pulse). Behavior: Starting from i=2, multiply accumulator by i, compare with input x, increment i until accumulator >= x, then output i-1. Reset: accumulator=1, i=2. Use combinational comparison (64-bit). Timing: reset cycles=2, max 30 iterations per request. Note: Input may be up to 10^6 digits (string), but for HDL we will only test n≤27 (fits 64-bit). HDL interface will treat input as 64-bit integer (the testbench will simulate large numbers by truncating). Do NOT implement big integer handling; assume input fits 64-bit. Output n as 8-bit (0-31). Include done signal (asserted when result ready). Use asynchronous reset.
