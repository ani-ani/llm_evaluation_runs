Implement a Verilog module that calculates the minimum number of extra lines needed to ensure W warlords each receive at least one infinite-area sector. The problem reduces to computing the number of unbounded regions in a planar line arrangement.

Simplified Approach:
1. Model lines as integer coefficients (A, B, C) from point pairs (x1,y1), (x2,y2) where line equation is Ax + By + C = 0.
2. For N lines, the maximum number of infinite regions is 2N when all lines are in general position (no parallel, no concurrent intersections).
3. Each warlord needs at least one infinite region. So required infinite regions = W.
4. If current infinite regions < W, compute additional lines needed. Additional lines add up to 2 new infinite regions each if no parallel/concurrent.

Inputs:
  - W: number of warlords (4-bit, 1-100)
  - N: number of lines (7-bit, 0-100)
  - Lines: N sets of (x1, y1, x2, y2), each 12-bit signed (-4096 to 4095)

Outputs:
  - result: number of extra lines (8-bit, 0-100)
  - done: 1 when valid

Implementation Constraints:
  - Use combinatorial logic for line parameter computation
  - Assume all lines are in general position for maximum infinite regions
  - Compute: extra = max(0, W - 2*N) if W > 2*N else 0
  - Handle edge cases: N=0 requires ceil(W/2) lines
  - Use fixed-point approximation for coefficient calculation (scale by 1024)

Timing: start->done within 50 cycles
Reset: result=0, done=0, min 2 cycles
