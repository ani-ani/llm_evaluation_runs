Implement a Verilog module that computes the count of valid infinite sequences modulo 10^9+7.

Problem Analysis:
The sequence must satisfy:
1. From the n-th element onward, all elements are equal.
2. For every position i, the a_i elements immediately following a_i are all equal.

The solution uses dynamic programming with the recurrence:
dp[i] = dp[i+1] + (sum of dp[i+d] for d=3 to n-1) + (n-1)^2 + additional terms

can be computed iteratively from the end of the sequence.

Implementation Constraints:
- Scale: n ≤ 1,024 (2^10) for the Verilog version to fit in hardware resources.
- Modulus: 10^9+7 (0x3B9ACA07). Use 32-bit unsigned arithmetic with overflow handling.
- Memory: Requires storage for dp array and a running sum. For n=1024, this is feasible with block RAM.
- Algorithm: Iterate from i=n-1 down to 0, maintaining a sliding window sum of the last (n-2) dp values.

Module Interface:
- Inputs:
  - clk: System clock, rising edge active.
  - rst_n: Active-low asynchronous reset.
  - start: 1-cycle pulse to initiate calculation for input n.
  - n_in: 10-bit input specifying the sequence length n (1 to 1024).
- Outputs:
  - result: 32-bit result (count modulo 10^9+7).
  - done: 1-cycle pulse indicating result is valid.

Timing Requirements:
- Calculation for n=1024 must complete within 10,000 cycles.
- Throughput: One calculation per start pulse.

Functional Specification:
1. On reset, result=0, done=0.
2. On start pulse, latch n_in and begin computation.
3. Compute dp values iteratively.
   - Base cases: dp[n-1] = n, dp[n-2] = n*n (mod M).
   - Maintain a sliding window sum of dp values over a range of indices.
   - Update dp[i] using the sum and current state variables.
   - All additions and multiplications must be modulo 10^9+7.
4. When computation finishes (after n cycles), assert done and present result on result bus.

Verification:
- The testbench will provide n=2 (expected output 4) and n=3 (expected output 15) as basic functional tests.
- The testbench must simulate the sequential nature of the computation.
