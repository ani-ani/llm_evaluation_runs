Implement a Verilog module to calculate minimum fuel mass for a rocket visiting n planets (2 <= n <= 1000). The rocket starts with payload mass m (1-1000) and returns to Earth. Each flight from planet i to (i+1)%n involves take-off from i and landing on (i+1)%n. The fuel efficiency is given by arrays a[0:999] and b[0:999] (1 <= a_i, b_i <= 1000), where 1 ton of fuel can lift/land 'a_i' or 'b_i' tons respectively. The calculation requires working backwards from Earth's landing to determine initial fuel mass. If any a_i or b_i equals 1, output -1 (impossible). Otherwise, the fuel required is calculated as: initial_fuel = m * product over all i of (a_i / (a_i - 1)) * (b_i / (b_i - 1)) - m. Due to hardware constraints, n is fixed at compile time (maximum 1000). Use Q16.16 fixed-point arithmetic for the multiplicative factors and 32-bit unsigned integers for intermediate mass. The final result must be output in Q16.16 format.

Interface:
  Inputs:
    clk: system clock
    rst_n: active-low synchronous reset
    start: 1-cycle pulse to initiate calculation
    a_i: array of n 10-bit inputs (efficiency coefficient for take-off)
    b_i: array of n 10-bit inputs (efficiency coefficient for landing)
    m: 10-bit input (payload mass)
  Outputs:
    result: 32-bit output (fuel mass in Q16.16 format, or 0xFFFFFFFF for -1)
    done: 1-cycle high when calculation is complete
  Timing: start->done within 100,000 cycles (worst case n=1000).
  Reset: done=0, result=0.
