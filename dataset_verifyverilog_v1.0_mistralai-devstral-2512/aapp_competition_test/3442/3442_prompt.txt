Design a Verilog module that counts Sheldon numbers in a range [X, Y] where 0 <= X <= Y < 2^63.

Sheldon Numbers Definition:
A positive integer is a Sheldon number if its binary representation follows the pattern ABAB...A or ABAB...B where:
- A = N consecutive 1s (N > 0)
- B = M consecutive 0s (M > 0)
- At least one A must appear
- M can be 0 (but if M=0, B is empty, so pattern is just A's)

Constraints:
- Input values are 64-bit (use 64-bit unsigned type)
- Implement as a combinatorial lookup: pre-compute ALL valid Sheldon numbers <= 2^63
- There are exactly 1,134 Sheldon numbers <= 2^63 (verified via simulation)
- Store in a sorted array of 64-bit values
- Use binary search or linear scan for count

Interface:
Inputs:
  clk: clock signal (synchronous logic)
  rst_n: active-low asynchronous reset
  x_i: 64-bit input, lower bound
  y_i: 64-bit input, upper bound
  start: 1-cycle pulse to start computation

Outputs:
  result: 16-bit count (since max count < 1000)
  done: 1-cycle pulse when computation complete
  valid: indicates output is valid

Timing:
- Operation completes within 100 clock cycles
- Both sequential and combinatorial implementations acceptable

Implementation Details:
1. Generate all valid Sheldon numbers <= 2^63 in simulation or as initial block
2. Store in ROM: sheldon_nums[0:1133] as 64-bit values
3. On start, count how many values satisfy X <= value <= Y
4. Use binary search for efficiency, or linear scan (1134 elements)
5. Output 16-bit count

Testbench:
- Must verify with sample inputs: 1-10 (count=10), 70-75 (count=1)
- Must verify 73 is detected (binary 1001001)
- Must handle edge cases: 0 (not Sheldon), 1 (is Sheldon), max values

Key Insight:
Sheldon numbers are rare (< 0.001% of numbers in range). The pattern constraints mean:
- Binary must be alternating runs of 1s and 0s
- Runs can be N or M where N>0, M>0 (M can be 0 for single A)
- At least one run of 1s must exist

Example valid patterns for N=1,M=2, 5 runs:
1 00 1 00 1 = 1001001 = 73

Example valid patterns for N=2,M=1, 4 runs:
11 0 11 0 = 110110 = 54

This is a pure combinatorial problem with bounded search space (1134 patterns).
