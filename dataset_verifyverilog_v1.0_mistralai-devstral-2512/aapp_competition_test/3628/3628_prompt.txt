Design a Verilog module that determines if there exist two permutations π and σ of {1..n} such that (π[i] + σ[i]) mod n equals input a[i] for each position i, and outputs such permutations if they exist. For hardware feasibility, limit n to 16 maximum (input a is 4-bit values). Use a backtracking approach with state machines.

**Module Interface:**
- Inputs: 
  - clk, rst_n: Clock and active-low reset
  - start: 1-cycle pulse to start computation
  - a[0:15]: 16x4-bit array (input sequence values 1..n)
  - n: 4-bit input (n ≤ 16)
- Outputs:
  - pi[0:15]: 16x4-bit array (π permutation if solution exists)
  - sigma[0:15]: 16x4-bit array (σ permutation if solution exists)
  - done: 1-cycle pulse when computation completes
  - valid: 1-bit indicating if solution found (1=yes, 0=no)

**Implementation Requirements:**
1. Use a backtracking algorithm with bounded state space (max 16 positions)
2. Maintain used boolean arrays for π and σ values (1..n)
3. For each position i from 0 to n-1:
   - Try values v for π[i] from 1 to n that are unused
   - Compute required σ[i] = (a[i] - v) mod n
   - Check if computed σ[i] is valid (1..n, unused)
   - Recursively proceed to next position
4. Since exhaustive search is impractical in hardware, implement a bounded exploration with timeout
5. Use finite state machine with states: IDLE, SEARCH, VALID, INVALID
6. Result arrays should be packed for efficient storage
7. Timing: Within 10,000 cycles for n=16

**Signal Widths:**
- Values: 4 bits (since n ≤ 16, values 1-16 fit in 4 bits)
- Indices: 4 bits (0-15)
- n: 4 bits
- Valid flag: 1 bit

**Edge Cases:**
- When n=1: π[0]=σ[0]=1, a[0] should be (1+1) mod 1 = 0 (or 1)
- Modulo arithmetic: (v + w) mod n should produce values in 0..n-1, but inputs are 1..n
- Handle modulo wrap correctly: (a[i] - v) mod n may produce 0, need to adjust to n

**Output Format:**
- When valid=1: pi and sigma arrays contain valid permutations
- When valid=0: pi and sigma arrays can be all zeros
- done pulses exactly once per computation

**Testbench Expectations:**
- Test with n=5, a=[3,2,3,1,1] should find solution
- Test with n=4, a=[3,1,1,4] should return impossible
- Verify permutation constraints: each value 1..n appears exactly once in pi and sigma
- Verify sum constraint: (pi[i] + sigma[i]) mod n == a[i] for all i
