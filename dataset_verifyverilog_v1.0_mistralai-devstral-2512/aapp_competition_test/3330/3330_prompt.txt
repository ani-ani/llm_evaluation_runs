Implement a Verilog module that minimizes the product of average prices of potato stores. 

**Input Interface:**
- `clk`, `rst_n`: Standard clock and active-low reset
- `start`: 1-cycle pulse to start computation
- `a[0:15]`: 16x8-bit array, potato bags per farmer (scaled to max 16 farmers)
- `c[0:15]`: 16x16-bit array, price per bag (scaled to 16-bit)
- `N`: 4-bit input (actual number of farmers, 2-16)
- `L`: 4-bit input (required bags in at least one store, 1-15)

**Output Interface:**
- `result`: 32-bit fixed-point (Q16.16) minimal product of averages
- `done`: 1-cycle pulse when computation complete (within 10,000 cycles)

**Algorithm:**
1. Compute total bags and total price across all farmers
2. Use Dynamic Programming to track achievable (bag_count, price_sum) pairs for both stores
3. Since sum(a_i) ≤ 500, map to 9-bit index (0-511)
4. DP state: dp[store][bags] = min/max achievable price (scaled to 16-bit)
5. Two passes: one where store1 has exactly L bags, one where store2 has exactly L bags
6. For each valid partition, compute: P1 = price1 / bags1, P2 = price2 / bags2
7. Calculate product = P1 * P2 using fixed-point arithmetic
8. Track minimum product across all valid partitions

**Implementation Details:**
- Use Q16.16 fixed-point for prices and products
- Division: scale numerator by 65536 (2^16) then integer divide
- DP array size: 512 entries per store
- Pipeline the computation: input loading → DP filling → result calculation
- Use state machine: IDLE → LOAD → DP_PASS1 → DP_PASS2 → CALC → DONE
- Clamp all arithmetic to prevent overflow (use 32-bit intermediates)
- Reset: done=0, result=0, all internal counters clear

**Timing:**
- start → done: ≤10,000 cycles (N=16, sum(a)≤500)
- When done=1, result holds valid fixed-point output
- Sample result only when done=1
