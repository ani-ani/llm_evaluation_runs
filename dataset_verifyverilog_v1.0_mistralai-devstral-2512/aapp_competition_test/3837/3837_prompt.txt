Implement Verilog module for bug scheduling with binary search on days. Given m bugs (complexities) and n students (abilities, costs), find minimum days D such that total cost <= s.

Interface:
- Inputs: clk, rst_n, start, m[7:0], n[7:0], s[15:0], bugs[0:15][15:0], abilities[0:15][15:0], costs[0:15][15:0]
- Outputs: result[3:0] (student assignment for bug 0), done
- Constraints: m <= 16, n <= 16, 256 cycles max, 16-bit values
- Algorithm: Binary search days 1-16. For each D: sort bugs descending, group by D bugs/day, assign cheapest valid student per group.
- Reset: all zero, 2 cycles min.
- Timing: start->done within 256 cycles.
