Implement a Verilog module to solve the critic ordering problem. Constraints: n ≤ 16 (scaled from 2×10^5), m ≤ 255, k ≤ n×m. Use Q8.8 fixed-point for averages. Design an iterative FSM to try permutations (using lexicographic generation or randomized search with bounded attempts) to find an ordering where the final sum of scores equals k. Inputs: n (5-bit), m (8-bit), k (16-bit), a[0:15] (8-bit each). Outputs: p[0:15] (5-bit indices, 0-indexed), valid (1-bit), done (1-bit). Behavior: First critic always scores m. Subsequent critics score m if average_so_far ≤ a[i], else 0. The average is calculated as sum/(critics_seen). The total sum after n critics must equal k. Implement a sequential FSM with a fixed iteration limit (e.g., 1024 permutations or a deterministic construction if logic exists). If no valid order found within limit, set valid=0.
