Design a Verilog module that computes the minimum operations to make all array elements equal to 1 by repeatedly replacing adjacent elements with their GCD. Scale problem to handle array size up to 16 elements with 32-bit values. 

### Interface Specification:
Inputs:
  clk: rising edge clock
  rst_n: active-low synchronous reset
  start: 1-cycle pulse to start computation
  arr[0:15]: 16-element array of 32-bit unsigned integers
  len: 4-bit unsigned integer (0-15) indicating actual array length

Outputs:
  result: 16-bit signed integer (uses two's complement for -1)
  done: 1-cycle pulse indicating result is valid

### Behavior Specification:
1. Reset: When rst_n=0 (sync), all outputs zero, done=0
2. Operation:
   - If start=1, begin computation on rising clock edge
   - Algorithm:
     a. Count number of elements equal to 1 (count_ones)
     b. If count_ones > 0: result = len - count_ones
     c. Else, compute overall GCD of all elements
        - If overall GCD != 1: result = -1
     d. Else, find shortest contiguous subarray with GCD=1
        - Scan all possible subarrays starting at index i, ending at j
        - Compute GCD incrementally for each subarray
        - Track minimum length (j-i) where GCD becomes 1
        - result = (min_length - 1) + (len - 1)

3. Timing: Computation must complete within 256 clock cycles
4. All arithmetic uses unsigned operations except final result

### Implementation Constraints:
- Use iterative GCD computation (Euclidean algorithm)
- Use fixed-size registers for intermediate results
- Handle len=0 case (result = 0)
- For single element arrays: if element=1 result=0, else -1
- Use 32-bit for GCD computation, 16-bit for result
- Clamp all intermediate calculations to prevent overflow

### Test Cases:
- Arrays with existing 1s should return len - count(1s)
- Arrays where overall GCD != 1 should return -1
- Minimum operations calculation as per algorithm above
- Handle edge cases: len=0, len=1, all 1s, no 1s possible

Provide only the module specification, not the implementation code.
