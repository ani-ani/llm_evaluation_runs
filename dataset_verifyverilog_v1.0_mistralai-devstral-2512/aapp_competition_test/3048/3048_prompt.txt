Implement a Verilog module that counts optimal paths of length exactly 2 in a tree with N nodes (1 ≤ N ≤ 16). A path is optimal if there is no shorter path between start and end. For a tree, an optimal path of length 2 exists iff the middle node has degree d ≥ 2, contributing d*(d-1) paths (ordered: start and end are distinct neighbors). The module takes an adjacency matrix for up to 16 nodes, computes degrees, sums deg[i]*(deg[i]-1) for all nodes. Input: clk, rst_n, start (1-cycle pulse), adjacency matrix as a 16x16 bit array (16*16 = 256 bits total). Output: result (16-bit, max paths ~16*15*16/2 ≈ 1920 < 2^16), done (1-cycle pulse when valid). Timing: start asserted high for 1 cycle; after processing, done pulses for 1 cycle with valid result. Reset: async or sync, initializes internal state. Processing: compute degrees (4-bit each, max 15) in 16 cycles, compute sum in additional cycles (≤ 256 cycles total).
