You are tasked with implementing a Verilog module that identifies two overlapping square buildings in a grid. The grid is provided as an 8x8 binary matrix where 1='x' (building) and 0='.' (empty). You must find two squares (defined by top-left corner and size) such that their union covers all 'x's in the grid. The squares may overlap. Output the first square's parameters (row, col, size) and the second square's parameters. Assume the input fits in 8x8 grid. The algorithm should scan the grid to find the first maximal square, then identify the remaining 'x's and find a second square covering them.

Module Interface:
- Inputs:
  - clk: system clock
  - rst_n: active-low synchronous reset
  - start: 1-cycle pulse to start processing
  - grid_in: 64-bit input, representing the 8x8 grid (row-major order, bit 0 is grid[0][0], bit 1 is grid[0][1], etc.)
- Outputs:
  - r1, c1, s1: 3-bit unsigned (0-7) for first building's row, column, size
  - r2, c2, s2: 3-bit unsigned for second building's row, column, size
  - done: 1-cycle pulse when processing is complete

Timing:
- Processing must complete within 1000 clock cycles after start.
- Reset should clear all outputs to 0 and set done=0.
- On start, process the grid and output valid parameters.

Implementation Requirements:
1. Store the grid as a 64-bit register array.
2. Use a finite state machine (FSM) with states: IDLE, SCAN_SQ1, FIND_REMAINING, SCAN_SQ2, OUTPUT.
3. Scanning logic: Iterate over all possible top-left positions (0-7) and sizes (1-8). For each candidate square, check if all cells within the square are 'x' in the input grid.
4. First square: Find the largest possible square. If multiple, pick the first one found (smallest row, then smallest col).
5. Second square: Mark cells covered by first square. Then scan for the largest square covering the remaining 'x's.
6. Output format: r1, c1, s1 are the row, column (0-indexed), and size of the first square. r2, c2, s2 are for the second square.
7. Constraints: Grid is 8x8, sizes 1-8. Use 3-bit signals for coordinates and size.

Note: The input grid is provided as a single 64-bit vector. You need to extract bits to check specific cells (e.g., grid_bit = grid_in[row*8 + col]).

Edge Cases:
- Overlapping squares: The second square must cover all 'x's not covered by the first square. It may also cover some 'x's already covered.
- Single 'x' cells: size 1 squares.

Do not implement the full module; just provide the Verilog specification prompt.
