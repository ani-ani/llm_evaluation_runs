Implement a Verilog module that computes the water height in a 2D convex polygon cross-section scaled to depth D and water volume L liters. Input constraints: N ≤ 8 (simplified from 100), coordinates ≤ 128cm (scaled), D ≤ 100cm, L ≤ 200 liters. Use 32-bit fixed-point arithmetic (Q16.16). The polygon is defined by up to 8 vertices (x,y) in CCW order, with exactly two base vertices at y=0 and two top vertices at max y. Water is poured between the two top vertices. The module should compute the water height H such that the cross-sectional area times depth D equals volume L liters (1000 L/m³). Use trapezoidal rule integration over y-axis slices to compute area for a given height H. Use binary search on H (100 iterations max, range 0 to max_y) to find H where area * D = L. Input interface: 8x (x_i, y_i) arrays (each 16-bit signed), D (16-bit unsigned), L (16-bit unsigned). Output: water_height (32-bit fixed-point Q16.16), valid (1-cycle pulse). Clock domain with start/done handshake. Reset sets all outputs to 0. Implement binary search FSM: idle, compute_intersection, integrate_area, check_volume, update_search, done. For integration, at each y-slice (fixed 100 steps), find intersection points of horizontal line at y with polygon edges, compute width at that y (x_right - x_left). Accumulate area using trapezoidal rule. Scale: 1 pixel = 1cm. Volume = area (cm²) * depth (cm) / 1000 to get liters (approximate). Target precision: 0.01cm height (1/100). Handle overflow by clamping to 32-bit.
