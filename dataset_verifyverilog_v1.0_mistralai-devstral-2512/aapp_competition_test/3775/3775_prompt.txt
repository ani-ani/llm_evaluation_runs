You are to design a Verilog module that solves the competitive programming problem described below. The problem involves determining a shared number based on pairs of numbers communicated between two participants.

### Problem Specification

**Inputs:**
- `clk`: System clock (rising edge triggered)
- `rst_n`: Active-low synchronous reset
- `start`: 1-cycle pulse to start computation
- `p1_in[47:0]`: 48-bit input for first participant's pairs (12 pairs * 4 bits per number, 2 numbers per pair)
- `p2_in[47:0]`: 48-bit input for second participant's pairs (12 pairs * 4 bits per number, 2 numbers per pair)
- `n`: 4-bit input (1-12, number of pairs for first participant)
- `m`: 4-bit input (1-12, number of pairs for second participant)

**Outputs:**
- `result`: 4-bit output (the answer: -1 (4'b1111), 0 (4'b0000), or 1-9)
- `done`: 1-bit output (goes high for 1 cycle when result is valid)

**Algorithm:**
1. **Parse Inputs**: Extract pairs from `p1_in` and `p2_in`. Each pair consists of two numbers (1-9). Store as 4-bit values.
2. **Generate Possible Pairs**: For each pair from participant 1 (i from 0 to n-1) and each pair from participant 2 (j from 0 to m-1), check if they share exactly one number (intersection size = 1).
   - If they share exactly one number, record that number as a candidate.
3. **Determine Answer:**
   - **Case 1 (Output X)**: If the set of all possible shared numbers from valid pair combinations has exactly 1 unique value, output that value (1-9).
   - **Case 2 (Output 0)**: If the set of possible shared numbers has more than 1 value, BUT for every pair from participant 1, the intersection with any valid pair from participant 2 is always the same number (similarly for participant 2), then output 0.
   - **Case 3 (Output -1)**: Otherwise, output -1.

**Constraints:**
- All numbers are 1-9 (4 bits, 0-15).
- n, m ≤ 12.
- Execution time: Within 256 clock cycles.
- Reset sets `result` to 0 and `done` to 0.

**Interface Details:**
- `p1_in` is a packed array of 12 4-bit numbers (first 48 bits). Bit [47:44] is pair 0, number 0. Bit [43:40] is pair 0, number 1. Bit [39:36] is pair 1, number 0, etc.
- `p2_in` is similar.
- The module must be fully synchronous to `clk` and `rst_n`.

### Implementation Hints
- Use a Finite State Machine (FSM) with states: IDLE, PARSE, COMPARE, CALCULATE, DONE.
- Use ROMs/LUTs to store parsed pairs.
- Use fixed-width arithmetic (4-bit for numbers).
- Iterative logic is preferred; unroll loops for the small bounds.

Provide the complete Verilog module code.
