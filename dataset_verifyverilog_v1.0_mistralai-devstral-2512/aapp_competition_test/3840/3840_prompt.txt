Implement a Verilog module that computes the minimum number of moves to empty chests according to the game rules.

## Module Interface
Inputs:
  clk: single-bit clock (rising edge triggered)
  rst_n: single-bit active-low synchronous reset
  start: single-bit start pulse (1 cycle high)
  a_1_to_a_n: array of n 10-bit values (a_1 through a_n)
  n: 7-bit unsigned (1 to 100, must be odd for valid solution)

Outputs:
  result: 16-bit unsigned result (minimum moves, or -1 as 0xFFFF if impossible)
  done: single-bit pulse (1 cycle high when result is valid)

## Implementation Details
- Scale coin counts (1-1000) to 10-bit (0-1023).
- n must be odd and >1 for valid solution; if n is even or n==1, set result=0xFFFF and done=1 immediately (within 2 cycles).
- Use bottom-up tree traversal: iterate i from n down to 2 (i must be odd, skip even).
- For each odd i, compute parent index p = i/2 (integer division, truncates).
- Track moves count (max 25500) using 16-bit register.
- Algorithm:
  1. If invalid (n==1 or n even), output -1 (0xFFFF) and done.
  2. Initialize moves=0, copy input a[] to internal buffer (100x10-bit).
  3. For i = n down to 3, step -2:
     - child_max = max(buffer[i], buffer[i-1])  // both 10-bit
     - moves += child_max
     - parent_new = buffer[p] - child_max
     - if parent_new < 0, parent_new = 0
     - buffer[p] = parent_new
     - buffer[i] = 0, buffer[i-1] = 0
  4. After loop, moves += buffer[1] (remaining coins in root).
  5. Set result = moves, done=1.
- Timing: start->done within 100 cycles.
- Reset: done=0, result=0xFFFF, internal buffers cleared.

## Testbench Requirements
- Verify n=1,3,5,...100 (odd), and even n cases.
- Use 10-bit input width, clamp values.
- Check result against expected (compute in Python).
