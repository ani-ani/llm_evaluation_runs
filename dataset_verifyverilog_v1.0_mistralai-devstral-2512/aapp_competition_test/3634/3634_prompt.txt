Implement a Verilog module to count the number of ways to place 3 sensors on a 1D grid with snow levels satisfying strict ascending order (left < middle < right). 

**Constraints & Simplifications:**
1. **Coordinate Range**: The coordinate range is limited to 0 to 255 (8-bit). Input values > 255 are clamped or ignored.
2. **Input Format**: Instead of streaming intervals, the input is provided as a pre-calculated array of snow depths `snow_levels[0:255]`. Each `snow_levels[i]` represents the snow depth at coordinate `i`.
3. **Logic**: The module must calculate the total number of triplets `(i, j, k)` such that `0 <= i < j < k <= 255` and `snow_levels[i] < snow_levels[j] < snow_levels[k]`.
4. **Output**: The count modulo 1,000,000,009.

**Interface Specification:**
- **Inputs**:
  - `clk`, `rst_n`: Standard synchronous control.
  - `start`: 1-cycle pulse to initiate calculation.
  - `snow_levels`: A 256-element array of 8-bit unsigned integers (0-255). In Verilog, this can be a 256x8 bit memory or 256 separate 8-bit inputs. Use a memory `reg [7:0] snow_mem[0:255]` for simplicity.
- **Outputs**:
  - `result`: 32-bit integer (since max count is ~2.7M, 32 bits is sufficient).
  - `done`: 1-cycle pulse indicating calculation is complete.

**Implementation Details:**
1. **State Machine**: Design a simple FSM with states: `IDLE`, `LOAD`, `CALC`, `DONE`.
2. **Load Phase**: Accept 256 values sequentially or in parallel (simulated via memory write in testbench).
3. **Calculation Phase**: 
   - Iterate through the array with nested loops (logic unrolled or state-based).
   - For each `j` (middle sensor), count:
     - `left_count`: number of `i < j` where `snow_levels[i] < snow_levels[j]`.
     - `right_count`: number of `k > j` where `snow_levels[k] > snow_levels[j]`.
     - Contribution for this `j`: `left_count * right_count`.
   - Sum contributions modulo 1,000,000,009.
4. **Timing**: The calculation must complete within a fixed number of cycles (e.g., 10,000 cycles) to meet the timeout constraint.

**Testbench Requirements:**
- The testbench will generate the `snow_levels` array based on interval inputs.
- It will load this array into the DUT.
- It will assert `start` and wait for `done`.
- It verifies the result matches the expected triplet count modulo 1000000009.
