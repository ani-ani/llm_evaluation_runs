Implement a Verilog module that solves a simplified 2-coloring graph problem. Given an 8-node undirected graph where each edge has a constraint: 0 (no lounge), 1 (exactly one lounge), or 2 (both lounges). Determine if the constraints are satisfiable (output 'impossible' flag) and if so, compute the minimum number of lounges required (0-8). The graph is defined by a fixed number of edges (up to 16) provided as inputs.

**Interface Specification:**
- **Inputs:**
  - `clk`: System clock (rising edge active)
  - `rst_n`: Active-low synchronous reset
  - `start`: 1-cycle pulse to initiate processing
  - `edge_count`: 4-bit input indicating number of edges (1-16)
  - For each edge `i` (0 to 15), provide:
    - `u_i`: 3-bit (0-7) node index
    - `v_i`: 3-bit (0-7) node index  
    - `c_i`: 2-bit constraint (0, 1, or 2)
- **Outputs:**
  - `done`: 1-cycle pulse when computation completes
  - `impossible`: 1-bit flag, high if constraints cannot be satisfied
  - `min_lounges`: 4-bit result (0-8), valid when `done` = 1 and `impossible` = 0

**Algorithm Requirements:**
1. Use BFS/iterative traversal starting from node 0.
2. Assign lounge (1) or no lounge (0) to each node based on constraints.
3. Handle constraint types:
   - `c=0`: Both nodes must be 0
   - `c=2`: Both nodes must be 1  
   - `c=1`: Nodes must have opposite values (XOR = 1)
4. If constraints conflict, assert `impossible`.
5. Compute minimum lounges across all valid assignments (graph may have multiple components).
6. Process within 256 cycles.

**Implementation Notes:**
- Use a 8-bit reg array `assigned[0:7]` for node values.
- Use a 8-bit reg array `visited[0:7]` for traversal state.
- Store edges in registers or iterate through input ports.
- The algorithm must be iterative (no recursion).
- Reset state: `done=0`, `impossible=0`, `min_lounges=0`.
- Start pulse initiates computation. Sample edge inputs at start.
