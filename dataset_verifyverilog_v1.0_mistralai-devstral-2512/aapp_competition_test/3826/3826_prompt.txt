Verilog module specification for finding minimum subsegment removal to make remaining elements distinct:

Inputs:
  clk: rising edge | rst_n: active-low sync reset
  start: 1-cycle pulse to initiate calculation
  arr[0:7]: 8x8-bit input array (elements 1-255, clamped to 8 bits)
  len: 4-bit value (1-8 elements)

Outputs:
  result: 8-bit output (minimum subsegment length 0-8)
  done: 1-cycle high when calculation complete

Functionality:
  1. On start=1, process array of length 'len'
  2. Use two-pointer sliding window approach
  3. Maintain frequency table for values 0-255 (8-bit values)
  4. Find minimum window [l,r] such that removing it makes remaining elements distinct
  5. Output minimum window length

Implementation Notes:
  - Clock speed: 10 MHz (100ns period)
  - Maximum operations: 256 cycles
  - Use finite state machine with states: IDLE, CHECK_DISTINCT, EXPAND_RIGHT, SHRINK_LEFT, UPDATE_MIN
  - Frequency table: 256 x 4-bit counters (support counts 0-8)
  - All arithmetic in 8-bit unsigned
  - If array already distinct, result=0
  - Reset behavior: result=0, done=0, freq table cleared

Timing:
  - start pulse triggers computation
  - done goes high when minimum found
  - result valid when done=1
  - Typical latency: <200 cycles for n≤8

Constraints:
  - n ≤ 8 (hardcoded in design)
  - Element values ≤ 255 (8-bit)
  - Output result ≤ 8
