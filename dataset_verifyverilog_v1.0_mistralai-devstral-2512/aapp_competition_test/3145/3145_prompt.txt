Design a Verilog module to count multiples of X in range [A, B] composed of allowed digits (scaled to 16-bit inputs). 

**Interface Spec:**
- Inputs:
  - `clk`: Clock signal (rising edge).
  - `rst_n`: Active-low synchronous reset.
  - `start`: 1-cycle pulse to initiate calculation.
  - `X[15:0]`: 16-bit divisor (scaled from original).
  - `A[15:0]`: 16-bit lower bound (scaled).
  - `B[15:0]`: 16-bit upper bound (scaled).
  - `allowed[9:0]`: 10-bit mask where bit `i` is 1 if digit `i` is allowed.
- Outputs:
  - `result[15:0]`: 16-bit count of multiples found.
  - `done`: High for 1 cycle when calculation is complete.
- **Functionality**:
  1. On `start` pulse, reset internal state.
  2. Iterate through all numbers `n` from `A` to `B` (inclusive).
  3. For each `n`, check if `n % X == 0`.
  4. If divisible, check if all decimal digits of `n` are present in `allowed` mask (using a digit-by-digit extraction loop).
  5. Increment `result` counter for valid numbers.
  6. Set `done` high for 1 cycle when loop finishes.
- **Timing**: 
  - Max iterations: 65535 (B - A). 
  - Internal operations: Modulo and digit extraction must complete within ~100 cycles.
  - `result` resets to 0 on `rst_n`.
- **Constraints**:
  - Use sequential logic (FSM) to iterate `n` from `A` to `B`.
  - Modulo operation: Implement as repeated subtraction or loop (X fits 16 bits).
  - Digit extraction: Extract digits of `n` into a temporary buffer, verify against `allowed` mask.
  - If `n` is 0, handle as single digit 0.
  - Assume `A <= B`.

**Testbench Expectation:**
- Provide a Python-based Cocotb testbench.
- Inputs: `X`, `A`, `B` (scaled 16-bit), `allowed` digits as a string (converted to mask).
- Expected behavior: The module computes the count of numbers in `[A, B]` divisible by `X` and composed solely of allowed digits.
- Include edge cases: A=B (single number check), 0 in allowed digits, small ranges.
- Clamp inputs to 16-bit range (0-65535).
- The testbench will simulate the calculation and compare the module's `result` against the expected Python count.
