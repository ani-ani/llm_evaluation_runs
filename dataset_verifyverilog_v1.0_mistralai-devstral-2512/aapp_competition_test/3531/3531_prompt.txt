Design a Verilog module that finds the minimum spanning tree (MST) cost with a constraint on the number of special-nonspecial edges. Input: n nodes (2-16), m edges (1-32), k special nodes (1-8), w target count of special-nonspecial edges. Nodes are 1-indexed. The module must output the minimum total cost of a spanning tree containing exactly w edges that connect a special node to a non-special node, or -1 if no valid tree exists. 

Interface:
- Inputs: clk, rst_n, start (1-cycle pulse)
- Input data provided sequentially via 'edge_in' port: 32-bit vector containing {cost[15:0], node_a[7:0], node_b[7:0]}. 
- Control signals: edge_count (5-bit, max 32), special_mask (16-bit, bit i=1 if node i+1 is special), target_w (4-bit).
- Outputs: result (16-bit), done (1-bit, active high for 1 cycle when result valid).

Implementation Requirements:
1. Use a Kruskal-like algorithm with a Union-Find (Disjoint Set Union) data structure.
2. Implement a comparator sort network for edges (max 32 edges). Sort by cost ascending.
3. Maintain a counter 'current_w' for special-nonspecial edges added.
4. Iterate through sorted edges, union sets if edge doesn't form a cycle. 
5. If edge is special-nonspecial, increment current_w (max 16).
6. After processing all edges, check if spanning tree formed (n-1 edges added) AND current_w == target_w.
7. If valid, output total cost. Else, output -1.
8. Assume graph connectivity is limited; use 16-bit costs and 16-bit accumulator.
9. Reset state: done=0, result=0, all internal counters/fsm reset.
