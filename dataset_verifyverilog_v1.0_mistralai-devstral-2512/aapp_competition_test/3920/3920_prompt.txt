Design a Verilog module that calculates the number of 1cm triangles in an equiangular hexagon with integer side lengths. The hexagon has 6 sides (a1-a6) each 1-1000cm. The problem guarantees the hexagon exists.

The formula is: triangles = (a1 + a2 + a3)^2 - a1^2 - a3^2 - a5^2

Use this input protocol:
- 6 separate 16-bit inputs for sides a1-a6 (only need 10 bits but use 16 for safety)
- 1-bit start signal (active high)
- clock and active-low reset

Output:
- result[31:0]: 32-bit unsigned integer count of triangles
- done: 1-cycle pulse when calculation complete

Implementation details:
- Use a single-clock cycle combinational path for the formula
- The result fits in 32 bits (max: (3000^2 - 3*1000^2) = 6,000,000)
- 16-bit inputs are sufficient since a_i <= 1000 < 2^10
- The module should register inputs on start pulse and compute in 1 cycle
- done is asserted for 1 cycle after computation

Timing:
- start pulse width: 1 cycle
- done asserted: 1 cycle after start
- Reset: all outputs 0

No external memory needed - pure arithmetic unit.
