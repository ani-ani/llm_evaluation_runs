Implement a Verilog module to detect possible bingo ties. The module analyzes a fixed number of 5x5 bingo cards (scaled to n=2 for feasibility) where each cell contains a 16-bit number (1-3000). A tie occurs if two cards share a number that can complete a horizontal row in both cards. The module iterates through all pairs of cards and checks for shared numbers that are the last needed in a row for both. Inputs: clk (global clock), rst_n (active-low reset), start (1-cycle pulse to start analysis). For each card (identified by index i), the input interface provides 25 numbers (arr_i_0 to arr_i_24) as 16-bit values. The module outputs a valid signal (done) when analysis completes, and the indices a and b (1-based) of the first pair found. If no tie exists, output a=b=0. The implementation must be sequential, processing one card pair per clock cycle, with a maximum of C*(C-1)/2 pairs (C=2, so 1 pair) to check. Timing: start->done within 200 cycles. Reset sets all outputs to 0 and done to 0.
