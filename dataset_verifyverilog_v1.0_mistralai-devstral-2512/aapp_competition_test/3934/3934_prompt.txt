You are to implement a Verilog module that determines if a tree can be transformed to any edge-value configuration using the given operation. The key insight is that the answer is YES if and only if the tree has NO nodes with degree exactly 2.

Your module should:
1. Accept n nodes and n-1 edges as input
2. Compute the degree of each node
3. Check if any node has degree exactly 2
4. Output YES (1) if no node has degree 2, NO (0) otherwise

Verilog Interface Specification:
- Inputs:
  - clk: global clock (rising edge)
  - rst_n: active-low synchronous reset (min 2 cycles)
  - start: 1-cycle pulse to start computation
  - n: 8-bit integer (2 <= n <= 20)
  - edges: for i in 0..18: edge_u[i] (5-bit), edge_v[i] (5-bit) representing node numbers 1..20
  - edge_valid[i]: 1-bit valid flag for each edge (edge_valid[i]=1 means edge i is present)

- Outputs:
  - result: 1-bit (1=YES, 0=NO)
  - done: 1-bit (1-cycle pulse when result is valid)

- Constraints:
  - Maximum n = 20, so use 5-bit node IDs (1..20)
  - Degrees can be up to 20, use 5-bit counters
  - Processing must complete within 200 clock cycles for n <= 20
  - When n <= 1, handle edge case (should be YES by definition)

- Algorithm:
  - Initialize degree counters for all nodes (1..20) to 0
  - For each valid edge (u,v), increment degree[u] and degree[v]
  - After processing all edges, scan degrees
  - If any node has degree == 2, output NO, else YES

- Implementation Notes:
  - Use iterative processing of edges during compute state
  - Use a counter to track which edge is being processed
  - Use a sequential scan of degrees after all edges are processed
  - Set done=1 for one cycle when result is ready
  - On reset, result=0, done=0, all internal counters reset
