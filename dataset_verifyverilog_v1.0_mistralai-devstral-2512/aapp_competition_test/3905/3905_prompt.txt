Implement a Verilog module that solves a scaled-down version of the data center availability problem. Given n data centers (2-16), m clients (1-32), and h hours (2-16), and maintenance hours u_j for each center, and client pairs (c_i1, c_i2), build a directed graph where an edge from center i to j exists if (u_i + 1) % h == u_j. Find the smallest strongly connected component (SCC) that is a sink (has no outgoing edges to other SCCs). Output the size and indices of data centers in that SCC.

Constraints: n ≤ 16, m ≤ 32, h ≤ 16, u_j < h. Use iterative DFS for SCC detection (Kosaraju's algorithm) with fixed-size registers. The module should compute the result in combinational logic with a maximum of 256 cycles.

Interface:
- Inputs: clk, rst_n (active-low sync reset), start (1-cycle pulse)
- Inputs: n[4:0], m[5:0], h[4:0]
- Inputs: u[0:15][4:0] (16 centers, 5 bits each for hour value)
- Inputs: client1[0:31][4:0], client2[0:31][4:0] (32 clients, 5 bits each for center index, 1-indexed)
- Outputs: result_size[4:0], result_indices[0:15] (16 centers, 1-bit each flag), done (1-cycle pulse when valid)

Algorithm steps:
1. Build adjacency matrix/adjacency lists (max 16 nodes, 32 edges)
2. First DFS (Kosaraju step 1): compute finish order using iterative stack
3. Build transpose graph
4. Second DFS (Kosaraju step 2): assign SCC IDs in reverse finish order
5. Compute out-degree of each SCC (edges to different SCCs)
6. Find SCC with out-degree 0 and minimum size
7. Output indices of nodes in that SCC

Timing: start->done within 256 cycles. Reset: all outputs 0, done=0. Use fixed-size arrays and bounded loops.
