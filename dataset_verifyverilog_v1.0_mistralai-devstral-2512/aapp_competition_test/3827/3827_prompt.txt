Design a Verilog module that checks if a string matches the pattern 'a^+b^+c^+' where the count of 'c' equals the count of 'a' or the count of 'b'.

Inputs:
  clk: rising edge clock
  rst_n: active-low synchronous reset
  start: 1-cycle start pulse
  char_in: 8-bit ASCII character input (valid when start=1)
  length: 5-bit input (1-32 characters, padded to 32 max)

Outputs:
  result: 1-bit output (1=valid YES, 0=NO)
  done: 1-cycle pulse when processing completes

Behavior:
1. Upon start, sample the input string character sequence.
2. Verify the string follows strictly non-decreasing order (all 'a's, then all 'b's, then all 'c's).
3. Count the number of 'a', 'b', and 'c' characters.
4. Check that at least one 'a' and one 'b' exists.
5. Check that count of 'c' equals count of 'a' OR count of 'c' equals count of 'b'.
6. Set result=1 if all checks pass, otherwise result=0.
7. Pulse done=1 for one cycle when finished.

Constraints:
- Maximum string length is 32 characters (stored in internal RAM or registers).
- ASCII values for 'a'=97, 'b'=98, 'c'=99.
- Processing must complete within 100 clock cycles.
- Implementation must be purely combinational logic or a simple FSM (no external RAM).
