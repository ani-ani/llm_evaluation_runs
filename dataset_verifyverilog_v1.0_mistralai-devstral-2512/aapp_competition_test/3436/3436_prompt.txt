Design a Verilog module to compute a 2D recurrence F(x,y) defined as:
- Base cases: F(0,0)=0, F(0,1)=F(1,0)=1
- Boundaries: F(i,0) = Fibonacci(i), F(0,i) = Fibonacci(i)
- Inner: F(i,j) = F(i-1,j) + F(i,j-1) for i,j >= 1
- Modulo M = 10^9 + 7 (use 32-bit arithmetic with wrap-around)

SCALED REQUIREMENTS (for hardware feasibility):
- Input x, y: 4-bit values (0..15)
- Total states: 16x16 = 256
- State width: 32 bits (for modulo M)
- Computation order: Row-by-row, left-to-right
- Iterations: 16*16 = 256 cycles max

MODULE INTERFACE:
- Inputs:
  clk: system clock (rising edge)
  rst_n: active-low synchronous reset
  start: 1-cycle start pulse
  x_in: 4-bit (0..15)
  y_in: 4-bit (0..15)
- Outputs:
  result: 32-bit value of F(x_in, y_in) modulo 10^9+7
  done: 1-cycle pulse (high when result valid)

IMPLEMENTATION DETAILS:
1. Use a lookup table (16x16 array) for F(i,j) values
2. Initialize boundaries (row 0 and col 0) with Fibonacci sequence
3. Compute inner cells using DP: F[i][j] = F[i-1][j] + F[i][j-1]
4. All arithmetic modulo 10^9+7 (32-bit overflow is fine due to modulo)
5. Start signal triggers computation, done goes high after completion
6. Computation must finish within 256 cycles after start
7. Reset must clear internal state and set done=0
8. Handle edge cases: (0,0), (0,1), (1,0)

BENCHMARK GOAL: Demonstrate ability to implement recursive/DP algorithms in hardware using iterative FSM and memory arrays.
