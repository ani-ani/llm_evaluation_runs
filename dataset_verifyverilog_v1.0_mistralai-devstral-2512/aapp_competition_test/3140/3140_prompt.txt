You need to design a Verilog module that computes the maximum number of grid points where fish can be caught given constraints on time and movement. Since HDL cannot handle large dynamic arrays or complex graph traversal directly, we must scale down the problem and implement a hardware-friendly solution.

**SCALED REQUIREMENTS:**
- Grid dimensions: r=8, c=8 (8x8 grid, 64 cells max)
- Time limit: l=128 seconds (fits in 8 bits)
- Fish duration: k=5 seconds (constant)
- Start time: 1 second (fixed)
- Movement cost: 1 second per step (cardinal directions)
- Fish amount per point: 1 (constant)

**ALGORITHM:**
1. Represent the 8x8 grid as a 64-element array of timing windows (each: appear_time)
2. Use BFS or iterative DP to compute reachability at each time step
3. For each cell at each time t (0 to l), compute if reachable AND fish available
4. Fish is available if t >= appear_time AND t < appear_time + k
5. Sum all valid (cell, time) pairs where reachable and fish available
6. Output the total count

**VERILOG MODULE SPEC:**

**Interface:**
- Inputs:
  - clk: System clock
  - rst_n: Active-low synchronous reset
  - start: 1-cycle pulse to initiate computation
  - grid_t[63:0]: 64 x 8-bit array, grid_t[i] = appear time at cell i (row-major: row*8+col)

- Outputs:
  - result: 16-bit total count of fish-eligible points
  - done: 1-cycle pulse when computation finishes

**Parameters (Fixed in Verilog):**
- GRID_SIZE = 64 (8x8)
- MAX_TIME = 128
- K = 5
- START_TIME = 1
- START_POS = 0 (top-left, row 0, col 0)

**Functional Requirements:**
1. On start pulse, reset internal state and begin computation
2. Compute reachability using iterative BFS over time (0 to MAX_TIME-1)
3. For each time step t from START_TIME to MAX_TIME-1:
   - Update reachable cells from previous step (north/south/east/west)
   - Check if cell is reachable AND fish available at time t
   - Fish available: t >= grid_t[cell] AND t < grid_t[cell] + K
   - If both true, increment count
4. result is the total count of such (cell, time) pairs
5. done pulse asserted for 1 cycle when computation completes
6. Computation completes within 1000 cycles

**Implementation Notes:**
- Use 2 x 64-bit shift registers to track reachable cells (current and next)
- Time counter: 8-bit (0-255)
- Use combinational logic to compute next reachable cells
- For each time step, use a 64-bit combinatorial adder to check eligibility
- Do NOT output cell locations, just count eligible (cell, time) pairs

**Timing:**
- reset: 2 cycles, sets done=0, result=0
- computation: starts after start, runs for MAX_TIME cycles
- done: asserted for 1 cycle at completion
- Result valid when done=1

**Example:**
If grid has fish at (0,0) appearing at t=1, k=5:
- Reachable at t=1: cell 0
- Fish available: t=1,2,3,4 (since t<1+5)
- This contributes 4 to count if reachable

**Constraint:**
- Max cycles: 2000
- Internal state: 2x 64-bit registers, 8-bit time counter
- Result width: 16 bits (max 64 cells * 128 times = 8192, but 16-bit is safe)

Please implement the module with these exact specifications.
