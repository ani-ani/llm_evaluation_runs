Design a Verilog module that determines if a tree exists satisfying the given constraints. 

Problem Analysis:
- Given n nodes (1 ≤ n ≤ 24) with subtree sizes c[i] (1 ≤ c[i] ≤ n)
- Tree must be rooted and satisfy: each internal node (degree ≥ 2) must have at least 2 children
- Node i's subtree must contain exactly c[i] nodes including itself
- Root must have c[root] = n
- All c[i] values must be distinct

Hardware Adaptation:
- n is scaled to max 16 nodes (fits in 5-bit addressing)
- c[i] values fit in 5-bit values (1-16)
- Use bitmask (16-bit) to represent subtree nodes
- Use iterative depth-first search with backtracking
- State machine tracks: current node, parent, current mask, valid flag

Algorithm (Simplified for HDL):
1. Sort nodes by descending c[i] (largest subtree must be root)
2. Check that c[0] == n (root must cover all nodes)
3. Check no c[i] == 2 (internal nodes need ≥2 children, so subtree size ≥3 for internal)
4. For each node in order, try to attach it to an existing node that has sufficient remaining capacity
5. Track remaining capacity for each node: rem[i] = c[i] - 1 (subtract self)
6. When attaching child with size s, reduce parent's rem by s
7. Validate all nodes have rem = 0 or are leaves (c[i] == 1)

Interface Specification:
- Inputs:
  - clk: system clock (rising edge)
  - rst_n: active-low synchronous reset
  - start: 1-cycle start pulse
  - c_in[0:15]: 16x5-bit array of subtree sizes (padded for n≤16)
  - n_in[4:0]: actual number of nodes (1-16)
- Outputs:
  - result: 1-bit (1=YES, 0=NO)
  - done: 1-cycle pulse when valid
- Timing: Start to done within 5000 cycles
- Reset: result=0, done=0

Implementation Notes:
- Use combinational logic for sorting comparator network (16 nodes, O(n²))
- State machine states: IDLE, SORT, CHECK_ROOT, CHECK_TWOS, SEARCH_PLACEMENT, VALIDATE, FINISH
- Use 16-bit mask for each node to track which nodes are in its subtree
- Capacity tracking uses 5-bit registers (max size 16)
- Backtracking implemented via depth-limited search with maximum depth = n
- When attaching node j to node i: require rem[i] >= c[j] and not (rem[i] == c[j] and child_count[i] == 0)
- Must handle at least 2 children requirement for internal nodes

Constraints:
- Module must handle n=1..16
- All arrays sized for 16 elements (n≤24 scaled down)
- No dynamic memory allocation
- Fixed iteration bounds
- Internal node validation: if node has children, must have ≥2

Test Cases (scaled to n≤16):
1. n=4, c=[1,1,1,4] → YES (root with 3 leaves)
2. n=5, c=[1,1,5,2,1] → NO (invalid combination)
3. n=16, c=[1]*15 + [16] → YES
4. n=2, c=[1,2] → NO (root needs 2 children but only 1 other node)
5. n=8, c=[1,1,1,1,4,1,1,8] → YES (root, internal, leaves)
6. n=3, c=[1,1,3] → NO (root needs 2 children, but leaves must have c=1)
