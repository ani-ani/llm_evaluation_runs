Design a Verilog module that generates a string satisfying constraints: length N (1-16), distinct chars K (1-16), longest palindromic substring length exactly P (1-16). Input: N[3:0], K[3:0], P[3:0]. Output: char_array[0:15][7:0] (16 bytes, lowercase a-z). Also output valid flag (1-bit) and error flag (1-bit). The module must be combinational (no clock). It implements a simplified construction algorithm:
- If P > N or K > N or P < 1 or K < 1: error=1, valid=0.
- If P == 1: Generate string with N distinct chars (if K >= N) or repeat pattern ensuring no palindrome >1 (e.g., 'abcabc...').
- If P == N: Must be palindrome. If K > N/2+1 or (N odd and K > (N+1)/2), error. Else generate 'abc...cba' pattern.
- If 1 < P < N: Generate string with one palindromic block of length P (e.g., 'a...a'), and remaining characters distinct and non-repeating to avoid longer palindromes. Ensure total distinct chars = K.
Constraints: Output array must be packed or unpacked. Valid asserted only if solution exists. Use 8-bit ASCII for 'a'-'z'. No sequential logic, pure combinational decode of constraints.
