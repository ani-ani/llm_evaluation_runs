You are given a sequence of plant species indices (integers 1 to m). The goal is to find the minimum number of plants to remove so the remaining sequence is non-decreasing. This is equivalent to n - (length of Longest Non-Decreasing Subsequence). 

Implement a hardware accelerator that computes the LIS length of a given sequence.

**Interface Specification:**
- Input: `clk`, `rst_n` (active low), `start` (1-cycle pulse).
- Input: `species_in` (4-bit unsigned, representing species 1-16). Valid when `valid_in` is high.
- Input: `valid_in` (1-bit). Indicates a new species value is available.
- Input: `len_in` (8-bit unsigned). Total number of plants in the current sequence (max 256).
- Output: `result` (16-bit unsigned). Length of the longest non-decreasing subsequence.
- Output: `done` (1-bit). High for 1 cycle when computation is complete.

**Operation:**
1. When `start` is high, reset internal state.
2. Accept up to `len_in` values on `species_in` when `valid_in` is high, synchronized with `clk`.
3. Once all values are received (tracked internally), compute the LIS.
4. Output `result` and assert `done`.

**Constraints:**
- `len_in` <= 256.
- Species values <= 16.
- Must be pipelined or iterative; do not use O(n^2) memory if possible, though 256x256 array is acceptable for FPGA logic.
- Output should be available within 1000 cycles after the last input.
