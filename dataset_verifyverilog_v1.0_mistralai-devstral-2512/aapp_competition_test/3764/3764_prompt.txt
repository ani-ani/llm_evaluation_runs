Implement a Verilog module that simulates k iterations of the given operation on n rangers. The operation consists of: 1. Sorting the array of rangers by strength (ascending). 2. Applying bitwise XOR with x to elements at even indices (0-indexed). After k iterations, output the maximum and minimum values of the array.

Constraints:
- n ≤ 8 (reduced from 10^5 to fit hardware)
- k ≤ 16 (reduced from 10^5; typically converges quickly)
- x ≤ 1023 (10-bit)
- Ranger strengths ≤ 1023 (10-bit)

Interface:
Inputs:
  clk: rising edge
  rst_n: active-low synchronous reset
  start: 1-cycle pulse to start the operation
  n_in[3:0]: number of rangers (0-8)
  k_in[3:0]: number of iterations (0-16)
  x_in[9:0]: XOR value
  arr_in[7:0][9:0]: 8-element array of 10-bit strengths

Outputs:
  max_out[9:0]: maximum strength after k iterations
  min_out[9:0]: minimum strength after k iterations
  done: 1-cycle pulse when operation completes

Implementation Details:
- Use a Finite State Machine (FSM) with states: IDLE, SORTING, XORING, CHECKING, FINISHED
- Sorting: Implement a simple bubble-sort network for ≤8 elements (or use a combinational sorting network). Since n is small, a fixed 8-cycle sorting phase is acceptable.
- XOR: Apply to even indices only after sorting.
- Iteration Counter: Track the number of k iterations.
- Memory: Use a register file with 8 entries of 10 bits to store the current state of rangers.
- Timing: The module should complete within (k * (sorting_cycles + extra)) cycles, where sorting_cycles ≤ 8 and k ≤ 16.
- Output: Sample max_out and min_out when done goes high. They should be the max/min of the internal array after the final iteration.

Edge Cases:
- If n_in = 0, output 0 for both max and min.
- If k_in = 0, output max/min of input array immediately.
