Design a Verilog module to determine election outcomes for candidates. The system must handle n candidates (1-8), k seats, m total voters (1-100), and a already voted voters. Each voter votes for a candidate 1-n.

For each candidate, output one of three values:
1 = Guaranteed seat regardless of remaining votes
2 = Possible seat (depends on remaining votes)
3 = No chance for seat

**Algorithm Summary** (to be implemented in Verilog):
1. Read initial votes and last vote time for each candidate from the first 'a' votes
2. For each candidate i (1 to n):
   - Check if guaranteed: Can i stay in top k even if all remaining votes go to candidates that currently beat i?
   - Check if possible: Can i reach top k if all remaining votes go to i?
   - Otherwise: impossible (3)

**Verilog Interface Specification:**

Inputs:
  clk: clock (rising edge)
  rst_n: active-low synchronous reset
  start: 1-cycle pulse to start computation
  n[3:0]: number of candidates (1-8, use 4 bits)
  k[3:0]: number of seats (1-8)
  m[6:0]: total voters (1-100, use 7 bits)
  a[6:0]: already voted voters (1-100)
  vote_index[6:0]: index for current vote input (0 to a-1)
  vote_cand[3:0]: candidate voted for (1-n)
  vote_en: enable signal for loading votes

Outputs:
  result[2:0]: result for current candidate (1,2,3)
  candidate_idx[3:0]: current candidate index being evaluated (0 to n-1)
  done: 1-cycle pulse when all candidates evaluated

**Implementation Details:**
- Use 4-bit registers for votes per candidate (max 100 votes)
- Use 7-bit registers for last vote time (max 100)
- Implement as sequential FSM with state machine
- Process one candidate per clock cycle after loading votes
- Use 3-bit output per candidate (1-3)
- Clock frequency: 100MHz (10ns period)
- Reset sets all results to 0, clears counters

**Memory Constraints:**
- Votes array: 8 candidates × 4 bits = 32 bits total
- Last vote array: 8 candidates × 7 bits = 56 bits total
- Result array: 8 candidates × 3 bits = 24 bits total
- Total state: <128 registers

**Test Cases:**
- Verify with example inputs from problem statement
- Edge cases: single candidate, no votes cast, all votes to one candidate
- Timeout: 1000 cycles maximum
