Implement a Verilog module that solves the graph partition problem for up to 16 nodes. The module should:

**Interface:**
- Inputs: `clk`, `rst_n` (active-low synchronous), `start` (1-cycle pulse)
- Configuration: `n` (4-bit, number of nodes, max 16), `edges` (256-bit, bit-packed adjacency matrix)
- Outputs: `valid` (1-bit, 1 if partition exists), `arya_mask` (16-bit, bitmask for Arya's cities), `sansa_mask` (16-bit, bitmask for Sansa's cities), `other_mask` (16-bit, bitmask for remaining cities), `done` (1-cycle pulse when computation complete)

**Algorithm:**
1. On `start`, initialize state machines for Arya and Sansa
2. Arya's clique must contain node 1 (Winterfell, bit 0). Expand by adding all neighbors of node 1 that are connected to all nodes currently in Arya's clique
3. Sansa's clique must contain node 2 (King's Landing, bit 1) and cannot include any nodes from Arya's clique. Expand similarly
4. All remaining nodes (not in Arya's or Sansa's clique) must form a clique (each pair connected)
5. If any constraint fails or adjacency matrix indicates direct edge between node 1 and 2, output valid=0
6. The design must be combinational within a FSM that runs for ≤256 cycles

**Constraints:**
- Node numbering: bit 0 = city 1 (Winterfell), bit 1 = city 2 (King's Landing)
- No direct edge between node 1 and 2 (given by problem, but verify in input)
- Each assigned collection must be a clique (complete subgraph)
- The remaining cities (if any) must also form a clique
- All masks must be disjoint

**Timing:**
- After `start`, `done` should be high after ≤256 clock cycles
- `valid`, `arya_mask`, `sansa_mask`, `other_mask` are valid only when `done` is high
- On reset (`rst_n=0`), all outputs (including `done`) are 0

**Implementation notes:**
- Use a finite state machine (FSM) with states: IDLE, COMPUTE_A, COMPUTE_B, COMPUTE_REMAINING, VERIFY, DONE
- You may use combinational logic to compute clique membership
- The `edges` input is a 256-bit vector where bit (i*16 + j) = 1 if there is an edge between node i and node j (for i,j < 16)
- Assume symmetric adjacency (edge i-j implies j-i)
- For nodes > n (if any in edges input), they should be treated as disconnected/unused

**Test Cases:**
- Example 1: n=9, edges as given → should produce valid=1 with appropriate masks
- Example 2: n=9, missing edge → should produce valid=0
- Small valid case: n=4, edges 1-3, 2-4 → valid=1, masks: {1,3}, {2,4}, {}
- Invalid case: n=5, overlapping cliques → valid=0

Provide only the module specification in the prompt, not the implementation code.
