Input constraints: M ≤ 1000000. a, b, P can be up to M-1. Compute a, b by parsing a fixed-width expression representing a linear polynomial.

Interface:
- Inputs: clk, rst_n (active-low), start (1-cycle pulse), P[19:0], M[19:0]
- Expression inputs: Provide expression as a sequence of tokens via separate ports. Since parsing is complex, simplify input to pre-computed coefficients: a[19:0], b[19:0] (representing ax+b).
- Outputs: x_out[19:0], done (1-cycle pulse)

Algorithm (Hardware-friendly):
1. Compute (P - b) % M to get target value.
2. Solve ax ≡ target (mod M) for x.

   - Compute x = (target * inv_a) % M.
   - If x < 0, add M (but result is non-negative).

Implementation details:
- Use iterative state machine for Extended Euclidean Algorithm.
- Bit width: 20 bits (covers M and intermediate values).
- Cycles: < 100 cycles.
- Reset: clear state.
