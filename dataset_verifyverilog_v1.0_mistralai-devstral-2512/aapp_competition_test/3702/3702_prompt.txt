Implement a Verilog module that computes values b and e for a given Fibonacci substring search problem using precomputed modular arithmetic constants. The solution uses the fact that Fibonacci numbers modulo 10^9 have period 12*10^9 and the recurrence F(k + 12*10^9) ≡ 673419592000000001 * F(k) (mod 10^9) for the last 9 digits.

**Interface Specification:**

Inputs:
  - n: 20-bit unsigned (1 to 1,000,000)
  - a: 20-bit unsigned (1 to 1,000,000)  
  - d: 20-bit unsigned (1 to 1,000,000)

Outputs:
  - b: 64-bit unsigned (0 < b < 2^64)
  - e: 64-bit unsigned (0 < e < 2^64)
  - valid: 1-bit, goes high when outputs are ready

**Implementation Details:**
1. Use precomputed constants:
   - N = 12 * 10^9 = 12,000,000,000 (34-bit)
   - MULTIPLIER = 368131125 (29-bit)
   - MOD = 10^9 = 1,000,000,000 (30-bit)

2. Compute intermediate values:
   - u = (MULTIPLIER * a) % MOD
   - v = (MULTIPLIER * d) % MOD

3. Compute final results:
   - b = u * N + 1
   - e = v * N

4. Use iterative multipliers for large number multiplication (since a and d are only up to 10^6, we can use simpler fixed-point arithmetic or lookup tables)

5. The algorithm should complete within 1000 cycles.

**Timing:**
- Start pulse initializes computation
- Valid output within 1000 clock cycles
- Reset (active-low) clears all registers and outputs

**Note:** This is a mathematical problem that reduces to modular arithmetic. The core computation involves multiplying small numbers (up to 10^6) by large constants (368131125, 12000000000) and computing modulo operations. Since the inputs are small, we can compute this efficiently using iterative multiplication or even precomputed lookup tables for common values.
