The probability is (Total cells - Searched cells) / Total cells. You must calculate the number of unique cells reachable within distance K from any starting cell on an 8x8 grid. Since the grid is small, you can use a combinatorial approach or lookup table. The output is p * q^-1 mod 1000000007.
