Design a Verilog module that solves the "best solution sequence" problem using an iterative greedy approach with lookahead. The module should handle up to 8 input sequences (scaled from N=1000) where each sequence has up to 16 elements (scaled from L=1000) with 8-bit values (scaled from 100000000). 

**Algorithm:**
1. Maintain pointers to the current head of each sequence (indices).
2. At each step, evaluate each available sequence head:
   - Compare current values directly
   - For ties (equal values), look ahead to the next element in each sequence
   - Recursively compare subsequent elements until a difference is found or one sequence is exhausted
3. Select the sequence that yields the lexicographically smallest continuation
4. Output the chosen value, advance the pointer, and repeat
5. Use an FSM to orchestrate the comparison logic

**Interface Specification:**
- Inputs:
  - `clk`: System clock (rising edge)
  - `rst_n`: Active-low synchronous reset
  - `start`: 1-cycle pulse to begin processing
  - `seq_data[0:7][0:15]`: 8 sequences × 16 elements × 8-bit values (packed as flattened array or individual signals)
  - `seq_lens[0:7]`: 4-bit lengths for each sequence (max 16)
  - `total_len`: 8-bit total length (max 128)
- Outputs:
  - `out_val`: 8-bit output value for solution sequence
  - `out_valid`: High when `out_val` is valid (continues for `total_len` cycles)
  - `done`: 1-cycle pulse when all output is complete

**Timing:**
- After `start`, the module outputs `out_val` and asserts `out_valid` for `total_len` cycles
- `done` is asserted exactly one cycle after the last `out_valid` cycle
- Reset clears all counters, pointers, and outputs

**Implementation Notes:**
- Use a state machine with states: IDLE, INIT, COMPARE, OUTPUT, DONE
- For comparison (tie-breaking), implement a lookahead FSM or iterative comparator that checks 2-4 elements ahead max
- Since values are 8-bit, use combinational comparators that can be pipelined
- The comparison logic should be efficient: first compare current elements, then if equal, compare next elements, etc.
- Total cycles: within 200 cycles for max 128 outputs
- DO NOT generate the solution sequence in advance; generate on-the-fly
- Use at most 8 concurrent comparators for performance

**Detailed Signal Definitions:**
- `seq_data`: Flattened array or hierarchical. If flattened: `seq_data[i*16 + j]` for sequence i, element j
- `seq_lens`: Array of 8 4-bit values
- `out_val`: Valid only when `out_valid` is high
- `done`: Single cycle pulse after last output

**Reset Behavior:**
- During reset: `done = 0`, `out_valid = 0`, `out_val = 0`, all internal state cleared
- After reset, at least 2 cycles needed before start can be asserted

**Constraints:**
- Use at most 256 state transitions for worst case
- Clock frequency: 100 MHz (10ns period)
- No combinational loops
- All timing paths must meet setup/hold
