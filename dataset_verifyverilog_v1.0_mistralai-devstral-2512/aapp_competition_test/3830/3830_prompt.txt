Design a Verilog module that counts returnable rooms in a circular snake exhibition. The system has n rooms (scaled to max 16) arranged in a circle with conveyor belts between adjacent rooms. Each belt has a direction: '>' (clockwise, allows flow i->i+1), '<' (anticlockwise, allows flow i+1->i), or '-' (off, allows both directions). A room is 'returnable' if a snake can leave and return to it. The core logic: If all belts are '>' or all are '<', all rooms are returnable. Otherwise, a room i is returnable if the belt to its left (connecting i-1 and i) or the belt to its right (connecting i and i+1) is '-'. Indices are circular modulo n.

Module Interface:
Inputs:
  clk: Clock signal (rising edge).
  rst_n: Active-low synchronous reset.
  start: 1-cycle pulse to start processing a new test case.
  n: 5-bit unsigned integer (number of rooms, 2 <= n <= 16).
  belt_0, belt_1, ..., belt_15: 2-bit values representing belt directions (0='>', 1='<', 2='-'). Only indices 0 to n-1 are valid.

Outputs:
  result: 6-bit unsigned integer (count of returnable rooms, 0 to 16).
  done: 1-bit signal, pulsed high for 1 cycle when computation is complete. Result is valid when done is high.

Timing:
  Start pulse initiates the count. Computation should complete within 256 clock cycles (enough for n=16 with simple loops). Assert done when finished.
  Reset initializes all state: done=0, result=0, internal counters reset.

Implementation Requirements:
  1. Scale n to max 16 for hardware constraints.
  2. Use a Finite State Machine (FSM) or iterative logic.
  3. First, check if all belts are '>' (state 0) or all are '<' (state 1). If so, result = n, set done.
  4. If mixed directions, iterate i from 0 to n-1. For each i, check belt (i-1)%n and belt i. If either is '-', increment counter.
  5. Handle circular indexing carefully (e.g., belt index -1 wraps to n-1).
  6. Use fixed-width registers for counters and indices (e.g., 4-bit for i, 6-bit for counter).
  7. Do not use dynamic memory; loop iteratively.
