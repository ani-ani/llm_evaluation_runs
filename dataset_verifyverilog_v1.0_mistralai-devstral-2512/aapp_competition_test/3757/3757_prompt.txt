You are to implement a module that reconstructs a binary string given counts of subsequences.

Input Constraints:
- a00, a01, a10, a11 are 32-bit non-negative integers.
- The output string length must not exceed 1024 characters.
- If no valid string exists, output `Impossible`.

Module Interface:
- Inputs: `clk`, `rst_n`, `start`, `a00[31:0]`, `a01[31:0]`, `a10[31:0]`, `a11[31:0]`
- Outputs: `done` (1 cycle pulse), `valid` (1 when output char is valid), `result_char` (8-bit ASCII '0' or '1'), `is_impossible` (1 when impossible)

Algorithm Logic:
1. Determine the number of 0s (n0) and 1s (n1):
   - n0 must satisfy n0*(n0-1)/2 == a00. If a00=0, n0 can be 0 or 1.
   - n1 must satisfy n1*(n1-1)/2 == a11. If a11=0, n1 can be 0 or 1.
   - Valid pairs satisfy n0*n1 == a01 + a10.
2. If no valid (n0, n1) pair exists, assert `is_impossible`.
3. Construction (Greedy):
   - Maintain remaining `rem_a01` and `rem_a10`.
   - While n0 > 0 and n1 > 0:
     - If `rem_a01` >= n1: Output '0', decrement n0, subtract n1 from `rem_a01`.
     - Else: Output '1', decrement n1, subtract n0 from `rem_a10`.
   - Output remaining 0s or 1s.
4. Ensure the output string length fits within 1024.

State Machine:
- IDLE: Wait for start.
- CHECK: Validate inputs and find n0, n1.
- OUTPUT_CHAR: Stream characters to output bus (set `valid=1`).
- DONE: Assert `done` pulse.

Timing:
- Start to Done: < 5000 cycles.
- Output streaming: 1 cycle per character.
