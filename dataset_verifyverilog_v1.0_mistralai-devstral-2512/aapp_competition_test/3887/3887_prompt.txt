Implement a Verilog module that solves the rebus problem: ? + ? - ? + ? ... = n

**Specification:**

- **Input Format**: The rebus expression contains only '+', '-', '?' operators and a final integer n. No more than 16 question marks.
- **Output**: Determine if solution exists and output the assignment.

**Algorithm to Implement:**
1. Parse expression to count '+' and '-' operators
2. Initialize all '?' with value 1
3. Calculate current sum = (#pos) - (#neg)
4. If current_sum < n: increment positive terms until sum reaches n
5. If current_sum > n: increment absolute value of negative terms until sum reaches n
6. Check if sum equals n within constraints

**Verilog Interface:**

Inputs:
  - clk: clock (1 bit, rising edge)
  - rst_n: active-low synchronous reset (1 bit)
  - start: start processing (1 bit, 1-cycle pulse)
  - expr_data: packed expression data (max 128 bits, each byte represents a token: 1='?', 2='+', 3='-', 4='=', 0=end)
  - n_value: target integer value (16-bit, signed Q16.16 fixed-point)
  - num_qmarks: number of question marks (4-bit, 1-16)

Outputs:
  - result: output expression string (max 256 chars, ASCII encoded)
  - done: completion signal (1 bit, 1-cycle pulse)
  - possible: solution exists flag (1 bit)

**Constraints:**
- Maximum 16 question marks
- n value: up to 1,000,000 (scaled to 16-bit fixed-point)
- Each question mark value: 1 to n (scaled to 16-bit)
- Operation count: within 100 clock cycles
- Expression tokens: sequential byte array input

**Implementation Notes:**
- Use iterative state machine to parse and compute
- Store question mark signs in registers (1=positive, 0=negative)
- Use 16-bit arithmetic with saturation
- Output expression can be simplified (only show first and last values if many)
- For complexity, accept simplified output: just show first few values and result
