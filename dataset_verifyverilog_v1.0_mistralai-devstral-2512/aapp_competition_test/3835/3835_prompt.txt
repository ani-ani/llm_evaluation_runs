Design a Verilog module `matrix_restore` that recovers the original array `a[0:n-1]` from an `n x n` multiplication table `M` where diagonal elements are 0. Given `M[i][j] = a[i] * a[j]` for `i ≠ j`, we can compute `a[i]` using the formula: `a[i] = sqrt( M[i][(i+1)%n] * M[i][(i+2)%n] / M[(i+1)%n][(i+2)%n] )`.

**Interface:**
- `clk`: 1-bit, rising edge clock
- `rst_n`: 1-bit, active-low synchronous reset
- `start`: 1-bit, 1-cycle pulse to start computation
- `matrix[0:7][0:7]`: 8x8 array of 32-bit inputs (flattened as 64 signals `matrix_0_0` to `matrix_7_7` or a packed 32-bit array `matrix[0:63]`)
- `n`: 3-bit integer (2 to 8)
- `result[0:7]`: 8x32-bit outputs (flattened)
- `done`: 1-bit, pulses high for 1 cycle when all `result[i]` are valid

**Implementation Details:**
1. Use fixed-point Q16.16 for intermediate division/sqrt operations or integer-only math with rounding.
2. For each `i` from 0 to `n-1`:
   - Select `x = M[i][(i+1)%n]`, `y = M[i][(i+2)%n]`, `z = M[(i+1)%n][(i+2)%n]`
   - Compute `temp = (x * y) / z` (use 64-bit multiplication to avoid overflow, then divide)
   - Compute integer square root of `temp`. Use a non-restoring square root algorithm or a small lookup table for values ≤ 10^9.
   - Assign `result[i] = sqrt(temp)`
3. Use a state machine with states: IDLE, COMPUTE, OUTPUT, DONE.
4. Pipeline or sequential computation: Since n ≤ 8, compute each `a[i]` in 1-2 clock cycles.
5. Output width: `a_i` ≤ 10^9, fits in 32 bits. Intermediate `x*y` ≤ 10^18 (needs 60 bits), division reduces to ≤ 10^9.
6. Timing: start to done within 50-100 cycles.
7. Reset: all outputs 0, done=0.

**Edge Cases:**
- n < 8: ignore extra matrix entries.
- Division by zero: Not possible per problem guarantee.
- Integer sqrt: Round down (floor).

**Verilog Code Style:**
- Use combinational blocks for sqrt if small.
- Use sequential FSM for control.
- No dynamic memory, all sizes fixed.
