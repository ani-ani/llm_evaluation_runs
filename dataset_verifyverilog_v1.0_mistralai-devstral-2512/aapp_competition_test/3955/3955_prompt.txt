Implement a Verilog module that computes the maximum bitwise OR of an array after multiplying one element by x^k.

Constraints: n=8 elements, values 0-32 bits, k≤10, x=2-8. All operations use 32-bit unsigned arithmetic.

Algorithm:
1. Compute x_power = x^k (32-bit result)
2. For each position i (0 to n-1):
   - Compute left_OR = OR of a[0] to a[i-1] (0 if i=0)
   - Compute right_OR = OR of a[i+1] to a[n-1] (0 if i=n-1)
   - Compute candidate = left_OR | (a[i] * x_power) | right_OR
3. Return maximum candidate

Interface:
- Inputs: clk, rst_n, start, arr[0:7] (8x32-bit), k[3:0] (0-10), x[3:0] (2-8)
- Outputs: result[31:0], done (1-cycle pulse)
- Timing: start->done within 500 cycles
- Reset: done=0, result=0

Behavior: On rising edge after start, compute result. Set done=1 for 1 cycle when complete. Keep result valid until next start.
