Design a Verilog module that solves the minimal pile counting problem for up to 16 boxes. Given an array of box strengths (0-255), sort them ascending and greedily assign each box to an existing pile where the pile height <= box strength, or start a new pile if none exist. This yields the minimal number of piles.

**Interface Specification:**
- Inputs:
  - `clk`: Clock signal (rising edge)
  - `rst_n`: Active-low synchronous reset
  - `start`: 1-cycle pulse to start computation
  - `len`: 4-bit input (0-15) indicating number of boxes (n)
  - `arr[15:0]`: 16x8-bit array of box strengths (0-255)
- Outputs:
  - `result`: 8-bit output (0-255, minimal piles)
  - `done`: 1-cycle pulse indicating valid result

**Behavioral Specification:**
1. On reset: `done` = 0, `result` = 0
2. When `start` = 1: Begin processing
3. Algorithm (iterative, bounded by 256 cycles max):
   - Sort `arr` ascending using insertion sort (bounded 16^2 cycles)
   - Initialize pile_count = 0, pile_heights[0..15] = 0
   - For each box strength s in sorted array:
     - Find first pile where pile_heights[i] <= s
     - If found: increment pile_heights[i]
     - Else: create new pile (pile_count++, pile_heights[pile_count-1] = 1)
   - Output pile_count as result
4. Set `done` = 1 for 1 cycle when complete
5. Ready for new `start` pulse after `done`

**Timing:**
- start->done within 256 cycles
- Sample result when done=1
- Reset clears all state in 2 cycles

**Constraints:**
- Use only combinational logic and bounded sequential loops
- No unbounded memory or recursion
- Handle n=0 case: result = 0, done = 1 immediately
