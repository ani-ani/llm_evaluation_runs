You are to design a Verilog module that finds a path of length 9 (9 nodes) in a directed graph where nodes have unique labels (artists). 

**Specifications:**
- Input graph has N nodes (9 <= N <= 16).
- Each node has a label (artist name, mapped to integer ID 0-15).
- Each node has outgoing edges to other nodes.
- **Constraints:**
  1. Path length must be exactly 9 nodes.
  2. All nodes in the path must have distinct labels (artists).
  3. Edges are directed.

**Module Interface:**
- **Inputs:**
  - `clk`, `rst_n`: Standard clock and async reset.
  - `start`: 1-cycle pulse to start search.
  - `node_count`: 4-bit input, number of nodes in graph (1..16).
  - `labels[0:15]`: 16x4-bit array, artist ID for each node index (0-15).
  - `adj_matrix[0:15][0:15]`: 16x16 bit matrix, adj_matrix[i][j]=1 if edge i->j exists.
- **Outputs:**
  - `path[0:8]`: 9x4-bit array, the found path (node indices).
  - `done`: 1-cycle pulse when search completes (success or fail).
  - `found`: 1-bit register, high if valid path found.

**Behavior:**
- On `start` assert, perform a depth-limited search (DFS) for path length 9.
- Use a stack or iterative state machine to explore paths.
- Maintain a `visited_labels` bitmask (16 bits) to ensure unique artists.
- Limit total exploration cycles to 10,000 to prevent hang.
- If path found, assert `found=1`, output path in `path[0:8]`, then `done`.
- If no path found or cycle limit reached, assert `found=0`, output zeros, then `done`.

**Timing:**
- `start` to `done` within 10,000 cycles.
- `path` valid only when `done` is high.

**Hardware Constraints:**
- Depth 9 is fixed; recursion must be unrolled or iteratively managed.
- Use 16-bit visited label mask.
- Node indices are 0-based in hardware (input is 1-based, convert internally if needed).
