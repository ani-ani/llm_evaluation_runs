Design a Verilog module 'superdoku_solver' that solves an 8x8 Latin Square completion problem. The system receives the first k (k ≤ 4) rows of an 8x8 grid and must fill the remaining rows such that every row and column contains distinct integers from 1 to 8.

Inputs:
  clk: Rising edge clock
  rst_n: Active-low synchronous reset
  start: 1-cycle pulse to initiate solving
  input_row[2:0]: 3-bit index of the current input row (0 to 4)
  input_col[2:0]: 3-bit index of the current input column (0 to 7)
  input_val[3:0]: 4-bit value (1-8) to place at (input_row, input_col)
  valid_input: 1-bit flag indicating the current (input_row, input_col, input_val) is valid and should be stored

Outputs:
  result_grid: A 1D array of 64 4-bit values representing the solved 8x8 grid (Row-major order: row 0 col 0, ..., row 7 col 7).
  done: 1-cycle pulse when a solution is found or determined impossible
  solvable: 1-bit valid when done=1. 1 if solution found, 0 if impossible.

Internal Logic Constraints:
  1. Input Phase: Assume input is streamed in order (row by row). Use a internal RAM or registers to store the fixed rows.
  2. Search Algorithm: Implement a recursive backtracking algorithm iteratively. Iterate rows from k to 7. For each row, iterate columns 0 to 7. Try values 1 to 8. Check column constraints against already filled rows in current column and previously placed values in current row.
  3. State Machine: Use a Finite State Machine (FSM) with states: IDLE, LOAD_INPUT, FIND_SOLUTION, FOUND, IMPOSSIBLE.
  4. Resource Bounds: Use a 32-bit integer for tracking column usage (bitmask). Use a fixed 8x8 register array for the current solution attempt.
  5. Timing: Start to Done must complete within 10,000 clock cycles. If no solution found within 10,000 cycles, assume impossible and set done=1, solvable=0.
  6. Output: When solvable=1, output the full 8x8 grid (including initial rows) on 'result_grid'.

Testbench Requirements:
  - Initialize with a valid partial grid (e.g., first 2 rows of an 8x8 magic square).
  - Verify that the resulting grid is a valid Latin square (rows and columns contain distinct values 1-8).
  - Test an invalid case (duplicate in a row within initial input).
  - Check the 'done' and 'solvable' flags correctly.
