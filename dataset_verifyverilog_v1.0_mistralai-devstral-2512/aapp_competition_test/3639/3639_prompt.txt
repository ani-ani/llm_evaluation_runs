Implement a Verilog module that computes the minimum total wetness (rain + sweat) for a cyclist given rainfall forecast and distance constraints.

**SCALED CONSTRAINTS**:
- Maximum time intervals T: 32 minutes (instead of 10000)
- Distance d: Fixed-point Q8.8 (0.01 to 50 km) scaled to 8.8 = 8 integer + 8 fractional bits
- Constant c: Fixed-point Q8.8 (0.01 to 10) scaled to 8.8
- Rain values: 0-100 ml per minute, 7-bit width (max 127)
- Time precision: Q16.16 fixed-point for fractional minutes
- Result: Q16.16 fixed-point output

**MODULE INTERFACE**:
- Inputs:
  - clk: system clock
  - rst_n: active-low synchronous reset
  - start: 1-cycle pulse to begin computation
  - T_in[4:0]: 5-bit unsigned (1-32 minutes)
  - c_fixed[15:0]: Q8.8 fixed-point representation of c
  - d_fixed[15:0]: Q8.8 fixed-point representation of distance d
  - rain[0:31]: 32×7-bit array of rain values per minute
- Outputs:
  - result[31:0]: Q16.16 fixed-point total wetness
  - done: 1-cycle pulse when computation complete

**ALGORITHM SPEC**:
Implement dynamic programming with time discretization to minute boundaries and fractional minute optimization:

1. **State Machine**:
   - IDLE: Wait for start
   - SETUP: Initialize DP arrays
   - COMPUTE: Run DP for all time intervals
   - DONE: Latch result

2. **DP Formulation**:
   Let dp[i][j] = minimum wetness to be at distance j at time i (in minutes, 0 to T)
   - Distance resolution: 32 steps (0 to d in 1/32 increments)
   - Time resolution: T steps (0 to T minutes)
   - For each time step i and distance j:
     - Consider all possible speeds v (limited to 8 discrete values for efficiency)
     - v = (distance_step) / (time_step)
     - Sweat at speed v: s = c * v² per minute
     - Total sweat for Δt minutes: s * Δt
     - Rain for partial minute: fraction * rain[minute]
     - dp[i+1][j + speed * Δt] = dp[i][j] + sweat + rain_fraction

3. **Sweat Calculation**:
   - v = distance_covered / time_taken (km/h)
   - s = c * v² (ml/min)
   - Fixed-point multiplication: use shift and multiply
   - v²: Q16.16 * Q16.16 = Q32.32 → truncate to Q16.16
   - Multiply by c: Q16.16 * Q8.8 = Q24.8 → normalize to Q16.16

4. **Rain Integration**:
   - If crossing minute boundary k to k+1 with fraction f:
   - Rain = (1-f)*rain[k] + f*rain[k+1]
   - For complete minutes: sum rain[k] for k in range

5. **Optimization**:
   - Distance granularity: d/32 steps
   - Time granularity: 1/8 minute (7.5 second) increments for better precision
   - Maximum states: 32 time × 32 distance = 1024 states
   - Each state stores: wetness (Q16.16), previous state pointer

6. **Bit Widths**:
   - Wetness accumulation: Q24.8 (allow headroom, normalize to Q16.16)
   - Intermediate products: Q32.32 for v² * c
   - Distance traveled: Q16.16
   - Time elapsed: Q16.16

7. **Control Logic**:
   - Accept start pulse
   - Run DP computation over T minutes
   - At each minute, update DP state for all possible distances
   - When time reaches T, find minimum wetness for distance >= target
   - Output that minimum and set done=1

**IMPLEMENTATION NOTES**:
- Use block RAM for rain values (32 × 7-bit)
- Use dual-port block RAM for DP states (1024 × 32-bit entries)
- Pipeline multiplication operations for Q16.16 arithmetic
- Unroll loops for distance dimensions (max 32)
- Loop bound for time: 32 iterations max
- Speed values: precompute 8 discrete speeds (0.5 to 5.0 km/h in steps)

**TIMING**:
- start → done: within 2000 cycles (32 × 32 × 2 + overhead)
- Clock frequency: 100 MHz standard

**RESET BEHAVIOR**:
- rst_n=0: done=0, result=0, all state machines idle
- After 2 cycles of reset, ready for start

**RESULT FORMATTING**:
- Output is Q16.16 fixed-point
- To convert to float: divide by 2^16
- Example: 288.0 = 288 × 65536 = 18874368 (decimal)

**ERROR HANDLING**:
- If T=0 or invalid inputs: return 0
- Clamp speeds to valid range (0 to max_speed)
- Handle edge case: distance=0 → result=0

Provide the complete Verilog module implementation with all helper functions for fixed-point arithmetic.
