Design a Verilog module that solves the gear ratio problem for BicycleCo. The module must find two front sprocket sizes (f0, f1) and six rear sprocket sizes (r0..r5) such that the 12 input ratios n_i/d_i equal f_j / r_k for some j in {0,1} and k in {0..5}.

**Problem Reduction**: Since input ratios n_i/d_i are between 1/100 and 100/1, we can scale search space. Let's assume front sprockets are bounded 1-100 and rear 1-100 (scaled later). For each of 12 input ratios, we need to find which front/rear pair produces it.

**Algorithm**: 
1. Parse 12 input ratios (n_i, d_i) as 8-bit integers (since n_i,d_i ≤ 100).
2. For each possible front sprocket f in range 1-100 (or scaled), compute required rear sprocket r for each input ratio: r = (f * d_i) / n_i (must be exact integer).
3. Verify consistency: All 12 ratios must be generated by exactly 2 front and 6 rear sprockets.
4. Output valid sizes (f0,f1) and (r0..r5). Scale up to 1-10000 if needed.

**Simplified HW Implementation**: 
- Use fixed iteration bounds: 100 cycles for front search, 12 cycles for ratio processing.
- Compute r = (f * d) // n with overflow protection (use 16-bit multiply).
- Track unique rear candidates per front.
- Return first valid combination found.

**Module Interface**:
Inputs:
  clk, rst_n: Standard clock/reset
  start: 1-cycle pulse to start computation
  ratio_n[0:11], ratio_d[0:11]: 12 pairs of 8-bit input ratios (n_i, d_i)

Outputs:
  front0, front1: 8-bit (output front sprockets)
  rear0..rear5: 8-bit (output rear sprockets)
  valid: 1-cycle pulse when solution found (if valid=0 after computation, impossible)
  done: 1-cycle pulse when search completes (valid will be defined)

**Timing**: start->done within 2000 cycles (100*12*2 iterations)
**Constraints**: All outputs must be ≤ 10000 (output 8-bit scaled, user can multiply by 100 if needed)
**Reset**: all outputs = 0, valid=0, done=0

**Key Operations**:
- Multiplication: (front * d_i) → 16-bit product
- Division: (product / n_i) → integer check (product % n_i == 0)
- Set comparison: track unique front/rear sets
- Return first valid solution (any acceptable)

**Hardware Assumption**: For LLM generation, implement iterative search with bounded loops. Use FIFO/buffers for 12 ratios. Prioritize speed over exhaustive search.
