Implement a synchronous Verilog module for 'Rookie Bunny' license assignment. The module must handle sequential input of 4-bit time requirements (t_i) over a clock domain, with 4-bit service limits s1 and s2. The algorithm tracks the remaining time on both counters using a dynamic programming table (DP state) where state[i][j] is true if Counter 1 can serve up to customer k leaving j minutes, and Counter 2 serves the rest with i minutes (or vice versa). Since exact state space (1000*15*15) is large for 4-bit, implement a pipelined optimization: iterate customers 0 to n-1, maintaining a reachable set of (rem1, rem2) pairs using registers. For each customer t, update the reachable set by checking if t <= rem1 or t <= rem2. The maximum index reached is the output. Input interface: `clk`, `rst_n`, `start` (1-cycle pulse), `n` (4-bit), `s1` (4-bit), `s2` (4-bit), `t_i` (4-bit, provided sequentially when `load_ready` is high). Output: `result` (4-bit count), `done` (1-cycle pulse). Output valid when `done` is high. Timing: `start` to `done` within 256 cycles. Reset initializes `result` to 0, `done` to 0. The module should use a Moore FSM to control the input loading and DP calculation phases.
