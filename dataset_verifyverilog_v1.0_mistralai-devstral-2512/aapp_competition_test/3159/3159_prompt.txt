Implement a Verilog module that detects and removes advertisement images from a simulated web page.

**Problem Adaptation:**
- The web page is a fixed 200x200 grid of ASCII characters (8-bit).
- Images are rectangular frames bordered by '+' characters.
- Images are 3x3 minimum and do not share borders (no touching edges or corners).
- Nested images are allowed.
- Banned characters (everything except alphanumeric, '?', '!', ',', '.', space) trigger removal of the smallest enclosing image.
- When an image is removed, its content (including borders) is replaced with spaces (0x20).

**Module Interface:**
- **Inputs:**
  - `clk`: System clock (rising edge).
  - `rst_n`: Active-low synchronous reset.
  - `start`: 1-cycle pulse to begin processing.
  - `din`: 8-bit character input (row-major order).
  - `din_valid`: 1 when `din` contains valid data.
- **Outputs:**
  - `dout`: 8-bit character output (processed grid).
  - `dout_valid`: 1 when `dout` is valid.
  - `done`: 1-cycle pulse when processing is complete.

**Implementation Requirements:**
1. **Buffer Phase:** Clock in the 200x200 grid (40,000 characters) into internal Block RAM (BRAM).
2. **Detection Phase:** Scan the grid to identify all rectangle borders (frames) defined by '+'.
   - Store coordinates: Top-Left (x1, y1) and Bottom-Right (x2, y2) for each detected frame.
   - Use a stack or list to handle nesting (innermost frames are pushed last).
   - Maximum frames: 100 (scaling constraint).
3. **Validation Phase:** For each detected frame, scan its interior (excluding borders) for banned characters.
   - Allowed: a-z, A-Z, 0-9, '?', '!', ',', '.', space.
   - Banned: anything else (e.g., '#', '=', '>', '=').
4. **Selection Phase:** If a frame contains banned characters, flag it as an ad.
   - Conflict Resolution: If a larger frame also contains a banned character, the *smallest* enclosing frame is removed. 
   - Area Calculation: Width = (x2 - x1 + 1), Height = (y2 - y1 + 1). Area = Width * Height.
   - Strategy: Store flagged frames. Sort or compare by area (pixel count). **Control Flow (FSM):**
- **IDLE**: Wait for `start`.
- **LOAD**: Shift in 40,000 chars into BRAM (1 char/cycle).
- **SCAN**: Iterate through grid to find '+' corners. 
  - Horizontal scan: Identify top/bottom rows.
  - Vertical scan: Identify left/right columns.
  - Validate rectangle structure (corners match).
  - Store frame data (x1, y1, x2, y2) in a small FIFO/RAM (max 100 entries).
- **CHECK**: Iterate through stored frames. For each frame, scan interior for banned chars.
  - If banned char found, calculate area (W*H). 
  - Keep track of the minimal area frame for each banned char location (requires mapping or simply processing innermost first).
  - Simplified: Sort frames by area (ascending). Iterate. If a frame contains a banned char AND is not inside a previously marked frame (already removed), mark it for removal.
- **OUTPUT**: Iterate through grid. If coordinate is inside a marked frame, output 0x20, else output stored char.
- **DONE**: Pulse `done`.

**Signal Widths:**
- Grid Index: 12 bits (0-39999).
- Coordinates (Row/Col): 8 bits (0-199).
- Frame Count: 8 bits (0-100).
- Area: 16 bits (200*200).
- Character: 8 bits.

**Verilog Module Spec:**
- **Depth:** 40,000 x 8-bit buffer (use inferred BRAM).
- **Frame Storage:** 100 entries x 4 x 8-bit (x1, y1, x2, y2).
- **Logic:** 
  - `LOAD`: `addr <= addr + 1`, `mem[addr] <= din`.
  - `SCAN`: Double loop (i=0 to H-1, j=0 to W-1). Detect '+' corners. 
    - Top-Left: mem[r][c]=='+' && mem[r][c+1]=='-'? No, check horizontal runs of '+' and vertical runs of '+'.
    - Simple Scan: Find top-left '+'. Scan right for '+', down for '+'. Check bottom-right '+'. 
    - Store if valid rectangle and borders don't touch others.
  - `CHECK`: 
    - Sort frames by area (insertion sort in hardware for small N=100).
    - Iterate `pixel_idx` 0 to 39999.
    - Calculate `r`, `c` from `pixel_idx`.
    - If `char` is banned:
      - Loop `f_idx` 0 to N-1. If `pixel_in_frame(r, c, frame[f_idx])` -> `mark[f_idx] = 1`. Break.
  - `OUTPUT`: 
    - Iterate `pixel_idx` 0 to 39999.
    - `dout = space` if `pixel_in_marked_frame` else `mem[pixel_idx]`.
