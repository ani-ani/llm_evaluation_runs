Implement a Verilog module to classify touch gestures (pan, zoom, rotate) between two 15x30 pixel binary images. The module processes both images simultaneously, each represented as a 1D array of 450 pixels (packed or unpacked). The inputs include the initial image mask, the final image mask, and a 'start' signal. The module must detect connected components (touches) in both images (assuming up to 5 touches), calculate touch points (average position), grip points, grip spreads, and distances for pan, zoom, and rotation. 

The output should be the number of touches (3 bits) and the gesture type (3 bits: 000=pan, 001=zoom, 010=rotate) with direction (2 bits for zoom/rotate: 0=in/counter-clockwise, 1=out/clockwise). Use 'done' signal when complete. Use fixed-point arithmetic (Q16.16) for all calculations. Assume 1-to-1 correspondence between touches (since input guarantees same number). Minimizing squared distance for correspondence is simplified to matching touches in order of discovery or sorting by x/y coordinate.

Interface:
Inputs: clk, rst_n, start, init_img[449:0] (1-bit per pixel), final_img[449:0] (1-bit per pixel).
Outputs: touches[2:0], gesture_type[2:0], direction[1:0], done.
Constraint: Max 5000 clock cycles for computation.
