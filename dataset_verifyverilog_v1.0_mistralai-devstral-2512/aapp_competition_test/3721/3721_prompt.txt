Implement a Verilog module that computes the minimal number of purchases for an n×m periodic table with q existing elements. Model this as a bipartite graph: rows (0 to n-1) and columns (0 to m-1) are nodes, and element (r,c) is an edge connecting row r-1 and column m+c-1. The answer is (number of connected components) - 1. Use a Disjoint Set Union (DSU) with up to 200 nodes (n ≤ 200, m ≤ 200, n+m ≤ 200). Inputs: clk, rst_n, start, q (4-bit), and q pairs of (row, col) on a single port (row_col_packed[15:0] where [15:8]=row-1, [7:0]=col-1). Output: result (8-bit) and done (1-cycle pulse). Use 16-bit inputs for rows/cols (scaled). Reset sets result=0, done=0. Processing: When start=1, read q elements sequentially (1 per cycle) and update DSU. After q cycles, compute components = (n+m) - merges. Output result = components - 1. Ensure DSU handles up to 200 nodes with 8-bit indices.
