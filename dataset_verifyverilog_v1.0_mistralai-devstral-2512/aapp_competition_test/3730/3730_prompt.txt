Implement a Verilog module that finds the maximum length of a subsegment where at most one number can be changed to make it strictly increasing.

**Inputs:**
- `clk`: Clock signal (rising edge triggered)
- `rst_n`: Active-low synchronous reset
- `start`: 1-cycle pulse to start computation
- `arr[0:15]`: 16-element array of 8-bit unsigned integers (input sequence, n ≤ 16)
- `n`: 4-bit input (actual length of sequence, 1-16)

**Outputs:**
- `result`: 8-bit output (maximum subsegment length)
- `done`: 1-cycle pulse indicating result is valid

**Behavior:**
1. On `start` pulse, reset internal state and begin computation.
2. Compute two arrays: `left[i]` (length of increasing subsegment ending at i) and `right[i]` (length of increasing subsegment starting at i).
3. Calculate maximum answer considering:
   - Single increasing segment (max of left/right)
   - Merging two segments by changing one element (if arr[i-1] + 1 < arr[i+1])
   - Extending by one (answer + 1 if answer < n)
4. Set `result` when done and pulse `done` for 1 cycle.
5. Timing: Must complete within 256 cycles from start.
6. Reset: During `rst_n=0`, set `done=0`, `result=0`.

**Constraints:**
- Array length: max 16 elements
- Data width: 8 bits (0-255)
- Internal counters/indices: 4-8 bits
- State machine: 3-5 states
- No external memory, pure combinational/sequential logic.

**Interface Example:**
- `arr[0]` to `arr[15]` are individual 8-bit inputs
- All indices used must be within `n` range (0 to n-1)
- Edge cases: n=1 (return 1), n=2 (return 2), all increasing (return n)
