Design a Verilog module that constructs a forest (acyclic graph) with given vertex degrees. Scale constraints: V ≤ 16 nodes, degrees ≤ 255 (8-bit), max edges ≤ 15. Implement the following algorithm:

1. Input: V (4-bit), deg[0:15] (16x8-bit array)
2. Validate: Sum of degrees must be even, max degree ≤ V-1, no isolated nodes unless V=1
3. For forest feasibility: Sum(deg) ≤ 2*(V - num_components) where num_components is count of non-zero degrees
4. If possible, generate edges using degree-matching: repeatedly pair vertices with highest degrees, ensuring no cycles
5. Output: done (1-cycle), possible (1-bit), edges_a[0:14] (15x4-bit), edges_b[0:14] (15x4-bit), edge_count (4-bit)

Interface:
- Inputs: clk, rst_n, start (1-cycle), V (4-bit), deg[0:15] (8-bit each)
- Outputs: done (1-cycle when valid), possible (1-bit), edges_a[0:14], edges_b[0:14], edge_count (4-bit)
- Timing: start->done within 256 cycles
- Reset: done=0, possible=0, edge_count=0, edges=0

Implementation details:
- Use FSM with states: IDLE, VALIDATE, SORT_DEGS, GENERATE_EDGES, DONE
- Sort vertices by degree (descending) using bubble sort (16 items, 256 cycles max)
- Generate edges: pair highest degree vertices while maintaining acyclic property
- Check for cycles using BFS/DFS on 16-node graph (implement with 16-bit visited masks)
- Output edges in order, unused entries (edge_count to 14) set to 0
- Fixed-point arithmetic not needed here, use integer counters
- Edge validation: a and b must be 1-indexed (1-16)
