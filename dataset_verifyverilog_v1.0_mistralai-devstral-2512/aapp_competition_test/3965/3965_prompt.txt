Implement a Verilog module `verse_matcher` that checks if a text matches a verse pattern by counting vowels in each line.

**Interface:**
- Inputs:
  - `clk`: Main clock (rising edge)
  - `rst_n`: Active-low synchronous reset
  - `start`: 1-cycle pulse to begin processing a line
  - `line_str`: 8-bit array of size 16, representing ASCII characters of the current line (fixed width 16 chars, space-padded if shorter)
  - `line_len`: 4-bit input (0-15) indicating actual length of valid characters in `line_str`
  - `target_p`: 8-bit input, the expected vowel count for this line
- Outputs:
  - `match`: 1-bit, asserted high for one cycle when the line matches the target pattern
  - `done`: 1-bit, asserted high for one cycle when processing of the line is complete

**Behavior:**
1. Upon `start` assertion, process `line_str` up to `line_len`.
2. Identify vowels as 'a', 'e', 'i', 'o', 'u', 'y' (ASCII values: 97, 101, 105, 111, 117, 121).
3. Count the number of vowels in the line.
4. After counting, compare the count to `target_p`.
5. Assert `match` if equal, otherwise de-assert.
6. Assert `done` to signal completion.

**Constraints:**
- Use combinational logic for character comparison (lookup table or casex).
- The counting logic should be pipelined or iterative to fit within FPGA resources. Max 256 cycles per line.
- Handle `line_len` correctly: do not process characters beyond this length.
- `line_str` is an array of 16 signals. Each signal is 8 bits wide.
- Reset state: `match` = 0, `done` = 0.
